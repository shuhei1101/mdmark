# 配布物を読み込む

バージョンを固定した URL で JavaScript と CSS を読み込む

mdmark を使用するページを作るときに実行する。
サーバーの言語に関わらず、ページに記載したタグだけで使用できる。

## 前提

- 読み込むバージョンのタグが公開されている（[変更履歴](../../はじめに/変更履歴.md) に載っているバージョン）

## 手順

### 読み込むバージョンのタグを決める

[変更履歴](../../はじめに/変更履歴.md) から使用するバージョンを選び、`v{MAJOR}.{MINOR}.{PATCH}` の構造のタグで記録する。
ブランチ名・`latest`・バージョンの範囲は使用しない。
CDN にキャッシュされ、新しいバージョンへ切り替わるまで時間がかかる（[配信元の説明](https://github.com/jsdelivr/jsdelivr)）。

### CSS と JavaScript を読み込む

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{タグ}/dist/index.css">
<script type="module">
  import { version } from "https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{タグ}/dist/index.js";

  console.log(version());
</script>
```

`{タグ}` を手順の最初に決めたタグに置き換える。
2 つの URL で同じタグを使用する。
違うタグにすると、CSS と JavaScript のバージョンが食い違う。

## 反映

即時。ページを再読み込みすると、記載したタグのバージョンが読み込まれる。

## 確認

#### 公開関数がバージョンを返却する

ブラウザの開発者ツールのコンソールを開く。

コンソールに出た `console.log(version())` の出力が、記載したタグと同じ `v{MAJOR}.{MINOR}.{PATCH}` になる。

#### CSS が読み込まれている

```js
getComputedStyle(document.documentElement).getPropertyValue("--mdmark-version")
```

記載したタグと同じバージョンを引用符で囲んだ文字列が出る。

#### 読み込めなかったとき

タグかファイルが無いと、CDN は 404 を返却する。
ページの本文はそのまま表示され、`index.js` を読み込めなかったエラーがコンソールに出る。
タグの記載し間違いと、そのタグが公開されているかを確認する。

## 元に戻す

`<link>` と `<script>` の 2 行をページから削除する。
CDN にもページにも残るものはない。
