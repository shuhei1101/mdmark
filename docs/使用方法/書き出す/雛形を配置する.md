# 雛形を配置する

`mdmark init` で設定・`theme.css`・索引・拡張のビルドの雛形を配置する手順

書き出しに使用する設定と索引と利用側の CSS を、フォルダに初めて用意するときに実行する。

## 前提

- Node 24 以降

## 手順

### 雛形を配置する

#### `init` を呼ぶ

```bash
npx github:shuhei1101/mdmark#v{バージョン} init [{配置先のフォルダ}]
```

`{バージョン}` は使用するバージョンの `{MAJOR}.{MINOR}.{PATCH}`。
バージョンは [変更履歴](../../はじめに/変更履歴.md)。
配置先のフォルダを省くと今のフォルダに配置する。
配置先のフォルダが無ければ作る。

次のファイルを、この順に配置する。

- `mdmark.config.yaml`: `version`・`index`・`theme`・`build` を記載した設定
- `theme.css`: CSS 変数を上書きする例
- `index.yaml`: 文書と用語が 0 件の索引
- `extensions/example.ts`: `registerExtension` に指定する拡張を既定の export にする例
- `tsconfig.json`・`package.json`: 拡張の型の検査と JavaScript への変換のコマンド

配置したファイルごとに 1 行ずつ出る。

```text
配置した: mdmark.config.yaml
配置した: theme.css
配置した: index.yaml
配置した: extensions/example.ts
配置した: tsconfig.json
配置した: package.json
```

配置した設定の `version` は、呼んだ CLI のバージョン。
手元のバージョンとして、`mdmark upgrade` が読み込む（[バージョンを上げる](../導入/バージョンを上げる.md)）。
配置した設定と索引は、`schemas/mdmark.config.schema.json` と `schemas/mdmark.index.schema.json` に合う。

#### 既にあるファイルを残す

既にあるファイルは、中身を読み込まず上書きしない。
配置しなかったファイルは `配置しなかった（既にある）:` の行で出る。

```text
配置しなかった（既にある）: mdmark.config.yaml
配置した: theme.css
```

#### JavaScript で記載するときは `--js` を付ける

```bash
npx github:shuhei1101/mdmark#v{バージョン} init --js
```

`extensions/example.ts` の代わりに `extensions/example.js` を配置し、`package.json` は配置しない。
`extensions/example.js` は先頭に `// @ts-check` を配置し、JSDoc の `@type` で `MdmarkExtension` の型を付けた例。
配置する `tsconfig.json` は JavaScript を変換せずに点検する（`allowJs`・`checkJs`・`noEmit`）。
使用するバージョンの `dist/index.d.ts` を `mdmark/` に配置して `npx tsc --noEmit` を実行すると、型を誤った行がファイルと行つきで出る（[固有の部品とCSSを適用する](../図を描く/固有の部品とCSSを適用する.md)）。

#### 記載できないとき

配置先のフォルダを作れないときと、ファイルを書き込めないときは、標準エラーに書き込めなかったパスと修正方法の 1 文を出し、終了コード 1 で終わる。
それまでに記載できたファイルは残る。

## 反映

即時。`init` が終わると、ファイルがその場に配置されている。

## 確認

#### 雛形が配置されている

`配置した:` の行が出て、`init` の終了コードが 0 になる。
配置しなかったファイルがあっても、終了コードは 0 になる。
文書を追加した後の点検は [点検する](./点検する.md)。

## 元に戻す

配置したファイルを削除する。
配置しなかったファイルは `init` が変えていないため、戻すものは無い。
