# MCP のツールを使用する

ガイドを dev-docs で参照させ、文書の書き出し・まとめ・点検を Claude Code から呼ぶ手順

プラグインを入れた後、Claude Code に mdmark の文書を記載させるとき、書き出し・点検を頼むときに実行する。
ツールの引数・戻り値・エラーは [MCP](../../リファレンス/MCP.md)。

## 前提

- [プラグインを入れる](./プラグインを入れる.md)
- [常駐サーバーを起動している](./MCPサーバーを起動する.md)
- 設定ファイル `mdmark.config.yaml` をセッションのフォルダか上のフォルダに配置している（[雛形を配置する](../書き出す/雛形を配置する.md)）
- ガイドを参照させるときは、mdmark のクローンを dev-docs の配信元 `mdmark` として登録している（[プラグインを入れる](./プラグインを入れる.md)）

## 手順

### ガイドを参照させる

#### mdmark の文書を記載するよう頼む

記法・部品・図の描き方・拡張の仕方を使用する作業を頼むと、Claude Code が MCP サーバーの `instructions` に従い、dev-docs の `search_docs` で配信元 `mdmark` の `docs` の行をタグ `topic:ガイド` で絞って一覧を検索し、作業に要るページの本文を参照してから記載する。

```text
表に並べ替えを付けて、設計書の一覧を記載して
```

dev-docs が無い、または配信元 `mdmark` が登録されていないときは、ガイドを参照せずに記載する。
記載した後に `check` で点検させる。

### 点検する

#### `check` を呼ばせる

```text
mdmark の設定と索引を点検して
```

`check` が `mdmark check` と同じ点検をして、ずれの一覧（ファイル・場所・種類・内容）を返却する。
ずれがあってもエラーにならず、設定・索引・文書は書き換わらない。
内容にもう一度従ってせ、`issues` が空になるまで繰り返す。

YAML のキーの値や文字列に記載した記法を点検するときは、`check` に `file`・`key` か `text` を指定するよう頼む。
描いたときの記載の警告・描くときに無視するマーカーの知らない引数・知らないマーカー・図の配置のずれを、同じずれの一覧で返却する。

```text
records.yaml の items[0].body に記載した記法を mdmark で点検して
```

`change_together` の組のうち片方の文書だけを修正したことも点検するときは、比べる基準の git の ref を `base` に指定するよう頼む。

```text
origin/develop を基準に、mdmark の設定と索引を点検して
```

基準と HEAD の merge-base から変わった文書を比べ、片方だけが変わった組を `missed_change_together` で返却する。
`base` を省くと、修正漏れは点検しない。

### 文書を書き出す・まとめる

#### `export_html` と `build_site` を呼ばせる

```text
docs/guide.md を 1 枚の HTML に書き出して
```

```text
設定の build の文書を 1 枚の HTML にまとめて
```

`export_html` が `mdmark export`、`build_site` が `mdmark build` と同じ処理で HTML を書き込み、書き込んだパスと警告を返却する。
同じ文書・設定では、CLI と同じ中身の HTML になる。

### CSS のテンプレートを使用する

#### 作った CSS を登録させる

```text
brand.css を、見出しを社の色にする CSS としてテンプレートに登録して
```

`add_template` が CSS を端末の設定のフォルダの `templates/css/` へコピーし、名前・説明・タグを索引 `templates.yaml` に記載する。
同じ名前のテンプレートがあるときはエラーになり、何も書き換わらない。
置き換えるときは、上書きするよう頼む。

#### 一覧から選んで配置させる

```text
登録した CSS のテンプレートから、見出しの色を変えるものを選んで配置して、theme に記載して
```

`list_templates` がテンプレートの名前・説明・タグを返却し、選んだテンプレートを `apply_template` が最も近い `mdmark.config.yaml` のフォルダへコピーする。
`apply_template` は `theme` を書き換えず、記載する値（`./brand.css` など）を返却するので、その値を設定の `theme` に記載させる。
別のフォルダへ配置するときは、配置先のフォルダを `dir` に指定するよう頼む。

### 設定ファイルの場所を決める

ツールの `config` を省くと、端末の設定と、Claude Code のセッションのフォルダから上のフォルダの `mdmark.config.yaml` を重ねて読み込む（[設定を重ねて読み込む仕組み](../../はじめに/コアコンセプト/設定を重ねて読み込む仕組み.md)）。
別の設定ファイルを使用するときは、そのパスを `config` に指定するよう頼む。

## 反映

ツールを呼ぶたびに、その場の設定・索引・文書を読み込む。
`export_html`・`build_site` は HTML を書き込む。
`add_template` はテンプレートのフォルダに CSS と索引を、`apply_template` は配置先に CSS を書き込む。

## 確認

#### 点検のずれが 0 件になっている

`check` を呼ばせ、`issues` が空になる。

#### 書き出した HTML がある

`export_html` と `build_site` が返却した `out` のファイルがある。

#### テンプレートが登録され、配置されている

`list_templates` が登録した名前を返却し、`apply_template` が返却した `path` のファイルがある。

## 元に戻す

`check` は何も書き換えない。
書き出した HTML は、`out` のファイルを削除する。
登録したテンプレートは、テンプレートのフォルダの CSS と索引の行を削除する。
配置した CSS は、`path` のファイルを削除し、設定の `theme` から除外する。
