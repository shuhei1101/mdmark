| 子 | 終わりの条件 |
| --- | --- |
| [#368](https://github.com/shuhei1101/mdmark/issues/368) | `migrations/no-steps.yaml` の `schema: mdmark.settings.schema.json`・`schema: mdmark.templates.schema.json` の行を、配布物のビルドの移行の点検（`checkMigrations`）が誤りとして返さない。ER 図『移行の手順』の `schema` 列の `enum_values` と、インターフェース定義『配布物をビルドする』の「移行の手順の点検」の constraint が、`scripts/migrations.ts` の `CHECKED_SCHEMAS` と一致する |
