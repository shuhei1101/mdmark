## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 開発コマンドの配布ファイルの上限 | `CMD-472-1.yaml` の「ビルド・生成」の `effects` の `688KB` を `712KB` に置き換える。文のほかの部分は変えない | - |
| ガイドのページのエイリアスの判定 | `docs/guide/files.yml` の行ごとに、ページの名前と、本文・会話・Issue でそのページを呼んだ名前を候補に、判定フローチャート『エイリアスの登録』と判定表『エイリアスを登録しない条件』で判定する | 判定の結果を候補ごとに表にして、この計画書に記載する |
| `files.yml` の行の `id`・`aliases` | 登録すると判定したページの行に `id`（ガイドのページの変わらない ID）と `aliases` を記載する | `id` の付け方と、登録しないページの行の扱いは `未確定`（[要件](./要件.mark.md) の `## 要望`） |
| `project-index.yaml` の `docs` の行 | `id: docs` の行に `alias_type: doc` を付ける | - |
| 照合の確認 | project-index の `list_match_words`（`source: mdmark`）で、登録したページの名前と別名が `docs` の行から出ることと、ほかの文書・用語の単語と重ならないことを確認する | - |
