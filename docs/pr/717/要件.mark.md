# 要件

## 要望

map のクラス図で、ノート（`note for {クラス} "..."`）のノードの高さを、ノードの幅で折り返した文の行が全て入る高さにする。

- 文が 2 行以上に折り返しても、最後の行がノードの下端で切れず、ノードの矩形の中に描かれる
- 1 行に収まるノートのノードの大きさは変えない
- クラス・namespace のノードの大きさと、ノートとクラスをつなぐ破線は変えない
