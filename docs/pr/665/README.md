# 図のノードとグループの説明のマーカーを、押せる大きさ 24px 以上か隣の押せる要素と間を空けて描く

## 概要

読者が、図のノードとグループの説明のマーカーを、隣の押せる要素と押し間違えずに押せる。

## 背景

[map のノードの説明のマーカーを、押せる大きさ 24px 以上か、隣の押せる要素と間を空けて描く](https://github.com/shuhei1101/mdmark/issues/609) の要望。
作業 PR [#596](https://github.com/shuhei1101/mdmark/pull/596) の reviewer の対象外の逸脱の報告から切り出した。
`src/index.css` の `.mdmark-diagram-info` が 22px 四方で、ストーリー `Parts/MapState` の Collapsed が axe の `target-size` に該当する。
24px 四方に広げているのは、リンク先を持つノード・マインドマップ・軸と格子の配置の図の項目の中のマーカーだけ。
