# 要件

## 要望

- 図のノードの説明のマーカー（`button.mdmark-diagram-info`）を、押せる大きさ 24px 四方以上にするか、隣の押せる要素（ノードの押せる要素・リンク・開閉のボタン・タイトルのボタン）と、マーカーの中心から半径 12px の円が重ならない間を空けて描く
- 同じ型の箇所として、map の構成図のグループのタイトルの右の説明のマーカー（`.mdmark-diagram-info.mdmark-diagram-group-info`。18px 四方）も同じ基準に合わせる
- 同じ型の箇所として、埋め込んだ HTML の `data-hint` の要素の右上のマーカー（`.mdmark-hint-mark`。22px 四方）も 24px 四方以上にする
- 構成図・ER 図・状態遷移図・クラス図・アーキテクチャ図・C4 図の開いたノードと閉じたグループのノードで、ストーリーを axe にかけて `target-size` が出ない
- マーカーを広げても、ノードの名前・種類の行・閉じたグループの「{数} 件」の行と重ならない
