| 案 | 内容 |
| --- | --- |
| A | `plugin/` の下へ移す（`plugin/guide-index.yaml` など）。索引はプラグインのビルドだけが読み、プラグインには写さない |
| B | `docs/guide/` の下へ移す（`docs/guide/plugin-index.yaml` など）。索引が指すガイドのページと同じフォルダに並ぶ |
| C | `scripts/` の下へ移す。索引を読むビルドのスクリプトと並ぶ |

推奨: B

索引の中身はガイドのページの一覧と案内する場面で、ページと同じフォルダにあれば改名のたびに同じフォルダの中で合わせられるため。`plugin/` はプラグインの配布物のフォルダで、配布しない原本を混ぜると配布物と原本の区別が崩れる。

`未確定`: ガイドのページの GitHub 上の URL が変わる扱い（決める段: 単一ユースケース設計。規約『ユーザー確認が必須な事項』の「外へ出る・戻せない」に当たるためユーザーへ確認する）

| 案 | 内容 |
| --- | --- |
| A | 改名し、旧 URL は残さない（リポジトリの中のリンクは全て合わせる） |
| B | 改名し、旧パスに移動先へのリンクだけを持つ `.md` を残す |

推奨: A

旧パスの `.md` を残すと、拡張子だけが違う同名の文書が並び、ガイドの一覧と管理用の YAML の行が増えるため。
