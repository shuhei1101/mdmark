# 文書の先頭のフロントマターの title・tags などの値を、索引・文書の一覧・文書のタイトルに使用する

## 概要

文書を記載する人が、文書の先頭のフロントマターに記載した `title`・`tags` などの値が、索引の文書のメタデータ・まとめた HTML の文書の一覧・文書のタイトルに使用されるようになる。

## 背景

[文書の先頭のフロントマターの title・tags などの値を、索引・文書の一覧・文書のタイトルに使用する](https://github.com/shuhei1101/mdmark/issues/461) の要望。
[PR #422](https://github.com/shuhei1101/mdmark/pull/422)（[#325](https://github.com/shuhei1101/mdmark/issues/325)）で、フロントマターを描く前に本文から除外し、既定で表示しないようにした。
今の文書のタイトルは、索引の `title`、無ければ本文の最初の h1、無ければファイル名で決まり、フロントマターの値は使用されない。
コアコンセプト『索引と被参照』は、文書のメタデータを索引の YAML だけに持つと定めている。
