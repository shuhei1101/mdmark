## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 名前の幅の見積もり | `layoutMap` の引数 `measureText`（1 行の幅を返す関数）で、`textWidth`・`splitLines` の幅と行の分け方を決める。`attachMapFlow` は、範囲の要素の `font-family` と 14px・太字のフォントで canvas の `measureText` で測る関数（同じ文字の列は覚えて使い回す）を指定し、`extension.overrides` にも同じ関数を指定する。DOM を持たない `scripts/storybook-render.ts` と単体テストは、今の見積もりを `estimateTextWidth` として指定する | 案 A で決定（要件の `## 要望`）。ストーリーの描画は `未確定`（要件の `## 要望`） |
| 形状ごとの左の余白 | `LABEL_METRICS` に `pill` の左の余白 `padPill`（16px）を持たせ、`MapOverride` に `padLeft` を追加する。`attachMapFlow` が、種類の形状が `pill` のノードの上書きに `padLeft` を加え、`sizeLeaf` は `padLeft`（無ければ `padX`）で見積もる | `src/index.css` の `pill` の `padding-inline` のコメントに `LABEL_METRICS.padPill` と同じ値であることを記載する |
| 同じ型の見積もり | `class-diagram.ts` の `nameWidth` と `noteSize` も同じ名前の幅の求め方にする。`nameWidth` の左右の余白を、`padX * 2` から `sizeLeaf` と同じ `padX + padRight + border * 2` にする | クラスのノードにも map のノードの `padding-right: 28px` が適用されるため |
| 部品設計 | CMP-472-5・CMP-531-2・CMP-596-1 のノードの大きさの記述を、描いたフォントの名前の幅と形状ごとの左の余白で見積もる記述にし、状態 MeasuredName（構成図は `pill` のノードを含む）を追加する | - |
| モジュール構成 | MOD-472-141 の `layoutMap`（`measureText`）・`MapOverride`（`padLeft`）・`textWidth`・`splitLines`・`LABEL_METRICS`（`padPill`）と、`estimateTextWidth` の追加、MOD-472-130 の `attachMapFlow` の名前の幅を測る関数と `MapFlowExtension.overrides`、MOD-596-1 の `classPartInputs`、MOD-596-4 の `attachMapClass` を修正する | - |
| インターフェース定義 | IF-472-35 の構成図・状態遷移図・クラス図の結合テストのフローに、描いた名前の行の数が見積もりの行の数と一致し、`pill` のノードの名前が左の余白に食い込まない期待を追加する | - |
| 再現の見本 | `scripts/storybook-render.ts` に、`pill` の形状のノードと、半角の多い名前のノードを持つ構成図の見本を追加し、ブラウザで今の描画が見積もりと合わないことを確認してから修正する | - |
| テスト | 単体テストで、測った名前の幅で行に分けることと、`pill` のノードが左 16px の余白で見積もられることを確認する。結合テストで、ブラウザで描いた再現の見本のノードの名前の行の数が見積もりの行の数と一致することを確認する | - |
