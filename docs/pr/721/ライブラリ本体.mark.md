## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 名前の幅の見積もり | 描いたノードの名前と同じフォントで測った幅で、`textWidth`・`splitLines` の幅と行の分け方を決める。測れない環境では今の見積もりを使用する | `未確定`（要件の `## 要望` の案 A / B。決める段: モジュール構成設計） |
| 形状ごとの左の余白 | `LABEL_METRICS` に `pill` の左の余白 16px を持たせ、`sizeLeaf` がノードの種類の形状を受けて左の余白を選ぶ。他の形状は `padX` のまま | `src/index.css` の `pill` の `padding-inline` のコメントに `LABEL_METRICS` の値と同じことを記載する |
| 同じ型の見積もり | `class-diagram.ts` の `nameWidth` と `noteSize` も同じ名前の幅の求め方にする | - |
| 部品設計 | CMP-472-5 と CMP-531-2 のノードの大きさの記述を、描いたフォントの名前の幅と形状ごとの左の余白で見積もる記述にし、`pill` のノードの状態を追加する | - |
| モジュール構成 | MOD-472-141 の `textWidth`・`splitLines`・`sizeLeaf`・`LABEL_METRICS`、MOD-472-130 の `layoutMap` を呼ぶ前の処理、MOD-596-1 の `nameWidth` を修正する | - |
| インターフェース定義 | IF-472-35 の構成図・状態遷移図の結合テストのフローに、描いた名前の行の数が見積もりの行の数と一致し、`pill` のノードの名前が左の余白に食い込まない期待を追加する | - |
| 再現の見本 | `scripts/storybook-render.ts` に、`pill` の形状のノードと、半角の多い名前のノードを持つ構成図の見本を追加し、ブラウザで今の描画が見積もりと合わないことを確認してから修正する | - |
| テスト | 単体テストで、測った名前の幅で行に分けることと、`pill` のノードが左 16px の余白で見積もられることを確認する。結合テストで、ブラウザで描いた再現の見本のノードの名前の行の数が見積もりの行の数と一致することを確認する | - |
