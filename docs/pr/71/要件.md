# 要件

## 要望

インターフェース定義『文書を描く』の制約「対応ブラウザ」を、非機能要件『対応ブラウザ』の決定値と同じ Chrome 99・Firefox 98・Safari 16.4 以降にする。
制約の `decided_by`（非機能要件）は変えない。

## 影響するユースケース

| 種別 | ユースケース | 影響 | 依存 |
| --- | --- | --- | --- |
| 単一ユースケース | [使う側のページが文書を描く](https://github.com/shuhei1101/mdmark/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%82%B7%E3%83%8A%E3%83%AA%E3%82%AA/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/%E6%96%87%E6%9B%B8%E3%82%92%E6%8F%8F%E3%81%8F.yaml) | なし（インターフェース定義の制約の記述だけを直し、動作は変わらない） | |

なし
