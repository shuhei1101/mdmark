# map のシーケンス図の複合フラグメントのタブの開閉のボタンを、押せる大きさ 24px 以上か、タイトルのボタンと間を空けて描く

## 概要

読者が、map のシーケンス図の複合フラグメントのタブの開閉のボタンを、タイトルのボタンと押し間違えずに押せる。

## 背景

[map のシーケンス図の複合フラグメントのタブの開閉のボタンを、押せる大きさ 24px 以上か、タイトルのボタンと間を空けて描く](https://github.com/shuhei1101/mdmark/issues/666) の要望。
作業 PR [#665](https://github.com/shuhei1101/mdmark/pull/665)（起点 Issue [#609](https://github.com/shuhei1101/mdmark/issues/609)）のレビューで同じ型の箇所として見つかり、スコープ外として切り出した。
`src/index.css` の `.map-seq-fragment-tab .map-disclosure` が、map の開閉のボタンの既定（24px 四方）を 22px 四方に上書きし、`gap: 2px` でタイトルのボタンと並ぶため、axe の `target-size` に該当する。
