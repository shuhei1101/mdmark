# 要件

## 要望

- map のシーケンス図の複合フラグメントのタブの開閉のボタン（`.map-seq-fragment-tab .map-disclosure`）を、押せる大きさ 24px 四方以上で描く
- 開閉のボタンを広げても、タブのタイトルのボタン（`.map-seq-fragment-title`）と重ならず、タブの位置がブロックの枠線の左上からずれない
- ストーリー `Parts/MapSequence` の Default と BlockCollapsed を axe にかけて、タブの開閉のボタンとタイトルのボタンで `target-size` が出ない
- 同じ型の箇所として、モックの `docs/mock/refs/445/assets/map-mock.css` の `.map-seq-fragment-tab .map-disclosure`（22px 四方）も製品と同じ大きさに合わせる

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `src/index.css` の `.map-seq-fragment-tab .map-disclosure` の `width: 22px; height: 22px` と `.map-seq-fragment-tab` の `gap: 2px` | [9412c199](https://github.com/shuhei1101/mdmark/commit/9412c199)（`Mermaid と補足で書き、自動配置で描いて階層を辿れる新しい図（map）を追加する (#445)`） | map の図を追加したときに、モック（`docs/mock/refs/445/assets/map-mock.css`）の同じ値をそのまま製品の CSS へコピーした。押せる大きさの基準に合わせて決めた値ではない | 1 回 | 上書きを解除して map の開閉のボタンの既定（24px 四方）に戻す修正は、タブの中に開閉とタイトルのボタンを並べる目的を壊さない |
