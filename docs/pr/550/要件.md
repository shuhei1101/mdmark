### #518 右側の目次の変わったセクションのマーカー

- 変わったセクションは、見出しから次の同じか上の階層の見出しの前までのブロックに、比較元から追加・変更・削除の色分けを持つブロックがある見出しとする（見出しのブロック自身が変わったときも含める）
- `hover` の目次の枠の項目と、`fixed` の目次の項目の両方にマーカーを出す。`hover` の右端の線にも出すかはモックで決める
- マーカーは視覚のアイコンと、読み上げで `変更` と読む視覚に出さない文言を持つ
- `update` で `baseMarkdown` を `null` にしたとき、比較元が本文と同じとき、比較元を省いて描いたときは、マーカーを出さない
- `diffSource` の `diffMode: blocks` で色分けしたときも、同じ色分けから同じマーカーを出す
- 公開関数の引数・戻り値は変えない

### #526 長文の列の並べ替え

- 長文の列は、#458 で入れた列の幅の自動計算の長文の列（`findLongColumns`・`data-long`）と同じものにする。絞り込みの種類の既定（長文の列は文字で絞り込む）と同じ判定を使用する
- 長文の列の見出しには並べ替えのボタンを出さない。表の種類と、`features.sort: {}` を記載したかによらない。ほかの列の並べ替えと、長文の列のピン止め・絞り込み・列の幅の変更は今のまま
- 列ごとの指定 `columns.{列名}.sort` を追加する。`true` で長文の列にも並べ替えを付け、`false` で短い値の列から並べ替えを外す。表のマーカーのスキーマ（`schemas/marks/table.schema.json`）と移行の手順（`migrations/`）も変更する
- 長文の列に並べ替えを戻す指定は `columns.{列名}.sort: true` だけにする。`features.sort: {"enabled": false}` の表は、`columns.{列名}.sort` の `true` があっても並べ替えを付けない
