### #518 右側の目次の変わったセクションのマーカー

- 変わったセクションは、見出しから次の同じか上の階層の見出しの前までのブロックに、比較元から追加・変更・削除の色分けを持つブロックがある見出しとする（見出しのブロック自身が変わったときも含める）
- `hover` の目次の枠の項目と、`fixed` の目次の項目の両方にマーカーを出す。`hover` の右端の線にも出すかはモックで決める
- マーカーは視覚のアイコンと、読み上げで `変更` と読む視覚に出さない文言を持つ
- `update` で `baseMarkdown` を `null` にしたとき、比較元が本文と同じとき、比較元を省いて描いたときは、マーカーを出さない
- `diffSource` の `blocks` で色分けしたときも、色分けしたブロックから同じマーカーを出すかは設計で決める
- 公開関数の引数・戻り値は変えない

### #526 長文の列の並べ替え

- 長文の列は、表の見出しを除いたセルの文字数か改行で判定する（閾値と、#458 の列の幅の自動計算のセルの測り方を流用するかは設計で決める）
- 長文と判定した列の見出しには並べ替えのボタンを出さない。ほかの列の並べ替え・ピン止め・絞り込み・列の幅の変更は今のまま
- `features.sort` を表に記載した指定（`{}`・`{"enabled": false}`）の意味は変えない。列ごとに並べ替えを戻す指定を足すかは設計で決め、足すときはマーカーのスキーマと移行の手順（`migrations/`）も変更する
