## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 変わったセクションの判定 | 右側の目次を付けるとき、本文の色分けしたブロック（追加・変更・削除）を見出しのセクションごとに集め、1 つ以上ある見出しを変わったセクションとする | `mount.ts` から色分けの結果を渡すか、目次の側が DOM の色分けの印を読むかは設計で決める |
| 目次のマーカー | 変わったセクションの項目に、塗った円のアイコンと読み上げの文言 `変更` を付ける。`hover`・`fixed` の両方に出す | 項目の右端に配置する橙（`--mdmark-color-callout-warning`）の塗った円。`hover` の右端の線も変わったセクションの線を橙にする（[モック a-dot-end](../../mock/pages/document/550/a-dot-end/index.html)） |
| 読み上げの文言 | 変わったセクションの項目のリンクに `aria-label`（`{見出しの文字}（変更）`）を付け、マーカーの円は `aria-hidden` にする。リンクの文字には足さない | 目次を出すボタンの今いる見出しは項目のリンクの文字から写すため、視覚に出さない要素をリンクの中に置くとボタンに見える |
| マーカーの解除 | `update` で `baseMarkdown` を `null` にして色分けを解除したら、描き直す目次にマーカーを付けない | - |
| 長文の列の判定 | 列の幅の自動計算の長文の列（`findLongColumns` の結果、`data-long`）をそのまま使用する | 絞り込みの種類の既定と同じ判定 |
| 並べ替えの既定 | 長文の列の見出しには並べ替えのボタンを出さない | - |
| 列ごとの並べ替えの指定 | `columns.{列名}.sort` の `true` で長文の列に並べ替えを付け、`false` で外す | 表のマーカーのスキーマを変更する |
| アクセシビリティ | マーカーは視覚に出さない文言で読み上げる。並べ替えを出さない列の見出しは `aria-sort` を持たない | - |
| 既存機能への影響 | 公開関数の引数・戻り値は変えない。`features.sort` を記載した表の意味は変えない | - |
