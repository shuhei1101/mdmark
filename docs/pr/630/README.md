# 純粋な Mermaid のコードブロックにも、記法が無くても付けられるビュワーの操作（シーケンス図の参加者の行の固定・図の中の文字のコピー など）を付ける

## 概要

読者が、mdmark の記法を記載していない純粋な Markdown と純粋な Mermaid だけの文書でも、シーケンス図の参加者の行の固定・図の中の文字の選択とコピーなど、記法が無くても付けられるビュワーの操作を使用できるようになる。

## 背景

[Issue #500](https://github.com/shuhei1101/mdmark/issues/500) の要望。
言語 `mermaid` のコードブロックは図として描かれるが、map の図が持つ操作が付かず、シーケンス図の参加者の行がスクロールで留まらない。
図の中の文字の上でドラッグすると図が動き、文字をコピーできない。
map の操作と図の種類を増やした [#464](https://github.com/shuhei1101/mdmark/issues/464)・[#465](https://github.com/shuhei1101/mdmark/issues/465) の後に着手する。
