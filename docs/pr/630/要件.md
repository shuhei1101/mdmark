# 要件

## 要望

map の範囲の外にある言語 `mermaid` のコードブロック（純粋な Mermaid）にも、記法を記載しなくても付けられるビュワーの操作を付ける。

| 操作 | 今 | 終了の条件 |
| --- | --- | --- |
| シーケンス図の参加者の行の固定 | map のシーケンス図だけが、図の枠を縦にスクロールしても参加者の行を表示する枠の上端に留める。純粋な Mermaid のシーケンス図は留めない | 純粋な Mermaid のシーケンス図も、図の枠を縦にスクロールしたとき参加者の行が表示する枠の上端に留まる |
| 図の中の文字の選択とコピー | 純粋な Mermaid の図は、文字の上で押してドラッグすると図が動き、文字を選べない（map の図は文字の上をドラッグの対象から除外している） | 純粋な Mermaid の図のノード・ラベル・メッセージの文字を、ドラッグで選んでコピーできる。文字の無い所のドラッグは今のとおり図を動かす |
| map の操作のうち補足が無くても付けられるもの | 純粋な Mermaid の図には付かない | 設計で一覧にした操作が、純粋な Mermaid の図にも付く |

- 記法が無くても付ける操作と、記法を記載したときだけ付く操作の一覧を、設計書に表で持つ。図以外の記法（表 など）も同じ一覧で確認し、記法が無くても付けられるのに付いていない操作があれば同じ PR で付ける
- 新規の複合ユースケース（純粋な Markdown だけの文書を描いて操作する）を作るかは、複合ユースケース設計で決める

`未確定`: 純粋な Mermaid に操作を付ける方法（決める工程: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | map の範囲の外の mermaid のコードブロックを、補足の無い map の範囲として map の描画と操作の処理で描く（map が描けない種類は今の mermaid の描画のまま） | map の操作がそのまま付き、map に操作を追加すると純粋な Mermaid にも付く | 自動配置の結果が Mermaid の配置と違い、今の図と見た目が変わる |
| B | mermaid の描画を残し、mermaid が描いた SVG に参加者の行の固定と文字の選択を後から付ける | 文書の作成者が記載した Mermaid の見た目を変えない | map に操作を追加するたびに SVG 向けにも作る |

推奨: A

Issue の要望は「map でできる操作のうち、純粋な Mermaid だけでも使用できるもの」を得ることで、B では map に操作が増えるたびに 2 か所に作ることになる。
見た目が変わる点は、モック作成でユーザーに確認する。
