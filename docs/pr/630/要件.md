# 要件

## 要望

map の範囲の外にある言語 `mermaid` のコードブロック（純粋な Mermaid）にも、記法を記載しなくても付けられるビュワーの操作を付ける。

| 操作 | 今 | 終了の条件 |
| --- | --- | --- |
| シーケンス図の参加者の行の固定 | map のシーケンス図だけが、図の枠の中を縦に動かしたときに参加者の行を表示する枠の上端に留める。文書をスクロールして図の上端が画面の外へ出ると、参加者の行も画面の外へ出る。純粋な Mermaid のシーケンス図は留めない | 純粋な Mermaid と map のシーケンス図で、図の枠の中を縦に動かしたときは表示する枠の上端に、文書をスクロールして図の上端が画面の外へ出たときは画面の上端に、参加者の行が留まる。図の下端が過ぎたら一緒に画面の外へ出る |
| 図の中の文字の選択とコピー | 純粋な Mermaid の図は、文字の上で押してドラッグすると図が動き、文字を選べない（map の図は文字の上をドラッグの対象から除外している） | 純粋な Mermaid の図のノード・ラベル・メッセージの文字を、ドラッグで選んでコピーできる。文字の無い所のドラッグは今のとおり図を動かす |
| map のノードの名前の位置 | 種類を持たないノードも種類の行の高さを空けて描くため、名前が下に寄り、2 行の名前の上に空白が出る | 種類を持たないノードは、名前をノードの上下の中央に描く |
| map のシーケンス図の左上の枠線 | 参加者の行の背景が、表示する枠の左の枠線に重なり、ツールの行と参加者の行の間の左の枠線が欠ける | 参加者の行を留めても、表示する枠の枠線が欠けない |
| map の操作のうち補足が無くても付けられるもの | 純粋な Mermaid の図には付かない | 設計で一覧にした操作が、純粋な Mermaid の図にも付く |

- 純粋な Mermaid の図に記法が無くても付ける操作と、map の範囲で記載したときだけ付く操作の一覧を、設計書に表で持つ。図以外の記法（表 など）はスコープ外（#632）

純粋な Mermaid のコードブロックは、補足の無い map の範囲として map の描画と操作の処理で描く。map が描けない種類（gantt・pie など）は今の mermaid の描画のまま（[確認事項](https://github.com/shuhei1101/mdmark/pull/630#discussion_r4591221761)で案 A に決定）。

map で描くことで、次も変わる。

| 対象 | 今 | 終了の条件 |
| --- | --- | --- |
| classDiagram の `click`・`link` の URL | mermaid の描画で、許可する URL のクラスをリンクにする | map の classDiagram も、同じ URL のクラスをリンクにする（map の classDiagram は今 `click`・`link` の行を読まない） |
| 設定の `mermaid` のテーマ | 全ての種類の mermaid の図に当たる | map が描けない種類の図にだけ当たる。map で描く図は map の配色で描く |
| 機能 `map` をオフにした文書 | map の範囲を描かず、範囲の中のブロックを mermaid で描く | 範囲の外の map が描ける種類のコードブロックも、mermaid で描く |

| 単一 UC | 変更 |

| 『シーケンス図の参加者を選んで強調する』（SC-472-19） | 正常シナリオ（純粋な Mermaid のシーケンス図）を追加した |
