# 要件

## 要望

map の範囲の外にある言語 `mermaid` のコードブロック（純粋な Mermaid）にも、記法を記載しなくても付けられるビュワーの操作を付ける。

| 操作 | 今 | 終了の条件 |
| --- | --- | --- |
| シーケンス図の参加者の行の固定 | map のシーケンス図だけが、図の枠を縦にスクロールしても参加者の行を表示する枠の上端に留める。純粋な Mermaid のシーケンス図は留めない | 純粋な Mermaid のシーケンス図も、図の枠を縦にスクロールしたとき参加者の行が表示する枠の上端に留まる |
| 図の中の文字の選択とコピー | 純粋な Mermaid の図は、文字の上で押してドラッグすると図が動き、文字を選べない（map の図は文字の上をドラッグの対象から除外している） | 純粋な Mermaid の図のノード・ラベル・メッセージの文字を、ドラッグで選んでコピーできる。文字の無い所のドラッグは今のとおり図を動かす |
| map の操作のうち補足が無くても付けられるもの | 純粋な Mermaid の図には付かない | 設計で一覧にした操作が、純粋な Mermaid の図にも付く |

- 純粋な Mermaid の図に記法が無くても付ける操作と、map の範囲で記載したときだけ付く操作の一覧を、設計書に表で持つ。図以外の記法（表 など）はスコープ外（#632）

純粋な Mermaid のコードブロックは、補足の無い map の範囲として map の描画と操作の処理で描く。map が描けない種類（gantt・pie など）は今の mermaid の描画のまま（[確認事項](https://github.com/shuhei1101/mdmark/pull/630#discussion_r4591221761)で案 A に決定）。

書き直す単一 UC:

| 単一 UC | 書き直す内容 |
| --- | --- |
| 『mermaidの図を描く』（SC-472-11） | map が描ける種類の図の既存の期待値（mermaid の本体への要求・actor のアイコン・ノードの色・ダークの配色・テーマ・機能のオフ）を、map で描く図の期待値に書き直す |
| 『シーケンス図の参加者を選んで強調する』（SC-472-19） | 純粋な Mermaid のシーケンス図でも参加者を選び・並べ替えるシナリオを追加し、影響を `changed` にする |
| 『図を拡大・縮小・移動する』（SC-472-42） | 今回追加した文字の選択の期待値のまま |
