# 要件

## 要望

map の範囲の外にある言語 `mermaid` のコードブロック（純粋な Mermaid）にも、記法を記載しなくても付けられるビュワーの操作を付ける。

| 操作 | 今 | 終了の条件 |
| --- | --- | --- |
| シーケンス図の参加者の行の固定 | map のシーケンス図だけが、図の枠を縦にスクロールしても参加者の行を表示する枠の上端に留める。純粋な Mermaid のシーケンス図は留めない | 純粋な Mermaid のシーケンス図も、図の枠を縦にスクロールしたとき参加者の行が表示する枠の上端に留まる |
| 図の中の文字の選択とコピー | 純粋な Mermaid の図は、文字の上で押してドラッグすると図が動き、文字を選べない（map の図は文字の上をドラッグの対象から除外している） | 純粋な Mermaid の図のノード・ラベル・メッセージの文字を、ドラッグで選んでコピーできる。文字の無い所のドラッグは今のとおり図を動かす |
| map の操作のうち補足が無くても付けられるもの | 純粋な Mermaid の図には付かない | 設計で一覧にした操作が、純粋な Mermaid の図にも付く |

- 純粋な Mermaid の図に記法が無くても付ける操作と、map の範囲で記載したときだけ付く操作の一覧を、設計書に表で持つ。図以外の記法（表 など）はスコープ外（#632）

`未確定`: 純粋な Mermaid に操作を付ける方法（決める工程: 単一ユースケース設計。どちらの案も、単一 UC の期待値が変わるためユーザーに確認する）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | map の範囲の外の mermaid のコードブロックを、補足の無い map の範囲として map の描画と操作の処理で描く（map が描けない種類は今の mermaid の描画のまま） | map の操作（シーケンス図の参加者の選択・並べ替え など）がそのまま付き、map に操作を追加すると純粋な Mermaid にも付く | map が描ける種類の図は、自動配置の結果が Mermaid の配置と違い、今の図と見た目が変わる |
| B | mermaid の描画を残し、mermaid が描いた SVG に参加者の行の固定と文字の選択を後から付ける | 文書の作成者が記載した Mermaid の見た目を変えない | map の操作のうち、参加者の行の固定と文字の選択のほかは付かず、要件の 3 行目を縮める。map に操作を追加するたびに SVG 向けにも作る |

推奨: A

Issue の要望は「map でできる操作のうち、純粋な Mermaid だけでも使用できるもの」を得ることで、B では要件を縮めることになる。

案ごとに書き直す単一 UC:

| 単一 UC | 案 A | 案 B |
| --- | --- | --- |
| 『mermaidの図を描く』（SC-472-11） | map が描ける種類の図の既存の期待値（mermaid の本体への要求・actor のアイコン・ノードの色・ダークの配色・テーマ・機能のオフ）を、map で描く図の期待値に書き直す | 今回追加したシナリオのまま |
| 『シーケンス図の参加者を選んで強調する』（SC-472-19） | 純粋な Mermaid のシーケンス図でも参加者を選び・並べ替えるシナリオを追加し、影響を `changed` にする | `run_only` のまま |
| 『図を拡大・縮小・移動する』（SC-472-42） | 今回追加した文字の選択の期待値のまま | 同左 |
