## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 操作を付ける方法 | map の範囲の外の mermaid のコードブロックを map の描画と操作の処理で描く（map が描けない種類は今の mermaid の描画のまま） | 要件の案 A に決定 |
| シーケンス図の参加者の行の固定 | 純粋な Mermaid のシーケンス図の参加者の行を、map と同じ `.mdmark-diagram-seq-heads` の処理で表示する枠の上端に留める | - |
| 図の中の文字の選択 | 純粋な Mermaid の図のノード・ラベル・メッセージの文字を、ドラッグの対象から除外して選べるようにする。文字の無い所のドラッグは今のとおり図を動かす | - |
| 記法が無くても付ける操作の一覧 | 記法が無くても付ける操作と、記法を記載したときだけ付く操作を、インターフェース定義の制約に表で持つ | - |
| 既存機能への影響 | map の範囲の中の図・click の行のノードのリンク・ツールチップ・配色の切り替えの描画を変えない | - |
| アクセシビリティ | 留めた参加者の行と選べる文字は、スクリーンリーダーに今と同じ順で出す | - |
