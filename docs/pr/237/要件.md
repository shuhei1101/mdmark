| --- | --- |
| [#231](https://github.com/shuhei1101/mdmark/issues/231) | `tests/e2e/単一ユースケース/ステップ・ファイルツリー・バッジで本文を組む.spec.ts` の `test_normal_when_tree_annotated`・`test_normal_when_tree_folders_toggled`・`test_error_when_tree_clipboard_denied` が Chromium・Firefox の両方で pass する（has に渡すロケーター・閉じたフォルダのボタンの探し方・クリップボードを拒否したときの期待する文言を設計どおりの描画に合わせる） |
| [#232](https://github.com/shuhei1101/mdmark/issues/232) | `tests/e2e/単一ユースケース/文書を印刷する.spec.ts` の `test_normal_when_syntax_expanded` が Chromium・Firefox の両方で pass する（期待するタブ名に、閉じたタブの範囲の `uv`・`pip` を含める） |
