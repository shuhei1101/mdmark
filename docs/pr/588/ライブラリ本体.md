## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `vitest.config.ts` | プロジェクト `integration-browser-touch` を足す。`integration-browser` と同じ配信・`globalSetup`・`maxWorkers`・`groupOrder` を持ち、Playwright の `contextOptions` に `hasTouch: true` を渡す。`include` は `tests/integration/lib/mount.browser.test.ts`、`setupFiles` は `tests/integration/touch-setup.ts` | `npm run test:integration`（`--project 'integration*'`）に含まれる。`testNamePattern` はプロジェクトごとに書けない（Vitest の `NonProjectOptions`）ため使わない |
| `tests/integration/touch-setup.ts` | `beforeEach` で、名前が `_by_touch` で終わらないテストを `context.skip()` で飛ばす | 新規。`tests/files.yaml` に行を足す |
| `test_normal_when_column_resized_by_touch` | `Emulation.setTouchEmulationEnabled` の 2 か所を消し、`test.runIf(navigator.maxTouchPoints > 0)` で、タッチの点があるプロジェクトだけで動かす。確かめる内容（つまみを常に出す・押せる幅 24px・タッチのドラッグとダブルタップ）は変えない | 画面の幅 390px と、終わりに幅を戻す処理は残す |
| 戻ったことの確認 | 確かめるテストは足さない。`integration-browser` ではタッチのテストが CDP を使わずに飛ばされ、同じページに代役が残らない | - |
