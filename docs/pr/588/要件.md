# 要件

## 要望

- `test_normal_when_column_resized_by_touch` の後に同じページで動くテストで、`matchMedia("(hover: hover)")`・`matchMedia("(pointer: fine)")` が `true` になる
- ポインターを乗せて確かめる結合テスト（`test_normal_when_code_fold_column_hovered` など）を、タッチのテストより後に置いても pass する
- `test_normal_when_column_resized_by_touch` が確かめている内容（つまみを常に出す・押せる幅 24px・タッチのドラッグとダブルタップ）は変えない

直し方（インターフェース定義設計で決めた）:

- CDP の `Emulation.setTouchEmulationEnabled` を使わず、`hasTouch` を付けたブラウザのコンテキストで動く結合テストのプロジェクト `integration-browser-touch` を足し、`test_normal_when_column_resized_by_touch` をそのプロジェクトだけで動かす
- テストは `mount.browser.test.ts` に置いたまま、テストの名前も変えない（インターフェース定義『文書を描く』・シナリオ『表を操作する』・`tests/files.yaml` は変えない）
- 元のプロジェクト `integration-browser` では、タッチの点が無い（`navigator.maxTouchPoints` が 0）ため、このテストを飛ばす

CDP で後始末する案と、別のファイルへ移す案は、試した結果、採らない。

| 試したこと | 結果 |
| --- | --- |
| `setTouchEmulationEnabled` の `enabled: false` の後に、`setEmitTouchEventsForMouse` の false・`clearDeviceMetricsOverride`・`setDeviceMetricsOverride`・`setEmulatedMedia` の `hover`・`pointer`・マウスの移動・3 秒の待ちを順に当てる | どの後も `(hover: hover)`・`(pointer: fine)` は `false` のまま（`(pointer: coarse)` も `false` で、ポインターが無い状態になる） |
| 後始末の後に、同じページに新しい iframe を作る | iframe の中も `false` のまま |
| タッチのテストを別のファイルに置き、その後に同じブラウザで動く別のファイルで確かめる | 2 回のうち 1 回は `true`、1 回は `false` で、ファイルを分けても戻るとは限らない |
| `hasTouch` を付けたコンテキストのプロジェクトで動かす | `(pointer: coarse)` が `true`、`navigator.maxTouchPoints` が 1。元のプロジェクトのテストには影響しない |
