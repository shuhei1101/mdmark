# 要件

## 要望

まとめた HTML で `side-toc` をオフにし、コメントの列でも包まないときも、脚注の番号・戻るリンクを押したときに URL の `#` を書き換えない。

- `attachFootnotes` の `root` が、まとめた HTML の `view` と同じ要素でも別の要素でも、脚注の `click` がまとめた HTML の `view` の `click` より先に既定の動作を止める
- 番号で一覧の項目へ、戻るリンクで番号へ移る先とフォーカスは今のまま変えない
- 直し方は Issue の案 A（`attachFootnotes` の `root` の `click` をキャプチャーフェーズで受ける）にする。`src/viewer/bundle.ts` は変えない

| `src/interact/footnotes.ts` の `root.addEventListener("click", onClick)` | [b98f1c19](https://github.com/shuhei1101/mdmark/commit/b98f1c19)（`脚注（[^1] と行内の ^[…]）をツールチップと末尾の一覧で描く (#311)`） | 番号と戻るリンクの `click` を `root` で 1 つの処理に束ねて受けるため。バブリングフェーズで受けることに理由は書かれていない | 1 回 | キャプチャーフェーズへ変えても、`root` の中の番号と戻るリンクを束ねて受ける目的は壊さない |
