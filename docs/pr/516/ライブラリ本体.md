## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 脚注の `click` の受け方 | `attachFootnotes` は `root` の `click` を `{ capture: true }` で受け、削除する関数でも同じ指定で外す | `root` の祖先がバブリングフェーズで受ける `click` より先に既定の動作を止める |
| 設計書 | モジュール構成『操作 / footnotes.ts』の `attachFootnotes` の説明に、`root` の `click` をキャプチャーフェーズで受けることと理由を追加し、単体テストの行を追加する | - |
| 単体テスト | `attachFootnotes` より先に `root` 自身へ、`defaultPrevented` でなければ `history.replaceState` で URL の `#` を書き換えるバブリングフェーズの `click` を付け、番号と戻るリンクを押しても `location.hash` が変わらないことを確かめる | まとめた HTML の `view` と `root` が同じ要素のときを再現する |
| 既存機能への影響 | 番号と戻るリンクで移る先・フォーカス・ツールチップの開閉は変えない | 既存の単体テストと結合テストで回帰を確かめる |
