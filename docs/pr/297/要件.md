# 要件

## 要望

`tests/unit/vscode/scripts/build.test.ts` の `test_build_extension` で、作業ツリーの `vscode/` を一時フォルダへコピーするとき、`node_modules` に加えて、テストの結果に影響する `vscode/` 配下の生成物と取得物を除外する。

- 除外する対象: `vscode/.vscode-test/`・`vscode/out/`・`vscode/dist/`・`vscode/media/preview.js`・`vscode/media/preview.css`
- `dist/` と `media/preview.{js,css}` は、テストがビルドで作成されたことを検証するファイルのため、除外に含める
- 結合テストを実行した後の作業ツリー（`.vscode-test/` と `out/` がある状態）で `npm run test:unit` を実行し、`test_build_extension` が 30 秒以内に成功する
