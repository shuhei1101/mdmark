# 要件

## 要望

VS Code 拡張機能のタグ一覧の要求（`vscode/src/version.ts` の `fetchLatestVersion`）が、待ちの上限 `TAGS_TIMEOUT_MS`（3000 ms）より前に中断される原因を特定して修正する。

- 要求を始めてから中断されるまでが、待ちの上限より短くならない
- 待ちの上限の値（3000 ms）と、取れないときに前回のバージョンで描く流れは変えない
- `vscode/tests/integration/preview-open.test.ts` の `test_normal_when_tags_unreachable` を、VS Code 1.141.0 と stable のそれぞれで 10 回繰り返して全 pass する
- 書き出し（`vscode/src/export/export.ts`）も同じ `fetchLatestVersion` を使うため、修正は両方に効かせる
