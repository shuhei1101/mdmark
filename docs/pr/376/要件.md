# 要件

## 要望

VS Code 拡張機能の E2E の準備 `buildExtensionAndDist`（`tests/e2e/vscode.ts`）が、一時フォルダに複製した拡張機能をビルドするときに、リポジトリの直下の `src/`（`config-files.ts`・`bundle-module.ts`）と、その依存を解決できるようにする。
単体テストの準備 `copyExtension`（`tests/unit/vscode/scripts/build.test.ts`）と同じく、一時フォルダの直下に `src`・`schemas`・`node_modules` のリンクを作る。
製品のコード・設計書・`docs/` は変えない。

終わりの条件は、`useVscodeE2E` を使う VS Code 拡張機能の E2E が、拡張機能のビルドの `Could not resolve` で失敗せずに流れること。
