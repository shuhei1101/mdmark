# ピン止めした列の用語のツールチップを、表の見出し行とピン止めした列より手前に出す

## 概要

表の列をピン止めしても、その列のセルの用語のツールチップを、表の見出し行に隠れずに読めるようにする。

## 背景

[Issue #729](https://github.com/shuhei1101/mdmark/issues/729) の要望。dev-docs の ai-monitor の用語集で「用語」の列をピン止めし、その列のセルの用語にポインターを乗せると、上に開いたツールチップが見出し行の下に潜り、上の部分が見えない。

ツールチップ（`.mdmark-term-tip`）は開くと `position: fixed`・`z-index: 10` で画面に対して配置されるが、要素はセルの中に残る。
ピン止めした列のセル（`.is-pinned-col`）は `position: sticky` で重なりのまとまりを作り、見出し行のセル（`z-index: 3`、ピン止めした列の見出しは `4`）より下に描かれるため、ツールチップがそのまとまりの中に閉じ込められていると見込んでいる（画面での切り分けは設計で行う）。
