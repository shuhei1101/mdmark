## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | ピン止めした列・見出し行を留めた表を画面に描き、ツールチップが sticky のセルの重なりのまとまりに閉じ込められていることを、`document.elementFromPoint` と、セルの `position` を解除したときの見え方で確認する | モジュール構成設計で行う |
| 用語のツールチップ | 開いている間、見出し行・集計の行・ピン止めした列のセルより手前に描く。画面に対する配置（`chooseTipSide` で上下を選び、画面の端から 16px 空ける）は変えない | 方法は `要件.mark.md` の `未確定`（推奨: A） |
| 脚注のツールチップ | 用語のツールチップと同じ方法で手前に出す | - |
| 重なりの順 | 見出し行・集計の行・ピン止めした列の `z-index` は変えない | 案 C を採らない理由は `要件.mark.md` の由来 |
| アクセシビリティ | `aria-describedby`・`aria-details`、単語の次の Tab で中のリンクとボタンへ移る順、Esc で閉じてフォーカスを単語へ戻す振る舞いを変えない | - |
| 既存機能への影響 | 表の外の本文・ピン止めしていない列のセル・図の中の用語のツールチップ、タッチでの開閉、印刷の前に閉じる振る舞いを変えない | - |
