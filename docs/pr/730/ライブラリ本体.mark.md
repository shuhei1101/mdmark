## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | ピン止めした列のセル（`position: sticky`）が作る重なりのまとまりに、中の `position: fixed` のツールチップが閉じ込められ、見出し行（`z-index: 3`・`4`）より下に描かれる | モジュール構成設計で画面で確認した（`要件.mark.md` の決定 C の根拠） |
| 用語のツールチップ | `attachTermTips` が、開いている間ツールチップを持つ表のセル（`th`・`td`）に `is-tip-open` を付け、閉じたときに削除する。画面に対する配置（`chooseTipSide` で上下を選び、画面の端から 16px 空ける）は変えない | MOD-472-266 |
| 脚注のツールチップ | `attachFootnotes` も同じく `is-tip-open` を付け、閉じたときに削除する | MOD-472-238 |
| 重なりの順 | `is-tip-open` のセルを `z-index: 10`（ツールチップと同じ値）にし、見出し行・集計の行の規則より後ろに配置する。見出し行・集計の行・ピン止めした列・右側の目次の `z-index` は変えない | MOD-472-170 |
| アクセシビリティ | `aria-describedby`・`aria-details`、単語の次の Tab で中のリンクとボタンへ移る順、Esc で閉じてフォーカスを単語へ戻す振る舞いを変えない | - |
| 既存機能への影響 | 表の外の本文・ピン止めしていない列のセル・図の中の用語のツールチップ、タッチでの開閉、印刷の前に閉じる振る舞いを変えない | - |
