## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 点検の項目 | `collectCheckIssues` に、点検する文書の本文から知らない印を拾ってずれにする項目を足し、今の並びの最後に置く | 点検する文書は索引の点検に渡す文書と `build` の対象の文書を合わせ、重なりを除く |
| 知らない印の判定 | 描く処理と同じ正規表現・同じトークン（`html_block`・`html_inline`）で印を拾い、`features`・記法の印・設定の `libraries`・拡張の `directive`・`check.ignore` の名前に当たらないものを知らない印にする | コードブロックとインラインコードの中は拾わない |
| 拡張の印の名前 | 設定の `extensions` を `bundleModule` で束ね、Node で読み込んで既定の書き出しの `directive` を取る | 束ねられない・読み込めない・`directive` を持たない拡張は `extensions[{位置}]` の `schema` のずれ |
| 設定のキー | `check.ignore`（`string[]`、省いてよい）を足し、`schemas/mdmark.config.schema.json`・CLI の設定の検め・`migrations/no-steps.yaml` の行を直す | 印の名前の書式に合わない値は `schema` のずれ |
| ずれの形 | 種類を `unknown_mark` にし、場所は印のある行の番号、内容は印の名前と、名前を直すか拡張・対応表・`check.ignore` に足すかの直し方の 1 文にする | - |
| 終了コード | 知らない印のずれも今のずれと同じく数え、1 件以上なら 1 | - |
| 既存機能への影響 | `mdmark upgrade` が移行の後に呼ぶ点検では、知らない印を点検しない | `collectCheckIssues` に知らない印を点検するかの指定を足す |
