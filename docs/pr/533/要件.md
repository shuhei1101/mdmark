# 要件

## 要望

`table.pin` が `each`・`through` のどちらの表でも、留めた列の幅の合計が表の見える幅（表を包む要素の `clientWidth`）を超えたときに、留めた列どうしが重ならずに読めるようにする。

- 留めた列の幅の合計が見える幅を超えても、どの留めた列もほかの留めた列に重なって隠れない
- 見える幅に収まらない留めた列があるとき、読む人がそのことを知れる
- 見える幅が広がって収まるようになったら（ウィンドウの幅の変更・ほかの列の解除・列の幅の変更）、その列は再び留まる
- ピン止めのボタンの `aria-pressed` は、読む人が選んだ列を表す

見える幅に収まらない留めた列は、読む人が選んだ列（`through` は押した列までの列）を左から順に足し、見える幅を超える列から右の列を留めずにスクロールに任せる。
ボタンの `aria-pressed` は `true` のままにする。

選んだのに留まっていない列は、その列のピン止めのボタンの見た目とアクセシブルな名前で示す（`through` は押した列のボタン）。
ウィンドウの幅を狭めて留まらなくなった場合も、ボタンが今の状態を示す。

留まっていないことを示すボタンは、ピンのアイコンを塗らない破線にし、ボタンの枠線も破線・アイコンの色を薄くする。
読み上げの名前と `title` は、今のボタンの名前の後ろに「（表の幅に収まらないため留まっていません）」を付ける。

`through` の表も同じく重なることを、390px の画面幅で 10 列（各 164px 前後）の表の 3 列目を押し、右端までスクロールして確かめた。

| ブラウザ | 2 列目の右端 | 3 列目の左端 |
| --- | --- | --- |
| Chromium | 351px | 249px |
| Firefox | 355px | 247px |
