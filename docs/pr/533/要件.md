# 要件

## 要望

`table.pin: each` の表で、留めた列の幅の合計が表の見える幅（表を包む要素の `clientWidth`）を超えたときも、留めた列どうしが重ならずに読めるようにする。

- 留めた列の幅の合計が見える幅を超えても、どの留めた列もほかの留めた列に重なって隠れない
- 見える幅に収まらない留めた列があるとき、読む人がそのことを知れる
- 見える幅が広がって収まるようになったら（ウィンドウの幅の変更・ほかの列の解除・列の幅の変更）、その列は再び留まる
- ピン止めのボタンの `aria-pressed` は、読む人が選んだ列を表す

`未確定`: 見える幅に収まらない留めた列の扱い（決める段: 単一ユースケース設計）

| 案 | 内容 |
| --- | --- |
| A | 右側の留めた列から、収まらない列を留めずにスクロールに任せる。ボタンの `aria-pressed` は `true` のまま |
| B | 収まらない列を押したときは留めず、ボタンの `aria-pressed` を `false` に戻す |

推奨: A

読む人の選んだ列を保ったまま、幅が広がれば元どおり留まるため。B は押す前に留めた列が後から収まらなくなる場合（ウィンドウを狭めたとき）を扱えない。

`未確定`: 留められないことの知らせ方（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 留まっていない列のピン止めのボタンの見た目を変え、`title` に留められない理由を出す |
| B | 押した直後に表の上に短い知らせを出す |

推奨: A

ウィンドウの幅の変更でも状態が変わり、押した時だけの知らせでは今の状態が分からないため。
