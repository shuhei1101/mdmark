# 表の留めた列の幅の合計が見える幅を超えても、留めた列が重なって見えなくならないようにする

## 概要

表を参照する人が、複数の列を留めて留めた列の幅の合計が表の見える幅を超えても、留めた列どうしが重ならずに読めるようにする。

## 背景

[表の留めた列の幅の合計が表の見える幅を超えると、留めた列が重なって見えなくなる](https://github.com/shuhei1101/mdmark/issues/453) の要望。
`table.pin: each` で複数の列を留めると、留めた列の幅の合計が表の見える幅を超えたときに留めた列どうしが重なり、一部の列が隠れる（390px の画面幅で 10 列の表の 1・3・9 列目を留めると 3 列目が隠れる）。
[表のピン止めを選んだ列だけを留める動きにし、留めた列をスクロールの位置で左端か右端に留める](https://github.com/shuhei1101/mdmark/pull/438) で選んだ列だけを留める動きを入れ、[表の列の幅を、見出しの右端をドラッグして変えられるようにし、ダブルクリックで元の幅に戻す](https://github.com/shuhei1101/mdmark/pull/449) で列を広げるときの上限を設けたが、幅を変えない場合の重なりは [表の列の幅を、見出しの右端をドラッグして変えられるようにし、ダブルクリックで元の幅に戻す](https://github.com/shuhei1101/mdmark/pull/449) の範囲の外として切り出された。
