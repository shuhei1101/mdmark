## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 留める列の選び方 | 留める位置を求める前に、選んだ列（`through` は押した列までの列）を左から順に足し、幅の合計が表の見える幅を超える列から右の列を留める列から外す | `each`・`through` の両方に当てる |
| 留める位置 | 外した後の列だけで `left`・`right` を求め、外した列は `left`・`right` と `is-pinned-col` を外してスクロールに任せる | 留めた列の間に隙間と重なりを出さない |
| 計算し直す契機 | ウィンドウの幅の変更・ピン止めのボタンの押下・列の幅の変更・列の表示の切り替え・列の並べ替えのたびに選び直す | 収まるようになった列は再び留める |
| ボタンの状態 | 選んだ列のボタンの `aria-pressed` は、留めたかによらず読む人の選択を表す | - |
| 知らせ | 選んだのに留まっていない列のピン止めのボタン（`through` は押した列のボタン）の見た目とアクセシブルな名前を、留まっていない状態にする | 見た目（印・`title` の文言）は `未確定`（[要件](./要件.md)）。モック作成で決める |
| アクセシビリティ | 知らせは色だけに頼らず、ボタンの `title`・アクセシブルな名前でも伝える | - |
| 列の幅の上限 | `columnWidthLimit` の `pinned` へ、選んだ列ではなく実際に留まっている列を渡す（`columnWidthLimit` の中身は変えない） | 留まっていない列の幅を上限から引かない。列を狭めて収まるようになった列が再び留まることは単体テストで確かめる |
| 既存機能への影響 | 選んだ列が全て見える幅に収まる場合の留め方は変えない | - |
| #457 の 2 つの事象 | 単体テスト・結合テストで再現を確かめ、実装の不具合ならこの PR で直すか別の Issue に起票する | - |
