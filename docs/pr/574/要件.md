# 要件

## 要望

- knowledge のテンプレート『フォルダ構成』（`template-layout`）の書式で、リポジトリに 1 枚、`docs/layout/LAY-472-1.yaml` を作る
  - リポジトリの直下からの全てのフォルダとファイルを `entries[]` の入れ子で記載する
  - 生成物・複製・一時ファイルは `gitignore[]` と `generated_from` で、中身の種類は `content_types` で記載する
  - 配下の配置を言語の規約が定めるフォルダは `convention` で規約を指す
- `dev-docs.yaml` の `documents` に layout の行を追加し、設計書を knowledge のスキーマ（`schemas/design/layout.schema.yaml`）で検査させる
- 規約『フォルダ構成の切り方とレビュー』（`dev-folder-layout`）のレビューの観点で今のフォルダ構成を確認し、見つかった問題を問題ごとに別の Issue へ起票する
  - 起票した Issue の番号は、要件.yaml のスコープ外の行に書く
- 終わりの条件
  - 設計書が knowledge のスキーマの検査を通る
  - 設計書の `entries[]` と develop の `git ls-tree` のフォルダ・ファイルに食い違いが無い（`convention` を持つフォルダの配下を除く）
  - レビューの観点で見つかった問題が全て起票されている
