# 要件

## 要望

文書を書く人が、ボード表示・表形式のビューと、選んだ箇所へのコメントの部品を文書に置ける。
読む人は、ビューで項目を見て、表形式のビューを列で絞り込み、選んだ箇所にコメントを付けられる。
使う側は、同じ部品を自分のページの JavaScript・TypeScript から呼べる。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| ビュー | 項目の集まりを、列ごとに分けたボード表示と、表形式のビューで描く。ビューは部品として読み込み、見た目はテーマの CSS 変数、振る舞いは部品のオプションで変える（D-19・D-5） |
| ビューの項目 | 印で囲んだ Markdown の表の行を項目、列を項目の値にする。印に対応しない表示（GitHub など）では表のまま読める |
| 列の絞り込み | 全項目の検索は、表形式のビューの列の見出しに付ける列ごとの絞り込みで満たす。付ける列と種類は印に `filter=列名:種類` で書き、記法の表の絞り込み（値を選ぶ・文字・日付）と同じにする。ボード表示には当てず、常に全ての項目を出す。ビューの上の検索欄と件数は持たない（[確認ログ](./確認ログ.md)） |
| ボードの列の見出し | 列の値の前にアイコンを出す。よく使う値（未着手・進行中・保留・完了・中止など）には既定のアイコンを当て、印の引数で値ごとのアイコンを上書きできる。アイコンは lucide から選ぶ（[確認ログ](./確認ログ.md)） |
| コメント | 読む人が文書の中で選んだ箇所にコメントを付け、付いたコメントを選んだ箇所の印から開ける（D-36）。機能 `comments` を足し、既定はオフにする |
| コメントの保存 | mdmark はコメントを保存しない。使う側が `mount` にコメントの読み書きの関数を渡し、使う側の保存先に残す（差分の取得と同じ形。D-17） |
| JavaScript・TypeScript から使う | ビュー・コメントの部品を描く関数を配布物から出し、使う側のページの JavaScript・TypeScript と、`registerExtension` の拡張のモジュールから呼べる。配布物の型定義に部品の関数の型を載せる（D-50）。文書の中からは、印の場所に拡張のモジュールから部品を描いて使う（[確認ログ](./確認ログ.md)） |
| スクリプト | 文書に書いた任意のスクリプトは今のとおり動かさない（D-22）。動くのは mdmark の部品と、使う側が登録した拡張だけ |
| 読み込み | 部品のモジュールは、印のある文書・関数を呼んだときにだけ読み込む（D-12）。非機能要件の配布ファイル 1 つのサイズを超えない |
| 機能のオン・オフ | ビュー・コメントを `features` の機能として足し、文書の印で上書きできる今の仕組みに載せる |
| 書き出し | `mdmark export`・`mdmark build` で書き出した 1 枚の HTML でも、ビューと列の絞り込みが外を読まずに動く |
| 完了の基準 | ビュー・コメントの部品が、文書の印と使う側の JavaScript の呼び出しの両方で E2E で確かめられ、非機能要件の対応ブラウザで通る |

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 文書に書いた任意のスクリプトを動かす | 安全に配れないため見送った（D-22・[確認ログ](./確認ログ.md)） | 予定なし |
| 部品の配置と見た目をサンプルとして使う側へ複製する（shadcn 式） | バージョンの更新に追従できなくなるため見送った（D-5・D-19） | 予定なし |
| コメントの保存先のサーバー・ファイル | mdmark はブラウザで描くライブラリで保存先を持たず、使う側が読み書きの関数で持つ | 予定なし |
| 文書をまたぐ検索・索引から文書を探すツール | #11 が持つ | [#11](https://github.com/shuhei1101/mdmark/issues/11) |
| 記法の表への件数の表示・列の表示の切り替え・集計の行・表のコピー・行へのリンク | #23 が持つ | [#23](https://github.com/shuhei1101/mdmark/issues/23) |
| 差分の表示 | #7 が持つ | [#7](https://github.com/shuhei1101/mdmark/issues/7) |
| インターフェース定義『文書を描く』の制約「対応ブラウザ」が `Firefox 97` で、非機能要件の `対応ブラウザ`（Firefox 98 以降）と合っていない | 非機能要件と設計書の値を揃える規約から外れているが、今回の要望（ビュー・コメントの部品）に含まれない | [#59](https://github.com/shuhei1101/mdmark/issues/59) |
