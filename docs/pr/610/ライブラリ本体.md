## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| Mermaid の図 | `<!-- map -->` のマーカーで囲み、補足を付けて map で描く。図の種類は規約『表し方の優先順位』の「伝えるものと図の種類」で選ぶ | 描き方はガイド『図を描く-Mermaidと補足で図を描く』 |
| シナリオの flow | ```mermaid で囲まれていない flow も、同じく map で描く | [#112](https://github.com/shuhei1101/mdmark/issues/112) を解消する |
| 文と箇条書き | 同じ属性を持つ項目が 2 件以上なら表にし、削れる文を削る | - |
| メタデータ | タグ・エイリアス・用語・description・関連を今の規約で付け直す | YAML の設計書は `write_docs` で書き込む |
| 本文の ID・Issue 番号・パス | 関連のキーとタイトル付きのリンクへ移す | - |
| 設計書の Schema | ER 図を除く設計書の行を knowledge の `design-schemas/v8.4.0` の参照へ切り替え、参照しなくなった `schemas/` のコピーを削除する。knowledge の Schema に無いキーは、knowledge の Schema が削除した理由に沿って削除するか `notes` へ移す | [#587](https://github.com/shuhei1101/mdmark/issues/587) の反映作業から引き取った分。設計書の Schema のため、`migrations/` の行は要らない |
