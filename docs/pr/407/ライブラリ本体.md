## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参照するフォルダの決め方 | 移行のスクリプトのファイル名を受け取り、そのスクリプトを持つ `migrations/next/` か `migrations/v{バージョン}/` を 1 つ返却する関数を、単体・結合・E2E が共有するテストの補助（`tests/migrations-dir.ts`）に配置する | 持つフォルダが 0 件・2 件以上なら例外を投げる。`next/` が別の Sprint の手順に変わっても、スクリプトを持つフォルダを参照する |
| 単体テストの import | `drop-tag-vocabulary.mjs`・`alias-rows.mjs` を持つフォルダのファイルを実行時に import する | `npm run typecheck` が、存在しないフォルダのパスを解決しないようにする |
| 結合テスト・E2E | `join(REPO_ROOT, "migrations", "next")` を、結合は `drop-tag-vocabulary.mjs`、E2E は `alias-rows.mjs` を持つフォルダに置き換える | - |
| 一時フォルダに `migrations/next/` を作るテスト | 変更しない | 影響を受けない |
