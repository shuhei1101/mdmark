## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 押せる範囲 | 列の幅のつまみの押せる範囲を、`pointer: fine` でも幅 24 CSS px 以上にし、見出しのボタンと重ならないよう見出しのセルの右の余白を合わせる | - |
| 列の幅のドラッグの代わり | クリック・タップだけで列の幅を広げる・狭める・元の幅に戻せる操作を追加する。変える幅の刻みと範囲は `←`・`→` と同じにする | `未確定`（[要件](./要件.mark.md)。決める段: モック作成） |
| 列の並べ替えのドラッグの代わり | テーブル設定のパネルで、クリック・タップだけで列を前・後ろへ移せる操作を追加する。移せない列（留めた列の境をまたぐ等）の扱いは今の `canMoveColumn` と同じにする | `未確定`（[要件](./要件.mark.md)。決める段: モック作成） |
| 今の操作 | ドラッグ・キー・ダブルクリック・ダブルタップ・`Enter`、幅と順を保存しないこと、`-resize`・`reorder` の機能のオン・オフは変えない | - |
| アクセシビリティ | 追加する操作の要素はキーボードで届き、名前（`aria-label`）を持つ | - |
