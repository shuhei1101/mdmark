## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 押せる範囲 | 列の幅のつまみの押せる範囲を、`pointer: fine` でも幅 24 CSS px 以上にし、見出しのボタンと重ならないよう見出しのセルの右の余白を合わせる。見た目（右端の線）は変えない | - |
| 列の幅のドラッグの代わり | 追加しない（ユーザーの決定。[要件](./要件.mark.md)） | - |
| 列の並べ替えのドラッグの代わり | テーブル設定のつまみを 1 回押すと「前へ移す」「後ろへ移す」のメニューを開く。移せない向きの項目は `disabled` にし、押した項目が `disabled` になったらフォーカスを反対の向きの項目へ移す。どちらにも動かせない列のつまみは今までどおり `disabled` | - |
| 表の操作のバー | 表の上の帯をやめ、見出し行の右上（最後の列のつまみの左）の「表のメニュー」のボタンに、件数・テーブル設定・集計・コピー・RAW の切り替えを入れる。最後の列の見出しはつまみとボタンの分だけ右を空ける。CSV の RAW の表示ではコードブロックの右上に「表で表示」のボタンを重ねる | ユーザーの決定（[要件](./要件.mark.md)） |
| 今の操作 | ドラッグ・キー・ダブルクリック・ダブルタップ・`Enter`、幅と順を保存しないこと、`-resize`・`reorder` の機能のオン・オフは変えない | - |
| アクセシビリティ | 追加する操作の要素はキーボードで届き、名前（`aria-label`）を持つ。メニューは `role="group"` のボタンの並びにし、`role="menu"`・`aria-haspopup` は使用しない | - |
