# 要件

## 要望

表の列の幅のつまみの押せる範囲を、ポインターの種類によらず 24 x 24 CSS px 以上にする。
テーブル設定の列の並べ替えに、ドラッグをせずに列の順を変えられる操作を用意する。
表の操作のバー（件数・テーブル設定・集計・コピー）を、表の高さを増やさない配置にする。

測る基準は次のとおり。

| 対象 | 基準 |
| --- | --- |
| 列の幅のつまみの押せる範囲 | 細かいポインター（`pointer: fine`）と粗いポインター（`pointer: coarse`）の両方で幅・高さ 24 CSS px 以上。axe の `target-size` の違反が 0 件 |
| 列の並べ替えのドラッグの代わり | テーブル設定のパネルで、つまみを 1 回押して開くメニューの「前へ移す」「後ろへ移す」で、クリック・タップだけで列を前・後ろへ移せる |
| 表の操作のバー | 操作のバーを持つ表の高さが、同じ表の操作のバーを持たない表の高さと同じ（差が 1px 以内） |
| 今の操作 | 列の幅のドラッグ・`←`・`→`・ダブルクリック・ダブルタップ・`Enter`、列の並べ替えのドラッグ・`↑`・`↓`、変えた幅と順を保存しないことは変えない |

決定: 列の幅を、ドラッグをせずに変える操作（[確認事項](https://github.com/shuhei1101/mdmark/pull/811#discussion_r4709824242)）

幅を広げる・狭めるのボタンやメニューは追加せず、列の幅を変える操作は今のドラッグ・`←`・`→`・ダブルクリック・ダブルタップ・`Enter` のままにする。

決定: 列の並べ替えを、ドラッグをせずに変える操作（[確認事項](https://github.com/shuhei1101/mdmark/pull/811#discussion_r4709825588)）

案 B: テーブル設定の列名の行のつまみを 1 回押すと、「前へ移す」「後ろへ移す」のメニューが開く。

`未確定`: 表の操作のバーの置き場所（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 操作のボタンを、表の右上の角に重ねて出す。ポインターを乗せたとき・表の中にフォーカスがあるときに出し、粗いポインターの画面では常に出す |
| B | 見出し行の右端に「表のメニュー」のボタンを 1 つ置き、件数・テーブル設定・集計・コピーをそのメニューに入れる |
