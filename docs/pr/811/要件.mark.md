# 要件

## 要望

表の列の幅のつまみの押せる範囲を、ポインターの種類によらず 24 x 24 CSS px 以上にする。
ポインターで、ドラッグをせずに列の幅を変え、元の幅に戻せる操作を用意する。
テーブル設定の列の並べ替えに、ドラッグをせずに列の順を変えられる操作を用意する。

測る基準は次のとおり。

| 対象 | 基準 |
| --- | --- |
| 列の幅のつまみの押せる範囲 | 細かいポインター（`pointer: fine`）と粗いポインター（`pointer: coarse`）の両方で幅・高さ 24 CSS px 以上。axe の `target-size` の違反が 0 件 |
| 列の幅のドラッグの代わり | クリック・タップだけ（ポインターを押したまま動かさない）で列の幅を広げる・狭める・元の幅に戻すことができる |
| 列の並べ替えのドラッグの代わり | テーブル設定のパネルで、クリック・タップだけで列を前・後ろへ移せる |
| 今の操作 | 列の幅のドラッグ・`←`・`→`・ダブルクリック・ダブルタップ・`Enter`、列の並べ替えのドラッグ・`↑`・`↓`、変えた幅と順を保存しないことは変えない |

`未確定`: 列の幅を、ドラッグをせずに変える操作の構造（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 列の見出しのメニュー（並べ替え・ピン止めのボタンの並び）に「幅を広げる」「幅を狭める」「元の幅に戻す」の項目を追加する |
| B | つまみを押すと、つまみの近くに「広げる」「狭める」「元に戻す」のボタンの小さいパネルを出す（#805 の動画の大きさのメニューと同じ開き方） |
| C | テーブル設定のパネルの列名の行に、幅を広げる・狭めるボタンを追加する |

推奨: B

つまみ自体から開くので、つまみを見つけた読者がそのまま操作でき、#805 の動画のリサイズハンドルと同じ開き方に揃う。ダブルクリックで元の幅に戻す今の操作とも両立する。

`未確定`: 列の並べ替えを、ドラッグをせずに変える操作の構造（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | テーブル設定のパネルの列名の行に、前へ・後ろへ移すボタンを追加する |
| B | つまみを押すと「前へ移す」「後ろへ移す」のメニューを出す |

推奨: B

列名の行に常に出すボタンを増やさず、つまみの見た目と今のドラッグをそのまま使える。
