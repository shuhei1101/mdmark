# 要件

## 要望

`vscode/tests/integration/preview-rerender.test.ts` の `test_normal` が、[インターフェース定義『プレビューを再描画する』](https://github.com/shuhei1101/mdmark/blob/develop/docs/interface/IF-472-21.ts.yaml) の正常系の期待値「`render` を送信した時刻が、最後の書き換えから 300 ms より後」を、拡張機能のホストの応答の速さによらず同じ結果で確かめる。

- 最後の書き換えの時刻は、文書が変わった時点（拡張機能が待ちを始める `workspace.onDidChangeTextDocument` と同じ契機）で取る。今は `editor.edit` の完了を待った後に `Date.now()` を取るため、完了の通知が遅れると、送信より後の時刻になる
- 観測値「-1254 ms」のとき、送信した `render` の中身は 3 回目の全文だった。3 回目の書き換えの後でなければこの中身は送信できないため、原因は拡張機能の送信の待ちではなくテストの時刻の取り方にある。実装（`vscode/src/`）は変えない
- 修正後のテストを stable と固定の版の VS Code で繰り返し実行し、全 pass を確かめる
