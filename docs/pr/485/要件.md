# 要件

## 要望

結合テストのテストごとの所要時間を測り、意味の薄い長いテストと確認する内容が重なるテストを削除・軽量化し、ときどき落ちる既存のテスト 3 件を修正する。

| No | 項目 | 終わりの条件 |
| --- | --- | --- |
| 1 | 所要時間の計測 | ライブラリの結合テスト（`npm run test:integration`）は vitest の JSON レポーターで、VS Code 拡張機能の結合テスト（`xvfb-run -a npm --prefix vscode run test:integration`）は mocha の ms の出力で、テストごとの所要時間を修正の前と後に測り、所要時間の長い順の一覧を PR ドキュメントの `テスト結果/` に置く |
| 2 | 長いテストの削除・軽量化 | No 1 の一覧の上位のテストのうち、ほかのテストと確認する内容が重なるものを削除し、準備・待ちが長いものを確認する内容を変えずに軽くする。削除・軽量化したテストごとに、確認する内容がどのテストに残るかを計画書に書く。削除したテストに対応するインターフェース定義のフローの `test:` を追随させる |
| 3 | `test_normal_when_color_scheme` | `preview.theme` を `dark` にした後、新しい描画の `config` を待ってから検証する。作業ブランチで 10 回続けて流して全 pass する |
| 4 | `test_normal_when_tags_unreachable` | 負荷が高いときに経過時間の上限（6000 ms）で落ちない検証にする。待ちの上限（3 秒）より前に前回のバージョンを要求しないことは引き続き確認する |
| 5 | `test_error_when_part_module_unavailable` | `console.error` の 2 つの呼び出し（view・comments）を、順番によらずに比べる |
| 6 | 全件の所要時間 | ライブラリと VS Code 拡張機能の結合テストの全件の所要時間を修正の前と後で計画書に並べる |

測る前から重いと分かっているものは、次の 3 つ。

- mermaid（5MB）を 1 枚の HTML に埋めて開く `test_normal_when_mermaid_embedded`（`tests/integration/lib/export.test.ts`・`bundle.test.ts`）: 各約 65 秒
- integration-storybook: Storybook の起動に約 40 秒、各ファイルの `beforeAll` の準備に約 1 分
- VS Code の `test_normal`（2 件、各約 28 秒）・`test_normal_when_loading_shown`（約 12 秒）

修正前のライブラリの結合テストは 1059 件で 1612 秒かかり、そのうち `tests/integration/lib/build.test.ts` の 11 件が 1 つのファイルの中で順に 1041 秒かかった（`テスト結果/20261113000000_f844e4e0_結合テストの所要時間_修正前.log`）。
mermaid を埋めて開く 2 件は 9〜14 秒で、削除・軽量化の対象にしない。
削除・軽量化するテストは次のとおり。

| テスト | 修正前 | 対応 | 確かめる内容が残るテスト |
| --- | --- | --- | --- |
| `build.test.ts` の `test_normal_when_schema_changed_with_steps` | 166 秒 | 削除 | 単体の `test_check_migrations`（[MOD-472-168](../../module/MOD-472-168.ts.yaml)）。手順の点検を通った後にビルドへ進むことは結合の `test_normal` |
| `build.test.ts` の `test_normal_when_schema_change_listed` | 157 秒 | 削除 | 単体の `test_check_migrations_when_listed`（MOD-472-168）と E2E の同名のテスト（SC-472-82） |
| `build.test.ts` の `test_normal_when_api_checked_before_use` | 146 秒 | 削除 | 単体の `test_find_baseline_violations_when_api_guarded`（[MOD-472-165](../../module/MOD-472-165.ts.yaml)）。下限の確認を通ったときにビルドを終えることは結合の `test_normal` |
| `build.test.ts` の残りの 8 件 | 各 27〜182 秒 | 軽量化 | 作業ツリーのコピー元（`scripts`・`src`・`schemas`・`templates`・依存の入力）を、ファイルで 1 回だけ一時フォルダに写し、各テストはそこから写す。ビルドしない異常系も 1 件ごとに約 26 秒かかっている |
