| `test_normal_when_mermaid_embedded` | 変えない | 修正前の計測で 9〜14 秒だったため |
| `test_error_when_part_module_unavailable` | `console.error` の呼び出しを順番によらずに比べる（`expect.arrayContaining` と件数 2 の確認） | 確かめる内容は変えない |
| 対象外 | メモリの使用の削減（#373）・`test_normal_when_range_scripts`（#364）は扱わない | - |
