## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 所要時間の計測 | `npm run test:integration -- --reporter=json --outputFile=...` でテストごとの所要時間を取り、所要時間の長い順の一覧にして `テスト結果/` に置く。修正の前と後に測る | - |
| 長いテストの削除・軽量化 | 計測の一覧の上位のうち、ほかのテストと確認する内容が重なるものを削除し、準備・待ちが長いものを確認する内容を変えずに軽くする | `未確定`（決める段: インターフェース定義設計。案と推奨は [要件](./要件.md) の `## 要望`） |
| `test_normal_when_mermaid_embedded` | `export.test.ts` と `bundle.test.ts` で、mermaid を埋めて file:// で開く確認が重なる。どちらか片方だけで開いて確かめ、もう片方は埋めたことの確認に絞るかを、計測の後に決める | 同上 |
| `test_error_when_part_module_unavailable` | `console.error` の呼び出しを順番によらずに比べる（`expect.arrayContaining` と件数 2 の確認） | 確かめる内容は変えない |
| 対象外 | メモリの使用の削減（#373）・`test_normal_when_range_scripts`（#364）は扱わない | - |
