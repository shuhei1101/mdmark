## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 枠線 | ツールチップの要素を 2 重にし、内側の枠 `.mdmark-term-tip-frame`・`.mdmark-fn-tip-frame` に 4 辺の `1px solid var(--mdmark-color-muted)` の枠線・角丸・背景・高さの上限・スクロール（`overflow-y: auto`）・中の余白を移す。外側の `.mdmark-term-tip`・`.mdmark-fn-tip` は配置場所・幅の上限・文字の大きさを残し、枠線と背景を持たない | `is-below` と幅の狭い画面の規則も同じ。幅の狭い画面で余白を上側に移す規則は、スクリプトが開いていないとき（`:not(.is-open)`）に限る |
| 間隔と当たり判定 | 外側の要素の単語（番号）の側に 0.4em の `padding` を置く（上に開くときは下側、`is-below` のときと、幅の狭い画面でスクリプトが開いていないときは上側）。余白は外側の要素の中なので、ポインターが渡っても `pointerleave`・`:hover` が外れない | スクリプトの配置（外側の要素を単語に接して置く）は変えない |
| 部品設計 | CMP-472-53・CMP-472-58 の出力の構造に内側の枠を加え、透明な線の記述を余白の記述にする | - |
| モジュール構成 | MOD-472-261（term-tip.part.ts）・MOD-472-333（footnote.part.ts）の出力に内側の枠を加え、MOD-472-170（index.css）の脚注の規則の行に枠と余白を記載する。term.interact.ts・footnote.interact.ts の配置は変えない | - |
| 結合テスト | 用語・脚注のツールチップの結合テストで、上に開いたとき・下に開いたときに、内側の枠の 4 辺の枠線が同じ色と幅で、外側の要素の単語（番号）の側に余白があることを確かめる。幅の狭い画面でスクリプトが上に配置したときも、余白が下側にあることを確かめる。脚注・用語の透明な線の期待を置き換える。関連文書が多いときは内側の枠がスクロールすることを確かめる | - |
| 単体テスト | 部品の出力が内側の枠を持つこと、単語（番号）からツールチップの余白を通ってポインターを移しても閉じないことを確かめる | - |
