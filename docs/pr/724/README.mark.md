# 用語と脚注のツールチップの 4 辺すべてに枠線を出す

## 概要

用語・エイリアスのツールチップの 4 辺すべてに枠線を出し、単語からツールチップへポインターを移しても閉じない動きは残す。

## 背景

[Issue #722](https://github.com/shuhei1101/mdmark/issues/722) の要望。表のセルの中の用語で、ツールチップの下の辺の枠線が出ない。

`src/index.css` の `.mdmark-term-tip` は、単語とツールチップの間をポインターが渡れるよう、単語の側の辺を 0.4em の透明な線にしている（上に開くときは下の辺、`.is-below` と幅の狭い画面では上の辺）。
脚注の番号のツールチップ `.mdmark-fn-tip` も「用語のツールチップと同じ枠」で、同じ透明な線を持つ。
