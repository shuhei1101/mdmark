# 要件

## 要望

用語・エイリアス・やめた言い方のツールチップ（`.mdmark-term-tip`）と、脚注・注記の番号のツールチップ（`.mdmark-fn-tip`）の 4 辺すべてに、`1px solid var(--mdmark-color-muted)` の枠線を出す。

- 単語（番号）の上に開いたとき・下に開いたとき（`is-below`）・幅の狭い画面（71rem 以下）のどれでも、4 辺の枠線の色と幅が同じになる
- 単語（番号）からツールチップへポインターを移す間にツールチップが閉じない。単語とツールチップの間の 0.4em の間隔は残す
- スクリプトが配置するとき（`position: fixed`）と、スクリプトが動かないとき（CSS の `:hover`・`:focus-within`）の両方で上の 2 点が成り立つ

脚注の番号のツールチップは用語のツールチップと同じ枠の規則を持ち、同じ透明な線で同じ辺の枠線が出ないため、要望に含める（規約『見積もりポイント』の `## まとめて対応する`）。

`未確定`: 間隔のポインターの当たり判定を保つ方法（決める段: 部品設計）

| 案 | 内容 |
| --- | --- |
| A | ツールチップの疑似要素（`::before`）を単語の側の 0.4em に置き、当たり判定だけを広げる。ツールチップを 0.4em 離して配置する |
| B | 開閉のスクリプトで、単語からツールチップへ移る間の `pointerleave` を遅らせて閉じる |

推奨: A

CSS だけで閉じ、スクリプトが動かないときも同じ動きになるため。ツールチップの中身がスクロールする（`overflow-y: auto`）ため、疑似要素がツールチップの外に出て当たり判定を持つかは部品設計で確かめる。
