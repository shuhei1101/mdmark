# 要件

## 要望

map のマーカーの引数に `mode` を追加するかを決める。

- 終わりの条件 1: 追加するかをユーザーが決め、決めた内容と理由が確認ログに残っている
- 終わりの条件 2: 追加する場合、`<!-- map: {"mode": "{値}"} -->` を記載した map の図が、値ごとの見せ方で描かれ、`mode` を省いた図は今の描き方（入れ子のグループ）のまま描かれる
- 終わりの条件 3: 追加する場合、`mode` に知らない値を記載すると、今の `map_invalid_value` と同じく書き方の警告と点検のずれが出て、既定の見せ方で描かれる

`list`（一覧の表示）は A-35 の No 17 に当たり、[#471](https://github.com/shuhei1101/mdmark/issues/471) で追加するかを決めるため、この作業 PR の `mode` の値に含めない。

`未確定`: `mode` を追加するか（決める段: 単一ユースケース設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 追加しない。層は今のとおり補足の `layout` とグループで表す | 記載方法が増えず、同じ図に 2 通りの書き方が生まれない | 層を横レーンに並べる見せ方を、文書の作成者が引数 1 つで選べない |
| B | `mode` を追加し、`boxes`（今の入れ子のグループ）と `layers`（1 レイヤー目のグループを層としてレーンに並べる見せ方）を切り替える | 同じ Mermaid のまま、構成図を層のレーンで読ませられる | レーンの配置と、レーンの中の開閉・中へ入る操作の設計と実装が増える |

推奨: A

PR #445 で、層は補足の `layout` とグループで表せ、入れ子のグループが既定の描き方になった。`layers` で描ける図は今の記載方法でも描けるため、切り替える先が無い。
