# 要件

## 要望

map のマーカーの引数に `mode` を追加するかを決める。

- 終わりの条件 1: 追加するかをユーザーが決め、決めた内容と理由が確認ログに残っている
- 終わりの条件 2: 追加する場合、`<!-- map: {"mode": "{値}"} -->` を記載した map の図が、値ごとの見せ方で描かれ、`mode` を省いた図は今の描き方（入れ子のグループ）のまま描かれる
- 終わりの条件 3: 追加する場合、`mode` に知らない値を記載すると、今の `map_invalid_value` と同じく書き方の警告と点検のずれが出て、既定の見せ方で描かれる

`list`（一覧の表示）は A-35 の No 17 に当たり、[#471](https://github.com/shuhei1101/mdmark/issues/471) で追加するかを決めるため、この作業 PR の `mode` の値に含めない。

`mode` は追加しない（[確認ログ](./確認ログ.yaml)。ユーザーが推奨案 A を承認した）。層は今のとおり補足の `layout` とグループ（`subgraph`）で表す。

確認した案は次のとおり。

| 案 | 内容 |
| --- | --- |
| A（採用） | 追加しない。層は今のとおり補足の `layout` とグループで表す |
| B | `mode` を追加し、`boxes`（今の入れ子のグループ）と `layers`（ルートのグループを図の幅いっぱいの同じ幅のレーンにして上から並べる）を切り替える |
| C | マーカーの引数は追加せず、補足の `layout` でグループにも幅を指定できるようにする |

層は `subgraph` と `direction TB` で上から並べて描ける（SC-472-8 の「正常シナリオ（構成図の層を指定する）」）。`layers` との違いはレーンの幅を揃えることとタイトルの位置だけで、切り替える先として独立した見せ方にならない。
