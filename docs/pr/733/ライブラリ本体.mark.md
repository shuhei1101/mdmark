| 対象 | 方針 | 補足 |
| --- | --- | --- |
| マーカーの引数 | `mode` を `title`・`focus`・`collapse` と同じ JSON のオブジェクトのキーとして読む。値は `boxes`・`layers`、省いたときは `boxes` | `未確定`（追加するか。要件.mark.md の案 A・B） |

| ドキュメント | 記法のリファレンスとコアコンセプト『図を自動配置して辿る仕組み』に `mode` を追加する | 追加する場合 |
