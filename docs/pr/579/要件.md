# 要件

## 要望

表の横スクロールの端の影は出さない（`src/index.css` の表の規則）を正とし、表の設計書と公開ドキュメントから表の端の影の記述を削除する。
CSS とテストは変更しない。

| ページ | 修正する記述 |
| --- | --- |
| 画面設計『文書』の要素「表」 | 「表の中で横スクロールし、続きがある側の端に影を出す」から端の影を削除する |
| インターフェース定義『文書を描く』の制約（表の縦の高さと列の幅） | 「表の中で横にスクロールし、続きがある側の端に影を出す」から端の影を削除する |
| 部品設計『表』の CSS 変数 `--mdmark-color-bg-opaque` | 用途の「横スクロールの影を隠す覆い」を削除する |
| モジュール構成『index.css』の表を包む要素 | 「続きがある側の端の影を持つ」を削除し、値の出典 `docs/mock/refs/308/assets/table.css` から端の影を除外する |
| API の CSS 変数の表の `--mdmark-color-bg-opaque` | 使用する場所の「表の本文の行と横スクロールの影を隠す覆い」から「横スクロールの影を隠す覆い」を削除する |
| API の CSS 変数の表の `--mdmark-color-scroll-shadow` | 使用する場所の「表とコードブロックに横の続きがあることを示す影」を「コードブロックに横の続きがあることを示す影」にする |
| テーマを上書きするの `--mdmark-color-bg-opaque` の説明 | 「ツールチップ・全画面の図・表の横スクロールの影を隠す覆いなど」から「表の横スクロールの影を隠す覆い」を削除する |
| 印刷するの横スクロールの行 | 「表とコードブロックの横スクロールと続きの影をやめ」の続きの影をコードブロックだけにする |

コードブロック（`pre`）の端の影は変えない。
