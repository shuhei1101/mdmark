# 表の設計書から横スクロールの端の影の記述を削除し、影を出さない表の CSS と統一する

## 概要

表の設計書の横スクロールの端の影の記述を削除し、端の影を出さない `src/index.css` の表の規則と統一する。

## 背景

[画面設計『文書』の表の「続きがある側の端に影を出す」と、表の CSS（端の影を出さない）を揃える](https://github.com/shuhei1101/mdmark/issues/529) の要望。
画面設計『文書』の要素「表」は「続きがある側の端に影を出す」と記載しているが、`src/index.css` の表は [はみ出す表は既定で先頭の列をピン止めし、pin=・wide= と真偽値の ✓ 表示を追加する](https://github.com/shuhei1101/mdmark/pull/283) から横スクロールの端の影を出さない。
[描いた文書の表示を改善する（表の列の幅の自動計算・ファイルツリーの既定の全開き・コードブロックの帯の線の削除・目次で押した見出しのセクションを開く）](https://github.com/shuhei1101/mdmark/pull/505) の結合テストで見つかり、[描いた文書の表示を改善する（表の列の幅の自動計算・ファイルツリーの既定の全開き・コードブロックの帯の線の削除・目次で押した見出しのセクションを開く）](https://github.com/shuhei1101/mdmark/pull/505) は画面設計の記述をスコープ外として残した。
