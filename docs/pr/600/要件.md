# 要件

## 要望

### [#557](https://github.com/shuhei1101/mdmark/issues/557) map の図の説明のツールチップに features.hints と tooltips.diagramPlacement を適用する

map の図の補足の `notes` の説明（ノード・線・グループ）と注記のツールチップとマーカーを、設定の `features.hints` がオフのときは描かず、`tooltips.diagramPlacement` が `top` のときは持ち主の上に先に出す。
ER 図・状態遷移図の map も構成図と同じ描画（`attachMapFlow`）を通るため、同じく適用する。

終わりの条件: map の構成図とシーケンス図の説明のツールチップとマーカーが、`features.hints` がオフのときに描かれず、`tooltips.diagramPlacement` が `top` のときに持ち主の上に先に出る。IF-472-35 の制約「図のツールチップ」の「map の図は常に `bottom`」の記載が修正されている。

### [#561](https://github.com/shuhei1101/mdmark/issues/561) ビューの表の長文の列に並べ替えを既定で付けないかを決める

ビューのマーカーの表にも、表のマーカーと同じく長文の列（`data-long`）に並べ替えを既定で付けず、`columns.{列名}.sort` で付け外しできるようにする（ユーザーが案 A を選んだ。確認ログ）。
ビューのマーカーが `columns.{列名}.sort` を読み（`schemas/marks/view.schema.json` にキーを追加）、インターフェース定義『文書をHTML文字列にする』の制約「ビューのマーカー」と使い方のビューのページに記載し、ビューの表で長文の列に並べ替えが付かないことの単体テストを追加する。

終わりの条件: ビューの表に同じ既定を適用するかをユーザーが決めている。適用する場合は、ビューのマーカーが `columns.{列名}.sort` を読み（`schemas/marks/view.schema.json` にキーがある）、インターフェース定義『文書をHTML文字列にする』の制約「ビューのマーカー」と使い方のビューのページに記載され、ビューの表で長文の列に並べ替えが付かないことの単体テストがある。
