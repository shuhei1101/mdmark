## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| map の図のツールチップを出す場所 | `flow-view.ts`・`sequence-view.ts` が `attachDiagrams` に `config.tooltips.diagramPlacement` を渡す | ER 図・状態遷移図の map も `attachMapFlow` を通るため同じく効く |
| map の図のヒント | `config.features.hints` がオフなら、`notes` の説明と注記のツールチップとマーカーを描かない。線のラベルとノードの名前は描く | 注記のツールチップも描かない。注記の本文は文書の末尾の注記の一覧に残す |
| ビューの表の並べ替え | `readView` が `columns.{列名}.sort` を読んで `sorts` に入れ、`tableOptionsOf` の `!fromView` の条件を外す | ユーザーが案 A を選んだ（確認ログ） |
| ビューのマーカーの Schema | `schemas/marks/view.schema.json` の `columns.{列名}` に `sort`（boolean）を加える | マーカーの Schema のため `migrations/no-steps.yaml` の行は要らない |
| 既存機能への影響 | 既定（`hints` オン・`diagramPlacement` `bottom`）では map の図の見え方は変わらない。#561 で、既存のビューの表の長文の列から並べ替えが外れる | - |
