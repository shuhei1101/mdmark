## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 開閉の記録 | `mount` ごとに 1 つ、手で開閉を変えたセクションの開閉を記録し、再描画しても保つ（`sideTocState` と同じ持ち方） | セクションの中身の `id` で対応づける |
| 記録へ書く | 開閉のボタン・Shift での入れ子の開閉・すべて展開・すべて折りたたむ・`#ID` で開く・右側の目次の項目で移る・コメントのマーカーへ移る・ページ内検索で開くのたびに、変わったセクションの開閉を記録へ書く | - |
| 始めの開閉 | `attachSection` は記録にあるセクションを記録の開閉で、無いセクションをマーカーのとおりの開閉で始める | 開閉のマーカーが記録したときと変わったセクションはマーカーのとおり。`update` では URL の `#ID` のセクションを開き直さない |
| 記録を捨てる | 同じ要素への 2 回目の `mount` と `destroy` で捨てる | - |
| 既存機能への影響 | 公開関数の引数・戻り値・マーカーは変えない。印刷の前後で全てを開いて戻す処理は記録へ書かない | - |
