# 要件

## 要望

`MountHandle.update` で描き直すとき、描き直す前に読者が変えたセクションの開閉を、描き直した後の同じセクションに引き継ぐ。

- 引き継ぐ操作: 開閉のボタン・Shift での入れ子の開閉・すべて展開・すべて折りたたむ・URL の `#ID` で開く・右側の目次の項目で移る・コメントのマーカーへ移る・ページ内検索で開く
- 描き直す前に無かったセクションと、手で開閉を変えていないセクションは、マーカーのとおりの開閉で描く
- 同じ要素への 2 回目の `mount` と `destroy` の後は引き継がない
- 公開関数の引数・戻り値・マーカーは変えない

- 描き直しの前後で、セクションの中身の `id`（`section-{見出しの ID}`）が同じものを同じセクションとする。見出しの文字を変えたセクションは新しいセクションとしてマーカーのとおりに描く
- 開閉のマーカーの指定が描き直す前と変わったセクションは、マーカーのとおりに描く
- URL の `#ID` が指すセクションを開くのは `mount` で初めて描いたときと `hashchange` のときだけにし、`update` の描き直しでは開き直さない
