# 要件

## 要望

`MountHandle.update` で描き直すとき、描き直す前に読者が変えたセクションの開閉を、描き直した後の同じセクションに引き継ぐ。

- 引き継ぐ操作: 開閉のボタン・Shift での入れ子の開閉・すべて展開・すべて折りたたむ・URL の `#ID` で開く・ページ内検索で開く
- 描き直す前に無かったセクションと、手で開閉を変えていないセクションは、マーカーのとおりの開閉で描く
- 同じ要素への 2 回目の `mount` と `destroy` の後は引き継がない
- 公開関数の引数・戻り値・マーカーは変えない

`未確定`: 描き直しの前後でセクションを対応づける方法（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | セクションの中身の `id`（`section-{見出しの ID}`）が同じものを同じセクションにする |
| B | 見出しの階層と出現順が同じものを同じセクションにする |

推奨: A

セクションの中を編集しても見出しの ID は変わらず、前にセクションを足したときも対応がずれないため。見出しの文字を変えたセクションは新しいセクションとしてマーカーのとおりに描く。

`未確定`: 手で開閉したセクションのマーカーを描き直しの間に変えたときの開閉（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | マーカーの開閉の指定が描き直す前と変わったセクションは、マーカーのとおりにする |
| B | マーカーが変わっても手の開閉を優先する |

推奨: A

作成者がマーカーを書き換えたときは、その指定を描いた結果で確かめたいため。
