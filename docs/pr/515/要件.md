# 要件

## 要望

VS Code 拡張機能の「HTML に書き出す」「ブラウザで開く」「PDF に印刷する」が書き出す HTML で、重ねて読み込んだ設定の `aliases` からエイリアスを作り、`mount` の `opts.aliases` に指定して、本文に出たエイリアスに下線と種類ごとのツールチップを出す。

- エイリアスはプレビューと同じ `loadAliases`（`src/cli/aliases.ts`）で作り、書き出す HTML の設定の JSON と同じ `<script type="application/json">` に埋める
- 設定に `aliases` が無いときは、今と同じ HTML を書き出す（`mount` に `aliases` を指定しない）
- `aliases` の行が指す YAML を読み込めない・スキーマに合わないときは、その行・レコードを除いて書き出し、出力チャネルに警告を記録する（書き出しは止めない）
- 確認の基準: `aliases` に用語のエイリアスの行を持つ設定ファイルの隣の Markdown を「HTML に書き出す」で書き出し、ブラウザで開くと、本文の別名に下線が付き、ホバーでツールチップに種類と意味が出る
