# 要件

## 要望

### #638 VS Code 拡張機能の設定 mdmark.version で develop の最新を選べるようにする

設定 `mdmark.version` に `develop` を記載でき、プレビューを開いたときとリロードしたときに、タグ一覧を取らずに jsDelivr の `@develop` の配布物を読み込んで描く。
今の `latest`・`v{X}.{Y}.{Z}` は今のまま使用できる。

- 終了の条件: mdmark.version に develop を記載でき、プレビューで develop の最新の配布物（jsDelivr の @develop）を読み込める。設定の設計書 CFG-472-2・公開ドキュメント・単体テストも合っている

### #639 develop の配布物の作り直しが、出したバージョンの移行の手順の配布物を書き換えて commit する

develop の配布物の作り直し（`develop-dist.yml`）とタグを打つときのビルドが、出したバージョン（`v{X}.{Y}.{Z}` のタグがあるバージョン）の `migrations/v*/` を書き換えない。
出していないバージョンの移行の手順（`migrations/next/` と、タグを打つ前に `next` から移したフォルダ）の配布物は今のまま作り直す。
develop の配布物の作り直しが書き換えた出したバージョンのファイルを、出したときの内容に戻す。

- 終了の条件: develop の配布物の作り直しとタグを打つときのビルドが、出したバージョンの migrations/v*/ を書き換えない。dd0b92b1 で書き換わった 3 ファイルが、出したときの内容に戻っている
- 戻すファイル: dd0b92b1 の 3 ファイル（`migrations/v0.11.0/THIRD_PARTY_LICENSES.txt`・`migrations/v0.11.0/legacy-marks.js`・`migrations/v0.13.0/retired-diagrams.js`）と、v0.14.0 のタグの後に develop の配布物の作り直しが書き換えた `migrations/v0.14.0/retired-diagrams.js`

戻し先: 4 ファイルとも最新のタグ（v0.14.0）の内容に戻す。`migrations/v0.13.0/retired-diagrams.js` は v0.13.0 のタグと v0.14.0 のタグで内容が違う（[aa5ae6f2](https://github.com/shuhei1101/mdmark/commit/aa5ae6f2)（#616）のビルドが作り直し、[#629](https://github.com/shuhei1101/mdmark/pull/629) が取り込む前の内容に戻した）が、jsDelivr の `@v0.14.0` と最新の CLI が配る中身は v0.14.0 のタグの内容のため、利用者が今受け取っている配布物と一致させる。
