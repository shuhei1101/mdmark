# 要件

## 要望

VS Code 拡張機能 `mdmark for VS Code` のアイコンを作り、Marketplace の `ShuheiNishikawa.mdmark-vscode` と VS Code の拡張機能のビューに表示する。

- 図案は SVG で案を作り、ユーザーに確認して決める（規約『VS Code 拡張機能の配布』の「アイコン」）
- 決まった SVG を原本として `vscode/` に配置し、`.vscodeignore` で .vsix から除く
- 原本から 256×256px の PNG を書き出し、`vscode/package.json` の最上位の `icon` にそのパスを記載する（`icon` に SVG は使用できない）
- `vscode/package.json` の `version` を `0.1.3` から `0.1.4` に上げ、マージの後に `vscode-v0.1.4` のタグで Marketplace へ公開する
- 配置したファイルの行を `vscode/files.yaml` に追加する

`未確定`: アイコンの図案（決める段: モジュール構成設計。案ごとに SVG を作って配信し、ユーザーに確認する）

| 案 | 内容 |
| --- | --- |
| A | mdmark の頭文字「m」に、マーカーで引いた線を重ねる |
| B | Markdown の「M↓」の形に、マーカーで引いた線を重ねる |
| C | 文書の紙の上に、図と表を表す図形を置く |

推奨: B

Markdown のプレビューの拡張機能だと拡張機能の一覧で見分けられ、名前の mark をマーカーの線で表せるため。
