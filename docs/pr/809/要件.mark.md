# 要件

## 要望

束の親 [Issue #808](https://github.com/shuhei1101/mdmark/issues/808) の子 Issue ごとの終了の条件。

| Issue | 終了の条件 |
| --- | --- |
| [#807](https://github.com/shuhei1101/mdmark/issues/807) | 部品『media』のモックを開いたときにスクリプトのエラーが出ない |
| [#806](https://github.com/shuhei1101/mdmark/issues/806) | 図の枠のリサイズハンドルの押せる範囲の高さが 24 CSS px 以上になる。ポインターでドラッグせずに高さを戻す操作は、今のダブルクリックのままにする |

測る基準は次のとおり。

| 対象 | 基準 |
| --- | --- |
| 部品『media』のモック | `detect_screen_issues`（`target`: `mock`）の 1280x800・390x844 で `script-error` が 0 件 |
| 図の枠のリサイズハンドルの押せる範囲 | 表示する枠の下の帯で、高さ 24 CSS px 以上。axe の `target-size` の違反が 0 件 |
| 今の操作 | ドラッグ・`↑`・`↓`・ダブルクリック、変えた高さの保持、設定の `features.diagram-resize` によるオフは変えない |

決定: ドラッグの代わりの操作の構造（[確認事項](https://github.com/shuhei1101/mdmark/pull/809#discussion_r4690120989)）

高くする・低くするのボタン（メニュー・右上のパネル）は追加しない。
ポインターでドラッグせずに高さを戻す操作は、今のダブルクリック（倍率を変えずに図の全体が収まる高さにする）のままにする。
リサイズハンドルの見た目は、表示する枠の下の 24px の帯の中央の横棒（shadcn/ui の Drawer の取っ手と同じ形）にする。

決定: 部品『media』のモックのスクリプトのエラーの修正方法（[確認事項](https://github.com/shuhei1101/mdmark/pull/809#discussion_r4690097156)）

案 A: モックのライトボックスに、実装と同じ拡大・縮小・全体・移動のボタンを追加する。
