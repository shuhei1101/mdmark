# 要件

## 要望

束の親 [Issue #808](https://github.com/shuhei1101/mdmark/issues/808) の子 Issue ごとの終了の条件。

| Issue | 終了の条件 |
| --- | --- |
| [#807](https://github.com/shuhei1101/mdmark/issues/807) | 部品『media』のモックを開いたときにスクリプトのエラーが出ない |
| [#806](https://github.com/shuhei1101/mdmark/issues/806) | 図の枠のリサイズハンドルの押せる範囲が 24 x 24 CSS px 以上になり、ポインターでドラッグ・ダブルクリックをせずに高さを変え、元に戻せる |

測る基準は次のとおり。

| 対象 | 基準 |
| --- | --- |
| 部品『media』のモック | `detect_screen_issues`（`target`: `mock`）の 1280x800・390x844 で `script-error` が 0 件 |
| 図の枠のリサイズハンドルの押せる範囲 | 幅・高さとも 24 CSS px 以上。axe の `target-size` の違反が 0 件 |
| ドラッグの代わりの操作 | ポインターのタップ・クリック（1 回押す）だけで、表示する枠の高さを高く・低くでき、元の高さに戻せる |
| 今の操作 | ドラッグ・`↑`・`↓`・ダブルクリック、変えた高さの保持、設定の `features.diagram-resize` によるオフは変えない |

`未確定`: ドラッグの代わりの操作の構造（決める工程: モック作成）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 作業 PR [#805](https://github.com/shuhei1101/mdmark/pull/805) の動画のリサイズハンドルと同じく、ハンドルを押す（動かさずに離す）か Enter で、高くする・低くする・元に戻すのボタンを持つメニューを開く | 動画と図で同じ操作になり、読者が覚える操作が 1 つで済む | メニューを開く 1 回の押す操作が増える |
| B | 図の右上のボタンのパネルに、高くする・低くする・元に戻すのボタンを追加する | 1 回押すだけで高さが変わる | パネルのボタンが増え、狭い図の枠で並べにくい |

推奨: A

動画のリサイズハンドルで合意した操作と統一されるため、読者が図と動画で別の操作を覚えずに済む。

`未確定`: 部品『media』のモックのスクリプトのエラーの修正方法（決める工程: モック作成）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | モックのライトボックスに、実装と同じ拡大・縮小・全体・移動のボタンを追加する | モックのライトボックスが実装と同じ構成になる | モックの HTML の差分が大きくなる |
| B | `media.js` で、無いボタンを探さないようにする | 修正が 1 か所で済む | モックのライトボックスが実装と違う構成のまま残る |

推奨: A

ライトボックスは図の全画面と同じボタンで拡大・縮小・移動するため、モックも実装と同じ構成にしておくと、モックで確認した見た目と実装が一致する。
