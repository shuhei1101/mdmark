## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 押せる範囲 | 図の枠のリサイズハンドルを、表示する枠の下の高さ 24 CSS px の帯にし、帯のどこでもドラッグできるようにする。見た目は帯の中央の横棒（shadcn/ui の Drawer の取っ手と同じ形）。map の図も同じ帯にする | - |
| 今の操作 | ドラッグ・`↑`・`↓`・ダブルクリック・変えた高さの保持と、機能 `diagram-resize` のオフは変えない | - |
| 部品『media』のモック | ライトボックスに、部品『figure』のモックと同じ画像の切り替え・移動・拡大と縮小・閉じるのボタンを追加し、開いたときにスクリプトのエラーを出さない | - |
