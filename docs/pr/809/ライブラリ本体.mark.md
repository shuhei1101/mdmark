## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 押せる範囲 | 図の枠のリサイズハンドルの押せる範囲を幅・高さとも 24 CSS px 以上にする。map の図の上書きも同じ大きさにする | 見た目はモック作成で決める |
| ドラッグの代わりの操作 | ポインターで 1 回押すだけで、表示する枠の高さを高く・低くし、元の高さに戻せる操作を追加する | `未確定`（[要件](./要件.mark.md) の案。決める工程: モック作成） |
| 今の操作 | ドラッグ・`↑`・`↓`・ダブルクリック・変えた高さの保持と、機能 `diagram-resize` のオフ（代わりの操作も出さない）は変えない | - |
| アクセシビリティ | 代わりの操作のボタンに読み上げの名前を付け、キーボードで開閉・操作でき、閉じたらハンドルへフォーカスを戻す | - |
| 印刷 | 代わりの操作の要素も印刷に出さない | - |
| 部品『media』のモック | ライトボックスを開いたときにスクリプトのエラーを出さない | `未確定`（[要件](./要件.mark.md) の案。決める工程: モック作成） |
