# はみ出す表の既定をピン止めなしにし、差分のブロックでフロントマターの変更を示す

## 概要

読者が、幅からはみ出す表を、どの列も留めない状態で参照し始められるようにする（設定で今の動きも選べる）。
読者が、比較元の Markdown を指定した差分のブロックで、文書の先頭のフロントマターの変更も確認できるようにする。

## 背景

束の親 [Issue #712](https://github.com/shuhei1101/mdmark/issues/712) が、次の 2 件をまとめている。

| Issue | 背景 |
| --- | --- |
| [#711](https://github.com/shuhei1101/mdmark/issues/711) | ピン止めを持つ表は、幅からはみ出すと描いた直後から先頭の列（行見出しがある表は行見出しの列）を左端に留める（[#283](https://github.com/shuhei1101/mdmark/pull/283) で入れた既定）。MindStella の画面で資料や検討事項の表を開くたびに先頭の列が固定され、利用者は既定では留めない表示を求めている |
| [#462](https://github.com/shuhei1101/mdmark/issues/462) | [PR #422](https://github.com/shuhei1101/mdmark/pull/422)（起点 Issue [#325](https://github.com/shuhei1101/mdmark/issues/325)）で文書の先頭のフロントマターを既定で描かないようにしたため、描いた文書の上で色分けする差分のブロックにフロントマターの変更が出ない（Markdown の行の差分には出る） |
