### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定 | 既定で留めるかを選ぶ設定を追加し、既定を留めない側にする | `table.pin_default`（真偽値、既定 `false`） |
| 描いた直後に留める列 | 既定で留めない設定では、`columns.{列名}.pinned` の `true` の列だけを留める。留める設定では今の決め方のまま | `each` / `through` の両方 |
| ピン止めのボタン | ボタンの表示・押したときの動き・`-pin` は変えない。描いた直後の `aria-pressed` は留めた列だけ `true` | - |
| 書き出し・CLI | CLI の設定の検査に追加した設定を含め、`render` の出力は設定に合わせる | - |
| 移行 | 既存の設定ファイルは書き換えずに使用できる | 手順の要否はデータ設計で決める |
