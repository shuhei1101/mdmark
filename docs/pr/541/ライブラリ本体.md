## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文書の拡張子 | mdmark の文書の拡張子を `.mark.md`、それ以外の `.md` を純粋な `.md` として判定する関数を 1 か所に置く | - |
| まとめる対象 | `.mark.md` と純粋な `.md` の両方を、今と同じく `build.include` の glob で集める | 雛形の `build.include` は変えない |
| 点検 | 純粋な `.md` の文書が記法を含むとき、文書と最初の記法の行を指し、内容に `.mark.md` への変更の提案を記載するずれを 1 文書に 1 行出す | 記法の判定の範囲は `要件.md` の `未確定` |
| 止める設定 | `mdmark.config.yaml` のキーで提案を止める。省略したときは提案を出す | キーの持ち方は `要件.md` の `未確定`。`migrations/no-steps.yaml` に行を置く |
| 既存機能への影響 | 既存の文書のうち記法を含む純粋な `.md` は、点検の終了コードが 1 になる | 止める設定で今と同じ結果にできる。既存の文書の移行は後続 |
| 描画・書き出し | 拡張子で振る舞いを変えない | - |
