# 要件

## 要望

次の 3 か所の用語集の行の用語の並びを、作業時点の [用語集](https://github.com/shuhei1101/mdmark/blob/45bcc4e1ff7ef3191f7260dcd9eb8ba1012b84ac/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/%E7%94%A8%E8%AA%9E%E9%9B%86.md) の冒頭の並びに統一する。

| 場所 | 項目 | 用語の並びの後ろに続く文言（変えない） |
| --- | --- | --- |
| [docs/リファレンス/index.yaml](https://github.com/shuhei1101/mdmark/blob/45bcc4e1ff7ef3191f7260dcd9eb8ba1012b84ac/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/index.yaml) | 用語集の行の `summary` | `の用語の意味` |
| [リファレンス](https://github.com/shuhei1101/mdmark/blob/45bcc4e1ff7ef3191f7260dcd9eb8ba1012b84ac/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/README.md) | 用語集の行の概要（`index.yaml` から再生成する） | `の用語の意味` |
| [docs/files.yaml](https://github.com/shuhei1101/mdmark/blob/45bcc4e1ff7ef3191f7260dcd9eb8ba1012b84ac/docs/files.yaml) | 用語集の行の `description` | `の用語の意味。名前から参照して確認するときに参照する。` |

統一した後、3 か所の用語の並びが冒頭の並びと文字列で一致する。

冒頭の並びは、「CSV の表」の後ろに `の用語の意味` が入り、その後ろに「カードの格子・ページの設定・配色の明暗」が続いている。
`の用語の意味` を並びの末尾へ戻してから、3 か所をその並びに統一する。

コードを変えず、`docs/` の文言だけを変えるため、関係する単体・結合テストは無い。
