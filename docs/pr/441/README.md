# 用語集の目次の用語の並びを用語集の冒頭の並びに統一する

## 概要

用語集の目次側の用語の並び（`docs/リファレンス/index.yaml`・`docs/リファレンス/README.md`・`docs/files.yaml` の用語集の行）を、用語集の冒頭の並びに統一する。

## 背景

[用語集の目次の用語の並びに「CSS のテンプレート」「テンプレートの索引」を足す](https://github.com/shuhei1101/mdmark/issues/362) の要望。
[端末の設定のフォルダに CSS のテンプレートを配置し、MCP で一覧・登録・配置する](https://github.com/shuhei1101/mdmark/pull/353) などが `docs/リファレンス/用語集.md` に用語を追加し、冒頭の並びにも追加したが、目次側の 3 か所には追加しておらず、冒頭の並びと食い違っている。
[索引のタグの語彙と、語彙に無いタグの点検をやめる](https://github.com/shuhei1101/mdmark/pull/355) のレビューで reviewer が対象外の逸脱として報告した。
