# 要件

## 要望

公開ドキュメントの GitHub Pages を `docs/_theme/` のレイアウトで描く。

- `docs/_theme/` を AI Monitor の develop の内容へ取り込む。配布物リスト（AI Monitor の `distribution.yaml`）の除外の `docs/_theme/assets/*.ts` と `docs/_theme/_data/nav.project.yml` は写さず、mdmark の今のファイルを残す
- `docs/_config.yml` に、AI Monitor の develop の `docs/_config.yml` と同じレイアウト（`layouts_dir`・`includes_dir`・`data_dir`・コレクション `theme`・`defaults` の `layout`）とプラグインの設定を追加する。`title`・`description`・`baseurl` は mdmark の値（`baseurl: /mdmark`）にし、`exclude` の文書を指す行は今のまま保つ
- Jekyll でビルドし、次を確かめる
  - 全ページが `_theme/_layouts/default.html` で描かれる
  - 上タブに `docs/_theme/_data/nav.project.yml` の `tabs`（はじめに・使用方法・リファレンス）が出て、各タブが分類のトップページ（`docs/guide/はじめに.md` などの `permalink`）を開く
  - `pages:` の対応表のページを開くと、対応するタブが選ばれる
  - `assets/` の CSS・スクリプト・`search.json`・`llms.txt` が `/mdmark/` の下の今までと同じ URL で出る

AI Monitor の develop にはバージョンのタグが無いため、取り込みは `python -m ai_monitor.distribution import-site` ではなく、develop の `docs/_theme/` を除外のとおりに写して行う。

上タブには、取り込んだ共通の `nav.yml` の「使い方」（AI Monitor の公開サイトへの外部リンク）と mdmark の「使用方法」が並ぶ。配布先で共通のタブを出さない設定は AI Monitor へ起票し（shuhei1101/ai-monitor#3410）、修正されるまでは両方のタブを並べる（[確認ログ](./確認ログ.yaml)）。
