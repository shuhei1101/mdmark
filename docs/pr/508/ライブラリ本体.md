### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図の移動 | 図をタップした後は、指のドラッグで図を横にも縦にも動かす。タップする前の縦のドラッグは文書のスクロールにする | 図の外のタップで解く |
| ズーム | ピンチとボタンのズームは今のまま | - |
| 今の図 | 図の枠は共通の部品のため、図の枠に描く全ての図に当てる | - |
| 中断 | `pointercancel` でドラッグを終え、動かした分を戻す（`src/map/drag.ts` のノード・線、`src/map/flow-view.ts` の保存、`src/map/sequence-view.ts` の参加者の並べ替え） | 操作中でない間の指の縦のドラッグをブラウザが文書のスクロールに切り替えると `pointercancel` が出るため |

### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 検出 | 言語が `tree` でない fence のコードブロックに、行頭（インデントの後）の罫線（`├── `・`└── `・`\|-- `・`` `-- ``）の行が 2 行以上あれば警告する | 言語 `tree` と、`mermaid`・`html` などマーカーが読むコードブロックは対象外 |
| 警告の文 | モック（`docs/mock/components/tree-lines-warning/`）の文言にする | ユーザーが合意（確認ログ）。画面設計の `error_message` に記載する |
| 止める指定 | コードブロックの直前の `code` のマーカーのキー `tree_warning` を `false` にして止める | ユーザーが合意（確認ログ）。`schemas/marks/code.schema.json` にキーを足す（マーカーの Schema は `scripts/migrations.ts` の `CHECKED_SCHEMAS` に無く、`migrations/no-steps.yaml` の行は要らない） |
| 点検 | `check` の `--text`・`--file` と MCP の `check` が、描いたときと同じ警告を `syntax_warning` で返す | 新しいずれの種類は作らない（IF-472-39 は変えない） |
