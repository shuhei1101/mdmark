### 参加者の表示と非表示（#404 の残り）

読者が map のシーケンス図の参加者を非表示にでき、非表示にした参加者だけに関わるメッセージを隠す（表の列の表示と非表示と同じ考え方）。
非表示にした参加者を表示に戻せ、「参加者の並び順と選択を元に戻す」で全て表示に戻る。

`未確定`: 非表示にする操作の置き場所（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 図の右上のボタンで参加者の一覧を開き、チェックで表示と非表示を切り替える |
| B | 参加者の箱のメニューから非表示にし、非表示の参加者を図の端の一覧から戻す |

推奨: A

表の列の表示と非表示と同じ操作で、非表示にした参加者も一覧から戻せるため。

### タッチでのドラッグ（#357）

スマホの指で図をタップしてから図の枠をドラッグすると、横にも縦にも図が動く。
タップする前の縦のドラッグは文書のスクロールにし、図の外をタップすると解ける。
図の枠は共通の部品のため、今の flow・sequence・mermaid の図にも当たる。
ズームの操作は今のままにする。

### 罫線のコードブロックの警告（#466）

言語が `tree` でないコードブロック（言語なし・`text`・`plaintext` など）に罫線の行（`├── `・`└── `・`|-- `）が 2 行以上あるとき、描いた文書（`export_html` の書き出しを含む）と、`check` の `--text`・`--file`（MCP の `check`）に、言語を `tree` にするよう案内する警告を出す。
罫線の例をそのまま見せたいコードブロックには、警告を止める指定を用意する（指定の形はインターフェース定義設計で決める）。

### ガイドの索引からの動線（#466）

ガイドのページの description（`docs/guide/files.yml`）と `guide/index.yaml` の `components` の `when` に、フォルダ構成・ファイルツリーを記載するときを追加し、フォルダ構成を記載しようとした Claude Code が dev-docs のガイドの検索で『本文を部品で組む』に行き着く。
SessionStart の案内は変えない（dev-docs の instructions がガイドの検索へ導き、記載した後の点検で警告が出るため）。
