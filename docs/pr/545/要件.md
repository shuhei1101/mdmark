# 要件

## 要望

`tests/integration/lib/build.test.ts` の `test_normal` で、作業ツリーへコピーする移行の手順のフォルダを、リポジトリの `migrations/` の下で `marker-json.mjs` を持つフォルダ（`tests/migrations-dir.ts` の `migrationsDirOf("marker-json.mjs")`）から取る。
コピー先は作業ツリーの `migrations/next` のまま保つ。
`migrations/next` があってもバージョンのフォルダへ移した後でも、`npm run test:integration` で `test_normal` が pass する。
