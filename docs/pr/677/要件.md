### 要件

- map の `C4Dynamic` の図では、番号つきの関係を番号の順に 1 本ずつ手順にした再生の帯を図の枠の下に出す。手順のバーの区切りか左右の矢印を押すと、その関係へ移って停止するまで繰り返し再生する
- 再生している手順では、その関係の線と両端の要素のほかを薄くし、その線にデータのマーカーを流す。手順のタイトルは番号と両端の要素の名前と関係のラベル、説明の文は補足の `notes` のその関係の説明にする
- 帯の操作（区切り・左右の矢印・キー・停止・強調する要素へのなめらかな移動）は、シーケンス図・状態遷移図の再生の帯と同じにする
- 見た目は DynamicArchitectViewer に合わせず、モックで決める
- `C4Dynamic` 以外の図の種類の描画は変えない
- 補足に案内の手順（`walkthroughs`）を記載した `C4Dynamic` では、状態遷移図と同じく帯が案内の手順を進め、関係の再生は出さない
