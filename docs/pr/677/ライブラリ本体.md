## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| C4Dynamic の再生の手順 | `C4Dynamic` の関係を番号の順に手順にして、状態遷移図と同じく構成図の帯（`attachMapFlow` の `walkthroughs`・`bandMode: playback`）へ指定する。手順ごとに関係の線と両端の要素を強調し、その線にデータのマーカーを流す | 補足に案内の手順があるときは、状態遷移図と同じく案内を進め、関係の再生は出さない |
| 既存の図への影響 | `C4Dynamic` 以外の C4 の種類・他の図の種類の描画と操作は変えない | - |
