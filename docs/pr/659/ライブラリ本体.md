## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 指 1 本の移動 | 全体が収まる倍率より拡大している図では、表示する枠の上の指 1 本の縦横のドラッグを図の移動にし、ページをスクロールしない。全体が収まる倍率の図では、縦のドラッグをページのスクロールにする | 図の端に達した後も同じ向きへ続けた指のドラッグは、文書のスクロールにする |
| ピンチ | 図の上の 2 本の指の間隔の変化を、2 本の指の中点を保った倍率の変更にする。倍率は全体が収まる倍率から上限（`ZOOM.max`）の間に収め、ブラウザのページの拡大を止める | ボタン・キーと同じ倍率の範囲 |
| 操作中のマーカー | 余白のタップで縦に動かせるようにする `data-touch-active` は、拡大の状態で切り替える方式へ置き換え、要らなくなれば削除する | 設計で決める |
| ボタンのパネル | 拡大・縮小・倍率・全画面（と移動）のボタンを、表示する枠の上の別の行から、表示する枠の右上に重ねる角の丸い小さいパネルへ移す。大きさ・配色はモックで決める | map の図のボタンのまとまり（`data-group="map"`）も同じパネルに含める |
| アクセシビリティ | パネルのボタンは `role="toolbar"` とスクリーンリーダー向けの名前、キーボードの操作を今のまま保つ。指で押せる大きさを守る | - |
| 既存機能への影響 | マウスのドラッグ・ホイール（文書のスクロール）・キー・リサイズハンドル・全画面のモーダル・ツールチップのタップ・map の参加者の箱のドラッグを壊さない | 回帰を結合テストで確認する |
| 公開ドキュメント | 『図を描く』『構成図の決まり』『mermaidの図を描く』『コードブロックのHTMLを描く』『API』『用語集』の記載を、パネルと指の操作に合わせる | 更新ドキュメントの表 |
