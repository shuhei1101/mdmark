# スマホで拡大した図を指で縦横に動かし、ピンチで拡大・縮小し、拡大・縮小・全画面のボタンを図に重ねるパネルにする

## 概要

スマホの読者が、拡大した図を指 1 本で縦にも横にも動かし、ピンチで図を拡大・縮小できるようになる。
拡大・縮小・全画面のボタンを、図に重ねる小さいパネルにする。

## 背景

[Issue #602](https://github.com/shuhei1101/mdmark/issues/602) の要望。
スマホのエミュレーション（Pixel 7）で、拡大した図の指 1 本の縦のドラッグがページと図の両方を動かし、ピンチはブラウザがページ全体を拡大して図の倍率が変わらない。
縦に動かすには、先に図の余白をタップして操作中（`data-touch-active`）にする必要がある。

今の動作は [Issue #464](https://github.com/shuhei1101/mdmark/issues/464)（作業 PR [#508](https://github.com/shuhei1101/mdmark/pull/508)）で入った。
拡大・縮小・全画面のボタンは図の上に図と別の行として配置しており、利用者は図の中に重ねる配置を望んでいる。
