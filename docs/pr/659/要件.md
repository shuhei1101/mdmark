# 要件

## 要望

| 要件 | 終了の条件 |
| --- | --- |
| 拡大した図を指 1 本で動かす | スマホで、全体が収まる倍率より拡大した図の上の指 1 本のドラッグで、図が縦にも横にも動き、ページはスクロールしない。余白を先にタップしなくても動く |
| 全体が収まっている図の上でページをスクロールする | 全体が収まる倍率の図の上の指 1 本の縦のドラッグで、ページがスクロールし、図は動かない |
| ピンチで図を拡大・縮小する | 図の上のピンチで図の倍率が変わり、ブラウザがページ全体を拡大しない。倍率は全体が収まる倍率と上限の間に収まる |
| ボタンを図に重ねる | 拡大・縮小・全画面のボタンを、図の上の別の行ではなく、図に重ねる小さいパネルに配置する。見た目は DynamicArchitectViewer に合わせず、モックで決める |

拡大した図の端まで動かした後も同じ向きへ続けた指のドラッグは、文書のスクロールにする（単一ユースケース設計で決めた）。
