# 要件

## 要望

| 要件 | 終了の条件 |
| --- | --- |
| 拡大した図を指 1 本で動かす | スマホで、開いたときの倍率より拡大した図の上の指 1 本のドラッグで、図が縦にも横にも動き、ページはスクロールしない。余白を先にタップしなくても動く |
| 開いたときの倍率の図の上でページをスクロールする | 開いたときの倍率の図の上の指 1 本の縦のドラッグで、ページがスクロールし、図は縦に動かない。横のドラッグでは、枠に収まらない分だけ図が横に動く |
| ピンチで図を拡大・縮小する | 図の上のピンチで図の倍率が変わり、ブラウザがページ全体を拡大しない。倍率は開いたときの倍率を 100% として 25%〜500% の間に収まる（ユーザーの決定。[確認ログ](./確認ログ.yaml)）。図の外の段落の上のピンチでは、ブラウザがページ全体を拡大する |
| ライトボックスの画像もピンチで拡大・縮小する | ライトボックスの画像の上のピンチで、図と同じ倍率の範囲で倍率が変わる。上のバーから移動のボタンを削除し、スマホの幅で拡大しても上のバーを 1 行のままにする（ユーザーの決定。[確認ログ](./確認ログ.yaml)） |
| ボタンを図に重ねる | 拡大・縮小・全画面のボタンを、図の上の別の行ではなく、図の右上に重ねる小さいパネルに配置する。パネルは倍率の表示と開くボタンだけに畳んで開き、開くと拡大・縮小・全画面のボタンを並べる。図を動かす矢印のボタンは削除する（ユーザーの決定。[確認ログ](./確認ログ.yaml)）。見た目は DynamicArchitectViewer に合わせず、モックで決めた |

Issue の「全体が収まる倍率」は「開いたときの倍率」に言い換えた。map の図は開いたとき等倍で全体が枠に収まらないことがあり、図の種類によらず同じ条件にするため。

指を離さずに拡大した図の端を越えて続けたドラッグは、端を越えた分だけ文書のスクロールにする（単一ユースケース設計で決めた）。
