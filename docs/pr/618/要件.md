# 要件

## 要望

部品にしない Mermaid の図を `securityLevel: "strict"` のまま（Mermaid にスクリプトを動かさせずに）描き、描いた後に mdmark がソースの `click` の行を読んで、URL を指すノードをリンクにする。

| 入力（Mermaid のコードブロックの行） | 描いた後 |
| --- | --- |
| `click {ノード} href "{URL}"` | そのノードを `href` が `{URL}` の `<a>` で囲む |
| `click {ノード} "{URL}"` | `href` の形と同じ |
| `click {ノード} href "{URL}" _blank` など、後ろに target・ツールチップの値を持つ行 | `href` の形と同じ（後ろの値は読んで捨てる） |
| `click {ノード} call {関数}()`・`click {ノード} {関数}` などのコールバック | 今と同じく何もしない |

- 対象の種類は `click` を書ける `flowchart`（`graph` を含む）と `classDiagram`
- `{URL}` は書かれた文字列のまま `href` に入れる（相対パス・`#` のアンカー付きのパスを含む）。許すスキームは、map のノードのリンクと同じく、インターフェース定義『文書をHTML文字列にする』の制約「URL のスキーム」の許可（`http`・`https`・`mailto` と相対 URL）とし、`javascript:` などはリンクにしない
- ノードの `<a>` は本文のリンクと同じく同じタブで開き、クリックのイベントは本文の要素まで伝わる（dev-docs は本文の `a[href]` のクリックを拾って画面の中で文書を開く）
- `mermaid.initialize` の `securityLevel: "strict"` は変えない。公開関数・設定も変えない
- ノードのリンクの見た目とキーボードでのフォーカスは、map のノードのリンク（部品設計『mapの構成図』の `mdmark-diagram-node-link`）に揃える

終わりの条件: `flowchart`・`classDiagram` の `click` の URL の行のノードが、書いた URL の `<a>` の中にあり、押すと本文のリンクと同じくその URL を開く。
スクリプトの URL とコールバックの `click` の行のノードはリンクにならない。
