## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `click` の行の読み取り | ソースの `click {ノード} [href] "{URL}" ...` の行からノードの ID と URL を読む。コールバックの形（`call`・関数名）は読んで捨てる | DOM を使用しない処理として `mermaid-source.ts` 側に置く |
| URL の許可 | 制約「URL のスキーム」と同じ許可（`http`・`https`・`mailto` と相対 URL）で確認し、許さない URL のノードはリンクにしない | map のノードのリンクと同じ判定を使う |
| ノードの特定 | 描いた SVG で、描画の ID と種類の接頭辞（`flowchart-`・`classId-`）とノードの ID から `id` が `{描画の ID}-{接頭辞}-{ノードの ID}-{連番}` の `g.node` を引く | 画面用と印刷用の SVG の両方に当てる |
| ノードのリンク | 引いたノードを `<a class="mdmark-diagram-node-link" href="{URL}">` で囲む。`target` は付けず同じタブで開き、クリックのイベントを止めない | 見た目とフォーカスは map のノードのリンクに揃える |
| `securityLevel` | `strict` のまま変えない | - |
| アクセシビリティ | リンクは Tab でフォーカスでき、Enter で開く。スクリーンリーダー向けの名前はノードの名前 | - |
| セキュリティ | Mermaid にスクリプトを動かさせない。`javascript:` などの URL はリンクにしない | - |
| 既存機能への影響 | `click` を持たない図と、map の構成図の描き方は変わらない | - |
