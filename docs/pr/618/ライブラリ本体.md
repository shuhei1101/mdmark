### strict での Mermaid のリンクの出力（実測）

mermaid 12.3.0 を `securityLevel: "strict"` で初期化し、Playwright の Chromium で `mermaid.render` にかけた SVG の `<a>` を記録した（2026-11-16）。

| 図 | 行 | 出力された `<a>` |
| --- | --- | --- |
| flowchart | `click A href "./a.md"` | `<a xlink:href="./a.md">` |
| flowchart | `click B "../b.md#c"` | `<a xlink:href="../b.md#c">` |
| flowchart | `click C href "https://example.com/" _blank` | `<a xlink:href="https://example.com/">`（`target` 無し） |
| flowchart | `click A href "./設計/a b.md#見出し"`・`"mailto:x@example.com"`・`"?rev=x&base=y" "ツールチップ" _self` | 記載した文字のままの `xlink:href`（`&` は `&amp;`）。`target` と `<title>` 無し |
| flowchart | `click D href "javascript:alert(1)"`・`click D href "data:text/html,x"` | `xlink:href` も `href` も持たない `<a>` |
| flowchart | `click E call show()` | `<a>` 無し |
| classDiagram | `click A href "./a.md"`・`link B "../b.md#c"`・`click C href "https://example.com/" _blank` | flowchart と同じ |
| classDiagram | `click D href "javascript:alert(1)"` | `xlink:href` も `href` も持たない `<a>` |
| classDiagram | `click A "./a.md"` | 解釈できないエラー（`Parse error on line 3`） |

Mermaid は URL のノードを `xlink:href` だけを持つ `<a>` で囲み、`href` 属性を持たない。`target` は DOMPurify が外す。
mdmark の `finishSvg` はこの `<a>` をそのまま残している。

## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| Mermaid のリンクの読み取り | ソースの `click` の行は読まず、Mermaid が出力した SVG の `<a>` の `xlink:href` を読む | Mermaid が `click`・`link` の文法を解釈し、コールバックの行には `<a>` を出力しない |
| URL の許可 | `xlink:href` を制約「URL のスキーム」と同じ許可（`http`・`https`・`mailto` と相対 URL）で確認する | map のノードのリンクと同じ判定を使う |
| ノードのリンク | 許可する `<a>` に `xlink:href` と同じ値の `href` と `class="mdmark-diagram-node-link"` を付け、`target` を外す。`xlink:href` を持たない `<a>` と許可しない `<a>` は、子を残して `<a>` だけを外す。クリックのイベントは止めない | 画面用と印刷用の SVG の両方に当てる（`finishSvg`）。見た目とフォーカスは map のノードのリンクに揃える |
| `securityLevel` | `strict` のまま変えない | - |
| アクセシビリティ | リンクは Tab でフォーカスでき、Enter で開く。スクリーンリーダー向けの名前はノードの名前 | - |
| セキュリティ | Mermaid にスクリプトを動かさせない。`javascript:` などの URL はリンクにしない | - |
| 既存機能への影響 | `click` を持たない図と、map の構成図の描き方は変わらない | - |
