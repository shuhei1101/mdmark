# 要件

## 要望

- 利用側のページが `dist/index.js` を 1 枚の HTML に埋めて読み込むときに、mermaid のモジュールも埋めて mdmark に指定できる公開の手段を用意する
- 指定したときは、mermaid で描くコードブロックがあっても設定の `mermaid.url` へ要求せず、指定したモジュールで図を描く
- 指定しないときは、今と同じく `mermaid.url` から読み込む。書き出した HTML の起動の処理（`setEmbeddedMermaid` で指定する）の描き方は変えない
- 指定したモジュールの構造の確認（既定の export が `initialize` と `render` を持つか）は、`mermaid.url` から読み込むときと同じにする
- 手段は、#655 の部品の読み込みの手段（`setPartModuleLoader`。部品を初めて使用するときに 1 回だけ呼ぶ関数を指定する）に合わせる

公開の手段は、`setPartModuleLoader` の名前に `"mermaid"` を追加し、mermaid のモジュールを返却する関数を指定する（インターフェース定義『部品のモジュールを指定する』）。
mermaid で描くコードブロックがある文書でだけ関数を呼ぶため、mermaid を使用しない文書では読み込まない。
