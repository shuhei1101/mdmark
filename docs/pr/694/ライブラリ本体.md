## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| mermaid を指定する手段 | 公開関数 `setPartModuleLoader` の名前に `"mermaid"` を追加し、利用側が mermaid のモジュールを返却する関数を指定する | インターフェース定義『部品のモジュールを指定する』 |
| 読み込み先の優先 | 利用側の指定 → 書き出した HTML の起動の指定（`setEmbeddedMermaid`）→ `mermaid.url` の順にする | 書き出した HTML は利用側の手段を呼ばないため、今の描き方は変わらない |
| 構造の確認と失敗 | 指定した関数が reject するか、既定の export が `initialize`・`render` を持たないときは、`mermaid.url` から読み込めないときと同じく `console.error` に出し、コードブロックのまま描いてほかの描画を続ける | `mermaid.url` へは要求し直さない |
| 呼ぶ時期 | mermaid で描くコードブロックがある文書を `mount` する前に指定する。読み込んだ後の指定は、読み込み済みのモジュールを使用し続ける | 部品の指定と同じ |
| 埋める mermaid | 利用側は mermaid を自分のビルドで 1 つのモジュールにして埋める。jsDelivr の `mermaid.esm.min.mjs` は分割したファイルを読み込むため、そのままでは埋められない旨をガイドに記載する | 書き出した HTML は esbuild でまとめている |
| 配布ファイルのサイズ | `dist/index.js` に mermaid を含めない | 非機能要件『配布ファイル 1 つのサイズ』 |
