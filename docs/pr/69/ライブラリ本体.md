## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 元の行番号の属性 | 本文のブロック（段落・見出し・リスト・表・コードブロック・引用・印の範囲）の要素に、Markdown の元の行番号（0 始まりか 1 始まりかはインターフェース定義で決める）の属性を出し、sanitize で許す | 属性名は `未確定`（要件.md）。[PR #65](https://github.com/shuhei1101/mdmark/pull/65) がコードブロックの行に `data-line` を足しているため、先にマージされた側に合わせて取り込む |
| ダークの配色 | 描く先の要素の祖先に決めた class（`vscode-dark`・`vscode-high-contrast` など）があるときもダークの配色の値を当て、`vscode-light` などのライトの class があるときは OS の設定がダークでもライトの配色にする | 印刷では今と同じく明るい配色のままにする。class の名前と優先順はインターフェース定義で決める |
| `libraries` の基準 | 要件.md の推奨案 B では変えない | 案 A に決まったときだけ、`mount` に基準を渡す口を足す |
| 使い方の文書 | Webview に組み込むときの CSP（jsDelivr の `script-src`・`style-src`、`libraries` の配信元）と、Webview の中では `print()` が効かないことを書く | - |
| 既存機能への影響 | 描いた HTML のブロックに属性が増えるだけで、今の使い方の見た目は変わらない | 移行の手順は要らない（設定・索引の Schema を変えない） |
