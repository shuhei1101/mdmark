## 要望

VS Code 拡張機能の結合テスト（`xvfb-run -a npm --prefix vscode run test:integration`）で、次の 2 件が VS Code 1.141.0 と stable の両方で pass する。

| テスト | 今の fail |
| --- | --- |
| `vscode/tests/integration/export.test.ts` の `test_normal_when_relative_mermaid` | 相対パスの `mermaid.url`（`./libs/mermaid/mermaid.esm.min.mjs`）で書き出した HTML の `config.mermaid.url` が `data:text/javascript` で始まらない |
| `vscode/tests/integration/preview-open.test.ts` の `test_normal_when_mermaid` | プレビューで mermaid の図を 60 秒以内に描かない（`Error: mermaid の図を描かない`） |

- 原因を特定し、インターフェース定義（[IF-472-15](https://github.com/shuhei1101/mdmark/blob/develop/docs/interface/IF-472-15.ts.yaml)・[IF-472-22](https://github.com/shuhei1101/mdmark/blob/develop/docs/interface/IF-472-22.ts.yaml)）のケースの期待と照らして、テストと実装のどちらが誤っているかを決めてから、誤っている側を修正する
- テストの期待を変える場合は、インターフェース定義のケースも書き換える。実装を変える場合は、モジュール構成（[MOD-472-102](https://github.com/shuhei1101/mdmark/blob/develop/docs/module/MOD-472-102.ts.yaml) など）も合わせる
- 他の結合テストの結果（Issue の時点で 81 件 pass）を悪化させない
