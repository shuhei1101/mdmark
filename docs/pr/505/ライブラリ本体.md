### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 判定の順 | 読者が変えた幅 → `width.mode` が `nowrap` → `width.min`・`width.max` の記載 → 長文の列か（1 行の文字数）→ 全ての列の最小の幅の合計が見える幅に収まるか → 長文の列が折り返さずに収まるか、の順で列ごとに判定する（[ユーザーの追加の指示](https://github.com/shuhei1101/mdmark/pull/505#discussion_r4554479222)） | 判定フローチャートを部品設計『表』に配置する |
| 最長の行の幅 | 見出しと全てのセルを改行（`<br>`・リストの項目・段落）で行に分け、最も長い行の表示の幅を取る | 測り方（文字数から算出するか、描いた要素を測るか）は部品設計で決める |
| 最小の幅・最大の幅 | 長文の列の最小の幅は決めた値（モックは 20em）、ほかの列は最も長い行の幅。最大の幅は持たず、長文の列は本文の幅いっぱいまで広げる。`width.min`・`width.max`（em）があればその値 | 長文の列とみなす文字数と最小の幅は部品設計で決める（モックは 20 文字・20em） |
| 表の幅 | 長文の列が折り返す表は本文の幅いっぱいまで広げる。全ての列が折り返さずに収まる表は列の幅の合計で描き、本文の幅まで広げない | 「常に最大の幅」は #168 の本文の幅に広げる描き方で起きる（[要件](./要件.md)） |
| 見える幅が狭いとき | 全ての列の最小の幅の合計が見える幅を超えたら、最小の幅で描いて表を横にスクロールする | 表ごとの切り替えのキーは追加しない |
| 狭い幅で最終列を畳む描き方 | 削除する（[ユーザーの回答](https://github.com/shuhei1101/mdmark/pull/505#discussion_r4555812978)の案 A）。部品設計『表』（CMP-472-61）・CMP-472-60・画面設計『文書』（SCR-472-4）・インターフェース定義『文書を描く』（IF-472-35）に残る畳む描き方は、それぞれの設計の工程で削除する | - |
| 計算し直す時期 | 表を描いた直後と、表の見える幅が変わったときだけ。絞り込み・並べ替え・列の表示の切り替えでは変えない | 行の数が多い表は、測る行の数を限る |
| 列の幅のつまみ | 読者が変えた幅を自動の幅より優先し、描いた直後の幅に戻すと自動の幅に戻る | つまみで狭められる下限（今の 6em）を自動の最小の幅と分けるかはモジュール構成設計で決める |
| 印刷 | 印刷では自動の幅を適用しない（今の印刷の描き方のまま） | 文書を印刷する（SC-472-58）を実行して確認する |
