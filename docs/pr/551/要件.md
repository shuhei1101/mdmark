## 要望

直下の配信元の設定 `dev-docs.yaml`（`project-index.yaml` へ移った後はそちら）に、使用する場面の行の並び `when` を記載する。

| 項目 | 内容 |
| --- | --- |
| 1 行目 | 最もよく使用する場面: mdmark の記法・部品・図の描き方を確認するとき（文書の MCP の instructions に表示される） |
| 2 行目以降 | 配信元が持つ他の文書を検索する場面（CLI・設定・索引のキーの確認、ライブラリ・CLI・VS Code 拡張機能の設計書・コード・テストの調査） |
| 検証 | project-index の develop の配信元の設定のスキーマ（`schemas/project-index.schema.json`）に通る |
