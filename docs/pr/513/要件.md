# 要件

## 要望

develop から、今ある E2E のテストと、E2E だけが使用する部品を削除する。

- `tests/e2e/` を削除する
- E2E だけが使用する設定・依存・コマンドを削除する: `playwright.config.ts`、`package.json` の `test:e2e` と `@playwright/test`、`tsconfig.json` の include の `playwright.config.ts`、`.gitignore`・`biome.json` の `test-results`・`playwright-report`
- 管理用の YAML `tests/files.yaml` から `tests/e2e/` の行を削除する
- 設計書・ドキュメントのうち、削除した E2E のファイル・コマンド・依存を指す記述を削除する（テスト実行方法の E2E テスト、開発コマンドの Firefox の取得、外部ライブラリ『playwright』『vitest』、モジュール構成の `tests/e2e/vscode.ts`、公開ドキュメント『図を描く-見本』の「E2E が開く文書」）
- 結合テストも使用する `playwright`・`@vitest/browser-playwright` と、設計書のシナリオ（`test_file` を含む）は残す
- 単体テストと結合テストが全て pass し、lint・型検査が通ることを確かめる

E2E を手段として挙げる記述のうち、シナリオから E2E を作り直すときにも成り立つもの（シナリオの説明「E2E テストの元」、非機能要件の測定方法、アーキテクチャ図の `tests/` の説明、スキーマの E2E の型）は残す。
