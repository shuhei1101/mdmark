# 要件

## 要望

- map の範囲の Mermaid の 1 行目が `classDiagram`・`architecture-beta`・`C4Context` のとき、コードブロックのまま表示せず、今の入れ子の自動配置で描く
- マーカー（`map`）・Mermaid のブロック・補足（`notes`・`layout`・巡回）の記載方法と、拡大と縮小・凡例・ツールチップ・中へ入る・開閉・巡回・ノードと線を動かす操作は、flowchart・sequenceDiagram・erDiagram・stateDiagram-v2 と同じにする。種類ごとに追加するのは、読み取り・描画・種類に固有の機能だけにする
- 項目（クラス・メンバー・関係・service・線・要素・境界）を補足の `notes` で説明でき、入れ子（namespace・group・境界）は開閉と中へ入るができる。クラスはメンバーを開閉できる
- 項目を選ぶと、関わる項目とつながりだけを強調する。2 つ選ぶと、つなぐ最短の経路だけを残す
- 読めない行は、ほかの種類と同じく描画を止めずに書き方の警告にし、補足が指す無い項目は点検のずれにする
- 描けない種類の案内の文言（描ける種類の一覧）を、追加した種類に合わせる
- 既存の flowchart・sequenceDiagram・erDiagram・stateDiagram-v2・ER 図の部品・map の範囲外の mermaid のコードブロックの記載方法と描画は変えない

mindmap（木の配置）・gantt / timeline / gitGraph / journey（軸に沿った配置と再生）・block-beta（格子の配置）は、新しい配置の処理ごとに子の Issue へ切り出した（スコープ外）。
