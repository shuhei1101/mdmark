# 要件

## 要望

map の範囲と言語 `mermaid` のコードブロックの `classDiagram` を、次の条件を満たすクラス図で描く。

終わりの条件:

- 関係のラベルが、どのクラス（名前の行・種類の行・メンバーの行）・ノート・namespace のタイトルとも重ならない
- メンバーの行が 1 行に収まらず折り返したとき、そのクラスのノードの高さが折り返した行の数だけ増え、次の行と重ならない
- クラスの名前・メンバーの文字がノードの幅に収まらないとき、図の中身の幅がクラスを含む大きさになり、図の枠の右端でクラスが切れない（図の枠は横にスクロールできる）
- 補足の `layout` の `{クラス名}.width` が、そのクラスのノードの幅になる
- メンバーの型の `~T~`（`tuple~int, int~`・`dict~str, str~`・入れ子の `list~dict~str, int~~`）が `<T>` で描かれる
- Issue の再現（observability の `docs/module/MOD-49-1.yaml` の `diagrams[0].diagram`）を 1280 幅で描いて、上の条件を満たす
