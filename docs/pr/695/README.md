# map のクラス図で、線のラベル・折り返したメンバーの行・図の幅からはみ出るクラスの重なりを修正し、メンバーの型の ~T~ を <T> で描く

## 概要

文書の作成者が map の範囲に `classDiagram` を記載すると、関係のラベル・メンバーの行・クラスが互いに重ならず図の幅に収まったクラス図になり、メンバーの型の `~T~` が `<T>` で描かれる。

## 背景

[Issue #622](https://github.com/shuhei1101/mdmark/issues/622) の要望。[#596](https://github.com/shuhei1101/mdmark/pull/596)（map で classDiagram を描く）の後、[shuhei1101/observability#88](https://github.com/shuhei1101/observability/pull/88) でモジュール構成のクラス図を map で描くと、関係のラベルがクラス名に重なり、折り返したメンバーの行が次の行に重なり、図の幅に収まらないクラスが右端で切れ、メンバーの型の `~T~` が `<T>` にならない。補足の `layout` の `width` を付けてもクラスの幅は変わらない。observability#88 はこの修正を待ってからマージする。
