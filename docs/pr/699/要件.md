# 要件

## 要望

mdmark のマーケットプレイスに、Claude Code の画面を mdmark の共通スタイルで描く mod の単独のプラグイン `mdmark-style` を配置する。

| 要件 | 終了の条件 |
| --- | --- |
| 返答の描き換え | アシスタントの返答の表は Box の罫線と列の幅、注意書きは左の縦線と色と先頭のラベル、見出しは太字と色、コード・差分は Code 部品で描く。図（mermaid・map）と埋め込んだ HTML は描かない |
| 狭い画面の表 | デスクトップ版は表を横にスクロールさせ、ターミナル版・VS Code はセルの中で折り返して端末の幅に収める |
| コードブロックの飾り | コードブロックを背景の面と言語のラベルで本文と分け、マーカー `<!-- code: ... -->` のタイトル・行番号・行の強調と、行末の `[!code ++]` などの行の色、コピーの Button を描く。行の畳みは描かない |
| 開閉の範囲 | details の範囲・セクションの開閉・注意書きの `closed` を、押すと開閉する Button（`[ ▸ タイトル ]`）で描く |
| マーカーを画面に出さない | 返答に記載された mdmark のマーカー（`<!-- table: ... -->` など）を描き方に使用し、マーカーの文字は画面に出さない |
| マーカーの記載方法の注入 | SessionStart で、マーカーの記載方法の短い説明を 1 セッションに 1 回だけ注入する。`/clear`・圧縮の後の SessionStart でも、消えた説明を 1 回注入し直す |
| 用語のマーカー | 利用者の発言とアシスタントの返答に出た用語・エイリアスに下線を付け、ポインターを乗せると開くカードと、マウスを使えないときのための脚注を出す。用語は設定 `glossary` が指す `mdmark.config.yaml` の索引・aliases・用語集の表から取り、YAML の文書・MCP は参照しない |
| 共通スタイルの共有 | 色・表の型・注意書きの種類の定義を TypeScript のモジュール 1 か所に配置し、Web の描画と mod の両方が参照する。Web の CSS 変数の名前と値は変えない |
| 設定 | `MDMARK_STYLE_CONFIG`（無ければ既定のパス `~/.config/mdmark-style/settings.yaml`、ファイルも無ければ既定値）の `global`・`projects` で、`enabled`・`parts.*`（table・heading・callout・code・fold・terms・hover_card・footnote）・`targets`（assistant・user）・`glossary`・`inject_marker_guide` を変えられる。サンプル `settings.sample.yaml` をプラグインの中に配置する |

`未確定`: hover で開くカードが有効な端末の範囲と、デスクトップ版・VS Code での HTML コメントの描き方（決める工程: PoC 検証）

| 案 | 内容 |
| --- | --- |
| A | ターミナル版（tmux）で `ui.render` による返答の描き換え・マーカーの削除・hover のカードを PoC で確認する。利用者の端末（WSL の Windows Terminal・VS Code の統合ターミナル）の hover と、デスクトップ版・VS Code の拡張機能の描き方は、利用者に手元で確認してもらい、確認できなかったものを未確認として外部ライブラリの設計書に記録する |
| B | ターミナル版・デスクトップ版・VS Code の 3 つを全て PoC で確認してから設計に入る |

推奨: A

手元で自動で起動して画面を読めるのはターミナル版で、描く部品の木は 3 つの画面で共通のため。

mdmark-style は、アーキテクチャ図のサブシステム「Claude Code プラグイン」に含め、サブシステムがプラグインを 2 つ持つ構造にする。
