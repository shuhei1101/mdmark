## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 共通スタイルの定義 | 色（明るい配色・暗い配色）・表の型・注意書きの種類を TypeScript のモジュールに配置し、Web の CSS と mod の両方がそこから参照する | 配置先と、CSS への渡し方（ビルドで CSS 変数を書き出すか）はモジュール構成設計で決める |
| Web の外観 | `--mdmark-` の CSS 変数の名前と値、選べるテーマの値を変えない | 破壊的変更にしない。SC-472-25・SC-472-64 の E2E で確認する |
| 用語の取り出し | `src/knowledge/` の用語の集め方と本文の照合を、DOM を使わずに mod から呼べる構造で公開する | 公開の範囲はインターフェース定義設計で決める。SC-472-65 の E2E で Web の振る舞いが変わらないことを確認する |
