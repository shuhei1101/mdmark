### 行の無いファイルの扱い

origin/develop の [8e05422c](https://github.com/shuhei1101/mdmark/commit/8e05422c) で、管理用の YAML ごとに行も除外も無いファイルを数えた。
`tests/files.yaml` の `e2e/` の分は、E2E のテストを削除した [#450](https://github.com/shuhei1101/mdmark/issues/450) で無くなった。
`scripts/files.yaml`・`docs/guide/files.yml` の分は、配信元の設定の `exclude`（`*.txt`・`README.md`・`index.yaml` ほか）で既に除外されている。

| 管理用の YAML | 行の無いファイル | 扱い |
| --- | --- | --- |
| `tests/files.yaml` | `integration/`・`unit/` のテストと補助のファイル 92 件 | 行を追加する |
| `tests/files.yaml` | `unit/helpers/media/short.webm` | 配信から除外する（バイナリ） |
| `docs/mock/files.yml` | `components/`・`pages/`・`refs/` の HTML・Markdown・CSS・JavaScript 19 件 | 行を追加する |
| `docs/mock/files.yml` | `refs/263/assets/media/` の画像・動画・音声 4 件 | 配信から除外する（バイナリ） |
| `plugin/files.yaml` | `bin/setup.js`・`scripts/session-start.js`・`scripts/guide-notice.js` | 配信から除外する（まとめた配布物）。除外済みの `pre-tool-use.js` と合わせて、フォルダの単位の除外にそろえる |
| `plugin/files.yaml` | `templates/mdmark.config.yaml` | 行を追加する |
| `vscode/files.yaml` | `package-lock.json` | 配信から除外する（lock ファイル） |

扱いは、[#483](https://github.com/shuhei1101/mdmark/pull/483) で決めた「`files.yaml` の行の対象を、生成物・lock ファイル・バイナリ以外とする」にそろえる。
行を持たせないファイルは、配信元の設定の `files` の行の `exclude` で除外する。
ライセンスのコピーは、`scripts/` の `*.txt` と `plugin/` の `THIRD_PARTY_LICENSES.txt` が既に除外されていて、扱いを変えない。
