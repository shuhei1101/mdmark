## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 種類の判定 | Mermaid の 1 行目の `erDiagram`・`stateDiagram-v2`・`stateDiagram` を map の種類にする | マーカーは map のまま（D-56） |
| 読み取り | erDiagram はテーブル・列（型・名前・キー・コメント）・関連（多重度・ラベル）を、stateDiagram-v2 は状態・遷移・開始と終了・入れ子の状態・注記を読む。読めない行は項目にして返す | flowchart・sequence の読み取りと同じ戻り値の形 |
| 共通の部分 | 補足の notes・layout・巡回、拡大と縮小・凡例・ツールチップ・中へ入る・開閉・選択の状態の保存を種類に依らない処理にし、種類ごとの描画から呼ぶ | 切り出しの範囲はモジュール構成設計で決める |
| 配置 | ER 図はテーブルを列の行を持つノード、状態遷移図は入れ子の状態をグループとして、今の入れ子の自動配置で配置する。ER 図の関連は FK の列（無ければ PK の列）の行の高さの辺から引く。状態遷移図の入れ子の状態への遷移は中の開始へ、入れ子の状態からの遷移は中の終了からつなぎ、中に `[*]` が無ければ開始・終了を補う。同じ状態への遷移は状態の辺から出て戻る線にする。`note` は点線でつないだ注記のノードにする | 開始と終了は小さい丸、分岐はひし形のノード |
| ER 図に固有の機能 | テーブルの列の開閉、補足の `groups` の分類の箱、テーブルを選ぶと関連するテーブルと関連だけを強調する、2 つのテーブルをつなぐ経路で 1 対多の関連に印を付ける | - |
| 状態遷移図に固有の機能 | 状態を選ぶと入る遷移と出る遷移だけを強調する。遷移を 1 歩ずつ進める再生を、シーケンス図の再生と同じ帯で行う | 再生の順は遷移の記載順。補足の `walkthroughs` があれば案内を優先する |
| 点検 | 補足が指すテーブル・列・状態・遷移の ID の照合を、今の書き方の警告と点検のずれに加える | - |
| 既存機能への影響 | flow・sequence・ER 図の部品・map の範囲の外の mermaid のコードブロックの記載方法と描画を変えない | 破壊的変更は付けない |
| アクセシビリティ | テーブル・状態・遷移の選択と再生を、今の map と同じキー操作で行う | - |
