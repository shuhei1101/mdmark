# 要件

## 要望

- map の範囲の Mermaid の 1 行目が `erDiagram`・`stateDiagram-v2`（`stateDiagram` を含む）のとき、コードブロックのまま表示せず、自動配置した図として描く
- マーカー（`map`）・Mermaid のブロック・補足（`notes`・`layout`・巡回）の記載方法と、拡大と縮小・凡例・ツールチップ・中へ入る・開閉・巡回の操作は、flowchart・sequenceDiagram と同じにする。種類ごとに追加するのは、読み取り・配置・種類に固有の機能だけにする
- ER 図
  - テーブルと列、関連と多重度を描き、テーブルの列を開閉する
  - 補足でテーブル・列・関連に説明を付ける
  - テーブルを選ぶと、関連するテーブルと関連だけを強調する
- 状態遷移図
  - 状態・遷移・開始と終了・入れ子の状態を描き、入れ子の状態を開閉し、中へ入る
  - 補足で状態・遷移に説明を付ける
  - 状態を選ぶと、入る遷移と出る遷移だけを強調する
  - 遷移を 1 歩ずつ進める再生を、シーケンス図の再生と同じ帯で行う
- 読めない行は、flowchart・sequenceDiagram と同じく描画を止めずに書き方の警告と点検のずれにする
- 描けない種類の案内の文言（描ける種類の一覧）を、追加した種類に合わせる
- 既存の flow・sequence・ER 図の部品・map の範囲の外の mermaid のコードブロックの記載方法と描画は変えない
