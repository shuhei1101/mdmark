# map の図の線の操作と表示を改善し（ドラッグ中のスクロール・ドラッグ後の経路・線の上の文字・データの印の動き）、フックの注入文をプロンプトファイルへ移す

## 概要

読者が map の図の線を、文書をスクロールさせずにドラッグでき、動かした後も自然な経路でたどれるようにする。
線の上の文字が線より長くても線の向きが見え、同じ長さの線が並んでもデータの印の動きが線ごとにずれるようにする。
あわせて、Claude Code プラグインのフックの注入文をプロンプトファイルへ移す。
