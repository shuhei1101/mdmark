# 音声の再生バーを見切れずに出し、コードブロックの折り返しを読者が切り替えられるようにし、表以外の部品のドラッグにドラッグしない操作を用意する

## 概要

読者が、埋め込んだ音声の再生バーの全体を見られ、コードブロックの折り返しを 1 回の操作で切り替えられ、表以外の部品のドラッグの操作をドラッグしないでも行えるようになる。

## 背景

[#819](https://github.com/shuhei1101/mdmark/issues/819) の束で、次の 3 件をまとめて扱う。

| Issue | 背景 |
| --- | --- |
| [#814](https://github.com/shuhei1101/mdmark/issues/814) | MindStella の資料の画面で、埋め込んだ音声の再生バーの下が見切れる。`src/index.css` の `.mdmark-media audio` は高さを指定していない |
| [#813](https://github.com/shuhei1101/mdmark/issues/813) | コードブロックの折り返しは記載する側がマーカーの `wrap` で決めるだけで（[#294](https://github.com/shuhei1101/mdmark/issues/294)）、読者は長い行を横にスクロールしながら参照する |
| [#815](https://github.com/shuhei1101/mdmark/issues/815) | 作業 PR [#811](https://github.com/shuhei1101/mdmark/pull/811) で表の列の並べ替えにドラッグしない操作を用意した。表以外の部品（map の図・差分のミニマップ・拡大した図 など）の代わりの操作の有無は調べていない |
