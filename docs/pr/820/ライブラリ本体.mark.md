## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 音声の再生バー | Storybook の『動画と音声』と MindStella の資料の画面で同じ音声を描いて原因を切り分け、mdmark 側なら `audio` か入れ物の高さ・`overflow` を修正する | MindStella 側が原因ならスコープ外の行のとおり MindStella へ起票する |
| 音声の既存の表示 | 動画・動画のリサイズハンドル・画像の図・再生のダイアログの外観と操作を変えない | 結合テストのストーリーで確認する |
| 折り返しのボタン | コードブロックとファイルツリーの帯の右端のコピーのボタンの前に、lucide の `wrap-text` のアイコンだけのトグルボタン（`aria-pressed`、スクリーンリーダー向けの名前とツールチップ `画面の端で折り返す`）を配置し、コピーのボタンも文言を出さずアイコンだけにする | IF-472-35 の制約『コードブロックとファイルツリーの折り返しの切り替え』『コードブロックのコピー』 |
| 折り返しの既定 | 描いた直後は、マーカーの `wrap` を持つブロックと、設定の `code.wrap` が `true` のときのマーカーの無いブロックを折り返して `aria-pressed` を `true` にし、押すたびに `mdmark-code-wrap`・`mdmark-tree-wrap` のクラスを付与・除外する | 状態は保存せず、`update` の再描画では保つ |
| 折り返しのキー操作 | ボタンは Tab で移り、Enter・Space で切り替える | - |
| ファイルツリー | 帯に折り返しのボタンを付け、折り返したときに注釈を持つフォルダの名前が 1 文字ずつ縦に折れる今の不具合（#822）をこの作業で修正する | 確認ログ『コードブロックの折り返しのボタンをファイルツリーの帯にも付けるか』 |
| 既定の折り返しの設定 | 設定に `code.wrap`（boolean、既定 `false`）を追加し、`schemas/mdmark.config.schema.json` に最上位の `code.wrap` を加え、`migrations/no-steps.yaml` に行を置く | 省いてよいキーの追加で、既存の設定を書き換える手順は要らない。CFG-472-3 の `code.wrap` |
| ドラッグの代わりの点検 | `src/` のドラッグの操作を部品ごとに洗い出し、ポインターで 1 回押す操作で同じことができるかを表にする | 表は部品設計に記載する |
| ドラッグの代わりの操作 | 代わりが無い操作に、#811 の列の並べ替えと同じく、ドラッグの持ち手を押して開くメニューに動かす向きの項目を並べる | 項目の文言と動かす量はモック作成で決める |
| 図の枠のリサイズハンドル | 動かさずに押すか Enter・Space で、動画のリサイズハンドルと同じ構造の大きさのメニュー（「低くする」「高くする」「全体が収まる高さにする」）を開く | IF-472-35 の制約『図の高さのリサイズハンドル』 |
| アクセシビリティ | 追加するボタン・メニューは、axe の検査で違反を出さず、押せる範囲を 24px 以上にする | WCAG 2.2 の 2.5.7・2.5.8 |
| 既存機能への影響 | ドラッグ・キーの操作は今のまま残し、代わりの操作だけを追加する | - |
