## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | 症状が出た資料（MindStella のワークスペースの `docs/A-65.mark.md`）を、mdmark の配布物だけを読み込んだページと MindStella のプレビューの両方で描き、表・タブとその前後のブロックの間と、表の下の線の位置を実測する | MindStella のプレビューだけで間が `--mdmark-space` 未満なら、上書きしている MindStella の CSS の規則を特定してスコープ外の Issue に記載する |
| 表・タブの前後の余白 | mdmark だけのページでも間が `--mdmark-space` 未満か下の線が見えない組み合わせがあれば、その組み合わせの規則を修正する | 余白の量は `未確定`（[要件](./要件.mark.md)） |
| 表の下の線 | 直後のブロックと重なって下の線（`box-shadow: inset 0 -1px`）が見えない場合は、線が見える描き方へ修正する | - |
| 結合テスト | 実際のブラウザで、表 → 段落・表 → 表・段落 → 表・タブ → 段落・タブ → 表・タブの中身の表 → 段落を並べて描き、前のブロックの下端と後のブロックの上端の差が決めた余白になることと、表の下の線が見えることを確認する | 既存の正常系「ブロックの間隔」に組み合わせを加える |
