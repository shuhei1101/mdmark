## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 原因の切り分け | 済み。mdmark だけで描くと表・タブの前後は 14px（`--mdmark-space`）で、0px になるのは MindStella が包む `div.md-section-body` の中だけ（[要件](./要件.mark.md) の `## 原因の切り分け`） | MindStella 側は [shuhei1101/mindstella#729](https://github.com/shuhei1101/mindstella/issues/729) |
| 表・タブの前後の余白 | `src/index.css` の規則と余白の量は変えない | - |
| 表の下の線 | 描き方は変えない | 直後のブロックとの間が `--mdmark-space` あれば線は直後のブロックに接しない |
| 結合テスト | 正常系「ブロックの間隔」の、見出しのセクションの中身（`.mdmark-section-body`）とタブの中身（`.mdmark-tab-panel`）の検査に、段落 → 表・表 → 段落・表 → 表の組を加え、どれも `--mdmark-space` になることを確認する | 本文の直下の組は既存の `SPACING_BLOCKS` の全ての組み合わせが表・タブを含めて測っているため加えない |
