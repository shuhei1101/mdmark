# 表とタブの前後に、ほかの要素と区別できる余白を取る

## 概要

文書の読者が、表とタブ（中に表を持つもの）を、表の下の文や続く表とくっつかずに区別して参照できるようにする。

## 背景

[表とタブの前後の余白が少なく、表の下の文や続く表が密着する](https://github.com/shuhei1101/mdmark/issues/825) の不具合。
MindStella のプレビューで、表の真下の文が表に詰まって見え、2 つ続く表が密着し、表の下の罫線が消えて見えることがある。
原因が mdmark の CSS か MindStella の画面の CSS かは切り分けていない。

develop の [src/index.css](https://github.com/shuhei1101/mdmark/blob/88bb645727253d7429c180afae3029c1a9286430/src/index.css) は、描く先の要素 `.mdmark` の `> * + *` でブロック同士に `--mdmark-space`（既定 14px）の間を付け、表の入れ物 `.mdmark-table` とタブの入れ物 `.mdmark-tabs` は自分の外側の余白を持たない。
表の下の線は枠ではなく `box-shadow: inset 0 -1px` で描いている。
同じ種類の不具合の [コードブロックとファイルツリーの前に、ほかのブロックと同じ間隔を空ける](https://github.com/shuhei1101/mdmark/pull/386) で、組み合わせごとの間を測る結合テストを入れている。
