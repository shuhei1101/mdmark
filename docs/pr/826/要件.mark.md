# 要件

## 要望

表と、タブ（中に表を持つものを含む）の前後に、ほかの要素と区別できる余白を取る。
次の 3 つの症状が、MindStella のプレビューと mdmark の配布物を読み込んだページの両方で起きないようにする。

| 症状 | 終了の条件 |
| --- | --- |
| 表の真下の文が表に詰まって見える | 表の下端と直後の段落の上端の間が、段落同士の間（`--mdmark-space`）以上ある |
| 表が 2 つ続くと密着する | 前の表の下端と後の表の上端の間が、段落同士の間（`--mdmark-space`）以上ある |
| 表の下の罫線が消えて見える | 表の最後の行の下の線が、直後のブロックと重ならずに見える |

タブの入れ物の前後と、タブの中身の中の表の前後も同じ条件にする。

原因が mdmark の CSS か MindStella の画面の CSS かを、インターフェース定義設計で切り分ける。
mdmark 側の原因は、この作業 PR で修正する。
MindStella の画面の CSS が mdmark の余白を上書きしている分は、MindStella の Issue に分ける（[スコープ外](./requirements.yaml)）。

マージの前に、話し合いのフォルダの依頼（MindStella のワークスペースのスレッド TH-163・会話ログ L-84）とずれていないか、要望の機能を落としていないかを突き合わせる。

## 原因の切り分け

2026-11-27 に、症状が出た資料（ワークスペース `299e2b07-63db-4f69-b593-c6ec6cf23ebb` の `docs/A-65.mark.md`）を 1280px 幅で描き、前のブロックの下端と後のブロックの上端の差を実測した。

| 描き方 | 段落 → 表 | 表 → 段落 | タブの中身の表 → 表 | map の図 → リスト |
| --- | --- | --- | --- | --- |
| MindStella のプレビュー | 0px | 0px | 14px | 0px |
| mdmark だけで書き出した HTML（`export_html`） | 14px | 14px | 14px | 14px |

MindStella は本文を見出しごとに独自の `div.md-section-body` で包む。
mdmark のブロック同士の間の規則は `.mdmark > * + *`・`.mdmark-section-body > * + *`・`.mdmark-tab-panel > * + *` の子だけに適用するため、`div.md-section-body` の中の子には届かず、表に限らず全てのブロックの間が 0px になる。
表の下の線が消えて見えるのは、直後の段落が間を空けずに線へ接するため。

mdmark 側は表・タブの前後に既に `--mdmark-space` の間を取っており、余白の量と CSS は変えない。
MindStella 側の修正は [shuhei1101/mindstella#729](https://github.com/shuhei1101/mindstella/issues/729) に分けた。
