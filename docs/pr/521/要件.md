# 要件

## 要望

`buildLegacyMarks` が移行の手順のフォルダへ書き込む `legacy-marks.js` にまとめた依存（パッケージの名前・バージョン・ライセンス・ライセンスの本文）を、後のバージョンで `dist/` の依存が変わっても、`src/render/legacy-marks.ts` を削除した（[#479](https://github.com/shuhei1101/mdmark/issues/479)）後も欠けないように表記する。
移行の手順のフォルダを `migrations/v{バージョン}/` に移す release の前に入れる。

表記は、`buildLegacyMarks` が `legacy-marks.js` と同じフォルダへ `THIRD_PARTY_LICENSES.txt` として書き込む。
`buildLegacyMarks` の metafile を `dist/THIRD_PARTY_LICENSES.txt` の集計に加える案は採らない。
`buildLegacyMarks` は `src/render/legacy-marks.ts` が無いと何も書き込まないため、その案では #479 の後に `dist/` の表記から依存が消え、`migrations/v{バージョン}/legacy-marks.js` だけが残る。
