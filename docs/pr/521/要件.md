# 要件

## 要望

`buildLegacyMarks` が移行の手順のフォルダへ書き込む `legacy-marks.js` にまとめた依存（パッケージの名前・バージョン・ライセンス・ライセンスの本文）を、後のバージョンで `dist/` の依存が変わっても、`src/render/legacy-marks.ts` を削除した（[#479](https://github.com/shuhei1101/mdmark/issues/479)）後も欠けないように表記する。
移行の手順のフォルダを `migrations/v{バージョン}/` に移す release の前に入れる。

`未確定`: 表記の置き場所（決める段: モジュール構成設計）

| 案 | 内容 |
| --- | --- |
| A | `buildLegacyMarks` が `legacy-marks.js` と同じフォルダへライセンスのファイルを書き込む |
| B | `buildLegacyMarks` の metafile を `writeThirdPartyLicenses` の集計に加え、`dist/THIRD_PARTY_LICENSES.txt` に載せる |

推奨: A

`buildLegacyMarks` は `src/render/legacy-marks.ts` が無いと何も書き込まず metafile も返さないため、B では #479 の後に `dist/` の表記から依存が消え、`migrations/v{バージョン}/legacy-marks.js` だけが残る。A はファイルと表記が同じフォルダに残り続ける。
