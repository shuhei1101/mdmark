# 要件

## 要望

map の構成図・状態遷移図で、大きさの上書き（`overrides` の `size`）を持たないノードの大きさの既定の見積もりを、描画のノードの左右の余白（左 `LABEL_METRICS.padX`・右 `MAP_NODE_PAD_RIGHT`）で名前の幅を見積もる見積もりにする。

- 名前の文字の幅が「ノードの幅 − 38px」から「ノードの幅 − 20px」の範囲にあるノードでも、名前の最後の行がノードの下の余白に食い込まず、ノードの矩形の中に描かれる
- 大きさの上書きを持つノード（クラス図のクラス・ノート、ER 図のテーブル、C4 図の要素、状態遷移図の開始・終了・分岐、閉じたグループ）の大きさは変えない
- 補足の `layout` で幅（`width`）を指定したノードは、指定した幅のまま、右の余白を見積もった幅で折り返した行が全て入る高さにする
- 描いたノードを測って大きくする処理（`src/map/flow-view.ts` の `measure`）は、中身が下の余白まで入る高さにする。見積もりの文字の幅と実際のフォントの幅がずれたノードでも、名前の最後の行が下の余白に食い込まない
- 名前の幅を左右とも `padX` の余白で見積もる同じ型の箇所 `wrapLabel`（`src/map/layout.ts`。`src/` から呼ばれない）は削除する

- 1 行に収まる名前のノードの幅は、名前の幅に左右の余白（10px + 28px）を加えた幅（`MAP_LAYOUT.minWidth` から最大の幅まで）にする。名前の幅が 82px を超えるノードは幅が最大 18px 広がる（モジュール構成設計で、幅は今のままで高さだけを決める案と比べて決定した。理由は [ライブラリ本体](./ライブラリ本体.mark.md) の `## 変更方針`）
