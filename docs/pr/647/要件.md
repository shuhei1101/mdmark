# 要件

## 要望

次の 6 ファイルごとに、ファイルの要素を `container` に記載した物理ファイルごとのモジュール構成を作り、[docs/module/index.yaml](https://github.com/shuhei1101/mdmark/blob/730b1a56/docs/module/index.yaml) に行を追加する。

| ファイル | 記載する要素 |
| --- | --- |
| `src/render/syntax/blocks.ts` | 関数 `blockStartOf`・`insertWarningsBeforeBlocks`・`pairRanges`・`outermostRanges` |
| `src/render/syntax/tokens.ts` | 型 `TabBoundary`、定数 `TAB_BOUNDARY_KEY`、関数 `envOf`・`featureOn`・`ownBlock`・`tabBoundaryBlock`・`tabBoundaryOf`・`markOf`・`findClose`・`findNestedClose`・`textOf` |
| `src/viewer/includes.ts` | 関数 `includesOf`・`knowledgeOptions` |
| `src/viewer/viewer.css` | スタイル（`@layer mdmark` の中の、まとめた HTML の画面と印刷の規則） |
| `vscode/src/escape.ts` | 関数 `escapeHtml` |
| `vscode/src/workspace.ts` | 関数 `baseDirOf` |

- `src/files.yaml` の 4 ファイルの行と、`vscode/files.yaml` の 2 ファイルの行の implements を、新規作成するモジュール構成へ向ける
- 終了の条件: `git grep -F 'container: {ファイル}' -- docs/module` が 6 ファイルともヒットし、6 ファイルの管理用の YAML の行の implements が新規作成したモジュール構成を指す
