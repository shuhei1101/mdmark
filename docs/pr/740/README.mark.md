# map に A-35 の No 13〜17（確信度のマーカー・変更の表示・環境とシナリオ・書き出し・一覧の表示）を追加するかを決める

## 概要

資料 A-35 の No 13〜17（確信度のマーカー・変更の表示・環境とシナリオ・書き出し・一覧の表示）を map に追加するかを項目ごとに決め、追加する項目は文書の作成者と読者が map の図で使用できるようにする。

## 背景

[Issue #471](https://github.com/shuhei1101/mdmark/issues/471) の要望。[PR #445](https://github.com/shuhei1101/mdmark/pull/445)（[#324](https://github.com/shuhei1101/mdmark/issues/324) の作業 PR）のスコープ外として起票された。

#324 は A-35 の No 13〜17 を「未検討で、この Issue に含めない」とした。
No 17（一覧の表示）は、[#468](https://github.com/shuhei1101/mdmark/issues/468)（[PR #733](https://github.com/shuhei1101/mdmark/pull/733)）で map のマーカーの引数 `mode` の値 `list` として挙がり、この Issue へ移された。#468 は `mode` を追加しないと決めた。
