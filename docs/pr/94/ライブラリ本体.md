## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 要素の検証 | 見出し（`h1`）・段落（`p`）・リスト（`ul`）・表（`table`）・コードブロック（`pre`・`code`）・リンク（`a`）・折り畳み（`details`）の要素名ごとに、`<{要素名}` の後ろが空白か `>` である開始タグがあることを正規表現で確かめる | `<p` が `<pre` に当たらないよう、要素名の直後を空白か `>` に限る |
| スクリプトとコメントの検証 | `<script` と `<!--` を含まないことの検証は変えない | - |
| 他のケース | `test_normal_when_in_browser`・`test_normal_when_syntax`・`test_normal_when_index` は変えない | 属性の無い開始タグの文字列で探していない |
