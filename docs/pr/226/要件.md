# 要件

## 要望

mdmark のリポジトリに MIT のライセンスを付ける。

- リポジトリの直下に `LICENSE` を追加する。本文は MIT License の全文で、著作権表示は `Copyright (c) 2026 shuhei1101` にする
- 直下の `package.json` に `"license": "MIT"` を追加し、`package-lock.json` の直下のパッケージの項目にも同じ値を入れる

v0.7.0 のタグの配布物は変えない。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| [vscode/LICENSE](https://github.com/shuhei1101/mdmark/blob/develop/vscode/LICENSE) の著作権表示（`Shuhei Nishikawa`）を直下の `LICENSE` に揃える | 要望に含まれない。VS Code 拡張機能は独自の `package.json` と LICENSE を持つ別の配布物 | 予定なし |
| [plugin/.claude-plugin/plugin.json](https://github.com/shuhei1101/mdmark/blob/develop/plugin/.claude-plugin/plugin.json) への `license` の追加 | 要望に含まれない | 予定なし |
| [README.md](https://github.com/shuhei1101/mdmark/blob/develop/README.md) へのライセンスのセクションの追加 | 要望に含まれない。GitHub は直下の `LICENSE` をリポジトリのライセンスとして表示する | 予定なし |
| `dist/` への mdmark 自身の `LICENSE` の同梱 | 要望に含まれない。配る書き出しのライセンスの表示は mindstella 側で MIT の本文を入れる | 予定なし |
