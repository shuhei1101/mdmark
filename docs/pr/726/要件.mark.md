# 要件

## 要望

本文の表のセル（`td`・`th`）の中の文字を選んでコメントのボタンが出ても、そのセル・同じ列のセル・表の幅と高さが、選ぶ前と変わらない。

- `mount` で描いた文書の表と、`mountComments` に指定した要素の中の表の両方で成り立つ
- ボタンは今までどおり選んだ文字の終わりの下（収まらなければ上）に出て、押すと入力欄を開く
- ボタンを隠したとき・入力欄を開いたとき・閉じたときにも、表の幅と高さは変わらない
- セル以外のブロック（段落・リストの項目・見出し・引用）で文字を選んだときのボタンの出方は変えない

セルが広がる原因を切り分け、ボタンの DOM の配置先を決めて直す（決める段: インターフェース定義設計）。
インターフェース定義『コメントを付ける』（IF-472-27）の `side_effects` はボタンを `document.body` に配置するとし、インターフェース定義『文書を描く』（IF-472-35）・画面設計『文書』（SCR-472-4）・部品設計『コメントのボタン』（CMP-472-14）・モジュール構成（MOD-472-157）と実装は選んだ文字のブロックの直後に配置するとしていて食い違うため、決めた配置先に揃える。
CMP-472-14 の「選んだ後の Tab で届く」は、決めた配置先でも成り立たせるか、代わりの届き方を部品設計で決める。

`未確定`: ボタンの DOM の配置先（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | 表のセルを選んだときだけ、ボタンを表の外（表を包む要素の直後）に配置する。他のブロックは今までどおりブロックの直後 |
| B | どのブロックでも、ボタンを `document.body` に配置する |
| C | どのブロックでも、ボタンを `root` の直下の末尾に配置する |

推奨: A

選んだ後の Tab で届く順を、セル以外のブロックでは変えず、セルでも表の直後で届くため。
