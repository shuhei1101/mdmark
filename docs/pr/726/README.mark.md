# 表のセルの中の文字を選んでコメントのボタンが出ても、セルと表の幅を変えないようにする

## 概要

読者が表のセルの中の文字を選んでコメントのボタンが出ても、セルと表の幅が変わらないようにする。

## 背景

[Issue #723](https://github.com/shuhei1101/mdmark/issues/723) の要望。表のセルの中の文字を選ぶと「コメント」のボタンが出て、同時にそのセルの幅が大きく広がる。

`src/comments/index.ts` の `syncButton` は、選んだ文字のブロック（`COMMENT_BLOCKS`。`td`・`th` を含む）の直後にボタンを配置する（`block.after(addButton)`）。セルを選ぶと、ボタンは `tr` の直下、セルの隣に入る。ボタン自体は `position: fixed` で、セルが広がる直接の原因は確かめていない。
