# 要件

## 要望

mdmark の文書を純粋な Markdown（GFM と Mermaid）に変換する処理を 1 つ用意し、CLI・MCP のツール・ビュワーのボタンの 3 か所から呼ぶ。
書き出した Markdown を mdmark の無い表示（GitHub・VS Code の標準のプレビュー）で開いたとき、記法の文字・HTML のコメント・定義の JSON が見えず、内容（図を含む）が読める。

| 要件 | 終了の条件 |
| --- | --- |
| HTML のコメントの削除 | マーカーを含め、HTML のコメントを全て取り除く |
| 記法ごとの変換 | Issue の「記法ごとの書き出しの形」のとおりに変換する（表・タブ・ステップ・セクションの開閉・行の詳細・用語集の表・ビューはマーカーを取り除く。注意書きはそのまま。ファイルツリーはコードブロックを残す。バッジは頭の `badge:` を取り除いた行内のコード。コードブロックの飾りはマーカーと行末の `[!code …]` を取り除き、タイトルを直前の太字の行にする。図と表の番号はリンクの文字を `図 1`・`表 1` にする。目次は見出しのリンクの箇条書き） |
| 図の変換 | map は Mermaid のコードブロックだけを残して補足を取り除く。`chart`・`param`・埋め込んだ HTML は、CLI・MCP では SVG のファイルに書き出して画像のリンクに置き換える |
| 拡張のマーカー | 拡張の登録に省略できる書き出しのフックを追加し、フックがあればその形、無ければ取り除く |
| CLI | Markdown に書き出すコマンドで、書き出した Markdown と SVG のファイルを書き出し先に配置する |
| MCP のツール | CLI と同じ処理を呼ぶツールで、書き出したパスを返す |
| ビュワーのボタン | mount が描く文書とまとめた HTML に「Markdown でコピー」（クリップボード）と「Markdown でエクスポート」（ファイルの保存）のボタンを追加する。画像を一緒に配置できないため、`chart`・`param`・埋め込んだ HTML と生の HTML は取り除く |

`flow`・`sequence` は #467 で廃止したため、Mermaid への変換の対象は map だけになる。

`未確定`: `chart`・`param`・埋め込んだ HTML を、画面を持たない CLI・MCP で SVG にする方法（決める工程: PoC 検証）

| 案 | 内容 |
| --- | --- |
| A | `render` が返す HTML 文字列から図の部品の SVG を取り出し、埋め込んだ HTML は SVG の `foreignObject` に包む |
| B | Playwright でブラウザを起動して描いた結果を SVG に取る |

推奨: A

`chart` の部品は既に SVG の文字列を返しており、Playwright は開発の依存だけで配布物に含まれないため。

`未確定`: ボタンの文言と配置（決める工程: モック作成。文言はユーザーに確認する）

| 案 | 内容 |
| --- | --- |
| A | 右側の目次の帯（狭い幅では帯）に、2 つのボタンを並べる |
| B | 文書の右上に、2 つの操作を持つ 1 つのメニューのボタンを重ねる |

推奨: A

右側の目次の帯は描いた文書の全体に対する操作（すべて展開・すべて折りたたむ）を既に持ち、文書の全体を対象にする操作を同じ場所にそろえられるため。
