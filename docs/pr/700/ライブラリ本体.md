## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 変換の処理 | Markdown の文字列と設定を受け、純粋な Markdown の文字列と、書き出す画像の一覧（ファイル名と SVG）を返す公開関数を 1 つ用意する。DOM に頼らず、ブラウザと Node で同じ出力にする | 関数の名前と引数はインターフェース定義設計で決める |
| 画像の扱い | 関数の引数で、画像に書き出すか取り除くかを切り替える。CLI・MCP は書き出し、ボタンは取り除く | - |
| SVG の作り方 | `chart`・`param`・埋め込んだ HTML を画面なしで SVG にする | `未確定`（要件.md。決める工程: PoC 検証） |
| 拡張のフック | `registerExtension` に省略できる書き出しのフックを追加し、無いときはマーカーの範囲を取り除く | 省略できる項目の追加のため、破壊的変更にしない |
| CLI | `mdmark export` と同じ設定の読み込みで、Markdown と画像を書き出し先に配置するコマンドを追加する | コマンド名（新しいコマンドか `export` の引数か）はインターフェース定義設計で決める |
| ボタン | mount が描く文書とまとめた HTML に「Markdown でコピー」「Markdown でエクスポート」を追加する。ファイルの名前は文書のタイトルから決める | 文言と配置は `未確定`（要件.md。決める工程: モック作成） |
| 機能のオン・オフ | ボタンを設定の `features` で消せるようにする | キーの名前はデータ設計で決める |
| 既存機能への影響 | HTML への書き出し・`render` の出力は変えない | SC-472-56・SC-472-57 を実行のみで確かめる |
