## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 変換の処理 | Markdown の文字列と設定を受け、純粋な Markdown の文字列と、書き出す画像の一覧（ファイル名と SVG）を返す公開関数を 1 つ用意する。DOM に頼らず、ブラウザと Node で同じ出力にする | 関数の名前と引数はインターフェース定義設計で決める |
| 画像の扱い | 関数の引数で、画像に書き出すか取り除くかを切り替える。CLI・MCP は書き出し、ボタンは取り除く | - |
| SVG の作り方 | `render` の HTML を解析し、`chart`・`param` はグラフの SVG、埋め込んだ HTML は `foreignObject` に包んだ SVG にする。`index.css` から断片で使う規則とライトの配色の変数だけを SVG に埋め、不透明な背景の矩形を配置する。タイトルと凡例は画像の前後の Markdown の文字にする | `## PoC 結果` |
| 拡張のフック | `registerExtension` に省略できる書き出しのフックを追加し、無いときはマーカーの範囲を取り除く | 省略できる項目の追加のため、破壊的変更にしない |
| CLI | `mdmark export` と同じ設定の読み込みで、Markdown と画像を書き出し先に配置するコマンドを追加する | コマンド名（新しいコマンドか `export` の引数か）はインターフェース定義設計で決める |
| ボタン | mount が描く文書とまとめた HTML に「Markdown でコピー」「Markdown でエクスポート」を追加する。ファイルの名前は文書のタイトルから決める | 配置と文言は要件.md のとおり（モック作成で決定） |
| 機能のオン・オフ | ボタンを設定の `features` で消せるようにする | キーの名前はデータ設計で決める |
| 既存機能への影響 | HTML への書き出し・`render` の出力は変えない | SC-472-56・SC-472-57 を実行のみで確かめる |

## PoC 結果

結論: 成立。`chart`・`param`・埋め込んだ HTML を、ブラウザを起動せずに Node だけで、自己完結した SVG のファイルにできる（PoC PR [#703](https://github.com/shuhei1101/mdmark/pull/703)、commit [fb92e985](https://github.com/shuhei1101/mdmark/commit/fb92e985)）。

| 観点 | 基準 | 実測 | 判定 |
| --- | --- | --- | --- |
| 画面なしで作れる | `node` で見本の 6 種から SVG を作り、ブラウザ・DOM のライブラリを読み込まない | `node poc/svg/export-svg.ts` で 6 種を作成。使用したのは `render`・Node の標準のモジュールと、`sanitize-html` の依存として入っている `htmlparser2`・`dom-serializer`・`postcss`（HTML と CSS の解析器で、描く処理は持たない） | 成立 |
| 自己完結 | `href`・`src`・`url(` の値が `data:` 以外のものが 0 件 | 外部の参照は 0 件。`data:` 以外は SVG の中の `url(#パターンの ID)` だけ。Chromium で SVG を開いたときの外部へのリクエストは 0 件 | 成立 |
| 見た目 | `mount` で描いた図と同じ配置と色。見本 1・2 のタイトルと凡例の系列の名前が Markdown の文字で出る | 系列の色・模様・軸の文字・表の色は `mount` と同じ。差はパネル・高さのハンドル（除いたもの）と、`param` のスライダー（書き出さないもの）だけ | 成立 |
| 大きさ | 見本 3・4・6 で内容が切れず、外側の余白が 24px 以内 | 切れなし。余白は下 1〜2px・右 0px（見本 3: 333×118、見本 4: 1276×816、見本 6: 760×492） | 成立 |
| 表示先 | GitHub と VS Code の標準のプレビューで、テーマの設定と OS の配色の設定の 4 通りずつ、6 種が空にならず読める | GitHub は 4 通りとも 6 種が出て読める。VS Code 1.147 はテーマのライト・ダークで 6 種が出て読める | 成立（注 2） |
| 扱えない中身 | 見本 5 はスクリプトを除き警告 1 件、見本 6 は相対パスの画像がデータ URL で出て `https` の画像の警告 1 件、パネルとハンドルが出ない | 警告はそれぞれ 1 件。見本 6 のデータ URL の画像は GitHub でも出る | 成立 |

注:

1. 1 行の文の見本 5 は、最初の見積もりでは VS Code の標準のプレビューで折り返して下が切れた。表示する側のフォントで文字の幅が変わるため、1 行に収まる見積もりの行は折り返さず、1 文字の幅を余らせて解消した。Windows・macOS のフォントでは確認していないため、見積もりの余りの値は設計で決める
2. VS Code では、OS の配色を切り替える方法（GTK のテーマ・`--force-dark-mode`）が Xvfb の上で有効にならなかった（`prefers-color-scheme: dark` が真にならない）。SVG は `prefers-color-scheme` を使用せず、不透明な背景の矩形を持つため、OS の配色で見た目は変わらない。GitHub（Chromium の配色の指定で切り替え）では 4 通りとも同じ見た目だった
3. `sanitize-html` は SVG の属性の名前を小文字にする（`viewBox` → `viewbox`）。SVG のファイルにするときは大文字小文字を戻す
4. `foreignObject` の中の XHTML に入れた `svg` 要素は、`xmlns` を明示しないと SVG として描かれない
5. SVG 1 枚の大きさは 12〜22KB（CSS の規則と変数を、断片で使うものだけに絞った後）

最小再現コードの要点（[poc/svg/export-svg.ts](https://github.com/shuhei1101/mdmark/blob/fb92e985/poc/svg/export-svg.ts)）:

```ts
// index.css を平らにし、断片にある class と要素名だけの規則を残す（ダーク・別のテーマ・VS Code のテーマの選択子は落とす）
const pruneCss = (options: { classes: Set<string>; tags: Set<string> }): string => {
  for (const rule of flatRules) {
    const selectors = rule.selectors.filter((selector) => selectorApplies({ selector: selector.trim(), ...options }));
    // :root の変数は、残した規則が参照するものだけをたどって入れる
  }
  return `:root{${vars}}${kept.join("")}.mdmark{padding:0!important;max-width:none!important}`;
};

// 埋め込んだ HTML: スクリプト・パネルを除き、画像をデータ URL にし、文字数と範囲の CSS の余白から大きさを見積もって包む
const htmlToSvg = (sample: string, root: Element): string => {
  prepareHtml(sample, root);
  const size = estimate(root, WIDTH);
  const body = `<foreignObject width="${width}" height="${height}"><div xmlns="http://www.w3.org/1999/xhtml" class="mdmark" style="width:${width}px">${toXml(root)}</div></foreignObject>`;
  return svgFile({ width, height, css, body }); // 背景の矩形と style 要素を持つ svg
};
```

PR の diff の見どころ: `export-svg.ts` の `flatten`・`selectorApplies`（入れ子の CSS を平らにして絞る）、`estimate`・`boxOf`（大きさの見積もり）、`toXml`（属性の大文字小文字と名前空間）。確認は `check.ts`（Chromium）・`check-github.ts`（GitHub）・`check-vscode.ts`（VS Code の標準のプレビュー）。
