## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 種類の判定 | Mermaid の 1 行目の `mindmap` を map の種類にする。範囲の外の mindmap のコードブロックも補足の無い map の図にする | マーカーは map のまま |
| 読み取り | 字下げの深さで親子を読み、項目の ID・表示する文字・形を読み取る。字下げが親より浅く戻る行は直前の同じ深さの項目の兄弟にし、根が 2 つ以上あるなど読めない行は書き方の警告にする | `::icon()` の行と `:::` のクラスは描かず、書き方の警告にもしない |
| 木の配置 | 根を中央に置き、根の子を左右に振り分け、子孫を外へ広げる。入れ子の自動配置（`src/map/layout.ts`）とは別の配置の処理にする | 左右の振り分け方はモック作成で決める |
| 共通の部分 | 種類に依らない部分（補足の notes・巡回、拡大と縮小・凡例・ツールチップ・選択の状態の保存）を使用し、種類ごとの読み取り・木の配置・固有の機能だけを追加する | 構成図への差し込み（`MapFlowExtension`）に乗せるか別の描画にするかはモジュール構成設計で決める |
| 開閉と中へ入る | 子を持つ項目を開閉し、閉じた項目に子孫の数を出す。中へ入ると、その項目を根にして子孫だけを木の配置で描き直す。戻る操作はグループの中へ入るときと同じ | - |
| 選択と強調 | 項目を選ぶと、根からその項目までの道筋と子孫を残し、ほかを薄くする | - |
| 補足 | `notes` のキーと `layout` の当て方は要件.md の `未確定` のとおり | - |
| 点検 | 補足が指す無い項目と、キーで指せない項目（同じ文字の重複など）を点検のずれにする | 要件.md の `未確定` で案 A のとき |
| アクセシビリティ | 項目はほかの種類のノードと同じくキーボードで選べ、開閉のボタンに開閉の状態を持たせる | - |
| 既存機能への影響 | ほかの種類の読み取り・配置・描画は変えない | - |
