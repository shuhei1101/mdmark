## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 名前の置き換え | 書き出しの最後に、HTML・CSS（配布物と利用側の `theme.css`）・まとめたスクリプト（拡張のモジュールを含む）・埋め込みの JSON の全体へ、同じ対応表で `mdmark` を含む名前を短い別名へ置き換える | `未確定`（[要件](./要件.md) の案 A / B。決める段: PoC 検証） |
| コメントの削除 | 書き出した HTML の本文と埋め込みの Markdown から、HTML のコメントとマーカーのコメントを削除する。Lucide のライセンスの表記は、mdmark の名前を含まない形で残す | 埋め込みの Markdown のマーカーは描画に要るため、削除の時点は描画に影響しない範囲で設計で決める |
| バージョン・ライセンス | `--mdmark-version` と、esbuild の `Bundled license information` のうち mdmark 自身の表記を、書き出した HTML から削除する | 第三者のライブラリの表記は残す |
| 既定と開発用の指定 | 既定で隠す。CLI の `export`・`build` に隠さない書き出しの引数を追加する | 引数の名前はインターフェース定義設計で決める |
| 既存機能への影響 | 隠した書き出しでも、表示・操作・利用側の CSS・拡張が隠さない書き出しと同じに動く | 書き出しの E2E を隠した書き出しで実行する |
| 保守性 | 終わりの条件（文字列 `mdmark` と `<!--` が残らない）を、書き出した HTML を検査する結合テストで確かめる | - |
