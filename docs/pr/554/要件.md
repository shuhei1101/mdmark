# 要件

## 要望

HTML の書き出し（CLI の `export`・`build`、MCP の `export_html`・`build_site`）は、指定が無くても、書き出した HTML から mdmark を使用していることを読み取れなくする（D-453 No 1・7）。

| 対象 | 書き出した HTML での扱い | 出典 |
| --- | --- | --- |
| 文書の本文の地の文を除く全体（CSS のクラス名・CSS 変数・要素名・`id`・`data-` 属性・スクリプトの名前と文字列・設定の値・ログの文）に、語の一部として出る `mdmark`（大文字・小文字を区別しない） | 書き出しのときに短い別名へ置き換える。文書の本文の中の部品の要素名（`<mdmark-*>`）・CSS 変数（`--mdmark-*`）・`mdmark-` のクラスも同じ規則で置き換え、地の文の語としての `mdmark` だけを残す | D-453 No 2 |
| HTML のコメントとマーカーのコメント | 書き出した HTML と、開いた後の文書から全て削除する。埋め込みの Markdown のマーカーのコメントは描画に要るため残し、埋め込みそのものを無くす #532 で消える。埋め込みの Markdown のマーカーでない HTML のコメントは削除する | D-453 No 3（埋め込みの Markdown の扱いはユーザーへ確認する） |
| mdmark のバージョンの情報（`--mdmark-version` など）と mdmark 自身のライセンスの表記 | 削除する | D-453 No 4 |
| 同梱する第三者のライブラリ（Mermaid・Lucide など）のライセンスの表記 | 残す | D-453 No 4 |

- 終わりの条件: 既定で書き出した HTML（`export`・`build` の両方）の中に、文字列 `mdmark`（大文字・小文字を区別しない）が、残すと決めた第三者のライブラリのライセンスの表記と、文書の本文の地の文の語を除いて現れない。埋め込みの JSON は復号した中身に当てる
- 終わりの条件: `<!--` が、書き出した HTML の文字列と、埋め込みの JSON を復号した中身（埋め込みの Markdown のマーカーのコメントを除く）に現れない。開いた後の文書の DOM にコメントのノードが無い
- 文書の本文のコードの例に書いた mdmark の名前（`<mdmark-chart>` など）は、隠した書き出しでは別名で表示される
- 書き出した HTML の表示と操作（目次・タブ・表の並べ替え・図・文書の行き来など）は、隠さない書き出しと同じに動く
- 利用側の `theme.css` と拡張のモジュールが参照する mdmark の名前も同じ別名へ置き換え、今の上書きと拡張がそのまま効く（破壊的変更にしない）
- 開発のときだけ、CLI の引数と MCP の引数で、隠さない書き出しを指定できる

名前の置き換えの方法は、書き出しのときに出力全体へ 1 つの規則で置き換える（配布物は 1 つのまま）。成り立つかは PoC 検証で確かめる。
