# map のシーケンス図の参加者の箱で、名前の用語とフォーカスできる要素の入れ子を解消する

## 概要

スクリーンリーダー・キーボードの利用者が、名前に用語を持つ map のシーケンス図の参加者の箱と名前の用語を、入れ子にならない要素として操作できるようになる。

## 背景

[map のシーケンス図の参加者の箱の中に名前の用語がフォーカスできる要素として入れ子になり、axe の nested-interactive に当たる](https://github.com/shuhei1101/mdmark/issues/580) の要望。
[図の枠のリサイズハンドルに描いた直後から必須の ARIA 属性を持たせ、map の構成図の説明を持つノードのフォーカスできる要素の入れ子を解消する](https://github.com/shuhei1101/mdmark/pull/577) の部品設計で同じ型の箇所として見つかり、スコープ外として起票された。
[図の枠のリサイズハンドルに描いた直後から必須の ARIA 属性を持たせ、map の構成図の説明を持つノードのフォーカスできる要素の入れ子を解消する](https://github.com/shuhei1101/mdmark/pull/577) は構成図のノードを、ノードを覆う押せる要素を名前・中身の下に重ねる構造にした。
シーケンス図の参加者の箱は別の関数（`renderSeqHead`）で描き、箱の `div` が `role="button"`・`tabindex="0"` を持ったまま、中に `tabindex="0"` の `span.mdmark-term` を描く。
