## 要望

- 名前に用語を持つ参加者の箱でも、フォーカスできる要素が入れ子にならず、axe の `nested-interactive` が出ない
- 参加者の選択（名前の文字の外を押す・Enter・Space）、ドラッグと Alt + 左右の矢印キーでの並べ替え、名前の文字の選択、名前の用語のツールチップの開閉を保つ
