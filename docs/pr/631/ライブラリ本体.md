## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参加者の箱の HTML | 箱の `div` から `role`・`tabindex`・`aria-keyshortcuts`・`aria-label` を除外し、箱を覆う押せる要素（`span.mdmark-diagram-node-hit`）を先頭に入れて持たせる。名前の `span.mdmark-diagram-node-name` はその兄弟にする | 構成図のノードと同じ構造。選んだかの `data-selected`・`is-selected` は箱の `div` に残す |
| キー操作 | `sequence-view.ts` の選択・並べ替えは、押せる要素から `closest(".map-participant")` で参加者を参照する今の作りを保ち、並べ替えた後のフォーカスを押せる要素へ戻す | Enter・Space・Alt + 左右の矢印キー |
| ポインター操作 | 名前の文字の外を押す選択とドラッグの並べ替え、名前の文字の選択を保つ | 押せる要素は名前の下に重ねる |
| フォーカスの枠線 | 押せる要素の `:focus-visible` の枠線を箱の形状に合わせて出す | 既存の `.mdmark-diagram-node-hit` の指定を使用する |
| 用語のツールチップ | 名前の用語の `span.mdmark-term` は押せる要素の外に配置し、ツールチップの開閉を保つ | - |
| テスト | 単体テストで参加者の箱の構造と属性を、結合テストで名前に用語を持つ参加者に axe の `nested-interactive` が出ないことと、選択・並べ替え・ツールチップの開閉を確認する | - |
