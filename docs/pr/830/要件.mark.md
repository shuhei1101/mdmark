# 要件

## 要望

タブ名の並びが横幅に入りきらないときは、折り返さずに 1 行のまま並びの中で横にスクロールさせ、選んだタブを並びの見える位置へ移す。

- 横幅に入りきらないタブ群でも、タブ名の並びの高さはタブ 1 行分のまま変わらない
- 並びに収まらないタブは、並びを横にスクロールすると読める（ページ全体は横にスクロールしない）
- 次のどの選び方でも、選んだタブのボタンの全体が並びの見える範囲に入る
  - 押す・左右の矢印・Home・End で選ぶ
  - 描いた直後に選ぶ（同じ組で残したタブ名のタブ・URL の `#ID` が指すタブを含む）
  - 同じ組のほかのタブ群で選んだタブ名に切り替わる
- 選んだタブを見える位置へ移すとき、ページと文書をスクロールする要素の縦のスクロール位置は変えない（押したタブのボタンの画面の位置を保つ今の決まりを壊さない）
- 入れ子のタブ（タブの中のタブ）の並びにも同じく当てる
- 横幅に収まるタブ群の見た目は今のまま
- タブのマーカーの指定（`<!-- tabs: {"wrap": true} -->`）で、そのタブ群だけタブ名の並びを今までどおり折り返して並べられる。指定しないタブ群は横スクロールにする（[確認ログ](https://github.com/shuhei1101/mdmark/pull/830#discussion_r4726214787)）
