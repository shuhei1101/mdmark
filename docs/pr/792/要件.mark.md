`未確定`: #784 の指定の名前と値の型（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | 真偽値の `opts.diffControls`（既定 `true`。`false` でボタンと欄を出さない） |
| B | `diffMode` に値を追加する |

推奨: A

`diffMode` は差分の見せ方（行・ブロック・左右）を選ぶ値で、ボタンと欄を出すかは見せ方と組み合わせて決まるため。

#783 は、狭い幅では、変えたブロックだけ前（削除の色）の下に後（追加の色）を縦に並べ、変えていないブロックは 1 回だけ出す。広い幅では左右の列を 1 つのスクロールで動かす。

#790 の狭い幅の右側の目次は、バーを固定せず、目次を開くボタンだけを右上の端に固定する。

#790 の目次を開くボタンのアイコンは、右側のパネル（Lucide の `panel-right`）にする。

`未確定`: #790 で右上の端に固定する目次を開くボタンの大きさ（決める段: モック作成。案をモックで出して利用者が選ぶ）

| 案 | 内容 |
| --- | --- |
| A | 見た目は 32px 四方（アイコン 16px）に小さくし、押せる範囲は周りの透明な余白で 44px 四方に保つ |
| B | 見た目も押せる範囲も 32px 四方（アイコン 16px） |
| C | 見た目も押せる範囲も 28px 四方（アイコン 16px） |

推奨: A

見た目は小さくしても、スマートフォンで主に使う操作の押せる範囲（44px 四方）を保てるため。

#788 は、表示する枠に縦に収まらない図だけ、開いたときの倍率でも指の縦の動きで図の中を動かし、図の端を越えた分は文書をスクロールする。枠に縦に収まる図は今のまま文書をスクロールする。
