#784 の指定は、真偽値の `opts.diffControls`（既定 `true`。`false` でボタンと欄を出さない）にする。

#785 で、ラベルの置き場所が無くラベルを描かない線だけは、今までどおり線そのものの上とフォーカスで説明を出す。

`未確定`: #790 の iPad の Safari の見出し行のずれを、再現しないまま直すか（決める段: モジュール構成設計）

Playwright の WebKit（iPad Pro 11 の端末設定）で測ると見出し行は Chromium と同じ位置に留まり、ずれは再現しなかった（[測定のログ](./ipad-webkit-measurement.log)）。iPad・iPhone の Safari を見分ける `CSS.supports("-webkit-touch-callout", "none")` も Playwright の WebKit では偽で、テストでは見分けられない。

| 案 | 内容 |
| --- | --- |
| A | 推測のまま、iPad・iPhone の Safari では表の見出し行を JS でずらす方式にし、マージの後に実機で確認する |
| B | `animation-timeline` の方式と JS でずらす方式を切り替えられる確認用のページを配信し、利用者が iPad の実機でどちらがずれるかを確認してから直す |

推奨: B

再現しないまま直すと、直ったかを確かめる手段がなく、テストも直す前から通るため。

#783 は、狭い幅では、変えたブロックだけ前（削除の色）の下に後（追加の色）を縦に並べ、変えていないブロックは 1 回だけ出す。広い幅では左右の列を 1 つのスクロールで動かす。

#790 の狭い幅の右側の目次は、バーを固定せず、目次を開くボタンだけを右上の端に固定する。

#790 の目次を開くボタンのアイコンは、右側のパネル（Lucide の `panel-right`）にする。

#790 の目次を開くボタンは、見た目を 32px 四方（アイコン 16px）にし、押せる範囲は周りの透明な余白で 44px 四方に保つ。

#788 は、表示する枠に縦に収まらない図だけ、開いたときの倍率でも指の縦の動きで図の中を動かし、図の端を越えた分は文書をスクロールする。枠に縦に収まる図は今のまま文書をスクロールする。
