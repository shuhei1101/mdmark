`未確定`: #784 の指定の名前と値の型（決める段: インターフェース定義設計）

| 案 | 内容 |
| --- | --- |
| A | 真偽値の `opts.diffControls`（既定 `true`。`false` でボタンと欄を出さない） |
| B | `diffMode` に値を追加する |

推奨: A

`diffMode` は差分の見せ方（行・ブロック・左右）を選ぶ値で、ボタンと欄を出すかは見せ方と組み合わせて決まるため。

`未確定`: #783 の左右に並べる見せ方の、狭い幅での見せ方と左右のスクロールの連動（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 狭い幅では、変えたブロックだけ前（削除の色）の下に後（追加の色）を縦に並べ、変えていないブロックは 1 回だけ出す。広い幅では左右の列を 1 つのスクロールで動かす |
| B | 狭い幅でも左右に並べ、横にスクロールさせる |

推奨: A

スマートフォンの幅で左右に並べると、1 列の幅が本文を読めない幅になるため。

`未確定`: #790 の狭い幅の右側の目次の固定の見せ方（決める段: モック作成。案を複数のモックで出して利用者が選ぶ）

| 案 | 内容 |
| --- | --- |
| A | 狭い幅では帯を固定せず、本文の先頭にだけ置く |
| B | 下へスクロールしている間は帯を隠し、上へスクロールしたら出す |
| C | 目次を開くボタンだけを画面の端に固定する |

推奨: B

帯で今いるセクションを確認できる働きを残したまま、読んでいる間は本文を隠さないため。

#788 は、表示する枠に縦に収まらない図だけ、開いたときの倍率でも指の縦の動きで図の中を動かし、図の端を越えた分は文書をスクロールする。枠に縦に収まる図は今のまま文書をスクロールする。
