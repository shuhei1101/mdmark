## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 差分のボタンと欄を出さない指定（#784） | `mount` の `opts` に指定を追加し、指定したときは差分の行を出したまま変更表示のボタンとリビジョンを選ぶ欄を配置せず、取り出し元の一番新しいリビジョンとその 1 つ前を比べる。指定を省いたときは今の動きのまま | `未確定`（指定の名前と値の型。要件の案 A を推奨） |
| 左右に並べる差分（#783） | `diffMode` に値を追加し、前のリビジョンを左・後のリビジョンを右に描き、変えていないブロックを同じ高さで向かい合わせ、追加・削除・変更したブロックを差分のブロックの色で示す。ブロックの対応づけは `blocks` の比べ方を使用する | `未確定`（狭い幅の見せ方・スクロールの連動。モックで決定する） |
| 差分のブロックの箇条書きの記号（#786） | 追加・削除した箇条書きの項目の +・− を、項目の 1 行目の高さに描く | 再現を画面で確認してから、`.mdmark-diff-block` の規則と項目の包み方のどちらで修正するかを部品設計で決定する |
| 手順のバー（#787） | 選んだ区切りを、塗りのアニメーションをせずに選んだ時点で全体を緑にする | 案内と再生の両方 |
| 線のツールチップ（#785） | 線の補足のツールチップを、線そのもの（押せる帯）の上では出さず、線のラベルにポインターを乗せたとき・フォーカスしたときだけ出す | ラベルの無い線の補足を出す場所と、対象の図の種類は、画面で確認してから部品設計で決定する |
| 図の縦の指の操作（#788） | スマートフォンで、図の中を指で縦にも動かせるようにする | 図が枠に収まっていないときに縦が動かない原因を画面で切り分ける。収まっているときの動き（#602）を変える場合はユーザーに確認する |
| `--mdmark-sticky-top` の読み方（#789） | `calc()`・`rem` など px 以外の長さも px に解決してから使用し、`script` の方式で `timeline` の方式と同じ位置に留める。表・先頭へ戻るボタン・図の見出しの 3 つの処理を同じ読み方にする | `@property` で登録するか、読み込む前に要素で測るかはモジュール構成設計で決定する |
| iPad の Safari の見出し行（#790） | Playwright の WebKit の iPad の端末設定で、ページと区画のスクロールの見出し行の位置を測って原因を切り分け、表の上端が留める位置に達した時にだけその位置に留める | 範囲の求め方を修正するか、Safari で `script` の方式に切り替えるかは切り分けの結果で決定する |
| 狭い幅の右側の目次（#790） | 狭い幅の帯の固定の見せ方を、モックで複数の案を出して利用者が選んだ案に変える。iPhone の幅で見出し行が帯の裏に隠れる事象が解消することを確認する | `未確定`（要件の案 A〜C。モックで決定する） |
| テスト | 単体: 差分の指定と値・`--mdmark-sticky-top` の長さの解決・手順のバーの塗り・線のツールチップの出入り口。結合: ストーリーで左右に並べる差分・箇条書きの記号・狭い幅の帯の見え方と、WebKit の端末設定での見出し行の位置 | - |
