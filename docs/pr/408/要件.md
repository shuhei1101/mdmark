## 要望

`src/index.css` の `.mdmark .mdmark-tree-row { display: flex }` を `.mdmark-tree-list` の中に限定し、表のキーの階層の `<tr class="mdmark-tree-row">` に当てない。
行が隠れた後に同じ 4 件の続きで fail した、印刷中の表のボタンの隠し方と、全体のパスのツールチップの位置も合わせて修正する。

- 表のキーの階層の `hidden` を付けた行（折りたたんだ行・絞り込みで外れた行）の計算後の `display` が `none` になる
- ファイルツリーの項目の行は今と同じく `display: flex` で並ぶ
- 印刷中は表のキーの階層の開閉とコピーのボタンが隠れる
- 全体のパスのツールチップは名前に重ならず、ポインターを受け止めない
- クラス名 `mdmark-tree-row` と、部品が返す HTML は変えない
- fail した E2E 4 件（『表を操作する』の `test_normal_when_tree_folded`・`test_normal_when_tree_filtered`・`test_normal_when_tree`、『文書を印刷する』の `test_normal_when_tree_folded`）が pass する
