## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 注記の定義 | 行頭の `※[ID]: 本文` で定義する（4 文字の字下げで続く段落を含む）。定義は記載した位置に出力しない。同じ ID の定義が 2 つあれば後の定義を無視して警告する | [文書をHTML文字列にする](../../interface/IF-472-34.ts.yaml) の制約「注記」 |
| 本文・表のセルからの参照 | 行内の `※[ID]` で参照し、定義の本文を参照の場所のツールチップに出す。1 か所に複数の注記を並べて参照できる。`※` の直後の `[ID]` がリンクになるとき（`※[ID](URL)` と、リンクの参照の定義があるときの省略形・完全形・簡略形）はリンクを優先する | 表のセルは本文と同じ記法で参照する |
| map のノードと線からの参照 | 補足の `notes` のノード・線ごとの値に `annotations`（注記の ID の並び）を持ち、図のツールチップでノードの説明の下に区分を分けて注記の本文を出す。説明を持たない線も、注記を持てばツールチップを持つ | [ER 図『map の補足』](../../er/ER-472-2.yaml) の `notes` |
| 参照のマーカーとツールチップ | 脚注の参照の番号とツールチップの部品を拡張して使用する。マーカーは上付きの「※」と番号（`※1`）にし、番号は文書の中で最初に参照した順に 1 から振り、脚注の番号とは別に数える。同じ注記は同じ番号にする。ツールチップのタイトルは `注記 {番号}`。ポインター・フォーカスで出し、Esc で閉じ、タッチ・印刷の振る舞いは脚注と同じにする | [確認ログ](./確認ログ.yaml)（マーカーは案 C） |
| 末尾の注記の一覧 | 脚注の閉じた一覧の部品を拡張し、参照された注記を番号の順（最初に参照した順）に並べ、項目の頭に `※{番号}` を出す。見出しは `注記（{件数} 件）`。脚注の一覧とは分け、本文 → 脚注 → 注記 → 関連文書の順に配置する。一覧の項目から参照の場所へ戻れる。印刷では開いて出す | [確認ログ](./確認ログ.yaml)（一覧は分ける案 A） |
| 脚注への影響 | 脚注の記法・番号・ツールチップ・一覧の今の表示と操作は変えない | 既存の脚注のテストを回帰確認に使用する |
| 点検 | 描画の記載の警告として、定義の無い ID の参照・参照されていない定義・同じ ID の 2 つ目の定義を出し、`mdmark check`・MCP の `check` が `annotation_undefined`・`annotation_unused`・`annotation_duplicate` のずれで返す。map の補足の定義の無い注記の参照も `annotation_undefined` にする | - |
| 機能のオン・オフ | 設定と文書の `features` に `annotations`（既定はオン）を追加する。オフのときは参照と定義を記載した文字のまま描く | `schemas/mdmark.config.schema.json` を変えるため、`migrations/no-steps.yaml` に行を追加する（既定がオンで既存の設定の移行は不要） |
| 1 枚にまとめた HTML | `mdmark build`・`export` の HTML でも、マーカー・ツールチップ・一覧が働く | 脚注と同じ経路で埋め込む |
| Mermaid の `note` の呼び名 | 状態遷移図の種類の行の表示（`src/parts/map.ts` の `note: "注記"`）を `ノート` にし、map のシーケンス図・状態遷移図の `note` を指す設計書・ガイド・コメント・テストの「注記」を「ノート」に改める。点検だけが通知する「マーカーの注記」（画面に出ない内部の呼び名）は変えない | [確認ログ](./確認ログ.yaml)（Mermaid の `note` は「ノート」の案 A） |
| アクセシビリティ | マーカーはフォーカスでき、ツールチップを `aria-describedby` で結び、一覧への移動を Enter で行える | 脚注と同じ |
