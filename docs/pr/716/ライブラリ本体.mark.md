## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 色の名前の色 | `COLOR_NAMES` の色ごとに、Web の `--mdmark-color-accent-{色}-bg`・`-text` と同じ値の文字色・背景色を共通スタイルの定義に追加する | 追加した値が CSS 変数と同じことを単体テストで確認する |
| 色の無いバッジの色 | 共通スタイルの定義に面の色（`--mdmark-color-surface`）と本文の色（`--mdmark-color-text`）を同じ値で追加する | 色を付けないバッジ（`badge:文言`）が Web の `.mdmark-badge` と同じ色になる |
| Web の外観 | CSS 変数の名前と値を変えない | 破壊的変更にしない |
