## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| jsDelivr の配布物 | スプリントの区切りに develop の worktree で管理作業（移行の手順の移し・`npm run build -- --version v{バージョン}`・`dist/` と `plugin/` の commit）をし、develop の commit に `v{X}.{Y}.{Z}` のタグを打つ | E2E は回さない |
| URL | `https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{タグ}/dist/` は変えない | 破壊的変更にしない |
| master を指す参照 | 文書・設計書の `blob/master`・`@master`・`/master/` を develop に修正する | 外部ライブラリのコピー（`docs/_theme/assets/vendor/`）と ER 図の種類 `master` は対象外 |
| 変更履歴 | 次のバージョンに配り方の変更を記載する | - |
