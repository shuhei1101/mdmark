# 要件

## 要望

行の詳細（`<!-- row-detail: N -->` 〜 `<!-- /row-detail -->`）の中身に表を置いても、次を満たして描く。

- 親の表の本文の行は、詳細を付けた行の位置（最後の行・最後以外の行）によらず、全て親の表の `<table>`〜`</table>` と部品『表』の囲みの中に残る
- 親の表の本文の各セルの `data-label` は、親の表の見出しの文字になる
- 親の表の件数（`+count`）・行へのリンク（`+rowlink`）・集計（`+total`）は、親の表の本文の行だけを数え・対象にする（行の詳細の中の表の行を含めない）
- 行の詳細の中の表は、中の表の見出しで `data-label` を付ける
- 行の詳細の中の表には、その表を囲む表のマーカーの指定を当て、親の表のマーカーの指定は当てない（マーカーが無ければ既定の種類）
- 表のマーカー（`<!-- table: data -->`）の範囲の内と外のどちらに親の表を置いても、同じ結果になる
- `fig` のマーカーを付けた親の表は、行の詳細の中に表があっても、親の表の全ての行を図表の囲みの中に入れる（`table` の機能のオン・オフによらない）
- 描いた後の親の表の操作（ピン止め・絞り込み・最終列の畳み）は、行の詳細の中の表の部品の要素を拾わない
