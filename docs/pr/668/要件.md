# 要件

## 要望

`docs/module/*.yaml` の `functions[].summary` と `constants[].summary` のうち、400 字を超え、5 文以上を持つ 31 項目（27 ファイル）を次の状態にする。

- `summary` は 1 文の概要（何を担うか）にする
- 移した詳細は、同じ要素の `description` に置く。既に `description` を持つ要素は、既存の本文と重ならないように合わせる
- `description` は規約『表し方の優先順位』に沿って、1 文 1 行で書き、並列の項目（条件ごとの挙動・引数ごとの扱い 等）は表にする
- 詳細の中身（挙動・条件・値）は変えない

対象の 31 項目の一覧は [ライブラリ本体](./ライブラリ本体.md) の `## 現状` に置く。
Issue 本文の 28 項目は受付時の数で、develop の今の数（[#663](https://github.com/shuhei1101/mdmark/pull/663) までを含む）で数え直した。
同じ型の `constants[].summary`（`MOD-472-214` の `SANITIZE_OPTIONS`）も、規約の同じ型の箇所として含める。
