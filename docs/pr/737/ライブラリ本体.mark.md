## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 除く要素 | `visibleText` が、用語のツールチップに加えて脚注・注記の参照（`.mdmark-fn-ref`。番号・スクリーンリーダー用の文字・ツールチップ）を除く | `src/shared/text.interact.ts` の内部の定数 `TIP_SELECTOR` を `.mdmark-term-tip, .mdmark-fn-ref` にする |
| セルの値 | `cellValue` は `data-value` を優先し、無ければ `visibleText` の文字を返す今の形を保つ | - |
| 他の呼び出し元 | 右側の目次の見出しの文字・行の詳細の開閉ボタンの名前・表の見出しの名前・ビューの文字も `visibleText` の戻り値で変わる。呼び出し元のコードと設計書（MOD-472-228・MOD-472-219・MOD-472-222・MOD-472-156）の記述は `visibleText` を名指すだけで変えない | `visibleText` の単体テスト `test_visible_text_when_footnote_ref` で確かめる |
| 結合テスト | 脚注を含むセルの表で、並べ替えの順・絞り込みの候補・コピーした中身に脚注の定義の文字が入らないことを確かめる | - |
