## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 除く要素 | `visibleText` が、用語のツールチップに加えて脚注・注記の参照（`.mdmark-fn-ref`。番号・スクリーンリーダー用の文字・ツールチップ）を除く | `未確定`（要件の案 A〜C。推奨は B。決める段: モジュール構成設計） |
| セルの値 | `cellValue` は `data-value` を優先し、無ければ `visibleText` の文字を返す今の形を保つ | - |
| 他の呼び出し元 | 右側の目次の見出しの文字・行の詳細の開閉ボタンの名前・ビューの文字から脚注・注記の定義の文字が消えることを単体テストで確かめる | - |
| 結合テスト | 脚注を含むセルの表で、並べ替えの順・絞り込みの候補・コピーした中身に脚注の定義の文字が入らないことを確かめる | - |
