# 要件

## 要望

脚注・注記の参照を持つ表のセルで、並べ替え・絞り込み（候補を含む）・コピー・集計の値に、脚注・注記のツールチップの文字（タイトルと定義）を入れない。

- `data-value` を持つセルの値は今のまま `data-value` にする
- 用語のツールチップの文字は今のまま値に入れない
- 脚注・注記を持たないセルの値は今の値から変えない

`未確定`: 除く範囲（決める段: モジュール構成設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `visibleText` で `.mdmark-fn-tip` も除く。参照の番号のリンク（スクリーンリーダー用の `脚注 ` と番号）は残す | 右側の目次・行の詳細の開閉ボタン・ビューの文字からも脚注の定義の文字が消える。変更が 1 か所で済む | セルの値に `脚注 1` のような参照の文字が残る |
| B | `visibleText` で脚注・注記の参照（`.mdmark-fn-ref`）を丸ごと除く | セルの値が本文の文字だけになり、並べ替え・絞り込みが参照の有無に左右されない | コピーした表から脚注の番号が消える |
| C | `cellValue` の経路だけで `.mdmark-fn-tip` を除き、`visibleText` は変えない | 表以外の文字は変わらない | 右側の目次・行の詳細の開閉ボタンに脚注の定義の文字が残る |

推奨: A

`visibleText` を使う右側の目次の見出しの文字・行の詳細の開閉ボタンの名前・ビューの文字にも同じ定義の文字が入るため、1 か所で直す。参照の番号は画面に見えている文字で、スクリーンリーダー用の文字を値に残す今の前提（MOD-472-229 の `test_cell_value`）とも合う。
