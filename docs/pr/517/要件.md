# 要件

## 要望

プラグインの PreToolUse のフックが `updatedInput` を返却するときは、`hookSpecificOutput` に `permissionDecision` と `permissionDecisionReason` を付けて返却する。
auto モードで、フックが `project_dir` を入れた mdmark のツールの呼び出しが、入力の書き換えを理由に拒否されないことを終わりの条件にする。

- `permissionDecision` の値は設計（インターフェース定義設計）で決める。`allow` にする場合は、`hooks.json` の `matcher` が作業のフォルダを使用する mdmark の MCP のツールだけに該当することを制約に残す
- `CLAUDE_PROJECT_DIR` が無く引数を書き換えないときは、今と同じく何も出力しない
- 単体テストと結合テストで、出力に `permissionDecision` があることを確認する
- 設計書のうち `permissionDecision` を記載する 3 つ（インターフェース定義『作業のフォルダを引数に入れる』・モジュール構成『ClaudeCodeプラグイン / フック / pre-tool-use.ts』・外部ライブラリ『ClaudeCode』）を、出力と公式の資料に合わせる
- PreToolUse のフックは `plugin/hooks/hooks.json` の 1 つだけで、ほかに `permissionDecision` を確認するフックは無い
