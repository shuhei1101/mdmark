## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 属性を付ける要素と CSS の起点 | `data-mdmark-sticky` を `root` でなく表ごとの留める要素（表を包む `.mdmark-table-scroll`、包む要素が無い表は `table`）に付け、`src/index.css` の留める規則は `.mdmark` の `&` でなく `[data-mdmark-sticky]` を起点にする | モジュール構成設計で決定（MOD-472-221・MOD-472-170） |
| 対象の表 | 本文の行を持つ全ての表（種類・`+機能`・`-機能`・`features.table` によらない）の見出し行を留める。`features.table` がオフの表は、表の部品で包まない `table` 要素にも留める処理と CSS を適用する | `要件.md` の `## 要望` |
| 留める位置の基準 | `timeline` と `script` のどちらも、表の横のスクロールの要素の外側で最も近い、縦にはみ出していて縦にスクロールする祖先の上端（祖先が無ければ画面の上端）に `--mdmark-sticky-top` を加算した位置に留める。`view-timeline` が従う要素がスクロールする場所と違う表は、`animation-timeline` を持つブラウザでも `script` にする | `script` は祖先の scroll も受け取ってずらす量をもう一度求める。横にだけスクロールする要素（`<!-- wide -->` の範囲など）は基準にしない |
| 集計の行 | 見出し行と同じく、スクロールする区画の下端（祖先が無ければ画面の下端）に留める | 見出し行の基準と統一する |
| 印刷 | 今のとおりずらさない | - |
| 既存機能への影響 | 右側の目次・狭い幅の帯・図の参加者の行が使用する `--mdmark-sticky-top` は既にスクロールする場所の上端を基準にしているため変えない | `要件.yaml` のスコープ外の 1 行目 |
