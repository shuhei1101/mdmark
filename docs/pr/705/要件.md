# 要件

## 要望

表の見出し行を、全ての表で、描き方とスクロールする場所によらず、同じ規則で留める。

| No | 要件 | 測り方 |
| --- | --- | --- |
| 1 | `mount` で描いた表の見出し行が、部品『表』の定義のとおりに留まる | 40 行・8 列の表を `mount` で描き、ページを表の上端から 400px スクロールした後、`thead th` の上端が `--mdmark-sticky-top` の位置（既定 0）にある（Chromium と Firefox） |
| 2 | スクロールする区画の中に描いた表で、`timeline` と `script` の見出し行が同じ位置に留まる。位置は、スクロールする区画の上端（画面全体がスクロールするときは画面の上端）に `--mdmark-sticky-top` を加算した位置 | 上端が 48px の位置にある `overflow: auto` の区画の中で区画を 400px スクロールした後、`thead th` の上端が `--mdmark-sticky-top` 無しで 48、`48px` で 96 になる（Chromium と Firefox で同じ値） |
| 3 | 表の種類（既定・`data`・`plain`）・機能の指定（`features.table` を含む）・描き方（`mount`・VS Code 拡張機能のプレビュー・CLI の書き出し）によらず、本文の行を持つ全ての表の見出し行が留まる | 種類・機能の指定・描き方の組み合わせごとに、1 と同じ測り方で `thead th` が留まる |
| 4 | 固定されない表がある前提の記述・設定を、設計書・公開ドキュメントから無くす | 設計書と `docs/guide/` に、見出し行を留めない表・設定がある前提の記述が無い |
| 5 | `--mdmark-sticky-top` の基準（2 の位置）を `docs/guide/API.mark.md` に記載する | `--mdmark-sticky-top` の行の説明が、スクロールする区画の上端からのずれになっている |

3 で `features.table` を `false` にした文書の表は、見出し行を留める処理と CSS を `features.table` の条件から除外し、表の部品で包まない表（`table` 要素だけ）にも適用して留める（インターフェース定義設計で案 A に決定。[reviewer の合意](https://github.com/shuhei1101/mdmark/pull/705#discussion_r4628036540)）。
