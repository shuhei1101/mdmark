## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図を付ける関数の引数 | `attachMapClass`・`attachMapEr`・`attachMapState`・`attachMapArchitecture`・`attachMapC4` の第 3 引数を `{ args, resolveIdLink }` の形にし、受け取った `resolveIdLink` を `attachMapFlow` に渡す | 引数の形はモジュール構成設計で決める |
| `FLOW_BASED` と `attachRange` | `FLOW_BASED` の型を上の引数に合わせ、`attachRange` は `context.resolveIdLink` を渡して付ける | - |
| 許可と書き方の警告 | `attachMapFlow` の `mapLinkProblems` と `attachRange` の `warnRange` をそのまま使い、flowchart と同じ許可・警告にする | 新しい判定を作らない |
| 結合テストのケース | IF-472-35 の『正常系（map のノードの id: のリンク先を URL に変える）』にクラス図の範囲を加えるか、クラス図の別のケースを追加する | インターフェース定義設計で決める |
