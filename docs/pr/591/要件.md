# 要件

## 要望

`MountHandle.update` で描き直しても、読者が手で開閉した図のグループ・シーケンス図のブロックと、フロントマターの折りたたみの開閉を引き継ぎ、マーカーのとおりの初期の開閉へ戻さない。

- 対象の部品: map の構成図（ER 図・状態遷移図を含む）のグループの開閉（`data-group-toggle`）、map のシーケンス図のブロックの開閉（`data-fragment-toggle`）、フロントマターの折りたたみ（`details.mdmark-frontmatter`）
- 図のグループ・シーケンス図のブロックは、描き直しで開閉が戻るかを先に確かめる。戻らなければ、図のコードは変えず、描き直しの後も開閉が残ることを結合テストで確かめる。戻るときは、戻る条件を特定して直す
- フロントマターの折りたたみは、PR #540 の部品の開閉の記録（`PartStates`）に対象として加え、details の範囲と同じ決まりで引き継ぐ（手で押した要素だけを引き継ぐ・押した回数によらず最後の開閉を記録する・開閉のマーカーが変わった要素はマーカーのとおりに描く・2 回目の `mount` と `destroy` の後は引き継がない）
- 公開関数の引数・戻り値・マーカーは変えない
