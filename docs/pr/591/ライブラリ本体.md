## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図のグループ・シーケンス図のブロック | `update` の前に手で開閉し、描き直した後の `aria-expanded` と描いたノード・メッセージを確認する。残るなら図のコードは変えず、結合テストで残ることを固定する | 戻るときは、戻る条件（図の番号のずれ・sessionStorage を使えない場合 等）を特定して修正する |
| フロントマターの折りたたみ | `PART_SELECTORS` にフロントマターの種類を加え、`attachDetailsStates` の対象にする | 鍵は details の範囲と同じ（囲むセクションの `id` と同じ種類の何番目か）。マーカーは `open` 属性の有無 |
| 既存機能への影響 | details の範囲の数え方（`details` の種類の何番目か）は変えない | フロントマターを別の種類として数え、details の範囲の鍵をずらさない |
