# 描き直しで手で変えた図のグループ・シーケンス図のブロック・フロントマターの開閉を保つ

## 概要

読者が手で開閉した図のグループ・シーケンス図のブロック・フロントマターの折りたたみが、利用側のページが `update` で描き直した後もその開閉のまま表示される。

## 背景

[Issue #543](https://github.com/shuhei1101/mdmark/issues/543) の不具合。[PR #540](https://github.com/shuhei1101/mdmark/pull/540) のスコープ外の行から切り出した。

- PR #540 は、行の詳細・details の範囲・折りたたみの注意書き・ER 図の列・ファイルツリー・コードの折りたたみ・表のキーの階層の開閉を、描き直しをまたいで保つ記録（`src/interact/part-states.ts`）を入れた
- フロントマターの `<details>` は class に `mdmark-frontmatter` を加えるため、記録の対象のセレクタ（class が `mdmark-collapsible` だけの `details`）に当たらず、描き直すたびに閉じる
- 図のグループ・シーケンス図のブロックの開閉は、Issue ではコードを読んだ見込みで戻るとしている。開閉は図ごとの sessionStorage の記録（`src/map/state.ts`）が持ち、描き直しで図を付け直すときに読み直すため、戻るかを先に確かめる
