# 要件

## 要望

次の設計書の前提と実測を、手元の tmux のセッションの中で動かしても手元の tmux サーバーにつながらない分け方に修正する。

| 箇所 | 修正 |
| --- | --- |
| `docs/library/LIB-472-29.yaml` の `verification` | 手元の tmux サーバーから分けたサーバー（`tmux -L {一時のソケット名}` など）で実測を取り直し、分け方を記載する |
| `docs/interface/IF-472-7.ts.yaml`・`IF-472-11.ts.yaml`・`IF-472-12.ts.yaml`・`IF-472-14.ts.yaml` の前提 | `TMUX_TMPDIR` だけで分ける記載を、手元の tmux サーバーにつながらない分け方の記載にする |
| `docs/scenario/SC-472-22.yaml`・`SC-472-69.yaml` の前提 | 同上 |
| `docs/module/MOD-472-12.ts.yaml` の `test_start_with_tmux` の mock | 同上 |

終わりの条件:

- `verification` の実測を、手元の tmux サーバーの設定・セッションが変わらない分け方で取り直している
- 上の設計書の前提が、`TMUX` のある環境で従っても手元の tmux サーバーにつながらない分け方を記載している
- テストのコードが設計書の前提の分け方で動いている

分け方は、`TMUX`・`TMUX_PANE` を子プロセスの環境から除外し、`TMUX_TMPDIR` を空の一時フォルダの下にする。
テストのコードは既にこの分け方で、テストする `src/plugin/setup/` は `TMUX_TMPDIR` を受けて tmux を呼ぶため、`-L` / `-S` を渡すインターフェースを追加しない。
