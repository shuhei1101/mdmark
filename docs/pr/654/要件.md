# 要件

## 要望

廃止した `flow`・`sequence` の範囲の文字（ノードの `sub` など）に `--` があっても、`mdmark upgrade` が map の範囲へ書き換えた文書が点検に合格し、点検のずれで全ての変更をコピーから戻さない。

- 終了の条件: Issue の事象の文書（flow のノードの `sub` が `コンテナの中・--mcp-config`）を含む文書のフォルダへ `mdmark upgrade --yes` を適用すると、終了コード 0 で全ての範囲が map の範囲になり、補足の文字は元の `--` のまま描かれる
- 出したバージョン（v0.13.0・v0.14.0）の `migrations/` の配布物は書き換えない

修正方法: 点検（`src/map/data.ts`）が、HTML コメントの中にそのまま記載した `--` だけをずれにし、JSON の Unicode エスケープで記載した `--` は合格させる。変換（`src/map/convert.ts`）は今のまま、`--` をエスケープして書き出す。

変換の出力は既に HTML コメントを閉じない表記で、食い違っているのは点検の側だけのため。点検は upgrade を実行する CLI が持つため、出したバージョンの配布物を変えずに解消し、元の文字（`--mcp-config`）も変わらない。
