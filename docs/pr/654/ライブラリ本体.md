## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 補足の文字の値の点検 | HTML コメントの中にそのまま記載した `--` だけを `map_invalid_value` にし、JSON の Unicode エスケープで記載した `--` は合格させる | - |
| 描画 | 点検に合格した補足の文字は、解析した後の値（元の `--`）のまま描く | - |
| 移行の手順の配布物 | 出したバージョンの `migrations/v0.13.0/`・`migrations/v0.14.0/` は書き換えない | - |
| upgrade の戻し方 | 点検のずれがあればコピーから全て戻す今の設計は変えない | - |
