## 同じ記載を描く処理の洗い出し（#748）

### 洗い出しの結果

`src/` の mermaid 以外の部品（`*.part.ts`・`*.syntax.ts`・`*.interact.ts`・`src/render/`・`src/map/`）を、同じ名前の公開関数・「廃止」「今の書き方」「旧」を含む処理・図の種類ごとの差し替えの処理（`rewire`）で洗い出した。

| 箇所 | 中身 | 判定 |
| --- | --- | --- |
| [src/map/map.part.ts](https://github.com/shuhei1101/mdmark/blob/133b1da5/src/map/map.part.ts) の `spreadMapEnds` と [src/map/layout.ts](https://github.com/shuhei1101/mdmark/blob/133b1da5/src/map/layout.ts) の `portsOf` | 同じ点から出る・入る線の端を 16px ずらす処理が、クラス図・C4 図の `rewire` にだけあり、構成図・ER 図・状態遷移図・アーキテクチャ図は辺の中点 1 か所のまま（#767 の原因） | 寄せる。`spreadMapEnds` を `layout.ts` の `spreadWireEnds` に移し、全ての図で `separateWires` の前に適用する。クラス図・C4 図の `rewire` から外す |
| [src/render/legacy-marks.ts](https://github.com/shuhei1101/mdmark/blob/133b1da5/src/render/legacy-marks.ts) | マーカーの今の書き方を読む処理 | [#479](https://github.com/shuhei1101/mdmark/issues/479) が持つ（スコープ外） |
| [src/diagram/diagram.syntax.ts](https://github.com/shuhei1101/mdmark/blob/133b1da5/src/diagram/diagram.syntax.ts)・[src/map/convert.ts](https://github.com/shuhei1101/mdmark/blob/133b1da5/src/map/convert.ts) | 廃止した `flow`・`sequence`・`er` の範囲 | 描かずに記載の警告と `mdmark upgrade` の変換だけを持ち、描く処理が 2 つある箇所ではない |
| [vscode/src/export/html.ts](https://github.com/shuhei1101/mdmark/blob/133b1da5/vscode/src/export/html.ts) と [src/cli/html.ts](https://github.com/shuhei1101/mdmark/blob/133b1da5/src/cli/html.ts) | 書き出す HTML の組み立て | 前者は jsDelivr を読み込む HTML、後者は外へ要求しない 1 枚の HTML で、出力の目的が違う。#769 で埋める中身（描いた結果と純粋な Markdown）だけを揃える |
