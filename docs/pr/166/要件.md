# 要件

## 要望

長い文書を読む人が、今いる節を確かめながら目次から別の節へ移り、節の開閉を文書全体や入れ子の単位でまとめて行えるようにする。
`mount` で描く文書全般（使う側のページ・書き出した HTML・まとめた HTML・VS Code 拡張機能のプレビュー）に当てる。

<!-- table: data -->

| 項目 | 振る舞い |
| --- | --- |
| 右側の目次 | 描いた文書の右側に、文書の見出しの目次を出す。項目を押すとその見出しへ移る。`<!-- toc -->` のマーカーで本文の中に置く目次は今のまま残す |
| 目次の出し方 | 設定で `hover`（既定）と `fixed` から選ぶ。`hover` は文書の右端にポインターを置くと目次を出し、離すと消す。目次のピン止めのボタンを押すと、離しても出し続ける。`fixed` は三点リーダーのボタンを押すと、目次をサイドバーとして出し続ける |
| キーボードでの表示 | `hover` の目次は、キーボードのフォーカスが目次に入ったときも出し、フォーカスが外れると消す |
| 今いる節 | スクロールの位置で今読んでいる節を決め、右側の目次の中でその項目をハイライトする。スクロールするたびに追従する |
| 閉じた節の中の見出し | 右側の目次から閉じた節の中の見出しへ移るときは、外側の閉じた節を開き、選ばれていないタブの中ならそのタブを選んでから移る（URL の `#ID` で移るときと同じ） |
| H1 の節 | H1 の見出しも、H2〜H4 と同じく見出しを押して節を開閉できる。見出しの直後の `<!-- section: closed -->` / `<!-- section: open -->` も H1 に当てる |
| すべて展開・すべて折りたたむ | 文書の全ての節を開くボタンと、H1 の節を開いたまま H2 以下の全ての節を閉じるボタンを、右側の目次の上部にアイコンだけで置く |
| 入れ子をまとめて開閉 | Shift を押しながら節の開閉のボタンを押すと（キーボードの Enter・Space を含む）、その節と中の入れ子の節を全て同じ状態に開くか閉じる |
| 印刷 | 印刷では、右側の目次・すべて展開とすべて折りたたむのボタン・目次を出すボタンを出さない。閉じた節は今のとおり開いて出す |
| 狭い幅 | 描いた文書の幅が狭いときも、右側の目次が本文を読めなくするほど覆わない |
| 描き直しと片付け | `update` で描き直すと右側の目次を作り直し、`destroy` で取り除く |

<!-- /table -->

右側の目次は `features` の新しい機能 `side-toc` でオン・オフし、出し方は機能の名前と同じ綴りの新しいキー `side-toc.mode`（`hover` / `fixed`）で選ぶ。
右側の目次には h1〜h3 の見出しを載せる。

`side-toc` の機能をオフにした文書では、すべて展開・すべて折りたたむのボタンも無くなる。
