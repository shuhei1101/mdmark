## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 種類の判定 | Mermaid の 1 行目の `gantt`・`timeline`・`gitGraph`・`journey`・`block-beta` を map の種類にする。範囲の外のこの 5 種類のコードブロックも補足の無い map の図にする | マーカーは map のまま |
| 読み取り | 種類ごとに読み取りの処理を追加する。gantt はタスクの開始・終了・期間・`after` の依存・`section`・`dateFormat`、timeline は `section` と期間ごとの出来事、gitGraph は `commit`・`branch`・`checkout`・`merge`・`cherry-pick`、journey は `section` とタスクの点数・登場人物、block-beta は `columns`・幅 `:{数}`・`space`・入れ子の `block … end`・矢印を読む。読めない行は書き方の警告にする | - |
| 軸に沿った配置 | gantt は日付の軸、timeline・gitGraph・journey は記載順の軸に項目を並べる。入れ子の自動配置・木の配置とは別の配置の処理にする | 5 種類を 1 つの配置のモジュール（`src/map/axis-grid-layout.ts`）で種類ごとに配置する（モジュール構成設計） |
| 格子の配置 | block-beta は `columns` の列の数の格子に記載の順で配置し、幅と `space` で列を進め、入れ子は中の `columns` で格子を作り直す | - |
| 共通の部分 | 種類に依らない部分（補足の notes・巡回、拡大と縮小・凡例・ツールチップ・選択の状態の保存）を使用し、種類ごとの読み取り・配置・固有の機能だけを追加する | - |
| 開閉と中へ入る | gantt・timeline・journey の section と block-beta の入れ子のブロックを開閉し、中へ入るとその中だけを描き直す。戻る操作はグループの中へ入るときと同じ | 閉じた section・入れ子の見え方は確認ログのとおり（要件.md） |
| 選択と強調 | 項目を選ぶと、その項目と種類ごとのつながり（gantt の `after`・gitGraph の親の commit とブランチ・block-beta の矢印）を残し、ほかを薄くする | - |
| 再生 | gantt・timeline・gitGraph・journey は、案内の帯で記載順に 1 歩ずつ項目を強調する | 帯の手順のバー・速度は [#603](https://github.com/shuhei1101/mdmark/issues/603) の範囲 |
| 補足 | `notes` のキーは ID か表示する文字（commit は記載順の番号も）、section は名前にする。`layout` は色と `collapsed` だけを適用し、座標・並び順は書き方の警告にする。ドラッグしない | 同じ文字・同じ名前を指すキーは `map_ambiguous_ref` |
| 点検 | 補足が指す無い項目（`map_unknown_ref`）と、同じ文字の項目を指すキー（`map_ambiguous_ref`）を点検のずれにする | - |
| ノードのリンク | `mount` の設定に `id:` を URL に変える関数を追加し、map の flowchart の `click` の `id:` と本文の `[名前](id:...)` に適用する。`mapLinkProblems`・書き方の警告の文・点検を合わせ、`mdmark check` は `id:` をずれにしない | 確認ログ『map の flowchart の click の id: をどこで URL に変えるか』 |
| アクセシビリティ | 項目はほかの種類のノードと同じくキーボードで選べ、開閉のボタンに開閉の状態を持たせる | - |
| 既存機能への影響 | ほかの種類の読み取り・配置・描画は変えない。`id:` を変える関数を指定しない利用側では、ノードのリンクと本文のリンクの扱いを変えない | - |
