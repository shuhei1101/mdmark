### 要件

- map の範囲の Mermaid の 1 行目が `gantt`・`timeline`・`gitGraph`・`journey`・`block-beta` のとき、コードブロックのまま表示せず map の図にする
- map の範囲の外のこの 5 種類のコードブロックも、ほかの map が描ける種類と同じく、補足の無い map の図にする
- マーカー（`map`）・Mermaid のブロック・補足（`notes`・`layout`・巡回）の記載方法と、拡大と縮小・凡例・ツールチップの操作は、既存の種類と同じにする。
  種類ごとに追加するのは、読み取り・配置・種類に固有の機能だけにする
- gantt は日付の軸、timeline・gitGraph・journey は記載順の軸に沿って配置する。入れ子の自動配置（`src/map/layout.ts`）・木の配置（`src/map/mindmap-layout.ts`）とは別の配置の処理にする
- gantt・timeline・journey の section は開閉と中へ入るができ、gitGraph のブランチは選択で強調できる
- 4 種類は、案内の帯（シーケンス図・状態遷移図の再生と同じ帯）で記載順に 1 歩ずつ再生できる
- block-beta は `columns` の列の数の格子に記載の順で配置し、幅 `:{数}`・`space`・入れ子の `block … end`（入れ子の中の `columns` を含む）を読む。入れ子のブロックは開閉と中へ入るができる
- 項目を選ぶと、その項目と、種類ごとに決めたつながり（gantt の依存 `after`・gitGraph の親の commit・block-beta の矢印）だけを強調する
- 読めない行は、ほかの種類と同じく描画を止めずに書き方の警告にし、補足が指す無い項目は点検のずれにする
- 描けない種類の案内の文言（描ける種類の一覧）に 5 種類を加える
- map の flowchart の `click {ノード} "id:{ID}#{項目のパス}"`（`href` を挟む書き方を含む）は、`mount` の設定で利用側が指定した `id:` を URL に変える関数でノードのリンクにする。同じ関数を本文の `[名前](id:...)` にも適用し、関数が返した URL も本文のリンクと同じ許可で確認する。関数を指定しないときは今の書き方の警告のまま、`mdmark check` は `id:` のリンク先をずれにしない（確認ログ『map の flowchart の click の id: をどこで URL に変えるか』）
- 補足の `layout` は、軸と格子の配置の図でも色と閉じた状態（`collapsed`）だけを適用し、座標・並び順は書き方の警告にする。項目はドラッグで動かさない
- 補足の `notes` のキーと再生の帯は、ID を書いた項目を ID、書かない項目を表示する文字（commit の `msg`・期間と出来事の文・タスク名）で指し、`id:` も `msg` も無い commit は記載順の番号で指す。section は名前で指す。同じ文字の項目・同じ名前の section を指すキーは `map_ambiguous_ref` にする
- gantt の今日の線は Mermaid の `todayMarker` の指定に従い、指定が無ければ読者の端末の今日の日付に描き、`todayMarker off` で描かない
- `title` を持たない図の枠のタイトルは「ガントチャート」「タイムライン」「Git グラフ」「ジャーニー」「ブロック図」にする（確認ログ『title を持たない図の枠のタイトルに出す timeline・gitGraph・journey・block-beta の種類の名前』）
- 既存の種類と、map の範囲の外の mermaid のコードブロック（5 種類以外）の記載方法と描画は変えない

`未確定`: 閉じた section と中へ入った section の見え方（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 閉じた section は、gantt が section の名前とタスクの数を持つ 1 行の、最初の開始日から最後の終了日までの 1 本の棒、timeline が section の名前と期間の数を持つ期間 1 つ分の幅の箱、journey が点数の平均の高さの印 1 つで描く。中へ入った section は、3 種類ともその section の項目だけを配置し直してほかの section を描かず、パンくずに section の名前を出す。gantt の日付の軸はその section の期間に縮め、journey の点数の目盛りは変えない |
| B | 閉じた section も中へ入った section も、軸の幅は変えずにほかの section を薄くする |

推奨: A

中へ入る操作は、ほかの種類でも中だけを描き直す操作で、B は選択の強調と見分けが付かない。閉じた section は、日付の軸・点数の高さの意味を保ったまま 1 つにまとめる。

`未確定`: block-beta の閉じた入れ子のブロックの大きさと、ほかのブロックの列の位置（決める段: モック作成）

| 案 | 内容 |
| --- | --- |
| A | 閉じた入れ子のブロックは、記載した幅（`:{数}`）の 1 行の高さに縮め、中のブロックの数を出す。ほかのブロックの列の位置は変えない |
| B | 閉じた入れ子のブロックを 1 列の幅に縮め、後ろのブロックを左へ詰める |

推奨: A

列の位置が変わると、`columns` で並べた位置が崩れて別の図に見える。
