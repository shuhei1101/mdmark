## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 再現 | 要件の文書を `mount` で描く結合テストを先に作り、fail を確かめてから、リンクが落ちる箇所を特定する | テストは `tests/integration/` のブラウザのプロジェクトに置く |

| モジュール構成 | MOD-596-4 の手順 3 に `links` を渡す記載を追加し、MOD-472-133 の `renderMapClassDiagram` のテストにリンクを持つクラスのケースを追加する。特定した箇所のモジュール構成も合わせる | - |
