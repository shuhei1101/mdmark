# 要件

## 要望

言語 `mermaid` のコードブロック（`data-map-plain` の範囲）と map の範囲の `classDiagram` で、`click {クラス} href "{URL}"`・`link {クラス} "{URL}"` の行のクラスを、`mapLinkProblems` が許したリンク先だけ `a.mdmark-diagram-node-link` を持つノードにする。

終わりの条件:

- `mount` で描いた次の文書で、`.mdmark a[href="./doc-2"]` が 1 件見え、押すとリンク先へ移る（dev-docs の `body_mermaid_click_link` と同じ文書）

  ````markdown
  ```mermaid
  classDiagram
    class 受付
    click 受付 href "./doc-2"
  ```
  ````

- 許可しないリンク先（`javascript:` 等）のクラスはリンクを持たない
- flowchart のノードのリンクの描き方は変えない

## 現状の確認

develop（27f48163）で確認した結果。

| 経路 | 結果 |
| --- | --- |
| `attachMapClass` を直接呼ぶ（`tests/unit/src/map/class-view.browser.test.ts` と同じ準備） | 受付のノードが `a.mdmark-diagram-node-link[href="./doc-2"]` を持つ。`renderMapClassDiagram` は `...args` で `links` を構成図の部品へ渡している |
| ストーリー `linked-class`（`tests/integration/lib/map-class.story.test.ts` の `test_linked_class`） | 部品の HTML ではリンクになる |
| `needsMermaidFallback`（`kind: classDiagram`、上の文書） | `false`（mermaid のライブラリへ切り戻さない） |
| `mount` で純粋な Mermaid のコードブロックを描く | 単体テストの環境では map が付かず確かめられなかった |

Issue 本文が原因に挙げた「`renderMapClassDiagram` が `links` を参照しない」は、develop では当たらない。
リンクが落ちる箇所は `mount` から `attachMap`・`attachRange`・`attachMapClass` へ渡る経路にあり、実装の工程で、純粋な Mermaid のコードブロックを `mount` で描く結合テストで再現してから特定する。
