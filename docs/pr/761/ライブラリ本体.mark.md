## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 再現の確認 | 縦・横・斜め・グループをまたぐ・多数の線が 1 つのノードに集まるの 5 つの配置を、構成図と ER 図で描き、線の端の辺とノードの上を通る区間を確かめる | 再現しない場合は起点 Issue へ報告して作業 PR を閉じる |
| 端の辺の選び方 | 補足の `ends`・Mermaid の辺の指定が無い端は、相手のノードの中心の向きの辺を優先し、ふさがっているときだけ残りの辺で経路が短い辺にする | `portsOf` で 4 つの辺を同じ扱いにしている箇所を直す |
| ノードを避ける経路 | 両端とその祖先のグループ以外のノードの矩形を通らない | 再現したパターンの原因に合わせて直す |
| ER 図 | 関連の端を列の行の高さへ付け替えた後も、近い側の辺につながり、ほかのテーブルの上を通らない | `rewireMapEr` |
| 単体テスト | 5 つの配置ごとに、端の辺とノードの上を通らないことを確かめる | - |
| 結合テスト | 『文書を描く』の map の図で、線の端の辺とノードを避ける経路を確かめる | - |
