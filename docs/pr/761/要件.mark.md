# 要件

## 要望

map の構成図の部品の上に描く図（構成図・ER 図・状態遷移図・クラス図・アーキテクチャ図・C4 図）で、ノードをつなぐ線を次の形で引く。

- 線の端は、相手のノードに近い側の辺につながる。補足の `ends`・Mermaid の辺の指定がある端は、指定の辺のままにする
- 線は、両端のノードとその祖先のグループ以外のノードの上を通らない
- ER 図で関連の端を列の行の高さへ付け替えた後も、上の 2 つを満たす

進め方は、ノードの配置のパターン（縦に並ぶ・横に並ぶ・斜め・グループをまたぐ・多数の線が 1 つのノードに集まる）を図の種類ごとに用意して今の経路を確かめ、上の形にならないパターンを直す。どのパターンでも再現しない場合は、確かめたパターンと結果を起点 Issue へ報告して、作業 PR を閉じる。

「近い側の辺」は、相手のノードの中心から見た向き（上下・左右のうち差が大きい方）の辺とする。その辺がほかのノードやグループの枠でふさがっているときは、残りの辺のうち経路が短い辺にする。

ER 図は、端を列の行の高さにつなぐため、「近い側の辺」を左右の辺のうち相手のテーブルの中心に近い方の辺とする。横の中心の差が無いときは、両端とも右の辺にする。
