# map の図の接続線を、ノードの近い辺につなぎ、ほかのノードを避けて通す

## 概要

map の図を読む利用者が、ノードどうしをつなぐ線を、近い辺につながりほかのノードを避けて通る形で読めるようにする。

## 背景

[Issue #754](https://github.com/shuhei1101/mdmark/issues/754) の要望。ER 図・フローチャートなどの map の図で、線がノードの近い辺ではなく遠い辺につながることと、ほかのノードの上を通ることがある。どの資料の図かの記録は無く、今の版で残っているかは確認していないため、ノードの配置のパターンごとの再現の確認から始める。

線の経路は `src/map/layout.ts` の `routeEdges` が、ノードの上下左右の 4 つの辺の出口から格子の経路探索で引く。ER 図は同じ経路の後に、関連の端を列の行の高さへ付け替える（`src/map/map.part.ts` の `rewireMapEr`）。[#613](https://github.com/shuhei1101/mdmark/issues/613) は複数の線が同じ通り道に重なるのをずらす対応で、つながる辺の選び方とノードの上を通る経路は対象にしていない。
