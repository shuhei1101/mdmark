## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| map の図で薄くした要素 | `.map-dim`・`.map-focus` の強調しない要素・`.map-faded` の文字を `opacity` で薄くせず、`color-mix(in srgb, var(--mdmark-color-text) 68%, var(--mdmark-color-bg))` にし、ノード・グループ・線のラベル・多重度の枠と面も背景の色と混ぜる。文字を持たない線・ライフライン・関係の端は `opacity: 0.25` のまま。ER 図・状態遷移図・クラス図・シーケンス図の `.map-dim` も同じ薄め方にする | 合意したモックは `docs/mock/refs/707/assets/dim-contrast.css` の案 B。実装の工程で `src/index.css` と、共有のモックの CSS（`refs/445`・`refs/531`・`refs/596`）へ反映する |
| CSS 変数 `--mdmark-map-dim-opacity` | 薄め方に合わせて部品設計 CMP-472-5 の記載を変える。変数を残すか・既定値を変えるかは部品設計で決める | 公開の CSS 変数のため、名前は変えない |
| 列の幅のつまみの ARIA の値 | `updateValues` が `aria-valuemin <= aria-valuenow <= aria-valuemax` を常に満たす値を入れる | 上限を今の幅・最小の幅とどう比べて決めるかはインターフェース定義設計で決める |
| アクセシビリティ | axe の `color-contrast`・`aria-valid-attr-value` が 1280x800・390x844 で出ないことを結合テストで確認する | - |
