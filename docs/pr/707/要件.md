# 要件

## 要望

子 Issue ごとの終了の条件（束の親 Issue [#706](https://github.com/shuhei1101/mdmark/issues/706) の本文からコピーした）。

| Issue | 終了の条件 |
| --- | --- |
| [#678](https://github.com/shuhei1101/mdmark/issues/678) | `docs/mock/refs/445/assets/map-mock.css` と `src/index.css` の `.map-dim`・`.map-focus` の強調しない要素・`.map-faded`（ER 図・状態遷移図・クラス図の `.map-dim` を含む）の文字のコントラストが 4.5:1 以上になり、axe の `color-contrast` が 1280x800・390x844 で出ない。部品設計 CMP-472-5 と結合テスト（axe）を合わせる |
| [#686](https://github.com/shuhei1101/mdmark/issues/686) | `src/table/table-resize.interact.ts` の `updateValues` が `aria-valuemin <= aria-valuenow <= aria-valuemax` を常に満たす値を入れ、axe の `aria-valid-attr-value` が 1280x800・390x844 で出ない。IF-472-35・CMP-472-61・MOD-472-226 と単体・結合テスト（axe）を合わせる |

#678 は、モックの ER 図・状態遷移図（`docs/mock/refs/531/assets/er-state.css`）とクラス図（`docs/mock/refs/596/assets/class-arch-c4.css`）の `.map-dim` も同じ型のため、同じ薄め方にする。
確認する画面は、[#677](https://github.com/shuhei1101/mdmark/pull/677) で追加した `docs/mock/components/map-c4-dynamic-play/index.html` の状態の見本と、`docs/mock/components/map-class-arch-c4/index.html`・`docs/mock/components/map-c4-kinds/index.html` の「配置図（配置先のノードの中）」。

#686 は、モックの `docs/mock/refs/449/assets/table-resize.js` の `aria-valuemax` も同じ型のため、同じ値の決め方にする。

薄くした要素の文字は `opacity` で薄くせず、本文の文字色と背景の色を 68% : 32% で混ぜた色にし、ノード・グループ・線のラベル・多重度の枠と面も背景の色と混ぜて薄く見せる。
文字を持たない線・ライフライン・関係の端の形状は、今の `opacity: 0.25` のまま薄くする（[確認事項](https://github.com/shuhei1101/mdmark/pull/707#discussion_r4629470732)で案 B に決定）。
