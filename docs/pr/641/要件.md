# 要件

## 要望

`tools/eslint/eslint.config.js` の複雑さの規則のまとまりの `files` に `tests/**/*.{ts,tsx}`・`vscode/tests/**/*.{ts,tsx}` を追加し、`src/` などと同じ 4 規則（`complexity: 10`・`max-depth: 4`・`max-params: 3`・`sonarjs/cognitive-complexity: 15`）をテストコードにも error で適用する。

- `npm run lint:eslint` が、テストコードを含めて違反 0 件・終了コード 0 で終わる
- origin/develop（[e2d0e7d8](https://github.com/shuhei1101/mdmark/commit/e2d0e7d88db58a00b297bff6934c8a20b505fe57)）で 4 規則だけを `tests/`・`vscode/tests/` に適用した違反は 32 ファイルで 53 件（complexity 48・max-params 3・cognitive-complexity 2）。これをテストの検証内容を変えずに修正する
  - 違反は `tests/unit/`・`tests/integration/`・`vscode/tests/integration/` にあり、`tests/` の直下（`tests/git-env.ts`・`tests/migrations-dir.ts`）と `tests/fixtures/` には無い
- 違反を `eslint-disable` のコメントで除外しない（MOD-472-41 の「外部が引数を決めるコールバック」と同じ扱い）
- 修正したテストは、修正する前と同じケースで pass する
