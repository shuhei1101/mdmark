# 要件

## 要望

origin/develop の次の画像を、削除の commit で取り除く（履歴は書き換えない）。

| 対象 | 件数 | 容量 |
| --- | --- | --- |
| `docs/pr/*/スクリーンショット/` | 3,247 件 | 約 203MiB |
| `docs/pr/*/ストーリー/` | 479 件 | 約 9.4MiB |

削除した後、origin/develop と比べて `git ls-tree -r origin/{作業ブランチ} -- docs/pr` に `スクリーンショット/`・`ストーリー/` の下のファイルが 0 件で、それ以外のファイルの増減が無いこと。
