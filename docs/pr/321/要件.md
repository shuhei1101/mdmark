# 要件

## 要望

依存の `sanitize-html` を 2.18.0 から 2.18.1 に上げ、次の勧告を解消する。

| 勧告 | 深刻度 | 該当範囲 | 内容 |
| --- | --- | --- | --- |
| [GHSA-c9rx-x947-fp3h](https://github.com/advisories/GHSA-c9rx-x947-fp3h) | moderate | >=2.18.0 <2.18.1 | 除外した iframe の fallback を再サニタイズするときに再帰が無制限になり、スタックオーバーフローする（`nestingLimit` が効かない）。mdmark は `iframe` を許可しないため除外の対象になり、該当する |

終わりの条件:

- `package.json` の `sanitize-html` が `2.18.1`（完全一致）で、`package-lock.json` の `node_modules/sanitize-html` が 2.18.1 を指す
- 外部ライブラリの設計書『sanitize-html』の `version`・`catalogs[].version`・`purl`・`install` が 2.18.1 を指す
- 単体テスト・結合テスト・lint・型検査が全て通る
- `npm audit` で sanitize-html の勧告が出ない
- 影響するユースケースの `実行のみ` の行の E2E が release で通る
