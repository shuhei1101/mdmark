# 要件

## 要望

| No | 対象 | 終わりの条件 |
| --- | --- | --- |
| 1 | [開発コマンド](https://github.com/shuhei1101/mdmark/blob/develop/docs/dev-command/CMD-472-1.yaml) の拡張機能のタグの手順 | `vscode-v{バージョン}` のタグのワークフローが success で終わった後、Marketplace の一覧にそのバージョンが出るまで数分〜十数分かかることと、公開の確認は一覧にバージョンが出るまで条件で待ってから行うことが記載されている |
| 2 | 同じ手順の公開の確認 | 待ちの上限（と問い合わせの間隔）が、規約『資源の値の決め方』で観測値（公開から一覧に出るまで約 11 分）から導いた値と導出で記載されている |
| 3 | 同じ手順の公開の確認 | 確認を回し直すときの判定が記載されている。タグが存在し、そのバージョンが公開済みなら済んだ状態として飛ばし、タグが無いのに公開済みのときだけ失敗にする |
| 4 | [vsce の外部ライブラリの設計書](https://github.com/shuhei1101/mdmark/blob/develop/docs/library/LIB-472-34.yaml) の `vsce publish` | 公開が終わっても Marketplace の一覧に出るまで数分〜十数分かかる（`Extension URL (might take a few minutes)`）ことが記載されている |
| 5 | [拡張機能の配布物を作る](https://github.com/shuhei1101/mdmark/blob/develop/docs/scenario/SC-472-50.yaml) の正常シナリオ | Marketplace の最新のバージョンが変わるのはワークフローの完了から一覧に出るまで待った後であることが、期待する結果に記載されている |
