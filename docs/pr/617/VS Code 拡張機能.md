## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 拡張機能のタグの手順 | ワークフローの完了の後、Marketplace の一覧にバージョンが出るまで条件で待ってから公開を確認する手順を記載する | 待ちの上限と間隔は規約『資源の値の決め方』で観測値（約 11 分）から導き、導出を添える |
| 公開の確認の回し直し | タグがあり公開済みなら済んだ状態として飛ばし、タグが無いのに公開済みのときだけ失敗にする判定を記載する | - |
| `vsce publish` の説明 | 公開が終わっても一覧に出るまで数分〜十数分かかることを記載する | - |
| 正常シナリオの期待する結果 | 最新のバージョンが変わるのは一覧に出るまで待った後であることを記載する | - |
