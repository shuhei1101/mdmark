## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| HTML の表示 | 印を付けた `html` のコードブロックの中身を、今の生の HTML と同じサニタイズを通してその場に描く。印の無いコードブロックはコードのまま出す | 印は `<!-- html -->`〜`<!-- /html -->`（[要件](./要件.md)）。中身の要素の `style` は、レイアウト・余白・枠・色・文字の宣言だけを残し、`url(`・`vw`・`vh`・`position` を落とす（[確認ログ](./確認ログ.md)） |
| スクリプト | `script` 要素とイベントの属性は今のサニタイズのとおり落とし、動くのは mdmark の部品だけにする | D-22 |
| チャート | 埋め込んだ HTML の中の図の部品の custom element（`<mdmark-chart>` など）の中身の JSON を部品の定義として読み、#21 の SVG のグラフの部品で描く。グラフの定義に種類（折れ線・棒・円・散布図）を足し、縦の軸の範囲を省いたときは 1・2・5×10 のべき乗の刻みで自動で切る | 外部ライブラリは使わない（ライブラリ選定で決めた） |
| チャートの操作 | チャートを #21 の図の枠に載せ、右上のボタンとキーの `+`・`-`・`0` の拡大・縮小・ドラッグでの移動・ホイールのスクロールを同じにする。部品でない HTML は図の枠に載せない。全ての図の枠で戻すのボタン（`rotate-ccw`）をなくし、倍率の表示をボタンにして、押すと開いたときの倍率と位置に戻す。読み上げの名前は `倍率 {今の倍率}。全体が収まる倍率に戻す` | D-43・[確認ログ](./確認ログ.md) |
| ヒント | `data-hint` を持つ要素と、部品の定義の `hint`・`io` に、#21 の図のツールチップと同じ部品のツールチップを付ける。機能 `hints`（既定はオン）をオフにすると、`data-hint`・`hint`・`io`・線の詳細のツールチップをまとめて外す | 機能のオン・オフは設定の `features` と文書の印の今の仕組みに載せる |
| 用語のツールチップ | 埋め込んだ HTML の中の文字にも、用語の下線と用語・関連資料のツールチップを付ける。チャートのキャンバスの中の文字は対象にしない | D-45 |
| 機能のオン・オフ | HTML の表示とヒントを `features` の機能として足し、文書の印で上書きできる今の仕組みに載せる | オフのときはコードブロックのまま出す |
| 書き出し | 埋め込んだ HTML とチャートを `mdmark export`・`build` の 1 枚に描き、外を読まずに動かす | 配布物が描くため、足す埋め込みは無い |
| 印刷 | 埋め込んだ HTML とチャートを印刷に出し、ツールチップと拡大・縮小のボタンは出さない | - |
| アクセシビリティ | ツールチップは `role="tooltip"`・`aria-describedby` でホバーとフォーカスの両方で出し、Esc で消える。チャートは読み上げの名前を持つ | #21 の図のツールチップと同じ |
| 非機能要件 | チャートの種類を足した配布ファイル 1 つのサイズが、今のビルドの上限（`MAX_DIST_FILE_BYTES`）の検査に通ることを確かめる | develop の `dist/index.js` は上限まで約 26 KB の余り |
