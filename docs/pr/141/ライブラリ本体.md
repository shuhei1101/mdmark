## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 常駐サーバーの起動の入口 | 要件の `未確定`（推奨 A）のとおり、CLI に `serve` を加え、前面で MCP サーバーを待ち受ける。止めるときは Ctrl+C（SIGINT）か SIGTERM で待ち受けを閉じて 0 で終わる | `未確定`（決める段: 単一ユースケース設計）。B に決まったら、この計画書の行は外す |
| ポートの確認 | 起動したときに待ち受けたアドレスとポートを標準出力に 1 行出す | 文言はインターフェース定義設計で決める |
