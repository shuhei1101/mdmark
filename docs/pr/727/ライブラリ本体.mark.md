## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 文字の幅の測り方 | 1 つの表の測る全てのセルの行・半角の単語の計測用の要素を先に全て配置し、幅をまとめて取得し、最後にまとめて取り除く。要素の配置と幅の取得を交互にしない | モジュール構成設計（MOD-472-347）で案 A に決定 |
| 見出しのセルの中身の幅 | 見出しの計測用の要素も、本文のセルの計測と同じまとまりで配置して取得する | ピン止めのボタンの出し入れで見出しだけを測り直す処理も、全ての列の見出しをまとめて測る |
| セルの余白と罫線 | セルごとの `getComputedStyle` は残し、計測用の要素を配置する前にまとめて取得する（取得の間に要素を書き換えないため、スタイルの計算は 1 回で済む） | セルごとに読むことで、今の幅と同じ結果を保つ |
| 列の幅の結果 | `--mdmark-auto-width`・`--mdmark-auto-table-width`・`--mdmark-column-head-width` の値を今のとおりにする | 差は 1px 以内 |
| 性能 | 表 16 個・本文のセル 480 個の文書で、`mount` を呼んでから全ての表の列の幅を決定するまでの時間を、非機能要件 NFR-13（1,000 ミリ秒）に収める | 今の実装は 1,600〜2,444 ms（NFR-472-1 の `verification`） |
| 既存機能への影響 | 隠した列を後から測る・ピン止めのボタンの出し入れで測り直す・見える幅が変わったときに決め直す振る舞いは変えない | - |
