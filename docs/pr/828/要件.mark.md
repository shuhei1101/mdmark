# 要件

## 要望

document に取り付ける前の要素へ `mount`（`features.table: true`）で描いた表でも、取り付けた後と表の見える幅が変わった後に、列の幅のつまみの `aria-valuemin`・`aria-valuenow`・`aria-valuemax` を有限の数（px の整数）で入れ、`aria-valuemin` ≤ `aria-valuenow` ≤ `aria-valuemax` を満たす。

- 取り付けた後、つまみにフォーカス・ホバーする前から、全ての列のつまみが上の条件を満たし、axe-core の `aria-valid-attr-value` が出ない
- 取り付けた後に窓の幅を変えても、全ての列のつまみが上の条件を満たす
- 配置の無い時点（取り付ける前・`display: none` の中）でも、つまみの値に `NaN` を入れない
- 2 列以上の表で、フォーカスした列だけでなく全ての列のつまみが条件を満たす
