## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| アクセシビリティ（値） | 配置の無い時点でも、つまみの `aria-valuemin`・`aria-valuenow`・`aria-valuemax` に有限の数を入れる（余白・罫線の計算値が数にならないときは 0 として数える） | `min ≤ now ≤ max` を保つ今の決まりは変えない |
| アクセシビリティ（時点） | 表の見える幅が 0 から変わったとき（取り付けた後）と、見える幅が変わって列の幅を決め直した後に、全ての列のつまみの値を更新する | きっかけを `table-width.interact.ts` の `apply` の後にするか、つまみ側で見える幅を監視するかはモジュール構成設計で決める |
| 既存機能への影響 | 配置のある表で描いた直後・フォーカス・操作の後に入れる値は今のまま | 表のカスタム要素（`<mdmark-table>`）も同じ処理を使う |
