# 要件

## 要望

`tools/eslint/eslint.config.js` の複雑さの 4 規則（`complexity: 10`・`max-depth: 4`・`max-params: 3`・`sonarjs/cognitive-complexity: 15`、いずれも error）を、次の TypeScript に適用する。

| 範囲 | 補足 |
| --- | --- |
| `src/**/*.ts` | ライブラリ本体 |
| `scripts/**/*.ts` | ビルドと検査のスクリプト |
| `vscode/src/**/*.ts`（`vscode/src/webview/` を除く） | VS Code 拡張機能のホスト側 |
| `plugin/**/*.ts` | develop には無い。配置されたときに検査に入る |

終わりの条件は次のとおり。

- 引数なしの `npm run lint:eslint` が、上の範囲と Webview を検査し、違反 0 件・終了コード 0 で終わる
- 違反は関数を分けて修正し、`eslint-disable` のコメントで除外しない。分け方は規約『設計原則』の SLAP と cognitive complexity で判断する
- 公開関数・CLI・MCP のツール・設定の挙動を変えない。既存の単体・結合テストが全て pass する
- Webview だけの規則（React・アクセシビリティ・import の向き・Tailwind・記載方法・型の情報を使用する規則）は、今と同じく Webview だけに適用する
- 設計書『ライブラリ本体 / 検査』『ライブラリ本体 / 検査 / eslint.config.js』と、テスト実行方法の `lint` 層の説明を、広げた範囲に合わせる
