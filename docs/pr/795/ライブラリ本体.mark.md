## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 複合 UC | アプリの画面が配布物を `@0` で読み込み、`<mdmark-table>` に列の定義と行のデータを指定し、表を操作してイベントで保存・詳細を開く流れを新規の複合 UC にする | - |
| 単一 UC | `<mdmark-table>` で表を描き、操作をイベントで受け取る単一 UC を新規に作る。『配布物を読み込む』に `@0` の範囲の指定で読み込む場合を追加する | - |
| データ | 列の定義と行のデータの構造を、データの設計書に新規で記載する（表のマーカーの設定と同じキーの名前に統一する） | 利用者の確認が要る（データの構造） |
| インターフェース | タグの名前・プロパティ・属性・イベントの名前と `detail`・セルの中身の差し替え方・引数の誤りのときの扱いをインターフェース定義に新規で記載する | - |
| 表の機能 | 並べ替え・絞り込み・ピン止め・列の表示・列の並べ替え・列の幅の変更・長い文字の折り返しは、今の `src/table/` の処理を再利用し、Markdown の表と同じ外観にする | 同じ処理を 2 つ持たない |
| 編集・追加 | 表の部品がセルの入力欄と「行追加」のボタンを描き、確定した値をイベントで通知する | [要件](./要件.mark.md) の決定のとおり |
| 部品設計 | 部品設計『表』に、行のデータから描いた表の状態と、行の押下・セルの編集・行の追加の状態とイベントを追加し、Storybook のストーリーを追加する | - |
| 配布 | カスタム要素は今の配布物（`dist/index.js` か、その隣に分けたモジュール）から登録する。分けるかはモジュール構成設計で決定する | - |
| ほかの部品 | カスタム要素の登録の処理を部品ごとに追加できる構造にする | 表のほかのカスタム要素はこの PR で作らない |
| 既存機能への影響 | `mount`・`render`・`mountView`・`mountComments`・Markdown の表の外観と操作を変えない | 単一 UC『表を操作する』『部品をJavaScriptから使用する』の E2E で確認する |
| セキュリティ | 列名と行の値は文字として出し、HTML として解釈しない | - |
| アクセシビリティ | 行の押下・セルの編集・行の追加をキーボードで操作できる | - |
| ガイド | 使用方法のページを `docs/guide/` に新規で作り、リファレンスの API と用語集に追加する | 索引の行は [Claude Code プラグイン](./ClaudeCodeプラグイン.mark.md) |
