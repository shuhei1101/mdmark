## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 手順のバー | 案内・再生のバーに、手順の数だけ区切ったバーを配置し、済んだ手順・今の手順・残りの手順を描き分け、今の手順を自動で進める間隔に合わせて塗る | 見た目はモックで決める |
| 手順の移動 | 区切りを押すとその手順へ移る。区切りはキーボードで選べ、スクリーンリーダー向けに手順の番号とタイトルを持つ | 手順が多く区切りが狭いときの扱いはモックで決める |
| 再生の種類と速度 | 自動で進めるを、この手順だけの再生（今の手順を 1 回流して止まる）と全ての手順の再生に分け、速度の倍率を選べる | 速度は帯で 0.5 倍・1 倍・2 倍から選び、マーカーの引数は追加しない |
| なめらかな移動 | 手順を進めたときに、強調するノードを囲む矩形が表示する枠に収まる倍率と位置へ、拡大・縮小の処理で時間をかけて移す。倍率は図の枠に合わせた倍率以上・読者の拡大の上限以下にし、囲む範囲の周りに余白を残す。読者が図の枠を触ったら次に帯を操作するまで移さない | 動きを減らす設定では時間をかけずに移す。この作業 PR で扱うかは `未確定`（要件.md） |
| C4 の種類の判定 | Mermaid の 1 行目の `C4Container`・`C4Component`・`C4Dynamic`・`C4Deployment` を map の種類にし、範囲の外のコードブロックも補足の無い map の図にする | - |
| C4 の読み取り | `C4Context` の読み取りを広げ、4 種類の要素・境界・`C4Dynamic` の番号つきの関係（`RelIndex` を含む）・`C4Deployment` の配置先のノードを読み取る。読めない行は書き方の警告にする | - |
| C4 の描画 | 要素は種類の行・名前・技術・説明を持つノード、境界は破線のグループ、配置先のノードは実線のグループにし、外部の要素は `C4Context` と同じく灰色の面で描き分ける。`C4Dynamic` の関係のラベルに記載の順の番号を出す（`RelIndex` の第 1 引数は Mermaid と同じく読まない） | - |
| 補足 | 4 種類でも `notes`・`layout`・案内・ドラッグを `C4Context` と同じに使用できる | - |
| アクセシビリティ | 手順のバーの区切りと再生の種類・速度の操作はキーボードで操作でき、スクリーンリーダー向けの名前と状態を持つ | - |
| 既存機能への影響 | 前へ・次へ・停止、マーカーの引数 `interval`・`play`、読者の拡大・縮小・移動の操作は今の振る舞いを保つ。`C4Context` の描画は変えない | - |
