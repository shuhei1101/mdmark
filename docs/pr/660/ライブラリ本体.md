## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 手順のバー | 案内・再生の帯を、手順の数だけ区切ったバーと手順のタイトル・説明の文だけにし、番号・停止と再生のボタン・速度を置かない。バーの左右に前・次の手順へ移る矢印を常に出す。何もしていないときは帯の枠線と面を出さず、バーと矢印だけを出す。バーは 1 行で区切りを幅に合わせて細くし、区切りが 12px より細くなったときだけ今の区切りを 24px に広げる。済んだ手順・今の手順・残りの手順を描き分け、再生している手順の区切りを 1 周の間に合わせて塗る | 確認ログ『案内・再生の帯をバーだけにするか』『帯のモックの修正』『手順が多いときの対策』 |
| 手順の移動と再生 | 区切りか左右の矢印を押すと、その手順へ移り、停止するまでその手順を繰り返し再生する。同じ区切りをもう一度押すと、その手順の最初から再生し直す。帯のバー以外と図の空いた場所を押すと停止する（4px 以上動かしたらドラッグとして止めない）。バーは 1 つのスライダーで、← → で前後の手順へ移って再生し、Esc で停止する。矢印のボタンを押した後はそのボタンにフォーカスを残す | 1 つの手順の 1 周の時間はモジュール構成設計で決める。確認ログ『帯のモックの修正』 |
| 自動で進めるの廃止 | 帯の自動で進めると、マーカーの引数 `play`・`interval` を廃止する。既存の文書の `play`・`interval` は書き方の警告と点検のずれにし、`migrations/next/` に引数を削除する移行の手順を置く | 破壊的変更。確認ログ『連続再生の廃止に…』。既存の文書のマーカーから引数を削除するため移行の手順が要る |
| なめらかな移動 | 手順へ移したときに、強調するノードを囲む矩形が表示する枠に収まる倍率と位置へ、拡大・縮小の処理で時間をかけて移す。倍率は図の枠に合わせた倍率以上・読者の拡大の上限以下にし、囲む範囲の周りに余白を残す。読者が図の枠を触ったら次にバーを押すまで移さない | 動きを減らす設定では時間をかけずに移す。この作業 PR で扱う |
| C4 の種類の判定 | Mermaid の 1 行目の `C4Container`・`C4Component`・`C4Dynamic`・`C4Deployment` を map の種類にし、範囲の外のコードブロックも補足の無い map の図にする | - |
| C4 の読み取り | `C4Context` の読み取りを広げ、4 種類の要素・境界・`C4Dynamic` の番号つきの関係（`RelIndex` を含む）・`C4Deployment` の配置先のノードを読み取る。読めない行は書き方の警告にする | - |
| C4 の描画 | 要素は種類の行・名前・技術・説明を持つノード、境界は破線のグループ、配置先のノードは実線のグループにし、外部の要素は `C4Context` と同じく灰色の面で描き分ける。`C4Dynamic` の関係のラベルに記載の順の番号を出す（`RelIndex` の第 1 引数は Mermaid と同じく読まない） | - |
| 補足 | 4 種類でも `notes`・`layout`・案内・ドラッグを `C4Context` と同じに使用できる | - |
| アクセシビリティ | 手順のバーはスライダーとしてキーボードで操作でき、今の手順の番号とタイトルを読み上げの値で持つ | - |
| 既存機能への影響 | 読者の拡大・縮小・移動の操作は今の振る舞いを保つ。`C4Context` の描画は変えない。帯のボタンと自動で進める・`play`・`interval` は廃止する | - |
