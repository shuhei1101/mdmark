## 要望

### 要件

- 案内（構成図）と再生（シーケンス図・状態遷移図・時系列の図）の帯を、手順の数だけ区切った手順のバーと、手順のタイトル・説明の文だけにする。前へ・次へ・番号・停止と再生のボタン・速度の切り替えは置かない（確認ログ『案内・再生の帯をバーだけにするか』）。何もしていないときは、帯の枠線と面を出さずバーだけを出す
- 手順のバーは済んだ手順・今の手順・残りの手順を描き分け、再生している手順の区切りを 1 周の間に合わせて塗り、塗り終えたら最初から塗り直す
- バーの区切りを押すと、その手順へ移り、停止するまでその手順を繰り返し再生する。同じ区切りをもう一度押すと、その手順の最初から再生し直す
- 帯の中のバー以外の場所と、図の枠の中のノード・線・ボタン以外の空いた場所を押すと停止する（4px 以上動かしたらドラッグとして止めない）（確認ログ『「バー以外をタップで停止」の範囲』）
- キーボードでは、バー（スライダー）にフォーカスして ← → で前後の手順へ移って再生し、Esc で停止する
- 全ての手順を続けて再生する機能（帯の自動で進める）と、マーカーの引数 `play`・`interval` は廃止する。既存の文書の `play`・`interval` は書き方の警告と点検のずれにし、版を上げる移行の手順で削除する（破壊的変更。確認ログ『連続再生の廃止に、今ある自動で進める機能とマーカーの引数 play・interval を含めるか』）
- 手順へ移したときに、その手順で強調するノード（参加者・線の両端を含む）が表示する枠に収まる位置と倍率へ、図をなめらかに移す。読者が図の枠を触った後は、次にバーを押すまで移さない
- なめらかな移動はこの作業 PR で扱い、子の Issue に分けない
- 動きを減らす設定（`prefers-reduced-motion: reduce`）では、なめらかな移動をせずにその位置と倍率へ移す
- 見た目は DynamicArchitectViewer に合わせず、モックで決める
- map の範囲の Mermaid の 1 行目が `C4Container`・`C4Component`・`C4Dynamic`・`C4Deployment` のとき、`C4Context` と同じ読み取りと描画で map の図にする。範囲の外のこの 4 種類のコードブロックも、`C4Context` と同じく補足の無い map の図にする
- 要素の種類（`Container`・`ContainerDb`・`ContainerQueue`・`Component`・`ComponentDb`・`ComponentQueue` と、それぞれの `_Ext`）・境界の種類（`Container_Boundary` など）・`C4Dynamic` の番号つきの関係・`C4Deployment` の配置先のノード（`Deployment_Node`・`Node` など）を読み取る
- 4 種類の図でも、中へ入る・開閉・選択・案内・ドラッグ・補足の `notes`・`layout` を `C4Context` と同じに使用できる。読めない行は描画を止めずに書き方の警告にする
- 描けない種類の案内の文言（描ける種類の一覧）に 4 種類を加える
- 既存の種類の記載方法と描画は、帯の操作と `play`・`interval` の廃止のほかは変えない
