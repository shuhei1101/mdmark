# 要件

## 要望

Sprint v0.10.0 の E2E（release の [4bb3708b](https://github.com/shuhei1101/mdmark/commit/4bb3708be49be0d95be47b793f54e5d07e412fad)）で fail した単一ユースケース『表を操作する』の次の 9 件を、release で pass させる。
修正は release ブランチ `release/v0.10.0` へ入れる。
release の [4d5568c4](https://github.com/shuhei1101/mdmark/commit/4d5568c462d098a65a7beb5a0b01e18951c0ad00) で 9 件とも同じ内容で fail することを手元の chromium で確認した。

終わりの条件は、上の 9 件が release の今の配布物で chromium と firefox の両方で pass し、同じ spec の他のケースが fail しないこと。

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `src/interact/tables.ts` の `SORT_CYCLE` と、`filter=` の列だけに絞り込みのボタンを配置する処理 | [a6e0aad8](https://github.com/shuhei1101/mdmark/commit/a6e0aad8)（`HTML コメントの印で表・注意書き・タブなどの表示を付ける拡張記法を作る (#19)`） | 並べ替えを降順から回し、絞り込みは `filter=` で指定した列にだけ付ける | 1 回 | 後から追加したテスト（#275・#283・#307・#303）が、昇順から回る・全ての列に絞り込みが付く前提で記載されている。実装は変えず、テストとシナリオの準備を合わせる |
| `src/interact/tables.ts` の `SCROLL_CLASS`（表を包む横スクロールの要素） | [95957699](https://github.com/shuhei1101/mdmark/commit/95957699)（`描いた文書の表示を改善する（…表の幅…） (#308)`） | 表を本文の幅に広げ、はみ出す表だけを包む要素の中で横にスクロールさせる | 1 回 | 先に入った #283 のピン止めのテストは表そのものをスクロールさせていて、#308 で横にスクロールする要素が変わったのに追従していない。同じ問題を修正し続けてはいない |
