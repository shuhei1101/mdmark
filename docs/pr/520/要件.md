# 要件

## 要望

mdmark を使用するほかのリポジトリと MindStella のワークスペースの文書に、マーカーの JSON の記載への移行の手順（`migrations/next/marker-json.mjs`）を含むバージョンの `mdmark upgrade` を適用し、移行の報告に挙がる記載（拡張・`libraries` のマーカー、書き出さない記載）を記載し直す。
移行の手順は `migrations/next/` にあり、`mdmark upgrade` で適用できるのは、次のマイナーバージョン（v0.11.0）の release が master へ入った後になる。

対象は、AI Monitor の監視対象のプロジェクトのうち、develop に今の書き方のマーカーを持つ Markdown があるリポジトリと、MindStella のワークスペース。
ファイル数は 2026-11-13 の各リポジトリの `origin/develop` を、マーカーの名前の後ろに JSON でない引数を持つ行で数えた値。

全てのリポジトリで終わりの条件を満たしたら、[#451](https://github.com/shuhei1101/mdmark/issues/451) にその旨をコメントし、`確認:task-planner` を付ける。

リポジトリごとに、そのリポジトリへ Issue を起票し、そのリポジトリの作業 PR で v0.11.0 の配布後に `mdmark upgrade` を適用して記載し直す（起点 Issue の本文の「リポジトリごとに Issue を分ける」）。
起票した Issue の番号は、`要件.yaml` のスコープ外の行に持つ。
MindStella のワークスペースの文書は、mindstella のリポジトリの Issue に含める。
