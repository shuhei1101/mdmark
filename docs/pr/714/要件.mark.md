# 要件

## 要望

`docs/module/*.yaml` の `functions[]`・`constants[]`・`data_models[]`・`classes[]` の `summary` のうち、200 字を超え 2 文以上を持つ 96 項目（70 ファイル）を次の状態にする。

- `summary` は 1 文の概要（何を担うか）にする
- 移した詳細は、同じ要素の `description` に置く。既に `description` を持つ要素は、既存の本文と重ならないように合わせる
- `description` は規約『表し方の優先順位』に沿って、1 文 1 行で書き、並列の項目（条件ごとの挙動・引数ごとの扱い 等）は表にする
- 詳細の中身（挙動・条件・値）は変えない

対象の 96 項目の一覧は [ライブラリ本体](./ライブラリ本体.mark.md) の `## 現状` に置く。
受付の判断の 89 項目は、#614 の基準（400 字超・5 文以上）に当たる項目を除いた数である。
#668 が 4 文以下と数えて直さなかった 400 字超の 10 項目（Issue 本文の例の `useAnnotations` を含む）も develop に残っているため、対象に含める。
文は、括弧とインラインコードの外の `。` で区切って数える（括弧の中の `。` だけを持つ `summary` は 1 文）。
200 字以下の 2 文以上の `summary` は対象外。
