## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品を読み込める手段 | 部品の名前（`map`・`view`・`comments`）とモジュールを返却する関数を指定する公開関数を `dist/index.js` の export に追加する | `未確定`（要件.md の案 A / B。決める段: インターフェース定義設計） |
| 指定の時期 | `mount`・`mountView`・`mountComments` を呼ぶ前に指定する。部品を読み込んだ後に指定した名前は、読み込み済みのモジュールを使い続ける | 今の `partModules` の 1 回だけ読み込む動きに合わせる |
| 構造の確認 | 指定した関数が返却したモジュールも、export する関数を隣から読み込むときと同じく確認し、合わなければ同じエラーにする | 今の `readPartModule` を使う |
| 既存機能への影響 | 指定しない部品は今と同じく隣から読み込む。書き出した HTML の起動（`prepareModules`）の指定の仕方は変えない | - |
| 配布ファイルのサイズ | `dist/index.js` に部品を含めない | 非機能要件『配布ファイル 1 つのサイズ』 |
