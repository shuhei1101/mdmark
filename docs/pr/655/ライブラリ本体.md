## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品を読み込める手段 | 部品の名前（`map`・`view`・`comments`）とモジュールを返却する関数を指定する公開関数を `dist/index.js` の export に追加する | 公開関数の名前は `setPartModuleLoader`（インターフェース定義『部品のモジュールを指定する』） |
| 指定の時期 | `mount`・`mountView`・`mountComments` を呼ぶ前に指定する。部品を読み込んだ後に指定した名前は、読み込み済みのモジュールを使い続ける | 今の `partModules` の 1 回だけ読み込む動きに合わせる |
| URL を作れない失敗 | 指定しなかった部品の隣の URL を作れない失敗（`import.meta.url` が階層を持たない）も、`loadPartModule` が同期で投げず、戻り値の Promise の拒否にする。`mount` は `console.error` に出して描画を続け、`mountView`・`mountComments` は Promise を拒否する | インターフェース定義『部品のモジュールを指定する』の異常系（指定しない部品の URL を作れない・console.error） |
| 構造の確認 | 指定した関数が返却したモジュールも、export する関数を隣から読み込むときと同じく確認し、合わなければ同じエラーにする | 今の `readPartModule` を使う |
| 既存機能への影響 | 指定しない部品は今と同じく隣から読み込む。書き出した HTML の起動（`prepareModules`）の指定の仕方は変えない | - |
| 配布ファイルのサイズ | `dist/index.js` に部品を含めない | 非機能要件『配布ファイル 1 つのサイズ』 |
