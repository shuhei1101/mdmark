# 要件

## 要望

- 利用側のページが `dist/index.js` を 1 つのファイルとして埋め、`import.meta.url` が階層を持たない URL（Blob の URL など）で読み込んでも、map・ビュー・コメントの部品のモジュールを読み込める手段を用意する
- 利用側は部品の配布ファイル（`dist/map.js`・`dist/view.js`・`dist/comments.js`）を同じく埋め、`mount`・`mountView`・`mountComments` を呼ぶ前に公開関数で指定する。指定した部品は配布物の隣へ要求しない
- 指定しない部品は、今と同じく `dist/index.js` の隣から読み込む。指定しない利用側のページと書き出した HTML の描き方は変えない
- 部品のモジュールの構造（export する関数）の確認は、隣から読み込むときと同じにする

部品を読み込める手段は、部品のモジュールを返却する関数を指定する公開関数 `setPartModuleLoader` を `dist/index.js` の export に追加する（インターフェース定義『部品のモジュールを指定する』）。
部品を全てまとめた 1 ファイルの配布物は、配布ファイル 1 つのサイズの上限（NFR-472-1）に掛かり、利用側が使用しない部品も埋めることになるため置かない。
