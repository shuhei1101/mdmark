## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 組み直すか | 機能ごとのフォルダへ組み直す | [要件](./要件.md) |
| 機能のフォルダの切り方 | 記法の単位で `src/{機能}/` を切り、その記法のコアルール・部品・ストーリー・操作・DOM を使用しない計算を入れる。新しく作るフォルダは `table`・`tree`・`code-block`・`footnote`・`inline`・`callout`・`card`・`section`・`tabs`・`steps`・`layout`・`figure`・`frontmatter`・`embedded-html`・`media`。図・map・索引と用語・ビュー・コメント・差分・書き出した HTML の起動の記法と部品は、既にある `src/diagram/`・`src/map/`・`src/knowledge/`・`src/views/`・`src/comments/`・`src/diff/`・`src/viewer/` に入れる | 行内の小さな記法（バッジ・キー・アイコン・蛍光ペン・文字の色）は `inline/`、範囲の記法（段組み・wide・details・改ページ）は `layout/` にまとめ、中身が 1 つだけのフォルダを作らない |
| ファイル名 | 機能のフォルダのファイル名の後ろに中身の役割を付ける（`{name}.syntax.ts`・`{name}.part.ts`・`{name}.part.stories.ts`・`{name}.interact.ts`・`{name}.logic.ts`）。移す前の層ではなく中身で決め、DOM もトークンも使用しないファイルは `.logic.ts` にする。既存のフォルダの役割を持たないファイル（`definition.ts` など）は今の名前のまま | フォルダ構成 LAY-472-1 の補足『src の機能のフォルダのファイル名』 |
| 複数の機能が使用するもの | 持ち主の機能が無い助け（トークン・範囲のマーカー・折り畳みの指定・記載の警告・エスケープ・マーカー・アイコン・色・折り畳み・通知ブロック・読み込み中のブロック・クリップボード・ツールチップの配置・スクロールする祖先・開閉の記録・要素の文字・拡大と縮小・URL の `#` の読み込み）は `src/shared/` に配置する。ある機能の記法・部品・操作を別の機能が組み込むときは、持ち主の機能のフォルダに置いたまま import する | 規約『フォルダ構成の切り方とレビュー』の「共通のもの」 |
| 描画の流れ | `src/render/` は Markdown を HTML にする流れ・マーカーの解釈・sanitize に絞り、`render/syntax/includes.ts` を `render/includes.ts` へ移す。`render/frontmatter.ts`・`render/scope-css.ts` はそれぞれ `frontmatter/`・`embedded-html/` の `*.logic.ts` へ移す | - |
| 操作の起点 | `src/interact/index.ts`（`attachInteractions`）は `src/interact.ts` へ移す | 分類『描く』 |
| 既に機能で分かれているフォルダ | `src/map/`・`src/cli/` などの中の分け方は変えず、import のパスだけを修正する | - |
| ファイルの移動 | `git mv` で移し、中身は import のパスの修正だけにする。例外として、`src/table-logic.ts` の `rowIdFromHash` を `src/shared/row-hash.logic.ts` へ、`src/parts/inline-icon.ts` の `iconNodeSvg`・`MdmarkIconNode` を `src/shared/icon-node.logic.ts` へ切り出す | 下の移動の対応表 |
| 公開関数・配布物の起点 | `src/index.ts` の export と、`dist/` の起点のファイル名は変えない。`dist/` の下のフォルダの型定義は移した先のパスに変わる | [要件](./要件.md) |
| 設計書 | モジュール構成の分類（記法・操作・部品）を機能の分類にし、分類をまとめる設計書を機能ごとに作り、『記法』『操作』『部品』を削除する。モジュール構成・部品設計・インターフェース定義・外部ライブラリ・フォルダ構成のパスを移した先に合わせる | - |
| 単体テスト | `tests/unit/src/` の置き場所を移した先の `src/` の並びに合わせ（`tests/unit/src/{移した先のパス}.test.ts`。`*.interact.ts` は今と同じ `.browser.test.ts`）、import を修正する | テストの中身は変えない |
| 結合テスト | import を修正する | テストの中身は変えない |
| 確認 | lint・型検査・ビルド・単体テストを全件で実行して合格させる。ビルドした `dist/index.js`・`dist/view.js`・`dist/comments.js`・`dist/map.js` が、組み直す前と同じ公開関数を export していることを確認する | 結合テストの実行範囲は、実行の前に計画書の表にしてレビューで確認する |
