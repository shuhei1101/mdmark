# src/ を層のフォルダから機能ごとのフォルダへ組み直すかを決め、組み直す

## 概要

`src/` のライブラリ本体のコードを、層（記法の変換・読者の操作・部品・直下の `*-logic.ts`）のフォルダから機能ごとのフォルダへ組み直すかを決め、組み直す。
組み直さないなら、層で分ける理由をフォルダ構成の設計書に記載する。

## 背景

[Issue #583](https://github.com/shuhei1101/mdmark/issues/583) の要望。
[#574](https://github.com/shuhei1101/mdmark/pull/574)（[#361](https://github.com/shuhei1101/mdmark/issues/361) のフォルダ構成の設計書の作成）で、今のフォルダ構成をレビューの観点で確認して見つかった。
1 つの機能のコードが `src/render/syntax/`・`src/interact/`・`src/parts/`・直下の `*-logic.ts` の 4 か所に散り、knowledge の規約『フォルダ構成の切り方とレビュー』の「機能で分ける」と、レビューの観点「同じ種類が散る」に反している。
