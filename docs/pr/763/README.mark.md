# map の図の ER 図の開閉のボタン・全画面での線の動き・ER 図の 1 対多の向き・グループの角のドラッグでの大きさの変更を修正する

## 概要

読者が、map の図で ER 図のテーブルをほかの開閉と同じ見た目のボタンで開閉し、全画面でも線の動きを見て、ER 図の線から 1 対多の向きを読み取り、グループの角をドラッグして大きさを変えられるようになる。

## 背景

[#762](https://github.com/shuhei1101/mdmark/issues/762) の束の要望（子 Issue [#758](https://github.com/shuhei1101/mdmark/issues/758)・[#756](https://github.com/shuhei1101/mdmark/issues/756)・[#755](https://github.com/shuhei1101/mdmark/issues/755)・[#757](https://github.com/shuhei1101/mdmark/issues/757)）。
ER 図のテーブルの開閉のボタンだけが枠線と「列 {数}」の表示を持ち、全画面では線の動きが出ず、ER 図の線のデータの印は多重度と関係なく線の元から先へ流れ、グループの大きさは自動の配置で決まり読者が変えられない。
