# 要件

## 要望

子 Issue ごとの要件と終わりの条件。

| Issue | 要件 | 終わりの条件 |
| --- | --- | --- |
| [#758](https://github.com/shuhei1101/mdmark/issues/758) | ER 図・クラス図のテーブルの開閉のボタン（`.map-er-toggle`）の枠線を無くし、閉じたときの「列 {数}」の文字を閉じたことを示すアイコンに置き換える。`.map-er-note` の見た目は変えない | ER 図・クラス図のテーブルの開閉のボタンが枠線を持たずほかの開閉のボタンと同じ見た目になり、閉じたときは閉じたことを示すアイコンだけを出す（`.map-er-note` の見た目は変えない） |
| [#756](https://github.com/shuhei1101/mdmark/issues/756) | 全画面のモーダルで開いた map の図に、通常の表示と同じ線の強調とデータの印の操作を付ける。最初に再現を確認する | 全画面でも、map の図の線にポインターを重ねたときの動きが通常の表示と同じに出る（再現しない場合は確認した図の種類・操作・結果を起点 Issue へ報告して閉じる） |
| [#755](https://github.com/shuhei1101/mdmark/issues/755) | ER 図の関連の線で、どちらが多い側かを読み取れるようにする | ER 図の関連の線で、どちらが多い側（1 対多の向き）かが、データの印の向きかほかの見せ方で分かる |
| [#757](https://github.com/shuhei1101/mdmark/issues/757) | グループを持つ map の図で、グループの角をドラッグして大きさを変えられるようにする | グループを持つ map の図で、グループの角をドラッグして大きさを変えられる |

ER 図の 1 対多の向きは、線にポインターを重ねたときとテーブルを選んだとき、データの印を多い側のテーブルから少ない側のテーブルへ流して示す（モック作成で確定）。

グループの角をドラッグして変えた大きさは、ノードの移動と同じく図の状態として同じタブの中で保ち、補足の `layout` には書き戻さない（単一ユースケース設計で確定）。
