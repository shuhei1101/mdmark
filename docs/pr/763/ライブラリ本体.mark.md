## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| テーブルの開閉のボタンの見た目（#758） | `.map-er-toggle` を `.map-er-note` の規則から分けて枠線を外し、ほかの開閉のボタン（山形だけ）と同じ規則にする。閉じたときは `列 {数}` の文字を、閉じたことを示すアイコン（ほかの開閉の閉じたときと同じアイコン）に置き換える | ER 図とクラス図の両方。`aria-label` に列の数は残す |
| 全画面での線の動き（#756） | 全画面のモーダルの複製に、通常の表示と同じ map の図の操作（線の強調・選択・データの印・開閉・中へ入る・ドラッグ・グループの大きさ・案内と再生）を付け直す。全画面で変えた開閉・配置・グループの大きさは元の図と同じ状態として保ち、閉じた後の元の図に反映する。全画面の Esc は、ツールチップを閉じる・選択を解く・外へ戻るを順に 1 つずつ行い、どれも無いときに閉じる | `openDiagramDialog` は図を複製して拡大・移動とツールチップだけを付け直し、map の操作を付けないため、複製の上では線の強調とデータの印が出ない（コードで確認。画面での再現はテスト作成で確かめる） |
| ER 図の 1 対多の向き（#755） | 関連の両端の多重度から多い側を決め、線にポインターを重ねたときにその向きを見せる | `未確定`（要件の案と推奨。決める段: モック作成） |
| グループの大きさの変更（#757） | ノードの移動が構成図と同じ規則の図（構成図・ER 図・状態遷移図・クラス図・アーキテクチャ図・C4 図）のグループの右下の角にハンドルを置き、ドラッグとキーで大きさを変える。中のノードを囲む大きさより小さくはしない。押せる範囲は 24px 四方にし、見た目の斜線は 16px にする（モックのレビューの提案） | 変えた大きさはノードの移動と同じく同じタブの中で保ち、補足の `layout` に書き戻さない |
| アクセシビリティ | 角のハンドルはキーボードで操作でき、フォーカスの見た目を持つ | - |
| 既存機能への影響 | ノード・グループの移動とグループの開閉・中へ入る操作は変えない | - |
