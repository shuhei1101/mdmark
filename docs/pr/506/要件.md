# 要件

## 要望

[docs/scenario/SC-472-35.yaml](https://github.com/shuhei1101/mdmark/blob/develop/docs/scenario/SC-472-35.yaml) の `notes.項目の記載方法` にある記法の説明 `` `icon:名前` `` を、mdmark の点検（`check --text -`）で `syntax_warning` が 0 件になる書き方に修正する。
修正した後も、項目の最初のリンクの前の `icon:` の行内のコードがアイコンになるという説明の意味は変えない。

記法の説明は、mdmark の記法の打ち消し `` `icon\:名前` `` で記載する。
mdmark で描くと `icon:名前` の文字のまま表示され、実在するアイコンの名前の例にすると説明の箇所がアイコンに置き換わって記法が読めなくなるため。
