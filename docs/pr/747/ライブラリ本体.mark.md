## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| アーキテクチャ図 | `notes.フォルダ役割` の表の `guide/` の行を、`plugin/guide-index.yaml`（`guides[]`）を指す記述へ修正する | `write_docs` で記載する |
| 罫線の検知 | 言語が `tree` でないコードブロックの罫線の行が `TREE_WARNING_MIN_LINES` 以上なら、言語 `tree` と同じ読み取りでファイルツリーにする。罫線を読み取れない行を持つときは言語 `tree` と同じ記載の警告にする | 対象の言語は `未確定`（[要件](./要件.mark.md)） |
| `tree_warning` | `false` のときは罫線を検知せず、コードブロックのまま描く | `未確定`（[要件](./要件.mark.md)）。改名する設計になったら Schema と移行の手順を加え、起点 Issue へ報告する |
| ファイルツリーの帯 | コードブロックの帯と同じ高さ・余白・色・言語のラベル・コピーのボタンの位置で描く | 部品を共通にするかは `未確定`（[要件](./要件.mark.md)） |
| 範囲の外の mermaid（`config`・`%%{`） | front matter の `config`・`%%{` の行を持つ map が描ける種類のコードブロックを map の図にする | テーマの指定は map の図に適用しない |
| 範囲の外の mermaid（読めない行・見た目を指定する行） | map の読み取りを広げ、map が読めない行・見た目を指定する行を持つ map が描ける種類のコードブロックを map の図にする | 色を適用するかは `未確定`（[要件](./要件.mark.md)） |
| map が描けない種類 | mermaid のライブラリの経路を残すか削除するかを単一ユースケース設計で決める | `未確定`（[要件](./要件.mark.md)）。削除する設計になったら起点 Issue へ報告し、`破壊的変更` を付ける |
| 更新前の見た目の原因 | 設計の最初に、ビュワーが読み込む mdmark のバージョンと文書の mermaid が戻す場合に該当するかを確認する | - |
