# 要件

## 要望

まとめた HTML（`mdmark build` の 1 枚の HTML）で、文書を行き来したときのスクロール位置を、判定フローチャート『画面の状態の保持先』と規約『入力と文言』の「スクロール位置とタブの切り替え」に合わせる。

| 移り方 | 表示する位置 |
| --- | --- |
| ブラウザの戻る・進むで、前に開いた文書の履歴の項目へ戻る | その履歴の項目を離れたときのスクロール位置 |
| 同じ履歴の項目を再読み込みする | その履歴の項目を離れたときのスクロール位置 |
| 文書の一覧・文書間のリンクで新しく移る | 今どおり、見出しを指していればその見出し、指していなければ文書の頭 |
| 開いている文書の中の見出しへ移る（見出しのアンカー・目次） | 今どおり、その見出し |

- スクロール位置は履歴の項目ごとに sessionStorage へ保存し、URL には出さない
- まとめた HTML の起動の処理がルーターとして `history.scrollRestoration` を `manual` にし、ブラウザに位置を戻させない
- 今の履歴の項目のキーをメモリに持ち、`popstate`・文書の一覧と文書間のリンクのクリック・`pagehide`・間引いたスクロールのときに、そのキーへ保存する
- 戻すのは文書を描いた後。保存した位置が文書の高さを超えるときは、文書の末尾まで戻す
- 保存した位置を持たない履歴の項目へ戻ったときは、今どおり見出しか文書の頭から表示する

描いた文書の部品の画面の状態の保持を、同じ決まりと突き合わせる。

| 状態 | 今の保持先 | 決まりとの突き合わせ |
| --- | --- | --- |
| `group=` のタブで選んだタブ名 | localStorage の `mdmark-tabs:{group}` | 端末ごとの好み（OS・言語の選択）に当たり、localStorage で決まりに合う。変えない |
| リサイズハンドルで変えた図の高さ | sessionStorage（ページ・図の順・題名のキー） | そのタブで画面を離れて戻ったときに戻す状態に当たり、画面を表すキーの sessionStorage で決まりに合う。変えない |
| 本文の開閉（`<details>`〔閉じた表・折りたたみ・注意書き・脚注〕・セクション・行の詳細・最終列の畳み・コードの行の畳み・ER 図の畳み・ファイルツリーのフォルダ・表のツリーと見本）と、`group=` の無いタブで選んだタブ | 保持しない（描くたびにマーカーのとおり） | そのタブで画面を離れて戻ったときに戻し、戻る・進むの履歴の項目ごとに違ってよい状態に当たる。スクロール位置と同じ履歴の項目のキーで sessionStorage に保存し、戻る・進む・再読み込みで戻ったとき、開閉とタブを戻してからスクロール位置を戻す |

開閉とタブを戻さないと、開閉で文書の高さが変わった後に保存したスクロール位置が同じ箇所を指さない。

表のメニュー・ドロワー・絞り込み、右側の目次、差分のパネル、コメントの吹き出しは、操作の間だけ開く一時的な表示のため戻さない。
