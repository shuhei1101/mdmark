# 要件

## 要望

表の列の幅を、セルに見えている文字だけから決める。

- 開いていないツールチップ（用語・脚注・注記）など、セルの中で表示していない要素の文字を、列の幅の計測に含めない
- 用語を含むセルは、用語の単語（例: 「ターン」）だけの幅で測る
- 表示している文字だけのセルの列の幅は、今の値から変えない（差は 1px 以内）
