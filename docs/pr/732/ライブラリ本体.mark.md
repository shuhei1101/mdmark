## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 測る文字 | `linesOf` で複製したセルから、用語・脚注・注記のツールチップ（開いているかに関わらない）と画面に出さないスクリーンリーダー用の文字を除いてから、改行で行に分けて文字を取る | 除く要素は表示の状態ではなくクラス（`.mdmark-term-tip`・`.mdmark-fn-tip`・`.mdmark-visually-hidden`）で決め、`src/shared/text.interact.ts` に定数 `HIDDEN_TEXT_SELECTOR` と関数 `removeHiddenText` を置く。`visibleText` は並べ替え・絞り込みの値にスクリーンリーダー用の文字を含めるため変えない |
| 見出しのセル | 見出しのセルの中身（`.mdmark-th`）を測るときも、同じく表示していない要素の文字を幅に含めない | 見出しの用語のツールチップ |
| 列の幅の結果 | 表示している文字だけの表は、`--mdmark-auto-width`・`--mdmark-auto-table-width`・`--mdmark-column-head-width` の値を今のとおりにする | 差は 1px 以内 |
| 既存機能への影響 | 計測用の要素の配置と幅の取得を交互にしない処理（[#727](https://github.com/shuhei1101/mdmark/pull/727)）は保つ | - |
