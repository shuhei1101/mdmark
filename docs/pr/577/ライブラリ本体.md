### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 入れ子の解消 | リンク先を持たないノードは、ノードの `div` をフォーカスさせず、ノードの全体を覆う押せる要素（`span.mdmark-diagram-node-hit`）に `role="button"`・`tabindex="0"`・`aria-roledescription`・`aria-keyshortcuts`・名前を持たせる。押せる要素は種類の行・名前・説明のマーカー・ノードの中に入れた部品（ER 図の列の行と、列の開閉・列の説明のボタン）の下に重ね、それらを押せる要素の中に入れない | CMP-472-5 の accessibility。リンク先を持つノードの `a.mdmark-diagram-node-link` と同じ構造 |
| 対象のノード | `markFlowNode` を通る構成図・ER 図・状態遷移図の選べるノード全て（説明を持たないノードを含む） | ER 図のテーブルのノードの列の開閉・列の説明のボタンと、名前の中の用語（`span.mdmark-term`）も同じ入れ子のため、同じ構造で解消する（CMP-531-1・CMP-531-2） |
| キー操作 | Enter・Space での選択と Alt + 矢印キーでの移動を、押せる要素で今と同じに動かす | `nodeKeyTarget` の対象を押せる要素にする |
| 名前の文字の選択 | 名前の文字と ER 図の列の名前の文字は押せる要素の上に重ね、今と同じく選んでコピーできる。名前の文字の外を押すとノードを選ぶ | - |
| ツールチップ | 説明のマーカーのフォーカス・押下で説明のツールチップを開閉する今の振る舞いを保つ | - |
| テスト | 単体テストで構造とキー操作を確認し、結合テストで `parts-mapflow--default` に axe の `nested-interactive` が出ないことを確認する | - |

案 A（説明のマーカーをノードの `div` の外に移す）は、ER 図のノードの中のボタンと名前の中の用語の入れ子が残るため採らない。
