## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 操作の一覧 | インターフェース定義『文書を描く』に、記法（表・コードブロック・リスト・見出しとセクション・画像・脚注 など）ごとに、記法が無くても付く操作と記法を記載したときだけ付く操作の表を、制約『範囲の外の map の図に付く操作』と同じ構造で追加する | 単一ユースケース設計で洗い出し、インターフェース定義設計で表にする |
| マーカーの無い表 | 一覧で「記法が無くても付けられる」とした操作を、既定の種類の機能に加える | `未確定`（[要件](./要件.md) の案 A / B。決める工程: 単一ユースケース設計） |
| ほかの記法 | 一覧で「記法が無くても付けられるのに付いていない」とした操作を付ける | 洗い出しの結果、付ける操作が無い記法は表に記載するだけにする |
| 表の外観 | 既定の種類の表の上のバーに増えるボタンの見た目を、変わる表だけモックで合意する | 画面一覧・画面遷移は変わらない |
| 既存機能への影響 | マーカーで `plain` を指定した表と、`features` で機能を除外した表には、加えた操作を付けない | - |
