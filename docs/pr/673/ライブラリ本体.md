## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 操作の一覧 | インターフェース定義『文書を描く』に、記法（表・コードブロック・リスト・見出しとセクション・画像・脚注 など）ごとに、記法が無くても付く操作と記法を記載したときだけ付く操作の表を、制約『範囲の外の map の図に付く操作』と同じ構造で追加する | 単一ユースケース設計で洗い出し、インターフェース定義設計で表にする。リスト（番号付き・タスクリストを含む）は記法が無くても付く操作が無く、ステップ・カードの格子はマーカーで付くため、表の行を「記法が無くても付く操作: -」で配置する |
| マーカーの無い表 | 既定の種類の機能を、ピン止め・列の幅の変更・並べ替えにする。列の幅を決める処理は、見出しの中身（列名・並べ替えのアイコン・ピン止めのボタン）の幅を列の最小の幅にする | 絞り込み・件数・テーブル設定・コピー・集計・行へのリンクは、表のマーカーで指定した表にだけ付ける |
| 押したピン止めのボタン | 枠線と背景色を付けず、リンクの色で塗ったピンのアイコンにする。見える幅に収まらず留まっていない列のピンは、枠線と背景色を付けず、薄い色の破線のピンにする | 全ての種類の表。部品設計『表』の CSS と状態を変える |
| 絞り込み中のボタン | 押したピンと同じく、枠線と背景色を付けず、リンクの色で塗った漏斗にする | 全ての種類の表 |
| 押していないピン止めのボタン | PC の幅では見出しにポインターが乗ったときかフォーカスが当たったときだけ出し、スマホの幅では常に出す | 押したピン止めのボタンは常に出す |
| 列の幅のつまみ | 狭めるときの最小の幅を、見出しの列名・並べ替えのアイコン・ピン止め・絞り込みのボタンが収まる幅にする | `table-resize.interact.ts` と列の幅を決める処理で同じ最小の幅を使う |
| ほかの記法 | 一覧で「記法が無くても付けられるのに付いていない」とした操作を付ける | 洗い出しの結果、付ける操作が無い記法は表に記載するだけにする |
| 表の外観 | 既定の種類の表の上のバーに増えるボタンの見た目を、変わる表だけモックで合意する | 画面一覧・画面遷移は変わらない |
| 既存機能への影響 | マーカーで `plain` を指定した表と、`features` で機能を除外した表には、加えた操作を付けない | - |
