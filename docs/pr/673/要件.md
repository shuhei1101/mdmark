# 要件

## 要望

図以外の記法（表・コードブロック・リスト・見出し・画像 など）にも、記法を記載しなくても付けられるビュワーの操作を付ける。

| 対象 | 今 | 終了の条件 |
| --- | --- | --- |
| 操作の一覧 | 純粋な Mermaid の図だけが、範囲の外と範囲の中で付く操作の表を持つ（インターフェース定義『文書を描く』の制約『範囲の外の map の図に付く操作』）。図以外の記法には、記法が無くても付く操作と、記法を記載したときだけ付く操作の一覧が無い | 図以外の記法ごとに、記法が無くても付く操作と、記法を記載したときだけ付く操作を、設計書に表で持つ |
| 表 | マーカーの無い表は既定の種類で、ピン止めと列の幅の変更だけが付く。並べ替え・絞り込み・コピーなどは、表のマーカーで種類か機能を指定したときだけ付く | 記法が無くても付けられると一覧で決めた操作が、マーカーの無い表にも付く |
| 押したピン止めのボタン | 枠線と背景色を持つ、塗ったピンのボタン | 枠線と背景色を持たず、リンクの色で塗ったピンのボタンになる |
| コードブロック・リスト・見出し・画像 など | 記法が無くても付く操作と付かない操作を確認していない | 記法が無くても付けられると一覧で決めた操作が、記法の無い Markdown にも付く |

マーカーの無い表（既定の種類）の機能は、ピン止め・列の幅の変更・並べ替えにする。
絞り込み・件数・テーブル設定・コピー・集計・行へのリンクは、今のとおり表のマーカーで指定した表にだけ付ける。
列の値の種類（日付・選択肢）は作成者の指定でしか決定しないため、指定の無い絞り込みは文字の一致にしかならない。

押したピン止めのボタンは、枠線と背景色を付けず、リンクの色で塗ったピンのアイコンにする（全ての種類の表で同じ）。
押す前は線のピンのため、色と形状の両方で見分けられる。
