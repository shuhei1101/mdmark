# 表・コードブロックなど図以外の記法にも、記法が無くても付けられるビュワーの操作を付ける

## 概要

読者が、マーカーの無い表など記法を記載していない Markdown でも、記法が無くても付けられるビュワーの操作を使用できるようになる。

## 背景

[Issue #632](https://github.com/shuhei1101/mdmark/issues/632) の要望。
[#500](https://github.com/shuhei1101/mdmark/issues/500) は「表など、ほかの記法でも同じ（マーカーが無くても、ビュワーの側で付けられる操作は付ける）」を要望に含み、作業 PR [#630](https://github.com/shuhei1101/mdmark/pull/630) は純粋な Mermaid の図だけを扱って、図以外の記法を #632 へ切り出した。
マーカーの無い表は既定の種類でピン止めと列の幅の変更だけが付き、並べ替え・絞り込みなど、マーカーが無くても付けられるのに付いていない操作があるかは確認していない。
