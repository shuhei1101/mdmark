# コードブロックのモックの知らないマーカーの例を [!code blink] にし、使用できるマーカーを実装の 6 種類と統一する

## 概要

コードブロックのモックの「知らないコードの行のマーカー」の異常シナリオを、使用できないマーカー `[!code blink]` の例にし、記載の警告が挙げる使用できるマーカーを実装の 6 種類と統一する。

## 背景

[コードブロックのモックの異常シナリオが、使用できるマーカー ［!code focus］ を知らないマーカーの例にしている](https://github.com/shuhei1101/mdmark/issues/431) の要望。
[master を develop へバックマージする競合の解消](https://github.com/shuhei1101/mdmark/pull/429) のレビューで reviewer が対象外の逸脱として報告した。

モックの異常シナリオは、使用できるマーカー `[!code focus]` を知らないマーカーの例にしている。
記載の警告が挙げる使用できるマーカーは `[!code ++]`・`[!code --]`・`[!code highlight]` の 3 種類で、`focus`・`error`・`warning` を加えた [既存の記法・点検への項目の追加 6 件（グラフの種類・表のセルの結合・図の定義の点検・タブの入れ子・注意書きのタイトル・コードの折りたたみ）](https://github.com/shuhei1101/mdmark/pull/275) の実装の 6 種類と食い違っている。
