### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| マーカーの設定 | `glossary` のマーカーに、設定の `aliases` の行を指す引数を追加する。指したときは囲む表を持たない（`<!-- glossary: {…} -->` だけで描く） | 引数の名前は ER 図の設計で決める |
| 表を描く処理 | 指した用語の `name`・`aliases`・`avoid`・`description` から、用語・別名・使用しない言い方・意味の列の表を描く。表の種類は今の用語集の表と同じ `data` にする | - |
| 用語の扱い | 行を指して描いた表の用語は、エイリアスとして既に下線・ツールチップ・点検・`collectMatches` に入るため、表から入れる用語（`MdmarkGlossaryEntry`）に重ねて入れない | - |
| 記載の警告 | 指した行のエイリアスが無いとき、マーカーの場所に記載の警告を出す | - |
| 設定・索引の Schema | `schemas/marks/glossary.schema.json` を変えるため、`migrations/next/` に移行の手順か `migrations/no-steps.yaml` の行を配置する | 今の書き方は変えないため `no-steps.yaml` の見込み |
| 公開ドキュメント | `docs/guide/用語集.mark.md` の表を削除し、`docs/guide/用語集.yaml` を読み込むエイリアスの行を指すマーカーに置き換え、`mdmark.config.yaml` にその `aliases` の行を追加する | - |

### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書き出しの中身 | `ExportPayload` の `docs[].markdown`・`includes` を削除し、文書ごとに書き出すときに描いた HTML と、`toPureMarkdown` で作った純粋な Markdown を持たせる | まとめた HTML の画像は今と同じく `mdmark-asset:{キー}` で 1 回だけ埋める |
| 書き出すときの描画 | CLI の `export`・`build` が、`mount` に指定していた設定・索引・参照の表・エイリアス・取り込む文書・アイコンを `render` に指定して HTML を作る | MCP の `export_html`・`build_site` は CLI と同じ処理を呼ぶため追随する |
| 開いたときの起動 | `startViewer`・`startBundle` が、埋め込んだ HTML を描く先の要素に入れて操作を付ける | 起点は `未確定`（[要件](./要件.mark.md) の案 A / B） |
| 外部ライブラリと拡張 | マーカーの場所と引数を HTML に残し、開いたときに埋めたモジュールで描く | 今の `prepareModules` を使用する |
| Markdown でコピー・エクスポート | 書き出した HTML では、埋め込んだ純粋な Markdown をコピー・保存する | `mount` に Markdown を指定した利用側の動きは変えない |
| mdmark の痕跡を隠す処理 | `traces.ts` の隠す範囲を、埋め込む HTML・純粋な Markdown に適用する | - |
| セキュリティ | 埋め込む HTML は `render` が無害化した HTML だけにし、`script` 要素を閉じる並びのエスケープを今の `encodePayload` と同じに保つ | - |
