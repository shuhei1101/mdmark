# 要件

## 要望

E2E『文書を描く』の `test_normal_when_index` は、本文を差し替えた後の検証で、本文の段落だけを取って「別の段落」を含むことを確かめる。
被参照の一覧（`nav.mdmark-backlinks`）の題の `p` は検証の対象に入れない。
完了の基準は、release/v0.3.0 のビルドした配布物で `test_normal_when_index` が Chromium・Firefox の両方で pass すること。
