# 描き直しで手で変えた部品の開閉を保ち、タブの切り替えで押したタブの見出しの位置を保つ

## 概要

読者が手で開閉した部品が、利用側のページが `update` で描き直した後もその開閉のまま表示される。
読者がタブを切り替えても、押したタブの見出しが画面の同じ位置に残る。

## 背景

[Issue #539](https://github.com/shuhei1101/mdmark/issues/539) の束で、[Issue #498](https://github.com/shuhei1101/mdmark/issues/498) と [Issue #525](https://github.com/shuhei1101/mdmark/issues/525) の不具合。

- #498: `MountHandle.update` は毎回本文を丸ごと差し替えて操作を付け直す。[PR #497](https://github.com/shuhei1101/mdmark/pull/497) で見出しのセクションの開閉は引き継ぐようになったが、表の行の詳細・details の範囲・ER 図の列・ファイルツリー・コードブロックの折り畳み・表のキーの階層・折り畳む注意書きは、描き直すたびにマーカーのとおりの開閉へ戻る
- #525: タブの部品で中身の高さが大きく違うタブへ切り替えると、スクロール位置が動き、タブの部品が画面の外へ離れる。`src/interact/tabs.ts` のタブを選ぶ処理は、切り替えの前後で見出しの位置を保たない
