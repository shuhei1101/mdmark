## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 開閉の記録 | `mount` ごとに 1 つ持つ開閉の記録（#497 のセクションの開閉の記録）を、対象の部品の開閉へ広げる | 囲む見出しのセクションの `id` とその中の部品の順番、部品の中の鍵で対応を取る（[要件](./要件.md)） |
| 記録する | 対象の部品で読者が開閉を変えるたびに、変わった要素の開閉を記録する | - |
| 始めの開閉 | 各部品の操作を付けるとき、記録にある要素を記録の開閉で、無い要素をマーカーのとおりの開閉で始める | 開閉のマーカーが記録したときと変わった要素はマーカーのとおり |
| 記録を捨てる | 同じ要素への 2 回目の `mount` と `destroy` で捨てる | #497 と同じ |
| タブの見出しの位置 | タブを選ぶ処理で、切り替えの前後の押したタブの見出しの画面上の位置を測り、差の分だけスクロール位置を戻す。文書が縮んで戻しきれないときはスクロール位置の上限まで戻し、見出しを画面の中に残す | 同じ `group` のほかのタブの高さの変化も同じ差で戻す。URL の `#ID` で移る `revealTabTarget` は変えない |
| 既存機能への影響 | 公開関数の引数・戻り値・マーカーは変えない。印刷の前後で全てを開いて戻す処理は記録しない | - |
