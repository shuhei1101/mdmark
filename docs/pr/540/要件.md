### #498 描き直しで部品の開閉を引き継ぐ

- 対象の部品: 表の行の詳細（`row-detail`）・details の範囲（`<!-- details -->`。`collapse` で折りたたみに入れたタブ・ステップも同じ HTML のため含め、同じ種類として数える）・ER 図の列・ファイルツリー・コードブロックの折り畳み・表のキーの階層・折り畳む注意書きと `collapsible` の `<details>`
- 引き継ぐのは、描き直す前に読者が手で開閉を変えた要素だけにする。描き直す前に無かった要素と、手で開閉を変えていない要素は、マーカーのとおりの開閉で描く
- 開閉のマーカーの指定が描き直す前と変わった要素は、マーカーのとおりに描く
- 手で押した要素は、押した回数によらず最後の開閉を記録する（2 回押して元の開閉に戻した要素も手で変えた要素に数える）
- 同じ要素への 2 回目の `mount` と `destroy` の後は引き継がない
- 公開関数の引数・戻り値・マーカーは変えない

- 描き直しの前後で同じ部品とみなすのは、囲む見出しのセクションの `id`（#497 のセクションの開閉の記録と同じ）と、そのセクションの中で同じ種類の部品の何番目かが同じ部品。部品の中の要素は鍵（行の詳細はマーカーの `at` の行の位置、ER 図はテーブルの名前、ファイルツリーはフォルダのパス、コードの折りたたみは行番号、階層の表は行のパス）で対応を取る
- 別のセクションに部品を追加しても開閉はずれない。同じセクションの中で前に同じ種類の部品を追加したときは、後ろの部品の開閉が引き継がれない

### #525 タブの切り替えで押したタブの見出しの位置を保つ

- 押したタブの見出しの画面上の位置を、切り替えの前後で同じにする（ページの先頭・中ほど・末尾のどこにあるタブの部品でも）
- 文書の高さが縮んでスクロール位置を戻しきれないとき（タブの部品の下に短い中身しか残らないとき）は、スクロール位置の上限まで戻し、押したタブの見出しを画面の中に残す
- 再現の条件を特定し、高さの違うタブの組み合わせ（ページの先頭・中ほど・末尾）をテストに追加する

- 同じ `group` のほかのタブの部品の高さが変わるときも、押したタブの見出しの位置の差の分だけスクロール位置を戻す（上にあるタブの高さの変化は見出しの位置の差に含まれる）
