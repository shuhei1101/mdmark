# 要件

## 要望

`dev/` を廃止し、文書を `docs/` 1 つにまとめる。
移した後の構成は ai-monitor#3307 の [モニター.md](https://github.com/shuhei1101/ai-monitor/blob/1ac77c7c7/docs/pr/3307/モニター.md) の `### 種類のフォルダ` と `### 置き場所の規則` に合わせる。

| 今 | 移した後 |
| --- | --- |
| `dev/設計書/{種別}/`（YAML の設計書） | `docs/{kind}/`（`scenario`・`interface`・`module`・`component`・`screen`・`config`・`er`・`external-api`・`library`・`architecture`・`nonfunctional`・`dev-command`・`test-procedure`） |
| `dev/設計書/デザイン方針.md` | `docs/design-policy.md` |
| `dev/テンプレート/*.schema.yaml` | `schemas/{kind}.schema.yaml` |
| `dev/index.yaml`・`dev/設計書/index.yaml`・`dev/テンプレート/index.yaml`・`dev/コーディング規約/index.yaml`（目次だけ） | `docs/index.yaml` にまとめる |
| `dev/pr/`・`dev/mock/` | `docs/pr/`・`docs/mock/` |
| `docs/はじめに/`・`docs/使用方法/`・`docs/リファレンス/` | `docs/guide/`（はじめに・使い方・リファレンスはメタデータの分類） |

- 種類のフォルダの中はフラットにし、YAML の設計書のファイル名は `{ID}.yaml`（言語の規約を注入する種別は `{ID}.{lang}.yaml`）、Markdown は今のファイル名を保ち、サブフォルダにあったものは `{サブフォルダ}-{ファイル名}` にする
- 起点の索引は `docs/index.yaml` の 1 つにし、行が種類のフォルダを指す
- 公開範囲は各文書のメタデータ `visibility`（YAML の文書はキー、Markdown などは `files.yaml` の行）で持つ。今の `docs/` の下の文書は `public`、`dev/` から移す文書は `internal` にする
- `docs/_config.yml` の `exclude` に `internal` の種類のフォルダと `pr/`・`mock/`・`generated/` を載せ、Pages に出さない
- 種類のフォルダへ移す前に、AI Monitor の v0.4.0 の変換（設計書の参照をパスから ID へ書き換える）を `dev/` の置き場所のまま掛ける。変換は ai-monitor の [f135cff63](https://github.com/shuhei1101/ai-monitor/commit/f135cff63c1f6b4089f3db4bfdc1b2cb5bcdcb71) 以降、ai-monitor#3307 のマージの前の develop の `dev/テンプレート/変換/v0.4.0.py` を使う（[#454 の連絡](https://github.com/shuhei1101/mdmark/issues/454#issuecomment-6747091819)）
- `dev/` と今の `docs/` のパスを指す `CLAUDE.md`・`README.md`・`dev-docs.yaml`・`docs/rules.yaml`・各フォルダの `files.yaml`・`guide/index.yaml`・`.gitignore`・`biome.json`・コード・テストを、移した後の置き場所に合わせる
- develop に入った `tmp/screenshots/` の PNG 43 件を削除し、`tmp/` に中身が `*` だけの `.gitignore` を置く
- 移した後に、単体・結合テストと lint が全 pass し、dev-docs の `search_docs` で設計書・ガイドを引ける
