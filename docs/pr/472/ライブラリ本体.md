## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参照の変換 | 移す前に `dev/` の置き場所のまま AI Monitor の v0.4.0 の変換を掛け、設計書の参照をパスから ID へ書き換えて 1 commit にする | 変換は ai-monitor の f135cff63 以降、#3307 のマージの前の develop の `dev/テンプレート/変換/v0.4.0.py` |
| 設計書の置き場所 | `git mv` で `docs/{kind}/{ID}.yaml` へ移す。サブシステムごとのフォルダはメタデータへ移し、フォルダごとの `README.md`・`index.yaml` は `docs/index.yaml` にまとめる | 中身は変えない |
| Schema | `dev/テンプレート/*.schema.yaml` を `schemas/{kind}.schema.yaml` へ移し、`visibility`・分類のキーを持たせる | `schemas/` の既存の設定・索引の Schema とは名前を分ける |
| 公開ドキュメント | `docs/はじめに/`・`docs/使用方法/`・`docs/リファレンス/` を `docs/guide/` へ移し、分類はメタデータで持つ | Pages の URL は `docs/guide/` の下へ変わる |
| 公開範囲 | `docs/` から移す文書は `visibility: public`、`dev/` から移す文書は `visibility: internal` | |
| Pages の除外 | `docs/_config.yml` を作り、`exclude` に `internal` の種類のフォルダと `pr/`・`mock/`・`generated/` を載せる | |
| パスを指す設定・コード・テスト | `dev-docs.yaml`・`docs/rules.yaml`・各 `files.yaml`・`guide/index.yaml`・`src/`・`scripts/`・`tests/`・`biome.json`・`.gitignore` を移した後のパスに合わせる | 振る舞いは変えない |
| 一時ファイル | `tmp/screenshots/` を削除し、中身が `*` だけの `tmp/.gitignore` を置く | |

### v0.4.0 の変換

ai-monitor の [f135cff63](https://github.com/shuhei1101/ai-monitor/commit/f135cff63c1f6b4089f3db4bfdc1b2cb5bcdcb71) の `dev/テンプレート/変換/v0.4.0.py` を `dev/` の置き場所のまま掛けた（[d7054942](https://github.com/shuhei1101/mdmark/commit/d7054942)）。
変換はモジュール構成を物理ファイルごとに分けるときに、テストファイル 74 件の振り分け先を決められずに止まったため、手元の写しだけで次を足して掛けた（写しは commit していない）。

- テストの名前の末尾の `.browser` を外す（`mount.browser.test.ts` → `mount`）
- フォルダが合わないときは、名前が 1 つだけ当たる物理ファイルへ振り分ける（`tests/unit/git-env.test.ts` → `tests/git-env.ts`）
- 同じフォルダに同じ名前の物理ファイルが 2 つあるときは、テストと拡張子が同じものを選ぶ（`tests/unit/src/index.test.ts` → `src/index.ts`）
- 名前が当たらないときは、末尾の `-{語}` を外して当て直す（`mount-view.browser.test.ts` → `src/mount.ts`）

あわせて、アンカーの無い参照 `dev/設計書/ER図/mapの補足.yaml` を `dev/設計書/ER図/mapの補足#` に直してから掛けた。
