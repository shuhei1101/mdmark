## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| アクセシビリティ（#816） | `renderTableTools` が返すつまみに、描いた直後から `aria-valuenow`・`aria-valuetext`・`aria-valuemin`・`aria-valuemax` を入れる。描く時点の値の決め方は部品設計で決める | 操作を付けた後は今のとおり `table-resize.interact.ts` が更新する |
| レスポンシブ対応（#817） | スマホ幅（48rem 未満）で開いたテーブル設定のパネルの高さの上限を画面の高さの 25%（`25dvh`）にし、列の一覧をパネルの中でスクロールさせる。パネルの出し方（開くパネル）と位置の決め方は今のまま | モック作成でユーザーが案 A を選んだ（[確認事項](https://github.com/shuhei1101/mdmark/pull/824#discussion_r4716105350)） |
| 列の幅の決め方（#812） | 折り返さない列の既定の幅を、その列の全てのセルのうち一番長い中身の幅に余白を加えた幅以上にする。再現する条件（`width.mode`・セルの値・表の種類）を特定してから計算か計測を修正する | - |
| 列の幅のつまみ（#812） | 折り返さない列はつまみで一番長い中身の幅より狭くできないようにし、「幅を変えた `nowrap` の列は折り返す」を取り消す | 折り返す列は、最も長い半角の単語（空白で区切った半角の英数字・記号の連なり）が収まる幅を下限に加え、`width.max` より優先する（折り返す振る舞いは今のまま） |
| Storybook のストーリー | `SettingsOpenPhone` に `parameters.viewport` で 390x844 を指定し、結合テストのストーリーを 48rem 未満で描く | 部品設計・画面設計のレビューの細部 |
| 既存機能への影響 | 表のカスタム要素（`<mdmark-table>`）も同じ部品を使用するため、同じ振る舞いになることを結合テストで確認する | - |
