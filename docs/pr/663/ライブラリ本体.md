## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 閉じたグループのノード | タイトルの行（開くボタン・名前）を 1 行目、「{種類} {数} 件」を 2 行目に描き、2 つの行の矩形が重ならない | 構成図・ER 図・状態遷移図・クラス図・アーキテクチャ図・C4 図で共通 |
| 閉じたグループの高さ | 配置の結果の高さが 2 行に足りないときは、2 行が収まる高さで配置する | 高さを変えるかは部品設計で決める |
| 線の経路探索 | 先に引いた線が通った格子の区間に重みを足して、後の線が別の通り道を選ぶ | 線を引く順は今のまま |
| 避けられない区間 | 同じ区間を通る線を、区間の向きと直角にずらして並べ、線どうしの間を空ける | ずらす幅は設計で決める |
| 既存の制約 | 線が端点とその祖先以外の矩形を横切らない・祖先の枠の出入りが 1 回・同じ点から出る・入る線の端を 16px ずつずらすことは変えない | - |
| 既存機能への影響 | 線が 1 本だけの区間と、同じ点から出る・入る線の端の形は変えない | 既存の単体・結合テストの線の座標の期待値は、重なりを避けて変わる分だけ直す |
