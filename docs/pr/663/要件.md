# 要件

## 要望

| 子 | 終わりの条件 |
| --- | --- |
| [#608](https://github.com/shuhei1101/mdmark/issues/608) | 閉じたグループのノード（構成図・ER 図・状態遷移図・クラス図・アーキテクチャ図・C4 図）で、「{数} 件」がタイトルの行の下に描かれ、重ならない |
| [#613](https://github.com/shuhei1101/mdmark/issues/613) | 複数のノードから出る線が同じ区間を重ならずに通り、画面で線の出どころを追える |

- 閉じたグループのノードは、1 行目にタイトルの行（開くボタン・名前）、その下の行に「{種類} {数} 件」を描き、ノードの高さは 2 行が収まる高さにする
- 構成図の線の経路探索は、先に引いた線が使った区間を後の線が避け、避けられない区間では線どうしを重ねずに並べて通す
- 線が端点とその祖先以外の矩形を横切らないことと、祖先の枠の出入りが 1 回であることは今のまま保つ
- 同じ経路探索を使う ER 図・状態遷移図・クラス図・アーキテクチャ図・C4 図でも、線が同じ区間を重ならない
