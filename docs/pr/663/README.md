# map の閉じたグループの「{数} 件」をタイトルの行の下に描き、構成図の線が同じ通り道に重ならないようにする

## 概要

読者が、map の閉じたグループで「{数} 件」をタイトルと重ならずに読め、構成図で複数のノードから出る線の出どころを追える。

## 背景

束の親 [map の閉じたグループの「{数} 件」をタイトルの行に重ねずに描き、構成図の線が同じ通り道に重ならないようにする](https://github.com/shuhei1101/mdmark/issues/662) の要望で、次の 2 つの子 Issue を 1 つの作業 PR で直す。

- [map の閉じたグループのノードで、「{数} 件」をタイトルの行に重ねずに描く](https://github.com/shuhei1101/mdmark/issues/608): 作業 PR [#596](https://github.com/shuhei1101/mdmark/pull/596) のストーリーを撮って確かめたときに見つかった。`src/index.css` の `.map-group-head` が絶対位置（`top: 6px`）で、その後ろに置く `.map-closed-count` がタイトルの行を避けない
- [map の構成図で、複数のノードから出る線が同じ通り道に重なり、出どころを追えない](https://github.com/shuhei1101/mdmark/issues/613): 作業 PR [#610](https://github.com/shuhei1101/mdmark/pull/610) で map に書き換えた図を確かめたときに見つかった。`src/map/layout.ts` の `routeEdges` は線を 1 本ずつ別々に探し、先に引いた線が使った区間を次の線の重みに入れない
