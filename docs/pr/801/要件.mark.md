# 要件

## 要望

- 表のセルの中の `![名前](パス.mp4)` は、属性の指定が無くても、その場に再生バーを出さず、押すとモーダルで動画を再生する
- 段落の動画は、画像の後ろの属性（`{width=320 autoplay loop}` と同じ記載方法）にモーダルで再生する属性を記載すると、表のセルの中と同じくモーダルで再生する
- 属性を記載しない段落の動画は、今までどおりその場に再生バーを持つ図で描く
- モーダルは、画像のライトボックスと同じ開き方・閉じ方（Esc・閉じるボタン・背景を押す）にし、閉じると再生を止めてフォーカスを押した場所へ戻す
- 描いた後、表のセルの中のモーダルにした動画に、壊れた画像（読み込めない `img`）が残らない
- 表のセルのほかの狭い場所（箇条書きの中・文の途中）の動画は、属性を記載しなければ今のまま描く（文の途中は段落の後ろに図を配置する）。`modal` の属性を記載すれば、記載した場所にその場に出すものを配置する
- 表のセルの中の音声も、動画と同じくモーダルで再生する
- 画像のライトボックスの切り替えの並びに、動画・音声を含めない
- モーダルで再生する属性の名前は `modal`

`未確定`: その場に出すもの（決める工程: モック作成）
