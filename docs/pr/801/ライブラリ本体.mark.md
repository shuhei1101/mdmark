## 変更方針

<!-- table: {"kind": "data"} -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 単一 UC | SC-472-67 に、表のセルの中の動画と属性を記載した段落の動画を、その場に出すものとモーダルで描くシナリオを追加する。新規の単一 UC『動画と音声をモーダルで再生する』（`docs/scenario/SC-801-1.yaml`）に、読者がモーダルで再生して閉じるシナリオを置く。SC-472-58 に印刷のシナリオを追加する | 狭い場所・音声・属性の名前は `未確定`（[要件](./要件.mark.md)） |
| 記法 | 画像の後ろの属性にモーダルで再生する属性を追加し、動画・音声だけで読み込む。画像に記載したら記載の警告にする | 破壊的変更にしない（属性の無い段落の動画の HTML は変えない） |
| 表のセルの中の動画 | `buildImageFigures` で、表のセルの `inline` の動画・音声を、属性の指定が無くてもモーダルにしてその場に出すものにする | - |
| モーダル | ライトボックスの `dialog` と開閉・フォーカスの戻し方を動画・音声へ広げ、閉じたら再生を止める | 画像の切り替えの並びに動画を入れるかは設計で決める |
| その場に出すもの | 部品『動画と音声』に状態を追加する | `未確定`（決める工程: モック作成） |
| 印刷 | モーダルにした動画は、その場に出すものとキャプションを印刷する | - |
| `media` がオフ | 今と同じく動画・音声を画像として扱い、モーダルにしない | - |
| アクセシビリティ | その場に出すものを Tab でフォーカスでき、Enter で開ける。スクリーンリーダー向けの名前に動画のラベルを入れる | - |
