## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 変換 | `flow`・`sequence` の部品の定義を読み、`<!-- map -->` の範囲（`flowchart` か `sequenceDiagram` の `mermaid` のブロックと補足）に書き換える。座標は写さず自動配置に任せる | 置き場所は要件の `未確定`（推奨: 移行の手順） |
| 写せない値の報告 | map に写す先の無い値（題の行の範囲・更新日、`stickyTitles`）は落として、文書・行・項目を変換の報告に挙げる。配置の値（座標・大きさ）は写さず報告にも挙げない。部品の定義を読めない範囲は書き換えずに報告に挙げる | - |
| ノードのリンク | map の `flowchart` の `click` の行を読み捨てずに、ノードのリンク先として描く。許可しないリンク先は今のフロー図と同じ決まりで開かない | MOD-472-137 の「`click` は読んで捨てる」を修正する |
| 種類の設定 | フロー図のノードの種類と線の種類を、設定の `map.kinds`・`map.lines` に名前・アイコン・模様として作り、Mermaid のクラスと補足の `layout` の `line` で指す | 設定に同じ名前の行があれば書き換えない |
| 書き方の警告 | `flow`・`sequence` の範囲は描かずに、map へ変換できる旨と変換の方法を出す | 文言は画面設計で決める |
| 点検 | `mdmark check` が `flow`・`sequence` の範囲を、変換できる旨の通知にする。フロー図の定義の誤り・配置のずれ・`frame.hint` の点検は削除する | - |
| 廃止 | `flow`・`sequence` を読む処理・描く処理・custom element・ストーリー・テストを削除する | map が使う見た目の部品と、`chart`・`param`・`er` は残す。判定フローチャートは `flow` の部品のため変換して廃止する |
| 既存機能への影響 | map の構成図とシーケンス図は、今のフロー図・シーケンス図の部品で描いているため、残す部品の範囲を設計で確定してから削除する | 要件.yaml の `run_only` の行で確かめる |
| このリポジトリの図 | 使い方集・見本・設計書・モックの `flow`・`sequence` の図を変換で書き換え、報告に挙がった値を手で直す | 更新ドキュメント |
| 設定の Schema | 図の機能のキーの description から `flow`・`sequence` を削除する | `migrations/no-steps.yaml` に行を置く |
