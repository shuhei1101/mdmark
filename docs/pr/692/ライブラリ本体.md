## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| コピーの対象の文書 | 今の集め方（検めた後の設定の `build` の対象と、索引のフォルダの下の Markdown）に、検める前の設定の `build.include`・`build.exclude` の文書と、索引の `docs[].path` が指す文書を合わせる | 要件の案 A。インターフェース定義『バージョンを上げる』の制約「文書」 |
| 戻し方 | 手順の失敗か点検のずれがあればコピーから全て戻す今の設計は変えない | - |
| 移行の手順の配布物 | 出したバージョンの `migrations/v{バージョン}/` のスクリプトは書き換えない | - |
