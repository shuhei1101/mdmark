# 要件

## 要望

map のシーケンス図で、自分へのメッセージ（送り手と受け手が同じメッセージ）のラベルの札を、右へ折り返す線と重ならない位置に描く。

- ラベルの札の矩形と、折り返しの線（上の辺・右の辺・下の辺と矢じり）が重ならない
- ラベルの札と線のあいだに間を空ける
- ほかの参加者へのメッセージのラベルの位置は変えない
- 補足の `notes` を持つ自分へのメッセージでも、線の押せる帯とツールチップは今と同じに付く
