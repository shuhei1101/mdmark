# map のシーケンス図で、自分へのメッセージのラベルを折り返しの線と重ならない位置に描く

## 概要

map のシーケンス図で、自分のライフラインから出て自分のライフラインに戻るメッセージ（自分へのメッセージ）の線と、そのメッセージのラベルの札が重ならないように、間を空けて描く。

## 背景

[Issue #680](https://github.com/shuhei1101/mdmark/issues/680) の要望。MindStella の資料に埋め込んだ map のシーケンス図（`node->>node: Bash で完了ファイルを、上限の時間まで待つ` など）で、自分へのメッセージの線とラベルが同じ場所に重なって描かれる。

`src/map/map.part.ts` の `seqMessageLabel` は、ラベルの札の中心を線の左右の中点・線の高さの 14px 上に置く。
自分へのメッセージは送り手と受け手が同じため中点がライフラインの上になり、`seqMessageGeometry` が右へ 40px 折り返して描く線（ライフラインの 8px 上から 8px 下まで）の上の辺に札が重なる。
原因は mdmark の描画にあり、MindStella の側は直さない。
