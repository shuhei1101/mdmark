## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品設計 | CMP-472-4 の `states` に、自分へのメッセージ（補足の `notes` を持つ）の状態を追加し、ラベルの札が折り返しの線と重ならず間を空けて描かれることを記載する | - |
| ラベルの位置 | 自分へのメッセージのラベルの札の中心の左右を折り返しの左右の中央（ライフラインの 20px 右）にし、札の下端を折り返しの上の辺の 6px 上に置く。ほかのメッセージのラベルの位置は変えない | - |
| 線の形 | 折り返しの線の形（`d`）とデータの印の道筋は変えない | - |
| ストーリー | 自分へのメッセージを持つ状態のストーリーを追加する | - |
| テスト | 単体テストで、自分へのメッセージのラベルの札の中心が折り返しの左右の中央にあることと、札の下端が折り返しの上の辺より 6px 上にあることを確かめる。結合テストで、ブラウザで描いたラベルの札の矩形と折り返しの線の矩形が重ならないことを確かめる | - |
