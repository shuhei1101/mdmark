## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品設計 | CMP-472-4 の `states` に、自分へのメッセージ（補足の `notes` を持つ）の状態を追加し、ラベルの札が折り返しの線と重ならず間を空けて描かれることを記載する | - |
| ラベルの位置 | 自分へのメッセージのラベルの札を、折り返しの線の右の辺より右に、左端を揃えて置く。ほかのメッセージのラベルの位置は変えない | 線と札のあいだの間の px は部品設計で決める |
| 線の形 | 折り返しの線の形（`d`）とデータの印の道筋は変えない | - |
| ストーリー | 自分へのメッセージを持つ状態のストーリーを追加する | - |
| テスト | 単体テストで、自分へのメッセージのラベルの左端が折り返しの線の右の辺より右にあることを確かめる。結合テストで、ブラウザで描いたラベルの札の矩形と折り返しの線の矩形が重ならないことを確かめる | - |
