### #685 map の手順の再生で倍率を変えない

| No | 要件 | 測り方 |
| --- | --- | --- |
| 1 | 手順のバーの区切り・左右の矢印のボタン・矢印キーで手順を移したとき、図の倍率（倍率のボタンの文字。全体が収まる倍率を 100 % とした倍率）を変えない | 倍率のボタンの文字が、手順を移す前と後で同じ（100 %・300 % の両方） |
| 2 | 倍率が 100 % で、図の全体が表示する枠に収まっているときは、図の位置も変えない | 手順を移す前と後で、図の中身の矩形の位置が同じ |
| 3 | 倍率が 100 % より大きいときは、強調するノード（シーケンス図の線は送り手と受け手）を囲む矩形の中心を、表示する枠の中心へ移す | 手順を移した後、矩形の中心と表示する枠の中心の差が 1px 以内（図の端で移せない分を除く） |
| 4 | グループに入る・出る手順で図の中身が変わるときも、倍率のボタンの文字を保つ。100 % のときは、入った（出た）後の中身の全体が収まる倍率に合わせる | グループに入る・出る手順の前と後で、倍率のボタンの文字が同じ（100 %・300 % の両方） |
| 5 | 構成図の案内・シーケンス図の再生・状態遷移図・`C4Dynamic`・ガントチャート・タイムライン・Git グラフ・ジャーニーの全ての帯で同じ動きにする | 帯を持つ図の種類ごとに 1〜4 と同じ測り方 |

倍率が 100 % でも図の全体が表示する枠に収まらないとき（全体が収まる倍率の下限 0.75 で止めた mermaid の図など）は、インターフェース定義設計でユーザーと決めた（強調するノードが表示する枠に見えているときは位置を変えず、見えていない部分があるときだけ倍率を変えずに中央へ移す）。

### #697 言語が markdown のコードブロックでソースと描いた結果を切り替える

| No | 要件 | 測り方 |
| --- | --- | --- |
| 1 | 言語が `markdown` か `md` のコードブロックに、描いた結果の表示と元の Markdown の表示を切り替える操作を付ける | 言語が `markdown`・`md` のコードブロックに Raw のボタンがあり、ほかの言語のコードブロックには無い |
| 2 | 既定は描いた結果の表示にする。code のマーカーで、コードブロックごとに既定を元の Markdown の表示にできる | 描いた直後に描いた結果の要素が見え、元の Markdown の `pre` が隠れている。マーカーで指定したコードブロックは逆になっている |
| 3 | 帯のコピーボタンの左に Raw のボタンを配置し、押すと元の Markdown を出し、もう一度押すと描いた結果に戻る | Raw のボタンを押した後に元の Markdown の `pre` が見え、描いた結果の要素が隠れる。もう一度押すと逆になる |
| 4 | 切り替えの操作をキーボードとスクリーンリーダーで使用できる | ボタンにフォーカスして Enter・Space で切り替わり、押した状態（`aria-pressed` など）が今の表示と一致する |
| 5 | このリポジトリの `docs/guide/` の、記法の書き方を見せる言語 `markdown`・`md` のコードブロックは、既定を元の Markdown の表示にする | 書き方の例のコードブロックが、描いた直後に元の Markdown の表示になっている |

描く中身は、インターフェース定義設計でユーザーと決めた（文書と同じ mdmark の描き方で描き、目次・先頭へ戻る・Markdown のエクスポート・被参照・コメント・印刷の処理は中に付けない）。

既定を元の Markdown にする code のマーカーのキーは、インターフェース定義設計でユーザーと決めた（`raw`。真偽値で、既定は `false`）。

切り替えの操作の置き場所と見た目は、モック作成でユーザーと決めた（帯のコピーボタンの左に、コードのアイコンと「Raw」の文字のボタン）。

既存の文書の言語 `markdown`・`md` のコードブロックは、モック作成でユーザーと決めた（このリポジトリの `docs/guide/` の書き方の例にだけ、既定を元の Markdown にする code のマーカーを追加する。配布先の利用者の文書は、バージョンを上げた時点で描いた結果に変わる）。
