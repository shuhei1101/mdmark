### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 対象の言語 | 言語が `markdown`・`md` のコードブロックだけ | 言語 `tree`・図の部品の定義・`<!-- html -->` の範囲のコードブロックは今のとおり |
| 既定の表示 | 描いた結果の表示 | code のマーカーで、コードブロックごとに既定を元の Markdown の表示にできる（マーカーの書き方はインターフェース定義設計で決める） |
| 切り替えの操作 | 帯のコピーボタンの左の Raw のボタン 1 つで、描いた結果と元の Markdown を切り替える。押した状態（元の Markdown を出している）を `aria-pressed` で持つ | モック作成でユーザーと決めた |
| 描く中身 | 外の文書と同じ設定で、文書の単位で付く機能（右側の目次・先頭へ戻る・Markdown のコピーとエクスポート・被参照・コメント・印刷の処理）を切って描く | インターフェース定義設計でユーザーと決めた |
| 描く時期 | 文書を描くときに描く。マーカーで既定を元の Markdown にしたコードブロックは、初めて描いた結果に切り替えたときに描く | - |
| コピー | どちらの表示でも、コードブロックに記載した Markdown をコピーする | - |
| 印刷 | Raw のボタンを出さず、印刷した時点で出している側をそのまま出す | 部品設計で決めた。`docs/guide/カスタマイズ-印刷する.mark.md` に反映する |
| `render`（HTML 文字列） | `render` はコードブロックに `data-mdmark-markdown`・`data-mdmark-raw` だけを付け、Raw のボタンと描いた結果は `mount` が `code-preview.interact.ts` で付ける | ブラウザと Node で同じ文字列を返す制約を守る |
