### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 倍率 | 手順を移しても、読者の今の倍率を変えない | 全ての帯の図で共通（`createFollow` を使う全ての図） |
| 位置（100 %） | 全体が収まる倍率のときは、位置も変えない | `未確定`: 図が収まらないときの扱い（`要件.md` の `## 要望`） |
| 位置（100 % より大きい） | 強調するノードを囲む矩形の中心を、表示する枠の中心へなめらかに移す。図の端より外へは移さない | 動きを減らす設定では時間をかけずに移す（今のとおり） |
| 読者が触った後 | 今のとおり、次にバーか矢印のボタンを押すまで図を移さない | - |
| 停止 | 今のとおり、始めたときの倍率と位置へ戻す | `要件.yaml` のスコープ外の 2 行目 |

### 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 対象の言語 | 言語が `markdown`・`md` のコードブロックだけ | 言語 `tree`・図の部品の定義・`<!-- html -->` の範囲のコードブロックは今のとおり |
| 既定の表示 | 描いた結果の表示 | code のマーカーで、コードブロックごとに既定を元の Markdown の表示にできる（マーカーの書き方はインターフェース定義設計で決める） |
| 切り替えの操作 | 帯のコピーボタンの左の Raw のボタン 1 つで、描いた結果と元の Markdown を切り替える。押した状態（元の Markdown を出している）を `aria-pressed` で持つ | モック作成でユーザーと決めた |
| 描く中身 | `未確定`（`要件.md` の `## 要望`） | 推奨は文書と同じ描き方 |
| 描く時期 | 文書を描くときに描く。マーカーで既定を元の Markdown にしたコードブロックは、初めて描いた結果に切り替えたときに描く | - |
| コピー | どちらの表示でも、コードブロックに記載した Markdown をコピーする | - |
| 印刷 | 印刷のときに出す表示は部品設計で決める | `docs/guide/カスタマイズ-印刷する.mark.md` に反映する |
| `render`（HTML 文字列） | 切り替えのボタンと描いた結果は `mount` の操作が付け、`render` の出力は変えるかを部品設計で決める | ブラウザと Node で同じ文字列を返す制約を守る |
