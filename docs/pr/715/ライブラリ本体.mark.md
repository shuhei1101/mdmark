## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参加者のノードのポインター | 参加者の箱（`div.map-participant`。名前の文字と種類の行の上を含む）にポインターを合わせている間、その参加者を 1 人選んだときと同じ `map-dim` とデータの印を付け、箱とライフラインの外へ出たら解く。`state.selected` と sessionStorage は変えない | 選択・再生の強調があるときは出さない。選択を解いた直後は外へ動かすまで出さない |
| ライフラインのポインター | ライフラインに透明な判定の線（`data-lifeline` を持つ）を重ね、合わせたときに参加者のノードと同じ表示にする | 判定の幅はメッセージの線の `.map-wire-hit` に合わせる |
| ドラッグ中 | 並べ替えのドラッグの間は、ポインターの強調を出さない | - |
| タッチの端末 | `pointerType` が `touch` のときはポインターの強調を出さない | タップで選ぶ操作は変えない |
| 既存機能への影響 | 押して選ぶ・並べ替え・Esc・メッセージの線のポインター・再生の表示は変えない | - |
