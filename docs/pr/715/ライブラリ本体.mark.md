## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参加者のノードのポインター | 押せる要素（`span.mdmark-diagram-node-hit`）にポインターを合わせている間、その参加者を 1 人選んだときと同じ `map-dim` とデータの印を付け、外したら外す。`state.selected` と sessionStorage は変えない | 選択・再生の強調との重なりは `未確定`（[要件](./要件.mark.md)） |
| ライフラインのポインター | ライフラインに透明な判定の線（`data-lifeline` を持つ）を重ね、合わせたときに参加者のノードと同じ表示にする | 判定の幅はメッセージの線の `.map-wire-hit` に合わせる |
| ドラッグ中 | 並べ替えのドラッグの間は、ポインターの強調を出さない | - |
| タッチの端末 | - | `未確定`（[要件](./要件.mark.md)） |
| 既存機能への影響 | 押して選ぶ・並べ替え・Esc・メッセージの線のポインター・再生の表示は変えない | - |
