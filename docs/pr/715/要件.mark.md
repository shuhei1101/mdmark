# 要件

## 要望

map のシーケンス図（範囲の外の純粋な Mermaid のシーケンス図を含む）で、次の状態にする。

- 参加者のノードにポインターを合わせている間、その参加者を 1 人選んだときと同じ表示にする（その参加者が送る・受けるメッセージとライフラインのほかを薄くし、そのメッセージの線の上をデータの印が流れる）
- 参加者のライフラインにポインターを合わせている間も、その参加者のノードに合わせたときと同じ表示にする
- ポインターを外したら、合わせる前の表示に戻す
- ノードを押して選ぶ・ドラッグで並べ替える・Esc で解く操作と、メッセージの線のポインターの表示は変えない

ライフラインは 1px の破線のため、メッセージの線の `.map-wire-hit` と同じく、ポインターを合わせられる幅の透明な判定の線を重ねる。

参加者を選んでいる間・再生している間は、ほかの参加者にポインターを合わせても表示を変えない（選択・再生の強調を優先する。メッセージの線のポインターと同じ扱い）。

選択を解いた直後は、ポインターをその参加者のノード・ライフラインの外へ一度動かすまで、ポインターの強調を出さない。

タッチの端末（`pointerType` が `touch`）ではポインターの強調を出さず、今のタップで選ぶ操作だけにする。
