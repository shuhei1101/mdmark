# 要件

## 要望

map のシーケンス図（範囲の外の純粋な Mermaid のシーケンス図を含む）で、次の状態にする。

- 参加者のノードにポインターを合わせている間、その参加者を 1 人選んだときと同じ表示にする（その参加者が送る・受けるメッセージとライフラインのほかを薄くし、そのメッセージの線の上をデータの印が流れる）
- 参加者のライフラインにポインターを合わせている間も、その参加者のノードに合わせたときと同じ表示にする
- ポインターを外したら、合わせる前の表示に戻す
- ノードを押して選ぶ・ドラッグで並べ替える・Esc で解く操作と、メッセージの線のポインターの表示は変えない

ライフラインは 1px の破線のため、メッセージの線の `.map-wire-hit` と同じく、ポインターを合わせられる幅の透明な判定の線を重ねる。

`未確定`: 参加者を選んでいる間・再生している間に、ほかの参加者にポインターを合わせたときの表示（決める段: 部品設計）

| 案 | 内容 |
| --- | --- |
| A | 選択・再生の強調を優先し、ポインターでは表示を変えない（メッセージの線のポインターと同じ扱い） |
| B | ポインターを合わせている間だけ、合わせた参加者の強調に差し替え、外したら選択・再生の強調に戻す |

推奨: A

メッセージの線のポインターが、選択・再生の強調があるときは薄くしないため、同じ扱いにすると図の中で振る舞いがそろう。選んだ参加者の強調を見ている途中でポインターが通るたびに表示が変わらない。

`未確定`: タッチの端末での扱い（決める段: 部品設計）

| 案 | 内容 |
| --- | --- |
| A | ポインターの種類が `touch` のときはポインターの強調を出さず、今のタップで選ぶ操作だけにする |
| B | タップでもポインターの強調を出す |

推奨: A

タッチの端末にはポインターを合わせる操作が無く、タップは既に選ぶ操作で同じ強調を出すため。
