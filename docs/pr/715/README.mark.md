# map のシーケンス図で、参加者のノードとライフラインにポインターを合わせたときに、選んだときと同じ強調を出す

## 概要

読者が、map のシーケンス図の参加者のノードかライフラインにポインターを合わせるだけで、その参加者を選んだときと同じ強調を見られ、ポインターを外すと元の表示に戻るようにする。

## 背景

[#681](https://github.com/shuhei1101/mdmark/issues/681) の要望（MindStella の話し合いのスレッド TH-1251）。
今のシーケンス図は、メッセージの線にポインターを合わせたときだけ、その線と送り手・受け手のほかを薄くする（`src/map/sequence-view.ts` の `onPointerOver`）。
参加者のノードとライフラインにはポインターの処理が無く、参加者の強調はノードを押して選ばないと見られない。
