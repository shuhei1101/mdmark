# 表の列の幅を、見出しの右端をドラッグして変えられるようにし、ダブルクリックで元の幅に戻す

## 概要

表を参照する人が、列の見出しの右端をドラッグしてその列の幅を変え、ダブルクリック（スマホではダブルタップ）で元の幅に戻せるようにする。

## 背景

[表の列の幅を、見出しの右端をドラッグして変えられるようにし、ダブルクリックで元の幅に戻す](https://github.com/shuhei1101/mdmark/issues/359) の要望。
今の表の列の幅は、文書に記載する `wide=列名`（[はみ出す表は既定で先頭の列をピン止めし、pin=・wide= と真偽値の ✓ 表示を追加する](https://github.com/shuhei1101/mdmark/pull/283)）でしか変えられず、表を参照する人は狭い列を広げたり、広い列を狭めたりできない。
留めた列の位置の計算は、[表のピン止めを選んだ列だけを留める動きにし、留めた列をスクロールの位置で左端か右端に留める](https://github.com/shuhei1101/mdmark/pull/438) で選んだ列だけを左端か右端に留める動きに変わっている。
