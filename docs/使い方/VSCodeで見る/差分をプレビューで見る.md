# 差分をプレビューで見る

VS Code の差分ビューで見ている Markdown の変更を、mdmark のプレビューで追加・削除の色分けにして読む手順

見出し・表・図の変更を、描いた見た目のまま確かめるときに実行する。
仕組みは [差分を表示する仕組み](../../はじめに/コアコンセプト/差分を表示する仕組み.md)。

## 前提

- [プレビューを開く](./プレビューを開く.md) の前提を満たしている（拡張機能を入れている）
- Git のリポジトリのフォルダを開き、Markdown の変更を差分ビューで開ける
- 読む mdmark のバージョンが差分の表示に対応している。`mdmark.version` が `latest` なら最新のバージョンを読む。固定しているときは、対応するバージョンにする

## 手順

### 差分ビューを開く

次のどれかで、Markdown の差分ビューを開く。

| 開き方 | 比べる内容 |
| --- | --- |
| Source Control の変更から Markdown を開く | 作業ツリーの変更。ステージした変更も同じ |
| タイムラインの `変更を開く` | コミットと、その 1 つ前の差分 |
| コミットの差分を開く | 2 つのコミットの差分 |

変更前と変更後の両方が Markdown の差分ビューが対象になる。
Source Control のグラフから開く複数ファイルの差分エディターは対象外。
グラフからは、1 ファイルの差分ビューを開いてからプレビューを開く。

### プレビューを開く

差分ビューを開いたまま、`Shift+Alt+D`（Mac は `Shift+Option+D`）を押す。
エディタのタイトルのボタンか、コマンドパレットの `mdmark: プレビューを横に開く` でも開く。
`mdmark: プレビューを開く` は、差分ビューと同じ列のタブに開く。
コマンドは [プレビューを開く](./プレビューを開く.md) と同じで、差分ビューのときだけ差分で描く。

差分ビューの変更前の側にフォーカスがあるときも、変更後の側を対象にする。
パネルのタブは `差分プレビュー {ファイル名}` で、同じファイルを差分でないエディタから開いたプレビューとは別になる。
変更前と変更後の組が同じパネルが既に開いているときは、新しく作らず、そのパネルを表に出す。

「変更を見る」のボタンと、リビジョンを選ぶ欄は出ない。
開いた時点で、変更後の文書が色分けされた状態で出る。

### 色分けを読む

変更後の文書を描き、変更前と比べたブロックに色を当てる。

| 見え方 | 意味 |
| --- | --- |
| 追加の色の面と、左の余白の `+` | 追加・変更したブロック |
| 削除の色の面と、左の余白の `−` | 削除したブロック。変更前の文書での位置に出る |
| 色も余白の印も無い | 変えていないブロック |

色が見分けられなくても、左の余白の `+`・`−` と、読み上げの名前の `追加:`・`削除:` で区別できる。
色は `--mdmark-color-diff-*` の CSS 変数で決まり、VS Code のテーマの明暗と、選んだ配色のテーマに従う（[テーマを上書きする](../カスタマイズ/テーマを上書きする.md)）。

ブロックは、見出し・段落・コードブロック・注意書きなどの 1 つのまとまり。
リストは項目、表は行が単位で、変えた項目・行にだけ色が当たる。
削除した番号付きリストの項目は番号を出さず、後ろの項目の番号を進めない。
見出しごと消した節は、見出しと中身が 1 つの削除したブロックになる。

語を書き換えた段落は、追加の色だけで出る。
別の内容に入れ替えた段落は、削除と追加が並ぶ。
前後のブロックの文字を語ごとに比べ、同じ文字が長い方の半分以上なら書き換え、半分未満なら入れ替えと見分ける。

行の中の語の違いは、プレビューでは色分けしない。
差分ビューが左右に並べて出している。

### 書き換えて描き直す

変更後の側が作業ツリーのファイルのときは、書き換えると、同じパネルで差分を描き直す。
描き直すきっかけは [プレビューを開く](./プレビューを開く.md) の `mdmark.preview.liveUpdate` と `mdmark.preview.updateDelayMs` に従う。
変更前の側の書き換えでは、描き直さない。

エディタとプレビューのスクロールは、差分ビューの変更後の側と合う。
削除したブロックは、合わせる先にならない。

### 描けないときに直す

読む mdmark のバージョンが差分の表示に対応しないときは、変更後の文書だけの表示を出さず、文書の代わりに次の理由と「リロード」のボタンが出る。

```text
読み込んだ mdmark（{バージョン}）は差分の表示に対応していません。設定 mdmark.version を差分の表示に対応したバージョンか latest に変更してから、リロードしてください。
```

`mdmark.version` を `latest` か、差分の表示に対応したバージョンに直してから「リロード」を押す。
Markdown と差分ビューは書き換わらない。

## 反映

即時。
`mdmark.version` を直したときは、「リロード」を押す。

## 確認

#### 色分けされている

Git のリポジトリに置いた Markdown をコミットし、段落の語を 1 つ書き換え、別の段落を 1 つ削除する。
Source Control の変更から差分ビューを開き、`Shift+Alt+D` を押す。
差分ビューの横にタブ `差分プレビュー {ファイル名}` が開く。
書き換えた段落が追加の色と `+` で出て、削除した段落が変更前の位置に削除の色と `−` で出る。
変えていない見出し・段落・表は、色も `+`・`−` も無い。

#### 書き換えで描き直される

変更後の側の末尾に段落を 1 つ追加する。
待ちのあとに、パネルを開き直さずに、追加した段落が追加の色で出る。

## 元に戻す

パネルのタブを閉じる。
Markdown・差分ビュー・Git のリポジトリは、プレビューの操作では書き換わらない。
