# HTMLとPDFにする

開いている Markdown を HTML に書き出し、ブラウザで開き、PDF に印刷する手順

VS Code で書いた Markdown を、HTML のファイルにして配るとき、ブラウザで確かめるとき、PDF にするときに実行する。

## 前提

- [プレビューを開く](./プレビューを開く.md)（拡張機能を入れている）
- 書き出した HTML を開く環境が、ネットワークにつながっている（HTML は開くときに jsDelivr の配布物を読む）

## 手順

### HTML に書き出す

#### `mdmark: HTML に書き出す` を呼ぶ

Markdown を開き、コマンドパレットで `mdmark: HTML に書き出す` を選ぶ。
Markdown と同じフォルダに、拡張子を `.html` に替えたファイルを書く。
同じ名前のファイルがあれば上書きする。

保存していない書き換えも、書き出す内容に含まれる。
書き出せたら、書き出したファイルのパスと `ブラウザで開く` のボタンを通知で出す。

#### 書き出す先を変える

```json
{
  "mdmark.export.outputDir": "out"
}
```

空（既定）のときは Markdown と同じフォルダ。
相対パスは Markdown を含むワークスペースのフォルダから、絶対パスはそのまま使う。
フォルダが無ければ作る。

### ブラウザで開く

#### `mdmark: ブラウザで開く` を呼ぶ

コマンドパレットで `mdmark: ブラウザで開く` を選ぶ。
その場で書き出し直してから、既定のブラウザで開く。
前に書き出した HTML をそのまま開かないため、直した内容が反映される。
書き出しの通知は出ない。

### PDF に印刷する

#### `mdmark: PDF に印刷` を呼ぶ

コマンドパレットで `mdmark: PDF に印刷` を選ぶ。
書き出し直した HTML を既定のブラウザで開き、描き終えた後に印刷のダイアログが出る。
ダイアログの送信先で「PDF に保存」を選ぶと PDF になる。

外部ライブラリの描画を待ってから印刷する。
待つのは 10 秒までで、超えたらそのまま印刷する。
印刷では、閉じた折り畳みが開き、配色は明るい（[印刷する](../カスタマイズ/印刷する.md)）。

VS Code の Webview の中では印刷が効かないため、プレビューの上からは印刷せず、ブラウザで開いた HTML から印刷する。

### 書き出せないときに直す

| 通知 | 起きるとき | 直し方 |
| --- | --- | --- |
| HTML を書き出せませんでした: {パス}（{理由}） | 書き出す先に書けない | `mdmark.export.outputDir` を書き込めるフォルダに直す |
| HTML を書き出せませんでした。読む mdmark のバージョンを決められません | `mdmark.version` が `latest` で、タグ一覧を取れず前回のバージョンも無い | ネットワークを確かめてから、もう一度実行する |

どちらの場合も、ブラウザは開かない。

## 反映

即時。コマンドを呼ぶたびに、その時点の Markdown と設定で書き出し直す。

## 確認

#### HTML が書き出されている

書き出し先に `{Markdown の名前}.html` がある。
ブラウザで開くと、見出し・表・注意書きが mdmark の見た目で描かれ、相対パスの画像が出る。

#### 印刷のダイアログが出る

`mdmark: PDF に印刷` を呼ぶと、ブラウザが開き、描き終えた後に印刷のダイアログが出る。

## 元に戻す

書き出した HTML を削除する。
`mdmark: PDF に印刷` で書き出した HTML は、後から手で開くと、また印刷のダイアログが出る。
`mdmark: HTML に書き出す` か `mdmark: ブラウザで開く` で書き出し直すと、印刷の処理は無くなる。
Markdown は書き換わらない。

CDN に届かない環境へ配るときは、ネットワークを要さない 1 枚の HTML を CLI の `mdmark export` で書き出す（[文書を書き出す](../書き出す/文書を書き出す.md)）。
