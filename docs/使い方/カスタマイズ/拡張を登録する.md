# 拡張を登録する

`registerExtension` で印を足す手順。TypeScript を推奨し、配る前に JavaScript へ変換する

使う側のアプリが自分の印を文書に書けるようにするとき、その印を描くモジュールを足すときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)
- TypeScript で書くときは、配布物を読み込んだタグと同じタグの `dist/` にある型定義（`index.d.ts` と、それが読み込む `.d.ts`）を、拡張を書くプロジェクトに置く

## 手順

### 拡張のモジュールを書く

#### `draw` を書く

```ts
import type { MdmarkMarkArgs } from "./mdmark/index.js";

export function draw(slot: HTMLElement, value: MdmarkMarkArgs): void {
  slot.textContent = `こんにちは、${value.args[0]}`;
}
```

拡張は TypeScript と JavaScript のどちらでも書ける。
TypeScript で書くことを推奨する。
`draw` の引数に配布物の型が付き、書き間違いを配る前に型検査で見つけられる。
`slot` は印の場所の要素、`value.args` は `キー=値` でない引数を書いた順に並べたもの、`value.keys` は `キー=値` の引数。
`draw` は Promise を返す非同期でもよい。
`draw` が例外を投げると、その印の場所だけが知らせの枠に替わる。

### 配る

#### JavaScript に変換する

```bash
npx esbuild extensions/greet.ts --format=esm --outfile=public/extensions/greet.js
```

`load` が `import()` で読むのはブラウザなので、配るのは JavaScript にしたファイルだけ。
TypeScript のファイルは配らない。
変換の道具は使う側で選ぶ。
上は esbuild の例。

### 登録する

#### `registerExtension` を呼ぶ

```js
import { registerExtension } from "https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{タグ}/dist/index.js";

registerExtension({
  name: "greet",
  directive: "greet",
  load: () => import("/extensions/greet.js"),
});
```

`{タグ}` は CSS を読み込んだタグに置き換える。
`mount` や `update` で描く前に呼ぶ。
描いた後に登録した印は、次の `mount`・`update` から効く。
`name` は知らせの枠・書き方の警告・`console.error` に出す名前、`directive` は印の名前。
`directive` は英小文字で始まり、英小文字・数字・`-` だけを持つ。
`features` と記法の印（`table`・`tabs`・`steps`・`section`・`row-detail`・`fig`・`toc`・`glossary`）と、登録済みの拡張の `directive` は使えず、`Error` を投げて登録しない。
書式に合わない項目があると `TypeError` を投げて登録しない。
設定の `libraries` に同じ名前があるときは、拡張を優先する。

#### 引数を検査する

```ts
import * as v from "valibot";

registerExtension({
  name: "greet",
  directive: "greet",
  load: () => import("/extensions/greet.js"),
  schema: v.object({
    args: v.strictTuple([v.pipe(v.string(), v.regex(/^[a-z]+$/))]),
    keys: v.record(v.string(), v.string()),
  }),
});
```

印の引数を検査するときだけ `schema` を渡す。
`schema` は Standard Schema で、zod・valibot など `~standard` を持つ検査ライブラリの schema をそのまま渡せる。
mdmark は検査ライブラリを束ねない。
検査する値は `{ args: string[]; keys: Record<string, string> }`。
valibot の `tuple` は余る引数を許すため、引数の数を限るときは `strictTuple` を使う。
引数が合わない印の場所は、モジュールを読まずに書き方の警告に替わる。

### 文書に印を書く

#### 拡張の印を書く

```markdown
<!-- greet: world lang=ja -->
```

`draw` は `{ args: ["world"], keys: { lang: "ja" } }` を受け取る。
文書にその印があるときだけ、`mount` と `update` が `load` を呼ぶ。
同じ文書の同じ拡張の印は、`load` を 1 回だけ呼ぶ。
`render` は拡張の印を読み込み中の枠に置き換えるだけで、`load` も検査も呼ばない。

## 反映

即時。登録は同期で終わり、次に `mount` か `update` で描く文書から効く。

## 確認

#### 印の場所に描かれている

拡張の印を書いた文書を描く。
印の場所の要素に、`draw` が書いた内容が出る。
ブラウザの開発者ツールのネットワークで、拡張のモジュールへの要求が 1 件ある。

#### 印の無い文書で読まれていない

拡張の印を書いていない文書を描く。
拡張のモジュールへの要求が 0 件になる。

#### 引数が合わないとき

`schema` に合わない引数の印を書いて描く。
印の場所に題 `書き方の警告` の枠が出て、本文に印の文字と拡張の名前（`greet`）がある。
拡張のモジュールへの要求は 0 件になる。

#### モジュールを読めないとき

`load` が指す先を存在しない URL に変えて描く。
印の場所に知らせの枠が出て、題が `この図を表示できません`、本文が `表示に使う拡張（greet）を読み込めませんでした。` で始まる。
`console.error` に拡張の名前と元のエラーが出て、ほかの箇所は描かれる。

#### 型検査が通る

TypeScript で書いたとき、型検査を流す。

```bash
npx tsc --noEmit
```

型エラーが 0 件になる。

## 元に戻す

`registerExtension` の呼び出しを消す。
登録は同じページの間だけ効き、消すと文書の拡張の印は未知の印として取り除かれる。
配った JavaScript のファイルは別に消す。
