# テーマを上書きする

CSS 変数と層の外の CSS で、描いた文書の見た目を変える

mdmark が描いた文書の色・書体・余白などを、使う側のページで変えるときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)

## 手順

### 変数の値を変える

#### 変数を書く

```css
.mdmark {
  --mdmark-color-link: #c00;
  --mdmark-radius: 0;
}
```

書く先は、描く先の要素に付く class `mdmark`。
ページ全体に当てるときは `:root` に書いてもよい。
変数の一覧は [テーマの CSS 変数](../../リファレンス/API.md#テーマの-css-変数)。
変数名を書き間違えると値は当たらず、既定の見た目のままになる。

#### ダークの配色だけ変える

```css
@media (prefers-color-scheme: dark) {
  .mdmark {
    --mdmark-color-link: #f66;
  }
}
```

ダークの配色は、画面で OS の設定がダークのときに当たる。
`@media` で囲まずに書いた値は、明るい配色でもダークの配色でも当たる。

### 規則を上書きする

#### 層の外に CSS を書く

```css
a {
  text-decoration-line: none;
}
```

mdmark の CSS は `@layer mdmark` に入っている。
層の外に書いた CSS は詳細度によらず勝つため、mdmark が `.mdmark a` に当てる下線を、詳細度の低い `a` だけの指定で消せる。
mdmark の CSS を読み込む前と後のどちらに書いても、結果は変わらない。

### `theme.css` に分ける

#### `<link>` で読み込む

```html
<link rel="stylesheet" href="/theme.css">
```

mdmark は使う側の `theme.css` を読まない。
ページが `<link>` で、層の外に読み込む。
`theme.css` の中身を `@layer` で囲まない。

## 反映

即時。ページを再読み込みすると、書いた CSS が当たる。

## 確認

#### 変数の値が当たっている

文書にリンクがあるとき、リンクの色を確かめる。

```js
getComputedStyle(document.querySelector(".mdmark a")).color
```

`#c00` を書いたなら `rgb(204, 0, 0)` が出る。

#### 層の外の規則が勝っている

```js
getComputedStyle(document.querySelector(".mdmark a")).textDecorationLine
```

`a` に `text-decoration-line: none` を書いたなら `none` が出る。

## 元に戻す

書いた CSS を消す。
mdmark の既定の見た目に戻る。
