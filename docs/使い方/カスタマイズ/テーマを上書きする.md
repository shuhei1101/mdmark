# テーマを上書きする

CSS 変数と層の外の CSS で、描いた文書の見た目を変える

mdmark が描いた文書の色・書体・余白などを、使う側のページで変えるときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)

## 手順

### テーマを選ぶ

#### 設定で選ぶ

```yaml
colorTheme: theme-slate
```

`mdmark.config.yaml` の `colorTheme` に、`dev-swiss`（既定）・`theme-paper`・`theme-slate`・`theme-contrast` のどれかを記載する。
使う側のサーバーがこの設定を読み、`mount` の `opts.config` に渡す。
選んだテーマが替えるのは配色の変数だけで、書体・余白・角丸と配置の変数は全テーマで共通。
明暗は OS の設定とこのページの class が、選んだテーマの中で選ぶ。
テーマごとの値は [選べるテーマ](../../リファレンス/API.md#選べるテーマ)。

#### 選んだテーマの上から上書きする

選んだテーマの値は `:root` に当たる。
`.mdmark` や `:root` に層の外で書いた変数は、選んだテーマの値に勝つ。
次の「変数の値を変える」の書き方が、テーマを選んでもそのまま効く。

### 変数の値を変える

#### 変数を書く

```css
.mdmark {
  --mdmark-color-link: #c00;
  --mdmark-radius: 0;
}
```

書く先は、描く先の要素に付く class `mdmark`。
ページ全体に当てるときは `:root` に書いてもよい。
変数の一覧は [テーマの CSS 変数](../../リファレンス/API.md#テーマの-css-変数)。
変数名を書き間違えると値は当たらず、既定の見た目のままになる。

#### ダークの配色だけ変える

```css
@media (prefers-color-scheme: dark) {
  .mdmark {
    --mdmark-color-link: #f66;
  }
}
```

ダークの配色は、画面で OS の設定がダークのときに当たる。
`@media` で囲まずに書いた値は、明るい配色でもダークの配色でも当たる。

#### 図の色を変える

```css
.mdmark {
  --mdmark-color-diagram-llm: #be185d;
  --mdmark-color-series-1: #c00;
  --mdmark-diagram-lane-tint: 12%;
}
```

図の層の背景・箱の種類・線の種類・グラフの系列の色と、層の背景の濃さ、文書の中の図の高さの上限も、変数で変える。
変数の一覧は [テーマの CSS 変数](../../リファレンス/API.md#テーマの-css-変数) の図の変数。
色を変えても、箱の種類・線の種類・系列は、アイコン・模様・点の形でも分かれたまま。

#### 差分の色を変える

```css
.mdmark {
  --mdmark-color-diff-del-bg: #fecaca;
  --mdmark-color-diff-add-sign: #0e7490;
  --mdmark-diff-minimap-width: 18px;
}
```

[差分を表示する](../導入/差分を表示する.md) で出す差分の、削除した行・追加した行・変わった語の背景と、行頭の `-`・`+` とミニマップの印の色も、変数で変える。
ミニマップの帯の幅と重なり順（`--mdmark-diff-minimap-z-index`）も変数で変える。
変数の一覧は [テーマの CSS 変数](../../リファレンス/API.md#テーマの-css-変数) の差分の変数。
色を変えても、削除した行・追加した行は、行頭の `-`・`+` の印と読み上げの名前でも分かれたまま。

#### ビューとコメントの見た目を変える

```css
:root {
  --mdmark-view-column-width: 16rem;
  --mdmark-color-comment-bg: #e6f4ff;
  --mdmark-color-comment-line: #0969da;
  --mdmark-color-error: #c00;
}
```

[ビューとコメントを使う](../書く/ビューとコメントを使う.md) で出すビューとコメントの見た目も、変数で変える。
`--mdmark-view-column-width` はボードの列の最小の幅で、収まらない列はボードの中で横にスクロールする。
`--mdmark-color-comment-bg` と `--mdmark-color-comment-line` はコメントの印の地と下線の色で、入力欄を開いている間の選んだ文字の色にも使う。
`--mdmark-color-error` はコメントの入力欄の知らせの文字とアイコン、誤りのある本文の欄の枠の色。
コメントのボタン・入力欄・吹き出しは `document.body` に置かれ、`.mdmark` の外になる。
これらの変数は `.mdmark` ではなく `:root` に書く。
変数の一覧は [テーマの CSS 変数](../../リファレンス/API.md#テーマの-css-変数) のビューとコメントの変数。
色を変えても、コメントの印は下線でも、入力欄の知らせはアイコンと文でも分かれたまま。

#### コードブロックの色分けの色を変える

```css
.mdmark {
  --mdmark-color-syntax-keyword: #0e7490;
  --mdmark-color-syntax-string: #15803d;
}

@media (prefers-color-scheme: dark) {
  .mdmark {
    --mdmark-color-syntax-keyword: #67e8f9;
  }
}
```

コードブロックの色分けは、キーワード・文字列・数値・型・名前・コメントの 6 種類の色を変数で変える。
変数の一覧は [テーマの CSS 変数](../../リファレンス/API.md#テーマの-css-変数) の `--mdmark-color-syntax-*`。
ライトとダークの値を別々に持つため、ダークの値は `@media (prefers-color-scheme: dark)` の中で変える。
色を変えても、コメントは斜体でも分かれたまま。
色分けするコードブロックと言語は [コードブロックの飾り](../../リファレンス/記法.md#コードブロックの飾り)。

#### 固定ヘッダーの下に見出し行を留める

```css
.mdmark {
  --mdmark-sticky-top: 48px;
}
```

表の見出し行は、ページを縦にスクロールしても画面の上端に留まる。
ページの上端に固定したヘッダーを置いているときは、`--mdmark-sticky-top` にそのヘッダーの高さを渡すと、見出し行がヘッダーの下に留まる。
既定は `0px`。

#### 本文の幅を変える

```css
.mdmark {
  --mdmark-content-width: 40rem;
}
```

本文の幅は、既定では上限が無く、描く先の要素の幅を使う。
行の長さを抑えたいときに、`--mdmark-content-width` へ長さを渡す。
変数の一覧は [テーマの CSS 変数](../../リファレンス/API.md#テーマの-css-変数)。

### 配色を class で切り替える

#### 描く先に class を付ける

```html
<div class="mdmark-theme-dark">
  <div id="doc"></div>
</div>
```

描く先の要素かその祖先に `mdmark-theme-dark` を付けると、OS の設定がライトでもダークの配色で描く。
`mdmark-theme-light` は、OS の設定がダークでもライトの配色で描く。
class を付け替えると、描いた文書の配色がその場で替わる。

VS Code の Webview に描くときは、VS Code が `body` に付ける `vscode-dark`・`vscode-light` などに配色が従うため、何も付けなくてよい。
`mdmark-theme-*` は `vscode-*` より先に配色を決める。
決める順は [配色を切り替える class](../../リファレンス/API.md#配色を切り替える-class)。

印刷では、class によらず明るい配色で出る。

### 規則を上書きする

#### 層の外に CSS を書く

```css
a {
  text-decoration-line: none;
}
```

mdmark の CSS は `@layer mdmark` に入っている。
層の外に書いた CSS は詳細度によらず勝つため、mdmark が `.mdmark a` に当てる下線を、詳細度の低い `a` だけの指定で消せる。
mdmark の CSS を読み込む前と後のどちらに書いても、結果は変わらない。

### `theme.css` に分ける

#### `<link>` で読み込む

```html
<link rel="stylesheet" href="/theme.css">
```

mdmark は使う側の `theme.css` を読まない。
ページが `<link>` で、層の外に読み込む。
`theme.css` の中身を `@layer` で囲まない。

## 反映

即時。ページを再読み込みすると、書いた CSS が当たる。
`colorTheme` は、使う側のサーバーが設定を読み直して `mount` に渡し直すと当たる。

## 確認

#### 選んだテーマが当たっている

```js
getComputedStyle(document.querySelector(".mdmark")).backgroundColor
```

`theme-slate` を選び、OS の設定がライトなら `rgb(248, 250, 252)` が出る。
OS の設定がダークなら `rgb(15, 23, 42)` が出る。

#### 変数の値が当たっている

文書にリンクがあるとき、リンクの色を確かめる。

```js
getComputedStyle(document.querySelector(".mdmark a")).color
```

`#c00` を書いたなら `rgb(204, 0, 0)` が出る。

#### 色分けの色が当たっている

文書に言語を書いたコードブロックがあるとき、キーワードの色を確かめる。

```js
getComputedStyle(document.querySelector(".mdmark pre code .hljs-keyword")).color
```

`#0e7490` を書いたなら `rgb(14, 116, 144)` が出る。
色分けは描いた後に付くため、色分けのライブラリを読み終えてから確かめる。

#### 見出し行の位置と本文の幅が当たっている

表を持つ文書で、ページを縦にスクロールして表の途中を出す。
見出し行の上端が、`--mdmark-sticky-top` に渡した長さだけ画面の上端から下にあり、固定のヘッダーに隠れていない。
本文の段落の幅が、`--mdmark-content-width` に渡した長さを超えない。
何も渡さないときは、段落の幅が描く先の要素の中身の幅と同じになる。

#### class で配色が替わっている

`mdmark-theme-dark` を付けた文書の地の色が、OS の設定がライトでもダークの色になる。

#### 層の外の規則が勝っている

```js
getComputedStyle(document.querySelector(".mdmark a")).textDecorationLine
```

`a` に `text-decoration-line: none` を書いたなら `none` が出る。

## 元に戻す

書いた CSS を消す。
mdmark の既定の見た目に戻る。
選んだテーマは、設定の `colorTheme` を消すと既定の `dev-swiss` に戻る。
