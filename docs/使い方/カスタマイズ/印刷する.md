# 印刷する

印刷・PDF にしたときの文書の見え方

読む人が mdmark で描いた文書を印刷・PDF にしたときの見え方。
何も設定しなくても、次のとおりになる。

## 見え方

<!-- table: data -->

| 項目 | 印刷での見え方 |
| --- | --- |
| 折り畳み | 印刷の前に、閉じた折り畳みを全て開く。印刷の後に、印刷の前の開閉へ戻す |
| 閉じた節・行の詳細・閉じた表と注意書き | 印刷の前に開く。印刷の後に、印刷の前の開閉へ戻す |
| タブ | 全ての中身を、タブ名を題にして縦に並べる。印刷の後に、印刷の前に選んでいたタブだけを出す |
| 表の操作 | 絞り込み・ピン止め・開閉のボタンとタブの並びを隠す。見出し行と列を留めず、表の高さの上限を外してセルの余白を詰める |
| 表の件数・集計・隠した列 | 表の上の列の表示の切り替えとコピーのボタン、行へのリンクの印は出さない。件数と集計の行は出し、隠した列は隠したまま出す |
| 配色 | ダークの配色にしていても、明るい配色で出す |
| 地と余白 | 地の色と内側の余白を外し、紙の幅いっぱいに出す |
| リンク | `http` で始まるリンクの後ろに、URL を併記する |
| コードブロックの題・行番号・行の強調 | 題・行番号・強調した行の色と左端の線をそのまま出す。行番号は折り返した長い行の最初の 1 行にだけ出す |
| コードの行の印 | 足した行・消した行の色と行頭の `+`・`-` をそのまま出す。印と、印だけを持つ行コメントの頭は、画面と同じく出さない |
| コードブロックの色分け | 色分けの色を出す。ダークの配色にしていても、明るい配色の色で出し、色を省くブラウザの設定でも紙に出す |
| 表・コードブロック・図 | 改ページで切らない。読み込み中の枠と知らせの枠も同じ |
| 横スクロール | 表とコードブロックの横スクロールと続きの影をやめ、紙の幅に収める。長い行は折り返す |
| 見出し | 見出し 1〜3 の直後で改ページしない |
| 用語の下線とツールチップ | 下線を外し、語を本文の文字として出す。ツールチップは出さない |
| 被参照の一覧 | 一覧のリンクの後ろに、描いた文書からの相対パスを併記する。本文の相対リンクには併記しない |
| 狭い紙幅の表 | 紙の幅が 40rem 以下のとき、表を行ごとの「列名: 値」の並びに積む |

## 折り畳みを開かない

折り畳み（閉じた節・行の詳細を含む）を開く動きと、タブの全ての中身を並べる動きは、印刷の機能が担う。
既定でオンで、設定の `features.print` か文書の印でオフにできる（[機能をオン・オフする](./機能をオン・オフする.md)）。
オフにしても止まるのはその動きだけで、ほかの見え方は変わらない。

`render` が返す HTML 文字列を使う側のページに置いた場合、その動きは付かない。
その動きは `mount` が付ける。

## 確認

ブラウザの印刷プレビューを開く。
折り畳みが開き、タブの全ての中身が並び、リンクの後ろに URL が出ている。
OS の設定がダークでも、配色は明るい。
用語の下線とツールチップが無く、被参照の一覧のリンクの後ろに相対パスが出ている。
題・行番号・強調・足した行・消した行を付けたコードブロックは、題・行番号・行の色と `+`・`-` が紙に出ている。
言語を書いたコードブロックは、行の中のキーワード・文字列などが色分けの色で紙に出ている。
