# 印刷する

印刷・PDF にしたときの文書の見え方

読む人が mdmark で描いた文書を印刷・PDF にしたときの見え方。
何も設定しなくても、次のとおりになる。

## 見え方

<!-- table: data -->

| 項目 | 印刷での見え方 |
| --- | --- |
| 折り畳み | 印刷の前に、閉じた折り畳みを全て開く。印刷の後に、印刷の前の開閉へ戻す |
| 配色 | ダークの配色にしていても、明るい配色で出す |
| 地と余白 | 地の色と内側の余白を外し、紙の幅いっぱいに出す |
| リンク | `http` で始まるリンクの後ろに、URL を併記する |
| 表・コードブロック・図 | 改ページで切らない。読み込み中の枠と知らせの枠も同じ |
| 横スクロール | 表とコードブロックの横スクロールと続きの影をやめ、紙の幅に収める。長い行は折り返す |
| 見出し | 見出し 1〜3 の直後で改ページしない |
| 狭い紙幅の表 | 紙の幅が 40rem 以下のとき、表を行ごとの「列名: 値」の並びに積む |

<!-- /table -->

## 折り畳みを開かない

折り畳みを開く動きは、印刷の機能が担う。
既定でオンで、設定の `features.print` か文書の印でオフにできる（[機能をオン・オフする](./機能をオン・オフする.md)）。
オフにしても止まるのは折り畳みを開く動きだけで、ほかの見え方は変わらない。

`render` が返す HTML 文字列を使う側のページに置いた場合、折り畳みを開く動きは付かない。
折り畳みを開く動きは `mount` が付ける。

## 確認

ブラウザの印刷プレビューを開く。
折り畳みが開き、リンクの後ろに URL が出ている。
OS の設定がダークでも、配色は明るい。
