# 文書の書き方

人が読む資料を書く前に読む、表し方と文の決まり

| 決まり | 中身 |
| --- | --- |
| 表し方の優先順位 | knowledge の規約『表し方の優先順位』（[shuhei1101/knowledge#132](https://github.com/shuhei1101/knowledge/issues/132)）に従う。図（フロー図・構成図・グラフ・ファイルツリー）→ 表 → 箇条書き → 文 の順に選び、上の表し方で書けたものを下の表し方で重ねて書かない。どれを選ぶかは knowledge の判定フローチャート『表し方の選び方』で決める |
| 見れば分かることを書かない | 図・表を読めば分かる説明、冒頭のリード、概要を削る |
| 裏返しを書かない | 「〜する」の後の「〜しない」、同じことの言い直しを削る |
| 参考は末尾にまとめる | 参考のリンクと参考にした情報は、ページの末尾の参考のセクションにまとめ、既定で再帰的に閉じる。各セクションの補足は参考へのリンクか、閉じたセクションにする |
