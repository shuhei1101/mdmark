# 画像と動画を置く

画像の属性・キャプション・ライトボックス・ギャラリー・テーマごとの切り替え・動画・GIF・音声・アセットの置き場所の手順

文書に画像・スクリーンショット・動画・GIF・音声を置くときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)

## 手順

### 画像を置く

#### 画像だけの段落に title を書く

```markdown
![グラフ](images/chart.png "売上の推移")
```

画像 1 つだけの段落は図になり、title（`"売上の推移"`）が画像の下のキャプションになる。
文の中の画像とリンクで囲んだ画像は、図にしない。
番号を付けて参照するときは [図と表に番号を付ける](./図と表に番号を付ける.md)。

#### 後ろの `{…}` で幅と配置を決める

```markdown
![グラフ](images/chart.png "売上の推移"){width=300 align=center}

![写真](images/photo.png){width=40% align=left}
```

| 属性 | 書ける値 |
| --- | --- |
| `width` | `300`・`300px` の px か、`1`〜`100` の `%` |
| `align` | `left`・`center`・`right`。`left`・`right` は本文を回り込ませる。画像だけの段落にだけ書ける |
| `nolightbox` | 値なし。押しても拡大しない |

読めない属性を書くと、読めた属性だけを当て、画像の前に書き方の警告が出る。

#### ライトボックスで拡大させる

図の画像は、書き方を足さなくても、押すと全画面で拡大する。
拡大した画面では、左右の矢印キーとボタンで同じ文書の画像を前後に送り、`+`・`-`・`0` で拡大・縮小する。
Esc・閉じるボタン・画像の外を押すと閉じる。
アイコンのように拡大させない画像には `{nolightbox}` を書く。

#### 配色ごとに画像を出し分ける

```markdown
![構成](images/arch-dark.png#only-dark)
![構成](images/arch-light.png#only-light)
```

URL の末尾に `#only-dark` を付けた画像は暗い配色のときだけ、`#only-light` を付けた画像は明るい配色のときだけ出る。
印刷では明るい配色の画像が出る。

### 画像を並べる

#### ギャラリーのマーカーで囲む

```markdown
<!-- gallery: cols=3 -->

![開く](images/open.png "開く")
![書く](images/write.png "書く")
![保存する](images/save.png "保存する")

<!-- /gallery -->
```

範囲の画像を `cols=` の列の数（`1`〜`6`、省くと `2`）の格子に並べる。
置き場所の幅が狭いときは、2 列か 1 列に減らす。
範囲の中の画像以外の文は出ない。

### 動画・音声・GIF を置く

#### 画像と同じ書き方で書く

```markdown
![操作の様子](media/demo.mp4 "保存までの操作"){poster=images/demo.png width=480}

![読み上げ](media/voice.mp3 "手順の読み上げ")

![ビルドの様子](images/build.gif)
```

拡張子が `mp4`・`m4v`・`webm`・`mov`・`ogv` のファイルは動画、`mp3`・`m4a`・`aac`・`ogg`・`oga`・`opus`・`wav`・`flac` のファイルは音声として、再生バー付きで出る。
alt は読み上げの名前、title はキャプションになる。
`poster=` の画像は再生前と印刷のときに出る。
GIF には右上に止める・再生するボタンが付き、止めると最初のフレームで止まる。
OS の動きを減らす設定がオンのときは、GIF は止めた状態で始まる。

#### 再生の仕方を属性で決める

| 属性 | 動き |
| --- | --- |
| `autoplay` | 開いたときに音を消して再生する |
| `muted` | 音を消して始める |
| `loop` | 繰り返し再生する |

VS Code のプレビューで再生できる形式は [プレビューを開く](../VSCodeで見る/プレビューを開く.md) にある。

### ファイルの置き場所を決める

#### 文書からの相対パスで書く

画像・動画・音声のパスは、文書のフォルダからの相対パスで書く。

#### 1 か所にまとめて置く

```yaml
assets:
  root: assets
```

文書ごとのフォルダに置かず 1 か所にまとめるときは、`mdmark.config.yaml` に `assets.root` を書く。
文書からの相対パスにファイルが無いとき、`assets.root` のフォルダから同じ相対パスで探す。
`assets.root` を読むのは、書き出し・まとめ・点検と VS Code のプレビューで、`mount`・`render` は読まない。

書き出したときの画像・動画・音声の扱いは [文書を書き出す](../書き出す/文書を書き出す.md)、見つからないファイルの見つけ方は [点検する](../書き出す/点検する.md)。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書の書き方で決め直す。

## 確認

#### 図とキャプションになっている

```js
[...document.querySelectorAll(".mdmark figure.mdmark-image, .mdmark figure.mdmark-media")].map((f) => f.querySelector("figcaption")?.textContent ?? "")
```

画像・動画・音声の段落ごとに、title のキャプションが出る。

#### ライトボックスで拡大できる

図の画像を押すと全画面で拡大し、`{何枚目} / {全ての枚数}` が出る。
`{nolightbox}` の画像は押しても拡大しない。

#### 動画・音声を再生できる

再生バーの再生を押すと、動画・音声が再生される。
GIF の右上のボタンを押すと止まり、もう一度押すと動く。

#### `{…}` が本文に出ていない

画像の後ろに `{width=` などの文字が出ていない。

## 元に戻す

`{…}` と `#only-dark`・`#only-light`・ギャラリーのマーカーを削除する。
記法ごとに止めるときは、[機能をオン・オフする](../カスタマイズ/機能をオン・オフする.md) で `images`・`gallery`・`lightbox`・`media`・`gif` をオフにする。
