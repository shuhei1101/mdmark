# 図と表に番号を付ける

`fig` の印と、番号を出すリンクの書き方

本文から図や表を番号で参照したいときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)

## 手順

### 図と表にマーカーを付ける

#### 図の直前にマーカーを書く

```markdown
<!-- fig: arch -->

![全体の構成](./arch.png "全体の構成")
```

`<!-- fig: ID -->` を、図の直前に書く。
マーカーの直後の、画像 1 つの段落に番号を付ける。
画像の title（`"全体の構成"`）が、番号の後ろに出るタイトルになる。
図のタイトルは画像の下に `図 1` の書式で出る。

#### 表の直前にマーカーを書く

```markdown
<!-- fig: list -->

| 名前 | 値 |
| --- | --- |
| りんご | 10 |
```

マーカーの直後の表に番号を付ける。
表のタイトルは表の上に `表 1` の書式で出る。

### 本文から参照する

#### `#fig-ID` へのリンクを書く

```markdown
[図](#fig-arch) の構成を [表](#fig-list) にまとめる。
```

リンク先は `#fig-` にマーカーの ID を続ける。
リンクの文字が、その図表の `図 1`・`表 1` に替わる。
番号は文書の頭から、図と表で別に数える。

### 誤りを修正する

#### 参照が切れたとき

リンク先の ID の図表が無いと、リンクの文字は書いたままになり、書き方の警告が出る。
`<!-- fig: ID -->` を図か表の直前に書くか、リンク先を修正する。

#### ID が重なったとき

同じ ID のマーカーを 2 回書くと、2 つ目の図表には番号だけが付いて ID が付かず、書き方の警告が出る。
別の ID に修正する。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書のマーカーで決め直す。

## 確認

#### 番号が付いている

```js
[...document.querySelectorAll(".mdmark .mdmark-figure-caption")].map((c) => c.textContent)
```

文書の頭から順に、`図 1全体の構成` や `表 1` のように、番号とタイトルが出る。

#### リンクの文字が番号になっている

```js
document.querySelector('.mdmark a[href="#fig-arch"]').textContent
```

`図 1` が出る。
リンクを押すと、URL の末尾が `#fig-arch` になり、その図が画面に入る。

#### マーカーが本文に出ていない

文書にマーカーの文字が出ていない。

## 元に戻す

マーカーとリンクを削除する。
番号を付ける機能を止めるときは、[機能をオン・オフする](../カスタマイズ/機能をオン・オフする.md) で `figures` をオフにする。
オフにすると、マーカーを取り除き、リンクの文字は書いたままにする。
