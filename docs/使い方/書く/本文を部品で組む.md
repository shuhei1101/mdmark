# 本文を部品で組む

注意書き・タブ・ステップ・ファイルツリー・バッジ・脚注・コードブロックの飾り・目次・節の開閉・行の詳細を書く手順

文書に注意書き・タブ・手順・ファイルツリー・バッジ・脚注・目次を入れるとき、コードブロックにタイトル・行番号・行の強調を付けるとき、コードブロックを言語に応じて色分けさせるとき、セクションを閉じた状態で始めるとき、表の行に詳細を付けるときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)

## 手順

### 注意書きを書く

#### 引用の 1 行目に種類を書く

```markdown
> [!WARNING]
> 守らないと壊れる内容を書く。
```

種類は `NOTE`・`TIP`・`IMPORTANT`・`WARNING`・`CAUTION` で、タイトルはそれぞれ補足・ヒント・重要・警告・注意になる。
知らない種類は `NOTE` として出る。

#### 閉じた注意書きにする

```markdown
> [!WARNING]-
> 閉じた状態で始める内容を書く。
```

種類の末尾に `-` を付ける。
タイトルだけが出て、押すと開く。
`-` の代わりに `+` を付けると、開いた状態で始まる折り畳みになる。

#### タイトルを付けて入れ子にする

```markdown
> [!TIP] 設定を **先に** 確認する
> 確認の手順を書く。
>
> > [!WARNING]
> > 注意書きの中に、別の種類の注意書きを入れる。
```

種類（と `-`・`+`）の後ろに空白を挟んで書いた文字が、種類の名前の代わりにタイトルになる。
タイトルの中の `**` などの行内の記法も描かれる。
注意書きの中の引用も、1 行目に種類を書くと注意書きになる。

### タブにする

#### 範囲をマーカーで囲み、見出しで区切る

```markdown
<!-- tabs -->

### macOS

macOS の手順。

### Windows

Windows の手順。

<!-- /tabs -->
```

範囲の中で最初に出る見出しの階層で区切り、見出しの文字がタブ名になる。
タブ名にした見出しは、本文の見出しとして残らない。
見出しの無い範囲は、タブにせず中身をそのまま描き、書き方の警告が出る。

#### 同じ軸のタブ群に同じ組を付ける

```markdown
<!-- tabs: group=os -->

### macOS

macOS で入れる。

### Windows

Windows で入れる。

<!-- /tabs -->

<!-- tabs: group=os -->

### macOS

macOS で起動する。

### Windows

Windows で起動する。

<!-- /tabs -->
```

マーカーに `group=` と組の名前を書く。
同じページで同じ組のタブ群は、読む人がどれかのタブを選ぶと、同じタブ名のタブへ揃って切り替わる。
読む人が選んだタブ名はブラウザに残り、ページを開き直しても、そのタブで開く。
組を付けないタブ群は、ほかと揃わず、選んだタブも覚えない。
値の無い `group=` は組を付けないものとして描き、書き方の警告が出る。

#### タブを折り畳みに入れる

```markdown
<!-- tabs: closed -->

### uv

`uv add mdmark` で入れる。

### pip

`pip install mdmark` で入れる。

<!-- /tabs -->
```

`closed` は閉じた状態で始め、`open` は開いた状態で始める。
閉じているとき、見出し `タブ（uv・pip）` だけが出て、押すとタブの並びと中身が開く。
`title=入れ方` のように書くと、`title=` の値が見出しになる。
`title=` は `closed` か `open` と一緒に書く。どちらも無い `title=` は当てずに、書き方の警告が出る。
`closed` と `open` を両方書くと `closed` を当て、書き方の警告が出る。
`group=` とは一緒に書ける。

#### タブの中にタブを入れる

```markdown
<!-- tabs -->

### macOS

<!-- tabs -->

#### zsh

zsh で設定する。

#### bash

bash で設定する。

<!-- /tabs -->

### **Windows**

Windows で設定する。

<!-- /tabs -->
```

タブの中身に、もう 1 つタブのマーカーを書く。
内側のタブは、内側の範囲で最初に出る見出しの階層で区切る。
内側のタブを選んでも、外側のタブの選択は変わらない。
見出しを `**` で強調すると、タブのボタンでもタブ名が強調される。

閉じのマーカーが足りないときは、外側の開きに書き方の警告が出て、そこから文書の終わりまでの見出しと中身がタブにならずにそのまま出る。

### 手順にする

#### 番号付きリストをマーカーで囲む

```markdown
<!-- steps -->

1. 依存を入れる。
2. ビルドする。

<!-- /steps -->
```

範囲の最初の番号付きリストが手順になる。
項目の中の入れ子の番号付きリストは手順にならない。
番号付きリストの無い範囲は、中身をそのまま描き、書き方の警告が出る。

#### 手順を折り畳みに入れる

```markdown
<!-- steps: open title=準備 -->

1. 依存を入れる。
2. ビルドする。

<!-- /steps -->
```

`closed` は閉じた状態で始め、`open` は開いた状態で始める。
`title=` の値が見出しになり、省くと `手順（2 ステップ）` のように項目の数の見出しになる。
`title=` は `closed` か `open` と一緒に書く。
`closed` と `open` を両方書いたとき、`closed` も `open` も無い `title=` を書いたとき、ほかの指定を書いたときは、書き方の警告が出る。

### ファイルツリーを書く

#### 言語 `tree` のコードブロックに罫線で書く

````markdown
```tree
mdmark/
├── src/
│   └── index.ts
└── package.json
```
````

フォルダは名前の末尾を `/` にする。
上の行より 2 階層以上深い行があると読めず、コードブロックのまま描き、書き方の警告が出る。
罫線の階層を 1 階層ずつ深くして修正する。
`tree --charset=ascii` が出す `|-- `・`` `-- ``・`|   ` の罫線も、そのまま書ける。

#### 項目の右に注釈を書く

````markdown
```tree
mdmark/
├── src/ # ソース
│   └── index.ts # 入口の `mount`
└── README.md # **必読** `badge:新規`
```
````

名前の後ろに、空白と `#` と注釈を続ける。
前に空白がある最初の `#` から後ろが注釈になり、注釈の中のコード・リンク・太字・バッジを描く。
注釈は全ての行で同じ位置の列に揃う。
`C#/` や `#notes.md` のように、`#` の前に空白が無い名前は割れない。

#### 「ほかにもある」を `...` で示す

````markdown
```tree
src/
├── index.ts
└── ...
```
````

名前が `...` の項目は、ファイルでもフォルダでもない「ほかにもある」の項目になる。
省略のアイコンが付き、読み上げは `ほかにもあります` と伝える。

#### 開く階層を `open=` で選ぶ

````markdown
<!-- tree: open=all -->

```tree
app/
└── src/
    └── parts/
        └── tree.ts
```
````

コードブロックの直前に書く。
ルートだけを開いて描くのが既定で、`open=all` は全てのフォルダを、`open=2` のような階層の数は、その数より浅いフォルダ（ルートの深さが 0）を開く。
`all` でも 1 以上の整数でもない値は当てずに、書き方の警告が出る。

#### 長い名前と注釈を `wrap` で折り返す

````markdown
<!-- tree: open=all wrap -->

```tree
very-long-folder-name-for-the-generated-design-documents/
└── a-file-name-that-is-much-longer-than-the-box-width-on-phones.config.ts # 狭い幅では注釈も項目の中で折り返す
```
````

`wrap` を書いたツリーは、長い名前をアイコンの右の名前の列の中で折り返し、注釈を名前の下の行に名前の先頭から出す。
罫線と入れ子の位置は変わらない。
`wrap` を書かないツリーは折り返さず、ツリーの中で横にスクロールする。

#### 読む人の開閉とコピー

読む人は、フォルダの名前かアイコンを押すか、フォーカスして Enter・Space を押して、フォルダを開閉できる。
Shift を押しながら開閉すると、入れ子のフォルダも同じ状態になる。
ツリーの上の帯の `コピー` のボタンで、書いたとおりの罫線のテキスト（注釈と、閉じたフォルダの中の行を含む）をクリップボードへコピーする。
コピーできなければ、ツリーの下に罫線のテキストを選択したパネルが出て、手動でコピーできる。

ファイルのアイコンは拡張子ごとに変わる。
種類の一覧は [ファイルツリー](../../リファレンス/記法.md#ファイルツリー)。

### バッジを置く

#### 行内のコードの頭に `badge` と `:` を続ける

```markdown
このバージョンは `badge:v0.1.0` です。
```

頭を外した文言が札になる。
`badge:` の後ろが空か空白だけのときは、札にせず、書いたとおりの行内のコードで出る。
頭を打ち消して見せるときは、`:` の前に `\` を入れる。

#### バッジに色を付ける

```markdown
レビューの状態は `badge:red:要確認` です。
```

`badge:` の後ろに色の名前と `:` を続けると、札にその色を付ける。
色の名前は `blue`・`red`・`green`・`yellow`・`orange`・`purple`・`gray`。
最初の `:` の前が色の名前でないときは、`badge:v1:beta` の `v1:beta` のように、`badge:` の後ろを全て札の文言にする。
色の選び方は [色で強調する](./色で強調する.md)。

### 本文の文字に色を付ける

#### 角括弧で囲んだ文字の後ろに色を書く

```markdown
推奨は案 A。[既存の書き方のまま読める]{color=blue}。
```

角括弧で囲んだ文字の直後に `{color=色}` を書くと、その文字を色の名前の色と太字にする。
色を付けるのは、決め手の 1 文だけにする（[色で強調する](./色で強調する.md)）。

### 脚注を付ける

#### 本文に参照を、行頭に定義を書く

```markdown
テーマは CSS 変数で変えられる[^theme]。

[^theme]: CSS 変数と層の外の CSS で上書きする。
```

参照の場所に `[1]` の上付きの番号が出て、ポインターを乗せるかフォーカスすると中身をツールチップで出す。
文書の末尾に `脚注（{件数} 件）` の閉じた一覧が出て、番号を押すと一覧の項目へ、項目の戻るリンクで番号へ移る。
タッチの端末では、番号のタップでツールチップを出し、出した番号のもう一度のタップで一覧の項目へ移る。ツールチップと番号の外のタップで閉じ、ツールチップの中のリンクのタップでは閉じない。
定義はどこに書いてもよく、番号は本文で参照した順に振る。

#### 行内に脚注を書く

```markdown
外へは要求しない^[file:// で開いたときも同じ]。
```

定義を別に書かずに、`^[中身]` の中身を脚注にする。
ラベルの照合・2 段落以上の定義の書き方は [脚注](../../リファレンス/記法.md#脚注)。

### リンクと添付のカードを置く

#### リンク 1 つだけの段落を書く

```markdown
https://example.com/docs/guide

[設計の資料](https://example.com/design)

[仕様書](files/spec.pdf)
```

URL へのリンク 1 つだけの段落は、タイトル・ドメイン・URL のリンクのカードになる。
URL だけを書いたときは、スキームを除いた URL がタイトルになる。
PDF・Office の文書・表計算・スライド・圧縮ファイル・テキストへのリンク 1 つだけの段落は、種類のアイコン・拡張子・ファイル名の添付のカードになる。
文の中のリンク・`#` で始まるリンク・Markdown へのリンクはカードにしない。
カードはリンク先へ要求しないので、リンク先のタイトルは出ない。

### コードブロックを飾る

#### タイトル・行番号・行の強調をコードブロックの直前のマーカーに書く

````markdown
<!-- code: title=app.ts lines highlight=2,4-6 -->

```ts
import { mount } from "mdmark";
const doc = await fetch("/README.md");
mount(document.querySelector("#doc"), await doc.text());
```
````

`title=` がタイトル、`lines` が行番号、`highlight=` が強調する行になる。
使う引数だけを書く。
引数は空白で区切るため、タイトルに空白は書けない。
強調する行は `2`・`4-6` のように、行の番号と範囲をコンマで並べる。
`fold=` に同じ書き方で行を書くと、その行を最初から畳んで出す（[インデントで行を畳む](#インデントで行を畳む)）。
コードブロックの行の数を超える番号と、読めない番号は当てずに、書き方の警告が出る。タイトルに空白を書いたときは、空白の後ろの単語に書き方の警告が出る。知らないキーと指定は、警告を出さずに無視する。
マーカーの直後にコードブロックが無いときも、書き方の警告が出る。

#### 長い行を `wrap` で折り返す

````markdown
<!-- code: lines wrap -->

```ts
const url = "https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@v{版}/dist/index.js"; // バージョンを固定した URL から配布物を読む
```
````

`wrap` を書いたコードブロックは、長い行を枠の幅で折り返す。
行番号と行頭の `+`・`-` は折り返した行の 1 行目にだけ出て、コピーした中身に折り返しの改行は入らない。
`wrap` を書かないコードブロックは折り返さず、ブロックの中で横にスクロールする。
使う側のページの CSS が `pre` に折り返しを指定していても、この既定は変わらない。

#### 追加した行・削除した行・強調を行末のマーカーで分ける

````markdown
```ts
let count = 0; // [\!code --]
let count = 1; // [\!code ++]
count += 1; // 数える [\!code highlight]
```
````

行末の行コメントに `[!code ++]`（追加した行）・`[!code --]`（削除した行）・`[!code highlight]`（強調）・`[!code focus]`（注目）・`[!code error]`（エラー）・`[!code warning]`（警告）を書く。
行が色と行頭の `+`・`-`・`×`・`!` で分かれ、マーカーは画面に出ない。
`[!code focus]` の行を持つコードブロックは、ほかの行が薄く出る。
行コメントがマーカーだけのときは、行コメントの頭（`//` など）も出ない。
知らないマーカー（`[!code blink]` など）はその行に当てずに、書いた文字のまま出て、書き方の警告が出る。

マーカーそのものを見せるときは、`[` の後ろに `\` を入れて打ち消す。
打ち消したマーカーは、`\` を外した文字のまま出る。

言語 `tree` のコードブロック・図の部品の定義のコードブロック・`<!-- html -->` の範囲のコードブロックには、タイトル・行番号・行の強調も行末のマーカーも当たらない。

#### コードブロックに言語を書いて色分けさせる

````markdown
```yaml
name: mdmark # 名前
version: 1
```
````

コードブロックの開きの後ろに言語を書くと、キーワード・文字列・数値・型・名前・コメントが色分けされる。
マーカーは要らない。
色分けする言語は `typescript`（`ts`・`tsx`）・`javascript`（`js`・`jsx`・`mjs`・`cjs`）・`json`・`yaml`（`yml`）・`python`（`py`）・`bash`（`sh`・`shell`・`zsh`）・`html`（`xml`）・`css`・`markdown`（`md`）・`sql`・`dockerfile`（`docker`）・`diff`（`patch`）。
`diff` は `+` で始まる行と `-` で始まる行を、互いに違う色で分ける。
括弧の中の別名も同じ言語として扱い、大文字と小文字は区別しない。
一覧は [コードブロックの飾り](../../リファレンス/記法.md#コードブロックの飾り)。
言語の無いコードブロックと、一覧に無い言語（`text` など）のコードブロックは、色分けしない。

タイトル・行番号・行の強調・コードの行のマーカーを付けたコードブロックも、行ごとの分け方と行番号・行頭の `+`・`-` を保ったまま、行の中身が色分けされる。
色分けのライブラリは、色分けする言語のコードブロックがある文書でだけ読み込む。
読み込めないときは、コードを欠けさせずに色分けなしで出す。
色分けを止めるときは、設定の `features.syntax` か文書の `<!-- features: -syntax -->` でオフにする（[機能をオン・オフする](../カスタマイズ/機能をオン・オフする.md)）。
読み込み先は設定の `syntax.url` で変える（[設定](../../リファレンス/設定.md#色分けのライブラリの読み込み先)）。

言語 `tree` のコードブロック・図の部品の定義のコードブロック・`<!-- html -->` の範囲のコードブロックと、文書に書いた生の HTML の `pre`・`code` は、色分けしない。

#### 言語とファイル名をラベルに出す

````markdown
```python:hoge.py
def hello():
    print("hello")
```
````

コードブロックの開きの後ろに言語を書くと、コードの上の帯の左端に、言語のラベルが出る。
`python:hoge.py` のように `言語:ファイル名` の書式で書くと、`:` の前が言語、後ろがファイル名になり、ラベルに並んで出る。
`title=` でタイトルを付けたときは、ラベルの後ろにタイトルが出る。
言語の無いコードブロックには、ラベルを出さない。
ラベルは、文字を選んでコピーする中身に入らない。
`tree:src` のようにファイル名を付けた `tree` は、ファイルツリーにならず、普通のコードブロックとして描く。

#### コピーボタンで変更後のコードをコピーする

コードブロックの帯の右端に、`コピー` のボタンが付く。書くものは要らない。
押すと、コードをクリップボードへコピーする。
`[!code --]` の削除した行は含めず、コードの行のマーカーと、マーカーだけを持つ行コメントの頭（`//` など）も含めない。
行番号と行頭の `+`・`-` も入らない。
コピーできたらボタンが `コピーしました` に変わり、しばらくすると元に戻る。
クリップボードへ書けなかったときは、ボタンが `コピーできませんでした` に変わり、次に押すまで残る。コードの文字は選んで手動でコピーできる。

言語 `tree` のコードブロック・図の部品の定義のコードブロック・`<!-- html -->` の範囲のコードブロックには、ラベルもコピーボタンも付かない。

#### インデントで行を畳む

書くものは要らない。
インデントのある行に、深さごとの縦線が引かれる。
次の行がより深いインデントの行の行番号の右（行番号が無ければ行頭）に開閉のボタンが付き、押すと深い行を畳んで、行の末尾に `⋯` が出る。
開閉のボタンか `⋯` を押すと開く。
Shift を押しながら押すと、中の入れ子の行もまとめて同じ状態になる。

````markdown
<!-- code: fold=2 -->

```yaml
server:
  options:
    port: 8080
  name: mdmark
```
````

`fold=` に書いた行は、最初から畳んで出す。
畳めない行を書くと、書き方の警告が出る。
コピーボタンは、畳んだ行も含めてコピーする。

言語 `tree` のコードブロック・図の部品の定義のコードブロック・`<!-- html -->` の範囲のコードブロックは畳まない。

### 目次を置く

#### マーカーを書く

```markdown
<!-- toc -->
```

目次を出したい場所に書く。
h2〜h3 の見出しが入れ子で並び、各項目はその見出しへのリンクになる。

#### 右側の目次を使う

マーカーは要らない。
h1〜h3 の見出しがある文書には、右側の目次が出る。
画面の右端の線にポインターを置くか、フォーカスを目次へ移すと、目次が出る。
項目を押すと、その見出しへ移る。
閉じたセクションの中の見出しは、外側のセクションを開いてから移る。
今読んでいるセクションの項目はハイライトされる。

#### 右側の目次の出し方を選ぶ

```yaml
side-toc:
  mode: fixed
```

`hover`（既定）は、目次のピン止めのボタンを押すと出し続ける。
`fixed` は、三点リーダーの目次を出すボタンを押すと、目次をサイドバーとして出し続ける。
設定のキーは [右側の目次の出し方](../../リファレンス/設定.md#右側の目次の出し方)。

### セクションを閉じた状態で始める

#### 見出しの直後にマーカーを書く

```markdown
## 補足

<!-- section: closed -->

補足の本文。
```

`closed` で閉じた状態、`open` で開いた状態で始める。
マーカーを書かないセクションは開いた状態で始める。
開閉できるのは h1〜h4 のセクション。
`closed`・`open` 以外の値を書くと、開いた状態で描き、書き方の警告が出る。

### セクションをまとめて開閉する

#### Shift を押しながら開閉する

Shift を押しながら見出しのボタンを押す。
そのセクションと、中の入れ子のセクションが全て同じ状態になる。
キーボードでは、ボタンにフォーカスして Shift を押しながら Enter か Space を押す。

#### 右側の目次のボタンで開閉する

右側の目次の上部の「すべて展開」のボタンは、文書の全てのセクションを開く。
「すべて折りたたむ」のボタンは、h1 のセクションを開いたまま、h2〜h4 のセクションを全て閉じる。

### 行の詳細を付ける

#### 表の直後にマーカーで囲んで詳細を書く

```markdown
| 名前 | 値 |
| --- | --- |
| りんご | 10 |
| みかん | 2 |

<!-- row-detail: 2 -->

みかんの詳細。

<!-- /row-detail -->
```

行の位置は、見出し行を除いて 1 から数える。
表の行より大きい位置を書くと、詳細を表の後の本文として描き、書き方の警告が出る。

### アイコン・キー・ルビを書く

#### 行内のコードの頭に `icon\:` か `kbd\:` を付ける

```markdown
## `icon:flag` はじめに

`kbd:Ctrl+C` でコピーし、<ruby>漢字<rt>かんじ</rt></ruby>のルビも書けます。
```

`icon\:` の後ろは [Lucide](https://lucide.dev/icons/) のアイコンの名前にする。
`kbd\:` の後ろは `+` で区切ったキーにし、`+` のキーは `++` と書く。
ルビは文書に HTML の `<ruby>` で書く。
書き方の詳細は [アイコン](../../リファレンス/記法.md#アイコン)・[キー](../../リファレンス/記法.md#キー)・[ルビ](../../リファレンス/記法.md#ルビ)。

### 本文を横に並べる

#### columns の範囲を `<!-- column -->` で区切る

```markdown
<!-- columns -->

左の列

<!-- column -->

右の列

<!-- /columns -->
```

並べられるのは 2〜3 列で、描く先の要素が狭いときは縦に積む。
書き方の詳細は [段組み](../../リファレンス/記法.md#段組み)。

### リンクをカードの格子に並べる

#### リストを cards の範囲で囲む

```markdown
<!-- cards -->
- `icon:book` [使い方](使い方/README.md)
  導入と使い方の手順
- [リファレンス](リファレンス/README.md) 名前から引く一覧
<!-- /cards -->
```

項目の最初のリンクがタイトル、その前の `icon\:名前` がアイコン、残りの文字が説明になる。描く先の要素が狭いときは 1 列に積む。
書き方の詳細は [カードの格子](../../リファレンス/記法.md#カードの格子)。

### 範囲を折りたたむ

#### details の範囲で囲む

```markdown
<!-- details: 補足の手順 -->

閉じた状態で始まる中身

<!-- /details -->
```

開いた状態から始めるときは、タイトルの後ろに `open` を書く。
書き方の詳細は [details の範囲](../../リファレンス/記法.md#details-の範囲)。

### 印刷で改ページする

#### `<!-- pagebreak -->` を書く

```markdown
<!-- pagebreak -->
```

画面では何も出ず、印刷のときにその場所で改ページする。

### ほかの文書を取り込む

#### include のマーカーにパスを書く

```markdown
<!-- include: 共通/手順.md#実行 -->

<!-- include: ../src/app.ts#L3-L10 -->
```

パスはマーカーを書いた文書のフォルダから数え、`#` の後ろに見出しの ID か、Markdown 以外のファイルの行の範囲を書く。
書き方の詳細は [取り込み](../../リファレンス/記法.md#取り込み)。

### 図と表を本文の幅より広げる

#### wide の範囲で囲む

```markdown
<!-- wide -->

（幅の広い表や図）

<!-- /wide -->
```

範囲の上の右端のボタンで、広げた幅と本文の幅を切り替えられる。
本文の幅から始めるときは `<!-- wide: closed -->` と書く。
書き方の詳細は [wide の範囲](../../リファレンス/記法.md#wide-の範囲)。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書のマーカーで決め直す。

## 確認

#### 注意書きが枠になっている

```js
document.querySelector(".mdmark .markdown-alert-title").textContent
```

`警告` など、書いた種類のタイトルが出る。タイトルを書いた注意書きは、書いたタイトルが出る。
閉じた注意書きはタイトルだけが見え、押すと本文が出る。`+` の注意書きは開いて出る。
入れ子にした注意書きは、外側の枠の中に内側の枠が出る。

#### タブが切り替わる

```js
document.querySelector('.mdmark [role="tab"][aria-selected="true"]').textContent
```

最初のタブの名前が出る。
別のタブを押すか、フォーカスのあるタブで左右の矢印キーを押すと、そのタブの `aria-selected` が `true` になり、中身が切り替わる。
入れ子のタブは、内側のタブを選んでも外側のタブの選択が変わらない。

#### 同じ組のタブが揃い、選んだタブを覚えている

```js
localStorage.getItem("mdmark-tabs:os")
```

組のタブを押すと、同じ組で同じタブ名を持つタブ群のタブも選ばれる。
押したタブ名が、組の名前を付けたキーに残る。
ページを開き直すと、そのタブ名のタブが選ばれている。
localStorage が使えないブラウザでは、残さず・読まずに、揃える動きと切り替えだけが働く。

#### 手順・ファイルツリー・バッジが組まれている

```js
[".mdmark-steps", ".mdmark-tree", ".mdmark-badge"].map((s) => document.querySelector(`.mdmark ${s}`) !== null)
```

書いた記法の分だけ `true` が出る。

#### 色とカードが付いている

```js
[".mdmark-badge[data-color]", ".mdmark-color", ".mdmark-card"].map((s) => document.querySelector(`.mdmark ${s}`) !== null)
```

書いた記法の分だけ `true` が出る。
色を付けた文字は太字で出ている。

#### 折り畳みの見出しが出ている

```js
document.querySelector(".mdmark .mdmark-collapsible > summary").textContent
```

`closed` のタブとステップは、見出しだけが出ている。
見出しは `title=` の値で、省いたときはタブが `タブ（uv・pip）`、ステップが `手順（2 ステップ）` になる。
見出しを押すと開く。

#### ファイルツリーの注釈・開閉・コピーが働く

```js
document.querySelector(".mdmark .mdmark-tree-note").textContent
```

`#` の後ろに書いた注釈が、`#` を除いて出る。
フォルダの名前を押すと、フォルダの `aria-expanded` が切り替わり、中身が出る。
ツリーの上の `コピー` のボタンを押すと、ボタンが `コピーしました` になる。

#### コードブロックにタイトル・行番号・行の色が付いている

```js
document.querySelector(".mdmark .mdmark-code .mdmark-code-title").textContent
```

書いたタイトルが出る。
コードブロックの各行の左に行番号が出て、強調した行・追加した行・削除した行が色で分かれている。
コードブロックの文字を全て選んでコピーすると、行番号と行頭の `+`・`-` が入らない。

#### コードブロックに言語のラベルとコピーボタンが付いている

```js
document.querySelector(".mdmark .mdmark-code .mdmark-code-lang-name").textContent
```

言語を書いたコードブロックなら、書いた言語（`言語:ファイル名` なら `:` の前）が出る。
コードブロックの帯の右端に `コピー` のボタンがあり、押して貼り付けると、行番号と行頭の `+`・`-` を含まない変更後のコードが入る。

#### コードの行が畳める

```js
document.querySelector(".mdmark .mdmark-code-fold").getAttribute("aria-expanded")
```

インデントのある行を持つコードブロックなら `true` が出る（`fold=` で畳んだ行なら `false`）。
ボタンを押すと深い行が隠れ、行の末尾に `⋯` が出る。

#### コードブロックが色分けされている

```js
document.querySelector(".mdmark pre code .hljs-keyword") !== null
```

言語を書いたコードブロックなら `true` が出る。
色分けは描いた後に付くため、色分けのライブラリを読み終えてから確かめる。
コードブロックの文字を全て選んでコピーすると、色分けの前と同じ文字がコピーされる。

#### 目次から移れる

目次の項目を押すと、URL の末尾が `#` と見出しの ID になり、その見出しが画面に入る。

#### 右側の目次が出て、移れる

```js
document.querySelector(".mdmark .mdmark-side-toc") !== null
```

h1〜h3 の見出しがある文書で `true` が出る。
右端にポインターを置くと目次が出て、項目を押すと URL の末尾が `#` と見出しの ID になり、その見出しが画面に入る。
スクロールすると、今読んでいるセクションの項目が `aria-current="location"` を持つ。

#### セクションと行の詳細が開閉する

```js
document.querySelector(".mdmark .mdmark-section-toggle").getAttribute("aria-expanded")
```

閉じたセクションの見出しのボタンは `false` が出る。
押すと `true` になり、中身が出る。
行の詳細は、詳細を持つ行の先頭のセルのボタンで開閉する。
h1 のセクションのボタンも同じように開閉する。
Shift を押しながら押すと、中の入れ子のセクションも同じ状態になる。
右側の目次の「すべて折りたたむ」を押すと、h1 のセクションが開いたまま、h2〜h4 のセクションが全て閉じる。

#### マーカーが本文に出ていない

文書にマーカーの文字が出ていない。

## 元に戻す

マーカーを削除し、注意書き・ファイルツリー・バッジの書き方を引用・コードブロック・行内のコードに戻し、コードの行のマーカーと文字の色の `{color=色}` を外すと、普通の Markdown として描かれる。
カードを止めるときは、リンクを文の中に書くか、`cards` をオフにする。
記法ごとに止めるときは、[機能をオン・オフする](../カスタマイズ/機能をオン・オフする.md) で機能をオフにする。
