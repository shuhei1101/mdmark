# 本文を部品で組む

注意書き・タブ・ステップ・ファイルツリー・バッジ・コードブロックの飾り・目次・節の開閉・行の詳細を書く手順

文書に注意書き・タブ・手順・ファイルツリー・バッジ・目次を入れるとき、コードブロックに題・行番号・行の強調を付けるとき、コードブロックを言語に応じて色分けさせるとき、節を閉じた状態で始めるとき、表の行に詳細を付けるときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)

## 手順

### 注意書きを書く

#### 引用の 1 行目に種類を書く

```markdown
> [!WARNING]
> 守らないと壊れる内容を書く。
```

種類は `NOTE`・`TIP`・`IMPORTANT`・`WARNING`・`CAUTION` で、題はそれぞれ補足・ヒント・重要・警告・注意になる。
知らない種類は `NOTE` として出る。

#### 閉じた注意書きにする

```markdown
> [!WARNING]-
> 閉じた状態で始める内容を書く。
```

種類の末尾に `-` を付ける。
題だけが出て、押すと開く。

### タブにする

#### 範囲を印で囲み、見出しで区切る

```markdown
<!-- tabs -->

### macOS

macOS の手順。

### Windows

Windows の手順。

<!-- /tabs -->
```

範囲の中で最初に出る見出しの階層で区切り、見出しの文字がタブ名になる。
タブ名にした見出しは、本文の見出しとして残らない。
見出しの無い範囲は、タブにせず中身をそのまま描き、書き方の警告が出る。

#### 同じ軸のタブ群に同じ組を付ける

```markdown
<!-- tabs: group=os -->

### macOS

macOS で入れる。

### Windows

Windows で入れる。

<!-- /tabs -->

<!-- tabs: group=os -->

### macOS

macOS で起動する。

### Windows

Windows で起動する。

<!-- /tabs -->
```

印に `group=` と組の名前を書く。
同じページで同じ組のタブ群は、読む人がどれかのタブを選ぶと、同じタブ名のタブへ揃って切り替わる。
読む人が選んだタブ名はブラウザに残り、ページを開き直しても、そのタブで開く。
組を付けないタブ群は、ほかと揃わず、選んだタブも覚えない。
値の無い `group=` は組を付けないものとして描き、書き方の警告が出る。

#### タブを折り畳みに入れる

```markdown
<!-- tabs: closed -->

### uv

`uv add mdmark` で入れる。

### pip

`pip install mdmark` で入れる。

<!-- /tabs -->
```

`closed` は閉じた状態で始め、`open` は開いた状態で始める。
閉じているとき、見出し `タブ（uv・pip）` だけが出て、押すとタブの並びと中身が開く。
`title=入れ方` のように書くと、`title=` の値が見出しになる。
`title=` は `closed` か `open` と一緒に書く。どちらも無い `title=` は当てずに、書き方の警告が出る。
`closed` と `open` を両方書くと `closed` を当て、書き方の警告が出る。
`group=` とは一緒に書ける。

### 手順にする

#### 番号付きリストを印で囲む

```markdown
<!-- steps -->

1. 依存を入れる。
2. ビルドする。

<!-- /steps -->
```

範囲の最初の番号付きリストが手順になる。
項目の中の入れ子の番号付きリストは手順にならない。
番号付きリストの無い範囲は、中身をそのまま描き、書き方の警告が出る。

#### 手順を折り畳みに入れる

```markdown
<!-- steps: open title=準備 -->

1. 依存を入れる。
2. ビルドする。

<!-- /steps -->
```

`closed` は閉じた状態で始め、`open` は開いた状態で始める。
`title=` の値が見出しになり、省くと `手順（2 ステップ）` のように項目の数の見出しになる。
`title=` は `closed` か `open` と一緒に書く。
`closed` と `open` を両方書いたとき、`closed` も `open` も無い `title=` を書いたとき、ほかの指定を書いたときは、書き方の警告が出る。

### ファイルツリーを書く

#### 言語 `tree` のコードブロックに罫線で書く

````markdown
```tree
mdmark/
├── src/
│   └── index.ts
└── package.json
```
````

フォルダは名前の末尾を `/` にする。
上の行より 2 段以上深い行があると読めず、コードブロックのまま描き、書き方の警告が出る。
罫線の段を 1 段ずつ深くして直す。
`tree --charset=ascii` が出す `|-- `・`` `-- ``・`|   ` の罫線も、そのまま書ける。

#### 項目の右に注釈を書く

````markdown
```tree
mdmark/
├── src/ # ソース
│   └── index.ts # 入口の `mount`
└── README.md # **必読** `badge:新規`
```
````

名前の後ろに、空白と `#` と注釈を続ける。
前に空白がある最初の `#` から後ろが注釈になり、注釈の中のコード・リンク・太字・バッジを描く。
注釈は全ての行で同じ位置の列に揃う。
`C#/` や `#notes.md` のように、`#` の前に空白が無い名前は割れない。

#### 「ほかにもある」を `...` で示す

````markdown
```tree
src/
├── index.ts
└── ...
```
````

名前が `...` の項目は、ファイルでもフォルダでもない「ほかにもある」の項目になる。
省略のアイコンが付き、読み上げは `ほかにもあります` と伝える。

#### 開く階層を `open=` で選ぶ

````markdown
<!-- tree: open=all -->

```tree
app/
└── src/
    └── parts/
        └── tree.ts
```
````

コードブロックの直前に書く。
ルートだけを開いて描くのが既定で、`open=all` は全てのフォルダを、`open=2` のような階層の数は、その数より浅いフォルダ（ルートの深さが 0）を開く。
`all` でも 1 以上の整数でもない値は当てずに、書き方の警告が出る。

#### 読む人の開閉とコピー

読む人は、フォルダの名前かアイコンを押すか、フォーカスして Enter・Space を押して、フォルダを開閉できる。
Shift を押しながら開閉すると、入れ子のフォルダも同じ状態になる。
ツリーの上の帯の `コピー` のボタンで、書いたとおりの罫線のテキスト（注釈と、閉じたフォルダの中の行を含む）をクリップボードへコピーする。
コピーできなければ、ツリーの下に罫線のテキストを選択したパネルが出て、手でコピーできる。

ファイルのアイコンは拡張子ごとに変わる。
種類の一覧は [ファイルツリー](../../リファレンス/記法.md#ファイルツリー)。

### バッジを置く

#### 行内のコードの頭に `badge` と `:` を続ける

```markdown
この版は `badge:v0.1.0` です。
```

頭を外した文言が札になる。
`badge:` の後ろが空か空白だけのときは、札にせず、書いたとおりの行内のコードで出る。
頭を打ち消して見せるときは、`:` の前に `\` を入れる。

### コードブロックを飾る

#### 題・行番号・行の強調をコードブロックの直前の印に書く

````markdown
<!-- code: title=app.ts lines highlight=2,4-6 -->

```ts
import { mount } from "mdmark";
const doc = await fetch("/README.md");
mount(document.querySelector("#doc"), await doc.text());
```
````

`title=` が題、`lines` が行番号、`highlight=` が強調する行になる。
使う引数だけを書く。
引数は空白で区切るため、題に空白は書けない。
強調する行は `2`・`4-6` のように、行の番号と範囲をコンマで並べる。
コードブロックの行の数を超える番号と、読めない指定は当てずに、書き方の警告が出る。
印の直後にコードブロックが無いときも、書き方の警告が出る。

#### 足した行・消した行・強調を行末の印で分ける

````markdown
```ts
let count = 0; // [\!code --]
let count = 1; // [\!code ++]
count += 1; // 数える [\!code highlight]
```
````

行末の行コメントに `[!code ++]`（足した行）・`[!code --]`（消した行）・`[!code highlight]`（強調）を書く。
行が色と行頭の `+`・`-` で分かれ、印は画面に出ない。
行コメントが印だけのときは、行コメントの頭（`//` など）も出ない。
知らない印（`[!code focus]` など）はその行に当てずに、書いた文字のまま出て、書き方の警告が出る。

印そのものを見せるときは、`[` の後ろに `\` を入れて打ち消す。
打ち消した印は、`\` を外した文字のまま出る。

言語 `tree` のコードブロック・図の部品の定義のコードブロック・`<!-- html -->` の範囲のコードブロックには、題・行番号・行の強調も行末の印も当たらない。

#### コードブロックに言語を書いて色分けさせる

````markdown
```yaml
name: mdmark # 名前
version: 1
```
````

コードブロックの開きの後ろに言語を書くと、キーワード・文字列・数値・型・名前・コメントが色分けされる。
印は要らない。
色分けする言語は `typescript`（`ts`・`tsx`）・`javascript`（`js`・`jsx`・`mjs`・`cjs`）・`json`・`yaml`（`yml`）・`python`（`py`）・`bash`（`sh`・`shell`・`zsh`）・`html`（`xml`）・`css`・`markdown`（`md`）・`sql`・`dockerfile`（`docker`）・`diff`（`patch`）。
`diff` は `+` で始まる行と `-` で始まる行を、互いに違う色で分ける。
括弧の中の別名も同じ言語として扱い、大文字と小文字は区別しない。
一覧は [コードブロックの飾り](../../リファレンス/記法.md#コードブロックの飾り)。
言語の無いコードブロックと、一覧に無い言語（`text` など）のコードブロックは、色分けしない。

題・行番号・行の強調・コードの行の印を付けたコードブロックも、行ごとの分け方と行番号・行頭の `+`・`-` を保ったまま、行の中身が色分けされる。
色分けのライブラリは、色分けする言語のコードブロックがある文書でだけ読み込む。
読み込めないときは、コードを欠けさせずに色分けなしで出す。
色分けを止めるときは、設定の `features.syntax` か文書の `<!-- features: -syntax -->` でオフにする（[機能をオン・オフする](../カスタマイズ/機能をオン・オフする.md)）。
読み込み先は設定の `syntax.url` で変える（[設定](../../リファレンス/設定.md#色分けのライブラリの読み込み先)）。

言語 `tree` のコードブロック・図の部品の定義のコードブロック・`<!-- html -->` の範囲のコードブロックと、文書に書いた生の HTML の `pre`・`code` は、色分けしない。

#### 言語とファイル名をラベルに出す

````markdown
```python:hoge.py
def hello():
    print("hello")
```
````

コードブロックの開きの後ろに言語を書くと、コードの上の帯の左端に、言語のラベルが出る。
`python:hoge.py` のように `言語:ファイル名` の形で書くと、`:` の前が言語、後ろがファイル名になり、ラベルに並んで出る。
`title=` で題を付けたときは、ラベルの後ろに題が出る。
言語の無いコードブロックには、ラベルを出さない。
ラベルは、文字を選んで写す中身に入らない。
`tree:src` のようにファイル名を付けた `tree` は、ファイルツリーにならず、普通のコードブロックとして描く。

#### コピーボタンで変更後のコードをコピーする

コードブロックの帯の右端に、`コピー` のボタンが付く。書くものは要らない。
押すと、コードをクリップボードへコピーする。
`[!code --]` の消した行は含めず、コードの行の印と、印だけを持つ行コメントの頭（`//` など）も含めない。
行番号と行頭の `+`・`-` も入らない。
コピーできたらボタンが `コピーしました` に変わり、しばらくすると元に戻る。
クリップボードへ書けなかったときは、ボタンが `コピーできませんでした` に変わり、次に押すまで残る。コードの文字は選んで手でコピーできる。

言語 `tree` のコードブロック・図の部品の定義のコードブロック・`<!-- html -->` の範囲のコードブロックには、ラベルもコピーボタンも付かない。

### 目次を置く

#### 印を書く

```markdown
<!-- toc -->
```

目次を出したい場所に書く。
h2〜h3 の見出しが入れ子で並び、各項目はその見出しへのリンクになる。

#### 右側の目次を使う

印は要らない。
h1〜h3 の見出しがある文書には、右側の目次が出る。
文書の右端の線にポインターを置くか、フォーカスを目次へ移すと、目次が出る。
項目を押すと、その見出しへ移る。
閉じた節の中の見出しは、外側の節を開いてから移る。
今読んでいる節の項目はハイライトされる。

#### 右側の目次の出し方を選ぶ

```yaml
side-toc:
  mode: fixed
```

`hover`（既定）は、目次のピン止めのボタンを押すと出し続ける。
`fixed` は、三点リーダーの目次を出すボタンを押すと、目次をサイドバーとして出し続ける。
設定のキーは [右側の目次の出し方](../../リファレンス/設定.md#右側の目次の出し方)。

### 節を閉じた状態で始める

#### 見出しの直後に印を書く

```markdown
## 補足

<!-- section: closed -->

補足の本文。
```

`closed` で閉じた状態、`open` で開いた状態で始める。
印を書かない節は開いた状態で始める。
開閉できるのは h1〜h4 の節。
`closed`・`open` 以外の値を書くと、開いた状態で描き、書き方の警告が出る。

### 節をまとめて開閉する

#### Shift を押しながら開閉する

Shift を押しながら見出しのボタンを押す。
その節と、中の入れ子の節が全て同じ状態になる。
キーボードでは、ボタンにフォーカスして Shift を押しながら Enter か Space を押す。

#### 右側の目次のボタンで開閉する

右側の目次の上部の「すべて展開」のボタンは、文書の全ての節を開く。
「すべて折りたたむ」のボタンは、h1 の節を開いたまま、h2〜h4 の節を全て閉じる。

### 行の詳細を付ける

#### 表の直後に印で囲んで詳細を書く

```markdown
| 名前 | 値 |
| --- | --- |
| りんご | 10 |
| みかん | 2 |

<!-- row-detail: 2 -->

みかんの詳細。

<!-- /row-detail -->
```

行の位置は、見出し行を除いて 1 から数える。
表の行より大きい位置を書くと、詳細を表の後の本文として描き、書き方の警告が出る。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書の印で決め直す。

## 確認

#### 注意書きが枠になっている

```js
document.querySelector(".mdmark .markdown-alert-title").textContent
```

`警告` など、書いた種類の題が出る。
閉じた注意書きは題だけが見え、押すと本文が出る。

#### タブが切り替わる

```js
document.querySelector('.mdmark [role="tab"][aria-selected="true"]').textContent
```

最初のタブの名前が出る。
別のタブを押すか、フォーカスのあるタブで左右の矢印キーを押すと、そのタブの `aria-selected` が `true` になり、中身が切り替わる。

#### 同じ組のタブが揃い、選んだタブを覚えている

```js
localStorage.getItem("mdmark-tabs:os")
```

組のタブを押すと、同じ組で同じタブ名を持つタブ群のタブも選ばれる。
押したタブ名が、組の名前を付けたキーに残る。
ページを開き直すと、そのタブ名のタブが選ばれている。
localStorage が使えないブラウザでは、残さず・読まずに、揃える動きと切り替えだけが働く。

#### 手順・ファイルツリー・バッジが組まれている

```js
[".mdmark-steps", ".mdmark-tree", ".mdmark-badge"].map((s) => document.querySelector(`.mdmark ${s}`) !== null)
```

書いた記法の分だけ `true` が出る。

#### 折り畳みの見出しが出ている

```js
document.querySelector(".mdmark .mdmark-collapsible > summary").textContent
```

`closed` のタブとステップは、見出しだけが出ている。
見出しは `title=` の値で、省いたときはタブが `タブ（uv・pip）`、ステップが `手順（2 ステップ）` になる。
見出しを押すと開く。

#### ファイルツリーの注釈・開閉・コピーが働く

```js
document.querySelector(".mdmark .mdmark-tree-note").textContent
```

`#` の後ろに書いた注釈が、`#` を除いて出る。
フォルダの名前を押すと、フォルダの `aria-expanded` が切り替わり、中身が出る。
ツリーの上の `コピー` のボタンを押すと、ボタンが `コピーしました` になる。

#### コードブロックに題・行番号・行の色が付いている

```js
document.querySelector(".mdmark .mdmark-code .mdmark-code-title").textContent
```

書いた題が出る。
コードブロックの各行の左に行番号が出て、強調した行・足した行・消した行が色で分かれている。
コードブロックの文字を全て選んで写すと、行番号と行頭の `+`・`-` が入らない。

#### コードブロックに言語のラベルとコピーボタンが付いている

```js
document.querySelector(".mdmark .mdmark-code .mdmark-code-lang-name").textContent
```

言語を書いたコードブロックなら、書いた言語（`言語:ファイル名` なら `:` の前）が出る。
コードブロックの帯の右端に `コピー` のボタンがあり、押して貼り付けると、行番号と行頭の `+`・`-` を含まない変更後のコードが入る。

#### コードブロックが色分けされている

```js
document.querySelector(".mdmark pre code .hljs-keyword") !== null
```

言語を書いたコードブロックなら `true` が出る。
色分けは描いた後に付くため、色分けのライブラリを読み終えてから確かめる。
コードブロックの文字を全て選んで写すと、色分けの前と同じ文字が写る。

#### 目次から移れる

目次の項目を押すと、URL の末尾が `#` と見出しの ID になり、その見出しが画面に入る。

#### 右側の目次が出て、移れる

```js
document.querySelector(".mdmark .mdmark-side-toc") !== null
```

h1〜h3 の見出しがある文書で `true` が出る。
右端にポインターを置くと目次が出て、項目を押すと URL の末尾が `#` と見出しの ID になり、その見出しが画面に入る。
スクロールすると、今読んでいる節の項目が `aria-current="location"` を持つ。

#### 節と行の詳細が開閉する

```js
document.querySelector(".mdmark .mdmark-section-toggle").getAttribute("aria-expanded")
```

閉じた節の見出しのボタンは `false` が出る。
押すと `true` になり、中身が出る。
行の詳細は、詳細を持つ行の先頭のセルのボタンで開閉する。
h1 の節のボタンも同じように開閉する。
Shift を押しながら押すと、中の入れ子の節も同じ状態になる。
右側の目次の「すべて折りたたむ」を押すと、h1 の節が開いたまま、h2〜h4 の節が全て閉じる。

#### 印が本文に出ていない

文書に印の文字が出ていない。

## 元に戻す

印を消し、注意書き・ファイルツリー・バッジの書き方を引用・コードブロック・行内のコードに戻し、コードの行の印を外すと、普通の Markdown として描かれる。
記法ごとに止めるときは、[機能をオン・オフする](../カスタマイズ/機能をオン・オフする.md) で機能をオフにする。
