# 表に機能を付ける

表を印で囲み、種類と機能を選ぶ手順

読む人が表を並べ替えたり絞り込んだりできるようにするとき、表を折り畳みに入れるときに実行する。

## 前提

- [文書を描く](../導入/文書を描く.md)

## 手順

### 表をマーカーで囲む

#### 種類を選ぶ

```markdown
<!-- table: data -->

| 名前 | 値 |
| --- | --- |
| りんご | 10 |
| みかん | 2 |

<!-- /table -->
```

表の前に `<!-- table: 種類 -->`、後ろに `<!-- /table -->` を書く。
種類は `data`（並べ替え・ピン止め・絞り込み）か `plain`（機能を付けない）。
囲まない表は既定の種類で、ピン止めだけが付く。
閉じのマーカーを書き忘れると、マーカーから文書の終わりまでが範囲になり、書き方の警告が出る。

#### 機能を追加・削除する

```markdown
<!-- table: plain +sort -->
```

`+機能` で種類の機能に追加し、`-機能` で外す。
機能は `sort`（並べ替え）・`pin`（ピン止め）・`filter`（絞り込み）・`count`・`columns`・`total`・`copy`・`rowlink`。
`count` 以降の 5 つはどの種類にも入っておらず、`+機能` で追加した表にだけ付く（付け方は次のセクション）。
知らない機能を書くと、その指定だけを当てずに描き、書き方の警告が出る。

#### 絞り込む列を決める

```markdown
<!-- table: data filter=名前,更新日:date -->
```

`filter=列名:種類` で、絞り込みを付ける列を決める。
列名は表の見出しの文字で書き、複数の列はコンマで区切る。
種類は `select`（値を選ぶ）・`text`（文字を含む行）・`date`（期間）で、省くと `select`。
絞り込みのボタンは、ここで決めた列の見出しにだけ付く。
表に無い列名と知らない種類は、その列に絞り込みを付けずに描き、書き方の警告が出る。

### 表に件数・列の切り替え・集計・コピー・行へのリンクを付ける

#### 件数を出す

```markdown
<!-- table: data +count filter=名前:text -->
```

`+count` で、表の上に `2 / 3 件` のように、表示している行の数と全ての行の数を出す。
絞り込みで行が減ると、表示している行の数が変わる。

#### 列の表示を切り替える

```markdown
<!-- table: data +columns hide=説明 -->
```

`+columns` で、表の上に `列の表示` のボタンを置く。
ボタンから列ごとに表示・非表示を切り替えられる。
`hide=列名` を書くと、その列を最初から隠す。複数の列はコンマで区切る。
メニューの「既定に戻す」で、`hide=` の状態に戻る。
先頭の列は隠せない。`hide=` に書くと書き方の警告が出て、その列は隠れない。
`hide=` は `+columns` を書いた表にだけ当たる。

#### 集計の行を付ける

```markdown
<!-- table: data +total total=数量:sum,単価:avg,名前:count -->
```

`+total` と `total=列名:計算` で、表の末尾に集計の行を置く。
計算は `sum`（合計）・`avg`（平均）・`count`（空でないセルの数）で、計算ごとに 1 行ずつ、`合計`・`平均`・`件数` の順に並ぶ。
各行の先頭のセルに計算の名前が出て、その計算を書いた列のセルに値が出る。
集計するのは表示している行で、絞り込みに合わせて計算し直す。
`sum` と `avg` は、空のセルを除いて計算する。
`sum` と `avg` の列に、空でなく数として読めないセル（`-` や `約 3` など）が 1 つでもあると、その列のその計算のセルを空にして、表の上に書き方の警告が出る。
警告に出た値を、数に修正するか空のセルにする。
`total=` は `+total` を書いた表にだけ当たる。`+total` を書いて `total=` を書かない表は、集計の行を出さない。
知らない計算と表に無い列名は、その指定だけを当てずに描き、書き方の警告が出る。

表の上の `集計` のボタンを押すと、`出す集計` のメニューが開き、計算ごとのチェックボックスで集計の行を出し入れできる。
選んだ状態は覚えず、描き直すと全ての計算が出る。

#### 表をコピーする

```markdown
<!-- table: data +copy -->
```

`+copy` で、表の上に `表をコピー` のボタンを置く。
ボタンを押すと `コピーの形式` のメニューが開き、`Markdown の表` か `TSV` を選んでコピーする。
`Markdown の表` は文書に貼るとそのまま表になり、`TSV` は表計算ソフトに貼るとセルに分かれる。
見出しの行と、絞り込みの後に見えている行の、列の表示で見えている列を、選んだ形式でクリップボードへコピーする。
隠した列と絞り込みで隠れた行は含まれない。
コピーできたらボタンが `コピーしました` に変わる。
クリップボードへ書けなかったときは、ボタンが `コピーできませんでした` に変わり、コピーする中身を選択したパネルが開く。
パネルの中身を手でコピーできる。パネルは閉じるボタンか Esc で閉じる。

#### 行へのリンクを付ける

```markdown
<!-- table: data +rowlink -->
```

`+rowlink` で、各行の先頭のセルに、その行を指す `#ID` のリンクを置く。
`#ID` は先頭の列の文字から作り、見出しのアンカーと同じ規則で、同じ文書の中で重なれば `-1`・`-2` が付く。
URL の `#ID` が行を指すと、その行へ移って強調する。
閉じた表と閉じたセクションの中の行は開いてから、絞り込みで隠れた行は絞り込みを外してから移る。
行へのリンクを押すと、行へ移る動きに加えて、その行を指す URL をクリップボードへコピーし、リンクの横に `リンクをコピーしました` と短く出す。
コピーできなかったときは `リンクをコピーできませんでした` と出る。
アドレスバーの URL も、その行を指す URL になる。

### 見出し行と最終列

書き方は要らず、どの表にも当たる。

#### 見出し行を画面の上端に留める

表に高さの上限は無く、縦はページのスクロールだけで読める。
表が画面に残っている間、見出し行はページを縦にスクロールしても画面の上端に留まる。
`+total` の表では、集計の行が画面の下端に留まる。
ページの上端に固定したヘッダーを置いているときは、見出し行を留める位置を CSS 変数で下げる（[テーマを上書きする](../カスタマイズ/テーマを上書きする.md)）。
横にはみ出す表は、表の中で横にスクロールし、ピン止めした列も留まる。

#### 狭い幅で最終列を畳む

描く先の要素の幅が 720px 未満で、最終列のセルが 1 行に収まらないときだけ、最終列を畳む。
畳んだ表は、最終列を出さず、各行の先頭のセルにボタンを置く。
ボタンを押すと、行の下に最終列の見出しと中身が開き、押し直すと閉じる。
行の詳細を持つ行は、1 つのボタンで最終列と詳細を一緒に開閉する。
幅を広げると畳まない。列の表示で最終列を隠しているときも畳まない。

### 表を折り畳みに入れる

#### `closed` か `open` を書く

```markdown
<!-- table: data closed -->
```

表を折り畳みに入れる。
`closed` は閉じた状態で始め、`open` は開いた状態で始める。
折り畳みの見出しは `表（{本文の行の数} 行）`。
`closed` と `open` を両方書くと `closed` を当て、書き方の警告が出る。

#### `title=` で見出しを付ける

```markdown
<!-- table: data open title=リリースの一覧 -->
```

`title=` の値が折り畳みの見出しになる。
`closed` か `open` と一緒に書く。
どちらも無い `title=` は当てずに、折り畳みに入れず、書き方の警告が出る。
マーカーの引数は空白で区切るため、見出しに空白は書けない。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書のマーカーで決め直す。

## 確認

#### 並べ替えが働く

並べ替えを付けた表の、数値の列の見出しを押す。
押すたびに昇順・降順・元の並びを繰り返す。

```js
document.querySelector(".mdmark th[aria-sort]").getAttribute("aria-sort")
```

1 回押した後は `ascending`、2 回押した後は `descending` が出る。
3 回押して元の並びに戻ると、`th` から `aria-sort` が外れる。

#### 絞り込みが働く

`filter=` で指定した列の見出しの絞り込みのボタンを押す。
ドロワーが開き、候補の検索欄にフォーカスがある。
値を選ぶと、その値の行だけが表に残る。
「絞り込みを外す」を押すと、全ての行が戻る。
ドロワーの外を押すか Esc を押すと、ドロワーが閉じる。

#### ピン止めが働く

表が幅からはみ出すときだけ、各列の見出しにピン止めのボタンが出る。
ボタンを押すと、その列までが表の左端に留まる。

```js
document.querySelector(".mdmark .mdmark-pin").getAttribute("aria-pressed")
```

`true` が出る。

#### 件数が働く

`+count` を付けた表の上に、`3 / 3 件` のように件数が出ている。
絞り込みで行を減らすと、表示している行の数が変わる。

#### 列の表示の切り替えが働く

`+columns` と `hide=列名` を付けた表で、その列が隠れている。
表の上の `列の表示` のボタンを押すとメニューが開き、列名のチェックボックスを入れると列が出る。
先頭の列のチェックボックスは外せず、メニューに `先頭の列は隠せません` が出ている。
「既定に戻す」を押すと、`hide=` の列だけが隠れた状態に戻る。

#### 集計の行が働く

`+total` と `total=` を付けた表の末尾に、計算ごとの集計の行が `合計`・`平均`・`件数` の順に出ている。
絞り込みで行を減らすと、集計が計算し直される。
並べ替えても、集計の行は表の末尾のままになる。
`集計` のボタンを押すと `出す集計` のメニューが開き、チェックを外した計算の行が非表示になる。
数として読めないセルを持つ `sum`・`avg` の列は、集計のセルが空になり、表の上に書き方の警告が出ている。

#### 表のコピーが働く

`表をコピー` のボタンを押して `Markdown の表` か `TSV` を選ぶと、ボタンが `コピーしました` に変わる。
貼り付けると、見出しの行と見えている行の、見えている列が、選んだ形式で入る。

#### 行へのリンクが働く

各行の先頭のセルのリンクの `href` が、`#` に続けて行の ID になっている。

```js
document.querySelector(".mdmark .mdmark-row-anchor").getAttribute("href")
```

ページの URL の末尾にその `#ID` を付けて開くと、その行へ移って強調される。
リンクを押すと、リンクの横に `リンクをコピーしました` と出て、貼り付けるとその行を指す URL が入る。

#### 見出し行が留まり、最終列が畳まれる

縦に長い表を持つ文書で、ページを縦にスクロールして表の途中を出すと、見出し行が画面の上端に見えている。
描く先の要素の幅を 720px 未満にして最終列が 1 行に収まらない表では、最終列が出ておらず、各行のボタンを押すと行の下に最終列の見出しと中身が開く。

#### 折り畳みの見出しが出ている

`closed` の表は、見出し `表（3 行）` だけが出ていて、表の行が出ていない。
見出しを押すと、表が開く。
`open` と `title=リリースの一覧` を書いた表は、見出し `リリースの一覧` の下に表が出ている。

#### マーカーが本文に出ていない

表の前後に、マーカーの文字が出ていない。

## 元に戻す

マーカーを削除すると、表は囲まない表の既定の種類に戻る。
表の機能を止めるときは、[機能をオン・オフする](../カスタマイズ/機能をオン・オフする.md) で `table` をオフにする。
