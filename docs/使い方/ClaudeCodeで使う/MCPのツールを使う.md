# MCP のツールを使う

使い方集を読み、文書の書き出し・まとめ・点検・索引の検索と書き換えを Claude Code から呼ぶ手順

プラグインを入れた後、Claude Code に mdmark の文書を書かせるとき、書き出し・点検・索引の操作を頼むときに実行する。
ツールの引数・戻り値・エラーは [MCP](../../リファレンス/MCP.md)。

## 前提

- [プラグインを入れる](./プラグインを入れる.md)
- 設定ファイル `mdmark.config.yaml` をセッションのフォルダか上のフォルダに置いている（[雛形を置く](../書き出す/雛形を置く.md)）

## 手順

### 使い方集を読ませる

#### 索引の名前を渡して本文を読ませる

セッションの開始で、使い方集の索引（名前・読むとき・概要）が Claude Code に渡る。
記法・部品・図の描き方・拡張の仕方を使う作業を頼むと、Claude Code が索引の名前を `read_guide` に渡し、その名前が指すページの本文を必要な分だけ読む。
本文は、`docs/` の使い方・リファレンスのページ。

```text
表に並べ替えを付けて、設計書の一覧を書いて
```

索引に無い名前を渡すと、近い名前を添えたエラーになる。

### 点検する

#### `check` を呼ばせる

```text
mdmark の設定と索引を点検して
```

`check` が `mdmark check` と同じ点検をして、ずれの一覧（ファイル・場所・種類・内容）を返す。
ずれがあってもエラーにならず、設定・索引・文書は書き換わらない。
内容に従って直させ、`issues` が空になるまで繰り返す。

### 文書を書き出す・まとめる

#### `export_html` と `build_site` を呼ばせる

```text
docs/guide.md を 1 枚の HTML に書き出して
```

```text
設定の build の文書を 1 枚の HTML にまとめて
```

`export_html` が `mdmark export`、`build_site` が `mdmark build` と同じ処理で HTML を書き、書いたパスと警告を返す。
同じ文書・設定では、CLI と同じ中身の HTML になる。

### 索引を探す・書き換える

#### `find_docs` と `update_index` を呼ばせる

```text
設計のタグを持つ文書を索引から探して
```

```text
索引に文書 b（b.md、題は文書 B）を追加して
```

`find_docs` が設定の `index` の索引から、題・別名・概要の語、タグ、関係する文書で文書を引く。
`update_index` が、文書か用語の ID の項目を置き換える（無ければ追加し、`null` なら消す）。
書く前に、書き換えた後の索引を索引のスキーマで検査し、合わなければ書かずにエラーを返す。

### 設定ファイルの場所を決める

ツールの `config` を省くと、Claude Code のセッションのフォルダから上のフォルダへ順に `mdmark.config.yaml` を探す。
別の設定ファイルを使うときは、そのパスを `config` に渡すよう頼む。

## 反映

ツールを呼ぶたびに、その場の設定・索引・文書を読む。
`export_html`・`build_site` は HTML を書き、`update_index` は索引のファイルを書き換える。

## 確認

#### 点検のずれが 0 件になっている

`check` を呼ばせ、`issues` が空になる。

#### 書き出した HTML がある

`export_html` と `build_site` が返した `out` のファイルがある。

## 元に戻す

`check`・`read_guide`・`find_docs` は何も書き換えない。
書き出した HTML は、`out` のファイルを消す。
`update_index` で書き換えた索引は、git で戻す。
