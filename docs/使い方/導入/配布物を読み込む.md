# 配布物を読み込む

版を固定した URL で JavaScript と CSS を読み込む

mdmark を使うページを作るときに実行する。
サーバーの言語に関わらず、ページに書いたタグだけで使える。

## 前提

- 読み込む版のタグが公開されている（[変更履歴](../../はじめに/変更履歴.md) に載っている版）

## 手順

### 読み込む版のタグを決める

[変更履歴](../../はじめに/変更履歴.md) から使う版を選び、`v{MAJOR}.{MINOR}.{PATCH}` の形のタグで控える。
ブランチ名・`latest`・版の範囲は使わない。
CDN にキャッシュされ、新しい版へ切り替わるまで時間がかかる（[配信元の説明](https://github.com/jsdelivr/jsdelivr)）。

### CSS と JavaScript を読み込む

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{タグ}/dist/index.css">
<script type="module">
  import { version } from "https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{タグ}/dist/index.js";

  console.log(version());
</script>
```

`{タグ}` を手順の最初に決めたタグに置き換える。
2 つの URL で同じタグを使う。
違うタグにすると、CSS と JavaScript の版が食い違う。

## 反映

即時。ページを再読み込みすると、書いたタグの版が読み込まれる。

## 確認

#### 公開関数が版を返す

ブラウザの開発者ツールのコンソールを開く。

```js
version
```

ページの `console.log(version())` の出力が、書いたタグと同じ `v{MAJOR}.{MINOR}.{PATCH}` になる。

#### CSS が読み込まれている

```js
getComputedStyle(document.documentElement).getPropertyValue("--mdmark-version")
```

書いたタグと同じ版を引用符で囲んだ文字列が出る。

#### 読み込めなかったとき

タグかファイルが無いと、CDN は 404 を返す。
ページの本文はそのまま表示され、`index.js` を読み込めなかったエラーがコンソールに出る。
タグの書き間違いと、そのタグが公開されているかを確かめる。

## 元に戻す

`<link>` と `<script>` の 2 行をページから消す。
CDN にもページにも残るものはない。
