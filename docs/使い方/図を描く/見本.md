# 見本

フロー図・シーケンス図・グラフ・操作できる部品を組み合わせた見本の文書

部品の定義を書き写して始めるときに開く。
見本のページ（E2E が開く文書）は、この文書を描く。

## 問い合わせ窓口の設計メモ

問い合わせのメールを受け取り、意思決定モデルが返信の種類を選び、LLM がよくある質問から下書きを書いて、担当者のチャットへ控えを流す。
