mdmark-table

アプリの画面が <mdmark-table> に列の定義と行のデータを指定して描いた表（#793）。表の外観と操作は Markdown の表の部品と同じ。点線の枠線はアプリの画面の中の <mdmark-table> の場所（幅 480px）

通常

タイトルの列をピン止めし、状態の列に絞り込みを付け、列の表示・列の並べ替え・列の幅の変更を付けた表。200 文字ほどのタイトルは列の最小の幅で折り返し、表は枠線の中で横にスクロールする。1 行目の <script> は文字のまま出す

行を押す

行全体が押せる。3 行目はポインターを乗せた状態、4 行目はフォーカスした状態（Enter で押したことになる）。並べ替え・ピン止め・絞り込みのボタンを押しても行の押下にはならない

セルを編集する（要件の 未確定）

担当の列を編集できる列にした表で、2 行目の担当のセルを編集している状態

案 A: 表の部品が入力欄を描く（推奨）

編集できる列のセルは破線の下線で示す。セルを押すか、フォーカスして Enter・F2 で入力欄になる。Enter で確定するとセルの編集のイベントを通知し、Esc で取り消すと前の値に戻る

案 B: アプリがセルの中身の差し替えで入力欄を描く

表の部品はセルを押したことだけを通知し、アプリが自分の入力欄（ここでは選択と保存のボタン）をセルに描く

行を追加する

行の追加を許可した表の下の左端に「行追加」のボタンを配置する。押すと行の追加のイベントを通知し、アプリが行のデータを指定し直すと 6 行の表に描き直す

セルの中身を差し替える

アプリが状態の列のセルの描き方を指定し、値をバッジで描いた表。並べ替えと絞り込みは、バッジでなく行のデータの値で動く

データの誤り

行のデータに配列でない値を指定したとき、表の場所に誤りの通知を出す。ページのほかの要素は動く
