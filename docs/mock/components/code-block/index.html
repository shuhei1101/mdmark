コードブロックに無い行の番号（異常シナリオ）

記載の警告

<!-- code: highlight=2,5 --> の 5 行目がありません。コードブロックは 3 行です。行の番号を 1〜3 で記載してください。5 行目を除いて強調しています。

import { mount } from "mdmark";

mount(document.querySelector("#doc"), await doc.text());

知らないコードの行のマーカー（異常シナリオ）

記載の警告

コードの行のマーカー [!code blink] は使用できません。使用できるマーカーは [!code ++]・[!code --]・[!code highlight]・[!code focus]・[!code error]・[!code warning] です。1 行目には当てず、記載した文字のまま描いています。

const doc = await fetch("/README.md"); // [!code blink]
