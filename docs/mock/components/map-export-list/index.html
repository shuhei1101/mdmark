map-export-list

書き出すボタンとメニュー

パネルを開くと、全画面のボタンの隣に書き出すボタン（スクリーンリーダー向けの名前「図を書き出す」）がある。押すと SVG と PNG の項目のメニューを開き、選ぶとグループの開閉を今のまま、倍率と表示する位置に依らず等倍の図の全体を書き出す（PNG は 2 倍の画素数）。Esc と外側のクリックでメニューを閉じ、書き出すボタンへフォーカスを戻す。このモックでは実際にダウンロードする

メニューを開いた状態

一覧の表示（構成図）

パネルの map のグループの先頭に一覧の表示のボタン（「一覧で表示」と aria-pressed）がある。押すと表示する枠の中を、グループを子を持つ項目・ノードを項目にした入れ子の一覧に替える。ノードの項目は名前・種類の名前・補足の説明・出る線（「→ 相手」と線のラベル）を持つ。↑↓ で項目を移り、→ で開き、← で閉じる。もう一度押すと、倍率・位置・開閉を保ったまま図の表示に戻す

一覧の表示（シーケンス図）

メッセージを記載順に「送信元 → 送信先: メッセージ」の項目で並べる

一覧の表示のボタンを持たない図（ガントチャート）

マインドマップと軸と格子の配置の図のパネルには、一覧の表示のボタンが無い。書き出すボタンは全ての map の図のパネルにある
