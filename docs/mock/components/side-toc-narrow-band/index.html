side-toc-narrow-band

描く先の要素の幅が 48rem 未満のときの、右側の目次のバー（今いるセクションの見出しと目次を出すボタン）の固定の見せ方の案（#790）。どの見本も、利用側の高さ 48px の固定のヘッダーの下で、表の途中までスクロールした場面

今: バーを `--mdmark-sticky-top` に固定する
