map-wire-label

配布物の mount で描いた実物の図に、案ごとの線の上の文字の置き方を重ねている

線の上の文字の今の設定

項目今の設定
記載方法Mermaid の A -->|文字| B か A -- 文字 --> B。補足の notes の線の説明はツールチップに出し、線の上には出さない
位置（構成図・状態遷移図・アーキテクチャ図・C4 図）線の最も長い区間の中点に、文字の中心を重ねる
位置（ER 図）両端を除いた最も長い区間の中ほどで、横の区間は上へ 8px、縦の区間は右へ 8px 離して置く。ほかのラベルと重なるときは 1 行分ずつ下へずらす
位置（クラス図）両端を除いた区間を長い順に、中ほど・4 分の 1・4 分の 3 の位置で、縦の区間は右・左、横の区間は上・下を試し、ノードとほかの文字に重ならない最初の場所に置く。全て重なるときは ER 図と同じ置き方
位置（軸と格子の配置の図）線の中ほどから左へ 28px・上へ 20px の位置に、幅 56px で折り返して置く（ブロック図）
大きさ（構成図・状態遷移図・アーキテクチャ図・C4 図）11px（map の図の上書き）・行の高さ 1.5。左右に 6px の余白と枠線を持ち、背景の色で塗る（下の線を隠す）
大きさ（ER 図・クラス図）12px の SVG の文字。枠線は持たず、背景の色の 4px の縁取りで下の線を隠す
大きさ（軸と格子の配置の図）12px・幅 56px・角の丸み 4px。背景の色で塗る（下の線を隠す）
折り返し軸と格子の配置の図のほかはしない（1 行のまま線の長さを越えて伸びる）
色構成図・状態遷移図・アーキテクチャ図・C4 図は控えめな色（linkStyle の color を持つ線はその色）。ER 図・クラス図は本文の色
