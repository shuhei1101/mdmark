map-trust-changes

上の操作列の「ダーク」で、全ての場面をダークで確認できる

確信度のバッジ

補足の trust を持つノードとグループのタイトルの右上に、確信度の名前のバッジを枠線をまたいで重ねる。仮説・出典なしはバッジの枠線を破線にし、色に頼らず見分ける。ラベルを持つ線はラベルの後ろ、ラベルを持たない線は経路の中点にバッジだけを出す。trust を持たないノード（キャッシュ）と線にはバッジが無い

確信度を持つ線のツールチップ

確信度を持つ線にポインターを重ねると、補足の notes の説明の有無に依らずツールチップを出し、先頭の行を確信度にする。左は説明を持つ線、右は説明を持たない線

計画した変更

補足の changes の added は差分の追加の色、changed は色の名前 orange、removed は差分の削除の色の破線の枠線と取り消し線の名前で描き、それぞれのバッジを付ける。削除のノードと線も配置に含める。確信度と変更の両方を持つノード（mount）は、2 つのバッジを右から並べる

記載の警告

無い ID（map_unknown_ref）と知らない値（map_invalid_value。使用できる値の一覧を含む）を図の前の記載の警告に出し、その 2 つにはバッジを付けない。シーケンス図など trust・changes を使用できない種類に記載したときも、同じ記載の警告にしてバッジを付けない

狭い幅

図の倍率は変えず、バッジは図と一緒に横にスクロールする
