map-wire-drag-route

配布物の mount で描いた実物の図。線の区間・ノードをマウスでドラッグすると、今の決まりのとおりに経路が変わる。右上のパネルの「配置と選択を元に戻す」で自動配置に戻る

今の経路の決まり

操作・きっかけ固定するもの計算し直すもの
線の真ん中の区間をドラッグする ほかの区間の向きと、両端のノードの辺 動かした区間を区間と直角の向きへずらし、前後の区間を伸び縮みさせてつなぐ
線の端の区間をドラッグする 端がつながるノード 端をノードの辺に沿ってずらす。辺の端を越えると越えた側の辺へつなぎ替え、ノードの中央から直角にその辺へ入る
ずらした区間がノードの上に重なる 重なる前の区間 ノードの中に入った点を除き、手前の点からノードの辺へ直角に入り直す（真ん中の区間をノードの上へ動かすと上の辺から入る）
線を動かした後にノード・グループを動かす・開閉する - 自動配置で線の点の数が変わると、その線のずらしを捨てて自動の経路に戻す。点の数が同じなら、自動の経路に前のずらしの量をそのまま足す
再読み込みする ずらした区間の番号・ずらした量・線の点の数 自動配置の経路にずらしの量を足して描き直す

期待と違う形状になる図と操作（どの線のどの区間を、どの向きへ動かしたか）と、期待した形状を教えてください。指摘を反映したモックを作り直して確認を重ねます

入力の右の辺から出て、直角に曲がって点検の下の辺に入る線の、縦の区間を右へ動かしていく。点検の右端を越えたら、点検の右の辺へ回り込んでつなぐ。線の端はどの操作でも接続先のノードの辺に付き、ノードから浮かない
