diff-side-by-side

前のリビジョン（r1）を左、後のリビジョン（r2）を右に描き、変えていないブロックを同じ高さで向かい合わせる。追加・削除・変更したブロックは差分のブロックの色と記号で示す（#783）。変更表示のボタンとリビジョンを選ぶ欄を出さない指定で描いた状態（#784）

広い幅（1280px）

r1 → r2 で、段落の単語を書き換え、表の後に段落を 1 つ追加し、別の段落を 1 つ削除した。見出しと表は変えていない。向かいに対の無いブロックの向かいは斜線の空きにする

後: r2（2026-11-21）

追加・削除した箇条書きの項目の +・− を、項目の 1 行目の高さに描く。左が今の描き方の再現、右が修正後

今: 記号が項目の行より下にずれる

  • 本文の Markdown
  • 追加:+添付したファイル

  • 記録の YAML
  • 本文の Markdown
  • 追加:+添付したファイル。2 行目に折り返す長い項目でも、記号は 1 行目の高さに描きます
