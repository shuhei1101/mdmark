## 色の役割

<!-- table: data -->

| 役割 | 使用する場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 主 | 地・本文・見出し・主のボタン | `--mdmark-color-bg` / `--mdmark-color-text` / `--mdmark-color-heading` | 主のボタンは文字の色で塗り、ボタンの文字を地の色にする。主のボタンはコメントの入力欄の「コメントを保存」だけで、文言でも示す |
| 不透明な地 | 浮く部品・表の覆いと留める見出し・選んだタブの地、色を混ぜる先 | `--mdmark-color-bg-opaque` | 既定は `var(--mdmark-color-bg)`。`--mdmark-color-bg` を透明にする利用側は、ここに周りの面の色を指定する |
| 控えめな文字 | 引用 | `--mdmark-color-muted` | - |
| マーカー | リンク・フォーカスの枠 | `--mdmark-color-link` | mindstella のマーカーの色（青緑）。強い色はこの 1 色だけ。リンクは下線と併せて示す |
| 面と線 | コード・引用・表の見出し行の面、枠と罫線 | `--mdmark-color-surface` / `--mdmark-color-border` | mindstella の本文の表（`--surface-2` / `--border-soft`）と同じ明るさの差 |
| 表の見出し行 | マーカーの付いた表の留まる見出し行の面 | `--mdmark-color-table-head` | `--mdmark-color-surface` と同じ値 |
| 状態色 | 通知ブロック・記載の警告・やめた言い方のマーカーだけ | `--mdmark-color-notice-bg` / `--mdmark-color-notice-border` / `--mdmark-color-notice-text` | 記載の警告は線とタイトルのアイコンだけに使用し、地を塗らない。やめた言い方のマーカーは `--mdmark-color-avoided-underline` の既定に線の色を使用し、波線の形状でも示す |
| コメントのマーカー | コメントが付いた本文の文字の地と下線、入力欄を開いている間の選んだ文字 | `--mdmark-color-comment-bg` / `--mdmark-color-comment-line` | 地の色と下線で示し、色だけに頼らない |
| 入力欄の誤り | コメントの入力欄の通知の文字とアイコン、誤りのある本文の欄の枠、コードブロックのエラーの行の左端の線・行頭の文字・地 | `--mdmark-color-error` | 通知はアイコンと文でも示す。エラーの行の地はこの色を地に 12% 混ぜ、行頭の `×` でも示す |
| 種類の色 | 注意書きの面・線・タイトル・アイコンと、コードブロックの警告の行の左端の線・行頭の文字・地（`-warning` だけ）だけ | `--mdmark-color-callout-note` / `-tip` / `-important` / `-warning` / `-caution` | 面は種類の色を地に 7%、線は 40% 混ぜる。タイトルの文字とアイコンでも種類を示す。警告の行の地は `-warning` を地に 14% 混ぜ、行頭の `!` でも示す |
| 図の層・ノードの種類 | 図の層の背景、ノードの枠・アイコン | `--mdmark-color-diagram-llm` / `-dm` / `-script` / `-mcp` / `-data` / `-external` | 層の背景はノードの色を `--mdmark-diagram-lane-tint` でうっすら敷く。ノードの種類は色に加えてアイコンと種類の名前でも示す |
| 図の線の種類 | 図の処理の流れ・戻る線 | `--mdmark-color-diagram-line` | 線の種類は色と模様（破線の間隔・太さ・矢じり）の組で分け、色だけで分けない |
| グラフの系列 | グラフの系列の線・点・塗り | `--mdmark-color-series-1` 〜 `-6` | 色に加えて線の模様・点の形状・塗りの模様でも分ける |
| 色の名前（色のプリセット） | 作成者が色の名前を記載した表の列と行の面・バッジ・本文の文字だけ | `--mdmark-color-accent-{色}-bg` / `--mdmark-color-accent-{色}-text` | 色の名前は `blue`・`red`・`green`・`yellow`・`orange`・`purple`・`gray`。面の薄い色は色の名前ごとに色相を決めた OKLCH の値で、同じテーマ・配色の面どうしの色差（CIE76 の ΔE）を 10 以上にする。文字の色は地と面の薄い色の両方に 4.5:1 以上。値は選べるテーマごとに明るい配色と暗い配色の組で持ち、配置場所は `docs/mock/refs/263/assets/colors.css`。色だけで意味を伝えず、強調した列は見出しのセルの下端の線、色を付けた行は上下の 1px の線、本文の文字は太字でも示す（[確認ログ](./pr/263/確認ログ.md)） |
| 色分けの種類 | コードブロックの色分けの文字だけ | `--mdmark-color-syntax-keyword` / `-string` / `-number` / `-type` / `-name` / `-comment` | キーワード・文字列・数値・型・名前・コメントの 6 種類に絞り、変数名・引数・記号は本文の色のまま。コメントは斜体でも示す |

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 本文 | OS 標準のゴシック | `--mdmark-font-body`。大きさ 0.875rem（mindstella の本文の 13px より 1 段大きい 14px）、行間 1.8、行の長さは既定で描く先の幅いっぱい（利用側が `--mdmark-content-width` で上限を指定できる） |
| 見出し | 本文と同じゴシックの太字 | `--mdmark-font-heading` / `--mdmark-heading-weight`（700） |
| コード | 等幅 | `--mdmark-font-mono` |
| 数値 | 等幅数字 | 表の中で桁を統一する |

## 構造と奥行き

<!-- table: data -->

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| コードブロック・折り畳み・通知ブロック | 線と小さめの角丸 | `--mdmark-radius`（4px） |
| 引用 | 面の色と角丸 | 線を描かない |
| 表 | 角丸の外枠と縦横の 1px の線 | 見出し行だけ面の色、本文の行は地の色。外枠の角丸は `--mdmark-radius` の 2 倍 |
| 注意書き | 種類の色の薄い面と淡い線、小さめの角丸 | - |
| 記載の警告 | 破線と小さめの角丸 | 通知ブロックの塗りと見分ける |
| セクション | 余白と見出しの大きさ・太さ、見出し 1・見出し 2 の下の線 | 見出し 1・見出し 2 の下に薄い 1px の線を描き、文字と線の間を 0.3em にする。区切り線（`---`）は 0.25em の太さにして、見出しの線より太くする。見出しの上の余白を下より広く取る |
| 図の枠 | 表示するノード（右上のボタンの帯と表示する枠）の内側の 1px の線（`--mdmark-diagram-box-shadow`） | 枠の中で枠を重ねない。操作できる部品の中では線を描かず、枠を持つ面の中では利用側が線を削除する |
| 操作できる部品 | 1px の線と小さめの角丸 | 中の図の枠の線を描かず、部品の枠だけで囲む |

## 使用しないもの

| 使用しないもの | 理由 | 補足 |
| --- | --- | --- |
| マーカーの色以外の強い色 | マーカーが目立たなくなる | 状態・種類・系列の色は表示にだけ使用する。色の名前の色は、作成者が文書に記載した箇所にだけ付く |
| 影 | 奥行きは線と面の色で表し、表し方を混ぜない | - |
| グラデーション・光る影 | 静かな外観とぶつかる | - |
| 見出しの前の記号 | 開発者でない読み込み手に意味が伝わらない | 変数 `--mdmark-h1-marker` などの既定は空 |
