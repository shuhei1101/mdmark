# 図を自動配置して辿る仕組み

マーカーの引数・Mermaid・補足の役割の分け方、入れ子の自動配置と上書き、ノードと線を描く流れ、中へ入る・開閉で配置し直す流れ

map の範囲を記載してから、読者がグループの中へ入る・開閉・案内・再生で図を辿れるようになるまでの考え方。
手順は [Mermaidと補足で図を描く](./図を描く-Mermaidと補足で図を描く.md)。

## 記載するものの役割

| 記載するもの | 役割 |
| --- | --- |
| マーカーの引数（`<!-- map: {…} -->`） | 見せ方の初期値。図のタイトル・最初に入るグループ・自動で進めるか・間隔・折りたたみ |
| Mermaid のブロック | 図の中身。ノード・グループ（`subgraph`）・線・メッセージ。GitHub などでもそのまま図になる |
| 補足（`<!-- map-data: {…} -->`） | Mermaid に記載できない説明・案内の手順・配置と見た目の上書き・再生を重ねる構成図 |
| 設定の `map` | 文書をまたいで共通の、ノードの種類・線の種類・名前の長いノードの広げ方・状態の保ち方 |

座標はどこにも記載しない。
ノードの種類と線の意味は mdmark が持たず、利用側が設定で作る。

## 描くまでの流れ

1. `render` が map の範囲を `div.mdmark-map` にし、Mermaid のソースのコードブロックと、補足の JSON の文字を隠した要素を中に置く。範囲の形（マーカーの引数・ブロックの数・図の種類）の誤りだけを記載の警告にする
2. `mount` が `div.mdmark-map` を見つけた文書でだけ、map の処理を持つ配布ファイル `dist/map.js` を読み込む
3. Mermaid と補足を読み取り、読めない行・補足の誤り・無い ID を図の前の記載の警告にする。読めた部分は図にする
4. 入れ子のグループを自動で配置し、線の経路を引く
5. 配置の結果のノードと線を描き、グループの面・開閉と中へ入るボタン・データの印を重ねる
6. 描いたノードの中身を測り、見積もりと違う大きさのノードがあれば、測った大きさで配置し直す

Mermaid の読み取りと配置は mdmark が独自に持ち、mermaid のライブラリは読み込まない。
ツールチップ・図の枠の操作は、グラフ・ER 図と同じ部品で描く。

## 図の種類ごとに分ける部分

種類に依らない部分は構成図と共通にし、図の種類ごとに分けるのは読み取り・構成図の入力への読み替え・固有の機能だけにする。

| 部分 | 構成図 | シーケンス図 | ER 図 | 状態遷移図 |
| --- | --- | --- | --- | --- |
| 読み取り | `flowchart` | `sequenceDiagram` | テーブル・列・関連と多重度 | 状態・入れ子の状態・遷移・ノート |
| 配置 | 入れ子の自動配置 | 参加者とメッセージの行 | テーブルをノード、補足の `groups` の分類をグループにして、構成図と同じ自動配置 | 状態をノード、入れ子の状態をグループにして、構成図と同じ自動配置 |
| 固有の機能 | - | ブロックの開閉・参加者の並べ替え | 列の行と開閉・関連の端を列の行の高さへ付け替え・2 つのテーブルの経路と行が増える関連のマーカー | 開始・終了・分岐の形状・同じ状態への遷移・ノート・遷移の再生 |

補足の `notes`・`layout`・`walkthroughs`、拡大と縮小、ツールチップ、中へ入る・開閉、選択と強調、移動、案内と再生の帯、状態の保ち方は、どの種類でも同じ。

## 入れ子の自動配置

グループの内側から外側へ、次の順に配置する。

1. グループの中の線を、直下の子どうしの線に持ち上げる
2. 閉路の戻りを外した最長路で段を決め、`direction` の向きに段を並べる
3. 段の中の並びを、隣の段の重心で 4 回掃引して交差を減らす
4. 補足の `layout` の `align`・`order`・`justify`・`pos` を当て、グループの大きさを決める
5. 外側のグループへ座標を足し、ノードとグループの矩形を避ける格子の経路探索で、縦と横だけの線を引く。補足の `ends`・`via` がある線は、その辺から出入りし、経由点を通る

上書きの無い部分は自動の配置のまま。
上書きは配置し直しても保つ。

## 中へ入る・開閉で配置し直す

中へ入る・開閉のたびに、見せる木を作り直してから配置し直す。

| 操作 | 見せる木 |
| --- | --- |
| 中へ入る | 入ったグループの中だけを配置し、外は配置を変えずに薄く残す。外から中への線は、薄く残した外のグループから引く |
| 閉じる | 閉じたグループを 1 つのノードにし、中への線を閉じたグループへ付け替え、同じ相手との線を 1 本にまとめる |

配置し直しても、図の倍率・表示する位置・枠の高さは変えず、ノードとグループは前の位置から今の位置へ動かす（動きを減らす設定では動かさない）。

## 状態の保ち方

中へ入ったグループ・開閉・選んだノード・動かした位置は、同じタブの中で描き直しても保つため sessionStorage に入れる。
中へ入ったグループとシーケンス図の中だけを描くブロックは、URL のクエリ文字列 `map-{図の番号}` にも保ち、その URL を開くと同じ場所から描く。
最初の見せ方は、クエリ文字列 → sessionStorage → マーカーの引数 `focus` の順に決める。
動かした位置は文書に書き戻さない。

## 記載の警告と点検

描くときは、読めない行や誤りがあっても止めずに読めた部分を描き、図の前の記載の警告に修正方法を並べる。
マーカーの引数の知らないキーは描くときには無視し、`mdmark check` だけが `map_unknown_key` で通知する。
`mdmark check` は、描くときと同じ読み取りで、補足のスキーマ・補足が指す ID・`--` を含む値・設定の `map` のアイコン・クラス・線の名前を点検する。
