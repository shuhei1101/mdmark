# 共通の定義と固有の定義

基盤の部品と CSS、利用側の固有の部品と CSS の層と、該当する範囲

図・部品を、mdmark が持つ共通の定義と、利用側が追加する固有の定義に分ける考え方。

## 2 つの層

| 層 | 持つもの | 追加する場所 |
| --- | --- | --- |
| 共通の定義 | map の図・グラフ・ER 図・操作できる部品の部品と、色・文字・ライト / ダークの CSS 変数 | mdmark の配布物（`dist/index.js`・`dist/index.css`） |
| 固有の定義 | 利用側だけの部品と CSS | 利用側の拡張（`registerExtension`）と `theme.css` |

文書に記載するのは、部品の定義（JSON）だけ。
描くのは共通の部品か固有の部品で、文書に記載した任意のスクリプトは動かさない。

共通の部品は、文書のマーカーと、利用側の JavaScript・TypeScript の両方から使用できる。
文書のマーカーは `mount` が描き、利用側のページと拡張のモジュールは、配布物が出す `mountView` などの関数で同じ部品を描く（[部品をJavaScriptから使用する](./カスタマイズ-部品をJavaScriptから使用する.md)）。

## 固有の定義の追加方法

- 固有の部品は、`registerExtension` でマーカーと、そのマーカーを描くモジュールを追加する。部品の定義はマーカーの範囲に配置した `json` のコードブロックで、`definition` として渡る
- 固有の CSS は、層の外の CSS で CSS 変数と規則を上書きする（[文書を描く仕組み](./コアコンセプト-文書を描く仕組み.md#テーマの層)）
- 利用側が追加する JavaScript は、`// @ts-check` と JSDoc で記載し、配布物の型定義に対して `tsc --noEmit` で点検する

手順は [固有の部品とCSSを適用する](./図を描く-固有の部品とCSSを適用する.md)。

## 該当する範囲

固有の定義が該当する範囲は、設定ファイル `mdmark.config.yaml` の単位。

| 描き方 | 該当する文書 |
| --- | --- |
| `mount`・`render` | `registerExtension` を呼び、固有の CSS を読み込んだページの文書 |
| `mdmark export`・`mdmark build` | 同じ設定の `theme`・`extensions` で書き出した文書 |

読み込んでいない場所の文書では、固有の部品のマーカーは知らないマーカーとして取り除かれ、固有の CSS は該当しない。
共通の部品は、どこでも mdmark の既定の外観で描かれる。
