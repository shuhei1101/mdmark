# 索引

索引のキー・型・必須・既定と、点検が返却するずれの種類の一覧

利用側が文書のメタデータと用語を記載する YAML のファイルのスキーマ。
場所は設定の `index` で決める（[索引の場所](./設定.md#索引の場所)）。
mdmark はブラウザでファイルを読み込まない。
利用側のサーバーが読み込んだオブジェクトを、`mount`・`render`・`collectReferences`・`checkIndex` に指定する（[API](./API.md)）。
スキーマは、リポジトリの `schemas/mdmark.index.schema.json`（JSON Schema draft 2020-12）で縛る。
記載方法の手順は [索引と用語集を記載する](./記載する-索引と用語集を記載する.md)。

## 一覧

| 名前 | キー | 説明 |
| --- | --- | --- |
| [最上位のキー](#最上位のキー) | `schema`・`docs`・`terms` | 索引のバージョンと、文書・用語の並び |
| [文書](#文書) | `docs[]` | 索引に記載する文書 1 つのメタデータ |
| [用語](#用語) | `terms[]` | 索引に記載する用語 1 つ。本文に出たら意味のツールチップを付ける |
| [点検が返却するずれ](#点検が返却するずれ) | `kind` | `checkIndex` が返却するずれの種類 |

## 最上位のキー

ここに挙げたキー以外は記載できない。

<!-- table: data -->

| キー | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `schema` | 整数 | 必須 | 索引のスキーマのバージョン。今は `2`。v0.9.0 までの `1` の索引は `mdmark upgrade` で移す |
| `docs` | 文書の並び | 必須 | 索引に記載する文書 |
| `terms` | 用語の並び | 任意 | 索引に記載する用語 |

<!-- /table -->

```yaml
schema: 2
docs:
  - id: arch
    path: 設計/arch.md
    title: アーキテクチャ
    description: 全体の構成と依存の向き
    aliases: [構成図]
    tags: [設計, { name: topic:mcp, main: true }]
    related:
      - to: api
        type: requires
        when: 公開関数の仕様を確認するとき
  - id: api
    path: api.md
    title: API
terms:
  - id: workspace
    term: ワークスペース
    aliases: [WS]
    meaning: 話し合いの記録を配置するフォルダ
    avoid: [作業場]
```

## 文書

索引に記載した文書 1 つのメタデータ。

<!-- table: data -->

| キー | 型 | 必須 | 既定 | 説明 |
| --- | --- | --- | --- | --- |
| `id` | 文字列 | 必須 | なし | 文書の ID。`docs` の中で一意。空にできない |
| `path` | 文字列 | 必須 | なし | 文書のパス。索引のファイルのあるフォルダからの相対パスで、区切りは `/`。`docs` の中で一意。空にできない |
| `title` | 文字列 | 必須 | なし | 文書のタイトル。関連文書のリンクの文字に出す。空にできない |
| `description` | 文字列 | 任意 | なし | 1 文の概要。ツールチップの「関連文書」に出す |
| `aliases` | 文字列の並び | 任意 | `[]` | 本文での呼び名。本文に出たら、その単語のツールチップの「関連文書」にこの文書を出し、被参照にも数える。要素は空にできない |
| `tags` | タグの並び | 任意 | `[]` | タグ。描くことには使用しない。要素はタグの名前の文字列か、`name`（必須・空にできない文字列）と `main`（主題のタグか。任意・既定 `false`）を持つオブジェクト。文字列の要素は `main: false` と同じ |
| `related` | 関連の並び | 任意 | `[]` | この文書から他の文書への関連。要素は関連のオブジェクトか、関連する文書の `id` の文字列（[関連の要素](#関連の要素)）。件数の上限は配置しない。`to`（文字列の要素はその文字列）をこの文書からその文書への参照として数える。索引に無い `id` は点検が通知する |

<!-- /table -->

### 関連の要素

`docs[].related` のオブジェクトの要素のキー。
ここに挙げたキー以外は記載できない。

<!-- table: data -->

| キー | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| `to` | 文字列 | 必須 | 相手の文書の `id`。空にできない |
| `type` | 文字列 | 必須 | 関係の種類。`requires`・`references`・`replaces`・`part_of`・`change_together` のどれか |
| `when` | 文字列 | 必須 | いつ読み込むかの 1 文。空にできない |
| `paths` | 文字列の並び | 任意 | 関連が該当するファイルの glob の並び。要素は空にできない |

<!-- /table -->

関係の種類は次のとおり。

<!-- table: data -->

| `type` | 意味 |
| --- | --- |
| `requires` | 相手を先に読み込まないと分からない |
| `references` | 相手を必要なときに参照する |
| `replaces` | 相手を置き換えた |
| `part_of` | 相手の一部をなす |
| `change_together` | 片方を修正したらもう片方も修正する |

<!-- /table -->

関連は片側だけに記載する。
`change_together` だけは、両側に記載する。
片側にしか記載していない `change_together` は、点検が `one_sided_change_together` で通知する。

文字列の要素も読み込める。
`type` と `when` を持たない関連として扱い、点検が `untyped_related` でオブジェクトへの書き換えを求める。

## 用語

索引に記載した用語 1 つ。本文に出たら意味のツールチップを付ける。

<!-- table: data -->

| キー | 型 | 必須 | 既定 | 説明 |
| --- | --- | --- | --- | --- |
| `id` | 文字列 | 必須 | なし | 用語の ID。`terms` の中で一意。セクションごとに最初の 1 回だけ下線を付ける単位。空にできない |
| `term` | 文字列 | 必須 | なし | 用語の単語。空にできない |
| `aliases` | 文字列の並び | 任意 | `[]` | 別名。本文に出たら、用語と同じツールチップを出す。要素は空にできない |
| `meaning` | 文字列 | 必須 | なし | 意味。ツールチップの「用語」に出す。空にできない |
| `avoid` | 文字列の並び | 任意 | `[]` | やめた言い方。索引の文書の本文に出たら、点検が `avoided_term` で通知する。描いた文書では、本文に出たやめた言い方に波線のマーカーを付け、見出し「代わりの用語」に用語の単語と意味を出したツールチップを出す。要素は空にできない |

<!-- /table -->

タイトル・意味・概要は Markdown として解析せず、文字として出す。

## 点検が返却するずれ

[`checkIndex`](./API.md#索引を点検する) が返却するずれ 1 件の `kind`。
一覧の並びは、この表の順。

<!-- table: data -->

| `kind` | 意味 | `where` |
| --- | --- | --- |
| `schema` | 索引が Schema に合わない。必須のキーの欠け・型の違い・`docs[].id`・`docs[].path`・`terms[].id` の重なり・知らないキー（v0.9.0 までの最上位の `tags` を含む）・`2` でない `schema` を、合わないところごとに返却する。`schema` が `2` でないときは、`message` で `mdmark upgrade` を案内する | 合わないキーのパス（`docs[1].path`）。最上位は `schema` |
| `missing_doc` | 索引にあって、文書が見つからない | 索引の `docs[].path` |
| `orphan_doc` | 文書があって、索引に無い | 空文字 |
| `broken_ref` | `related` の `id`（オブジェクトの要素は `to`）が索引に無い | 索引の `docs[].related[]`（オブジェクトの要素は `docs[].related[].to`） |
| `untyped_related` | `related` の要素が `type` と `when` を持たない文字列。`to`・`type`・`when` を持つオブジェクトへの書き換えを求める。文字列の要素ごとに 1 件 | 索引の `docs[].related[]` |
| `one_sided_change_together` | `change_together` の相手が索引にあるのに、相手の `related` に自分を `to` とする `change_together` が無い。片側だけに記載した要素ごとに 1 件 | 索引の `docs[].related[]` |
| `related_link_overlap` | `change_together` でない `related` の相手を、自分の本文でもリンクしている。文字列の要素を含む。要素ごとに 1 件 | 索引の `docs[].related[]` |
| `missed_change_together` | `change_together` の組のうち、片方の文書だけが比べる基準から変わっている。組ごとに 1 件。基準を指定したときだけ返却する | 空文字 |
| `duplicate_term` | 用語の単語か別名が、NFKC・英字の小文字化・前後の空白の除去で正規化した後に重なっている。索引の `terms` どうし・索引の `terms` と用語集の表・用語集の表どうしで、重なり 1 組ごとに 1 件 | 組の後の側の場所（下記） |
| `avoided_term` | 索引の文書の本文に、用語のやめた言い方（索引の用語の `avoid` と、用語集の表の `avoid=` の列）が出ている。出た行とやめた言い方の組ごとに 1 件 | やめた言い方が出た文書の中の行（`8 行目`） |

<!-- /table -->

`mdmark check` は、`checkIndex` のずれに加えて、文書が指す画像・動画・音声・添付のファイルが文書のフォルダにもアセットのルートにも無い `missing_file` と、include のマーカーの取り込み先が無い `include_target_missing`・取り込みが循環する `include_circular` と、図の部品の定義のずれ（`diagram_invalid`・`diagram_node_overlap`・`diagram_node_overflow`・`diagram_wire_crosses_node`・`diagram_label_too_long`）を返却する（[CLI](./CLI.md#設定と索引を点検する)）。

`duplicate_term` の `file` と `where` は、重なった組のうち後の側を指す。
後の側は、索引、索引の `docs` の順の文書の順で、後に出た方。
索引の側は、`file` が `indexFile`、`where` が `terms[1].term` か `terms[1].aliases[0]` の書式になる。
用語集の表の側は、`file` が文書のパス、`where` が表のその行の文書の中の行番号（`12 行目`）になる。
`message` に、後の側に記載した表記と、もう片方の場所を記載する。

`avoided_term` の `file` は、やめた言い方が出た文書のパス。
`message` に、やめた言い方と、代わりに使用する用語の単語を記載する。
用語集の表のやめた言い方は、表を持たない文書も含めて、索引の全ての文書で探す。
同じやめた言い方が複数の用語にあるときは、索引の `terms`、索引の `docs` の順の文書の表の順で、先の用語の単語を記載する。
索引の `docs` にあって `documents` に指定された文書だけを探し、索引に無い文書は探さない。
探す範囲と単語の切れ目は文書の別名と同じで、コード・リンク・見出し・用語集の表の中は探さない。
やめた言い方と本文の文字は、正規化して比べる。
やめた言い方が用語の単語・別名の一部として出たところ（`ワーク` をやめた言い方にしたときの `ワークスペース`）は数えない。
同じ行に同じやめた言い方が 2 回出ても 1 件で、行が違えば別の件になる。

`related_link_overlap` は、本文を指定していない文書では確認しない。
リンクの比べ方は被参照と同じで、本文でリンクしている相手は、`related` から除外するか本文のリンクを削除して、どちらか一方にする。

`missed_change_together` の `file` は、変わっていない側の文書のパス。
`message` に、変わった側の文書のパスと、変わっていない側も修正するか確認することを記載する。
組は向きを問わず 1 回だけ確認し、相手が索引に無い組は確認しない。
比べる基準から変わった文書のパスを指定するのは、`checkIndex` の `changedPaths`、`mdmark check` の `--base`、MCP の `check` の `base`（[API](./API.md#索引を点検する)・[CLI](./CLI.md#設定と索引を点検する)・[MCP](./MCP.md#設定と索引を点検する)）。

`file` は、索引のずれが `indexFile`、文書のずれがその文書のパス。
`message` に、ずれの内容と修正する場所を日本語の 1 文で記載する。
