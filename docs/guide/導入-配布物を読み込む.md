# 配布物を読み込む

develop かバージョンのタグを指定した URL で JavaScript と CSS を読み込む

mdmark を使用するページを作るときに実行する。
サーバーの言語に関わらず、ページに記載した参照だけで使用できる。

## 前提

- バージョンを固定するときは、読み込むバージョンのタグが公開されている（[変更履歴](./変更履歴.mark.md) に載っているバージョン）

## 手順

### 読み込む参照を決める

| 参照 | 読み込む配布物 | 使用する場面 |
| --- | --- | --- |
| `develop` | develop の最新。develop へ commit が入ると、配布物が作り直されて入る | 既定。タグを待たずに develop の機能を使用する |
| `v{MAJOR}.{MINOR}.{PATCH}` のタグ | そのバージョンの配布物 | バージョンを固定する。[変更履歴](./変更履歴.mark.md) から選ぶ |
| commit の SHA | その commit の配布物 | 特定の develop の commit に固定する |

`latest`・バージョンの範囲は使用しない。
CDN にキャッシュされ、新しいバージョンへ切り替わるまで時間がかかる（[配信元の説明](https://github.com/jsdelivr/jsdelivr)）。
`develop` はブランチのため最大 12 時間、`latest` とバージョンの範囲は最大 7 日キャッシュされる。
タグと commit の SHA は中身が変わらない。

### CSS と JavaScript を読み込む

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{参照}/dist/index.css">
<script type="module">
  import { version } from "https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{参照}/dist/index.js";

  console.log(version());
</script>
```

`{参照}` を手順の最初に決めた参照に置き換える。
2 つの URL で同じ参照を使用する。
違う参照にすると、CSS と JavaScript のバージョンが食い違う。

## 反映

即時。
ページを再読み込みすると、記載した参照のバージョンが読み込まれる。
`develop` は、CDN のキャッシュが切れた後に develop の最新へ切り替わる。

## 確認

#### 公開関数がバージョンを返却する

ブラウザの開発者ツールのコンソールを開く。

コンソールに出た `console.log(version())` の出力が、記載したタグと同じ `v{MAJOR}.{MINOR}.{PATCH}` になる。
`develop` のときは、`v{MAJOR}.{MINOR}.{PATCH}+develop.{短縮 SHA}` の構造になり、短縮 SHA が配布物を作った develop の commit を指す。

#### CSS が読み込まれている

```js
getComputedStyle(document.documentElement).getPropertyValue("--mdmark-version")
```

`version()` と同じバージョンを引用符で囲んだ文字列が出る。

#### 読み込めなかったとき

タグかファイルが無いと、CDN は 404 を返却する。
ページの本文はそのまま表示され、`index.js` を読み込めなかったエラーがコンソールに出る。
タグの記載し間違いと、そのタグが公開されているかを確認する。

## 元に戻す

`<link>` と `<script>` の 2 行をページから削除する。
CDN にもページにも残るものはない。
