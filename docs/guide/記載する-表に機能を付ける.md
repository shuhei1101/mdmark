# 表に機能を付ける

表をマーカーで囲み、種類と機能を選ぶ手順

読者が表を並べ替えたり絞り込んだりできるようにするとき、表を折り畳みに入れるときに実行する。

## 前提

- [文書を描く](./導入-文書を描く.md)

## 手順

### 表をマーカーで囲む

#### 種類を選ぶ

```markdown
<!-- table: {"kind": "data"} -->

| 名前 | 値 |
| --- | --- |
| りんご | 10 |
| みかん | 2 |

<!-- /table -->
```

表の前に `<!-- table: {"kind": "種類"} -->`、後ろに `<!-- /table -->` を記載する。
種類は `data`（並べ替え・ピン止め・絞り込み・列の幅の変更）か `plain`（機能を付けない）。
囲まない表は既定の種類で、ピン止めと列の幅の変更が付く。
閉じのマーカーの記載を忘れると、マーカーから文書の終わりまでが範囲になり、記載の警告が出る。

#### 機能を追加・削除する

```markdown
<!-- table: {"kind": "plain", "features": {"sort": {}}} -->
```

`features` に `"機能": {}` を記載すると種類の機能に追加し、`"機能": {"enabled": false}` で削除する。
機能は `sort`（並べ替え）・`pin`（ピン止め）・`filter`（絞り込み）・`resize`（列の幅の変更）・`count`・`columns`・`reorder`・`total`・`copy`・`rowlink`。
`count` 以降の 6 つはどの種類にも入っておらず、`features` か列の設定に記載した表にだけ付く（付け方は次のセクション）。
知らない機能・キーは、警告を出さずに無視する。

#### 絞り込む列を決める

```markdown
<!-- table: {"kind": "data", "columns": {"名前": {"filter": {}}, "更新日": {"filter": {"type": "date"}}}} -->
```

`columns` の列名に `filter` を記載すると、その列に絞り込みを付ける。`filter` の機能は記載しなくても付く。
列名は表の見出しの文字で記載する。
`type` は `select`（値を選ぶ）・`text`（文字を含む行）・`date`（期間）。省くと、長文の列（改行で分けた 1 行が 20 文字以上のセルを持つ列）は `text`、ほかの列は `select` になる。
絞り込みのボタンは、ここで決めた列の見出しにだけ付く。
表に無い列名と知らない種類は、その列に絞り込みを付けずに描き、記載の警告が出る。

#### 並べ替える列を決める

```markdown
<!-- table: {"kind": "data", "columns": {"説明": {"sort": true}, "名前": {"sort": false}}} -->
```

並べ替えを付けた表でも、長文の列（改行で分けた 1 行が 20 文字以上のセルを持つ列）の見出しには並べ替えのボタンが付かない。
表の種類と、`features` に `sort` を記載したかによらない。
長文の列も並べ替えたいときは、その列に `"sort": true` を記載する。ほかの列から並べ替えを外すときは `"sort": false` を記載する。
`"sort": true` を記載すると、`sort` の機能は記載しなくても付く。`"sort": {"enabled": false}` の表では、`"sort": true` を記載しても並べ替えは付かない。

### 列の留め方・幅・真偽値の出し方を決める

#### ピン止めする列を決める

```markdown
<!-- table: {"kind": "data", "columns": {"物理名": {"pinned": true}}} -->
```

ピン止めを持つ表は、幅からはみ出すとき、描いた直後から先頭の列（`header.columns` の表は行見出しの列）が表の左端に留まる。
列名に `"pinned": true` を記載すると、その列が留まる。`"pinned": false` は、その既定で留まる列を留めない。表に無い列名は当てずに記載の警告が出て、ほかの列名は当てる。
設定の `table.pin` を `through` にすると、`true` の列のうち最も右の列までが留まる（[設定](./設定.md#表のピン止めの動き)）。
留めない表は `"features": {"pin": {"enabled": false}}` を記載する。ピン止めを持たない表の `pinned` は当てず、`mdmark check` が `mark_option_unapplied` で返す。
表がはみ出さない幅では留めない。

#### 列を広く取る

```markdown
<!-- table: {"kind": "data", "columns": {"説明": {"width": {"mode": "nowrap"}}}} -->
```

`width.mode` が `"nowrap"` の列は折り返さず、値の長さの幅を取る。
はみ出した分は表の中で横にスクロールする。

#### 列の幅の範囲を決める

```markdown
<!-- table: {"kind": "data", "columns": {"説明": {"width": {"min": 20, "max": 30}}}} -->
```

`width.min`・`width.max` は列の幅の下限と上限で、単位は em。
記載した列は、文字数によらず折り返し、記載した範囲の幅で描く。
片方だけも記載でき、`min` が `max` より大きいときは `max` を優先する。

#### 読者が列の幅を変える

`resize` を持つ表（既定の種類と `data`）は、読者が列の幅を変えられる。
列の見出しの右端にポインターを乗せると幅を変えるつまみの線が出て、ドラッグするとつまみの左の列の幅だけが変わる。
つまみにフォーカスして ←・→ キーでも変えられる。
つまみをダブルクリック（スマホではダブルタップ）するか Enter を押すと、自動で決めた幅に戻る。`"nowrap"` の列は値の長さの幅に戻る。

列は 6em より狭くならず、表の見えている幅からほかに留めた列の幅を引いた幅より広くならない。長文の列も 6em まで狭められる。
幅を変えた `"nowrap"` の列は折り返す。
変えた幅は保存せず、再描画すると Markdown に記載したとおりに戻る。
読者に幅を変えさせない表は `"features": {"resize": {"enabled": false}}` を記載する。

#### 真偽値を ✓ で出す

```markdown
<!-- table: {"kind": "data", "columns": {"必須": {"format": {"type": "check"}}, "既定": {"format": {"type": "check"}}}} -->
```

`format.type` が `"check"` の列は、`true` のセルを ✓、`false` のセルを空欄にして中央に配置する。
ほかの文字のセルはそのまま出る。
並べ替え・絞り込み・コピー・集計は、`true`・`false` の値で行う。

`columns` に表に無い列名を記載すると、その列の設定を当てずに記載の警告が出る。

### 表に件数・列の切り替え・集計・コピー・行へのリンクを付ける

#### 件数を出す

```markdown
<!-- table: {"kind": "data", "features": {"count": {}}, "columns": {"名前": {"filter": {"type": "text"}}}} -->
```

`"features": {"count": {}}` で、表の上に `2 / 3 件` のように、表示している行の数と全ての行の数を出す。
絞り込みで行が減ると、表示している行の数が変わる。

#### テーブル設定で列を切り替える・並べ替える

```markdown
<!-- table: {"kind": "data", "features": {"reorder": {}}, "columns": {"説明": {"hidden": true}}} -->
```

`features` の `columns` か `reorder` で、表の上にテーブル設定のボタンを配置する。ボタンはアイコンだけで、ポインターを乗せると `テーブル設定` と出る。列を隠している間は、アイコンに隠した列の数のバッジが付く。
ボタンを押すと、列名を並べたテーブル設定のパネルが開く。

`columns` の機能を持つ表は、列名の横の目のアイコンで、列ごとに表示・非表示を切り替えられる。
列名に `"hidden": true` を記載すると、その列を最初から隠す。`columns` の機能は記載しなくても付く。
Markdown に記載した先頭の列は、並べ替えた後も隠せない。`hidden` を記載すると記載の警告が出て、その列は隠れない。

`reorder` の機能を持つ表は、列名の横のつまみをドラッグするか、つまみにフォーカスして ↑・↓ キーで、列を並べ替えられる。
結合した見出しの下の列は、その見出しの範囲の中だけで動く。留めた列は留めたまま動く。設定の `table.pin` が `through` の表は、ピン止めの列とそれ以外の列の境はまたげない。
並べ替えた順は保存せず、再描画すると Markdown に記載した順に戻る。

切り替えた列の表示は、再描画すると `hidden` の状態に戻る。
利用側が残すときは、`mount` の `onColumnsChange` で切り替えのたびに隠している列を受け取り、次に描く Markdown の `hidden` に記載する（[API](./API.md#文書を描く)）。

```js
mount(el, {
  markdown,
  onColumnsChange: ({ tableIndex, hidden }) => saveHidden(tableIndex, hidden),
});
```

`tableIndex` は本文の中の `columns` の機能を持つ表の出現順（0 から）、`hidden` は隠している列の見出しの文字の配列。

#### 集計の行を付ける

```markdown
<!-- table: {"kind": "data", "columns": {"数量": {"total": [{"calc": "sum"}]}, "単価": {"total": [{"calc": "avg"}]}, "名前": {"total": [{"calc": "count"}]}}} -->
```

列名に `"total": [{"calc": "計算"}]` を記載すると、表の末尾に集計の行を配置する。`total` の機能は記載しなくても付く。
計算は `sum`（合計）・`avg`（平均）・`count`（空でないセルの数）で、計算ごとに 1 行ずつ、`合計`・`平均`・`件数` の順に並ぶ。
各行の先頭のセルに計算の名前が出て、その計算を記載した列のセルに値が出る。
集計するのは表示している行で、絞り込みに合わせてもう一度計算する。
`sum` と `avg` は、空のセルを除いて計算する。
`sum` と `avg` の列に、空でなく数として読み込めないセル（`-` や `約 3` など）が 1 つでもあると、その列のその計算のセルを空にして、表の上に記載の警告が出る。
警告に出た値を、数に修正するか空のセルにする。
`total` を記載した列の無い表は、集計の行を出さない。
知らない計算と表に無い列名は、その指定だけを当てずに描き、記載の警告が出る。

表の上の `集計` のボタンを押すと、`表示する集計` のメニューが開き、計算ごとのチェックボックスで集計の行を出し入れできる。
選んだ状態は覚えず、再描画すると全ての計算が出る。

#### 表をコピーする

```markdown
<!-- table: {"kind": "data", "features": {"copy": {}}} -->
```

`"features": {"copy": {}}` で、表の上に表をコピーのボタンを配置する。ボタンはアイコンだけで、ポインターを乗せると `表をコピー` と出る。
ボタンを押すと `コピーの形式` のメニューが開き、`Markdown の表` か `TSV` を選んでコピーする。
`Markdown の表` は文書に貼るとそのまま表になり、`TSV` は表計算ソフトに貼るとセルに分かれる。
見出しの行と、絞り込みの後に見えている行の、テーブル設定で見えている列を、選んだ形式でクリップボードへコピーする。
隠した列と絞り込みで隠れた行は含まれない。
コピーできたらボタンのアイコンがチェックに変わり、ツールチップが `コピーしました` になる。
クリップボードへ書き込めなかったときは、ボタンのツールチップが `コピーできませんでした` に変わり、コピーする中身を選択したパネルが開く。
パネルの中身を手動でコピーできる。パネルは閉じるボタンか Esc で閉じる。

#### 行へのリンクを付ける

```markdown
<!-- table: {"kind": "data", "features": {"rowlink": {}}} -->
```

`"features": {"rowlink": {}}` で、各行の先頭のセルに、その行を指す `#ID` のリンクを配置する。
`#ID` は先頭の列の文字から作り、見出しのアンカーと同じ規則で、同じ文書の中で重なれば `-1`・`-2` が付く。
URL の `#ID` が行を指すと、その行へ移って強調する。
閉じた表と閉じたセクションの中の行は開いてから、絞り込みで隠れた行は絞り込みを解除してから移る。
行へのリンクを押すと、行へ移る動きに加えて、その行を指す URL をクリップボードへコピーし、リンクの横に `リンクをコピーしました` と短く出す。
コピーできなかったときは `リンクをコピーできませんでした` と出る。
アドレスバーの URL も、その行を指す URL になる。

### 列と行に色を付ける

色の名前は `blue`・`red`・`green`・`yellow`・`orange`・`purple`・`gray`。
色の選び方は [色で強調する](./記載する-色で強調する.md)。
どの種類の表にも記載できる。

#### 列を強調する

```markdown
<!-- table: {"kind": "data", "columns": {"金額": {"highlight": {}}}} -->
```

列名に `"highlight": {}` を記載すると、その列を面の薄い色で強調し、見出しのセルの下端に線を描く。
色は `"highlight": {"color": "green"}` のように記載し、省くと `blue`。

#### 列の値で行に色を付ける

```markdown
<!-- table: {"kind": "data", "rows": {"colors": [{"column": "状態", "value": "完了", "color": "green"}, {"column": "状態", "value": "保留", "color": "yellow"}]}} -->
```

`rows.colors` の要素に `column`・`value`・`color` を記載すると、その列のセルの文字が値と一致する行に色を付ける。
要素は値ごとに並べ、別の列の値でも付けるときは、その列の要素を足す。
値で付けた色は行に付くので、並べ替え・絞り込みの後も行と一緒に動く。

#### 位置で行に色を付ける

```markdown
<!-- table: {"kind": "data", "rows": {"colors": [{"at": 1, "color": "blue"}, {"at": {"from": 3, "to": 4}, "color": "gray"}]}} -->
```

`rows.colors` の要素に `at` と `color` を記載すると、見出し行を除いて 1 から数えた位置の行に色を付ける。
`{"from": 3, "to": 4}` のように範囲も記載できる。
複数の要素が該当する行は、後ろの要素の色にする。
色を付けた行は、面の薄い色に加えて上下に線を描く。

表に無い列名・表に無い行の位置・色の名前に無い名前を記載すると、その指定を当てずに記載の警告が出る。

### 見出しを多段にしてセルを結合する

```markdown
<!-- table: {"kind": "data", "header": {"rows": 2, "columns": 1}} -->

| 地域 | 上期 | << |
| --- | --- | --- |
| ^^ | 売上 | 件数 |
| 東日本 | 120 | 8 |
| ^^ | 90 | 5 |
| 西日本 | 80 | 4 |

<!-- /table -->
```

`header.rows` で表の先頭の何行を見出し行にし、`header.columns` で本文の各行の先頭の何列を行見出しにする。
セルにちょうど `^^` を記載すると上のセルと、`<<` を記載すると左のセルと結合する。
`^^`・`<<` はマーカーで囲んだ表にだけ該当する。

本文の行の結合したセルは、結合の始まりのセルと同じ値を持つ。
並べ替え・絞り込みの後は、表示している行で隣り合う同じ値のセルだけをもう一度結合する。
コピー・集計も、結合したセルを値を持つセルとして扱う。
並べ替え・ピン止め・絞り込みのボタンは、列ごとに最も下の見出しのセルに出る。
行見出しを持つ表がはみ出すときは、最初から行見出しの列をピン止めする。

表に収まらない `header.rows`・`header.columns`、上のセルが無い `^^`、左のセルが無い `<<`、見出し行と本文の行をまたぐ `^^` は当てずに、記載の警告が出る。

### キーの列を階層で出す

#### `tree.key` でキーの列を決める

```markdown
<!-- table: {"kind": "data", "tree": {"key": {"column": "キー"}, "type": {"column": "型"}, "required": {"column": "必須"}, "default": {"column": "既定"}}} -->

| キー | 型 | 必須 | 既定 | 説明 |
| --- | --- | --- | --- | --- |
| features.table | bool | ✓ | true | 表の機能 |
| features.html | bool | | | 埋め込んだ HTML の機能 |
| aliases[].id | string | | | 別名の ID |
| aliases[].metadata.alias_type.type | ref \| custom | | | 別名の種類 |

<!-- /table -->
```

`tree.key.column` に列名を記載すると、その列の文字を `.` と `[]` で区切ったキーのパスとして読み込み、行を末尾の名前で階層に並べる。
キーの列には全体のパスを記載する。表に無い親のパス（例の `features`・`aliases[]`）は、mdmark が薄い斜体の行として補う。
`tree` の表には並べ替えが付かない。行は記載した順に並ぶ。

`tree.type.column` の列は型をバッジで出し、`ref \| custom` のように `\|` で区切ったセルは値ごとのチップで出す。
`tree.required.column` の列は出さず、`✓` か `true` を記載した行のキーの名前の後ろに `*` を付ける。
`tree.default.column` の列は、既定の値の書式で出す。

読者は、子を持つ行のボタンで子孫を畳み（Shift を押しながら押すと入れ子もまとめて）、キーの名前の後ろのボタンで全体のパスをコピーできる。
行を押すと、同じ親を持つ行の範囲の縦線が濃くなる。
キーの列を `{"filter": {"type": "text"}}` で絞り込むと、該当した行とその祖先の行が残る。

#### `tree.example` で YAML の見本と結ぶ

````markdown
<!-- table: {"kind": "data", "tree": {"key": {"column": "キー"}, "example": {"heading": "設定の見本"}}} -->

| キー | 説明 |
| --- | --- |
| features.table | 表の機能 |
| aliases[].id | 別名の ID |

<!-- /table -->

### 設定の見本

<!-- tabs -->

#### 最小

```yaml
features:
  table: true
```

#### エイリアス

```yaml
aliases:
  - id: terms
```

<!-- /tabs -->
````

`tree.example.heading` に見出しを記載すると、その見出しの直下のタブの範囲を表の下へ移し、YAML の見本にする。
見出しは元の場所に残る。見本が 1 つでも、タブの範囲で囲む。
表の行を選ぶと、開いているタブの見本の同じキーの行に色が付き、見本の行を押すと表の同じキーの行を選ぶ。
表の上の `見本を隠す` のボタンで見本を隠せる。

表に無い列名の `tree`、文書に無い見出しか直下にタブの無い見出しの `tree.example.heading` は当てずに、記載の警告が出る。

### 見出し行と列の幅

記載方法は要らず、どの表にも該当する。

#### 見出し行を画面の上端に留める

表に高さの上限は無く、縦はページのスクロールだけで読み込める。
表が画面に残っている間、見出し行はページを縦にスクロールしても画面の上端に留まる。
集計の行を持つ表では、集計の行が画面の下端に留まる。
ページの上端に固定したヘッダーを配置しているときは、見出し行を留める位置を CSS 変数で下げる（[テーマを上書きする](./カスタマイズ-テーマを上書きする.md)）。

#### 列の幅を中身から決める

列の幅は、列ごとのセルの中身から決まる。
改行で分けた 1 行が 20 文字以上のセルを持つ列（長文の列）だけを折り返し、ほかの列は折り返さずに最も長い行の幅にする。
数値・日付・✓・バッジ・行内のコードだけの列は、長くても長文の列にしない。

- 長文の列は、本文の幅いっぱいまで広がる。折り返さずに収まる長文の列は、最も長い行の幅で止まる
- 長文の列の最小の幅は 45em で、最も長い行の方が短ければその幅になる。既定は設定の `table.long_column_min` で変えられる（[設定](./設定.md#長文の列の最小の幅)）
- 全ての列が折り返さずに収まる表は、本文の幅まで広げずに列の幅の合計で描く
- 全ての列の最小の幅の合計が本文の幅に収まらないときは、最小の幅で描き、表の中で横にスクロールする。ピン止めした列も留まる。最終列を畳むことはない

列の幅は、表を描いたときと表の見える幅が変わったときだけ決め直す。並べ替え・絞り込み・列の表示の切り替えでは変わらない。
読者がつまみで変えた幅は、自動で決めた幅より優先する。
印刷では、自動で決めた幅を当てずに紙の幅に収める。

### 表を折り畳みに入れる

#### `collapse` を記載する

```markdown
<!-- table: {"kind": "data", "collapse": {"open": false}} -->
```

表を折り畳みに入れる。
`open` を省くか `false` にすると閉じた状態で始め、`true` にすると開いた状態で始める。
折り畳みの見出しは `表（{本文の行の数} 行）`。

#### `collapse.title` で見出しを付ける

```markdown
<!-- table: {"kind": "data", "collapse": {"open": true, "title": "リリースの一覧"}} -->
```

`title` の値が折り畳みの見出しになる。見出しに空白を記載できる。

### CSV を表にする

#### 言語 `csv` のコードブロックに記載する

````markdown
<!-- table: {"kind": "data"} -->

```csv
名前,拠点,金額
北山,"東京, 本社",1200
南田,大阪,800
```

<!-- /table -->
````

1 行目が見出しの行になる。
表のマーカーで囲むと、その種類と機能の表になり、囲まないときは既定の種類の表になる。
表の右端のボタンで、記載したとおりの CSV と表を切り替えられる。
表にせずコードとして見せるときは、言語を `text` にする。
記載方法の詳細は [CSV の表](./記法.md#csv-の表)。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書のマーカーでもう一度決める。

## 確認

#### 並べ替えが働く

並べ替えを付けた表の、数値の列の見出しを押す。
押すたびに降順・昇順・元の並びを繰り返す。

```js
document.querySelector(".mdmark th[aria-sort]").getAttribute("aria-sort")
```

1 回押した後は `descending`、2 回押した後は `ascending` が出る。
3 回押して元の並びに戻ると、`th` から `aria-sort` が削除される。
長文の列の見出しは並べ替えのボタンを持たず、表の囲みの `data-no-sort` にその列の位置が出る。

#### 絞り込みが働く

`filter` を記載した列の見出しの絞り込みのボタンを押す。
ドロワーが開き、候補の検索欄にフォーカスがある。
値を選ぶと、その値の行だけが表に残る。
「絞り込みを解除」を押すと、全ての行が戻る。
ドロワーの外を押すか Esc を押すと、ドロワーが閉じる。

#### ピン止めが働く

表が幅からはみ出すときだけ、各列の見出しにピン止めのボタンが出る。
描いた直後は、`pinned` が `true` の列（記載しなければ先頭の列。`header.columns` の表は行見出しの列）が留まっている。
別の列のボタンを押すと、その列も留まる。もう一度押すと、その列だけが外れる。
留めた列は、その列より左を表示している間は表の右端に、その列を過ぎて右へスクロールすると左端に留まる。
設定の `table.pin` を `through` にすると、押した列までが表の左端に留まる。
留める列の幅の合計が表の幅を超えるときは、左から順に収まる列だけが留まる。
収まらない列のボタン（`through` は押した列のボタン）は押したまま破線のピンになり、ポインターを乗せると「表の幅に収まらないため留まっていません」と出る。
表の幅が広がる・ほかの列を外す・列を狭めるなどで収まると、その列も留まる。

```js
document.querySelector('.mdmark .mdmark-pin[aria-pressed="true"]')
```

留めた列のボタンが出る。

#### 広く取る列と真偽値の列が出ている

`width.mode` が `"nowrap"` の列のセルが折り返さずに 1 行で出ている。
`format.type` が `"check"` の列は、`true` のセルに ✓ が出て、`false` のセルが空欄になっている。

#### 件数が働く

`count` の機能を付けた表の上に、`3 / 3 件` のように件数が出ている。
絞り込みで行を減らすと、表示している行の数が変わる。

#### テーブル設定が働く

`"hidden": true` を付けた列が隠れている。
表の上のテーブル設定のボタンに隠した列の数のバッジが付き、押すとパネルが開き、列名の横の目のアイコンを押すと列が出る。
先頭の列の目のアイコンは押せず、パネルに `先頭の列は隠せません` が出ている。
`reorder` の機能を付けた表で、パネルのつまみをドラッグすると、見出しとセルの順が変わる。

#### 集計の行が働く

`total` を付けた表の末尾に、計算ごとの集計の行が `合計`・`平均`・`件数` の順に出ている。
絞り込みで行を減らすと、集計がもう一度計算される。
並べ替えても、集計の行は表の末尾のままになる。
`集計` のボタンを押すと `表示する集計` のメニューが開き、チェックを解除した計算の行が非表示になる。
数として読み込めないセルを持つ `sum`・`avg` の列は、集計のセルが空になり、表の上に記載の警告が出ている。

#### 表のコピーが働く

表をコピーのボタンを押して `Markdown の表` か `TSV` を選ぶと、ボタンのアイコンがチェックに変わる。
貼り付けると、見出しの行と見えている行の、見えている列が、選んだ形式で入る。

#### 行へのリンクが働く

各行の先頭のセルのリンクの `href` が、`#` に続けて行の ID になっている。

```js
document.querySelector(".mdmark .mdmark-row-anchor").getAttribute("href")
```

ページの URL の末尾にその `#ID` を付けて開くと、その行へ移って強調される。
リンクを押すと、リンクの横に `リンクをコピーしました` と出て、貼り付けるとその行を指す URL が入る。

#### 多段の見出しとセルの結合が働く

`header.rows` が `2` の表の見出し行が 2 行で、`上期` のセルが 2 列を覆っている。
`^^` を記載したセルは上のセルと 1 つになり、`<<` を記載したセルは左のセルと 1 つになっている。
`売上` の見出しを押して並べ替えると、隣り合う同じ地域の行だけが 1 つのセルにまとまる。

```js
[...document.querySelectorAll(".mdmark thead tr")].length
```

`2` が出る。

#### キーの列が階層で出ている

`tree.key` が `キー` の列の表で、キーの列が末尾の名前で字下げして並び、`features` の行が補われている。

```js
[...document.querySelectorAll(".mdmark tr.mdmark-tree-row")].map((tr) => tr.dataset.path)
```

`features`・`features.table`・`features.html`・`aliases[]`・`aliases[].id`・`aliases[].metadata`・`aliases[].metadata.alias_type`・`aliases[].metadata.alias_type.type` の 8 件が、この順に出る。
`aliases[]` のボタンを押すと子孫の行が隠れ、キーの名前の後ろのボタンを押すと `コピーしました` が出る。
`tree.example` の表の下に見本が出ていて、表の `aliases[].id` の行を押すと、見本の `- id: terms` の行に色が付く。

#### 見出し行が留まり、列の幅が中身から決まる

縦に長い表を持つ文書で、ページを縦にスクロールして表の途中を出すと、見出し行が画面の上端に見えている。
長文の列を持つ表は、長文の列だけが折り返し、ほかの列が 1 行で出ている。
描く先の要素の幅を 390px にしても最終列が出ていて、表の中で横にスクロールできる。

```js
document.querySelector(".mdmark .mdmark-table").dataset.long
```

長文の列の位置が出る。

#### 折り畳みの見出しが出ている

`collapse` の `open` を省いた表は、見出し `表（3 行）` だけが出ていて、表の行が出ていない。
見出しを押すと、表が開く。
`collapse` の `open` を `true`、`title` を `リリースの一覧` にした表は、見出し `リリースの一覧` の下に表が出ている。

#### 列と行に色が付いている

`highlight` の列のセルが面の薄い色で、見出しのセルの下端に線が参照されている。
`rows.colors` の行が面の薄い色で、上下に線が参照されている。
並べ替えた後も、値で付けた色が同じ行に付いている。

```js
[...document.querySelectorAll(".mdmark tr[data-color]")].map((tr) => tr.dataset.color)
```

#### マーカーが本文に出ていない

表の前後に、マーカーの文字が出ていない。

## 元に戻す

マーカーを削除すると、表は囲まない表の既定の種類に戻る。
表の機能を止めるときは、[機能をオン・オフする](./カスタマイズ-機能をオン・オフする.md) で `table` をオフにする。
