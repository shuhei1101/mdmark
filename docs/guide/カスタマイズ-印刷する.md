# 印刷する

印刷・PDF にしたときの文書の見え方

読者が mdmark で描いた文書を印刷・PDF にしたときの見え方。
何も設定しなくても、次のとおりになる。

## 見え方

<!-- table: {"kind": "data"} -->

| 項目 | 印刷での見え方 |
| --- | --- |
| 折り畳み | 印刷の前に、閉じた折り畳みを全て開く。印刷の後に、印刷の前の開閉へ戻す |
| 閉じたセクション・行の詳細・閉じた表と注意書き | 印刷の前に開く。注意書きの中に入れ子にした注意書きも開く。印刷の後に、印刷の前の開閉へ戻す |
| タブ | 全ての中身を、タブ名をタイトルにして縦に並べる。入れ子のタブも同じく並べる。閉じたタブ群は折り畳みを開いてから並べる。印刷の後に、印刷の前に選んでいたタブだけを出し、閉じていたタブ群をもう一度閉じる |
| ステップ | 閉じたステップの折り畳みを開く。印刷の後に、もう一度閉じる |
| ファイルツリー | 閉じたフォルダを全て開き、ツリーの上の帯とコピーのボタンを出さない。印刷の後に、閉じていたフォルダをもう一度閉じる |
| 表の操作 | 絞り込み・ピン止め・開閉のボタンとタブの並びを隠す。見出し行・集計の行・列を留めず、セルの余白を詰める |
| 表の件数・集計・隠した列 | 表の上のテーブル設定・コピー・「集計」のボタン、集計とコピーの形式のメニュー、コピーできないときのパネル、行へのリンクのマーカーは出さない。件数と、出している計算の集計の行は出し、隠した列は隠したまま出す |
| 階層の表と YAML の見本 | 印刷の前に、畳んだ階層の行と隠した見本を開き、見本の全てのタブの中身を並べる。開閉・パスのコピー・見本の表示を切り替えるボタンは出さない。印刷の後に、畳んでいた行をもう一度畳み、隠していた見本をもう一度隠す |
| 配色 | ダークの配色にしていても、明るい配色で出す |
| 地と余白 | 地の色と内側の余白を削除し、紙の幅いっぱいに出す |
| 右側の目次 | 右側の目次、目次を出すボタン、すべて展開とすべて折りたたむのボタンを出さず、本文を紙の幅いっぱいに出す |
| 先頭へ戻るボタン | 出さない |
| リンク | `http` で始まるリンクの後ろに、URL を併記する |
| コードブロックのタイトル・言語のラベル・行番号・行の強調 | タイトル・言語のラベル・行番号・強調した行の色と左端の線をそのまま出す。行番号は折り返した長い行の最初の 1 行にだけ出す。コピーボタンは出さない |
| コードの行のマーカー | 追加した行・削除した行・注目・エラー・警告の行の色と行頭の `+`・`-`・`×`・`!` をそのまま出す。マーカーと、マーカーだけを持つ行コメントの頭は、画面と同じく出さない |
| 畳んだコードの行 | 印刷の前に開き、開閉のボタンと `⋯` を出さない。インデントの縦線は出す。印刷の後に、畳んでいた行をもう一度畳む |
| コードブロックの色分け | 色分けの色を出す。ダークの配色にしていても、明るい配色の色で出し、色を省くブラウザの設定でも紙に出す |
| 表・コードブロック・図 | 改ページで切らない。読み込み中のブロックと通知ブロックも同じ |
| 横スクロール | 表とコードブロックの横スクロールと続きの影をやめ、紙の幅に収める。長い行は折り返す |
| 見出し | 見出し 1〜3 の直後で改ページしない |
| 脚注 | 本文の番号は上付きのまま出し、ツールチップは出さない。末尾の閉じた脚注の一覧を印刷の前に開き、戻るリンクを出さない。印刷の後にもう一度閉じる |
| 用語の下線とツールチップ | 下線を削除し、単語を本文の文字として出す。ツールチップは出さない |
| 被参照の一覧 | 一覧のリンクの後ろに、描いた文書からの相対パスを併記する。本文の相対リンクには併記しない |
| 色の名前の色 | 表の列と行・バッジ・本文の文字の色と、列と行の線・文字の太字をそのまま出す。ダークの配色にしていても、選んだテーマの明るい配色の色で出す |
| 配色ごとの画像 | `#only-light` の画像を出し、`#only-dark` の画像を出さない |
| 画像の拡大と GIF | 画像の拡大のアイコンと、GIF の止める・再生するボタンを出さない |
| 動画と音声 | 動画と音声の再生バーを出さず、動画の `poster` の画像とキャプションを出す |
| リンクと添付のカード | カードの中に、リンク先の URL を文字で出す |
| details の範囲 | 閉じた範囲を印刷の前に開く。印刷の後にもう一度閉じる |
| 改ページ | `<!-- pagebreak -->` の場所で改ページする。画面では何も出さない |
| wide の範囲 | 切り替えのボタンを出さず、紙の幅に収める |
| CSV の表 | 表を出し、元の CSV のボタンを出さない |
| 狭い紙幅の表 | 紙の幅が 40rem 以下のとき、表を行ごとの「列名: 値」の並びに追加する |

## 折り畳みを開かない

折り畳み（閉じたセクション・行の詳細を含む）を開く動きと、タブの全ての中身を並べる動きは、印刷の機能が担う。
既定でオンで、設定の `features.print` か文書のマーカーでオフにできる（[機能をオン・オフする](./カスタマイズ-機能をオン・オフする.md)）。
オフにしても止まるのはその動きだけで、ほかの見え方は変わらない。

`render` が返却する HTML 文字列を利用側のページに配置した場合、その動きは付かない。
その動きは `mount` が付ける。

## 確認

ブラウザの印刷プレビューを開く。
折り畳みが開き、タブの全ての中身が並び、リンクの後ろに URL が出ている。
ファイルツリーの閉じていたフォルダも開き、コピーのボタンは出ていない。
OS の設定がダークでも、配色は明るい。
右側の目次と、そのボタンが無い。
用語の下線とツールチップが無く、被参照の一覧のリンクの後ろに相対パスが出ている。
タイトル・行番号・強調・追加した行・削除した行を付けたコードブロックは、タイトル・行番号・行の色と `+`・`-` が紙に出ている。
コードブロックの言語のラベルが紙に出ていて、コピーボタンは出ていない。
表の見出し行は表の先頭に 1 組だけ出ている。
階層の表の畳んでいた行と、隠していた YAML の見本が紙に出ている。
言語を記載したコードブロックは、行の中のキーワード・文字列などが色分けの色で紙に出ている。
色を付けた表の列と行・バッジ・本文の文字は、明るい配色の色で紙に出ている。
動画の場所には `poster` の画像とキャプションが出ていて、カードにはリンク先の URL が出ている。
