# テーマを上書きする

CSS 変数と層の外の CSS で、描いた文書の外観を変える

mdmark が描いた文書の色・書体・余白などを、利用側のページで変えるときに実行する。

## 前提

- [文書を描く](./導入-文書を描く.md)

## 手順

### テーマを選ぶ

#### 設定で選ぶ

```yaml
colorTheme: theme-slate
```

`mdmark.config.yaml` の `colorTheme` に、`dev-swiss`（既定）・`theme-paper`・`theme-slate`・`theme-contrast` のどれかを記載する。
利用側のサーバーがこの設定を読み込み、`mount` の `opts.config` に指定する。
選んだテーマが替えるのは配色の変数だけで、書体・余白・角丸と配置の変数は全テーマで共通。
明暗は OS の設定とこのページの class が、選んだテーマの中で選ぶ。
テーマごとの値は [選べるテーマ](./API.md#選べるテーマ)。

#### 文書ごとに選ぶ

```markdown
<!-- page: {"theme": "theme-paper", "scheme": "dark"} -->
```

文書の先頭の [ページの設定](./記法.md#ページの設定) に `theme` と `scheme` を記載すると、その文書だけ設定より優先してそのテーマと明暗で描く。
設定ファイルの `colorScheme` で、全ての文書の明暗の既定を `light`・`dark`・`auto` から選べる（[配色の明暗](./設定.md#配色の明暗)）。

#### 選んだテーマの上から上書きする

選んだテーマの値は `:root` に該当する。
`.mdmark` や `:root` に層の外で記載した変数は、選んだテーマの値に勝つ。
次の「変数の値を変える」の記載方法が、テーマを選んでもそのまま有効になる。

### 変数の値を変える

#### 変数を記載する

```css
.mdmark {
  --mdmark-color-link: #c00;
  --mdmark-radius: 0;
}
```

記載する先は、描く先の要素に付く class `mdmark`。
ページ全体に適用するときは `:root` に記載してもよい。
変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数)。
変数名を記載し間違えると値は該当せず、既定の外観のままになる。

#### 地を透明にして周りの面になじませる

```css
.mdmark {
  --mdmark-color-bg: transparent;
  --mdmark-color-bg-opaque: #f0f0f0;
}
```

`--mdmark-color-bg` を透明にするときは、`--mdmark-color-bg-opaque` に周りの面の色を記載する。
ツールチップ・全画面の図・表の横スクロールの影を隠す覆いなどは `--mdmark-color-bg-opaque` で塗るため、記載しないと透けて後ろの本文が重なる。
`.mdmark` の外に配置するコメントの入力欄と吹き出しにも適用するときは、`:root` にも記載する。

#### ダークの配色だけ変える

```css
@media (prefers-color-scheme: dark) {
  .mdmark {
    --mdmark-color-link: #f66;
  }
}
```

ダークの配色は、画面で OS の設定がダークのときに該当する。
`@media` で囲まずに記載した値は、明るい配色でもダークの配色でも該当する。

#### 図の色を変える

```css
.mdmark {
  --mdmark-color-diagram-line: #555;
  --mdmark-color-series-1: #c00;
}
```

図の線・グラフの系列の色と、文書の中の図の高さの上限も、変数で変える。
map の図のノードと線の種類の色は、設定の `map.kinds`・`map.lines` の色の名前で変える。
変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数) の図の変数。
色を変えても、系列は点の形状と塗りの模様でも分かれたまま。

#### 色の名前の色を変える

```css
.mdmark {
  --mdmark-color-accent-blue-text: #000080;
  --mdmark-color-accent-blue-bg: #e6f0ff;
}
```

表の列と行・バッジ・本文の文字に付ける色の名前の色は、色の名前ごとの面の薄い色（`--mdmark-color-accent-{色}-bg`）と文字の色（`--mdmark-color-accent-{色}-text`）の変数で変える。
選べるテーマの色の名前の色も、層の外で記載した値に替わる。
文字と面のコントラストを 4.5:1 以上に保つ値にする。
変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数) の色のプリセットの変数。

#### 差分の色を変える

```css
.mdmark {
  --mdmark-color-diff-del-bg: #fecaca;
  --mdmark-color-diff-add-sign: #0e7490;
  --mdmark-diff-minimap-width: 18px;
}
```

[差分を表示する](./導入-差分を表示する.md) で出す差分の、削除した行・追加した行・変わった単語の背景と、行頭の `-`・`+` とミニマップのマーカーの色も、変数で変える。
ミニマップの帯の幅と重なり順（`--mdmark-diff-minimap-z-index`）も変数で変える。
変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数) の差分の変数。
色を変えても、削除した行・追加した行は、行頭の `-`・`+` のマーカーとスクリーンリーダー向けの名前でも分かれたまま。

#### ビューとコメントの外観を変える

```css
:root {
  --mdmark-view-column-width: 16rem;
  --mdmark-color-comment-bg: #e6f4ff;
  --mdmark-color-comment-line: #0969da;
  --mdmark-color-error: #c00;
}
```

[ビューとコメントを使用する](./記載する-ビューとコメントを使用する.md) で出すビューとコメントの外観も、変数で変える。
`--mdmark-view-column-width` はボードの列の最小の幅で、収まらない列はボードの中で横にスクロールする。
`--mdmark-color-comment-bg` と `--mdmark-color-comment-line` はコメントのマーカーの地と下線の色で、入力欄を開いている間の選んだ文字の色にも使用する。
`--mdmark-color-error` はコメントの入力欄の通知の文字とアイコン、誤りのある本文の欄の枠の色。
コメントのボタン・入力欄・吹き出しは `document.body` に配置され、`.mdmark` の外になる。
これらの変数は `.mdmark` ではなく `:root` に記載する。
変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数) のビューとコメントの変数。
色を変えても、コメントのマーカーは下線でも、入力欄の通知はアイコンと文でも分かれたまま。

#### コードブロックの色分けの色を変える

```css
.mdmark {
  --mdmark-color-syntax-keyword: #0e7490;
  --mdmark-color-syntax-string: #15803d;
}

@media (prefers-color-scheme: dark) {
  .mdmark {
    --mdmark-color-syntax-keyword: #67e8f9;
  }
}
```

コードブロックの色分けは、キーワード・文字列・数値・型・名前・コメントの 6 種類の色を変数で変える。
変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数) の `--mdmark-color-syntax-*`。
ライトとダークの値を別々に持つため、ダークの値は `@media (prefers-color-scheme: dark)` の中で変える。
色を変えても、コメントは斜体でも分かれたまま。
色分けするコードブロックと言語は [コードブロックの飾り](./記法.md#コードブロックの飾り)。

#### 固定ヘッダーの下に見出し行を留める

```css
.mdmark {
  --mdmark-sticky-top: 48px;
}
```

表の見出し行は、ページを縦にスクロールしても画面の上端に留まる。
ページの上端に固定したヘッダーを配置しているときは、`--mdmark-sticky-top` にそのヘッダーの高さを指定すると、見出し行がヘッダーの下に留まる。
既定は `0px`。

#### 本文の幅を変える

```css
.mdmark {
  --mdmark-content-width: 40rem;
}
```

本文の幅は、既定では上限が無く、描く先の要素の幅を使用する。
行の長さを抑えたいときに、`--mdmark-content-width` へ長さを指定する。
変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数)。

### 配色を class で切り替える

#### 描く先に class を付ける

```html
<div class="mdmark-theme-dark">
  <div id="doc"></div>
</div>
```

描く先の要素かその祖先に `mdmark-theme-dark` を付けると、OS の設定がライトでもダークの配色で描く。
`mdmark-theme-light` は、OS の設定がダークでもライトの配色で描く。
class を付け替えると、描いた文書の配色がその場で替わる。

VS Code の Webview に描くときは、VS Code が `body` に付ける `vscode-dark`・`vscode-light` などに配色が従うため、何も付けなくてよい。
`mdmark-theme-*` は `vscode-*` より先に配色を決める。
決める順は [配色を切り替える class](./API.md#配色を切り替える-class)。

文書の `scheme` と設定の `colorScheme` が `light`・`dark` のときは、`mount` が描く先の要素に同じ class を付けるため、祖先の class より優先する。

印刷では、class によらず明るい配色で出る。

### 規則を上書きする

#### 層の外に CSS を書き込む

```css
a {
  text-decoration-line: none;
}
```

mdmark の CSS は `@layer mdmark` に入っている。
層の外に記載した CSS は詳細度によらず勝つため、mdmark が `.mdmark a` に適用する下線を、詳細度の低い `a` だけの指定で削除できる。
mdmark の CSS を読み込む前と後のどちらに記載しても、結果は変わらない。

ただし、コードブロックとファイルツリーを折り返すかは、記法の `wrap` で決まる。
利用側が層の外に `pre { white-space: pre-wrap; }` のような要素名だけの CSS を書き込んでも、`wrap` の無いコードブロックとファイルツリーは折り返さず、横にスクロールする。
このための既定は層の外に `.mdmark .mdmark-code pre` と `.mdmark .mdmark-tree .mdmark-tree-list` で配置してある。
意図して変えるときは、利用側もこのセレクタ以上の詳細度で記載する。

### `theme.css` に分ける

#### `<link>` で読み込む

```html
<link rel="stylesheet" href="/theme.css">
```

mdmark は利用側の `theme.css` を読み込まない。
設定の `theme` に記載すると、`mdmark export` で書き出した HTML と VS Code のプレビューの両方に該当し、プレビューは `theme.css` を保存すると再描画する。
ページが `<link>` で、層の外に読み込む。
`theme.css` の中身を `@layer` で囲まない。

#### テンプレートから配置する

作った CSS は、Claude Code から CSS のテンプレートに登録しておくと、ほかのリポジトリへ配置して `theme` に記載できる。
手順は [MCP のツールを使用する](./ClaudeCodeで使用する-MCPのツールを使用する.md#css-のテンプレートを使用する)。

## 反映

即時。ページを再読み込みすると、記載した CSS が該当する。
`colorTheme` は、利用側のサーバーが設定を再読み込みして `mount` にもう一度指定すると該当する。

## 確認

#### 選んだテーマが該当している

```js
getComputedStyle(document.querySelector(".mdmark")).backgroundColor
```

`theme-slate` を選び、OS の設定がライトなら `rgb(248, 250, 252)` が出る。
OS の設定がダークなら `rgb(15, 23, 42)` が出る。

#### 変数の値が該当している

文書にリンクがあるとき、リンクの色を確認する。

```js
getComputedStyle(document.querySelector(".mdmark a")).color
```

`#c00` を記載したなら `rgb(204, 0, 0)` が出る。

#### 色の名前の色が該当している

文書に `badge:blue:` のバッジがあるとき、バッジの文字の色を確認する。

```js
getComputedStyle(document.querySelector('.mdmark .mdmark-badge[data-color="blue"]')).color
```

`#000080` を記載したなら `rgb(0, 0, 128)` が出る。

#### 色分けの色が該当している

文書に言語を記載したコードブロックがあるとき、キーワードの色を確認する。

```js
getComputedStyle(document.querySelector(".mdmark pre code .hljs-keyword")).color
```

`#0e7490` を記載したなら `rgb(14, 116, 144)` が出る。
色分けは描いた後に付くため、色分けのライブラリを読み込み終えてから確認する。

#### 見出し行の位置と本文の幅が該当している

表を持つ文書で、ページを縦にスクロールして表の途中を出す。
見出し行の上端が、`--mdmark-sticky-top` に指定した長さだけ画面の上端から下にあり、固定のヘッダーに隠れていない。
本文の段落の幅が、`--mdmark-content-width` に指定した長さを超えない。
何も指定しないときは、段落の幅が描く先の要素の中身の幅と同じになる。

#### class で配色が替わっている

`mdmark-theme-dark` を付けた文書の地の色が、OS の設定がライトでもダークの色になる。

#### 層の外の規則が勝っている

```js
getComputedStyle(document.querySelector(".mdmark a")).textDecorationLine
```

`a` に `text-decoration-line: none` を記載したなら `none` が出る。

## 元に戻す

記載した CSS を削除する。
mdmark の既定の外観に戻る。
選んだテーマは、設定の `colorTheme` を削除すると既定の `dev-swiss` に戻る。
