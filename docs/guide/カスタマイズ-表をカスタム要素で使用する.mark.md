# 表をカスタム要素で使用する

アプリの画面に `<mdmark-table>` を配置し、列の定義と行のデータを指定して表を描き、行の押下・セルの編集・行の追加をイベントで受け取る手順

アプリの画面の一覧を、Markdown の表を囲んだときと同じ外観と操作（並べ替え・絞り込み・ピン止め・列の表示・列の並べ替え・列の幅の変更・長い文字の折り返し）で表示するときに実行する。
列名と行の値は文字として出し、HTML として解釈しない。
ビュー・コメント・グラフ・操作できる部品・map の図は、[部品をカスタム要素で使用する](./カスタマイズ-部品をカスタム要素で使用する.mark.md) の要素で描く。

## 前提

- [配布物を読み込む](./導入-配布物を読み込む.md) で、ページが `dist/index.js` と `dist/index.css` を読み込んでいる
- TypeScript で記載するときは、配布物を読み込んだ参照と同じ参照の `dist/` にある型定義（`index.d.ts` と、それが読み込む `.d.ts`）を配置する

## 手順

### 要素を配置する

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@0/dist/index.css">
<script type="module" src="https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@0/dist/index.js"></script>

<mdmark-table id="tasks"></mdmark-table>
```

`dist/index.js` を読み込むと、`<mdmark-table>` を登録する。
別の参照の配布物が先に登録していれば、登録しない。
要素は Shadow DOM を使用せず、中に class `mdmark` の要素を 1 つ配置して描くので、ページが読み込んだ `dist/index.css` とページの CSS がそのまま適用される。

### 列の定義と行のデータを指定する

```js
const table = document.querySelector("#tasks");

table.columns = [
  { key: "title", title: "タイトル", pinned: true },
  { key: "state", title: "状態", filter: { type: "select" } },
  { key: "owner", title: "担当", editable: true },
  { key: "updated", title: "更新日" },
];
table.rows = [
  { key: "FB-12", values: { title: "列の幅を広げる", state: "進行中", owner: "佐藤", updated: "2026-11-20" } },
  { key: "FB-13", values: { title: "ピン止めを使用する", state: "完了", owner: "鈴木", updated: "2026-11-15" } },
];
table.features = { count: {}, columns: {}, reorder: {}, add: {} };
```

`columns` と `rows` の両方を指定すると、次のマイクロタスクで表を描く。
同じマイクロタスクの中の代入は、まとめて 1 回だけ描く。
要素を登録する前に代入したプロパティも、登録した後に読み取る。

<!-- table: {"kind": "data"} -->

| プロパティ | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `columns` | 必須 | 列の定義の配列。並びが描いた直後の列の順になる。1 つ以上 |
| `columns[].key` | 必須 | 列のキー。`rows[].values` から値を参照し、イベントで列を特定する |
| `columns[].title` | 必須 | 列の見出しの文字。列の定義の中で重ならない |
| `columns[].pinned` | 任意 | `true` で描いた直後にピン止めする |
| `columns[].hidden` | 任意 | `true` で描いた直後に列を隠す。先頭の列には指定できない |
| `columns[].filter` | 任意 | 絞り込みを付ける。`type` は `select`・`text`・`date` で、省くと表のマーカーと同じ決め方で決める |
| `columns[].width` | 任意 | 列の幅（`mode`・`min`・`max`）。意味は表のマーカーの `columns.{列名}.width` と同じ |
| `columns[].editable` | 任意 | `true` の列のセルを押すと、入力欄で編集を始める |
| `columns[].render` | 任意 | セルの中身の描き方の関数（「セルの中身を差し替える」） |
| `rows` | 必須 | 行のデータの配列。並びが並べ替えていないときの行の順。空の配列は空の表を描く |
| `rows[].key` | 必須 | 行のキー。行のデータの中で重ならない |
| `rows[].values` | 必須 | 列のキーごとの値。値は文字列・数値・`null`。`null` とキーが無い値は空のセルにする |
| `features` | 任意 | 表の機能。キーは `sort`・`pin`・`filter`・`resize`・`count`・`columns`・`reorder`・`add` |

<!-- /table -->

`features` を省くと、表のマーカーの種類 `data` と同じ機能（並べ替え・ピン止め・絞り込み・列の幅の変更）と、列の定義に記載した機能を付ける。
機能を削除するときは `{ "resize": { "enabled": false } }` のように `enabled` を `false` にする。
`add` は表の下の左端に `行追加` のボタンを配置する。
集計・コピー・行へのリンクは付けられない。

### 操作のイベントを受け取る

```js
table.addEventListener("mdmark-row-click", (event) => {
  openDetail(event.detail.key);
});

table.addEventListener("mdmark-cell-edit", (event) => {
  const { key, column, value } = event.detail;
  if (!isValid(column, value)) {
    event.preventDefault();
    return;
  }
  save(key, column, value).catch(() => {
    table.rows = loadRows();
  });
});

table.addEventListener("mdmark-row-add", () => {
  table.rows = [...table.rows, createRow()];
});
```

<!-- table: {"kind": "data"} -->

| イベント | 発生する操作 | `detail` |
| --- | --- | --- |
| `mdmark-row-click` | 編集できない列のセルを押す・行にフォーカスして Enter を押す | `key`（行のキー） |
| `mdmark-cell-edit` | 編集できる列のセルの入力欄で、値を変えて確定する | `key`・`column`（列のキー）・`oldValue`（編集する前の値）・`value`（入力欄の文字列） |
| `mdmark-row-add` | `行追加` のボタンを押す | `{}` |

<!-- /table -->

3 つのイベントは `bubbles` と `composed` を持ち、要素を囲む要素でも受け取れる。
並べ替え・ピン止め・絞り込みのボタンとセルの中のリンクを押しても、`mdmark-row-click` は発生しない。
`mdmark-cell-edit` で `preventDefault()` すると、セルを前の値に戻す。
`preventDefault()` は受け取りの関数の中で同期で呼ぶ（`await` の後で呼んでも戻らない）。
非同期の保存に失敗したときは、元の値の `rows` を指定し直す。
戻さなければ、`rows` を指定し直すまでセルに確定した値を出し、並べ替えと絞り込みもその値で動く。
`oldValue` は、指定した値の型のまま通知する。同じ `rows` のまま同じセルを 2 回目以降に編集したときは、前回確定した文字列になる。
`mdmark-row-add` は行を追加しない。アプリが行を加えた配列を `rows` に指定し直す。

### キーボードで操作する

<!-- table: {"kind": "data"} -->

| キー | 操作 |
| --- | --- |
| Tab | 表の行のうち 1 行だけにフォーカスが入る |
| ↑・↓ | 表示している前の行・次の行へフォーカスを移す |
| Enter | フォーカスした行の `mdmark-row-click` を発生させる |
| F2 | フォーカスした行の中の、最初の編集できる列のセルの編集を始める |
| Enter（入力欄） | 編集を確定する。入力欄の外へフォーカスを移しても確定する |
| Esc（入力欄） | 編集を取り消し、行へフォーカスを戻す |

<!-- /table -->

### セルの中身を差し替える

```js
table.columns = [
  { key: "title", title: "タイトル" },
  {
    key: "state",
    title: "状態",
    render: (value, row) => {
      const badge = document.createElement("span");
      badge.className = "app-badge";
      badge.textContent = String(value);
      return badge;
    },
  },
];
```

`render(value, row)` が返却した `Node` をセルに配置し、文字列は文字のまま出す。
`row` はその行の `{ key, values }`。
並べ替え・絞り込みは、差し替えた中身でなく `rows[].values` の値で動く。
`render` が例外を投げたときは、そのセルに値を文字で出し、元のエラーをコンソールに出す。

### 行のデータを指定し直す

`columns`・`rows`・`features` を代入し直すと、表を描き直す。
並べ替え・絞り込み・列の幅・列の表示と並び順・ピン止めは、同じ `columns[].key` の列について保つ。
編集中のセルは取り消す。
要素をページから取り除くと受け取りを解除し、ページへ戻すと保持しているプロパティで描き直す。

### 指定の誤りを知る

指定に誤りがあると、プロパティの代入は例外を投げずに、要素の中にタイトル `この表を表示できません` の通知を出す。
本文に、最初に見つけた誤りの指定の名前（`rows`・`columns[1].title`・`features.total` など）と修正方法が入る。
ページのほかの要素は動く。
正しい指定を代入し直すと、通知が消えて表を描く。

## 反映

即時。
代入した次のマイクロタスクで描く。

## 確認

#### 表が描かれている

```js
document.querySelector("#tasks table") !== null
```

`true` になり、見出しの行と `rows` の数の行がある。

#### イベントが届く

行を押すと、`mdmark-row-click` の受け取りが行のキーで呼ばれる。

#### 誤りの通知が出ていない

要素の中に class `mdmark-notice` の要素が無い。
あれば、通知の本文の指定の名前を確認して修正する。

## 元に戻す

`<mdmark-table>` を画面から取り除く。
mdmark は行のデータを保存しないため、残るものはない。

型 `MdmarkTableElement`・`MdmarkTableColumn`・`MdmarkTableRow`・`MdmarkTableFeatures`・`MdmarkTableRowClickDetail`・`MdmarkTableCellEditDetail` は、型定義 `dist/index.d.ts` に書き出して配布物と一緒に配る。
構造は [API](./API.mark.md#表をカスタム要素で描く) を参照する。
