# 文書を描く

配布物を読み込んだページで `mount` を呼び、要素の中に Markdown を描く

mdmark を読み込んだページに、文書を初めて描くとき、本文を差し替えるとき、描いた文書を片付けるときに実行する。

## 前提

- [配布物を読み込む](./導入-配布物を読み込む.md)（CSS と JavaScript を同じタグで読み込んでいる）
- Chrome 99・Firefox 98・Safari 16.4 以上のブラウザ。このバージョンをビルドの対象にしている。動作は Playwright 同梱の Chromium と Firefox で確認している。3 つのブラウザのこのバージョンに無い API を使用していないかは、ビルドのたびに確認している。Safari の実機では確認していない

## 手順

### 描く

#### 描く先の要素を配置する

```html
<div id="doc"></div>
```

要素が無いと、文書は描かれない。

#### `mount` を呼ぶ

```html
<script type="module">
  import { mount } from "https://cdn.jsdelivr.net/gh/shuhei1101/mdmark@{タグ}/dist/index.js";

  const handle = mount(document.querySelector("#doc"), { markdown: "# 見出し\n\n本文" });
</script>
```

`{タグ}` は CSS を読み込んだタグに置き換える。
同じ要素へもう一度 `mount` を呼ぶと、前の描画を片付けてから描く。

#### 設定を指定する

利用側のサーバーが `mdmark.config.yaml` を読み込んだオブジェクトを、`config` に指定する。

```js
mount(document.querySelector("#doc"), { markdown, config: { features: { print: false } } });
```

省いたキーには既定を適用する。
キーは [設定](./設定.md)。

#### 索引と文書の `id` を指定する

利用側のサーバーが読み込んだ索引のオブジェクトと、描く文書の索引の `id` を指定する。

```js
mount(document.querySelector("#doc"), { markdown, index, docId: "arch", references });
```

`references` は `collectReferences` が返却した参照の表で、省ける。
本文に出た用語に意味のツールチップが付き、文書の末尾に被参照の一覧が出る。
索引の記載方法と参照の表の作り方は [索引と用語集を記載する](./記載する-索引と用語集を記載する.md)。

#### 取り込む文書を指定する

[取り込み](./記法.md#取り込み) のマーカーを使用する文書では、取り込むファイルを利用側が読み込み、パスから本文を参照する表を `includes` に指定する。
キーは描く文書のフォルダからのパスにする。

```js
mount(document.querySelector("#doc"), {
  markdown,
  includes: { "共通/手順.md": stepsMarkdown, "src/app.ts": appSource },
});
```

取り込むファイルが変わったときは、`update(markdown, { includes })` で表を差し替える。

### 本文を差し替える

#### `update` を呼ぶ

```js
handle.update("# 次の見出し");
```

本文だけを再描画する。
読者が開閉したセクションは、見出しと開閉のマーカーが変わっていなければ、その開閉のまま描く。
読者が開閉した表の行の詳細・details の範囲・折りたたみの注意書き・ER 図の列・ファイルツリーのフォルダ・コードの折りたたみ・表のキーの階層も、開閉のマーカーが変わっていなければ、その開閉のまま描く。
同じセクションの中で前に同じ種類の部品を追加すると、後ろの部品は開閉のマーカーのとおりに描く。
設定は `mount` に指定したものを使用する。
設定を変えるときは、`mount` をもう一度呼ぶ。

### 片付ける

#### `destroy` を呼ぶ

```js
handle.destroy();
```

要素の中を空にして class `mdmark` を削除し、印刷の受け取りを解除する。
呼んだ後の `update` は何もしない。

### Webview に組み込む

#### CSP に要るものを許す

VS Code の拡張機能の Webview のように CSP を付けたページに描くときは、次を許す。

| ディレクティブ | 許すもの |
| --- | --- |
| `script-src` | 配布物の配信元（`https://cdn.jsdelivr.net`）。外部ライブラリを使用するときは、設定の `libraries` の URL の配信元。読み込む `script` に付ける nonce |
| `style-src` | 配布物の配信元と `'unsafe-inline'` |
| `font-src` | 配布物の配信元 |
| `img-src` | 本文の画像の配信元 |

図とヒントの部品が HTML に `style` 属性を付けるため、`style-src` に `'unsafe-inline'` が要る。
スクリプトは nonce で絞れる。

#### 印刷は Webview の外で行う

Webview の中では、印刷（`window.print()`）が有効にならない。
印刷や PDF が要るときは、文書を HTML に書き出してブラウザで開き、そこで印刷する（[HTMLとPDFにする](./VSCodeで確認する-HTMLとPDFにする.md)）。

## 反映

即時。`mount` を呼ぶと、その場で描かれる。

## 確認

#### 文書が描かれている

```js
document.querySelector("#doc").classList.contains("mdmark")
```

`true` が出る。
要素の中に、Markdown に記載した見出しと本文が描かれている。

#### 外観が該当している

要素に地の色と内側の余白が付き、本文が描く先の要素の幅いっぱいに表示される。
該当していないときは、[配布物を読み込む](./導入-配布物を読み込む.md) の確認で CSS が読み込まれているかを確認する。

## 元に戻す

`destroy` を呼ぶ。
ページから `mount` の呼び出しと描く先の要素を削除すると、mdmark が描いたものは残らない。
