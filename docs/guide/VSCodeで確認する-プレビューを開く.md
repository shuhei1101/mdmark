# プレビューを開く

拡張機能を入れ、Markdown の横にプレビューを出して、バージョン・設定ファイル・配色・スクロールを整える手順

VS Code で Markdown を編集しながら、mdmark で描いた外観を確認するときに実行する。

## 前提

- VS Code 1.141.0 以上
- ネットワークにつながっている（プレビューは jsDelivr の配布物を読み込み、バージョンの決定で GitHub のタグ一覧を取る）

## 手順

### 拡張機能を入れる

#### Marketplace から入れる

VS Code の拡張機能の画面で `ShuheiNishikawa.mdmark-vscode` を検索し、表示名 `mdmark for VS Code` の拡張機能を入れる。
拡張機能のタグ `vscode-v{バージョン}` を打ったバージョンが Visual Studio Marketplace に公開され、入れた拡張機能は VS Code の拡張機能の更新で新しいバージョンになる。

#### .vsix を入れる

1. GitHub の Release（タグ `vscode-v{バージョン}`）から、`mdmark-{バージョン}.vsix` を落とす
2. VS Code のコマンドパレットで `Extensions: Install from VSIX...` を選び、落とした .vsix を指す

拡張機能のタグ `vscode-v{バージョン}` は、スプリントの区切りに develop の commit へ打つ。mdmark 本体のタグ `v{バージョン}` とは別で、拡張機能のバージョンと、プレビューが読み込む mdmark のバージョンは一致しない。

### プレビューを開く

#### Markdown の横に開く

Markdown を開き、`Shift+Alt+D`（Mac は `Shift+Option+D`）を押す。
エディタのタイトルのボタンか、コマンドパレットの `mdmark: プレビューを横に開く` でも開く。
ショートカットとボタンは、Markdown を開いているときだけ有効になる。

#### 同じ列に開く

コマンドパレットの `mdmark: プレビューを開く` を選ぶと、Markdown のエディタと同じ列のタブに開く。

同じ Markdown のプレビューが既に開いているときは、新しく作らず、そのプレビューを表に出す。

#### 差分ビューから開く

変更前と変更後の両方が Markdown の差分ビューで同じコマンドを呼ぶと、変更後の文書を描き、追加・削除したブロックを色分けしたプレビューが開く。
タブは `差分プレビュー {ファイル名}` で、差分でないエディタから開いたプレビューとは別になる。
読み込み方と、差分に対応しないバージョンのときの理由は [差分をプレビューで確認する](./VSCodeで確認する-差分をプレビューで確認する.md)。

### 読み込む mdmark のバージョンを決める

#### 最新のバージョンを読み込む

何も記載しないと、設定 `mdmark.version` の既定 `latest` で動く。
プレビューを開くときとリロードしたときに、GitHub のタグ一覧から最新の `v{X}.{Y}.{Z}` を選ぶ。
`vscode-` で始まる拡張機能のタグは選ばない。
タグ一覧を取れないときは、前回に選んだバージョンで描く。

#### バージョンを固定する

```json
{
  "mdmark.version": "v0.6.0"
}
```

`settings.json` に書き込む。
固定したバージョンはそのまま読み込み、タグ一覧を取らない。

### 描けないときに修正する

配布物を読み込めないときと、バージョンを決められないときは、文書の代わりに理由と「リロード」のボタンが出る。

| 理由 | 起きるとき | 修正方法 |
| --- | --- | --- |
| オフライン | jsDelivr に届かない | ネットワークを確認してから「リロード」を押す |
| 指定したバージョンが無い | `mdmark.version` に記載したバージョンの配布物が 404 | `mdmark.version` を公開されているバージョンに修正してから「リロード」を押す |
| バージョンを決められない | `latest` でタグ一覧を取れず、前回のバージョンも無い | ネットワークを確認してから「リロード」を押す |

「リロード」はコマンドパレットの `mdmark: プレビューをリロード` でも呼べる。
設定ファイルとバージョンをもう一度決め、配布物を再読み込みして描く。
新しい mdmark が打たれたときも、リロードで解釈する。

### 再描画とスクロールを整える

#### 再描画するきっかけを選ぶ

```json
{
  "mdmark.preview.liveUpdate": true,
  "mdmark.preview.updateDelayMs": 300
}
```

打つたびに、最後に打ってから `mdmark.preview.updateDelayMs` ミリ秒（0〜5000）待って再描画する。
`mdmark.preview.liveUpdate` を `false` にすると、保存したときだけ再描画する。
保存していない書き換えも、再描画するときの全文に含まれる。
背面に回ったプレビューは、表に戻ったときに最後の全文で、背面に回す前のスクロールの位置に再描画する。

#### スクロールを合わせる

エディタとプレビューのスクロールは、両方向に合う。
`mdmark.preview.scrollPreviewWithEditor` を `false` にするとエディタに合わせてプレビューを動かさず、`mdmark.preview.scrollEditorWithPreview` を `false` にするとプレビューに合わせてエディタを動かさない。

### 設定ファイルを使用する

#### 機能と外部ライブラリを決める

端末の設定と、Markdown のフォルダから上のフォルダの `mdmark.config.yaml` を重ねて、プレビューの描画に使用する（[設定を重ねて読み込む仕組み](./コアコンセプト-設定を重ねて読み込む仕組み.md)）。
`mdmark.configPath` に値を記載すると、上へ探さず、そのファイルと端末の設定だけを重ねる。
ワークスペースの直下から探し、無ければ mdmark の既定で描く。

```yaml
features:
  callout: false
libraries:
  my-chart: ./libs/my-chart.js
```

保存すると、プレビューを再描画する。
h1〜h3 の見出しがある Markdown のプレビューには、右側の目次が出る。
`features` に `side-toc: false` を記載するとオフにできる。
`libraries` の相対 URL は、設定ファイルのあるフォルダを基準にする。
`theme` の CSS と `extensions` の拡張もプレビューに該当し、書き出した HTML と同じ外観になる。
重ねた設定ファイル（端末の設定を含む）・`theme` の CSS・`extensions` のファイルを保存すると再描画する。
`aliases` に記載したエイリアスも、プレビューの本文に下線とツールチップで出る（[索引と用語集を記載する](./記載する-索引と用語集を記載する.md#設定の-aliases-で-yaml-からエイリアスを登録する)）。
行の `paths` に該当した YAML を保存すると再描画し、使用できない行は出力チャネルの `mdmark` に警告が出る。

#### 右側の目次の出し方を選ぶ

```yaml
side-toc:
  mode: fixed
```

`mdmark.config.yaml` に記載すると、プレビューの右側の目次が `fixed` になる。
`fixed` は、目次を出すボタンで開閉するサイドバーで出す。
記載しないときは `hover`（既定）で、右端の線を指すかフォーカスで目次を出す。
値は [右側の目次の出し方](./設定.md#右側の目次の出し方)。

#### 設定ファイルを開く

コマンドパレットの `mdmark: 設定ファイルを開く` で、設定ファイルをエディタで開く。
無いときは、雛形を作るかを尋ねる。
`作成` を選ぶと、`features`・`libraries`・`side-toc`・`colorTheme`・`theme`・`extensions` の記載例をコメントにした設定ファイルを作って開く。
尋ねずに作ることはない。

重ねた設定ファイルのどれかが YAML として読み込めない・設定の構造に合わないときは、文書の先頭に帯が出て、読み込めないファイルと行（またはキー）を通知する。
前に読み込めた設定で描いたままになり、帯の「設定ファイルを開く」で修正しに行ける。

### 配色を選ぶ

```json
{
  "mdmark.preview.theme": "auto"
}
```

`auto` は VS Code のテーマの明暗に合わせる。
`light`・`dark` を記載すると、その配色に固定する。
固定の仕組みは [テーマを上書きする](./カスタマイズ-テーマを上書きする.md)。

### テーマを選ぶ

#### VS Code の設定で選ぶ

```json
{
  "mdmark.colorTheme": "theme-slate"
}
```

プレビューの配色のテーマを選ぶ。
`dev-swiss`（既定）・`theme-paper`・`theme-slate`・`theme-contrast` から選び、空にすると設定ファイルに従う。
明暗は `mdmark.preview.theme` が決め、選んだテーマの中で明るい配色とダークの配色が切り替わる。
書き出した HTML と PDF にも、同じテーマが該当する。

#### 設定ファイルで選ぶ

```yaml
colorTheme: theme-paper
```

`mdmark.config.yaml` に記載すると、`mdmark.colorTheme` が空のときにプレビューがそのテーマで描く。
`mdmark.colorTheme` が空でないときは、そちらが勝つ。
記載しないときと知らない名前のときは、`dev-swiss` で描く。
値は [選ぶテーマ](./設定.md#選ぶテーマ)。

### 設定を開く

#### プレビューのボタンから開く

プレビューを開いている間、エディタのタイトルに歯車のボタンが出る。
押すと、VS Code の設定画面が mdmark の項目だけに絞って開く。
プレビューは閉じず、本文とスクロールの位置も変わらない。

#### コマンドパレットから開く

コマンドパレットの `mdmark: 設定を開く` でも、同じ絞り込みで設定画面が開く。
プレビューを開いていなくても使用できる。
YAML の設定ファイルを開くときは `mdmark: 設定ファイルを開く`。

設定画面で変えた設定は、リロードせずにプレビューへ映る。

### リンクと画像を使用する

- 外部の URL は、既定のブラウザで開く
- `.md` へのリンクは、元の Markdown と同じ列のエディタで開く
- `#` で始まるリンクは、プレビューの中で移る
- Markdown からの相対パスの画像は、プレビューに出る。ワークスペースの外の画像は読み込まず、代わりの文字が出る
- [取り込み](./記法.md#取り込み) のマーカーの取り込み先は、設定ファイルのフォルダ（無ければ Markdown のフォルダ）の中から保存した中身を読み込んで描く。取り込み先を保存すると再描画する

### 動画と音声を再生する

#### 相対パスで配置する

Markdown からの相対パスの動画・音声は、プレビューの再生バーで再生できる。
記載方法は [画像と動画を配置する](./記載する-画像と動画を配置する.md)。

#### 再生できる形式を選ぶ

| 形式 | プレビューでの再生 |
| --- | --- |
| mp3・ogg・wav | 再生できる |
| mp4・mov | 映像だけを再生し、音が出ない |
| m4a・webm | 再生できない |

プレビューの Webview は AAC の音声と webm を再生できない。
音が要る動画は、書き出した HTML をブラウザで開いて確認する（[HTMLとPDFにする](./VSCodeで確認する-HTMLとPDFにする.md)）。
再生できない動画・音声の場所には通知ブロックが出て、「既定のアプリで開く」を押すと OS の既定のアプリでファイルを開く。

#### 1 か所にまとめたファイルを読み込ませる

```yaml
assets:
  root: assets
```

画像・動画・音声を 1 か所にまとめて配置するときは、`mdmark.configPath` の設定ファイルに `assets.root` を記載する。
Markdown からの相対パスにファイルが無いとき、プレビューは設定ファイルのあるフォルダからの `assets.root` のフォルダで同じ相対パスを探す。
ワークスペースの外のファイルは読み込まない。

## 反映

`mdmark.version` を修正したときは、プレビューをもう一度開くか、リロードする。
それ以外の設定は、保存するとすぐに開いているプレビューへ該当する。

## 確認

#### プレビューが描かれている

Markdown の横に、タブ `プレビュー {ファイル名}` が開き、見出し・表・注意書きが mdmark の外観で描かれる。
h1〜h3 の見出しがあれば、プレビューの右端に線が出て、ポインターを配置すると右側の目次が出る。
Markdown を打つと、待ちのあとにプレビューが変わる。

#### 右側の目次の出し方が変わっている

`mdmark.config.yaml` に `side-toc` の `mode: fixed` を記載して保存する。
プレビューに目次を出すボタンが出て、押すと目次がプレビューの右の列に出る。

#### テーマが変わっている

設定 `mdmark.colorTheme` を `theme-slate` にする。
リロードせずに、プレビューの配色が theme-slate に変わる。
VS Code のテーマがライトなら theme-slate の明るい配色、ダークならダークの配色になる。

#### 設定が開く

プレビューを開いたまま、エディタのタイトルの歯車のボタンを押す。
VS Code の設定画面が開き、mdmark の項目だけに絞られる。
プレビューは開いたまま残る。

#### 動画と音声が再生できる

mp3 の音声を配置した Markdown のプレビューで、再生バーの再生を押すと音が出る。
m4a の音声の場所には、通知ブロックと「既定のアプリで開く」が出る。

#### スクロールが合っている

エディタを動かすとプレビューが同じ箇所まで動き、プレビューを動かすとエディタが同じ箇所まで動く。

## 元に戻す

プレビューのタブを閉じる。
拡張機能を使用しないときは、拡張機能の画面で mdmark を無効にするか、アンインストールする。
Markdown と設定ファイルは、プレビューの操作では書き換わらない。
