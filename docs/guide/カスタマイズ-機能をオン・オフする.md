# 機能をオン・オフする

設定の `features` と文書のマーカーで、機能のオン・オフを切り替える

機能の既定を設定で決めるとき、文書の作成者がその文書だけ機能を切り替えるときに実行する。

## 前提

- [文書を描く](./導入-文書を描く.md)

## 手順

### 設定で既定を決める

#### `features` を記載する

```yaml
features:
  print: false
```

利用側のサーバーが `mdmark.config.yaml` を読み込んだオブジェクトを、`mount` の `config` に指定する（[文書を描く](./導入-文書を描く.md)）。
CLI・MCP のツール・VS Code 拡張機能は、端末の設定と上のフォルダの設定の `features` をキーごとに重ねる（[設定を重ねて読み込む仕組み](./コアコンセプト-設定を重ねて読み込む仕組み.md)）。
記載しなかった機能は既定のままになる。
機能の名前と既定は [機能の既定](./設定.md#機能の既定)。

#### 記法の機能を切る

```yaml
features:
  table: false
  callout: false
```

表と注意書きの機能をオフにする。
オフにした記法は、記載した Markdown を普通の Markdown として描く。
脚注の `footnotes` をオフにすると、`[^ラベル]`・`^[中身]` と定義の行を記載した文字のまま描く。
アイコンの `icon`・キーの `kbd`・蛍光ペンの `highlight`・段組みの `columns`・details の範囲の `details`・改ページの `pagebreak`・取り込みの `include`・wide の範囲の `wide`・CSV の表の `csv`・カードの格子の `card-grid` も同じく切れる。
記法の機能の名前は [記法の機能](./設定.md#記法の機能)。

#### 用語と被参照の機能を切る

```yaml
features:
  glossary: false
  backlinks: false
```

`glossary` は用語のツールチップ、`backlinks` は被参照の一覧と文書の別名の機能。
`glossary` をオフにすると、用語集の表は普通の表として描く。
`backlinks` をオフにすると、末尾の一覧を出さず、文書の別名にだけ一致する単語に下線を付けず、ツールチップから「関連文書」の区分を削除する。
記載方法は [索引と用語集を記載する](./記載する-索引と用語集を記載する.md)、機能の名前は [用語の機能](./設定.md#用語の機能) と [被参照の機能](./設定.md#被参照の機能)。

#### 埋め込んだ HTML とヒントの機能を切る

```yaml
features:
  html: false
  hints: false
```

`html` は `<!-- html -->` の範囲の `html` のコードブロックを HTML として描く機能。
オフにすると、マーカーを取り除き、コードブロックをコードのまま描く。
`hints` は `data-hint`・図のノードと枠とレイヤーの `hint`・ノードの `io`・線の `tip` のツールチップの機能。
オフにすると、ツールチップの中身とマーカーを出さない。線のラベルとノードの名前は出す。
記載方法は [コードブロックのHTMLを描く](./図を描く-コードブロックのHTMLを描く.md)、機能の名前は [記法の機能](./設定.md#記法の機能)。

#### 範囲のスクリプトの機能をオンにする

```yaml
features:
  html-scripts: true
```

`html-scripts` は、`<!-- html -->` の範囲に配置した `css` をその範囲の HTML にだけ当て、`ts`・`js` の既定のエクスポートの関数を範囲の根の要素で呼ぶ機能で、既定がオフ。
文書に記載したコードを動かすため、利用側が許した文書でだけオンにする。
オフのときは、範囲の `html` だけを描き、`css`・`ts`・`js` をコードのまま出す。
`html` をオフにした文書では、`html-scripts` をオンにしても何も該当しない。
範囲ごとにはオン・オフできない。

#### mermaid の図の機能を切る

```yaml
features:
  mermaid: false
```

`mermaid` は、言語 `mermaid` のコードブロックを図にする機能。
オフにすると mermaid を読み込まず、コードブロックのまま描く。
文書の `<!-- features: {"mermaid": false} -->` で、その文書だけ切れる。
記載方法は [mermaidの図を描く](./図を描く-mermaidの図を描く.md)、機能の名前は [記法の機能](./設定.md#記法の機能)。

#### 色・画像・動画・カードの機能を切る

```yaml
features:
  text-color: false
  images: false
  cards: false
```

| 機能 | オンのときの働き | オフのときの描き方 |
| --- | --- | --- |
| `text-color` | `[文字]{color=色}` の文字に色を付ける | 記載した文字のまま描く |
| `images` | 画像の `{…}` の属性・title のキャプション・`#only-dark`・`#only-light` の出し分け | `{…}` を記載した文字のまま描き、画像を図にしない |
| `gallery` | `<!-- gallery -->` の範囲の画像を並べる | マーカーを取り除き、画像を並べない |
| `lightbox` | 図の画像を押すと拡大する | 押しても拡大しない |
| `media` | 動画・音声を再生バー付きで描く | 動画・音声を画像として描く |
| `gif` | GIF に止める・再生するボタンを付ける | ボタンを付けない |
| `cards` | リンク 1 つだけの段落をカードにする | リンクのまま描く |

表の列と行の色は `table`、バッジの色は `badge` の機能に含まれ、別にはオフにできない。
`mdmark export`・`mdmark build` は、`images`・`media` をオフにしても画像を埋め、動画・音声をコピーする。
記載方法は [色で強調する](./記載する-色で強調する.md) と [画像と動画を配置する](./記載する-画像と動画を配置する.md)、機能の名前は [記法の機能](./設定.md#記法の機能)。

#### ビューとコメントの機能を切り替える

```yaml
features:
  views: false
  comments: true
```

`views` は `<!-- view -->` の範囲の表を、ボード表示と表形式を切り替えるビューにする機能。
オフにすると、マーカーを取り除き、範囲の表を普通の表として描く（記載の警告も出さない）。
`comments` は、読者が本文の選んだ箇所にコメントを付けられる機能で、既定がオフ。
オンにしたうえで、`mount` に `docId` と `commentStore` を指定したときだけ有効になる。
記載方法は [ビューとコメントを使用する](./記載する-ビューとコメントを使用する.md)、機能の名前は [記法の機能](./設定.md#記法の機能) と [コメントの機能](./設定.md#コメントの機能)。

#### フロントマターを表示する

```yaml
features:
  frontmatter: true
```

`frontmatter` は、文書の先頭の YAML のフロントマターを、本文の先頭の閉じた折りたたみに yaml のコードブロックで出す機能で、既定がオフ。
オフのときもフロントマターは本文に出さない。
1 つの文書だけ出すときは、フロントマターの後ろに `<!-- features: {"frontmatter": true} -->` を記載する。
VS Code 拡張機能のプレビューでは、`mdmark.config.yaml` か端末の設定の `features.frontmatter` で切り替える。
記法は [フロントマター](./記法.md#フロントマター)、機能の名前は [フロントマターの表示の機能](./設定.md#フロントマターの表示の機能)。

#### 右側の目次の機能と出し方を選ぶ

```yaml
features:
  side-toc: false
```

右側の目次をオフにする。
目次を配置せず、すべて展開・すべて折りたたむのボタンも無くなる。

```yaml
side-toc:
  mode: fixed
```

出し方を選ぶ。
`hover`（既定）は右端の線を指すかフォーカスで目次を出し、`fixed` は目次を出すボタンで開閉するサイドバーにする。
`side-toc` の機能がオフのときは使用しない。
記載方法は [本文を部品で組む](./記載する-本文を部品で組む.md)、機能の名前は [記法の機能](./設定.md#記法の機能)、出し方は [右側の目次の出し方](./設定.md#右側の目次の出し方)。

#### 先頭へ戻るボタンの機能を切る

```yaml
features:
  back-to-top: false
```

先頭へ戻るボタンをオフにする。
オンのときは、描いた文書をスクロールする場所の高さ分スクロールすると、スクロールする場所の右下にボタンを出す。
機能の名前は [記法の機能](./設定.md#記法の機能)、ボタンの働きは [先頭へ戻るボタン](./記法.md#先頭へ戻るボタン)。

#### 図のリサイズハンドルの機能を切る

```yaml
features:
  diagram-resize: false
```

図の表示する枠の右下のリサイズハンドルを出さない。
表示する枠は定義から決まる高さのままになり、右上の拡大・縮小のボタンは出る。
機能の名前は [記法の機能](./設定.md#記法の機能)、リサイズハンドルの働きは [構成図の決まり](./構成図の決まり.md#操作)。

### 文書でその文書だけ上書きする

#### マーカーを記載する

```markdown
<!-- features: {"print": false} -->
```

`+機能` でオン、`-機能` でオフにする。
`<!-- features: {"機能A": true, "機能B": false} -->` のように、空白で区切って複数書ける。
マーカーは描いた本文に残らない。
コードブロックと行内のコードの中に記載したマーカーは、マーカーとして扱わない。

複数のマーカーは記載した順に重ね、同じ名前が何度も出たら後に記載したものが勝つ。
知らない機能名は無視する。
優先順は [文書を描く仕組み](./コアコンセプト-文書を描く仕組み.md)。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書のマーカーでもう一度決める。

## 確認

#### 印刷の機能がオフになっている

`<!-- features: {"print": false} -->` を記載した文書で、閉じた折り畳み（`details`）を持つものを描く。
ブラウザの印刷プレビューを開き、折り畳みが閉じたままになっている。

#### 印刷の機能がオンになっている

設定で `print` を `false` にし、文書に `<!-- features: {"print": true} -->` を記載する。
ブラウザの印刷プレビューを開き、折り畳みが開いている。

#### 記法の機能がオフになっている

`<!-- features: {"table": false, "callout": false} -->` を記載した文書で、`<!-- table: {"kind": "data"} -->` で囲んだ表と `> [!NOTE]` の引用を描く。

```js
document.querySelector(".mdmark .mdmark-table") === null && document.querySelector(".mdmark .markdown-alert") === null
```

`true` が出る。
表に並べ替えのボタンが無く、引用は注意書きの枠にならず引用のまま描かれている。

#### 用語と被参照の機能がオフになっている

`<!-- features: {"glossary": false, "backlinks": false} -->` を記載した文書で、索引を指定し、索引の用語が出る段落を描く。

```js
document.querySelector(".mdmark .mdmark-term") === null && document.querySelector(".mdmark .mdmark-backlinks") === null
```

`true` が出る。
用語に下線が付かず、文書の末尾に被参照の一覧が無い。

#### 埋め込んだ HTML とヒントの機能がオフになっている

`<!-- features: {"html": false} -->` を記載した文書で、`<!-- html -->` で囲んだ `html` のコードブロックを描く。

```js
document.querySelector(".mdmark .mdmark-html") === null && document.querySelector(".mdmark pre code.language-html") !== null
```

`true` が出る。
コードブロックが HTML として描かれず、コードのまま出ている。

`<!-- features: {"hints": false} -->` を記載した文書で、`data-hint` を持つ要素を埋め込んだ HTML に配置して描く。

```js
document.querySelector(".mdmark [data-hint], .mdmark .mdmark-hint-mark") === null
```

`true` が出る。
埋め込んだ HTML は描かれ、ツールチップのマーカーが無い。

#### 範囲のスクリプトの機能が切り替わっている

`html-scripts` を指定しない文書で、`<!-- html -->` の範囲に `html`・`css`・`ts` のコードブロックを配置して描く。

```js
document.querySelector(".mdmark .mdmark-html style") === null && document.querySelector(".mdmark pre code.language-ts") !== null
```

`true` が出る。
`<!-- features: {"html-scripts": true} -->` を記載すると、`css` が範囲の HTML に該当し、`ts` のコードブロックがコードとして出なくなる。

#### 色・画像・カードの機能がオフになっている

`<!-- features: {"text-color": false, "images": false, "cards": false} -->` を記載した文書で、`[決め手の 1 文]{color=blue}`・`![グラフ](./使用方法.md){width=300}`・URL だけの段落を描く。

```js
[".mdmark-color", "figure.mdmark-image", ".mdmark-card"].every((s) => document.querySelector(`.mdmark ${s}`) === null)
```

`true` が出る。
`{color=blue}` と `{width=300}` が記載した文字のまま出て、URL はリンクで描かれている。

#### ビューとコメントの機能が切り替わっている

`<!-- features: {"views": false} -->` を記載した文書で、`<!-- view: {"board": {"group": {"column": "状態"}}} -->` で囲んだ表を描く。

```js
document.querySelector(".mdmark .mdmark-view") === null && document.querySelector(".mdmark table") !== null
```

`true` が出る。
ビューの切り替えが無く、表が普通の表で描かれている。

`comments` を指定しない文書で、`commentStore` を指定して本文の文字を選ぶ。
コメントのボタンが出ず、`commentStore` の `load` も呼ばれない。
`<!-- features: {"comments": true} -->` を記載すると、文字を選んだときにボタンが出る。

#### 右側の目次の機能が切り替わっている

`<!-- features: {"side-toc": false} -->` を記載した文書で、見出しを持つ Markdown を描く。

```js
document.querySelector(".mdmark .mdmark-side-toc") === null
```

`true` が出る。
`-side-toc` を削除すると、右端に線を持つ右側の目次が出る。

#### 図のリサイズハンドルの機能がオフになっている

`<!-- features: {"diagram-resize": false} -->` を記載した文書で、ER 図を描く。

```js
document.querySelector(".mdmark .mdmark-diagram-resize") === null
```

`true` が出る。
`-diagram-resize` を削除すると、図の表示する枠の右下にリサイズハンドルが出る。

## 元に戻す

設定の `features` と文書のマーカーを削除する。
既定のオン・オフに戻る。
