# VS Code 拡張機能

VS Code 拡張機能のコマンド・既定のショートカット・設定の一覧

VS Code の拡張機能 mdmark のコマンドと設定。
コマンドはコマンドパレットで `mdmark:` から探す。
設定は VS Code の設定（`settings.json`）の `mdmark.*` で、ワークスペースの設定（`.vscode/settings.json`）が利用者の設定に勝つ。
手順は [VS Code で確認する](./使用方法.md)。

## プレビューを横に開く

Markdown の横の列に、プレビューを開く。
同じ Markdown のプレビューが開いていれば、新しく作らず表に出す。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: プレビューを横に開く` |
| 既定のショートカット | `Shift+Alt+D`（Mac は `Shift+Option+D`） |
| エディタのタイトル | アイコンのボタン（ポインターを合わせると `mdmark: プレビューを横に開く`） |

ショートカットとボタンは、Markdown を開いているとき（`editorLangId == markdown`）だけ有効になる。
コマンドパレットには、Markdown を開いているか、mdmark のプレビューにフォーカスがあるときに出る。

### 差分ビューで呼んだとき

アクティブなタブが、変更前と変更後の両方が Markdown の差分ビューで、`uri` がその変更前か変更後の側と一致する（省いたときはそのタブ）なら、変更後の文書を描き、追加・変更したブロックと削除したブロックを色分けした差分のパネルを開く。
変更前の側にフォーカスがあるときも、変更後の側を対象にする。

- パネルのタブは `差分プレビュー {変更後のファイル名}`。変更前と変更後の組ごとに 1 つで、同じ組のパネルが開いていれば新しく作らず表に出す。差分でないプレビューとは別になる
- 変更前と変更後の Markdown は、差分ビューの 2 つの側から読み込む。Git のコマンドは呼ばない
- 変更後の側の書き換えは、`mdmark.preview.liveUpdate` と `mdmark.preview.updateDelayMs` に従って再描画する。変更前の側の書き換えでは再描画しない
- 読み込んだ mdmark が差分の表示に対応しないときは、変更後の文書だけの表示を出さず、描けない理由と「リロード」を出す
- 複数ファイルの差分エディター（Source Control のグラフから開くもの）は、差分ビューとして扱わない

使用方法は [差分をプレビューで確認する](./VSCodeで確認する-差分をプレビューで確認する.md)。

### 引数

| 引数 | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `uri` | 任意 | プレビューを開く Markdown。省くと、mdmark のプレビューにフォーカスがあるときはそのプレビューの Markdown、それ以外はアクティブなエディタの Markdown |

## プレビューを開く

Markdown のエディタと同じ列のタブに、プレビューを開く。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: プレビューを開く` |

出す条件は [プレビューを横に開く](#プレビューを横に開く) のコマンドパレットと同じ。
差分ビューで呼んだときの振る舞いも同じ（[差分ビューで呼んだとき](#差分ビューで呼んだとき)）。

### 引数

[プレビューを横に開く](#プレビューを横に開く) と同じ。

## プレビューをリロードする

プレビューの設定ファイルと読み込むバージョンをもう一度決め、配布物を再読み込みして描く。
描けないときのボタン「リロード」も同じ処理を呼ぶ。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: プレビューをリロード` |
| プレビューのボタン | 描けないときに出る「リロード」 |

コマンドパレットには、mdmark のプレビューが 1 つ以上開いているときだけ出る。
`mdmark.version` が `latest` のときは、タグ一覧を 1 回もう一度取る。

### 引数

[プレビューを横に開く](#プレビューを横に開く) と同じ。省いたときの対象は、フォーカスのあるプレビューか、アクティブなエディタの Markdown のプレビュー。

## 設定ファイルを開く

最も近い `mdmark.config.yaml` をエディタで開く。設定ファイルを読み込めない帯から開いたときは、帯に出した読み込めないファイル（端末の設定を含む）を開く。
無いときは、雛形を作るかをダイアログで尋ね、`作る` を選んだときだけ作って開く。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: 設定ファイルを開く` |
| プレビューのボタン | 設定ファイルを読み込めない帯の「設定ファイルを開く」 |

コマンドパレットには常に出る。

雛形は、`features`・`libraries`・`side-toc`・`colorTheme` の記載例をコメントにした YAML で、キーは持たない。
作った直後のプレビューの外観は変わらない。

### 引数

[プレビューを横に開く](#プレビューを横に開く) と同じ。設定ファイルの場所を決める Markdown になる。

## 設定を開く

VS Code の設定画面を、mdmark の拡張機能の項目だけに絞って開く。
YAML の設定ファイルは開かない（それは [設定ファイルを開く](#設定ファイルを開く)）。
プレビューのパネルは閉じず、設定も設定ファイルも書き換えない。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: 設定を開く` |
| エディタのタイトル | 歯車のボタン（ポインターを合わせると `mdmark: 設定を開く`）。mdmark のプレビューがアクティブなときだけ出る |

コマンドパレットには常に出る。
歯車のボタンはキーボードで押せ、スクリーンリーダー向けの名前も `mdmark: 設定を開く`。

### 引数

なし。

## HTML に書き出す

開いている Markdown を、jsDelivr の配布物を読み込んで `mount` で描く HTML に書き出す。
書き出せたら、書き出したパスと `ブラウザで開く` のボタンを通知で出す。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: HTML に書き出す` |

書き出す先は `mdmark.export.outputDir`。
ファイル名は Markdown の拡張子を `.html` に替えたもの。
保存していない書き換えも書き出す内容に含む。
書き出した HTML は、開くときに jsDelivr へ届く必要がある。

### 引数

[プレビューを横に開く](#プレビューを横に開く) と同じ。書き出す Markdown になる。

## ブラウザで開く

呼ぶたびに [HTML に書き出す](#html-に書き出す) と同じ HTML をもう一度書き出し、既定のブラウザで開く。
書き出しの通知は出さない。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: ブラウザで開く` |
| 書き出しの通知 | `mdmark: HTML に書き出す` が出す「ブラウザで開く」のボタン |

### 引数

[プレビューを横に開く](#プレビューを横に開く) と同じ。開く Markdown になる。

## PDF に印刷

もう一度書き出した HTML を既定のブラウザで開き、描き終えた後に印刷のダイアログを出す。
PDF は、そのダイアログの送信先で「PDF に保存」を選んで作る。

### 使用方法

| 呼び方 | 内容 |
| --- | --- |
| コマンドパレット | `mdmark: PDF に印刷` |

外部ライブラリの描画を待つのは 10 秒まで。
書き出した HTML は、後から手で開くと、また印刷のダイアログが出る。

### 引数

[プレビューを横に開く](#プレビューを横に開く) と同じ。印刷する Markdown になる。

## 設定

拡張機能の動きを決める VS Code の設定。

### リクエスト

```json
{
  "mdmark.version": "latest",
  "mdmark.configPath": "",
  "mdmark.preview.liveUpdate": true,
  "mdmark.preview.updateDelayMs": 300,
  "mdmark.preview.scrollPreviewWithEditor": true,
  "mdmark.preview.scrollEditorWithPreview": true,
  "mdmark.preview.theme": "auto",
  "mdmark.colorTheme": "",
  "mdmark.export.outputDir": ""
}
```

<!-- table: {"kind": "data"} -->

| 設定 | 型 | 既定 | 許す値 | 説明 | 反映 |
| --- | --- | --- | --- | --- | --- |
| `mdmark.version` | 文字列 | `latest` | `latest` か `v{X}.{Y}.{Z}` | `latest` のときは、プレビューを開くときとリロードしたときに GitHub のタグ一覧から `v{X}.{Y}.{Z}` の最新を選ぶ。バージョンを記載するとそのバージョンに固定し、タグ一覧を取らない | プレビューをもう一度開くかリロードしたとき |
| `mdmark.configPath` | 文字列 | 空 | 空・相対パス・絶対パス | 拡張機能が読み込む YAML のパス。空のときは Markdown のフォルダから上へ `mdmark.config.yaml` を探して端末の設定と重ねる。値を記載したときは上へ探さず、そのファイルと端末の設定だけを重ねる。相対パスは Markdown を含むワークスペースのフォルダから（ワークスペースの外の Markdown は Markdown のフォルダから）解決する | 即時 |
| `mdmark.preview.liveUpdate` | 真偽値 | `true` | `true`・`false` | `true` のときは Markdown を打つたびに再描画する。`false` のときは保存したときだけ再描画する | 即時 |
| `mdmark.preview.updateDelayMs` | 整数 | `300` | 0〜5000 | 最後に打ってから再描画するまでのミリ秒。範囲の外の値は既定の値として扱う | 即時 |
| `mdmark.preview.scrollPreviewWithEditor` | 真偽値 | `true` | `true`・`false` | エディタをスクロールしたときに、プレビューを同じ箇所まで動かす | 即時 |
| `mdmark.preview.scrollEditorWithPreview` | 真偽値 | `true` | `true`・`false` | プレビューをスクロールしたときに、エディタを同じ箇所まで動かす | 即時 |
| `mdmark.preview.theme` | 文字列 | `auto` | `auto`・`light`・`dark` | `auto` は設定ファイルの `colorScheme`、無ければ VS Code のテーマの明暗に合わせ、`light`・`dark` はその配色に固定する。文書の先頭の [ページの設定](./記法.md#ページの設定) の `scheme` はこの設定より優先する。書き出す HTML には使用しない | 即時 |
| `mdmark.colorTheme` | 文字列 | 空 | 空・`dev-swiss`・`theme-paper`・`theme-slate`・`theme-contrast` | プレビューと、`mdmark.exportHtml`・`mdmark.openInBrowser`・`mdmark.printToPdf` が書き出す HTML の配色のテーマ。空のときは設定ファイルの `colorTheme` に従い、そこにも無ければ `dev-swiss`。設定画面の表示は「Mdmark: Color Theme」で、空の選択肢は「（設定ファイルに従う）」。明暗は `mdmark.preview.theme` が決める | 即時 |
| `mdmark.export.outputDir` | 文字列 | 空 | 空・相対パス・絶対パス | `mdmark.exportHtml`・`mdmark.openInBrowser`・`mdmark.printToPdf` が HTML を書き込むフォルダ。空のときは Markdown と同じフォルダ。相対パスは Markdown を含むワークスペースのフォルダから解決する | 即時 |

<!-- /table -->

### レスポンス

なし。

### エラー

`mdmark.version` が `v{X}.{Y}.{Z}` の構造でないと、VS Code が設定の入力欄で警告する。
`mdmark.preview.updateDelayMs` が範囲の外のときは、既定の 300 として扱う。

## 設定ファイルのキー

拡張機能が、端末の設定と上のフォルダの設定ファイルを重ねた設定から読み込むキー（[設定を重ねて読み込む仕組み](./コアコンセプト-設定を重ねて読み込む仕組み.md)）。
キーの意味は [設定](./設定.md)。

### リクエスト

```yaml
features:
  callout: false
libraries:
  my-chart: ./libs/my-chart.js
colorTheme: theme-slate
```

| キー | 説明 |
| --- | --- |
| `features` | 機能のオン・オフの既定。重ねた値を `mount` の `opts.config.features` に指定する |
| `libraries` | 外部ライブラリの対応表。`http:`・`https:` の URL はそのまま、相対 URL はその値を記載した設定ファイルのフォルダを基準に解決して、`mount` の `opts.config.libraries` に指定する。書き出す HTML には、相対 URL のうち文書にマーカーがあるモジュールを埋める |
| `html-scripts.url` | 範囲のスクリプトの変換のライブラリ。`http:`・`https:` の URL はそのまま、相対 URL はその値を記載した設定ファイルのフォルダを基準に解決して、`mount` の `opts.config.html-scripts.url` に指定する。書き出す HTML には、文書に `ts`・`js` の範囲があるとき相対 URL のモジュールを埋める |
| `colorTheme` | 配色のテーマ。`mdmark.colorTheme` が空のときだけ、記載した値をそのまま `mount` の `opts.config.colorTheme` に指定する。空でないときは `mdmark.colorTheme` の値に置き換える |
| `side-toc` | 右側の目次の出し方。値がマップのときだけ、記載した値をそのまま `mount` の `opts.config["side-toc"]` に指定する |
| `table` | 表の設定。値がマップのときだけ、記載した値をそのまま `mount` の `opts.config.table` に指定する（`pin` は[表のピン止めの動き](./設定.md#表のピン止めの動き)） |
| `labels` | 部品の文言。値がマップのときだけ、記載した値をそのまま `mount` の `opts.config.labels` に指定する |
| `tooltips` | ツールチップを出す場所。値がマップのときだけ、記載した値をそのまま `mount` の `opts.config.tooltips` に指定する |
| `syntax.url` | 色分けのライブラリの読み込み先。`http:`・`https:` の URL はそのまま、相対 URL はその値を記載した設定ファイルのフォルダを基準に解決して、`mount` の `opts.config.syntax.url` に指定する。書き出す HTML には、文書が使用する言語があるとき本体とその言語のモジュールを埋める |
| `colorScheme` | 配色の明暗。プレビューでは `mdmark.preview.theme` が `auto` のときだけ、書き出す HTML ではいつも、記載した値をそのまま `mount` の `opts.config.colorScheme` に指定する |
| `assets.root` | アセットのルート。Markdown のフォルダからの相対パスに無い画像・動画・音声を、その値を記載した設定ファイルのフォルダからのこのフォルダで同じ相対パスで探す。`mount` には指定しない |
| `aliases` | エイリアスの元の行。プレビューと書き出す HTML では、行の `paths` の YAML をその値を記載した設定ファイルのフォルダから読み込んでエイリアスを作り、`mount` の `opts.aliases` に指定する。使用できない行・レコードは除き、出力チャネルに `mdmark check` と同じ書式の警告を出す |

| `theme` | 利用側の CSS。その値を記載した設定ファイルのフォルダから解決し、プレビューでは配布物の CSS の後に読み込み、書き出す HTML には埋める |
| `extensions` | 拡張のモジュール。その値を記載した設定ファイルのフォルダから解決し、`mount` の前に登録する。書き出す HTML には 1 つのスクリプトにまとめて埋める |

表に無いキーは `mount` に指定しない。
最上位がマップでないファイルと空のファイルは、設定なしとして扱う。

### レスポンス

なし。保存すると、開いているプレビューを再描画する。

### エラー

重ねた設定ファイルのどれかが YAML として読み込めない・設定の構造に合わないときは、前に使用した設定（無ければそのファイルを除いた残りの設定）で描いたまま、プレビューの文書の先頭に読み込めないファイルと行（またはキー）を通知する帯を出す。
読み込めるようになると、帯は消える。
キーの中の知らない名前と型の違う値は、mdmark が無視する。
