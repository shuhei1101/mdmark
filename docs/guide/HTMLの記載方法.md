# HTML の記載方法

AI が HTML を作るときの記載方法の決まり

図・チャートなど外観のあるものを HTML で作るときに従う決まり。
構成図・シーケンス図は [Mermaidと補足で図を描く](./図を描く-Mermaidと補足で図を描く.md) の map、グラフ・操作できる部品・ER 図は [図を描く](./図を描く-図を描く.md) の部品の定義で描き、HTML を書き込まない。

## 用途

| 描くもの | 記載方法 |
| --- | --- |
| 文章・表・手順・リスト | Markdown |
| 構成図・シーケンス図 | map の範囲（Mermaid と補足） |
| グラフ・操作できる部品・ER 図 | 部品の定義（JSON） |
| 部品で描けない図・チャートなど外観のあるもの | HTML |

## 決まり

<!-- table: {"kind": "data"} -->

| 項目 | 決まり |
| --- | --- |
| 自己完結 | 外のファイル・CDN・フォントを読み込まない。図は 1 つの HTML に収める |
| 色と文字 | 色・書体・角丸は `--mdmark-` の CSS 変数で記載し、色の値を直に記載しない。変数はライトとダークで切り替わる。変数の一覧は [テーマの CSS 変数](./API.md#テーマの-css-変数) |
| 色だけで分けない | 意味の違いは、色に加えて形状・模様・文字・アイコンでも示し、凡例に全て記載する |
| タイトルと凡例 | 図ごとにタイトル・範囲・更新日と凡例を付ける |
| スクリーンリーダー | 図に名前を付け、操作できる要素にはスクリーンリーダー向けの名前を付ける。アイコンだけのボタンは `aria-label` を付ける |
| キーボード | 操作は全てキーボードでもできる。ドラッグだけの操作にしない |
| ツールチップ | ホバーとフォーカスの両方で出し、Esc で閉じ、上に乗っても閉じない。理解に必須のことは入れない |
| 拡大・縮小 | ボタンとキーで行う。ホイールは普通のスクロールに使用する |
| 文字 | 文字の上では選べる。ドラッグで図を動かすときは、文字の上を除く |
| スクリプト | 文書に記載した `<script>` は動かない。動きが要る部品は、利用側のページに記載して動かすか、`html-scripts` をオンにした文書で `<!-- html -->` の範囲の `ts`・`js` に記載する |
| 範囲の `ts`・`js` | 範囲の根の要素を受け取る関数を `export default` で記載し、要素は根の要素の中から探す。付けたイベント・タイマーは、返却した関数の中で削除する。`import` は記載しない |
| 範囲の `css` | 範囲の HTML の外観は範囲の `css` に記載し、根の要素は `:scope` で指す。色・書体・角丸は `--mdmark-` の CSS 変数で記載する |

<!-- /table -->

## 確認する

配置したら、動かして、スクリーンショットを撮って確認する。
手順は [描いた図を確認する](./図を描く-描いた図を確認する.md)。

## mdmark の文書に記載した HTML で残るもの

文書に記載した HTML は、描く前に許した要素・属性・URL だけを残す。

| 項目 | 残るもの |
| --- | --- |
| 要素 | 標準の要素と `img`・`del`・`details`・`summary`。文書に記載した `input` は、チェックボックスで操作できない状態に変換する。`svg`・`button`・`output` は残さない |
| `class` | `language-*`・`mdmark-align-*`・`task-list-item`・`mdmark-embed` だけ |
| 属性 | `style`・`id`・`data-*`・`on` で始まる属性は残さない |
| URL | `href` と `src` は `http`・`https`・`mailto` と相対 URL だけ |

外観を自分で作る HTML は、利用側のページに記載するか、画像にして配置する。

## 埋め込んだ HTML で残るもの

`<!-- html -->` の範囲に配置した `html` のコードブロックの HTML は、上の文書に記載した HTML と同じ許可の検査にかけてから、その場に描く。
記載方法は [コードブロックのHTMLを描く](./図を描く-コードブロックのHTMLを描く.md)。

<!-- table: {"kind": "data"} -->

| 項目 | 決まり |
| --- | --- |
| スクリプト・イベントの属性 | `script` 要素・`on` で始まる属性・`javascript:` の URL は落ち、動かない。動くのは mdmark の部品と、`html-scripts` をオンにした文書の範囲の `ts`・`js` だけ |
| `button` | 残る。`type="button"` に固定し、`form` で始まる属性は落とす。範囲の `ts`・`js` が操作を付けない限り、押しても何も起きない |
| `style` | 下の宣言だけが残る |
| `data-hint` | 任意の要素に記載でき、値の文がツールチップで出る。値は Markdown として読み込まず、文字として出す |
| 図の部品 | `<mdmark-chart>`・`<mdmark-param>` の中の JSON を、図の部品の定義として描く。要素の属性は読み込まない。廃止した `<mdmark-flow>`・`<mdmark-sequence>` は描かずに、記載方法を廃止した警告を出す |
| `id`・`data-*`（`data-hint` を除く） | 残さない |

<!-- /table -->

`style` の宣言は、次のものだけが残る。

| 項目 | 宣言 |
| --- | --- |
| 残す宣言 | `display`・`flex` で始まるもの・`align-items`・`align-self`・`justify-content`・`grid` で始まるもの・`gap`・`row-gap`・`column-gap`・`margin` で始まるもの・`padding` で始まるもの・`border` で始まるもの・`width`・`max-width`・`min-width`・`height`・`color`・`background-color`・`font-size`・`font-weight`・`text-align` |
| 落とす値 | `url(` を含む値・単位 `vw`・`vh` を含む値・`position`・負の `margin`・`padding` |

幅が本文の列より広い HTML は、描いた枠の中で横にスクロールする。

範囲の `css` の規則は `style` の宣言の制限を受けず、範囲の HTML の中だけに該当する。当て方は [記法の埋め込んだ HTML](./記法.md#埋め込んだ-html)。
