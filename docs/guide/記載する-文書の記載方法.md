# 文書の記載方法

人が読み込む資料を記載する前に読み込む、表し方と文の決まり

| 決まり | 中身 |
| --- | --- |
| 表し方の優先順位 | knowledge の規約『表し方の優先順位』（[shuhei1101/knowledge#132](https://github.com/shuhei1101/knowledge/issues/132)）に従う。図（map の構成図とシーケンス図・グラフ・ファイルツリー）→ 表 → 箇条書き → 文 の順に選び、上の表し方で記載できたものを下の表し方で重ねて記載しない。どれを選ぶかは knowledge の判定フローチャート『表し方の選び方』で決める |
| 確認すれば分かることを記載しない | 図・表を読み込めば分かる説明、冒頭のリード、概要を削る |
| 裏返しを記載しない | 「〜する」の後の「〜しない」、同じことのもう一度言いを削る |
| YAML のキーに記載した記法は記載した後に点検する | dev-docs の文書や MindStella の記録のように、YAML のキーの値に Markdown を記載したときは、記載した後に `mdmark check --file {ファイル} --key {キー}`（Claude Code からは MCP の `check` の `file`・`key`）で記法を点検する（[点検する](./書き出す-点検する.md#文字列と-yaml-のキーの記法を点検する)） |
| 参考は末尾にまとめる | 参考のリンクと参考にした情報は、ページの末尾の参考のセクションにまとめ、既定で再帰的に閉じる。各セクションの補足は参考へのリンクか、閉じたセクションにする |
