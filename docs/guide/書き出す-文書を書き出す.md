# 文書を書き出す

`mdmark export` で 1 文書を 1 枚の HTML に書き出す手順

Markdown を 1 つ、CDN を読み込まずに file:// で開ける HTML にして配るときに実行する。

## 前提

- [雛形を配置する](./書き出す-雛形を配置する.md)（設定ファイル `mdmark.config.yaml` を今のフォルダか上のフォルダに配置している）
- Node 24 以降
- 文書が外部ライブラリのマーカーを持つときは、書き出す手元から設定の `libraries` の URL の先へ届く
- 文書が色分けする言語のコードブロックを持つときは、書き出す手元から設定の `syntax.url` の先へ届く

## 手順

### 書き出す

#### `export` を呼ぶ

```bash
npx github:shuhei1101/mdmark#v{バージョン} export {文書} [--out {出力}] [--config {設定ファイル}] [--keep-traces]
```

`{文書}` は書き出す Markdown のパス。
`--out` を省くと、文書と同じフォルダに、拡張子を `.html` に替えたパスで記載する。
出力の親のフォルダが無ければ作り、出力が既にあれば上書きする。
`--config` を省くと、端末の設定と、今のフォルダから上のフォルダの `mdmark.config.yaml` を重ねて読み込む（[設定を重ねて読み込む仕組み](./コアコンセプト-設定を重ねて読み込む仕組み.md)）。
`--keep-traces` は、開発のときに mdmark の名前を残して書き出す（[mdmark を使用していることを隠す](#mdmark-を使用していることを隠す)）。

```text
書き出した: docs/使用方法/guide.html
```

#### 埋まるものを確認する

書き出した HTML には、次のものが埋まる。

- 配布物の JavaScript と CSS
- 設定の `theme` の CSS（配布物の CSS の後）
- 設定の `colorTheme` で選んだテーマ（書き出した HTML の `mount` に指定し、開いたときにそのテーマの配色で描く）
- 文書のマーカーにある外部ライブラリのモジュール（設定の `libraries` の URL から読み込み、モジュールが import する先もまとめる）
- 文書のコードブロックの言語に応じた色分けのライブラリの本体と、文書が使用する言語のモジュール（設定の `syntax.url` から読み込む。使用しない言語は埋めない）
- 設定の `extensions` の拡張のモジュール
- 文書が相対パスで指す画像（GIF・`#only-dark`・`#only-light` の画像・動画の `poster` を含む。`data:` URL に替え、URL のフラグメントは残す）
- 設定の `index` があるとき、索引と参照の表

相対パスの `libraries` と `syntax.url` の URL は、その値を記載した設定ファイルのフォルダを基準に読み込む。
画像・動画・音声は文書のフォルダを基準に探し、無ければ設定の `assets.root` のフォルダから同じ相対パスで探す（[アセットのルート](./設定.md#アセットのルート)）。
設定の `features.syntax` をオフにしたときと、文書の `<!-- features: {"syntax": false} -->` があるときは、色分けを埋めない。
文書に記載したスクリプトは実行されない。
文書間のリンクは記載したままの `href` で残る。
添付のファイル（PDF など）へのリンクも、記載したままの `href` で残る。
文書を行き来させたいときは [文書を1枚にまとめる](./書き出す-文書を1枚にまとめる.md)。

#### mdmark を使用していることを隠す

書き出した HTML は、既定で mdmark で作ったことが読み取れないように書き出す。

<!-- table: {"kind": "data"} -->

| 対象 | 書き出した HTML での扱い |
| --- | --- |
| クラス名・CSS 変数・要素名・`id`・`data-` 属性・スクリプトに出る `mdmark` | 別名へ置き換える。設定の `theme` の CSS と `extensions` の拡張の中の名前も、同じ別名へ置き換える |
| 本文の部品の要素名（`<mdmark-chart>` など）・CSS 変数（`--mdmark-*`）・`class` の値の `mdmark-` | 同じ別名へ置き換える。本文のコードの例に記載した名前も別名で表示される |
| HTML のコメント | 削除する。本文のマーカーのコメントは描画に使用するため残る |
| mdmark のバージョン（`--mdmark-version`） | 削除する |
| 本文の地の文の `mdmark`・文書のタイトル・文書のパス・索引 | 置き換えない |
| 第三者のライブラリと拡張のライセンスの表記 | 残す |

<!-- /table -->

表示と操作、`theme` の上書き、拡張は、隠さない書き出しと同じに動く。
開発のときに、書き出した HTML を mdmark の名前で調べたいときは、`--keep-traces` を付けて書き出す。

#### 動画と音声のコピーを確認する

文書が相対パスで指す動画・音声は HTML に埋めず、出力の HTML と同じフォルダの `{出力のファイル名から拡張子を除いた名前}_files/` へコピーする。
HTML の動画・音声は、そのコピーへの相対パスで再生する。

```tree
docs/
├── guide.html
└── guide_files/
    └── media/
        ├── demo.mp4
        └── voice.mp3
```

`_files/` の中のパスは、設定ファイルのフォルダからの相対パスになる。
設定ファイルのフォルダの外にあるファイルは `_files/external/` に配置する。
前の書き出しで `_files/` に配置したファイルは削除しないので、要らなくなったファイルは手で削除する。

#### 警告を読み込む

読み込めないものは、書き出しを止めず標準エラーに 1 つ 1 行で出す。
警告があっても終了コードは 0 で、読み込めたものだけを埋めて記載する。

```text
警告: docs/使用方法/guide.md: 画像 `img/missing.png` を読み込めません。パスを修正するか画像を配置してください。
```

警告の対象は、読み込めない画像・動画・音声・外部ライブラリのモジュール・色分けの本体と言語のモジュール・拡張・`theme` の CSS と、埋めずに残した絶対 URL の画像・動画・音声。
絶対 URL の画像・動画・音声は、開いたときに外へ要求する。
読み込めない外部ライブラリのマーカーの場所には、開いたとき通知ブロックが出る。
色分けの本体を埋められなかったときは全てのコードブロックが、言語のモジュールを埋められなかったときはその言語のコードブロックが、開いたとき色分けされずに記載したとおりに出る。
設定の `colorTheme` が選べるテーマの名前に無いときも警告に出し、`dev-swiss` で描く。

#### 書き出せないとき

設定ファイルが無い・読み込めない・Schema に合わないとき、`{文書}` を読み込めないとき、出力先か動画・音声のコピー先の `_files/` へ書き込めないときは、原因と修正方法の 1 文を標準エラーに出し、終了コード 1 で終わる。
HTML はどこにも記載しない。
設定が Schema に合わないときは、[点検する](./書き出す-点検する.md) でどこが合わないかを確認する。

### 開く

#### HTML を file:// で開く

書き出した HTML 1 つを、配る先へコピーして開く。
動画・音声を持つ文書は、HTML と隣の `_files/` を一緒に写す。
開いてから描き終えるまで、ページ自身・`_files/` の下のファイルと画像の `data:` のほかへ要求しない。
開くブラウザは Chrome 99・Firefox 98・Safari 16.4 以上。

## 反映

即時。`export` が終わると、出力に HTML が記載されている。

## 確認

#### HTML が記載されている

出力のパスに HTML があり、標準出力に `書き出した:` の行が出て、終了コードが 0 になる。

#### 文書が描かれている

HTML と隣の `_files/` だけを空のフォルダへコピーして file:// で開く。
文書が描かれ、表の並べ替えや用語のツールチップなどの操作が有効になる。
言語を記載したコードブロックは色分けされている。
動画・音声は再生できる。
ブラウザの開発者ツールのネットワークに、ページ自身・`_files/` の下のファイルと画像の `data:` のほかの要求が出ない。

#### mdmark の名前が残っていない

`--keep-traces` を付けずに書き出した HTML をテキストで開く。
文書のタイトル・パス・本文の地の文のほかに `mdmark` が無く、`<!--` が無い。

#### 選んだテーマが該当している

設定に `colorTheme: theme-slate` を記載して書き出した HTML を開く。
文書の配色が theme-slate になり、OS の設定がダークのときはダークの配色になる。

## 元に戻す

書き出した HTML と隣の `_files/` を削除する。
文書・設定・索引は `export` が書き換えない。
