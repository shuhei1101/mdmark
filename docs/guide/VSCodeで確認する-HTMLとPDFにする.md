# HTMLとPDFにする

開いている Markdown を HTML に書き出し、ブラウザで開き、PDF に印刷する手順

VS Code で記載した Markdown を、HTML のファイルにして配るとき、ブラウザで確認するとき、PDF にするときに実行する。

## 前提

- [プレビューを開く](./VSCodeで確認する-プレビューを開く.md)（拡張機能を入れている）
- 書き出した HTML を開く環境が、ネットワークにつながっている（HTML は開くときに jsDelivr の配布物を読み込む）

## 手順

### HTML に書き出す

#### `mdmark: HTML に書き出す` を呼ぶ

Markdown を開き、コマンドパレットで `mdmark: HTML に書き出す` を選ぶ。
Markdown と同じフォルダに、拡張子を `.html` に替えたファイルを書き込む。
同じ名前のファイルがあれば上書きする。

保存していない書き換えも、書き出す内容に含まれる。
設定の `aliases` に記載したエイリアスも、プレビューと同じく書き出した HTML に下線とツールチップで出る（[索引と用語集を記載する](./記載する-索引と用語集を記載する.md#設定の-aliases-で-yaml-からエイリアスを登録する)）。
書き出せたら、書き出したファイルのパスと `ブラウザで開く` のボタンを通知で出す。

#### 書き出す先を変える

```json
{
  "mdmark.export.outputDir": "out"
}
```

空（既定）のときは Markdown と同じフォルダ。
相対パスは Markdown を含むワークスペースのフォルダから、絶対パスはそのまま使用する。
フォルダが無ければ作る。

### ブラウザで開く

#### `mdmark: ブラウザで開く` を呼ぶ

コマンドパレットで `mdmark: ブラウザで開く` を選ぶ。
その場でもう一度書き出してから、既定のブラウザで開く。
前に書き出した HTML をそのまま開かないため、修正した内容が反映される。
書き出しの通知は出ない。

### PDF に印刷する

#### `mdmark: PDF に印刷` を呼ぶ

コマンドパレットで `mdmark: PDF に印刷` を選ぶ。
もう一度書き出した HTML を既定のブラウザで開き、描き終えた後に印刷のダイアログが出る。
ダイアログの送信先で「PDF に保存」を選ぶと PDF になる。

外部ライブラリの描画を待ってから印刷する。
待つのは 10 秒までで、超えたらそのまま印刷する。
印刷では、閉じた折り畳みが開き、配色は明るい（[印刷する](./カスタマイズ-印刷する.md)）。

VS Code の Webview の中では印刷が有効にならないため、プレビューの上からは印刷せず、ブラウザで開いた HTML から印刷する。

### 書き出せないときに修正する

| 通知 | 起きるとき | 修正方法 |
| --- | --- | --- |
| HTML を書き出せませんでした: {パス}（{理由}） | 書き出す先に書き込めない | `mdmark.export.outputDir` を書き込めるフォルダに修正する |
| HTML を書き出せませんでした。読み込む mdmark のバージョンを決められません | `mdmark.version` が `latest` で、タグ一覧を取れず前回のバージョンも無い | ネットワークを確認してから、もう一度実行する |

どちらの場合も、ブラウザは開かない。

## 反映

即時。コマンドを呼ぶたびに、その時点の Markdown と設定でもう一度書き出す。

## 確認

#### HTML が書き出されている

書き出し先に `{Markdown の名前}.html` がある。
ブラウザで開くと、見出し・表・注意書きが mdmark の外観で描かれ、相対パスの画像が出る。

#### 印刷のダイアログが出る

`mdmark: PDF に印刷` を呼ぶと、ブラウザが開き、描き終えた後に印刷のダイアログが出る。

## 元に戻す

書き出した HTML を削除する。
`mdmark: PDF に印刷` で書き出した HTML は、後から手で開くと、また印刷のダイアログが出る。
`mdmark: HTML に書き出す` か `mdmark: ブラウザで開く` でもう一度書き出すと、印刷の処理は無くなる。
Markdown は書き換わらない。

CDN に届かない環境へ配るときは、ネットワークを要さない 1 枚の HTML を CLI の `mdmark export` で書き出す（[文書を書き出す](./書き出す-文書を書き出す.md)）。
