# 色で強調する

色の名前の一覧と、決め手の 1 文だけに色を付ける色の使用方法のガイド

表の列と行・バッジ・本文の文字に色を付けるときに実行する。

## 前提

- [文書を描く](./導入-文書を描く.md)

## 手順

### 色の名前を選ぶ

#### 一覧から選ぶ

| 色の名前 | 用途の例 |
| --- | --- |
| `blue` | 推奨・採用・参考。`highlight` の既定 |
| `red` | 見送った理由・要確認・誤り |
| `green` | 完了・成立 |
| `yellow` | 保留・注意 |
| `orange` | 期限が近い・影響が大きい |
| `purple` | 分類の 1 つ（4 色で足りないとき） |
| `gray` | 中立・対象外・未着手 |

色の名前は小文字だけで記載する。
一覧に無い名前を記載すると、色を付けずに記載の警告が出る。
どの色も、明るい配色・暗い配色と選べるテーマのそれぞれで、文字と面のコントラストを 4.5:1 以上にしてある。

### 色を付ける

#### 記載する場所ごとの記載方法

| 場所 | 記載方法 | 色以外の見分け |
| --- | --- | --- |
| 表の列 | `<!-- table: {"kind": "data", "columns": {"金額": {"highlight": {"color": "blue"}}}} -->` | 見出しのセルの下端の線 |
| 表の行（列の値） | `<!-- table: {"kind": "data", "rows": {"colors": [{"column": "状態", "value": "完了", "color": "green"}, {"column": "状態", "value": "保留", "color": "yellow"}]}} -->` | 行の上下の線 |
| 表の行（位置） | `<!-- table: {"kind": "data", "rows": {"colors": [{"at": 2, "color": "red"}]}} -->` | 行の上下の線 |
| バッジ | `` `badge:red:要確認` `` | 札の文言 |
| 本文の文字 | `[決め手の 1 文]{color=blue}` | 太字 |

表の詳しい記載方法は [表に機能を付ける](./記載する-表に機能を付ける.md)、バッジと本文の文字は [本文を部品で組む](./記載する-本文を部品で組む.md)。

### 色を使用しすぎない

#### 決め手の 1 文だけに色を付ける

```markdown
採用: 案 A

[画像の属性と記載方法を 1 つにでき、mdmark の無い所でも文字として読み込める]{color=blue}。
案 B は、[文の途中がコードの外観になり読み込みにくい]{color=red}。
```

本文の文字に色を付けるのは、読者が判断に使用する決め手の 1 文だけにする。
推奨する案の決め手の 1 文を `blue`、見送った案の決め手になったデメリットの 1 文を `red` にする。
1 つの段落に色を付けるのは 1 文までにし、見出し・段落の全体・単語の 1 つ 1 つには付けない。
同じ意味には文書の中で同じ色の名前を使用する。

#### 色だけで意味を伝えない

色は、色の見分けにくい読者・白黒の印刷では伝わらない。
色を付けた文字は太字、表は線でも見分けられるようにしてあるが、意味は文の言葉で記載する（「推奨」「見送り」）。

## 反映

即時。`mount` と `update` で描くたびに、そのとき描く文書の記載方法でもう一度決める。

## 確認

#### 色が付いている

```js
[...document.querySelectorAll(".mdmark [data-color]")].map((e) => `${e.tagName}:${e.dataset.color}`)
```

記載した場所の要素と色の名前が出る。
OS の配色を切り替えると、その配色の色で再描画される。

#### 記載の警告が出ていない

色の名前の綴りを誤ると、その箇所の前に `記載の警告` の枠が出る。

## 元に戻す

表のマーカーの `highlight`・`rows.colors`、バッジの色の名前、本文の `{color=色}` を削除する。
本文の文字の色を止めるときは、[機能をオン・オフする](./カスタマイズ-機能をオン・オフする.md) で `text-color` をオフにする。
