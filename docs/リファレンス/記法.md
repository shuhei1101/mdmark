# 記法

印と記法の一覧（書き方・引数・印に対応しない表示での見え方）

文書に書いて、表・注意書き・タブなどの表示を付ける書き方の一覧。
どれも [文書を描く](../使い方/導入/文書を描く.md) で描いた文書に効く。

印は HTML コメントで書く。
1 か所に付ける印は `<!-- 名前: 引数 -->`、範囲を持つ印は `<!-- 名前: 引数 -->` 〜 `<!-- /名前 -->` で囲む。
引数の無い印はコロンを省いて `<!-- 名前 -->` と書ける。
引数は空白で区切り、種類・`+機能`・`-機能`・`キー=値`・`closed`・`open` を書ける。

## 表

表に、種類ごとの並べ替え・ピン止め・絞り込みと折り畳みを付ける。
機能の名前は `table`（[設定](./設定.md#記法の機能)）。
手順は [表に機能を付ける](../使い方/書く/表に機能を付ける.md)。

### 書き方

```markdown
<!-- table: data filter=名前,更新日:date closed -->

| 名前 | 値 | 更新日 |
| --- | --- | --- |
| りんご | 10 | 2026-10-01 |
| みかん | 2 | 2026-10-02 |

<!-- /table -->
```

印で囲んだ範囲の表すべてに当たる。
囲まない表は既定の種類で描く。

### 引数

| 引数 | 説明 |
| --- | --- |
| 種類 | `data` か `plain`。省くと既定の種類 |
| `+機能` / `-機能` | 種類の機能に足す・外す。機能は `sort`（並べ替え）・`pin`（ピン止め）・`filter`（絞り込み）・`count`（件数の表示）・`columns`（列の表示の切り替え）・`total`（集計の行）・`copy`（表のコピー）・`rowlink`（行へのリンク） |
| `filter=列名:種類,…` | 絞り込みを付ける列と種類。列名は表の見出しの文字で、複数の列はコンマで区切る。種類は `select`・`text`・`date` で、省くと `select` |
| `hide=列名,…` | 最初から隠す列。`+columns` を書いた表にだけ当たる。先頭の列は隠せない |
| `total=列名:計算,…` | 集計の行で集計する列と計算。`+total` を書いた表にだけ当たる。計算は `sum`（合計）・`avg`（平均）・`count`（空でないセルの数） |
| `closed` / `open` | 表を折り畳みに入れ、既定で閉じる・開く。折り畳みの見出しは `表を開く` |

種類ごとの機能は次のとおり。

| 種類 | 付く機能 |
| --- | --- |
| 既定 | ピン止め |
| `data` | 並べ替え・ピン止め・絞り込み |
| `plain` | なし。縦の罫線と面を外す |

`count`・`columns`・`total`・`copy`・`rowlink` はどの種類の既定にも入らず、`+機能` を書いた表にだけ付く。

機能の動きは次のとおり。

| 機能 | 動き |
| --- | --- |
| 並べ替え | 列の見出しを押すたびに、昇順・降順・元の並びを繰り返す。数値だけの列は数の大きさ、それ以外は文字の順で並べる |
| ピン止め | 表が幅からはみ出すときだけ、各列の見出しにボタンを出す。押した列までを表の左端に留め、押し直すと外す |
| 絞り込み | `filter=` で指定した列の見出しにだけボタンを出す。押すと絞り込みのドロワーが開き、外を押すか Esc で閉じる。列ごとの絞り込みは重ねて当たる |
| 件数の表示 | 表の上に `{表示している行の数} / {全ての行の数} 件` を出す。絞り込みで行が減ると表示している行の数が変わる |
| 列の表示の切り替え | 表の上の `列の表示` のボタンで、列名のチェックボックスを並べたメニューを開き、列ごとに表示・非表示を切り替える。`hide=` の列は最初から隠す。先頭の列のチェックボックスは外せず、メニューに `先頭の列は隠せません` を出す。「既定に戻す」で `hide=` の状態に戻す |
| 集計の行 | `total=` の列を表の末尾の行で集計する。題は計算ごとに `合計`・`平均`・`個数`。集計するのは表示している行で、絞り込みに合わせて計算し直し、並べ替えでは動かない。`sum`・`avg` は数として読めないセルを除く |
| 表のコピー | 表の上の `表をコピー` のボタンで、見出しの行と表示している行の、表示している列を、セルをタブで、行を改行で区切ったテキスト（TSV）にしてクリップボードへ写す。写せたらボタンが `コピーしました`、写せなかったら `コピーできませんでした` になる |
| 行へのリンク | 各行の先頭のセルに、その行を指す `#ID` のリンクを置く。URL の `#ID` が行を指すとき、その行へ移って強調する。閉じた表・閉じた節の中の行は開いてから、絞り込みで隠れた行はその表の絞り込みを外してから移る |

行へのリンクの `#ID` は、先頭の列の文字から見出しのアンカーと同じ規則で作り、同じ文書の中で重なれば `-1`・`-2` を付ける。

絞り込みの種類は次のとおり。

| 種類 | 絞り方 |
| --- | --- |
| `select` | 値をチェックボックスで選ぶ。候補を検索できる |
| `text` | 入れた文字を含む行に絞る |
| `date` | 開始日と終了日の期間に絞る。日付として読めないセルの行は、期間を指定すると合わない |

見出し行は面の色で本文の行と分け、表の中で縦にスクロールしても表の上端に留める。
表の高さの上限は `--mdmark-table-max-height`（[テーマの CSS 変数](./API.md#テーマの-css-変数)）。

### 印に対応しない表示

印は HTML コメントのため見えず、表は普通の表として読める。

## 注意書き

引用を、種類ごとの題・色・アイコンを持つ枠にする。
機能の名前は `callout`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

````markdown
> [!WARNING]
> 守らないと壊れる内容を書く。

> [!NOTE]-
> 閉じた状態で始める補足を書く。
````

### 引数

| 書き方 | 題 |
| --- | --- |
| `[!NOTE]` | 補足 |
| `[!TIP]` | ヒント |
| `[!IMPORTANT]` | 重要 |
| `[!WARNING]` | 警告 |
| `[!CAUTION]` | 注意 |

引用の 1 行目に書く。
`[!NOTE]-` のように末尾に `-` を付けると、題だけを出す閉じた折り畳みにする。
知らない種類は `NOTE` として出す。
種類は題の文字でも分かる。

### 印に対応しない表示

印ではない書き方のため、引用のまま読める。
引用の中に `[!NOTE]` などの文字が残る。

## タブ

範囲を、最初に出る見出しの階層で区切り、見出しの文字をタブ名にしたタブで切り替えて見せる。
機能の名前は `tabs`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

```markdown
<!-- tabs: group=os -->

### macOS

macOS の手順。

### Windows

Windows の手順。

<!-- /tabs -->
```

### 引数

| 引数 | 説明 |
| --- | --- |
| `group=名前` | タブの組の名前。同じページで同じ組のタブ群は、選んだタブ名を揃え、読む人が選んだタブ名を覚える。省くと組を持たないタブ群になる |

範囲の中で最初に出る見出しの階層で区切り、その見出しの文字がタブ名になる。
タブ名にした見出しは、本文の見出しとして残らない。
組を持たないタブ群は、描いた直後に最初のタブを選ぶ。
組を持つタブ群は、描いた直後に覚えたタブ名のタブを選び、覚えていないかそのタブ名が無いときは最初のタブを選ぶ。
タブは押すか、フォーカスがあるときの左右の矢印・Home・End で選ぶ。

組を持つタブ群の動きは次のとおり。

| 動き | 内容 |
| --- | --- |
| 揃える | 読む人がタブを選ぶと、同じページの同じ組のタブ群のうち、同じタブ名を持つものを同じタブ名へ切り替える。そのタブ名を持たないタブ群は今の選択のまま |
| 覚える | 読む人が押すかキーで選んだタブ名を、組ごとに localStorage のキー `mdmark-tabs:{組の名前}` へ残す。描いたときの選択と、揃えて切り替わった選択は残さない。読み直しや `update` で描き直したときも、覚えたタブ名で選ぶ |

localStorage を取り出す・読み書きするときに例外が出ると、残さず・読まずに、揃える動きと切り替えを続ける。
値の無い `group=` は組を持たないタブ群にし、`group=` 以外のキーと `キー=値` の形でない指定は当てずに、どれも [書き方の警告](#書き方の警告) を出す。

### 印に対応しない表示

印は見えず、見出しと本文が順に並ぶ。

## ステップ

番号付きリストを、番号と項目をつなぐ線を持つ手順に見せる。
機能の名前は `steps`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

```markdown
<!-- steps -->

1. 依存を入れる。
2. ビルドする。

<!-- /steps -->
```

### 引数

なし。
範囲の最初の番号付きリストを手順にする。
項目の中の入れ子の番号付きリストは手順にしない。

### 印に対応しない表示

印は見えず、普通の番号付きリストとして読める。

## ファイルツリー

罫線で書いたフォルダ構成を、フォルダとファイルの入れ子のツリーにする。
機能の名前は `tree`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

````markdown
```tree
mdmark/
├── src/
│   └── index.ts
└── package.json
```
````

### 引数

なし。
言語 `tree` のコードブロックに、`├──`・`└──`・`│` の罫線で書く。
名前の末尾が `/` の項目か、子を持つ項目をフォルダにし、それ以外をファイルにする。

### 印に対応しない表示

罫線で書いたコードブロックとして読める。

## バッジ

頭に `badge\:` を付けた行内のコードを、頭を外した文言の札にする。
機能の名前は `badge`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

```markdown
この版は `badge:v0.1.0` です。
```

### 引数

なし。
頭の後ろの文言が札の文言になる。
札にせず頭ごと見せるときは、頭の `:` の前に `\` を入れて打ち消す。

```markdown
`badge\:v0.1.0`
```

打ち消した行内のコードは、`\` を外したコードのまま出す。

### 印に対応しない表示

頭が付いた行内のコードとして読める。

## 目次

印の場所に、h2〜h3 の見出しを階層どおりに入れ子にした目次を置く。
機能の名前は `toc`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

```markdown
<!-- toc -->
```

### 引数

なし。
各項目は、その見出しの ID へのリンクになる。
h4 以降の見出しは載せない。

### 印に対応しない表示

印は見えず、何も出ない。

## 見出しのアンカー

見出しに GitHub と同じ規則の ID と、その ID へのリンクを付ける。
機能の名前は `anchors`。

### 書き方

印は無い。
全ての見出しに付く。

### 引数

なし。
見出しの文字から ID を作り、同じ ID の 2 つ目からは `-1`・`-2` を付ける。

| 見出し | ID |
| --- | --- |
| `Hello, World!` | `hello-world` |
| `使い方` | `使い方` |
| 2 つ目の `使い方` | `使い方-1` |

見出しの ID は、`anchors` がオフでも付く。
オンのときだけ、見出しの中に ID へのリンクを付ける。
リンクの読み上げの名前は `「{見出しの文字}」へのリンク`。

### 印に対応しない表示

印は無く、普通の見出しとして読める。

## 節の開閉

見出し（h2〜h4）の節を、見出しから開閉する。
機能の名前は `sections`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

```markdown
## 補足

<!-- section: closed -->

補足の本文。
```

### 引数

| 引数 | 説明 |
| --- | --- |
| `closed` | その節を閉じた状態で始める |
| `open` | その節を開いた状態で始める |

印は見出しの直後に書く。
印を書かない節は開いた状態で始める。
見出しの文字は開閉のボタンになる。
URL の `#ID` が閉じた節の中を指すとき、またはページ内検索が閉じた節の中に当たったときは、その節を開く。
h1・h5・h6 の見出しは節にせず、ID とアンカーだけを付ける。

### 印に対応しない表示

印は見えず、節は常に開いている。

## 行の詳細

表の行の下に、詳細を開閉して出す。
機能の名前は `row-details`。
手順は [本文を部品で組む](../使い方/書く/本文を部品で組む.md)。

### 書き方

```markdown
| 名前 | 値 |
| --- | --- |
| りんご | 10 |
| みかん | 2 |

<!-- row-detail: 2 -->

みかんの詳細。

<!-- /row-detail -->
```

### 引数

| 引数 | 説明 |
| --- | --- |
| 行の位置 | 詳細を付ける表の行。見出し行を除いて 1 から数える |

表の直後に書く。
詳細を持つ行の先頭のセルに開閉のボタンを置き、描いた直後は閉じる。
並べ替えと絞り込みでは、詳細はその行に付いて動く。

### 印に対応しない表示

印は見えず、詳細の本文が表の後ろに並ぶ。

## 図と表の番号

図と表に、種類ごとの通し番号の題を付け、本文のリンクの文字をその番号にする。
機能の名前は `figures`。
手順は [図と表に番号を付ける](../使い方/書く/図と表に番号を付ける.md)。

### 書き方

```markdown
<!-- fig: arch -->

![全体の構成](./arch.png "全体の構成")

本文から [図](#fig-arch) を参照する。
```

### 引数

| 引数 | 説明 |
| --- | --- |
| ID | 図表の `id` を `fig-{ID}` にする。本文のリンクは `#fig-{ID}` で指す |

印の直後の画像の段落と表に番号を付ける。
番号は文書の頭から、図と表で別に数える。
図は下に `図 1` と画像の title、表は上に `表 1` を置く。
本文の `#fig-{ID}` へのリンクの文字は、その図表の `図 1`・`表 1` に替わる。

### 印に対応しない表示

印は見えず、画像と表がそのまま出る。
リンクの文字は書いたままになる。

## 用語集の表

表の用語・意味・別名の列から用語を入れ、本文に出たその語に意味のツールチップを付ける。
機能の名前は `glossary`。
手順は [索引と用語集を書く](../使い方/書く/索引と用語集を書く.md)。

### 書き方

```markdown
<!-- glossary: term=用語 aliases=別名 meaning=意味 -->

| 用語 | 別名 | 意味 |
| --- | --- | --- |
| 印 | マーク、オン・オフの印 | HTML コメントで書く指定 |

<!-- /glossary -->
```

### 引数

| 引数 | 説明 |
| --- | --- |
| `term=列名` | 必須。用語の列。列名は表の見出しの文字 |
| `meaning=列名` | 必須。意味の列 |
| `aliases=列名` | 任意。別名の列。別名のセルは「、」か「,」で区切る。「・」は別名の中の文字として扱う |

用語か意味が空の行は飛ばす。
表は表の機能を持つ普通の表として描き、表の中の語には下線を付けない。
索引を渡したときは、ほかの文書の用語集の表から入れた用語も効く（[参照の表を作る](./API.md#参照の表を作る)）。
同じ語が複数あるときは、索引の `terms`、描く文書の表、ほかの文書の表（索引の `docs` で先に並ぶ文書）の順に優先する。

### 印に対応しない表示

印は見えず、表は普通の表として読める。

## ビュー

範囲の最初の表を項目にして、列ごとに分けたボード表示と、表形式のビューを切り替えて見せる。
表形式のビューは、`filter=` で指定した列を絞り込める。
機能の名前は `views`。
手順は [ビューとコメントを使う](../使い方/書く/ビューとコメントを使う.md)。

### 書き方

```markdown
<!-- view: group=状態 default=table filter=担当,題:text icons=未着手:inbox -->

| 題 | 状態 | 担当 |
| --- | --- | --- |
| 配色の変数を洗い出す | 未着手 | 佐藤 |
| 余白の変数を決める | 進行中 | 鈴木 |

<!-- /view -->
```

範囲の最初の表の見出しの行が列名、本文の行が項目、セルの文字が値になる。

### 引数

| 引数 | 説明 |
| --- | --- |
| `group=列名` | ボード表示で列に分ける列名。表の見出しの文字で書く。省くと、切り替えを置かず、表形式のビューだけを描く |
| `default=board` / `default=table` | 描いた直後に出すビュー。省くと、`group=` があればボード表示 |
| `filter=列名:種類,…` | 表形式のビューで絞り込みを付ける列と種類。書き方は [表](#表) の `filter=` と同じ（種類は `select`・`text`・`date` で、省くと `select`） |
| `icons=値:アイコンの名前,…` | ボードの列の見出しのアイコンを、`group=` の列の値ごとに上書きする |

ビューの動きは次のとおり。

| 項目 | 動き |
| --- | --- |
| 切り替え | ビューの頭の「ボード」「表」のボタンで切り替える。今のビューは `aria-pressed` で示す |
| ボード表示 | `group=` の列の値ごとの列を、表に出た順に横に並べる。列の見出しにアイコン・値・項目の数を出す。項目は表の行の順に並び、先頭の列の値が題になり、`group=` の列を除く残りの列を列名と値の組で出す。空の値は出さない。幅に収まらない列はボードの中で横にスクロールする |
| 表形式 | 範囲の表をそのまま使い、[表](#表) の並べ替えと、`filter=` の列にだけ同じ絞り込みを付ける |
| 絞り込み | 表形式にだけ当てる。ボード表示は常に全ての項目を出し、表形式に戻すと絞り込みは残っている。ビューの上に、検索欄と件数は置かない |
| 印刷 | 今のビューを出し、切り替えと絞り込みのボタンは出さない |

ボードの列の見出しのアイコンは lucide のもの。
既定の対応は、`未着手` が `circle-dashed`、`進行中` が `circle-dot`、`保留` が `circle-pause`、`完了` が `circle-check`、`中止` が `circle-x`、対応に無い値が `circle`。
使えるアイコンは、この 6 つと `inbox`・`archive`・`clock`・`flag`・`star`・`bug`・`eye`・`lock`・`zap`・`ban`。
アイコンは読み上げに含めず、列の見出しは値と項目の数だけが読み上げられる。

### 印に対応しない表示

印は見えず、範囲の表は普通の表として読める。
`views` がオフのときも同じ。

## 図の部品

範囲に置いた部品の定義（JSON）から、図と操作できる部品を描く。
機能の名前は `diagrams`。
手順は [図を描く](../使い方/図を描く/図を描く.md) と [操作できる部品を作る](../使い方/図を描く/操作できる部品を作る.md)。

### 書き方

````markdown
<!-- chart -->

```json
{
  "title": "返信までの時間",
  "scope": "10 月の第 2 週",
  "updated": "2026-10-18",
  "x": { "label": "曜日", "ticks": ["月", "火", "水", "木", "金"] },
  "y": { "label": "分", "min": 0, "max": 60, "step": 15 },
  "series": [{ "name": "自動返信", "points": [12, 9, 14, 8, 10] }]
}
```

<!-- /chart -->
````

### 引数

印に引数は無い。
範囲に言語 `json` のコードブロックを 1 つだけ置く。

| 印 | 描くもの | 定義の型 |
| --- | --- | --- |
| `flow` | フロー図。システムの枠と 3 層、箱と線を定義の座標に置く | `MdmarkFlowDefinition` |
| `sequence` | シーケンス図。相手を左から右へ、メッセージを上から下へ並べる | `MdmarkSequenceDefinition` |
| `chart` | 折れ線・棒・円・散布図のグラフ。系列は 4 つまで | `MdmarkChartDefinition` |
| `param` | スライダー・今の値を写すボタン・グラフを組み合わせた操作できる部品 | `MdmarkParamDefinition` |

定義の項目:

| 印 | 項目 |
| --- | --- |
| 共通 | `title`（題名）・`scope`（範囲）・`updated`（更新日。`YYYY-MM-DD`）。`param` は `title` と `knob`・`chart`・`table` |
| `flow` | `width`・`height`・`frame`・`lanes`・`nodes`・`wires`。箱は `kind`（`llm`・`dm`・`script`・`mcp`・`data`・`external`）、線は `line`（`flow`・`read`・`write`・`reply`・`loop`）と端の箱の `from`・`to` |
| `sequence` | `participants`・`steps`・`loop`。`steps` の `reply` が `true` のメッセージは返す線 |
| `chart` | `type`（`line`・`bar`・`pie`・`scatter`。省くと `line`）・`x`（`label`・`ticks`）・`y`（`label`・`min`・`max`・`step`）・`series`（`name`・`points`）。`line`・`bar` の `points` の数は `x.ticks` と同じ。`scatter` の `points` は `[x, y]` の組で、`x` に `ticks` を書かない。`pie` は `x`・`y`・`series` の代わりに `items`（`name`・`value`）と、凡例の値の単位 `unit` を書く。`y` の `min`・`max`・`step` は 3 つとも書くか 3 つとも省き、省くとデータから切る |
| `param` | `knob`（`key`・`label`・`min`・`max`・`step`・`value`）・`chart`（グラフの題と軸）・`table`（スライダーの値ごとの点） |

型は `dist/index.d.ts` に書き出して配布物と一緒に配る。
描いた図は `figure.mdmark-diagram` で、`data-diagram` が印の名前になる。
範囲のコードブロック以外の Markdown と、定義の JSON は描いた文書に残らない。
見た目の決まりは [構成図の決まり](./構成図の決まり.md) と [フローチャートの決まり](./フローチャートの決まり.md)。

### 印に対応しない表示

印は見えず、定義が `json` のコードブロックのまま読める。
`diagrams` がオフのときも同じ。
同じ名前の拡張を `registerExtension` で登録していると、拡張を優先して図の部品は描かない。

## 埋め込んだ HTML

範囲に置いた `html` のコードブロックの中身を、コードではなくその場の HTML として描く。
中に置いた図の部品の custom element は、図にして描く。
機能の名前は `html`。
手順は [コードブロックのHTMLを描く](../使い方/図を描く/コードブロックのHTMLを描く.md)。

### 書き方

````markdown
<!-- html -->

```html
<div style="display: flex; gap: 12px">
  <div style="padding: 12px">受け取り</div>
  <div style="padding: 12px">分類</div>
</div>
<mdmark-chart>
{
  "type": "pie",
  "title": "返信の種類の割合",
  "scope": "10 月の第 2 週",
  "updated": "2026-10-17",
  "unit": " 件",
  "items": [
    { "name": "よくある質問で答えた", "value": 186 },
    { "name": "担当者へ回した", "value": 92 }
  ]
}
</mdmark-chart>
```

<!-- /html -->
````

### 引数

印に引数は無い。
範囲に言語 `html` のコードブロックを 1 つだけ置く。

| 項目 | 内容 |
| --- | --- |
| 描き方 | コードブロックの中身を `<div class="mdmark-html">` の中に HTML として描く。範囲のコードブロック以外の Markdown は、描いた文書に残らない。範囲の外の `html` のコードブロックはコードのまま出る |
| 落とすもの | `script` 要素・`on` で始まる属性・`javascript:` の URL。`button` は `type="button"` に固定して残し、押しても何も起きない。`style` は一部の宣言だけが残る（[埋め込んだ HTML で残るもの](./HTMLの書き方.md#埋め込んだ-html-で残るもの)） |
| 図の部品 | `<mdmark-flow>`・`<mdmark-sequence>`・`<mdmark-chart>`・`<mdmark-param>` の中の JSON を、`flow`・`sequence`・`chart`・`param` と同じ定義として読み、同じ図に置き換える。要素の属性は読まない。`diagrams` がオフのときは、要素を中身ごと落とす |
| 用語 | 中の文章にも、本文と同じ用語と文書の別名の下線とツールチップを付ける |
| 横幅 | 幅が本文の列より広い間だけ、中で横にスクロールする |
| 拡大・縮小 | 中の図の部品だけに付く。部品でない HTML には付けない |

### 印に対応しない表示

印は見えず、`html` のコードブロックがコードのまま読める。
`html` がオフのときも同じ。

## ヒント

埋め込んだ HTML の要素に `data-hint` を書くと、その文をツールチップで出す。
機能の名前は `hints`。
手順は [コードブロックのHTMLを描く](../使い方/図を描く/コードブロックのHTMLを描く.md)。

### 書き方

```html
<div data-hint="返信の種類を 1 つ選ぶ">分類の結果</div>
<p>問い合わせは <span data-hint="本文を読んで返信の種類を決める処理">分類</span> してから返す。</p>
```

### 引数

| 項目 | 内容 |
| --- | --- |
| `data-hint` | ツールチップに出す文。文字として出し、Markdown として読まない |
| ブロックの要素 | 右上に情報のアイコンを付け、アイコンの上でだけ開く。要素の上では開かない |
| 行内の要素 | `span`・`a`・`abbr`・`b`・`strong`・`em`・`i`・`code`・`small`・`mark`・`sub`・`sup`・`time`・`kbd`・`q`・`s`・`u`。破線の下線を付け、要素そのものの上で開く |

ホバーとフォーカスの両方で開き、Esc で消え、ツールチップの上に乗っても消えない。
ポインターの形は変わらない。
図の部品の定義の箱の `hint` と `io`、線の `tip` も、同じ見た目のツールチップで出る。
`hints` をオフにすると、`data-hint`・`hint`・`io`・`tip` のツールチップの中身と印を出さない（線のラベルと箱の名前は出す）。

### 印に対応しない表示

`html` のコードブロックがコードのまま読めるため、`data-hint` は書いたまま読める。
`hints` がオフのときは、埋め込んだ HTML は描かれ、`data-hint` の文は出ない。

## 拡張の印

使う側が `registerExtension` で足した印を、その拡張のモジュールが描く。
手順は [拡張を登録する](../使い方/カスタマイズ/拡張を登録する.md)。

### 書き方

```markdown
<!-- greet: world lang=ja -->
```

### 引数

引数は、拡張が登録した `directive` の印に書く。
`キー=値` でない引数を書いた順に `args`、`キー=値` を `keys` にして、拡張の `schema` が検査し、`draw` が受け取る。
文書にその印があるときだけ、拡張のモジュールを読む。
印を範囲（`<!-- greet -->` 〜 `<!-- /greet -->`）で書き、範囲に言語 `json` のコードブロックを 1 つ置くと、その JSON を読んだ値が `definition` として `schema` と `draw` に渡る。

### 印に対応しない表示

印は見えない。

## 書き方の警告

記法の印に読めない指定を書いても、本文の描画は止まらない。
読めた指定だけを当てて描き、読めない指定とその直し方を、その箇所に題 `書き方の警告` の枠で出す。

次の場合に警告が出る。

- 記法の印に、知らない種類・`+機能`・`-機能`・キー・値を書いた（表に無い列名・知らない絞り込みの種類・知らない集計の計算・`hide=` の先頭の列・`+total` の無い表の `total=`・`+columns` の無い表の `hide=` を含む）
- 閉じの印の無い範囲を書いた（印から文書の終わりまでを範囲にして描く）
- タブ名にする見出しの無いタブの範囲を書いた
- タブの印に、値の無い `group=`・`group=` 以外のキー・`キー=値` の形でない指定を書いた（値の無い `group=` は組を持たないタブ群にする）
- 番号付きリストの無いステップの範囲を書いた
- 表に無い行を指す行の詳細を書いた
- 切れた図表のリンクを書いた、または図表の ID が重なった
- 読めない行を持つファイルツリーを書いた（コードブロックのまま描く）
- 拡張の印の引数が、拡張の `schema` に合わない
- 拡張の印の範囲の部品の定義を、JSON として読めない
- 図の部品の定義を読めない（JSON のコードブロックが無い・2 つ以上ある、JSON として読めない、形に合わない）。その図だけを描かず、ほかの図と本文は描く
- 埋め込んだ HTML の印の範囲に、`html` のコードブロックが無い・2 つ以上ある（範囲の中身はそのまま描く）
- 埋め込んだ HTML の中の図の部品の custom element の定義を読めない（その要素の場所だけを警告にし、同じ範囲のほかの HTML は描く）
- 用語集の表の印に、必須の `term=`・`meaning=` が無い、または指した列名が表に無い（この表からは用語を入れずに描く）
- ビューの印の `group=` や `filter=` の列が表に無い、`filter=` の種類が `select`・`text`・`date` でない、`icons=` に使えないアイコンの名前がある、知らないキーを書いた（`group=` の列が表に無いときはボードにせず表形式で描き、それ以外は読めた指定だけを当てる）
- ビューの印の範囲に、項目にする表が無い（範囲の中身をそのまま描く）

`features` の印の知らない機能名は、知らせずに無視する。
外部ライブラリや拡張のモジュールを読めない印の場所は、書き方の警告ではなく [知らせの枠](./用語集.md) に替わる。
