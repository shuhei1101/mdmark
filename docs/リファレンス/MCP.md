# MCP

MCP のツールの名前・引数・戻り値・エラーの一覧

Claude Code のプラグイン `mdmark` の MCP サーバー（`plugin:mdmark:mdmark`）が出すツールの一覧。
入れ方は [プラグインを入れる](../使い方/ClaudeCodeで使う/プラグインを入れる.md)、使い方は [MCP のツールを使う](../使い方/ClaudeCodeで使う/MCPのツールを使う.md)。
ツールの結果のテキストは、`read_guide` を除いて JSON の文字列 1 つ。
エラーは結果の `isError` を `true` にし、内容のテキストに、何が合わないかと直し方を日本語の 1 文で書く。
`config` を省くと、Claude Code のセッションのフォルダから上のフォルダへ順に `mdmark.config.yaml` を探す。
相対パスの引数は、セッションのフォルダからの相対パス。
設定のキーは [設定](./設定.md)、索引のキーは [索引](./索引.md)。

## 一覧

| 名前 | ツール | 説明 |
| --- | --- | --- |
| [使い方集を読む](#使い方集を読む) | `read_guide` | 使い方集の索引の名前ごとに、本文を返す |
| [文書を HTML に書き出す](#文書を-html-に書き出す) | `export_html` | `mdmark export` と同じ処理で、Markdown を 1 つ、1 枚の HTML に書き出す |
| [複数の文書を 1 枚の HTML にまとめる](#複数の文書を-1-枚の-html-にまとめる) | `build_site` | `mdmark build` と同じ処理で、設定の `build` の文書を 1 枚にまとめる |
| [設定と索引を点検する](#設定と索引を点検する) | `check` | `mdmark check` と同じ点検をして、ずれの一覧を返す |
| [文書を探す](#文書を探す) | `find_docs` | 設定の `index` の索引から、条件に当たる文書を返す |
| [索引を書き換える](#索引を書き換える) | `update_index` | 索引の文書か用語の項目を置き換え、足し、消す |

## 使い方集を読む

使い方集の索引の名前ごとに、索引の行が指すページの本文を返す。
索引の名前は、セッションの開始で渡る使い方集の索引にある。

### リクエスト

```json
{ "names": ["notation", "extension"] }
```

| フィールド | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `names` | 必須 | 読む使い方集の名前の並び。1 件以上。重なりは 1 つにまとめる |

### レスポンス

名前 1 つにつきテキストを 1 つ、渡した名前の順に返す。
テキストの 1 行目は `# {名前}`、空行を挟んでその名前が指すページの本文（Markdown）。

### エラー

| 発生条件 | 内容 |
| --- | --- |
| 渡した名前のうち 1 つでも索引に無い | 無い名前と、近い名前（3 件まで）。本文は 1 件も返さない |
| 渡した名前の本文の合計が 50,000 文字を超える | 名前ごとの文字数と、名前を分けて呼ぶこと。本文は 1 件も返さない |

## 文書を HTML に書き出す

`mdmark export` と同じ処理で、Markdown を 1 つ、外へ要求しない 1 枚の HTML に書き出す。
出力のパスにある HTML は上書きする。
手順は [文書を書き出す](../使い方/書き出す/文書を書き出す.md)。

### リクエスト

```json
{ "file": "docs/guide.md" }
```

| フィールド | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `file` | 必須 | 書き出す Markdown のパス |
| `out` | 任意 | 書き出す HTML のパス。省くと、文書と同じフォルダの拡張子を `.html` にしたパス |
| `config` | 任意 | 使う設定ファイルのパス |

### レスポンス

```json
{ "out": "/home/user/docs/guide.html", "warnings": [] }
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `out` | 文字列 | 書き出した HTML の絶対パス |
| `warnings` | 文字列の並び | `mdmark export` が標準エラーに出す警告の文 |

### エラー

| 発生条件 | 内容 |
| --- | --- |
| `file` のファイルが無い | 無いパス。HTML は書かない |
| 設定ファイルが無い・読めない、書き出せない | `mdmark export` が終了コード 1 で終わるときと同じ文 |

## 複数の文書を 1 枚の HTML にまとめる

`mdmark build` と同じ処理で、設定の `build` の文書を、行き来できる 1 枚の HTML にまとめる。
`build.out` の HTML は上書きする。
手順は [文書を1枚にまとめる](../使い方/書き出す/文書を1枚にまとめる.md)。

### リクエスト

```json
{}
```

| フィールド | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `config` | 任意 | 使う設定ファイルのパス |

### レスポンス

```json
{ "out": "/home/user/docs/dist/docs.html", "docs": 2, "warnings": [] }
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `out` | 文字列 | 書き出した HTML の絶対パス |
| `docs` | 数値 | 入れた文書の数 |
| `warnings` | 文字列の並び | `mdmark build` が標準エラーに出す警告の文（切れた参照など） |

### エラー

| 発生条件 | 内容 |
| --- | --- |
| 設定に `build` が無い | `mdmark build` が終了コード 1 で終わるときと同じ文。HTML は書かない |
| 設定ファイルが無い・読めない、`include` に当たる文書が 0 件、書き出せない | 同上 |

## 設定と索引を点検する

`mdmark check` と同じ点検をして、ずれの一覧を返す。
設定・索引・文書は書き換えない。
手順は [点検する](../使い方/書き出す/点検する.md)。

### リクエスト

```json
{}
```

| フィールド | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `config` | 任意 | 使う設定ファイルのパス |

### レスポンス

```json
{ "issues": [{ "file": "index.yaml", "where": "docs[1].path", "kind": "missing_doc", "message": "`old.md` が見つかりません。文書を戻すか、索引の `docs[1]` を消してください。" }] }
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `issues[].file` | 文字列 | ずれのあるファイル。設定ファイルのあるフォルダからの相対パス |
| `issues[].where` | 文字列 | 行かキーのパス。無いときは空の文字列 |
| `issues[].kind` | 文字列 | ずれの種類。意味は [CLI](./CLI.md#設定と索引を点検する) |
| `issues[].message` | 文字列 | 何が合わないかと直し方の 1 文 |

ずれがあってもエラーにせず、`issues` に並べる。
並びは `mdmark check` の出力の行の並びと同じ。

### エラー

| 発生条件 | 内容 |
| --- | --- |
| 設定ファイルが無い | 探した場所と、`mdmark init` で置けること |
| 設定ファイルを YAML として読めない | 読めない行 |

## 文書を探す

設定の `index` の索引から、題・別名・概要の語、タグ、関係する文書で文書を引く。
索引と文書は書き換えない。

### リクエスト

```json
{ "text": "構成", "tags": ["設計"] }
```

| フィールド | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `text` | 任意 | 題・別名・概要のどれかに含まれる語。大文字と小文字を区別しない |
| `tags` | 任意 | 全てを持つ文書に絞るタグ |
| `related_to` | 任意 | この文書の ID から参照している文書と、この文書を参照している文書（被参照）に絞る |
| `config` | 任意 | 使う設定ファイルのパス |

渡した条件を全て満たす文書を、索引の `docs` の並びで返す。
条件を 1 つも渡さないと、全ての文書を返す。

### レスポンス

```json
{ "docs": [{ "id": "arch", "path": "設計/arch.md", "title": "アーキテクチャ", "description": "全体の構成と依存の向き", "tags": ["設計"] }] }
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `docs[].id` | 文字列 | 文書の ID |
| `docs[].path` | 文字列 | 文書のパス。索引のファイルからの相対パス |
| `docs[].title` | 文字列 | 題 |
| `docs[].description` | 文字列か null | 概要。索引に無いときは `null` |
| `docs[].tags` | 文字列の並び | タグ |

当たる文書が 0 件でも、空の `docs` を返す。

### エラー

| 発生条件 | 内容 |
| --- | --- |
| 設定に `index` が無い | 設定に `index` が無いことと、`index` に索引のファイルを書くこと |
| 設定ファイルが無い・読めない、索引のファイルを読めない | 設定と索引を点検するときと同じ文 |

## 索引を書き換える

設定の `index` の索引の、文書か用語の ID の項目を置き換える。
ID の項目が無ければ、その一覧の末尾に追加する。
`item` が `null` なら、その ID の項目を消す。
索引のファイルを書き換える。
手順は [索引と用語集を書く](../使い方/書く/索引と用語集を書く.md)。

### リクエスト

```json
{ "kind": "doc", "id": "b", "item": { "path": "b.md", "title": "文書 B", "tags": ["設計"] } }
```

| フィールド | 必須 / 任意 | 説明 |
| --- | --- | --- |
| `kind` | 必須 | 書き換えるのが文書（`doc`）か用語（`term`）か。文書と用語の ID は、それぞれの一覧の中でだけ一意 |
| `id` | 必須 | 文書か用語の ID。空にできない |
| `item` | 必須 | その ID の項目の中身（`id` を除くキー）。項目ごと置き換える。`null` なら項目を消す。キーは [索引](./索引.md) の文書・用語 |
| `config` | 任意 | 使う設定ファイルのパス |

### レスポンス

```json
{ "action": "added", "index": "index.yaml" }
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `action` | 文字列 | `added`（追加した）・`replaced`（置き換えた）・`removed`（消した） |
| `index` | 文字列 | 書き換えた索引のファイルのパス。設定ファイルのあるフォルダからの相対パス |

渡した ID の項目の前後の項目と、ほかのキーは書き換えない。
書き換えた後の索引全体を、`mdmark check` が使う索引のスキーマの検査に通す。
索引と文書のずれは検査しない。

### エラー

| 発生条件 | 内容 |
| --- | --- |
| 書き換えた後の索引がスキーマに合わない | `{場所}: {内容}` の行を、合わないところの数だけ。索引のファイルは書き換えない |
| `item` が `null` で、その ID の項目が無い | その ID が一覧に無いこと |
| 設定ファイルが無い・読めない、設定に `index` が無い、索引のファイルを読めない | 何も書かない |
