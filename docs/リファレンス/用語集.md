# 用語集

印・記法・テーマ・機能・知らせの枠・書き方の警告の用語の意味

mdmark の公開ドキュメントで使う用語の一覧。

## 一覧

<!-- table: data -->

| 用語 | 意味 | 詳細 |
| --- | --- | --- |
| 印 | 文書に書く `<!-- 名前: 引数 -->` の形の HTML コメント（引数の無い印は `<!-- 名前 -->`）。名前は英小文字で始まり、英小文字・数字・`-` だけを持ち、引数は空白で区切る。コードブロックと行内のコードの中は印として扱わない。描いた本文には残らない | [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md) |
| 印の場所 | 外部ライブラリの印を置き換えた要素。外部ライブラリのモジュールが描く先になる | [外部ライブラリの対応表](./設定.md#外部ライブラリの対応表) |
| 対応表 | 印の名前から、外部ライブラリのモジュールの URL を引く表。mdmark が持つ既定に、設定の `libraries` を重ねる | [外部ライブラリの対応表](./設定.md#外部ライブラリの対応表) |
| 機能 | mdmark の働きのうち、オン・オフを決められるもの。設定の `features` が既定を決め、文書の印がその文書だけ上書きする | [機能をオン・オフする](../使い方/カスタマイズ/機能をオン・オフする.md) |
| テーマ | 描いた文書の見た目。`--mdmark-` で始まる CSS 変数と、`@layer mdmark` に入れた mdmark の CSS で決まる | [テーマを上書きする](../使い方/カスタマイズ/テーマを上書きする.md) |
| 層 | mdmark の CSS を入れる `@layer mdmark`。使う側が層の外に書いた CSS は、詳細度によらず層の中の mdmark の CSS に勝つ | [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md) |
| 読み込み中の枠 | 外部ライブラリを読み込んでいる間、印の場所に出す破線の枠。`図を読み込んでいます` と出し、図の高さを先に取る | [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md) |
| 知らせの枠 | 外部ライブラリや拡張のモジュールを読めない印の場所に出す枠。題は `この図を表示できません`（図でない印は `この箇所を表示できません`）で、本文に読めなかった印の名前と直し方を書く | [文書を描く](./API.md#文書を描く) |
| 範囲の印 | `<!-- 名前: 引数 -->` 〜 `<!-- /名前 -->` で本文を囲む印。閉じの印は `<!-- /名前 -->`。印に対応しない表示では印が見えず、囲んだ Markdown がそのまま読める | [記法](./記法.md) |
| 記法 | 印や書き方で、表・注意書き・タブなどの表示を付けるもの。記法ごとに機能としてオン・オフできる | [記法](./記法.md) |
| 表の種類 | 表の印に書く `data`・`plain`。種類ごとに並べ替え・ピン止め・絞り込みの機能が決まり、囲まない表は既定の種類になる | [表](./記法.md#表) |
| 注意書き | 1 行目が `[!NOTE]` などの引用を、種類ごとの題・色・アイコンを持つ枠にしたもの。末尾に `-` を付けると閉じた折り畳みになる | [注意書き](./記法.md#注意書き) |
| タブ | `<!-- tabs -->` の範囲を、見出しの文字をタブ名にして切り替えて見せるもの | [タブ](./記法.md#タブ) |
| ステップ | 番号付きリストを、番号と項目をつなぐ線を持つ手順にしたもの | [ステップ](./記法.md#ステップ) |
| ファイルツリー | 言語 `tree` のコードブロックの罫線を、フォルダとファイルの入れ子のツリーにしたもの | [ファイルツリー](./記法.md#ファイルツリー) |
| バッジ | 頭に `badge\:` を付けた行内のコードを、頭を外した文言の札にしたもの | [バッジ](./記法.md#バッジ) |
| 節の開閉 | 見出し（h2〜h4）の節を、見出しから開閉すること。見出しの直後の `section` の印で、閉じた状態で始められる | [節の開閉](./記法.md#節の開閉) |
| 行の詳細 | 表の行の下に開閉して出す詳細。表の直後の `row-detail` の範囲に書く | [行の詳細](./記法.md#行の詳細) |
| 図表の番号 | `fig` の印の直後の図と表に付ける、種類ごとの通し番号（`図 1`・`表 1`） | [図と表の番号](./記法.md#図と表の番号) |
| 拡張 | 使う側が `registerExtension` で足す印。文書に印があるときだけ、モジュールを読んで印の場所に描かせる | [拡張を登録する](./API.md#拡張を登録する) |
| 書き方の警告 | 記法の印や拡張の引数に読めない指定がある箇所に出す、題 `書き方の警告` の枠。読めた指定で本文を描き、読めない指定と直し方を書く | [書き方の警告](./記法.md#書き方の警告) |

<!-- /table -->
