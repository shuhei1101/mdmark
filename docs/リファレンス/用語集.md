# 用語集

印・テーマ・機能・知らせの枠の用語の意味

mdmark の公開ドキュメントで使う用語の一覧。

## 一覧

<!-- table: data -->

| 用語 | 意味 | 詳細 |
| --- | --- | --- |
| 印 | 文書に書く `<!-- 名前: 引数 -->` の形の HTML コメント。名前は英小文字で始まり、英小文字・数字・`-` だけを持ち、引数は空白で区切る。コードブロックと行内のコードの中は印として扱わない。描いた本文には残らない | [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md) |
| 印の場所 | 外部ライブラリの印を置き換えた要素。外部ライブラリのモジュールが描く先になる | [外部ライブラリの対応表](./設定.md#外部ライブラリの対応表) |
| 対応表 | 印の名前から、外部ライブラリのモジュールの URL を引く表。mdmark が持つ既定に、設定の `libraries` を重ねる | [外部ライブラリの対応表](./設定.md#外部ライブラリの対応表) |
| 機能 | mdmark の働きのうち、オン・オフを決められるもの。設定の `features` が既定を決め、文書の印がその文書だけ上書きする | [機能をオン・オフする](../使い方/カスタマイズ/機能をオン・オフする.md) |
| テーマ | 描いた文書の見た目。`--mdmark-` で始まる CSS 変数と、`@layer mdmark` に入れた mdmark の CSS で決まる | [テーマを上書きする](../使い方/カスタマイズ/テーマを上書きする.md) |
| 層 | mdmark の CSS を入れる `@layer mdmark`。使う側が層の外に書いた CSS は、詳細度によらず層の中の mdmark の CSS に勝つ | [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md) |
| 読み込み中の枠 | 外部ライブラリを読み込んでいる間、印の場所に出す破線の枠。`図を読み込んでいます` と出し、図の高さを先に取る | [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md) |
| 知らせの枠 | 外部ライブラリを読めない印の場所に出す枠。題は `この図を表示できません`（図でない印は `この箇所を表示できません`）で、本文に読めなかった印の名前と直し方を書く | [文書を描く](./API.md#文書を描く) |

<!-- /table -->
