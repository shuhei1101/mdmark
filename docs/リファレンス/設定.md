# 設定

設定のキーと既定の一覧

`mdmark.config.yaml` に書くキーの一覧。
mdmark はブラウザで YAML を読まない。
使う側のサーバーが `mdmark.config.yaml` を読んだオブジェクトを、`mount` と `render` の `opts.config` に渡す（[文書を描く](./API.md#文書を描く)）。
どのキーも省ける。省いたキーには既定を当てる。
設定の形の正は、リポジトリの `schemas/mdmark.config.schema.json`（JSON Schema）に置く。
この一覧のキーは全て Schema が検め、この一覧にないキーを書いても、mdmark は読まず、Schema も拒まない。
CLI は `mdmark.config.yaml` を自分で読んで、書き出しに使う（[CLI](./CLI.md)）。
`theme`・`extensions`・`build`・`check` は CLI だけが読み、`mount` と `render` は読まない。
`version` は `mdmark upgrade` だけが読む。

## 機能の既定

機能ごとのオン・オフの既定を決める。
文書の `<!-- features: +機能 -機能 -->` が、その文書だけ上書きする（優先順は [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md)）。

| 項目 | 内容 |
| --- | --- |
| 型 | キーが機能名、値が真偽値のオブジェクト |
| 既定 | `comments` を除く全ての機能が `true` |
| 許す値 | 値は `true` か `false`。知らない機能名と、真偽値でない値は無視する |

```yaml
features:
  print: false
```

見え方は [印刷する](../使い方/カスタマイズ/印刷する.md)。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `true` |

## 用語の機能

オフのときは、本文の用語に下線を付けず、用語集の表を普通の表として描く（表の印は取り除き、書き方の警告も出さない）。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `true` |

## 被参照の機能

文書の末尾に被参照の一覧を置き、索引の文書の `aliases` に一致した本文の語にも下線とツールチップの「関連文書」を付ける。
オフのときは、末尾の一覧を出さず、文書の別名にだけ一致する語に下線を付けず、ツールチップから「関連文書」の区分を外す。
参照の表を作るときも、`backlinks` がオフの文書は参照元にも参照先にもならない（[参照の表を作る](./API.md#参照の表を作る)）。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `true` |

```yaml
features:
  glossary: false
  backlinks: false
```

## コメントの機能

読む人が本文の選んだ箇所にコメントを付けられるようにする。
使う側が `mount` にコメントの読み書きの関数（`opts.commentStore`）と `opts.docId` を渡したときだけ効く（[文書を描く](./API.md#文書を描く)）。
オフのときは、文字を選んでもコメントのボタンを出さず、読み書きの関数の `load` も呼ばない。
オンで読み書きの関数を渡さないときは、ボタンを出さず、`console.error` に読み書きの関数が要ることを 1 回だけ出す。
書き方は [ビューとコメントを使う](../使い方/書く/ビューとコメントを使う.md)。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `false` |
| 既定がオフの理由 | コメントは使う側の保存先が要り、使わない文書で文字を選ぶたびにボタンを出さないため |

```yaml
features:
  comments: true
```

## 外部ライブラリの対応表

印の名前から、外部ライブラリのモジュールの URL を引く。
mdmark が持つ既定の対応表に重ね、同じ名前は URL を上書きし、対応表に無い名前は足す。
この版は既定の対応表を持たない。
足した名前の印は図の印として扱い、読めないときの知らせの枠の題は `この図を表示できません` になる。

| 項目 | 内容 |
| --- | --- |
| 型 | キーが印の名前、値が URL の文字列のオブジェクト |
| 既定 | `{}` |
| 許す値 | キーは英小文字で始まり、英小文字・数字・`-` だけを持つ。値は文字列の URL で、相対 URL はページの `document.baseURI` を基準に解決する。書式に合わないキーと、文字列でない値は無視する |

```yaml
libraries:
  my-chart: /assets/my-chart.js
```

モジュールは、`draw(slot, args)` を名前付きで export する。
`slot` は印の場所の要素、`args` は印の引数を空白で区切った文字列の配列で、`draw` は同期でも `Promise` を返す非同期でもよい。
文書に `<!-- my-chart: a b -->` と書くと、`slot` と `["a", "b"]` を渡して `draw` を呼ぶ。

## 色分けのライブラリの読み込み先

コードブロックの色分けに使うライブラリ（highlight.js）の `es/` フォルダの URL を書く。
本体を `{url}core.min.js`、言語を `{url}languages/{言語}.min.js` から読む。
`libraries` とは別のキーで、文書に印を書かせない。
`mount` が読み、`render` は読まない。
CLI は `mdmark.config.yaml` のあるフォルダを基準に相対パスを解決し、書き出す HTML に使う言語の分だけを埋める（[文書を書き出す](../使い方/書き出す/文書を書き出す.md)）。

| 項目 | 内容 |
| --- | --- |
| 型 | 文字列 |
| 既定 | `https://cdn.jsdelivr.net/npm/@highlightjs/cdn-assets@11.12.0/es/` |
| 許す値 | 末尾が `/` の URL かパス。`mount` は相対パスをページの `document.baseURI` を基準に解決し、文字列でない値を無視して既定を当てる。CLI は文字列でない値を設定ファイルの誤りにする |

```yaml
syntax:
  url: /vendor/highlightjs/es/
```

差し替える先には、`@highlightjs/cdn-assets` の `es/` フォルダをそのまま置く。
色分けのオン・オフは `features.syntax`（[記法の機能](#記法の機能)）で決める。

## ツールチップを出す場所

用語・図・ヒントのツールチップを、持ち主（下線の語・線のラベル・箱やヒントの印）の上と下のどちらに先に出すかを決める。
`top` は上に出し、上に収まらないときだけ下に出す。
`bottom` は下に出し、下に収まらず上に収まるときだけ上に出す。
`mount` が読み、`render` は読まない。

| 項目 | 内容 |
| --- | --- |
| 型 | `top` か `bottom` の文字列 |
| 既定 | `top` |
| 許す値 | `top`・`bottom`。`mount` は他の値を無視して `top` にし、CLI は他の値を設定ファイルの誤りにする |

```yaml
tooltips:
  placement: bottom
```

## 索引の場所

索引の YAML のパスを書く。
パスは、`mdmark.config.yaml` のあるフォルダからの相対パスで書く。
索引の文書の `path` は、この索引のファイルのあるフォルダからの相対パスで書く（[索引](./索引.md#文書)）。
mdmark はブラウザでファイルを読まず、`mount` と `render` もこのキーを読まない。
使う側のサーバーがこのパスの YAML を読み、読んだオブジェクトと描く文書の `id` を `opts.index`・`opts.docId` に渡す（[文書を描く](./API.md#文書を描く)）。
索引の形は [索引](./索引.md)。
CLI はこのパスの索引と、索引の文書を読み、参照の表を作って書き出しに埋める。

| 項目 | 内容 |
| --- | --- |
| 型 | 文字列 |
| 既定 | なし。省くと索引を渡さない文書と同じに描く |

```yaml
index: docs/index.yaml
```

## 使う側の CSS

CLI が書き出す HTML に、配布物の CSS の後で埋める使う側の CSS のパスを書く。
パスは、`mdmark.config.yaml` のあるフォルダからの相対パスで書く。
手順は [文書を書き出す](../使い方/書き出す/文書を書き出す.md)。

| 項目 | 内容 |
| --- | --- |
| 型 | 文字列 |
| 既定 | なし。使う側の CSS を埋めない |
| 許す値 | ファイルのパス。読めないときは書き出しを止めず、警告に出す |

```yaml
theme: theme.css
```

## 拡張のモジュール

CLI が書き出す HTML に束ねて埋め、描く前に `registerExtension` で登録する拡張のモジュールのパスを並べる。
各モジュールは、`registerExtension` に渡す拡張を既定の export にする（拡張の形は [拡張を登録する](./API.md#拡張を登録する)）。
`mdmark check` はモジュールを Node で読み込んで `directive` を取るため、読み込みの時点でブラウザの API（`HTMLElement`・`window` など）を使わず、使うのは `load` の中だけにする。
パスは、`mdmark.config.yaml` のあるフォルダからの相対パスで書く。

| 項目 | 内容 |
| --- | --- |
| 型 | 文字列の配列 |
| 既定 | `[]`。拡張を埋めず、拡張の印は知らない印として取り除かれる |
| 許す値 | TypeScript か JavaScript のファイルのパス。読めない・束ねられないものは書き出しを止めず、警告に出す |

```yaml
extensions:
  - extensions/example.ts
```

## まとめる設定

`mdmark build` が 1 枚の HTML にまとめる文書と、書き出す先を決める。
パスと glob は、`mdmark.config.yaml` のあるフォルダからの相対パスで書く。
手順は [文書を1枚にまとめる](../使い方/書き出す/文書を1枚にまとめる.md)。

| 項目 | 内容 |
| --- | --- |
| 型 | オブジェクト |
| 既定 | なし。`mdmark build` は、`build` が無いことを出して終了コード 1 で終わる |

```yaml
build:
  include: ["**/*.md"]
  exclude: ["下書き/**"]
  glossary: ["用語集.md"]
  entry: README.md
  out: dist/docs.html
```

<!-- table: data -->

| キー | 型 | 必須 | 既定 | 説明 |
| --- | --- | --- | --- | --- |
| `build.include` | 文字列の配列 | 必須 | なし | まとめる Markdown の glob。`**`・`*`・`?` を使え、当たるのは拡張子 `.md` のファイルだけ。1 つ以上書く。文書は glob の並びで並べ、同じ glob の中はパスの順に並べ、重なりは最初の 1 つだけを残す |
| `build.exclude` | 文字列の配列 | 任意 | `[]` | `include` に当たった文書から外す glob。書き方は `include` と同じ |
| `build.glossary` | 文字列の配列 | 任意 | `[]` | 用語集の表（`glossary` の印）を持つ文書のパス。表の用語を、まとめた全ての文書で効かせる。索引が無いときも効く。まとめる文書に当たらないパスは、`mdmark check` で `schema` のずれにし、`mdmark build` では飛ばして警告に出す |
| `build.entry` | 文字列 | 任意 | `include` で最初に当たった文書 | 開いたとき、URL の `#` が文書を指していないときに出す文書のパス。まとめる文書に当たらないときは、`mdmark check` で `schema` のずれにし、`mdmark build` では既定を当てて警告に出す |
| `build.out` | 文字列 | 必須 | なし | まとめた HTML を書くパス。拡張子 `.html` で書く。既にあれば上書きし、親のフォルダが無ければ作る |

<!-- /table -->

`build.include` と `build.out` が無いと、`mdmark build` は終了コード 1 で終わり、`mdmark check` は `schema` のずれにする。

## 点検から外す名前

`mdmark check` が文書の本文の知らない印として知らせない、印と同じ書き方の HTML コメントの名前を並べる。
`<!-- prettier-ignore -->`・`<!-- markdownlint-disable -->` のような他のツールへの指示を書いた文書で使う。

| 項目 | 内容 |
| --- | --- |
| 型 | 文字列の配列 |
| 既定 | `[]`。印に当たらない名前を全て知らない印として知らせる |
| 許す値 | 英小文字で始まり、英小文字・数字・`-` が続く名前。合わないと `mdmark check` は `schema` のずれにする |

```yaml
check:
  ignore:
    - prettier-ignore
    - markdownlint-disable
```

## 手元の版

この設定・索引・文書が合わせてある mdmark の版を書く。
`mdmark init` が呼んだ CLI の版を書き、`mdmark upgrade` が移行の手順を当てて点検が通った後に、呼んだ CLI の版へ書き換える。
手順は [版を上げる](../使い方/導入/版を上げる.md)。
`mount`・`render`・`export`・`build`・`check` は、値で振る舞いを変えない。

| 項目 | 内容 |
| --- | --- |
| 型 | 文字列 |
| 既定 | なし。`mdmark upgrade` が手元の版を聞く（v0.3.0 までの `init` が置いた設定） |
| 許す値 | `v{MAJOR}.{MINOR}.{PATCH}` の形。合わないと `mdmark check` は `schema` のずれにする |

```yaml
version: v0.4.0
```
