# 設定

設定のキーと既定の一覧

`mdmark.config.yaml` に書くキーの一覧。
mdmark はブラウザで YAML を読まない。
使う側のサーバーが `mdmark.config.yaml` を読んだオブジェクトを、`mount` と `render` の `opts.config` に渡す（[文書を描く](./API.md#文書を描く)）。
どのキーも省ける。省いたキーには既定を当てる。
JSON Schema は、リポジトリの `schemas/mdmark.config.schema.json` に置く。
この一覧にないキーを書いても、mdmark は読まず、Schema も拒まない。

| --- | --- | --- |

| [印刷の機能](#印刷の機能) | `features.print` | 印刷の前に閉じた折り畳みとタブ・閉じた節・行の詳細を開き、印刷の後に戻す |
| [記法の機能](#記法の機能) | `features.table` ほか | 記法ごとのオン・オフ |

## 機能の既定

機能ごとのオン・オフの既定を決める。
文書の `<!-- features: +機能 -機能 -->` が、その文書だけ上書きする（優先順は [文書を描く仕組み](../はじめに/コアコンセプト/文書を描く仕組み.md)）。

| 項目 | 内容 |
| --- | --- |
| 型 | キーが機能名、値が真偽値のオブジェクト |
| 既定 | 全ての機能が `true` |
| 許す値 | 値は `true` か `false`。知らない機能名と、真偽値でない値は無視する |

```yaml
features:
  print: false
```

## 印刷の機能

印刷の前に閉じた折り畳みと、タブ・閉じた節・行の詳細を開き、印刷の後に印刷の前の開閉へ戻す。
見え方は [印刷する](../使い方/カスタマイズ/印刷する.md)。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `true` |

## 記法の機能

記法ごとにオン・オフを決める。
オフにした記法は、書いた Markdown を普通の Markdown として描く。
書き方は [記法](./記法.md)。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `true` |

```yaml
features:
  table: false
  callout: false
```

## 用語の機能

索引の用語と用語集の表の用語に、破線の下線と意味のツールチップを付ける。
書き方は [索引と用語集を書く](../使い方/書く/索引と用語集を書く.md)。
オフのときは、本文の用語に下線を付けず、用語集の表を普通の表として描く（表の印は取り除き、書き方の警告も出さない）。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `true` |

## 被参照の機能

文書の末尾に被参照の一覧を置き、索引の文書の `aliases` に一致した本文の語にも下線とツールチップの「関連文書」を付ける。
オフのときは、末尾の一覧を出さず、文書の別名にだけ一致する語に下線を付けず、ツールチップから「関連文書」の区分を外す。
参照の表を作るときも、`backlinks` がオフの文書は参照元にも参照先にもならない（[参照の表を作る](./API.md#参照の表を作る)）。

| 項目 | 内容 |
| --- | --- |
| 型 | 真偽値 |
| 既定 | `true` |

```yaml
features:
  glossary: false
  backlinks: false
```

## 外部ライブラリの対応表

印の名前から、外部ライブラリのモジュールの URL を引く。
mdmark が持つ既定の対応表に重ね、同じ名前は URL を上書きし、対応表に無い名前は足す。
この版は既定の対応表を持たない。
足した名前の印は図の印として扱い、読めないときの知らせの枠の題は `この図を表示できません` になる。

| 項目 | 内容 |
| --- | --- |
| 型 | キーが印の名前、値が URL の文字列のオブジェクト |
| 既定 | `{}` |
| 許す値 | キーは英小文字で始まり、英小文字・数字・`-` だけを持つ。値は文字列の URL で、相対 URL はページの `document.baseURI` を基準に解決する。書式に合わないキーと、文字列でない値は無視する |

```yaml
libraries:
  my-chart: /assets/my-chart.js
```

モジュールは、`draw(slot, args)` を名前付きで export する。
`slot` は印の場所の要素、`args` は印の引数を空白で区切った文字列の配列で、`draw` は同期でも `Promise` を返す非同期でもよい。
文書に `<!-- my-chart: a b -->` と書くと、`slot` と `["a", "b"]` を渡して `draw` を呼ぶ。

## 索引の場所

索引の YAML のパスを書く。
パスは、`mdmark.config.yaml` のあるフォルダからの相対パスで書く。
索引の文書の `path` は、この索引のファイルのあるフォルダからの相対パスで書く（[索引](./索引.md#文書)）。
mdmark はブラウザでファイルを読まず、`mount` と `render` もこのキーを読まない。
使う側のサーバーがこのパスの YAML を読み、読んだオブジェクトと描く文書の `id` を `opts.index`・`opts.docId` に渡す（[文書を描く](./API.md#文書を描く)）。
索引の形は [索引](./索引.md)。

| 項目 | 内容 |
| --- | --- |
| 型 | 文字列 |
| 既定 | なし。省くと索引を渡さない文書と同じに描く |

```yaml
index: docs/index.yaml
```
