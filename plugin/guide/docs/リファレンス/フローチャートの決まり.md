# フローチャートの決まり

処理の順番を描くフローチャートの見た目の決まり（時系列・ループの帯・分岐）

処理の順番や時刻の流れを描く、シーケンス図とフロー図が守る決まり。
ノード・線・タイトルと凡例・交差・ツールチップ・操作は 構成図の決まり（read_guide の architecture-style） と同じ。

## 時系列

- 時系列は左から右。シーケンス図は、相手を定義の順に左から右へ、メッセージを時刻の順に上から下へ並べる
- 相手のノードの色とアイコンは、フロー図のノードの種類と同じ
- 拡大して下へ動かしても、相手の行は表示する枠の上端に留める
- 呼ぶ線は実線と塗った矢じり、返す線は破線と開いた矢じりで分ける

## ループの戻り

- ループの戻りは、上か下の 1 本の帯だけを通す。シーケンス図は右の帯を通す
- 戻りの線は破線（`loop`）にし、戻り先のラベルを付ける（例 `1 へ戻る（次の問い合わせ）`）
- 戻りの線で、ほかの線を横切る箇所を増やさない。横切るときは横の線が縦の線を飛び越える

## 分岐

- 分岐は、1 つのノードから複数の線を出し、線のラベルに分かれる条件を書く
- 分かれた線は、どれも処理の流れ（`flow`）にし、線のラベルの条件で見分ける。色や模様で分けない
- 分かれた先から戻るときは、ループの帯を通す
