# mdmark

Markdown 文書の表示（拡張記法・図・差分・部品）を各アプリで共通に使用するライブラリ

ドキュメント: https://shuhei1101.github.io/mdmark/

CDN を読み込めない環境へは、CLI で Markdown を 1 枚で完結する HTML に書き出して配る: [書き出す](./docs/guide/使用方法.md)

図・部品を文書に部品の定義で描く: [図を描く](./docs/guide/使用方法.md)

VS Code で Markdown のプレビューを出し、HTML・PDF にする拡張機能: [VS Code で確認する](./docs/guide/使用方法.md)

バージョンを上げるときは、CLI で移行の手順を適用する: [バージョンを上げる](./docs/guide/導入-バージョンを上げる.md)

mdmark の記法で記載する文書の拡張子は `.mark.md`（`hoge.mark.md`）にし、純粋な Markdown（`.md`）と分ける: [文書の記載方法](./docs/guide/記載する-文書の記載方法.md)

Claude Code にガイドへの動線と書き出し・点検のツールを指定する: [Claude Code で使用する](./docs/guide/使用方法.md)
