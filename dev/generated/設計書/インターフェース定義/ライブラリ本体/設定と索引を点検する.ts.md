# 設定と索引を点検する

> 種類: operation<br>
> 値: `mdmark check [--config {設定ファイル}]`（CLI。`npx github:shuhei1101/mdmark#v{版} check` で呼ぶ）<br>

文書を書く人が、設定ファイルの形・索引と文書のずれ（`checkIndex`）・`build` の対象の有無を点検し、ファイル・場所・種類・内容の一覧を受け取る。点検は設定・索引・文書を書き換えない。

- dev/設計書/シナリオ/単一ユースケース/設定と索引を点検する#

## リクエスト

| パラメータ | 型 | 必須 | デフォルト | 置き場所 | 説明 | 例 |
| --- | --- | --- | --- | --- | --- | --- |
| --config | string | - | なし（今のフォルダから上のフォルダへ順に `mdmark.config.yaml` を探し、最初に見つかったものを使う） | argument | 使う設定ファイルのパス | docs/mdmark.config.yaml |

## レスポンス

| フィールド | 型 | 説明 | 補足 |
| --- | --- | --- | --- |
| 標準出力 | string | ずれ 1 つを 1 行（`{ファイル}:{場所}: {種類}: {内容}`。場所が空のときは `{ファイル}: {種類}: {内容}`）で並べ、最後に `ずれ {件数} 件` の行を出す | ファイルは設定ファイルのあるフォルダからの相対パス。並びは設定の `schema` → `no_documents` → `checkIndex` が返した並び |
| 種類 | 'schema' \| 'no_documents' \| 'missing_doc' \| 'orphan_doc' \| 'broken_ref' \| 'duplicate_term' | `schema` は設定か索引が Schema に合わない（`build.glossary`・`build.entry` が `include` に当たらないものを含む）、`no_documents` は `build.include` に当たる文書が 0 件。ほかはインターフェース定義『索引を点検する』の `kind` | - |
| 終了コード | 0 \| 1 | ずれが 0 件なら 0、ずれがあるか点検できないときは 1 | - |

```text
docs/index.yaml:docs[1].path: missing_doc: `old.md` が見つかりません。文書を戻すか、索引の `docs[1]` を消してください。
mdmark.config.yaml:build: schema: `build.out` がありません。書き出す HTML のパスを書いてください。
ずれ 2 件
```

## 例外

| 例外 | 発生条件 | 補足 |
| --- | --- | --- |
| なし（正常終了） | ずれが 0 件。終了コード 0 | - |
| なし（ずれがある・終了コード 1） | ずれが 1 件以上ある | 全てのずれを出してから終わる |
| 設定ファイルが無い（終了コード 1） | `--config` のファイルが無い、または今のフォルダと上のフォルダに `mdmark.config.yaml` が無い | 標準エラーに、探した場所と `mdmark init` で置けることを出す |
| 設定ファイルを読めない（終了コード 1） | 設定ファイルを YAML として読めない | 標準エラーに、ファイルと読めない行と直し方を出す |

## 制約

| 項目 | 制約 | 決定値 |
| --- | --- | --- |
| 設定の点検 | `schemas/mdmark.config.schema.json` に合わないところごとに `schema` のずれにする。空の設定ファイル（読んだ値がオブジェクトでない）も `schema` のずれにする。`build.glossary`・`build.entry` がまとめる文書に当たらないものも `schema` のずれにする。`theme`・`extensions` のファイルが無いものも `schema` のずれにする | - |
| 索引の点検 | 設定に `index` があるときだけ行う。索引のフォルダの下の拡張子 `.md` のファイルのうち `build.exclude` に当たらないものを文書として `checkIndex` に渡し、返ったずれをそのまま出す。索引のファイルを読めないときは、索引を指す `schema` のずれにする | dev/設計書/インターフェース定義/ライブラリ本体/索引を点検する.ts# |
| build の対象 | 設定に `build` があるときだけ行う。`include` に当たり `exclude` に当たらない文書が 0 件なら `no_documents` のずれにする | - |
| 内容の文 | ずれごとに、何が合わないかと直し方を日本語の 1 文で書く | - |
| 動く Node の版 | Node 24 以降 | dev/設計書/非機能要件/非機能要件#requirements[CLI が動く Node の版] |
