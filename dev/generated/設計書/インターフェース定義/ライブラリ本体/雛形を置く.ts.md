# 雛形を置く

> 種類: operation<br>
> 値: `mdmark init [{置く先のフォルダ}] [--js]`（CLI。`npx github:shuhei1101/mdmark#v{版} init` で呼ぶ）<br>

文書を書く人が、設定・使う側の CSS・索引・拡張の雛形をフォルダに置く。雛形の正本はリポジトリの `templates/` に置き、既にあるファイルは上書きしない。

tests/integration/lib/init.test.ts

True

置く先のフォルダに、無い雛形のファイルとフォルダを書く

- dev/設計書/シナリオ/単一ユースケース/雛形を置く#

## リクエスト

| パラメータ | 型 | 必須 | デフォルト | 置き場所 | 説明 | 補足 |
| --- | --- | --- | --- | --- | --- | --- |
| {置く先のフォルダ} | string | - | `.`（今のフォルダ） | argument | 雛形を置くフォルダ | 無ければ作る |
| --js | boolean | - | false（TypeScript の拡張の雛形を置く） | argument | 拡張の雛形を JavaScript で置く | `tsconfig.json` と `package.json` を置かない |

## レスポンス

| フィールド | 型 | 説明 | 補足 |
| --- | --- | --- | --- |
| 標準出力 | string | 置いたファイルの行（`置いた: {パス}`）と、既にあって置かなかったファイルの行（`置かなかった（既にある）: {パス}`）を、雛形の並びで 1 行ずつ出す | パスは置く先のフォルダからの相対パス |
| 終了コード | 0 \| 1 | 置けたら（置かなかったファイルがあっても）0、書けなかったら 1 | - |

```text
置かなかった（既にある）: mdmark.config.yaml
置いた: theme.css
置いた: index.yaml
置いた: extensions/example.ts
置いた: tsconfig.json
置いた: package.json
```

## 例外

| 例外 | 発生条件 | 補足 |
| --- | --- | --- |
| なし（正常終了） | 無い雛形を全て書いた（既にあるファイルは置かずに一覧に出す）。終了コード 0 | - |
| 書けない（終了コード 1） | 置く先のフォルダを作れない、またはファイルを書けない | 標準エラーに書けなかったパスと直し方の 1 文を出す。書けたファイルは残す |

## 制約

| 項目 | 制約 | 決定値 | 補足 |
| --- | --- | --- | --- |
| 置く雛形 | `mdmark.config.yaml`（`version`・`index`・`theme`・`build` を書いた設定）・`theme.css`（CSS 変数を上書きする例）・`index.yaml`（文書と用語が 0 件の索引）・`extensions/example.ts`（`registerExtension` に渡す拡張を既定の export にする例）・`tsconfig.json`・`package.json`（拡張の型の検査と JavaScript への変換のコマンド）。`--js` のときは `extensions/example.js` を置き、`tsconfig.json` と `package.json` を置かない | - | 並びはこの順。中身の正本は `templates/` |
| 上書き | 既にあるファイルは中身を読まず、置かずに一覧に出す。上書きの指定は持たない | - | - |
| 置いた設定と索引の形 | 置いた `mdmark.config.yaml` と `index.yaml` は、`schemas/mdmark.config.schema.json` と `schemas/mdmark.index.schema.json` に合う | - | - |
| 動く Node の版 | Node 24 以降 | dev/設計書/非機能要件/非機能要件#requirements[CLI が動く Node の版] | - |
| 設定の版 | 置く `mdmark.config.yaml` の `version` は、ビルドが呼んだ CLI に埋めた版。`templates/mdmark.config.yaml` の `version` の値を置くときに置き換える | dev/設計書/設定/ライブラリ本体#settings[version] | - |
