### E2E テスト

E2E テスト

Playwright（`@playwright/test`）を Chromium と Firefox の 2 つのプロジェクトで流す。ブラウザを使わない『配布物をビルドして検査する』は Chromium のプロジェクトだけで流れ、Firefox の分は skip になる

- `npm ci` で依存を入れ、`npx playwright install chromium firefox` でブラウザを入れてある
- 『配布物をビルドして検査する』が一時フォルダのクローンで `npm ci` を流すため、npm レジストリへの接続が要る

```bash
npm run test:e2e
```

シナリオ

```bash
npx playwright test {シナリオファイルパス}
```

全件で数十秒（作業ツリーのクローンと `npm ci` を含む）

無料。npm レジストリへ接続する。jsDelivr へは接続せず、`page.route()` で手元の応答に差し替える

### 結合テスト（フロント）

結合テスト（フロント）

Vitest の `integration-node`（ビルドの入口を子プロセスで流す・ビルドした配布物を Node で読む）と `integration-browser`（ビルドした配布物を Chromium で読む）と `integration-storybook`（部品の描画の口と Storybook を空きポートで立て、ストーリーを Playwright で開く。起動に約 40 秒）の 3 つで流す

- `npm ci` で依存を入れ、`npx playwright install chromium` で Chromium を入れてある

```bash
npm run test:integration
```

ファイル

```bash
npx vitest run --project 'integration*' {テストファイルパス}
```

### 単体テスト（フロント）

単体テスト（フロント）

Vitest の `unit` プロジェクト（Node）と、DOM を使う `*.browser.test.ts` を流す `unit-browser` プロジェクト（Chromium）で流す

- `npm ci` で依存を入れ、`npx playwright install chromium` で Chromium を入れてある

```bash
npm run test:unit
```

ファイル

```bash
npx vitest run --project 'unit*' {テストファイルパス}
```

```bash
npm test
```

`npm run test:unit` のあとに `npm run test:integration` を流す。E2E は含まない。
