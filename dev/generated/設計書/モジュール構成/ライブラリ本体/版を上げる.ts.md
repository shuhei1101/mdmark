# ライブラリ本体 / 版を上げる

`mdmark upgrade` の処理。版の読み取りと比較、移行の手順の読み取り・検め・適用、写しと戻し、変更履歴の行の抽き出し、標準入力での問いを持ち、`runUpgrade` がこれらと CLI の点検をつなぐ。

- tests/unit/src/cli/versions.test.ts
- tests/unit/src/cli/migrations.test.ts
- tests/unit/src/cli/backup.test.ts
- tests/unit/src/cli/changelog.test.ts
- tests/unit/src/cli/prompt.test.ts
- tests/unit/src/cli/upgrade.test.ts

## ディレクトリ構成

```tree
src/cli/
├── versions.ts    # 版の書式・比較・呼んだ CLI の版
├── migrations.ts  # 移行の手順の読み取り・形の検め・適用
├── backup.ts      # 当てる前の写しと写しからの戻し
├── changelog.ts   # 変更履歴の表から範囲の行を抽き出す
├── prompt.ts      # 標準入力の 1 行を答えにする問い
└── upgrade.ts     # mdmark upgrade
schemas/
└── mdmark.steps.schema.json  # steps.yaml の JSON Schema
migrations/
├── v{版}/        # 出した版の steps.yaml とスクリプト
├── next/          # 出していない版の steps.yaml とスクリプト
└── no-steps.yaml  # 移行の手順が要らないスキーマの変更の一覧
```

## データモデル

### MigrationStep

MigrationStep

移行の手順

src/cli/migrations.ts

版を上げる

`steps.yaml` の `steps` の要素 1 つ。`op` で分けた判別子つきユニオン

#### プロパティ

| プロパティ名 | 型 | デフォルト | 説明 |
| --- | --- | --- | --- |
| op | "rename_key" \| "set_default" \| "map_values" \| "replace_mark" \| "call" | - | 手順の種類。残りのプロパティは種類ごとに ER 図『移行の手順』の必須のとおりに持つ |
| description | string | - | 何をどう変えるかの 1 文 |
| destructive | boolean | false | 壊す印 |
| file | "config" \| "index" | - | `rename_key`・`set_default`・`map_values` が書き換える YAML |
| from | string | - | `rename_key` の元のキーのパス、`replace_mark` の書き換える前の印 |
| to | string | - | `rename_key` の新しいキーのパス、`replace_mark` の書き換えた後の印 |
| key | string | - | `set_default`・`map_values` のキーのパス |
| value | unknown | - | `set_default` が足す値 |
| ask | string | - | `set_default` が値を聞く問いの文 |
| mapping | Record<string, unknown> | - | `map_values` の読み替えの表 |
| script | string | - | `call` のスクリプトの、`steps.yaml` のあるフォルダからの相対パス |
| files | ("config" \| "index" \| "documents")[] | - | `call` が書き換えうるもの |
