# 配布物をビルドして検査する

開発者が、クローンしたリポジトリで依存の導入・lint・型検査・ビルド・テストを順に流し、版を埋めた配布物を `dist/` に得る。

2

tests/e2e/単一ユースケース/配布物をビルドして検査する.spec.ts

mdmark の開発者

リポジトリをクローンした直後か、変更を commit する前

- Node.js v24 が入っている
- リポジトリの直下に `version.ini` がある

`dist/` に ES モジュールの JavaScript と CSS が 1 つずつあり、JavaScript の公開関数がビルドで埋めた版を返す。

ビルドが失敗したときは `dist/` に配布物を残さず、終了コード 0 以外で終わり、足りないものを出す。

sequenceDiagram
  actor D as 開発者
  participant N as npm
  participant B as ビルド
  participant F as dist/
  D->>N: npm ci
  N-->>D: 依存を入れた
  D->>N: E2E のブラウザを入れる

  B-->>D: 終了コード 0
  D->>N: npm test
  N-->>D: 全件 pass

- `dist/index.js` の公開関数が `v0.0.0` を返す
- lint の違反と型エラーが 0 件
- `dist/index.d.ts` があり、公開関数と拡張の型を持つ
