# 雛形を置く

文書を書く人が `mdmark init` を流し、設定・使う側の CSS・索引・拡張のビルドの雛形をフォルダに置く。

9

tests/e2e/単一ユースケース/雛形を置く.spec.ts

文書を書く人

文書を書く人が、mdmark で文書を書き出すフォルダを用意する

- 文書を書く人の手元に Node 24 以降がある

置く先のフォルダに `mdmark.config.yaml`・`theme.css`・索引の雛形・拡張のビルドの雛形があり、置いたファイルの一覧が出る。

既にあるファイルは上書きせず、置かなかったファイルの一覧を出す。

#### 期待値

- `mdmark.config.yaml`・`theme.css`・索引の雛形・拡張のビルドの雛形（tsconfig とビルドのコマンド）がある
- 置いた `mdmark.config.yaml` と索引が、設定と索引の JSON Schema に合う
- 置いた `mdmark.config.yaml` の `version` が、呼んだ CLI の版
- 出力に置いたファイルの一覧が出て、終了コードが 0
