# 設定: ライブラリ本体

使う側が `mdmark.config.yaml` に書く設定のキー。使う側のサーバーが読んだオブジェクトを `mount`・`render` の `opts.config` に渡すか、mdmark の CLI が読んで書き出しに使う。この一覧はライブラリ本体と CLI が読むキーを持ち、形の正を JSON Schema `schemas/mdmark.config.schema.json` に置く。

## ファイル一覧

| ファイル | 管理する値 | 補足 |
| --- | --- | --- |
| mdmark.config.yaml | 機能のオン・オフの既定、外部ライブラリの対応表、索引の場所、CLI の書き出しに埋める CSS と拡張、まとめる文書と書き出す先 | 使う側のリポジトリに置く（`mdmark init` が雛形を置く）。ブラウザの mdmark は YAML を読まず、使う側のサーバーか CLI が読んだオブジェクトを受け取る |
| schemas/mdmark.config.schema.json | `mdmark.config.yaml` のこの一覧の全てのキーの JSON Schema（draft 2020-12）。CLI の設定の検めと、配布物のビルドの移行の手順の点検がこの Schema を正にする | 他の Issue が足すキーを拒まないよう、最上位の `additionalProperties` は許す。形を変えるときは `migrations/next/` に移行の手順か `migrations/no-steps.yaml` の行を置く |
