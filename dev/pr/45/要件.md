# 要件

## 要望

文書を書く人が、Markdown のコードブロックに書いた HTML をその場で描かせ、その中にチャートと、ヒントの出る図を置ける。
読む人は、チャートを拡大・縮小・移動でき、図の要素と埋め込んだ HTML の中の用語・関連資料をツールチップで読める。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| HTML の表示 | `<!-- html -->` 〜 `<!-- /html -->` の範囲に置いた `html` のコードブロックを、コードではなくその場の HTML として描く（D-9）。範囲の外の `html` のコードブロックは今のとおりコードとして出す。機能の名前は `html` で、既定はオン |
| スクリプト | 埋め込んだ HTML に書いたスクリプト・イベントの属性は動かさない（D-22）。動くのは mdmark の部品だけで、今の `render` のサニタイズの条件を保つ |
| チャート | 埋め込んだ HTML の中に、図の部品の custom element（`<mdmark-chart>` など）を置き、中身に部品の定義（JSON）だけを書く。mdmark が #21 の自前の SVG のグラフの部品を広げて、折れ線・棒・円・散布図を描く（D-10・D-22）。外部ライブラリは使わない |
| チャートの拡大・移動 | チャートは拡大・縮小とドラッグでの移動ができる。拡大・縮小は #21 の図の部品と同じく右上のボタンとキーの `+`・`-`・`0` だけで行い、ホイールは文書のスクロールに使う。部品でない普通の HTML には拡大・縮小のボタンを付けない（D-43） |
| `data-hint` のヒント | 埋め込んだ HTML の任意の要素に `data-hint` 属性を書くと、その文がツールチップで出る。ブロックの要素は右上の印、行内の要素は下線の語の上でだけ出し、ポインターの形は変えない（[確認ログ](./確認ログ.md)）。見た目と操作（ホバーとフォーカスで出る・Esc で消える・上に乗っても消えない）は #21 の図のツールチップと同じにする（D-46） |
| 部品の JSON のヒント | 図の部品の定義の `hint`・`io` も同じ見た目のツールチップで出す。要らないときは機能 `hints`（既定はオン）をオフにして、`data-hint`・`hint`・`io`・線の詳細のツールチップをまとめて外せる（D-46） |
| 埋め込んだ HTML の中の用語 | 埋め込んだ HTML の中の文章にも、Markdown の本文と同じ用語集と関連資料のツールチップを出す（D-45） |
| 書き出し | `mdmark export`・`mdmark build` で書き出した 1 枚の HTML でも、埋め込んだ HTML・チャート・ツールチップが外を読まずに同じように動く |
| 完了の基準 | 埋め込んだ HTML・チャート・`data-hint`・部品の JSON のヒント・埋め込んだ HTML の中の用語のツールチップが、`mount` と書き出した HTML の両方で E2E で確かめられ、非機能要件の対応ブラウザで通る |

<!-- /table -->

図の部品の仕組み（文書に部品の定義を書いて描かせる口）と、フロー図・シーケンス図・グラフの部品は #21（[#42](https://github.com/shuhei1101/mdmark/pull/42)）で入っており、この PR はその仕組みに載せる。

HTML を描くコードブロックは、今の記法の印と同じ形の `<!-- html -->` の範囲で見分ける。
今の文書は `html` のコードブロックを書き方の見本として使っており、全てを描くと壊れるため。
印の形にすると、書き方の警告・機能のオン・オフ・印に対応しない表示の扱いを今の記法と同じにできる。

チャートは、外部ライブラリを使わずに #21 の自前の SVG のグラフの部品を広げて描く（ライブラリ選定で決めた）。
#21 の図の枠の拡大・縮小（CSS transform）でぼやけず、色を CSS 変数で直接変えられ、`render` の HTML 文字列にも同じものが出るため。
