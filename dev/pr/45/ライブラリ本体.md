## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| HTML の表示 | 印を付けた `html` のコードブロックの中身を、今の生の HTML と同じサニタイズを通してその場に描く。印の無いコードブロックはコードのまま出す | 印の形は `未確定`（[要件](./要件.md)） |
| スクリプト | `script` 要素とイベントの属性は今のサニタイズのとおり落とし、動くのは mdmark の部品だけにする | D-22 |
| チャート | 埋め込んだ HTML の中のチャートの要素にデータ（JSON）だけを書き、mdmark が描く。ライブラリは今の外部ライブラリの読み込み（印とモジュールの対応表）に載せ、文書が使うときだけ読む | 描き方は `未確定`（[要件](./要件.md)） |
| チャートの操作 | チャートを #21 の図の枠に載せ、右上のボタンとキーの `+`・`-`・`0` の拡大・縮小・ドラッグでの移動・ホイールのスクロールを同じにする。部品でない HTML は図の枠に載せない | D-43 |
| ヒント | `data-hint` を持つ要素と、部品の定義の `hint`・`io` に、#21 の図のツールチップと同じ部品のツールチップを付ける。外すオプションを設定と文書の印で持つ | オプションの置き場所は設計で決める |
| 用語のツールチップ | 埋め込んだ HTML の中の文字にも、用語の下線と用語・関連資料のツールチップを付ける。チャートのキャンバスの中の文字は対象にしない | D-45 |
| 機能のオン・オフ | HTML の表示とヒントを `features` の機能として足し、文書の印で上書きできる今の仕組みに載せる | オフのときはコードブロックのまま出す |
| 書き出し | チャートのライブラリを `mdmark export`・`build` の 1 枚に埋め、外を読まずに動かす | 今の外部ライブラリの埋め込みに載せる |
| 印刷 | 埋め込んだ HTML とチャートを印刷に出し、ツールチップと拡大・縮小のボタンは出さない | - |
| アクセシビリティ | ツールチップは `role="tooltip"`・`aria-describedby` でホバーとフォーカスの両方で出し、Esc で消える。チャートは読み上げの名前を持つ | #21 の図のツールチップと同じ |
| 外部ライブラリ | チャートのライブラリを採るときは、ライセンスと版の固定を外部ライブラリの設計書に書く | - |
| 非機能要件 | チャートのライブラリを足した書き出しのサイズと、配布ファイル 1 つのサイズが上限に収まるかを確かめる | ライブラリは配布物に束ねず、使うときだけ読む |
