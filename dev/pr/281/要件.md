# 要件

## 要望

部品の操作の不具合 3 件を修正する。
子 Issue ごとの終わりの条件は次のとおり。

<!-- table: plain -->

| Issue | 終了条件 |
| --- | --- |
| [#170](https://github.com/shuhei1101/mdmark/issues/170) | タッチ端末で開いた図のツールチップを、外のタップか持ち主のもう一度のタップで閉じられる（マウスのホバーとキーボードの開閉は今のまま） |
| [#267](https://github.com/shuhei1101/mdmark/issues/267) | Firefox で hover で開いた用語のツールチップが同じ文書のリンクを覆わず、E2E『複数の文書を1枚のHTMLにまとめる』の test_normal・test_normal_when_aliases が Firefox でも pass する |
| [#273](https://github.com/shuhei1101/mdmark/issues/273) | E2E『図を拡大・縮小・移動する』の test_normal_when_embedded_chart が、拡大してから余白をドラッグして図が動き、Chromium と Firefox で pass する |

<!-- /table -->

#170 の対象は図のツールチップの持ち主の全て（線のラベル・透明の太い線・箱の右上の印・箱の中の用語）と、同じ開閉を使う埋め込んだ HTML のヒントとする。
タッチのタップで開いたツールチップは、開いている間にツールチップと持ち主の外を `pointerdown` したときと、持ち主をもう一度タップしたときに閉じる。
持ち主のタップでの開閉の切り替えは、ポインターの種類が `touch` のときだけにする。

#267 と #273 は、原因を切り分けて、実装とテストのうち誤っている側を修正する。
実装を修正する場合は、修正した振る舞いをシナリオ・部品設計・モジュール構成に反映する。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| タッチ端末で用語のツールチップを閉じる操作 | 用語のツールチップ（`src/interact/terms.ts`）も `:hover, :focus-within` の間は閉じない同じ作りだが、#170 が報告したのは図のツールチップだけ。用語のツールチップは語のリンクやコピーのボタンを中に持ち、閉じ方を図と同じにするかは別に決める必要がある。含めるかはレビューで確定する | 起票予定 |
