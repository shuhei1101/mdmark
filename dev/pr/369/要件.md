# 要件

## 要望

VS Code 拡張機能の「HTML に書き出す」「ブラウザで開く」「PDF に印刷する」が書き出す HTML で、相対パスの `libraries` と `html-scripts.url` を Chromium 系のブラウザ（Chrome・Edge）でも読めるようにする。

- 相対パスの `libraries` のうち、文書にマーカーがある外部ライブラリを、`extensions` と同じく esbuild-wasm でまとめて `data:` の URL で HTML に埋める（CLI の `mdmark export` の制約「埋める外部ライブラリ」と同じく、文書にマーカーが無いものは埋めない）
- `http:`・`https:` の `libraries` と `html-scripts.url` は今のまま URL で読む
- まとめられないモジュールは埋めず、出力チャネルに警告を記録して書き出しを続ける。開いたときはそのマーカー・範囲に知らせの枠が出る
- 確認の基準: 相対パスの `libraries` のマーカーと、相対パスの `html-scripts.url` を使う `ts` の範囲を持つ文書を書き出し、Playwright の Chromium で file:// で開くと、マーカーの場所が描かれて知らせの枠が出ず、範囲のスクリプトが動く

- 相対パスの `html-scripts.url` は、文書に `ts`・`js` の範囲があり `html-scripts` がオンのときだけ、変換のライブラリを同じくまとめて `data:` の URL で埋める（範囲を変換して埋めず、配布物の `mount` の公開の引数を変えない）
