# 拡張記法でコードブロックの題・行番号・行の強調とコードの行の印を書けるようにする

## 概要

文書を書く人が、コードブロックに題・行番号・行の強調とコードの行の印を付けられるようにする。

## 背景

[Issue #25](https://github.com/shuhei1101/mdmark/issues/25) の要望。
[PR #19](https://github.com/shuhei1101/mdmark/pull/19)（起点 [Issue #4](https://github.com/shuhei1101/mdmark/issues/4)）の要件.md の `## スコープ外` に切り出した項目で、#4 の記法の一覧に無いため含めなかった。
PR #19 はマージ済みで、印の読み取り（`src/render/marks.ts`・`src/render/syntax/`）は develop にある。
今のコードブロックは、`pre` に読み上げの名前と `tabindex` を付けるだけで描いている。
