## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 題・行番号・行の強調の読み取り | コードブロックの直前の印 `<!-- code: title=題 lines highlight=行 -->` を読み、題・行番号の有無・強調する行の番号を部品へ渡す。強調する行は `2`・`4-6` をカンマで並べて書く。読めない指定・コードブロックに無い行の番号は書き方の警告にし、その指定だけを当てない。印の直後にコードブロックが無ければ書き方の警告にする | |
| コードの行の印の読み取り | 行末の行コメントの `[!code ++]`・`[!code --]`・`[!code highlight]` を読み、行に種類を付けて印を外す。行コメントが印だけなら行コメントの頭（`//`・`#` など）も外す。`[\!code ...]` は `\` を外した文字のまま出す。知らない印（`[!code focus]` など）は書き方の警告にし、行に当てずに書いた文字のまま出す | 行コメントの頭は言語に依らず、印の直前の `//`・`#`・`--`・`;`・`<!--`〜`-->`・`/*`〜`*/` を外す |
| 当てるコードブロック | ファイルツリー・図の部品の定義・埋め込んだ HTML として描くコードブロックには当てない | 記法を描くコアルールより後に並べる |
| 部品 | 題・行番号・行ごとの種類（強調・足した行・消した行）を受け、`figure` に題の `figcaption` と `pre` を置いた HTML を返す | 題が無く行番号も種類も無いコードブロックは今の `pre` のまま描く |
| 行番号 | 文字を選んで写す中身に入れない。折り返した行は行番号を最初の 1 行にだけ出す | 印刷ではコードブロックを折り返す |
| 機能のオン・オフ | 機能を 1 つ足し、既定はオン。オフの文書では題・行番号・行の強調を付けず、コードの行の印は書いた文字のまま出す | 機能名は印の名前と揃える。設定の Schema にキーを足し、移行の手順が要らない行を置く |
| 印刷 | 題・行番号・行の強調・コードの行の色と行頭の `+`・`-` をそのまま出す | |
| アクセシビリティ | 足した行・消した行・強調は色だけでなく行頭の `+`・`-` と線でも分け、読み上げで種類が分かるようにする。題があるときは `pre` の読み上げの名前に題を含める | |
| 既存機能への影響 | 指定も印も無いコードブロックの HTML は変えない | |
| 性能 | 配布物の大きさの上限（非機能要件）に収める | 増分はビルドの検査で確かめる |
