## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 右側の目次 | `mount` が描いた要素の右側に、文書の見出しの目次を置く。項目を押すと、URL の `#ID` で移るときと同じく閉じた節を開き、タブを選んでから見出しへ移る | 機能とキーは `未確定`（`要件.md` の案 A / B。決める段: 単一ユースケース設計）。載せる階層は `未確定`（`要件.md` の案 A / B。決める段: 単一ユースケース設計） |
| 目次の出し方 | `hover`（既定）は文書の右端にポインターかフォーカスが入ると出し、外れると消す。ピン止めのボタンで出し続ける。`fixed` は三点リーダーのボタンでサイドバーとして出し続ける | ピン止めの状態を覚えるかはインターフェース定義で決める |
| 今いる節 | スクロールの位置で今読んでいる見出しを決め、右側の目次の項目をハイライトする（`aria-current`） | 見出しの位置の監視は `IntersectionObserver` で行い、スクロールのたびに全ての見出しを測らない |
| H1 の節 | `wrapSections` の対象を h1〜h4 に広げる。`renderSection` の `level` に 1 を加える | `section` のマーカーと警告は H2〜H4 と同じ |
| すべて展開・すべて折りたたむ | 文書の全ての節を開く・閉じるボタンを置く | 置き場所は `未確定`（`要件.md` の案 A / B。決める段: モック作成） |
| 入れ子をまとめて開閉 | 節の開閉のボタンの `click` の `shiftKey` が立っているとき、その節と中の入れ子の節を全て同じ状態にする | キーボードの Enter・Space で押したときも `click` の `shiftKey` で判定する |
| 印刷 | 右側の目次・目次を出すボタン・まとめて開閉するボタンを印刷で出さない | 閉じた節を印刷の前に開く今の動き（`attachPrint`）は、H1 の節にも当たる |
| レスポンシブ対応 | 描いた文書の幅が狭いときは、`fixed` のサイドバーも本文を覆わない出し方にする | 境目の幅と出し方はモック作成で決める |
| まとめた HTML | 左の文書の一覧のパネルと右側の目次を両方出す | 並べ方はモック作成で決める |
| アクセシビリティ | 右側の目次は `nav` と読み上げ名を持ち、目次を出すボタン・ピン止めのボタン・まとめて開閉するボタンはキーボードで操作でき、`aria-expanded` / `aria-pressed` で状態を読み上げる | |
| 設定 | 出し方のキーは任意で、省くと `hover`。知らない値は `hover` にする | 設定・Schema のキーの追加なので、`migrations/no-steps.yaml` に行を置く |
| 配布物の大きさ | 今回の変更を入れた後の `dist/index.js` を実測し、上限 416KB を超えるときは非機能要件『配布ファイル 1 つのサイズ』の前例と同じく実測を添えて上限を上げる | |
| 既存機能への影響 | 本文の中の目次（`<!-- toc -->`）・見出しのアンカー・H2〜H4 の節の開閉・`section` のマーカー・URL の `#ID` で閉じた節を開く動き・タブの選択の見た目と振る舞いを保つ | |
