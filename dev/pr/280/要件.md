# 要件

## 要望

`mount` に次の 3 つの入出力を追加し、どれも省略したときは今と同じ挙動にする。
追加した指定・メソッドは全て `dist/mount.d.ts` の型に入る。

<!-- table: data -->

| 項目 | 入力 | 出力・振る舞い |
| --- | --- | --- |
| 比較元の Markdown との差分の強調 | `mount` のオプション `baseMarkdown?: string \| null`。`update(markdown, {baseMarkdown})` でも差し替える | `markdown` の本文の中に、`baseMarkdown` から追加・変更したブロックと、削除したブロックの位置を、`diffMode: blocks` と同じ差分のブロックで描く。`null`・省略は強調なし。`diffSource` を指定しなくても使える |
| 列の表示の切り替えの通知 | 初期の非表示は今の `hide=` のまま | `mount` のオプション `onColumnsChange?: (event: {tableIndex: number; hidden: string[]}) => void`。`+columns` の表で列を出し入れするたびに、表の番号（本文の中の `+columns` の表の出現順、0 から）と、隠している列の名前の全てを指定して呼ぶ |
| コメントの修正・削除 | `MdmarkCommentStore` に省略可能な `update({docId, id, body})` と `remove({docId, id})`（どちらも Promise）を追加する | `load`・`save` だけのストアも今のまま型検査に通り、動く |
| コメントの読み直し | - | `mount` の戻り値に `reloadComments(): Promise<void>` を追加する。`commentStore.load` を呼び直し、本文のコメントのマーカーを描き直す |
| コメントの場所への移動 | - | `mount` の戻り値に `focusComment(id: string): void` を追加する。そのコメントの引用の箇所へスクロールして強調する |

<!-- /table -->

コメントの修正・削除: ストアが `update`・`remove` を持つときだけ、吹き出しのコメントに「編集」「削除」を出し、押すとその関数を呼んでマーカーを描き直す（[確認ログ](./確認ログ.md)）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 本文の右の余白のコメントのマーカー | [#240](https://github.com/shuhei1101/mdmark/issues/240)（PR [#277](https://github.com/shuhei1101/mdmark/pull/277)）が扱う。#277 を取り込み、`reloadComments` は付け直した印に合わせて右の余白のマーカーも置き直す。`focusComment` は右の余白のマーカーを強調しない | [#240](https://github.com/shuhei1101/mdmark/issues/240) |
| `diffSource` の差分のパネルの比較元を文字列で指定する | 要望は本文の中の強調だけで、差分のパネル（リビジョンの選択・差分の行）は変えない | 予定なし |
| `+columns` の表の初期の非表示を `mount` から指定する | 要望は今の `hide=` のままとしている | 予定なし |
| VS Code 拡張機能のプレビューでの利用 | 要望は `mount` を使う側のページ向けで、プレビューは今の `diffSource` と `diffMode: blocks` を使い続ける | 予定なし |
| 1 行の段落だけの文書で、ブロックの色分けが変えていない段落を追加と判定する | `src/diff/` の `colorDiffBlocks` の行の比較の不具合で、#121 の `diffMode: blocks` でも起きる。今回の要望に含まれない | [#291](https://github.com/shuhei1101/mdmark/issues/291) |
| 390px 幅で、コメントの吹き出しと入力欄のストーリーに横スクロールが出る | `scripts/storybook-render.ts` の `STATIC_POPOVER_STYLE` のストーリーの表示の不具合で、この PR で変更していないストーリーでも起きる。今回の要望に含まれない | [#292](https://github.com/shuhei1101/mdmark/issues/292) |
