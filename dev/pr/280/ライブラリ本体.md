## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 比較元の指定 | `MountOptions` に `baseMarkdown?: string \| null` を追加し、文字列のときは `diffMode: blocks` と同じ描き方（`drawColoredBlocks`）で本文を描く | `diffSource` と同時に指定したときの優先は設計で決める |
| 比較元の差し替え | `update(markdown, options?: {baseMarkdown?: string \| null})` とし、第 2 引数を省いたときは前の比較元を保つ | 第 2 引数で `null` を指定すると強調を外す |
| 列の表示の通知 | `MountOptions` に `onColumnsChange` を追加し、`attachInteractions` から表の操作へ渡す。列のチェックの切り替えと「すべて表示」のたびに呼ぶ | 描いた直後の `hide=` の初期状態では呼ばない |
| 表の番号 | 本文の中の `+columns` の表だけを出現順に 0 から数える | `+columns` の無い表は数えない |
| コメントのストアの型 | `MdmarkCommentStore` に省略可能な `update`・`remove` を追加し、検査は持っているときだけ関数かを確かめる | 破壊的変更なし |
| コメントの読み直し | `MountHandle` に `reloadComments()` を追加し、`load` を呼び直してマーカーを描き直す | `comments` の機能がオフ・`commentStore` 無しのときは何もせずに解決する |
| コメントの場所への移動 | `MountHandle` に `focusComment(id)` を追加し、そのコメントのマーカーへスクロールして強調する | 見つからない `id` は何もしない。強調の見た目はモック作成で決める |
| コメントの修正・削除 | 要件.md の `未確定` の案 A のとき、吹き出しのコメントに「編集」「削除」を出す | `未確定`（決める段: 単一ユースケース設計のレビューの後のユーザーの確認） |
| 既存機能への影響 | 追加した指定・メソッドを全て省略したときは今と同じに描く | 既存の単体・結合テストが変更なしで通る |
| 配布物のサイズ | 非機能要件『配布ファイル 1 つのサイズ』の上限に収める | ビルドのサイズの検査で確認する |
