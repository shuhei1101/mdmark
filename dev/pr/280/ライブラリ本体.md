## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 比較元の指定 | `MountOptions` に `baseMarkdown?: string \| null` を追加し、文字列のときは `diffMode: blocks` と同じ描き方（`drawColoredBlocks`）で本文を描く | `diffSource` と同時に指定したときは、本文の中の色分けに比較元を使い、取り出し元は差分を開く UI にだけ使う（`diffMode: blocks` では取り出し元を呼ばない） |
| 比較元の差し替え | `update(markdown, options?: {baseMarkdown?: string \| null})` とし、第 2 引数を省いたときは前の比較元を保つ | 第 2 引数で `null` を指定すると強調を外す |
| 列の表示の通知 | `MountOptions` に `onColumnsChange` を追加し、`attachInteractions` から表の操作へ渡す。列のチェックの切り替えと「既定に戻す」のたびに呼ぶ | 描いた直後の `hide=` の初期状態では呼ばない |
| 表の番号 | 本文の中の `+columns` の表だけを出現順に 0 から数える | `+columns` の無い表は数えない |
| コメントのストアの型 | `MdmarkCommentStore` に省略可能な `update`・`remove` を追加し、検査は持っているときだけ関数かを確かめる | 破壊的変更なし |
| コメントの読み直し | `MountHandle` に `reloadComments()` を追加し、`load` を呼び直してマーカーを描き直す | `comments` の機能がオフ・`commentStore` 無しのときは何もせずに解決する |
| コメントの場所への移動 | `MountHandle` に `focusComment(id)` を追加し、そのコメントのマーカーへスクロールして強調する | 見つからない `id` は何もしない。強調はマーカーの背景を濃くし、2px の線で全周を囲む（モックで決定） |
| コメントの修正・削除 | ストアが `update`・`remove` を持つときだけ、吹き出しのコメントの本文の右上に「編集」「削除」のアイコンのボタンを出し、削除は吹き出しの中の確認を経てから `remove` を呼ぶ | 確認ログで決定 |
| 既存機能への影響 | 追加した指定・メソッドを全て省略したときは今と同じに描く | 既存の単体・結合テストが変更なしで通る |
| 配布物のサイズ | 非機能要件『配布ファイル 1 つのサイズ』の上限に収める | ビルドのサイズの検査で確認する |

## 実装

- Web の実装ガイド: `accessibility` を参照した。ガイドは同じ画面で「編集」の名前を別々の操作に使い回さないことを勧めるが、部品設計『コメントの吹き出し』が `aria-label` を `編集`・`削除` に決めているため、設計どおりにした
- 確認したストーリー: `parts-commentbubble--editable`・`--remove-only`・`--editing`・`--updating`・`--update-empty`・`--update-failed`・`--remove-confirm`・`--removing`・`--remove-failed`・`parts-commentmark--focused`。`start_storybook_serve` が `.venv` の Python を求めて起動できないため（ai-monitor#2432）、開発コマンドの手順で Storybook を起動し、Playwright で `iframe.html?id=` を開いてエラー無く描かれることを確認した
- 開発コマンド: `scripts/storybook-render.ts` はストーリーの引数の追加だけで、コマンドは変わらない
