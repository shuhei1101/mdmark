# 要件

## 要望

E2E のヘルパー `focusModifiedSide`（`tests/e2e/vscode-diff.ts`）が、差分ビューの変更後の側の本文の行を押してエディタにフォーカスを入れる。
今のロケーター `.monaco-diff-editor .editor.modified .view-lines` の `.first()` は、本文の行より DOM の前にある削除した行の view zone（`div.view-lines.line-delete`）に当たり、フォーカスが入らずに `Shift+Alt+D` が効かない。
PoC で、製品の `when`（`editorLangId == markdown`）のままで差分ビューの両側からプレビューが開くことを確かめたため、`vscode/package.json`・設計書・`docs/` は変えない。

終わりの条件は、release/v0.9.0 の E2E で fail した次の 4 ケースが VS Code 1.141.0 で pass すること。

| テスト | 今の失敗 |
| --- | --- |
| `差分ビューの変更をプレビューで見る.spec.ts` の `test_normal` | プレビューのフレームに `div.mdmark-diff-block` が現れない |
| `差分ビューの変更をプレビューで見る.spec.ts` の `test_normal_when_modified_side_edited` | プレビューのフレームに `div.mdmark-diff-block` が現れない |
| `差分ビューの変更をプレビューで見る.spec.ts` の `test_error_when_version_without_diff` | プレビューのフレームが現れない |
| `エディタとプレビューのスクロールを合わせる.spec.ts` の `test_normal_when_diff_preview` | プレビューのフレームに h2 が現れない |

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `tests/e2e/vscode-diff.ts` の `MODIFIED_LINES` | [3bd72cff](https://github.com/shuhei1101/mdmark/commit/3bd72cffb4085600f874e26eab8c72b54c245027)（`VS Code の差分ビューで開いた Markdown の変更を、mdmark のプレビューに色分けで表示する (#196)`） | 差分ビューの変更後の側を押してエディタにフォーカスを入れる。削除した行の view zone が同じクラスを持つことは考えていない | 1 回 | 本文の行に当てても、変更後の側にフォーカスを入れる目的は壊さない |

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 同じ spec の `test_normal_when_commit_diff` が VS Code 1.141 に無いコマンド名を探して fail する | テストのコマンド名の誤りで、`when` とは別の事象 | [#234](https://github.com/shuhei1101/mdmark/issues/234) |
| ショートカットとボタンの `when` に `resourceLangId == markdown` を追加する | PoC で今の `when` が差分エディターの両側で当たると確かめた（[確認ログ](./確認ログ.md)） | 予定なし |
| コマンドパレットの `when`（`editorLangId == markdown \|\| activeWebviewPanelId == 'mdmark.preview'`） | 差分ビューからコマンドパレットで開けることを切り分けで確かめており、今回の不具合に当たらない | 予定なし |
| 複数ファイルの差分エディターから開く | インターフェース定義の制約「差分ビューの判定」で差分ビューとして扱わないと決めている | 予定なし |
