# 要件

## 要望

VS Code の差分ビュー（変更前と変更後が Markdown）で、変更後か変更前の側にフォーカスがあるときに `Shift+Alt+D` を押すと、`mdmark.openPreviewToSide` が呼ばれて差分のパネルが開く。
同じ差分ビューで、エディタのタイトルの「mdmark: プレビューを横に開く」のボタンが出て、押すと同じく差分のパネルが開く。
Markdown を普通に開いたエディタでのショートカットとボタンの動きは今のまま変えず、Markdown でないエディタではどちらも効かないまま保つ。

終わりの条件は、release/v0.9.0 の E2E で fail した次の 4 ケースが VS Code 1.141.0 で pass すること。

| テスト | 今の失敗 |
| --- | --- |
| `差分ビューの変更をプレビューで見る.spec.ts` の `test_normal` | プレビューのフレームに `div.mdmark-diff-block` が現れない |
| `差分ビューの変更をプレビューで見る.spec.ts` の `test_normal_when_modified_side_edited` | プレビューのフレームに `div.mdmark-diff-block` が現れない |
| `差分ビューの変更をプレビューで見る.spec.ts` の `test_error_when_version_without_diff` | プレビューのフレームが現れない |
| `エディタとプレビューのスクロールを合わせる.spec.ts` の `test_normal_when_diff_preview` | プレビューのフレームに h2 が現れない |

`未確定`: `keybindings` と `menus` の `editor/title` の `when` に置く条件（決める段: PoC 検証）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | `editorLangId == markdown \|\| resourceLangId == markdown` | 普通のエディタで当たる今の条件を残したまま、差分エディターでアクティブなリソースの言語で当てる | 条件が長くなる |
| B | `resourceLangId == markdown` だけにする | 条件が短い | 普通のエディタでの当たり方が今と同じかを別に確かめる必要がある |

推奨: A

普通の Markdown のエディタで当たる今の条件を変えずに、差分エディターで当たる条件だけを追加できるため。
どちらの案も、VS Code 1.141.0 の差分エディターで実際に当たるかを PoC で確かめてから決める。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 同じ spec の `test_normal_when_commit_diff` が VS Code 1.141 に無いコマンド名を探して fail する | テストのコマンド名の誤りで、`when` とは別の事象 | [#234](https://github.com/shuhei1101/mdmark/issues/234) |
| コマンドパレットの `when`（`editorLangId == markdown \|\| activeWebviewPanelId == 'mdmark.preview'`） | 差分ビューからコマンドパレットで開けることを切り分けで確かめており、今回の不具合に当たらない | 予定なし |
| 複数ファイルの差分エディターから開く | インターフェース定義の制約「差分ビューの判定」で差分ビューとして扱わないと決めている | 予定なし |
