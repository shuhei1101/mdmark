## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `icon:` | `badge:` と同じ行内のコードの頭で読み、束ねた名前はそのまま描き、束ねていない名前は使う文書でだけ読む。読めない名前は書き方の警告にする | 読み方は `未確定`（要件.md） |
| columns | `<!-- column -->` で区切った 2〜3 列を CSS グリッドで並べ、狭い画面では縦に積む。入れ子・4 列以上は書き方の警告 | class 名は `.mdmark-columns-*` と別にする |
| 蛍光ペン | `==text==` を専用の class の `<mark>` にし、色の名前は文字の色と同じ一覧から選ぶ | `==text=={color=名前}`（確認ログ） |
| `kbd:` | `badge:` と同じ頭の書き方で `<kbd>` に描き、`+` で区切ったキーをそれぞれ描く | `+` の扱いはインターフェース定義で決める |
| ルビ | 描く処理は変えず、`<ruby>` を落とさないことを単体テストで確認する | 記法の一覧と使い方集に記載 |
| details | 既存の折りたたみの部品で範囲を包み、`open` で開いた状態にする。印刷では開く | |
| pagebreak | 画面では何も出さない要素にし、印刷の CSS で改ページする | |
| include | 取り込む文書の表から、文書の全体・見出しの中・コードの行の範囲を取り出して描く。無い取り込み先は書き方の警告にし、check でずれとして返す | 渡し方は `未確定`（要件.md）。行の範囲は `#L3-L10`（確認ログ）。循環する取り込みは警告にする |
| wide | 範囲を本文の幅の外へ広げ、右の目次・まとめた HTML の文書の一覧に重ならない幅に収める。範囲の上の本文の幅の右端のボタンで本文の幅と切り替え、本文の幅から始める指定を受ける | 確認ログで決定。指定は `<!-- wide: closed -->`。ボタンのアイコンは Lucide に無い形（両端の縦線へ向かう矢印）のため、独自の形を置く場所を部品設計・モジュール構成に記載する。#323 で画面の右端から 1rem に固定した、ピン止めしていない右側の目次（hover の出し方）の線と枠に、wide の範囲が重ならないかをインターフェース定義で確かめ、シナリオの期待値に加えるかを決める |
| CSV の表 | 言語 `csv` のコードブロックを GFM の表と同じトークンにし、表のマーカーの機能をそのまま当てる。表の右端の RAW のボタンで元の CSV と表を切り替える（RAW のボタンは CSV の表だけに付け、GFM の表には付けない） | 読み取りは `未確定`（要件.md）。マーカーの無いブロックも表にする（確認ログ） |
| 機能のオン・オフ | 新しい記法ごとに features のキーを追加する | 既定はオン（確認ログ） |
| 配布物のサイズ | 追加後の dist/index.js と dist/index.css が非機能要件の上限に収まることを確認する | |
