# 要件

## 要望

VS Code 拡張機能の結合テスト `vscode/tests/integration/preview-open.test.ts` の `test_normal_when_tags_unreachable` が fail したとき、要求が待ちの上限より早く終わった原因を、1 回の実行で切り分けられるようにする（[確認ログ](./確認ログ.md)）。

- 代役の配信（`vscode/tests/integration/stub-server.ts`）が、`/tags` の要求を受けた時刻と、その接続を拡張機能に閉じられた時刻を記録する
- `test_normal_when_tags_unreachable` のアサーションのメッセージに、記録した時刻と、拡張機能のログの `タグ一覧を取れない` の理由（`reason.name`・`reason.message`）を含める
- 期待の範囲（2800 ms 以上 6000 ms 未満）・待ちの上限 `TAGS_TIMEOUT_MS = 3000`・実装（`vscode/src`）は変えない
- 実行コマンドは `xvfb-run -a npm --prefix vscode run test:integration`。VS Code 1.141.0 と stable の両方で、結合テストを全 pass のまま保つ
