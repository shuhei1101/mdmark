## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 重なりの順（No 1） | 右側の目次（`.mdmark-side-toc`）に、広い幅と狭い幅のどちらも `z-index: 5` を与え、表の見出し行・集計の行（`3`）・ピン止めした列のセル（`4`）より前に描く。表の中の順は変えない | 先頭へ戻るボタン（`5`、DOM で後ろ）とツールチップ・メニュー（`10`）は目次より手前に残す。値は CSS 変数で持たない |
| 上端の見切れ（No 2） | 広い幅の hover でピン止めしていない右端の線を、枠と同じく `position: fixed` にし、`followPanelPosition` が `--mdmark-side-toc-rail-top`（aside の上端と枠の上端の大きい方）と `--mdmark-side-toc-rail-height`（見えている枠の下端までの高さ）を入れる。aside は線の幅を `min-width` で取る。#320 で決めた hover で開く枠の位置は維持する | 線が aside の高さを持たないため、描く先の要素の下端で押し上げられない |
| fixed の出し方・ピン止め・狭い幅の帯 | 重なりの順を同じく与え、本文の要素の後ろに隠れないようにする。位置は変えない | - |
| アクセシビリティ | 前に描いた枠の中の項目とボタンを、ポインターとキーボードの両方で操作できることを確かめる | - |
| 既存機能への影響 | 公開関数・設定のキーは変えない。CSS 変数を持つ場合は追加だけ | 破壊的変更なし |
