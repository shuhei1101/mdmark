# 要件

## 要望

E2E『ClaudeCodeにプラグインを入れる』（`tests/e2e/単一ユースケース/ClaudeCodeにプラグインを入れる.spec.ts`）の準備で、プラグインを入れる前に次の 2 つを確かめ、当たったときは理由を出してテストを失敗させる。

- HEAD が detached（`git rev-parse --abbrev-ref HEAD` が `HEAD`）のとき
- `git rev-parse HEAD` の commit と `git ls-remote origin {ブランチ}` の commit が一致しないとき（GitHub にブランチが無いときを含む）

どちらにも当たらないときは、今と同じく `shuhei1101/mdmark#{ブランチ}` からプラグインを入れて判定する。

## 影響するユースケース

| 種別 | ユースケース | 影響 | 依存 |
| --- | --- | --- | --- |
| 単一ユースケース | [文書を書く人が Claude Code に mdmark のプラグインを入れる](https://github.com/shuhei1101/mdmark/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%82%B7%E3%83%8A%E3%83%AA%E3%82%AA/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/ClaudeCode%E3%81%AB%E3%83%97%E3%83%A9%E3%82%B0%E3%82%A4%E3%83%B3%E3%82%92%E5%85%A5%E3%82%8C%E3%82%8B.yaml) | 実行のみ（シナリオの記述は変わらず、E2E の準備に前提の検査を加える） | |
