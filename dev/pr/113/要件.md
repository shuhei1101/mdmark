# 要件

## 要望

E2E『VSCodeでプレビューを開く』の `test_normal_when_tags_unreachable` の準備で、前回のバージョン `v0.6.0` で描いたプレビューを、フォーカスがプレビューとエディタのどちらにあっても閉じる。
閉じ方は、プレビューのタブを指して閉じる（タブを押してから閉じる）か、閉じる操作の前にフォーカスをプレビューへ移す形にする。
Markdown のタブは閉じずに残し、続く `focusEditor()` と `openPreviewWithShortcut()` の流れは変えない。

検証（読んだ配布物が `v0.6.0` で `v0.7.0` を読まないこと、描けない理由を出さないこと）は変えない。

完了の基準は、release/v0.7.0 のビルドした配布物で、このケースを `--repeat-each 5 --workers 1` で流して全て pass すること（Chromium のプロジェクト）。
