## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 使われているタグの取得 | `#### 文書に主題のタグを付ける` の前に、索引の `docs[].tags` を全件参照して使われているタグを取得し、同じ概念の言い方・活用の違いだけのタグは使い回す工程を追加する | 語彙（最上位の `tags`）と `list_tags` は使わない |
| 付与の判定 | 付与するかは knowledge の規約『タグと用語の登録』と判定フローチャート『タグの付与』で決める旨をリンクで記載する。その語で探した人にこの文書が出てほしいタグは全て付与し、最も分量の多い主題に `main: true` を付ける | 規約の本文のコピーは置かない |
| 既存の記述 | 語彙の記載方法・語彙の点検の記述は変更しない | 削除は [#179](https://github.com/shuhei1101/mdmark/issues/179) |
| 生成物 | `plugin/guide/` は Git の追跡外のビルドの生成物のため、commit しない | - |
