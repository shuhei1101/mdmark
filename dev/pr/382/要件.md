# 要件

## 要望

- 言語 `mermaid` のコードブロックを図として描く。描く経路は `mount`（VS Code 拡張機能のプレビューを含む）・CLI の `mdmark export`・`mdmark build`・VS Code 拡張機能の「HTML に書き出す」の全て
- 描いた図を図の枠に入れ、ほかの図と同じ拡大・縮小・移動・全画面・リサイズハンドルを付ける
- 既定のテーマは mdmark の見た目（色・書体・アイコン）に合わせ、設定の `colorTheme`・`colorScheme` と page のマーカーの明暗に追従する。mermaid の既定のテーマのままにしない
- テーマは設定で変えられる
- mermaid のライブラリは、文書に mermaid のコードブロックがあるときだけ読み込む。配布物の `dist/index.js` にはまとめない
- CLI の書き出しは、mermaid のコードブロックがある文書のときだけ mermaid をまとめ、[#189](https://github.com/shuhei1101/mdmark/issues/189) のまとめ方のとおり 1 つの script に入れて外へ要求しない
- 機能のオン・オフ `mermaid`（既定オン）で切り替える。オフの文書と、mermaid を読み込めない・記法を解釈できないコードブロックは、コードブロックのまま残す。読み込めないときは知らせの枠、解釈できないときは書き方の警告を前に配置する

図の枠のタイトルは、mermaid の front matter の `title`、無ければ `accTitle`、どちらも無ければ図の種類の名前（フローチャート など）にし、範囲・更新日は出さない（[確認ログ](./確認ログ.md)）。

テーマの設定のキーは `mermaid.url`・`mermaid.theme`（既定 `mdmark`、ほかに mermaid のテーマの名前）・`mermaid.themeVariables`（mermaid の変数の上書き）にし、`securityLevel`・`startOnLoad` など mdmark が決める値は使う側に開けない。

シーケンス図の actor などの人のアイコンは、mdmark の図と同じ lucide のアイコンに替え、本文の色の線で描く（[確認ログ](./確認ログ.md)）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 差分の表示で mermaid のコードブロックを図にする | 差分は Markdown の行を比べる表示で、埋め込んだ HTML 以外は描いた結果を比べない | 予定なし |
| mermaid の図の要素に用語の下線・図のツールチップを付ける | 要望に含まれない。mermaid の SVG の要素に mdmark のツールチップを適用する仕組みは、この PR の描画が入った後に決まる | 起票予定 |
| Mermaid と補足で記載し、自動配置で描く新しい図 | 別の記法の新設で、目的が違う | [#324](https://github.com/shuhei1101/mdmark/issues/324) |
| mdmark の文書を GFM と Mermaid の Markdown に書き出す | 書き出す先の形式の追加で、目的が違う | [#313](https://github.com/shuhei1101/mdmark/issues/313) |
