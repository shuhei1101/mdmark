## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 描画（`render`） | 言語 `mermaid` のコードブロックを、機能 `mermaid` がオンなら、mermaid のソースを持つ描く前の要素にする。オフならほかの言語と同じコードブロックにする | `render` は画面を持たないため、図にはしない |
| 読み込み（`mount`） | 描く前の要素が 1 つ以上あるときだけ、設定の `mermaid.url`（既定は jsDelivr のバージョンを固定した ES モジュール）を読み込む。`mount` ごとに 1 回だけ読み込む | `syntax.url`・`html-scripts.url` と同じく、マーカーの名前の対応表 `libraries` と分ける |
| 描画（`mount`） | mermaid の `render` で SVG を作り、図の枠に入れる。`securityLevel` は `strict`、`startOnLoad` は `false` に固定する | ラベルの HTML とクリックのスクリプトを無効にするため、使用する側の設定で上書きさせない |
| 図の枠 | 図の枠の種類に `mermaid` を追加し、ほかの図と同じ拡大・縮小・移動・全画面・リサイズハンドルを付ける。開いたときの倍率は全体が収まる倍率にする | タイトルは front matter の `title`、無ければ `accTitle`、どちらも無ければ図の種類の名前（[確認ログ](./確認ログ.md)） |
| テーマ | 既定のテーマ `mdmark` は、描く先の要素の計算済みの CSS 変数（色・書体）から mermaid の `base` テーマの変数を作る。テーマ・明暗が変わったら描き直す | mermaid の色の解釈が CSS の色の記法の一部しか受けない場合の変換は PoC で確認する |
| アイコン | 人のアイコンなどを mdmark の図と同じ lucide のアイコンにし、本文の色の線で描く | [確認ログ](./確認ログ.md) |
| 設定 | `mermaid.url`・`mermaid.theme`・`mermaid.themeVariables` と `features.mermaid` を追加する。知らない値は既定にする | - |
| 機能のオン・オフ | 機能 `mermaid`（既定オン）を追加し、文書の `<!-- features: -mermaid -->` で上書きできるようにする | - |
| エラー表示 | 読み込めないときは知らせの枠、mermaid が記法を解釈できないときは書き方の警告をコードブロックの前に配置し、コードブロックはそのまま残す | 例外は投げない |
| 書き出し（CLI） | `mdmark export`・`mdmark build` は、描く文書に mermaid のコードブロックがあるときだけ、`mermaid.url` のモジュールを 1 つのスクリプトにまとめる。動的 `import()` を残さない | [#189](https://github.com/shuhei1101/mdmark/issues/189) のまとめ方に合わせる。mermaid の ES モジュールが内部の動的 `import()` を持つため、まとめられるかを PoC で確認する |
| 印刷 | 暗い配色のときは明るい配色の SVG も先に描いて並べ、`@media print` では明るい配色の SVG だけを出す | `render` が非同期のため、`beforeprint` では描き直さない |
| 配布物 | mermaid を `dist/index.js` にまとめない | 配布物のサイズの検査を変えない |

結論: 成立。

所感:

- mermaid 12 の `base` テーマは `themeVariables.useGradient` が既定 `true` で、flowchart のノードの枠線を `primaryBorderColor` から派生色へのグラデーションにする。`useGradient: false` を指定すると枠線が `primaryBorderColor` になる。既定のテーマ `mdmark` はこの値を固定する
- 透明度の低い色を canvas で `#rrggbbaa` にすると、RGB が丸めでずれる（`rgba(24, 24, 27, 0.14)` が `#15151c24`）。計算済みの値が `rgb()`・`rgba()` のときは canvas を通さずに値を読み、それ以外（`oklab()`・`color()`）だけ canvas で変換する
- 比べる対応表の `background` に当たる SVG の要素は無かった（mermaid は図の背景を塗らない）。図の地は図の枠の CSS が持つ
- 外への要求が 0 件の 1 枚の HTML にまとめられるが、mermaid を使用する文書の書き出しは 5 MB を超える。非機能要件の書き出した HTML のサイズの決定値は、この実測を元に設計の工程で決める
- 描いた図の見た目のうち、ノードの影・円グラフの扇形がほぼ同じ色になること・ER の関係のラベルの地が濃くなることは、モック作成でテーマの変数を決めるときに扱う

最小再現コードの要点（[poc/mermaid/logic.js](https://github.com/shuhei1101/mdmark/blob/ff34427e99f18bfff63b68bb30998b369725f260/poc/mermaid/logic.js) から）:

```js
// CSS 変数を、試しの要素の color で解決して hex にする
export function resolveHex(root, name) {
  const probe = document.createElement("span");
  probe.style.color = `var(${name})`;
  root.append(probe);
  const computed = getComputedStyle(probe).color;
  probe.remove();
  const [r, g, b, a] = toRgba(computed); // 1x1 の canvas に塗って getImageData で読む
  return { computed, hex: `#${hex2(r)}${hex2(g)}${hex2(b)}${a === 255 ? "" : hex2(a)}` };
}

const themeVariables = Object.fromEntries(PAIRS.map(([key, name]) => [key, resolveHex(root, name).hex]));
themeVariables.fontFamily = getComputedStyle(root).getPropertyValue("--mdmark-font-body").trim();
themeVariables.useGradient = false;
mermaid.initialize({ startOnLoad: false, securityLevel: "strict", theme: "base", themeVariables });
const { svg } = await mermaid.render(id, source);
```
