## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 差分のパネルの行の比較（#336） | 空白だけの行を除いて行ごとに比べ、除いた空行を前と後の元の位置に戻してから塊に分ける。前 `A\n\nC\n\nD\n`・後 `A\n\nB\n\nC\n` で `C` を `same` にする | 戻す空行を `same`・`del`・`add` のどれにするかの規則はモジュール構成設計で決める |
| ブロックの色分けの段落の分割（#337） | 空白だけの行を除いた比較は残し、前の 1 つのブロックの行が後の 2 つ以上のブロックに分かれたときに、分かれた後のブロックを追加にする。追加も削除も無いときの終了は、ブロックの範囲の対応も変わらないときだけにする | #291 の `test_color_diff_blocks_when_one_line_paragraphs` を崩さない |
| 既存機能への影響 | 差分のパネルの行の並びと `counts`、ブロックの色分けの追加のブロックが変わる。同じ本文の `counts` は 0 のまま | - |
| 配布物の大きさ | jsdiff の新しい関数を import しない | 非機能要件の上限はビルドのサイズの検査で確認する |
