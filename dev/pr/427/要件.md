# 要件

## 要望

| 子 | タイトル | 終わりの条件 |
| --- | --- | --- |
| [#336](https://github.com/shuhei1101/mdmark/issues/336) | 差分のパネルで、1 行の段落だけの文書の変えていない段落を削除と追加の対で出す | 差分のパネル（`diffMode` が `blocks` でない差分）で、前 `A\n\nC\n\nD\n`・後 `A\n\nB\n\nC\n` のように空行どうしが一致する並びを避け、変えていない段落（`C`）を削除と追加の対で出さない |
| [#337](https://github.com/shuhei1101/mdmark/issues/337) | ブロックの色分けで、空行を足して段落を 2 つに分けた変更を追加と判定しない | ブロックの色分け（`diffMode: blocks` と比較元の Markdown との差分の強調）で、空行だけを追加して段落を 2 つに分けた変更（`X\nY` → `X\n\nY`）を追加のブロックと判定する。#291 の 1 行の段落だけの文書の判定は崩さない |

差分のパネルは今と同じく前と後の全ての行（空行を含む）を表示する。
