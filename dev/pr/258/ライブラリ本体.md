## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 設定の型 | `MdmarkConfig` に `labels?: { paramCopy?: string }` を、`ResolvedConfig` に `labels: { paramCopy: string }` を追加する | 知らないキーは読まない |
| 既定の適用 | `resolveConfig` は `labels.paramCopy` が空でない文字列ならその値、それ以外は既定の「今の値を写す」（定数 `DEFAULT_LABELS`）にする | 空文字はボタンの読み上げの名前が空になるため既定にする |
| 描く処理への受け渡し | `renderDocument` が既定を当てた `labels` を `RenderEnv` に入れ、`diagrams.ts`・`html.ts` が `renderParam` の `state` に `copyLabel` として渡す | `mount` の描き直しは同じ `config` で `renderDocument` を呼ぶため、同じ文言で描く |
| 部品の HTML | `renderParam` の `state.copyLabel` を `escapeHtml` してアイコンの後ろに描く。省いたときは既定の文言 | `aria-label` は付けず、ボタンの文字を読み上げの名前にする |
| 操作 | `src/interact/params.ts` はボタンの文字を書き換えないため変えない | スライダーで描き直すのはグラフと今の値・知らせだけ |
| 設定の検査 | `src/cli/config.ts` で、`labels` がマップでない・`labels.paramCopy` が空でない文字列でないときは、`tooltips` と同じくずれを積んでそのキーを落とす | `mdmark check` の `schema` のずれ、書き出しの設定ファイルの誤り（終了コード 1）になる |
| 書き出し | `src/cli/export.ts` の埋める設定に `labels` を写す（`tooltips` と同じく、書いてあるときだけ） | `mdmark export`・`mdmark build`・MCP の `export_html`・`build_site` が同じ処理を通る |
| JSON Schema と移行 | `schemas/mdmark.config.schema.json` に `labels`（`paramCopy`: string・`minLength: 1`、既定「今の値を写す」）を追加し、`migrations/no-steps.yaml` に行を置く | 任意のキーの追加で、既存の設定はそのまま読める |
| 単体テスト | `resolveConfig`（文字列・省略・空文字・文字列でない値）、`renderParam`（`copyLabel` の有無と HTML のエスケープ）、`src/cli/config.ts` の検査、`src/cli/export.ts` の埋める設定 | - |
| 結合テスト | `mount` に `labels.paramCopy` を渡して描き、ボタンの文字と読み上げの名前が渡した文言で、`update` で描き直した後も同じことを確かめる | `render` でも同じ文言になることを確かめる |
| E2E テスト | シナリオ『操作できる部品で値を変えて写す』に追加する正常シナリオ（設定で文言を替えたとき）を確かめる | - |
