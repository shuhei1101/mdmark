## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 索引の形 | Schema・`index-shape.ts`・ER図『索引』から最上位の `tags` を外し、`schema` を `2` にする。文書の `tags`（文字列か `{ name, main }`）は変えない | `schema` は `2` だけを受ける（[要件](./要件.md)） |
| 点検 | `checkIndex` から `findTagIssues` の呼び出しを外し、`MdmarkIndexIssue` の `kind` から語彙の 5 種類を外す | `mdmark check` は `checkIndex` の結果をそのまま返す |
| 語彙の照合 | `buildTagVocabulary`・`resolveTag`・`nearestTag`・`findTagIssues`・`TagVocabulary`・`NEAR_TAG_MAX_DISTANCE` を削除 | 文書のタグを読む `readDocTag` を使う処理が残るなら残す |
| 公開の型 | `src/index.ts` から `MdmarkIndexTag` の export を外す | 使う側の型の参照が切れる。古い索引は `mdmark upgrade` で移す |
| 移行 | `migrations/next/steps.yaml` に、語彙を外して `schema` を書き換える手順を置く | `call` のスクリプトで、別名とやめたタグを語彙の名前に書き換えてから語彙を外す（[要件](./要件.md)・[確認ログ](./確認ログ.md)） |
| 既存機能への影響 | 用語集・被参照・本文の参照の取り出しは文書の `tags` も最上位の `tags` も使わないことを、単体・結合テストを回して確かめる | - |
