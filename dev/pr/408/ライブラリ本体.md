## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既存機能への影響 | `src/index.css` の `.mdmark-tree-row { display: flex }` を `.mdmark-tree-list .mdmark-tree-row` にし、ファイルツリーのリストの中に限る | 名前の塊・注釈の規則は子の結合子（`>`）で表の行に当たらないため変えない |
| 印刷 | 印刷で隠す開閉とコピーのボタンの規則を `.mdmark-table[data-tree] :is(.mdmark-tree-toggle, .mdmark-tree-copy)` にする | 行が隠れるようになった後、`test_normal_when_tree_folded`（文書を印刷する）が印刷中の開閉ボタンの確認で fail した。表の `.mdmark-table[data-tree] .mdmark-tree-toggle { display: inline-flex }` とファイルツリーの `.mdmark .mdmark-tree-copy { display: inline-flex }` の詳細度が、印刷の `.mdmark-tree-toggle`・`.mdmark-tree-copy` より高かった。ファイルツリーのボタンは `.mdmark-tree-bar` を隠す既存の規則で隠れる |
| ツールチップ | 全体のパスのツールチップ `.mdmark-table[data-tree] .mdmark-tree-tip` を、`position: relative` にしたキーのセルの上（`inset-block-end: 100%`・`inset-inline-start: 0`）に出し、`pointer-events: none` にする。本文の行の上には見出しの行か前の行があるため、最後の行でもスクロールの包み（`overflow-x: auto`）の下端で切れない | `test_normal_when_tree`（表を操作する）の時間切れの原因。オフセットの無い絶対配置で `display: flex` のセルの先頭に出て名前に重なり、ポインターを受け止めて出たり消えたりを繰り返していた |
| 確認 | fail した E2E 4 件と、『文書を印刷する』『ステップ・ファイルツリー・バッジで本文を組む』の全件で確かめる | - |
