## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 印の読み取り | 解析器のトークンの上で、範囲の印の始まりと閉じの印を対にして範囲を決め、引数を種類・`+機能`・`-機能`・`キー=値`・`closed`・`open` に分ける | コロンの無い `<!-- 名前 -->` も印として読む |
| 記法の HTML | 各記法を解析器のコアルールとレンダラーで HTML にし、`render` と `mount` が同じ HTML を出す。スクリプトを動かさなくても中身が読める形にする | DOM に頼らない今の `render` の条件を保つ |
| サニタイズ | 記法が使う要素・属性・class だけを許可に足す | 描くごとに作る値を mdmark が出した要素にだけ `data-mdmark-own` で付け、`sanitize` がその要素にだけ記法の class・`data-*`・`id` を残す（モジュール構成『描画』『部品』の `markOwn`） |
| 操作 | 並べ替え・ピン止め・絞り込み・タブ・開閉は、`mount` が描いた要素に付け、`update` で付け直し、`destroy` で外す | - |
| 注意書き | 引用の 1 行目の `[!種類]` を読み、出力の class を GitHub と同じ `markdown-alert` にする | - |
| 見出しの ID | GitHub と同じ規則で付け、目次・アンカー・節の開閉が使う | 印の無い文書でも見出しに ID が付く |
| 図と表の番号 | 文書の頭から種類ごとに数え、`#fig-ID` へのリンクの文字を番号にする | 番号を出す形はモック作成で決める |
| 機能のオン・オフ | 記法ごとに機能を足し、既定はオン。オフの記法は印を無視して普通の Markdown として描く | 名前は [要件](./要件.md) の `機能のオン・オフ` |
| 拡張の登録 | `registerExtension` で足した印は、対応表の印と同じく印の場所を置き、文書に印があるときだけ `load` を呼ぶ | 引数は使う側が渡す Standard Schema で検査し、mdmark は検査のライブラリを束ねない（[ライブラリ選定](https://github.com/shuhei1101/mdmark/pull/19#discussion_r4269417402)） |
| 型定義 | 公開関数と拡張の型を `dist/` の型定義に書き出す | - |
| 印刷 | `beforeprint` でタブの全ての中身・閉じた節・行の詳細・閉じた表と注意書きを開き、`afterprint` で戻す | 今の `details` の開閉に載せる |
| アクセシビリティ | タブは WAI-ARIA のタブの作法、並べ替えは `aria-sort`、開閉のボタンは `aria-expanded` で状態を示す | - |
| エラー表示 | 書き手の誤りを知らせる見せ方 | モック作成で決める |
| 性能 | 束ねた後の配布ファイル 1 つのサイズが、非機能要件の上限に収まる | - |
| 既存機能への影響 | 印の無い文書でも、既定でオンの機能で出力が変わる（見出しに ID とアンカー、h2〜h4 の節の囲み、表の既定の種類の囲みとピン止め）。`anchors`・`sections`・`table` を外せば、見出しの ID のほかは今の出力に戻る。`features` の印・対応表の印・印刷の振る舞いを変えない | - |
