## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 確かめる配布ファイル | 使う側のブラウザが読む JS（`dist/index.js`・`dist/view.js`・`dist/comments.js`・`dist/viewer.js`） | `dist/cli.js`（Node 24）は対象外 |
| 確かめ方 | 配布ファイルの JS が下限の版に無い API を使っていないかを数える | `未確定`（決める段: PoC 検証。案と推奨は要件の `## 要望`） |
| 下限の版 | `BROWSER_TARGETS` の値から取る | 下限の版を 2 か所に書かない |
| 見つけたとき | API の名前と配布ファイルを出し、終了コード 1 で止める | 配布ファイルの上限超過と同じ止め方 |
| 有無を確かめてから使う API | 確かめの対象から外す。外す API と外す理由を 1 か所に並べる | `Intl.Segmenter`（`src/knowledge/dictionary.ts`・`src/diff/panel.ts`） |
| 組み込む場所 | `npm run build` で配布物を書いた後に流す | `未確定`（決める段: インターフェース定義設計。案と推奨は要件の `## 要望`） |
| 非機能要件 | 『対応ブラウザ』の `measurement` を確かめ方に合わせて書き換える | 決定値は変えない |

PoC 検証の成功条件は、v0.6.0 の `dist/index.js` で `Intl.Segmenter` を見つけて止まり、今の develop の配布物で止まらないこととする。
