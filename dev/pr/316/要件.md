## 要望

依存の `markdown-it` を 15.0.2 から 15.0.3 に上げ、次の勧告 2 件を解消する。

| 勧告 | CVE | CVSS | 内容 |
| --- | --- | --- | --- |
| GHSA-gfr2-rv44-r23c | CVE-2026-111758 | 7.5 | リンク参照定義の 2 次の計算量によるサービス停止 |
| GHSA-vfgh-jcmw-g37q | CVE-2026-111766 | 3.7 | - |

終わりの条件:

- `package.json` の `markdown-it` が `15.0.3`（完全一致）で、`package-lock.json` の `node_modules/markdown-it` が 15.0.3 を指す
- 外部ライブラリの設計書『markdown-it』のバージョンが 15.0.3 を指す
- 単体テスト・結合テスト・lint・型検査が全て通る
- 影響するユースケースの `実行のみ` の行の E2E が release で通る
