## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| コードブロックの入れ物 | `.mdmark :where(.mdmark-code)` の `margin: 0` から上の余白を除外し、上の余白は本文の `> * + *`・`:where(.mdmark-section-body) > * + *`・`.mdmark-tab-panel > * + *`・`:where(li, blockquote, details) > * + *`・`.mdmark-row-detail > td > * + *` に任せる | 帯の下に続く `pre` の `margin: 0` は変えない |
| ファイルツリーの入れ物 | `.mdmark .mdmark-tree` の `margin: 0` から上の余白を除外し、上の余白は同じ本文の規則に任せる | コピーできないときのパネルの余白は変えない |
| ほかの部品 | 要望の組み合わせを測り、間隔が 0px の組み合わせがあれば同じ方法で修正する | - |
| 結合テスト | 実際のブラウザで 2 つずつのブロックを並べて描き、前のブロックの下端と後のブロックの上端の差が、直下・節の中身・タブの中身は `--mdmark-space`、リストの項目・引用・折り畳み・行の詳細の中は `calc(var(--mdmark-space) / 2)` になることを確認する | 見出しの上の余白と区切り線の上下の余白のように独自の間隔を持つ組み合わせは、その値で確認する |
