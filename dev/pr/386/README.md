# コードブロックとファイルツリーの前に、ほかのブロックと同じ間隔を空ける

## 概要

文書を読む人が、コードブロックとファイルツリーを、直前の段落・表・リストなどとくっつかずに、ほかのブロックと同じ間隔で参照できるようにする。

## 背景

[Issue #326](https://github.com/shuhei1101/mdmark/issues/326) の不具合。
develop の 60e0bff2 で 2 つずつのブロックの組み合わせの縦の間隔を測ると、直後がコードブロック（`.mdmark-code`）かファイルツリー（`.mdmark-tree`）のときだけ 0px で、ほかの組み合わせは 14px だった。
VS Code のプレビューと `export_html` の書き出しで同じく起きる。

`src/index.css` は描く先の要素 `.mdmark` の `> * + *` でブロック同士の間隔を付ける。
コードブロックの `.mdmark :where(.mdmark-code) { margin: 0 }` は同じ詳細度でソースの後ろにあり、ファイルツリーの `.mdmark .mdmark-tree { margin: 0 }` は詳細度が高いため、どちらもこの間隔を無効にしている。
