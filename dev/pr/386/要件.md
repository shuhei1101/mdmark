# 要件

## 要望

描いた文書のブロック同士の縦の間隔を、直後のブロックがコードブロック（`.mdmark-code`）かファイルツリー（`.mdmark-tree`）のときも、ほかのブロックと同じ値にする。

- 描く先の要素の直下で、段落・表・コードブロック・箇条書き・番号付きリスト・引用・注意書き・ファイルツリーの直後のコードブロックとファイルツリーの上の間隔を `--mdmark-space`（既定で 14px）にする
- リストの項目・引用・折り畳みの中で、前のブロックに続くコードブロックとファイルツリーの上の間隔を、ほかのブロックと同じ `calc(var(--mdmark-space) / 2)` にする
- コードブロックとファイルツリーが先頭のとき（前のブロックが無いとき）は、上に間隔を空けない
- 段落・見出し・表・コードブロック・ファイルツリー・箇条書き・番号付きリスト・引用・注意書き・区切り線・タブ・ステップ・埋め込んだ HTML を 2 つずつ並べた組み合わせを全て測り、間隔が 0px の組み合わせが残らないことを結合テストで確認する。見出しと区切り線のように独自の間隔を持つ組み合わせは、その間隔のままにする
