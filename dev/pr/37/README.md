# E2E『文書を描く』の test_normal_when_index で本文の段落だけを検証する

## 概要

E2E『文書を描く』の `test_normal_when_index` が、本文を差し替えた後の段落を被参照の一覧の題に当てずに確かめる。

## 背景

[Issue #33](https://github.com/shuhei1101/mdmark/issues/33) の不具合。
release/v0.3.0 の E2E（[release PR #31](https://github.com/shuhei1101/mdmark/pull/31)）で、`test_normal_when_index` が Chromium・Firefox の両方で fail した。
[#27](https://github.com/shuhei1101/mdmark/pull/27) で入った被参照の一覧は題を `p` で描き、テストの `doc.locator("p")` が本文の段落と題の 2 つに当たって Playwright の strict mode で落ちる。
描いた本文と被参照の一覧は要件どおりで、製品の挙動は正しい。
