## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 書き出し・まとめの結果 | `runExport`・`runBuild` を、結果（書き出したパス・入れた文書の数・警告）を返す処理と、標準出力・終了コードに整える処理に分け、CLI と MCP が同じ処理を呼ぶ | CLI の出力と終了コードは変えない |
| 点検の結果 | MCP の `check` は `collectCheckIssues` の一覧をそのまま返す | CLI の出力は変えない |
| 文書を探す | 索引・参照の表から、題名・別名・概要の部分一致、タグ（全てを持つ）、関係する文書（参照先と被参照）で文書を引く関数を足す | 引数を 1 つも渡さないときは全ての文書を返す |
| 索引を書き換える | 文書か用語の ID の項目を置き換え・足し・消した後の索引を `normalizeIndex` に通し、問題が 1 件でもあれば書かずに問題の一覧を返す。一時ファイルに書いてから置き換える | 並びとコメントの扱いは ER 図『索引』の `MCP からの書き換え` |
| MCP サーバー | 標準入出力の MCP サーバーを立てて `read_guide`・`export_html`・`build_site`・`check`・`find_docs`・`update_index` を登録する処理を置き、配布物のビルドがそれを `plugin/` の JavaScript に束ねる | MCP サーバーの入口は `src/cli/main.ts` を読まない（`CliError` を `main.ts` の外へ出す）。PoC では束ねた先で `main` も走り、標準エラーに使い方が出た |
| 使い方集の同梱 | 配布物のビルドが `guide/` の索引と、索引が指す本文を `plugin/` に入れ、`read_guide` がそこから読む | 本文は `docs/` のページを指す（ER 図『使い方集』） |
| ビルドの検査 | 配布物のビルドで、使い方集の索引が 10,000 文字を超える・索引が指すページが無いときに止める | - |
| プラグインの版 | 配布物のビルドが、埋める版（`version.ini` か `--version`）を `plugin/.claude-plugin/plugin.json` の `version` に書く | hotfix の `--version` でも `dist/` と揃う |
| 既存機能への影響 | `mdmark export`・`build`・`check` の引数・出力・終了コードは変えない | 既存の結合テストで確かめる |
| 動作環境 | MCP サーバーは CLI と同じ Node 24 以降で動かす | - |
