## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 公開の入口 | `src/index.ts` から `mount`・`render` を公開する。配布物の入口は `dist/index.js` と `dist/index.css` の 1 つずつのまま | - |
| Markdown の解析 | GitHub Flavored Markdown を解析する外部ライブラリを、版を固定して配布物に束ねる | ライブラリは設計のライブラリ選定で決める |
| スクリプトの扱い | 解析した HTML から `script` 要素・イベント属性・`javascript:` の URL を落としてから描く | - |
| 設定 | `opts.config` をオブジェクトで受け、省いたキーに既定を当てる。Schema は `schemas/` に置く | ブラウザで YAML は読まない |
| 機能のオン・オフ | 設定の `features` に文書の `<!-- features: … -->` を重ねた結果を 1 か所で決め、機能のモジュールへ渡す | 知らない機能名は無視する |
| テーマ | 値を接頭辞 `--mdmark-` の CSS 変数で配り、mdmark の CSS を `@layer` に入れる | `未確定`（要件.md の「`@layer` と対応ブラウザの下限」） |
| 印刷 | `@media print` の CSS と、`beforeprint` で `details` を開き `afterprint` で戻す処理を持つ | - |
| 外部ライブラリ | 印からモジュールの URL を引く対応表を持ち、文書に印があるときだけ読む | `未確定`（要件.md の「外部ライブラリの読み込み方」） |
| エラー表示 | 外部ライブラリを読めない箇所に知らせの枠を出す | 見た目はモック作成で決める |
| 性能 | 配布ファイル 1 つのサイズの目標を決め、ビルドの検査の上限にする | 値はモジュール構成設計で、束ねた後の実測から決める |
| 動作環境 | 対応ブラウザの決定値を、PoC 検証の結果に合わせる | `未確定`（要件.md の「`@layer` と対応ブラウザの下限」） |
| 既存機能への影響 | `version()` と `--mdmark-version` の振る舞いを変えない | - |
