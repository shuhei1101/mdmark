## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 公開の入口 | `src/index.ts` から `mount`・`render` を公開する。配布物の入口は `dist/index.js` と `dist/index.css` の 1 つずつのまま | - |
| Markdown の解析 | GitHub Flavored Markdown を解析する外部ライブラリを、版を固定して配布物に束ねる | ライブラリは設計のライブラリ選定で決める |
| スクリプトの扱い | 解析した HTML から `script` 要素・イベント属性・`javascript:` の URL を落としてから描く | DOM に頼らないサニタイザーで落とす。許可する要素は列挙する。`style` 属性は許可せず、列の揃えは `text-align` の値だけを `mdmark-align-{left,center,right}` の class に移す（本文の CSS がこの class で揃えを当てる。モジュール構成設計で書く） |
| 印の読み取り | 解析器のトークンから HTML コメントの印を拾い、出力には残さない | 外部ライブラリの印は、描く場所を表す要素に置き換える |
| 設定 | `opts.config` をオブジェクトで受け、省いたキーに既定を当てる。Schema は `schemas/` に置く | ブラウザで YAML は読まない |
| 機能のオン・オフ | 設定の `features` に文書の `<!-- features: … -->` を重ねた結果を 1 か所で決め、機能のモジュールへ渡す | 知らない機能名は無視する |
| テーマ | 値を接頭辞 `--mdmark-` の CSS 変数で配り、mdmark の CSS を `@layer` に入れる。描く先の要素に `--mdmark-color-bg` の地の色を当てる | ダークの配色は `prefers-color-scheme: dark` に従う |
| 印刷 | `@media print` の CSS と、`beforeprint` で `details` を開き `afterprint` で戻す処理を持つ | 表の各セルに見出し行の文言を `data-label` で写す（`mount` と `render` の出力の両方。インターフェース定義に書く） |
| 外部ライブラリ | 印からモジュールの URL を引く対応表を持ち、文書に印があるときだけ URL を `import()` に渡して読む | import map は使わない |
| エラー表示 | 外部ライブラリを読めない箇所に知らせの枠を出す | 見た目はモック作成で決める |
| アクセシビリティ | 狭い幅で横スクロールするコードブロックと表へキーボードで届くようにし、表に続きがあることを示す | 示し方は画面設計で決める |
| CSS の書き方 | 本文の規則を `src/index.css` へ移すとき、CSS の入れ子が対応ブラウザの下限で効くかを確かめ、効かなければビルドで展開する | モジュール構成設計で決める |
| 性能 | 配布ファイル 1 つのサイズの目標を決め、ビルドの検査の上限にする | 値はモジュール構成設計で、束ねた後の実測から決める |
| 動作環境 | 非機能要件の対応ブラウザの下限を Chrome 99・Firefox 97・Safari 16.4 へ上げ、ビルドの target を合わせる | Safari は 16.4 のまま（`@layer` は 15.4 以降） |
| 既存機能への影響 | `version()` と `--mdmark-version` の振る舞いを変えない | - |

成立。
`render` は DOM に頼らずブラウザと Node で同じ出力を返し、外部ライブラリは `mount` の後から URL を `import()` に渡して読める。

機能が使える最初の版（`@mdn/browser-compat-data` 8.1.5）:

| 機能 | Chrome | Firefox | Safari |
| --- | --- | --- | --- |
| `@layer` | 99 | 97 | 15.4 |
| 動的 `import()` | 63 | 67 | 11.1 |
| import map | 89 | 108 | 16.4 |
| モジュールを読んだ後に足した import map | 133 | 150 | 18.4 |
| 非機能要件の下限 | 94 | 93 | 16.4 |

- 外部ライブラリの読み込みは、URL を `import()` に渡す形にする。`mount` の時点で足す import map は下限の版で効かない
- 対応ブラウザの下限は、`@layer` に合わせて Chrome 99・Firefox 97 へ上げる。今の下限は ES2022 の構文から導いた決定値で、ユーザーが決めた要件ではなく、起点 Issue が `@layer` での上書きを求めているため、ユーザーへの確認には回さない
- Playwright 同梱のブラウザは最新版で、実行の結果は下限の版を代表しない。下限は上の表の値で決めた

ライブラリ選定の材料:

- sanitize-html は許可する要素と属性を列挙する方式で、既定の許可に `details`・`summary` が無い。部品の custom element（[#6](https://github.com/shuhei1101/mdmark/issues/6)）も要素名の列挙が要る
- sanitize-html の既定は `class` 属性を落とすため、コードブロックの言語（`language-js`）と表のセルの寄せ（`style`）が出力から消える。残すには属性の許可が要る
- sanitize-html は HTML コメントを落とすため、印はサニタイザーの前に解析器のトークンから拾う

最小再現コードの要点（[poc/src/render.ts](https://github.com/shuhei1101/mdmark/blob/b594ce039a100cd6e327d1e7b1c1d09cb9bb54e2/poc/src/render.ts)）:

```ts
const md = new MarkdownIt({ html: true });
const tokens = md.parse(options.markdown, {});
for (const token of tokens) {
  if (token.type === "html_block") {
    token.content = takeMarks(token.content, context);
  }
  for (const child of token.children ?? []) {
    if (child.type === "html_inline") {
      child.content = takeMarks(child.content, context);
    }
  }
}
const html = sanitizeHtml(md.renderer.render(tokens, md.options, {}), {
  allowedTags: [...sanitizeHtml.defaults.allowedTags, "details", "summary"],
});
```

diff の見どころは、印を解析器のトークンの段で拾って取り除き、外部ライブラリの印だけを描く場所の要素に置き換えている点（[poc/src/render.ts](https://github.com/shuhei1101/mdmark/blob/b594ce039a100cd6e327d1e7b1c1d09cb9bb54e2/poc/src/render.ts)）と、その要素ごとに対応表の URL を `import()` に渡し、失敗した場所だけを知らせの枠に替えている点（[poc/src/index.ts](https://github.com/shuhei1101/mdmark/blob/b594ce039a100cd6e327d1e7b1c1d09cb9bb54e2/poc/src/index.ts)）。
実行の記録は [poc/検証の記録.log](https://github.com/shuhei1101/mdmark/blob/b594ce039a100cd6e327d1e7b1c1d09cb9bb54e2/poc/%E6%A4%9C%E8%A8%BC%E3%81%AE%E8%A8%98%E9%8C%B2.log)。
