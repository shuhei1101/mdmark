# 要件

## 要望

使う側のページが Markdown と設定を渡すと、mdmark がブラウザで文書を描く。
見た目は使う側の CSS で上書きできる。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 文書を描く | 公開関数 `mount(el, opts)` が、渡した要素の中に Markdown を HTML として描き、`update(markdown)`（本文だけを差し替えて描き直す）と `destroy()`（描いたものとイベントを片付ける）を返す |
| HTML 文字列にする | 公開関数 `render(markdown, opts)` が、画面を持たずに `mount` と同じ本文の HTML 文字列を返す。DOM に頼らず、ブラウザと Node の両方で動く |
| 設定の受け取り | 使う側のサーバーが `mdmark.config.yaml` を読んだオブジェクトを `opts.config` で受け取る。省いたキーには設定の既定を当てる |
| 設定の Schema | この Issue が読む設定のキー（`features`・`libraries`）の JSON Schema を `schemas/` に置く |
| テーマ | 見た目の値を接頭辞 `--mdmark-` の CSS 変数で配り、mdmark の CSS を `@layer` に入れる。使う側が層の外に書いた CSS は、詳細度によらず mdmark の CSS に勝つ。使う側の `theme.css` は、使う側のページが `<link>` で層の外に読む |
| 対応ブラウザ | 下限を、`@layer` が使える Chrome 99・Firefox 97・Safari 16.4 にする |
| 印刷・PDF | 印刷のとき、折り畳みを全て開き、図表を改ページで切らず、ダークの配色を解除し、リンクの URL を併記する |
| 機能のオン・オフ | 設定の `features` を既定にし、文書の `<!-- features: +機能 -機能 -->` がその文書だけ上書きする。決まったオン・オフを、機能を作る Issue が読める |
| 外部ライブラリ | 印とモジュールの対応表を持ち、文書が使う印があるときだけ、版を固定した URL を `import()` に渡してモジュールを読む（import map は使わない）。使わない文書では外部ライブラリへの要求が 0 件。URL は設定の `libraries` で上書きでき、対応表に無い印の名前も足せる |
| 例外 | 未知の印は無視して本文を描く。外部ライブラリを読めない箇所に知らせの枠を出し、ほかの箇所は描く |
| スクリプト | 文書に書いたスクリプト（`script` 要素・イベント属性・`javascript:` の URL）を実行しない |
| 完了の基準 | ビルドした配布物を読むページで `mount` を呼ぶと、GitHub Flavored Markdown の見出し・段落・リスト・表・コードブロック・リンクが描かれ、非機能要件の対応ブラウザの E2E が通る |

<!-- /table -->

## スコープ外

<!-- table: data -->

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 表・注意書き・タブなどの拡張記法と `registerExtension()` | 記法を作る Issue が、この Issue の印の読み取りと機能のオン・オフに載せる | [#4](https://github.com/shuhei1101/mdmark/issues/4) |
| 印刷時のタブの展開 | タブを作る Issue が、この Issue の印刷の仕組みに載せる | [#4](https://github.com/shuhei1101/mdmark/issues/4) |
| 索引（`opts.index`・`opts.docId`・`opts.linkResolver`）と設定の `index` | 索引を作る Issue が足す。この Issue の `mount` は索引を受け取らない | [#5](https://github.com/shuhei1101/mdmark/issues/5) |
| 対応表に載せる外部ライブラリ（Chart.js など）と `registerComponent()`、部品の JSON が Schema に合わないときの枠、設定の `libraries` で足す印と `registerComponent()` の棲み分け | 外部ライブラリを使う機能を作る Issue が足す。この Issue は対応表の仕組みを作り、テスト用の印で読み込みを確かめる | [#6](https://github.com/shuhei1101/mdmark/issues/6) |
| 差分のアダプター（`opts.diffSource`） | 差分表示を作る Issue が足す | [#7](https://github.com/shuhei1101/mdmark/issues/7) |
| `templates/` の `theme.css` の雛形、設定の `build`、未知の印を知らせる `check`、書き出す HTML への外部ライブラリの埋め込み（CDN を読まない） | CLI を作る Issue が足す | [#9](https://github.com/shuhei1101/mdmark/issues/9) |
| 設定の `version` | 版を上げる機能が読み書きする | [#10](https://github.com/shuhei1101/mdmark/issues/10) |

<!-- /table -->
