# Markdown をブラウザで描く土台（mount・render・テーマ・機能のオン・オフ）を作る

## 概要

使う側のページが Markdown と設定を渡すだけで mdmark がブラウザで文書を描き、見た目を使う側が上書きできるようにする。

## 背景

[Issue #3](https://github.com/shuhei1101/mdmark/issues/3) の要望。
[#12](https://github.com/shuhei1101/mdmark/pull/12) で入った土台は版を返す公開関数だけを持ち、Markdown を描く機能が無い。

## 計画書

| ファイル | 中身 |
| --- | --- |
| [要件](./要件.md) | 要望の整理と影響する UC 一覧 |
| [ライブラリ本体](./ライブラリ本体.md) | ライブラリ本体の計画書 |
| [確認ログ](./確認ログ.md) | ユーザーへの確認事項の決着 |
