# 要件

## 要望

読む人が、文書の 2 つのリビジョンを比べた差分を、描く先の要素の中で読める。
使う側は、リビジョンの一覧とリビジョンごとの本文を返す取り出し元（`DiffSource`）を渡す。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 行の色分け | 2 つのリビジョンの Markdown を行で比べ、前のリビジョンにだけある行を赤、後のリビジョンにだけある行を緑で出す。同じ行は色を付けずに出す（D-18） |
| 文字の色分け | 消した行と足した行が対になるとき、行の中で変わった文字だけを濃い赤・濃い緑にする（D-18）。日本語の文も語の切れ目で比べる |
| 色に頼らない表し方 | 消した行・足した行は、色のほかに行頭の `-`・`+` の印と読み上げの名前でも分かる |
| ミニマップ | 差分を開いている間、画面の右端に画面の高さいっぱいの縦の帯を貼り付け（描く先の要素がスクロールする枠の中にあるときは、その枠の右端）、消した行・足した行の位置を色の印で並べる。印を押すとその行へ差分が送られ、帯を押したまま上下に動かしても差分が送られる（mindstella の作りを参考にする・[確認ログ](./確認ログ.md)） |
| 取り出し元 | mdmark は `DiffSource` のインターフェースだけを持ち、Git や YAML の読み方は持たない（D-17）。`revisions(docId)` がリビジョンの一覧を新しい順に、`content(docId, revisionId)` がそのリビジョンの Markdown を返す |
| リビジョンの形 | `id`（文字列）・`at`（ISO 8601 の日時）を必須に、`label`（一言の説明）・`author`（書いた人）を任意に持つ（A-5 の 6 節） |
| 比べる 2 つのリビジョン | 既定は一番新しいリビジョンとその 1 つ前を比べ、読む人が前と後のリビジョンを選び直せる |
| 差分を出す入口 | `mount` の引数 `diffSource` に取り出し元を渡すと、描いた文書に差分を開く UI が付く（[確認ログ](./確認ログ.md)） |
| 取り出し元のサンプル | Git（コミット間）と YAML（項目ごとの変更履歴）の取り出し元をサンプルとして付け、使い方のページにコードとして載せる（D-17・[確認ログ](./確認ログ.md)） |
| 埋め込んだ HTML | `<!-- html -->` 〜 `<!-- /html -->` の範囲の HTML の変更も差分に出す（D-47）。既定はソースの行と文字の色分けで、読む人が描いた結果の前と後に切り替えられる（D-48） |
| 取り出せないとき | リビジョンの一覧か本文を取り出せないときは、差分の場所に知らせの枠を出し、黙って空にしない |
| 完了の基準 | 行と文字の色分け・埋め込んだ HTML の切り替え・取り出せないときの知らせが E2E で確かめられ、非機能要件の対応ブラウザで通る。サンプルの取り出し元は、テストで差分を出せることを確かめる |

<!-- /table -->

本文の差分は、描いた結果ではなく Markdown のソースの行で比べる。
D-48 の A 案が HTML のソースの色分けを「D-18 と同じ」としており、D-18 の色分けはソースの行に付くため。

文書の変更の 1 回分は「リビジョン」と呼ぶ。
mdmark では「版」が配布物の `v{MAJOR}.{MINOR}.{PATCH}` を指しており、同じ語にすると取り違えるため。

## スコープ外

<!-- table: data -->

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 書き出した 1 枚の HTML（`mdmark export`・`build`）で差分を出す | 書き出した HTML はリビジョンの一覧を持たず、取り出し元を渡す使う側のページが無い | 予定なし |
| Git や YAML の取り出し元を mdmark が持つ | 取り出し元ごとの事情を mdmark が抱えないため見送った（D-17 の B 案） | 予定なし |
| 左右に並べる表示との切り替え | 要望に含まれない | 予定なし |
| 図の部品の箱・線ごとの差分の色分け | 要望に含まれない。埋め込んだ HTML の描いた結果は前と後の切り替えで見る（D-48） | 予定なし |
| ai-monitor・mindstella の差分表示をこの差分表示へ置き換える | 使う側のリポジトリで行う | 予定なし |
| `src/knowledge/dictionary.ts` の `SEGMENTER` を読み込み時に作り、Firefox 98〜124 で配布物の読み込みが例外になる | 非機能要件『対応ブラウザ』（Firefox 98 以降）から外れる不具合で、今回の要望に含まれない | [#50](https://github.com/shuhei1101/mdmark/issues/50) |
