## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ノードの種類 | `MdmarkDiagramKind` と `NODE_KINDS` に判定フローチャートの開始・質問・アクション・結果の 4 種類を追加する。既存の 6 種類は変えない | 種類の名前は `start`・`question`・`action`・`result` |
| 凡例 | 追加した種類の凡例の名前を、判定フローチャートの意味（開始・質問・アクション・結果）にする。図に出る種類だけを凡例に出す今の処理を使う | - |
| ノードの形 | 追加した種類のノードを、開始は円・質問は菱形・アクションは角の丸くない四角・結果は両端の丸いノードで描く | - |
| 色 | 追加した種類ごとに `--mdmark-color-diagram-{種類}` を置き、全テーマのライト・ダークで値を持つ | 値は既存の種類の値を使い回す（開始 = `script`・質問 = `dm`・アクション = `mcp`・結果 = `external`） |
| アイコン | 追加した種類ごとに lucide のアイコンを 1 つ当てる | 開始 = play・質問 = circle-question-mark・アクション = wrench・結果 = flag |
| 書き方の警告 | 知らない種類の警告の「使える種類」の並びに、追加した種類が出る | `NODE_KINDS` の並びから作る今の処理のまま |
| 呼び方 | フロー図の書き方の警告と凡例の「箱」を、既存の種類の分も含めて「ノード」にする | 文言を確かめる既存のテストの期待値も変える |
| ボタンの帯 | 右上のボタンを 1.75rem・帯の余白を 0.25rem にして帯を低くし、狭い枠（30rem 未満）では間を詰めてスマホ幅（390px）で 1 行に収める。収まらない幅（約 266px 未満）では折り返す | 図の枠の全ての図（フロー図・シーケンス図・グラフ）に当たる |
| 倍率の表示 | 倍率のボタンに、全体が収まる倍率を 100% とした今の倍率を出す。拡大の上限は今の定義の大きさの 3 倍のまま | 図の枠の全ての図に当たる。図とライトボックスが共有する `attachZoom` に倍率の文字の基準 `percentBase` を加え、図だけを `fit` にする（ライトボックスは画像の大きさを 100% のまま） |
| 配置 | ノードの `x`・`y`・`w`・`h` と線の `points` は今のフロー図と同じく定義に書く | 自動配置は `## スコープ外` |
| 文字の折り返し | 判定フローチャートのノードの名前を `word-break: auto-phrase` で文節ごとに折り返す | 対応するのは Chromium 系だけで、Firefox・Safari では文字ごとの折り返しになる。Chromium だけの見た目の向上として扱い、E2E の Firefox では名前がノードの中に収まることだけを確かめる |
| アクセシビリティ | 色だけでなく、形・アイコン・種類の名前でも種類を見分けられる | 部品設計の `accessibility` の今の決まりに従う |
| 既存機能への影響 | 既存の種類のノード・線・凡例・ツールチップ・拡大と移動の描き方を変えない | 既存の結合テスト・E2E を回帰として回す |

## テスト結果

ドキュメント修正の工程は `docs/` と外部ライブラリの設計書だけを変え、関係する単体・結合テストは無い。
