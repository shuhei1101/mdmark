## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ノードの種類 | `MdmarkDiagramKind` と `NODE_KINDS` に判定フローチャートの開始・質問・アクション・結果の 4 種類を追加する。既存の 6 種類は変えない | 種類の名前は `未確定`（要件.md の `## 要望`、決める段: 部品設計） |
| 凡例 | 追加した種類の凡例の名前を、判定フローチャートの意味（開始・質問・アクション・結果）にする。図に出る種類だけを凡例に出す今の処理を使う | - |
| ノードの形 | 追加した種類のノードを、種類ごとの形で描く | `未確定`（要件.md の `## 要望`、決める段: モック作成） |
| 色 | 追加した種類ごとに `--mdmark-color-diagram-{種類}` を置き、全テーマのライト・ダークで値を持つ | 値はモック作成で決める |
| アイコン | 追加した種類ごとに lucide のアイコンを 1 つ当てる | アイコンはモック作成で決める |
| 書き方の警告 | 知らない種類の警告の「使える種類」の並びに、追加した種類が出る | `NODE_KINDS` の並びから作る今の処理のまま |
| 配置 | ノードの `x`・`y`・`w`・`h` と線の `points` は今のフロー図と同じく定義に書く | `未確定`（要件.md の `## 要望`、決める段: モジュール構成設計） |
| 文字の折り返し | 判定フローチャートのノードの名前を `word-break: auto-phrase` で文節ごとに折り返す | 対応するのは Chromium 系だけで、Firefox・Safari では文字ごとの折り返しになる。Chromium だけの見た目の向上として扱うことと、Firefox の見え方を E2E で確かめるかは部品設計で決める |
| アクセシビリティ | 色だけでなく、形・アイコン・種類の名前でも種類を見分けられる | 部品設計の `accessibility` の今の決まりに従う |
| 既存機能への影響 | 既存の種類のノード・線・凡例・ツールチップ・拡大と移動の描き方を変えない | 既存の結合テスト・E2E を回帰として回す |
