## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 最初の高さ | 文書の中の表示する枠の最初の高さを `min(定義の高さ × 全体が収まる倍率, --mdmark-diagram-max-height の計算値)` にする。`reset` が `style.maxHeight` を外して CSS の `max-height` の計算値を読み、高さを決める | 今の見た目を変えない。CSS の `max-height` は残し、`style.maxHeight`（定義の高さ × 今の倍率）で上書きする |
| 高さを変えたときの上限 | 使う側が高さを変えたとき、`--mdmark-diagram-max-height` で止めず、定義の高さ × 今の倍率を上限にする。倍率を変えるたびに上限を合わせ直す | 部品設計『図の枠』の `--mdmark-diagram-max-height` と「拡大・縮小する」 |
| 全画面のモーダル | 今のまま（表示する枠をモーダルの高さに合わせる） | - |
| CSS 変数の説明 | 部品設計『図の枠』と `docs/リファレンス/API.md` の `--mdmark-diagram-max-height` を「文書の中の表示する枠の最初の高さの上限」にする | 「全体が収まる倍率はこの高さと枠の幅に収める」も実装（幅だけで決める）に合わせる |
| 単体テスト | `attachDiagrams` に、定義の高さ × 倍率が `--mdmark-diagram-max-height` を超える図で、最初の高さが上限の値になることと、`style.height` を定義の高さ × 倍率にすると `clientHeight` がその値になることを確かめるテストを追加する | - |
| 結合テスト | 部品『図の枠』の `Fit` のストーリー（操作が付く）で、定義の高さ × 倍率が 36rem を超えるまで拡大してから、表示する枠に `resize: vertical` を当てて高さを広げたとき、36rem を超えて定義の高さ × 倍率まで広がることを確かめる | `Max` などの `zoom` を渡すストーリーには操作が付かない |
| 印刷 | `src/index.css` の `@media print .mdmark` で、図の表示する枠のインラインの高さと上限を `height: auto !important; max-height: none !important` で外す | モジュール構成『公開の入口』の `@media print .mdmark` |
| 結合テスト（印刷） | 部品『図の枠』の `Max` のストーリーを印刷のメディア（Playwright の `page.emulateMedia`）で開き、表示する枠の高さが定義の高さ × 倍率になることを確かめる | - |
