# 要件

## 要望

- VS Code 拡張機能の設定の読み取り（`pickPreviewConfig`）で、重ねた設定の `labels` がマップのときだけ取り出し、プレビューの `render` の `config` と書き出す HTML の `config` に入れる
- プレビュー・HTML に書き出す・ブラウザで開く・PDF に印刷のどれでも、`labels.paramCopy` を書いた `mdmark.config.yaml` の下の文書で、操作できる部品の今の値をコピーするボタンがその文言で描かれる
- `labels` がマップでないとき・書かないときは渡さず、ボタンは既定の文言で描かれる（`labels` の中の知らないキーと空文字・文字列でない値は mdmark が無視する）
