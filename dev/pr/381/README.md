# VS Code 拡張機能のプレビューと書き出す HTML へ設定 labels（部品の文言）を通す

## 概要

文書を書く人が `mdmark.config.yaml` に `labels.paramCopy` を書くと、VS Code 拡張機能のプレビューと書き出した HTML でも、操作できる部品の今の値をコピーするボタンがその文言で描かれる。

## 背景

[Issue #259](https://github.com/shuhei1101/mdmark/issues/259) の要望。
[PR #258](https://github.com/shuhei1101/mdmark/pull/258)（[Issue #155](https://github.com/shuhei1101/mdmark/issues/155)）でライブラリ本体と CLI に設定 `labels.paramCopy` が入ったが、拡張機能は `vscode/src/config.ts` の `pickPreviewConfig` で `labels` を取り出していないため、プレビューと書き出し（HTML に書き出す・ブラウザで開く・PDF に印刷）ではボタンが既定の文言のまま描かれる。
[docs/リファレンス/VSCode拡張機能.md](https://github.com/shuhei1101/mdmark/blob/develop/docs/%E3%83%AA%E3%83%95%E3%82%A1%E3%83%AC%E3%83%B3%E3%82%B9/VSCode%E6%8B%A1%E5%BC%B5%E6%A9%9F%E8%83%BD.md) は `labels` も渡すと書いており、実装と食い違っている。
