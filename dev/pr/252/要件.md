# 要件

## 要望

VS Code のプレビューを背面に回して Webview が作り直されたあと、表に戻して描き直したプレビューのスクロールの位置を、見えている先頭が行の途中にあったときも含めて、背面に回す前と 1 px 以内で同じ位置へ戻す。

- 歯車（`mdmark.openSettings`）から設定画面を開き、プレビューのタブを押して表に戻したとき、プレビューの `scrollY` が押す前と同じになる（`tests/e2e/単一ユースケース/プレビューから設定を開く.spec.ts` の `test_normal` が pass する）
- 狭い幅で右側の目次を上端の帯にしているとき（`topInset` が 0 でない）も同じ
- 差分のパネルも同じく戻す
- エディタへ送る `revealLine` の行は今のとおり整数のまま送り、戻した位置をエディタへ送り返さない

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| `vscode/src/webview/scroll.ts` の `lineForTop`（内分した行番号を `Math.floor` で切り捨てる） | [7fb28e4](https://github.com/shuhei1101/mdmark/commit/7fb28e4)（`VS Code で mdmark のプレビューを出す拡張機能を作る (#69)`） | プレビューのスクロールをエディタへ合わせるため、見えている先頭を `revealLine` で送る整数の行にする（インターフェース定義『スクロールを合わせる』の制約「プレビューから合わせる」） | 1 回 | 切り捨ては `revealLine` の行には要るため残し、保存する位置にだけ切り捨てない値を使えば目的を壊さない |
| `vscode/src/webview/preview.ts` の `saveLine`（`currentLine()` を `setState({ line })` で保存する） | [cb7213f](https://github.com/shuhei1101/mdmark/commit/cb7213f)（`VS Code のプレビューを背面から表に戻したとき、作り直した Webview を前のスクロールの位置へ戻す (#243)`） | 背面の間の書き換えで文書の高さが変わっても同じ箇所へ戻すため、位置を元の行番号で持つ | 1 回 | 元の行番号で持つ目的は保ったまま、行の途中の割合まで持てば行の途中の位置も戻る。同じ範囲を直し続けてはいない |
