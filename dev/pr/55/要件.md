# 要件

## 要望

文書を書く人が、ボード表示・表形式のビュー、全項目の検索、選んだ箇所へのコメントの部品を文書に置ける。
読む人は、ビューで項目を見て、検索で絞り、選んだ箇所にコメントを付けられる。
使う側は、同じ部品を自分のページの JavaScript・TypeScript から呼べる。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| ビュー | 項目の集まりを、列ごとに分けたボード表示と、表形式のビューで描く。ビューは部品として読み込み、見た目はテーマの CSS 変数、振る舞いは部品のオプションで変える（D-19・D-5） |
| ビューの項目 | 印で囲んだ Markdown の表の行を項目、列を項目の値にする。印に対応しない表示（GitHub など）では表のまま読める |
| 検索 | ビューの全項目を、項目の全ての列の文字で絞り込む。合わない項目は隠し、合った件数を出す |
| コメント | 読む人が文書の中で選んだ箇所にコメントを付け、付いたコメントを選んだ箇所の印から開ける（D-36）。機能 `comments` を足し、既定はオフにする |
| コメントの保存 | mdmark はコメントを保存しない。使う側が `mount` にコメントの読み書きの関数を渡し、使う側の保存先に残す（差分の取得と同じ形。D-17） |
| JavaScript・TypeScript から使う | ビュー・検索・コメントの部品を描く関数を配布物から出し、使う側のページの JavaScript・TypeScript と、`registerExtension` の拡張のモジュールから呼べる。配布物の型定義に部品の関数の型を載せる（D-50）。文書の中から使う範囲は `未確定`（下の論点） |
| スクリプト | `未確定`（下の論点）。案 A なら、文書に書いた任意のスクリプトは今のとおり動かさず（D-22）、動くのは mdmark の部品と、使う側が登録した拡張だけ |
| 読み込み | 部品のモジュールは、印のある文書・関数を呼んだときにだけ読み込む（D-12）。非機能要件の配布ファイル 1 つのサイズを超えない |
| 機能のオン・オフ | ビュー・検索・コメントを `features` の機能として足し、文書の印で上書きできる今の仕組みに載せる |
| 書き出し | `mdmark export`・`mdmark build` で書き出した 1 枚の HTML でも、ビューと検索が外を読まずに動く |
| 完了の基準 | ビュー・検索・コメントの部品が、文書の印と使う側の JavaScript の呼び出しの両方で E2E で確かめられ、非機能要件の対応ブラウザで通る |

<!-- /table -->

`未確定`: 全項目の検索の範囲（決める段: 単一ユースケース設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | ビューの全項目の全ての列を検索する | ビューと同じ部品で閉じ、作りが小さい | 文書の本文は検索できない |
| B | 文書の本文（見出し・段落・表）も検索する | 部品の無い文書でも使える | 本文の中の位置へ移る操作が要り、範囲が広がる |
| C | まとめた HTML の全ての文書を検索する | 文書をまたいで探せる | [#11](https://github.com/shuhei1101/mdmark/issues/11) の文書を探すツールと範囲が重なる |

推奨: A

Issue は検索をビューと並べたよく使う部品として挙げており、全項目はビューの項目を指すと読める。

`未確定`: 「Markdown の中の JavaScript・TypeScript から使う」の範囲（決める段: 複合ユースケース設計。ユーザーへ確認する）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 部品を描く関数を配布物から出し、使う側のページと `registerExtension` の拡張のモジュールから呼ぶ。文書に書いたスクリプトは動かさない | D-22 のまま安全に配れる。拡張のモジュールから呼べば、文書の印の場所に部品を描ける | 文書の中にスクリプトを直接書いて呼ぶことはできない |
| B | 文書に書いたスクリプトを動かし、その中から部品を呼べる | 文書だけで完結する | D-22 を覆し、#45 で保ったサニタイズの条件を崩す |

推奨: A

D-22 で文書に書いたスクリプトは動かさないと決めており、#45 もその条件を保った。
拡張のモジュールは文書の印の場所に描くため、文書から部品を使う道は A で開ける。
