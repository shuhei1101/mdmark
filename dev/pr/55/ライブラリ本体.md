## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ビュー | 印の項目を、列の値ごとに分けたボード表示と、表形式のビューで描き、ビューの上の切り替えで行き来する。表形式のビューは記法の表の並べ替え・絞り込みを使い回す | 項目は印で囲んだ Markdown の表の行（[要件](./要件.md)） |
| 列の絞り込み | 表形式のビューの列の見出しに、印の `filter=列名:種類` で指定した列ごとの絞り込みを付け、記法の表の絞り込みを使い回す。ボード表示には当てない | 検索欄と件数は持たない（[確認ログ](./確認ログ.md)） |
| ボードの列の見出し | 列の値の前に lucide のアイコンを出す。よく使う値には既定のアイコンを当て、印の引数で値ごとに上書きできる | 印の `icons=値:アイコンの名前,…`。使えるアイコンは mdmark が束ねるものに限る（インターフェース定義『文書を描く』の制約・[確認ログ](./確認ログ.md)） |
| コメント | 読む人が本文の文字を選ぶとコメントのボタンを出し、書いたコメントを選んだ文字と前後の文字と一緒に残す。付いた箇所に印を付け、印からコメントを開く。`update` で描き直した後は前後の文字で箇所を探し直し、見つからないコメントは文書の末尾の一覧に出す | 保存は使う側が `mount` に渡す読み書きの関数で行う（[要件](./要件.md)）。機能 `comments` の既定はオフ |
| JavaScript・TypeScript から使う | ビュー・コメントを描く関数を配布物から出し、要素と項目の値・オプションを受け取って描き、片付けの関数を返す。配布物の型定義に関数と引数の型を載せる | 使う側のページと `registerExtension` の拡張のモジュールから呼ぶ。文書に書いたスクリプトは動かさない（[確認ログ](./確認ログ.md)） |
| 見た目 | 色・余白・角丸はテーマの CSS 変数で配り、部品の CSS は今の `@layer` に入れる | デザイン方針に沿ってモックで決める |
| 部品のモジュールの読み込み | ビュー・コメントを `dist/view.js`・`dist/comments.js` に分け、印のある文書・関数を呼んだときにだけ読む。`export`・`build` は印のある文書にだけ `dist/view.js` を埋める | 使うときだけ読む決まり（[要件](./要件.md) の D-12）に合わせる（モジュール構成『ビューとコメント』） |
| 機能のオン・オフ | ビュー・コメントを `features` に足し、文書の印で上書きできる今の仕組みに載せる。オフのときビューの印の範囲は表のまま出す | - |
| 書き出し | `mdmark export`・`build` の 1 枚にビューと列の絞り込みを描き、外を読まずに動かす | - |
| 印刷 | ビューは印刷に出し、ビューの切り替え・列の絞り込みのボタン・コメントのボタンは出さない | - |
| アクセシビリティ | ビューの切り替えと列の絞り込みはキーボードで操作できる。コメントの印はフォーカスでき、Enter で開く | - |
| セキュリティ | コメントの本文と項目の値は文字として描き、HTML として解釈しない | - |
