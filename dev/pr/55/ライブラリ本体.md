## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ビュー | 印の項目を、列の値ごとに分けたボード表示と、表形式のビューで描き、ビューの上の切り替えで行き来する。表形式のビューは記法の表の並べ替え・絞り込みを使い回す | 項目は印で囲んだ Markdown の表の行（[要件](./要件.md)） |
| 検索 | ビューの上に検索欄を置き、入力した文字を全ての列に部分一致で当てて合わない項目を隠し、合った件数を出す。大文字・小文字と全角・半角は区別しない | 検索の範囲は `未確定`（[要件](./要件.md)） |
| コメント | 読む人が本文の文字を選ぶとコメントのボタンを出し、書いたコメントを選んだ文字と前後の文字と一緒に残す。付いた箇所に印を付け、印からコメントを開く。`update` で描き直した後は前後の文字で箇所を探し直し、見つからないコメントは文書の末尾の一覧に出す | 保存は使う側が `mount` に渡す読み書きの関数で行う（[要件](./要件.md)）。機能 `comments` の既定はオフ |
| JavaScript・TypeScript から使う | ビュー・検索・コメントを描く関数を配布物から出し、要素と項目の値・オプションを受け取って描き、片付けの関数を返す。配布物の型定義に関数と引数の型を載せる | 範囲は `未確定`（[要件](./要件.md)） |
| 見た目 | 色・余白・角丸はテーマの CSS 変数で配り、部品の CSS は今の `@layer` に入れる | デザイン方針に沿ってモックで決める |
| 部品のモジュールの読み込み | `未確定`（決める段: モジュール構成設計） | 下の表 |
| 機能のオン・オフ | ビュー・検索・コメントを `features` に足し、文書の印で上書きできる今の仕組みに載せる。オフのときビューの印の範囲は表のまま出す | - |
| 書き出し | `mdmark export`・`build` の 1 枚にビューと検索を描き、外を読まずに動かす | - |
| 印刷 | ビューは印刷に出し、検索欄・ビューの切り替え・コメントのボタンは出さない | - |
| アクセシビリティ | ビューの切り替えと検索欄はキーボードで操作でき、検索の件数を読み上げる。コメントの印はフォーカスでき、Enter で開く | - |
| セキュリティ | コメントの本文と項目の値は文字として描き、HTML として解釈しない | - |
