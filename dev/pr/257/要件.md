# 要件

## 要望

描いた文書の図の枠（`.mdmark-diagram-box`）が、次の場所で枠の中の枠にならないようにする。

- 操作できる部品の枠（`.mdmark-param`）の中に置いた図（`<mdmark-param>` のグラフ）
- 使う側の枠を持つ面（詳細パネル・モーダルなど）の中に描いた図

確かめる基準: [Issue #154](https://github.com/shuhei1101/mdmark/issues/154) と同じ配置（枠を持つ面の中の `<mdmark-param>` と `<mdmark-chart>`）を、`detect_screen_issues`（1280x800・390x844）で測ったとき、図の枠による `nested-cards` が出ない。

図の枠のまとまりの示し方: 図の枠の線（`box-shadow` の値）を CSS カスタムプロパティ `--mdmark-diagram-box-shadow` で持ち、`.mdmark-param` の中では mdmark が外し、枠を持つ面の中では使う側が `none` を指定して外す。
全画面のモーダルの中は、面に指定した値を受け継がず今の線のままにする。
既定値は `var(--mdmark-diagram-box-shadow, inset 0 0 0 1px var(--mdmark-color-border))` のフォールバックで持つ（[確認ログ](./確認ログ.md)）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 図の枠以外の部品（表・コードブロック・注意書き）の枠を、枠を持つ面の中で外す | Issue の計測で `nested-cards` に当たったのは図の枠だけで、他の部品は検出されていない | 予定なし |
| mindstella の埋め込み先の面で、図の枠を外す CSS カスタムプロパティを指定する | mindstella のリポジトリの作業（この PR のマージ後に mindstella 側で行う） | 予定なし |
