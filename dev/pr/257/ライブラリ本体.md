## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図の枠のまとまりの示し方 | 要件の `未確定`（案 A / B）をモック作成で決め、決めた案で `.mdmark-diagram-box` の線を当て直す | `未確定`（決める工程: モック作成） |
| 操作できる部品の中の図 | `.mdmark-param` の中の `.mdmark-diagram-box` には線を引かない。`.mdmark-param` の枠は残す | 案 A / B のどちらでも同じ |
| 全画面のモーダル | モーダルの中の図の枠の見た目は今のままにする | - |
| 部品設計 | 部品『図の枠』の `css_properties`（案 B のとき）と、部品『操作できる部品』の中の図の枠の扱いを書く | - |
| 結合テスト | 部品『操作できる部品』のストーリーで、中の `.mdmark-diagram-box` の `box-shadow` が `none` になることを確かめる。案 B のときは、部品『図の枠』のストーリーで CSS カスタムプロパティを指定すると線が外れることを確かめる | - |
