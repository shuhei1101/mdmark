# 要件

## 要望

印 `map` の範囲に Mermaid のブロックと補足（`<!-- map-data: format=yaml` 〜 `-->`）を置いた文書を、mdmark が自動配置の図として描き、読む人が階層を辿れる。
対象は A-35 の No 1〜5・8・9 と No 18（No 6 のノードのページと No 7 の視点はユーザーの判断で外した）。今の `flow`・`sequence` は変更せずに残す。

| No | 機能 | 終わりの条件 |
| --- | --- | --- |
| 1 | 書き方 | `<!-- map: … -->`〜`<!-- /map -->` の範囲の中の `mermaid` のブロック 1 つと補足 1 つを 1 つの図として読む。印の引数は見せ方の初期値（`focus`・`play`・`title`・`open`・`closed`）だけを持つ。`open`・`closed` は今の印と同じく図を折りたたみに入れる。図の種類は Mermaid の 1 行目で決め、この PR で描くのは `flowchart` と `sequenceDiagram`。補足は `version` と機能ごとのトップレベルのキー（`notes`・`walkthroughs`・`layout`・`plays_over`）を持ち、スキーマで検査する。知らないキー・知らない引数・描かない図の種類は描画を止めずに書き方の警告にする。1 つの文書に図を複数置ける |
| 2 | 自動配置 | `flowchart` の `subgraph` を入れ子の箱として、階層ごとに `direction` の向きで並べる。座標を書かずに、ノード・箱が重ならず、線が箱を横切らない。日本語の長いラベルは箱の幅の上限で折り返す |
| 3 | 配置と見た目の調整 | 補足の `layout` で、ノード・箱・線ごとに大きさ・色（mdmark の名前の色）・位置（同じ段に揃える・並び順の固定・寄せる・座標の固定）・線の出入りの辺と経由点を上書きする。上書きの無い部分は自動配置のまま。中へ入る・開閉で配置し直しても、上書きを保つ |
| 4 | 中へ入る | 箱をダブルクリック（キーボードでは Enter）すると、その箱の中だけを配置し直し、外は薄く残す。外から中への線は薄く残した外の箱から引く。図の右上の戻るボタンか Esc で外へ戻る |
| 5 | 開閉 | 箱を閉じると中を隠し、中への線を閉じた箱へ付け替え、同じ箱どうしの線を 1 本にまとめて件数を出し、件数のツールチップに元の線を出す。開閉と中へ入った状態は、同じタブの中で描き直しても保つ |
| 8 | 巡回 | 補足の `walkthroughs` の手順を、前へ・次へで進める。各手順は説明の文と、中へ入る箱・強調するノードを指す |
| 9 | シーケンスの再生 | `sequenceDiagram` の図を、`plays_over` で指した同じノードを持つ構成図の上で 1 通ずつ動かす。再生している間は今のメッセージの線の上の印を繰り返し動かし、自動で進める間隔（秒）を選べる。動きを減らす設定（`prefers-reduced-motion`）では強調と説明だけを出す |
| 18 | 枠の入れ子と層の分割 | 枠は `subgraph` の入れ子、層は補足の `layout` の層の指定で描き、構成図の 3 層（LLM・処理・データ）の見た目を残す。使い方集『構成図の決まり』に、入れ子は 2 レイヤーまでを推奨し、深いものは別の図に切り出してリンクする決まりと、枠と層の入れ子の凡例・層の色の重なり・枠のタイトルの位置の決まりを追加する（#309） |

今の図の機能は A-38 のとおりに扱う。

| 今の機能 | 新しい図での形 |
| --- | --- |
| 箱の種類（`llm`・`dm`・`script`・`mcp`・`data`・`external`）と色・アイコン | Mermaid のクラス（`:::llm` など） |
| 線の種類（`flow`・`read`・`write`・`reply`・`loop`）と模様 | Mermaid の矢印（`-->`・`-.->`・`==>`）とクラス |
| 箱の説明（`hint`・`io`）と線の詳細（`tip`） | 補足の `notes`。ツールチップに出す |
| 拡大・縮小・移動・全画面・凡例・ツールチップ・リサイズハンドル | 今の図の枠をそのまま使う |
| 箱の名前の用語の下線 | ラベルと補足の文に付ける |
| 点検（`check`） | 補足のスキーマの検査、補足から指すノード・線の ID の参照の検査、補足の値に `--` を含む警告を追加する |

`map` の範囲の中の `mermaid` のブロックは、`mermaid` のコードブロックの描画（mermaid のライブラリで描く経路）の対象から外す。

描く見た目は今のフロー図・シーケンス図の部品を使い、自動配置の結果を部品の定義にして渡す（線の交差の飛び越え・ノードの見た目・ツールチップが今の図と同じになる）。箱は部品の上に重ね、色を変えられる。操作しても描き直しても、図の倍率と表示する位置は変えない。

自動配置と Mermaid の記法の読み取りは、外のライブラリを使わずに mdmark に独自に作る（PoC 検証で成立を確認した。ライブラリ本体.md の `## PoC 結果`）。
