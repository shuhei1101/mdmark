# 要件

## 要望

印 `map` の範囲に Mermaid のブロックと補足（`<!-- map-data: format=yaml` 〜 `-->`）を置いた文書を、mdmark が自動配置の図として描き、読む人が階層を辿れる。
対象は A-35 の No 1〜5・8・9 と No 18（No 6 のノードのページと No 7 の視点はユーザーの判断で外した）と、map のシーケンス図への #404 の参加者の強調・表示と並び順（ユーザーの判断で取り込んだ）。今の `flow`・`sequence` は変更せずに残す。

| No | 機能 | 終わりの条件 |
| --- | --- | --- |
| 1 | 書き方 | `<!-- map: … -->`〜`<!-- /map -->` の範囲の中の `mermaid` のブロック 1 つと補足 1 つを 1 つの図として読む。印の引数は見せ方の初期値（`focus`・`play`・`title`・`open`・`closed`・`interval`）だけを持つ。`open`・`closed` は今の印と同じく図を折りたたみに入れる。図の種類は Mermaid の 1 行目で決め、この PR で描くのは `flowchart` と `sequenceDiagram`。補足は `version` と機能ごとのトップレベルのキー（`notes`・`walkthroughs`・`layout`・`plays_over`）を持ち、スキーマで検査する。知らないキー・知らない引数・描かない図の種類は描画を止めずに書き方の警告にする。1 つの文書に図を複数置ける |
| 2 | 自動配置 | `flowchart` の `subgraph` を入れ子の箱として、階層ごとに `direction` の向きで並べる。座標を書かずに、ノード・箱が重ならず、線が箱を横切らない。日本語の長いラベルは箱の幅の上限で折り返す |
| 3 | 配置と見た目の調整 | 補足の `layout` で、ノード・箱・線ごとに大きさ・色（mdmark の名前の色）・位置（同じ段に揃える・並び順の固定・寄せる・座標の固定）・線の出入りの辺と経由点・データの印（`packet`。色は線の色・元のノードの色・先のノードの色・色の名前、形は丸・四角・ひし形。既定は線の色の丸）・グループを最初に閉じるか（既定は開く）を上書きする。上書きの無い部分は自動配置のまま。中へ入る・開閉で配置し直しても、上書きを保つ |
| 4 | 中へ入る | 箱のタイトル（ボタン）を押すと、その箱の中だけを配置し直し、外は薄く残す。今入っている箱のタイトルは押せない。外から中への線は薄く残した外の箱から引く。図の右上の戻るボタンか Esc で外へ戻る。右上のツールの先頭に戻る・全て開く・全て閉じるを常に同じ位置で置き（全体の図では戻るは押せない）、図を動かす矢印のボタンは置かない |
| 5 | 開閉 | 箱を閉じると中を隠し、中への線を閉じた箱へ付け替え、同じ箱どうしの線を 1 本にまとめる（本数とラベルは出さない）。Shift を押しながら開閉のボタンを押すと、その箱と中の箱を全て開閉する。開閉と中へ入った状態は、同じタブの中で描き直しても保つ |
| 8 | 巡回 | 補足の `walkthroughs` の手順を、図の枠の下に常に出す帯の前へ・停止・自動で進める・次への 4 つのボタンで進める。帯の 1 行目に番号（左）と操作のボタン（右）、2 行目から説明の文を出し、説明の文の長さと行数によらずボタンの位置を変えない（説明の文が無いときは 1 行目だけ）。前へ・次へは常に押せ、端では反対の端へ回る（始める前の前へは最後の手順へ）。自動で進める間隔（秒）は印の引数 `interval` で決め、画面からは変えない（最後の次は最初へ戻る）。各手順は説明の文と、中へ入る箱・強調するノードを指し、強調するノードどうしの線を太くして、データの印を元から先へ流し続ける（両向きの矢印 `<-->` は両方へ）。強調するノードが図の枠の外にあるときだけ、図の枠の中をそのノードが入るまでスクロールする |
| 9 | シーケンスの再生 | `sequenceDiagram` の図の下に、構成図の案内と同じ帯（番号・説明の文と、前へ・停止・自動で進める・次への 4 つのボタン）を常に出し、メッセージを 1 通ずつ進める。帯の文はメッセージの文と補足の `notes` の説明（改行はそのまま）。進めたメッセージは、`plays_over` で指した同じノードを持つ構成図の上でも強調する（構成図の案内を始めるとシーケンス図の強調は解く）。再生している間は、構成図とシーケンス図の両方で今のメッセージの線を太くして、データの印を送り手から受け手へ流し続ける。ボタンと自動で進める間隔は巡回と同じ（最後の次は最初へ戻る）。データの印は再生の機能に欠かせない動きのため、読者が再生・次へを押して始めた動きは、動きを減らす設定（`prefers-reduced-motion`）でも流す（今の GIF と同じく、自動で始める再生は動きを減らす設定では止めて始める） |
| 404 | シーケンス図の参加者 | map のシーケンス図で、参加者の箱を押すとその参加者が送る・受けるメッセージとライフラインを強調し、ほかを薄くする（2 人以上ならそのあいだのメッセージ）。参加者の箱の右上のつまみを押したまま左右へ動かして（キーボードでは Alt + 左右の矢印）並び順を変え、右上の「参加者の並び順を元に戻す」で記載の順に戻す（参加者の表示と非表示はユーザーの判断で作らない） |
| 18 | 枠の入れ子と層の分割 | 枠は `subgraph` の入れ子、層は補足の `layout` の層の指定で描く。層の名前・並び・色は使う側が決め、mdmark は層の種類を持たない。使い方集『構成図の決まり』に、入れ子は 2 レイヤーまでを推奨し、深いものは別の図に切り出してリンクする決まりと、枠と層の入れ子の凡例・層の色の重なり・枠のタイトルの位置の決まりを追加する（#309） |

今の図の機能は A-38 のとおりに扱う。

| 今の機能 | 新しい図での形 |
| --- | --- |
| 箱の種類（`llm`・`dm`・`script`・`mcp`・`data`・`external`）と色・アイコン | mdmark は種類を持たない。使う側が設定（`mdmark.config.yaml` の `map.kinds`）で、種類ごとの名前・アイコン（Lucide の名前）・形（`rounded`・`rect`・`pill`・`double`）・色を作り、Mermaid のクラス（`:::app` など）で指す。種類を書かないノードは種類の行を出さない |
| 線の種類（`flow`・`read`・`write`・`reply`・`loop`）と模様 | mdmark は線の意味を持たない。使う側が設定（`map.lines`）で、Mermaid の矢印（`-->`・`-.->`・`==>`）ごとと名前ごとに、名前・模様（`solid`・`dashed`・`dotted`・`dash-dot`・`long-dash`）・太さ・矢じり（`filled`・`open`・`none`）・色を作る。名前の線は補足の `layout` の `line` で指す |
| 箱の説明（`hint`・`io`）と線の詳細（`tip`） | 補足の `notes`。ツールチップに出す |
| 拡大・縮小・移動・全画面・凡例・ツールチップ・リサイズハンドル | 今の図の枠をそのまま使う。凡例は、図で使っている種類と線のうち設定で名前を付けたものだけを、図の枠と帯のあいだに出す |
| 箱の名前の用語の下線 | ラベルと補足の文に付ける |
| 点検（`check`） | 補足のスキーマの検査、補足から指すノード・線の ID の参照の検査、補足の値に `--` を含む警告を追加する |

`map` の範囲の中の `mermaid` のブロックは、`mermaid` のコードブロックの描画（mermaid のライブラリで描く経路）の対象から外す。

描く見た目は今のフロー図・シーケンス図の部品を使い、自動配置の結果を部品の定義にして渡す（線の交差の飛び越え・ノードの見た目・ツールチップが今の図と同じになる）。箱は部品の上に重ね、色を変えられる。構成図とシーケンス図の線にポインターを当てると、線を太くして両端のノードを強調し（ほかは薄くしない）、補足の `notes` に説明がある線だけツールチップに説明を出す。ポインターの形は変えない。

図の枠は常に置き場所の幅いっぱい（`wide` の範囲と同じ幅）に広げ、本文の幅との切り替えのボタンは置かない。倍率は等倍より縮めず、収まらない分は図の枠の中で横にスクロールする。表示する枠の高さは開いたときの高さ（上限あり）か、読者がリサイズハンドルで変えた高さを保つ。操作しても描き直しても、図の倍率・表示する位置・枠の高さは変えず、ノードと箱は前の位置から今の位置へ動かす（`prefers-reduced-motion` では動かさない）。

自動配置と Mermaid の記法の読み取りは、外のライブラリを使わずに mdmark に独自に作る（PoC 検証で成立を確認した。ライブラリ本体.md の `## PoC 結果`）。
