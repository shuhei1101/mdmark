# 要件

## 要望

印 `map` の範囲に Mermaid のブロックと補足（`<!-- map-data: format=yaml` 〜 `-->`）を置いた文書を、mdmark が自動配置の図として描き、読む人が階層を辿れる。
対象は A-35 の No 1〜5・8・9 と No 18（No 6 のノードのページと No 7 の視点はユーザーの判断で外した）と、map のシーケンス図への #404 の参加者の強調・表示と並び順（ユーザーの判断で取り込んだ）。今の `flow`・`sequence` は変更せずに残す。

| No | 機能 | 終わりの条件 |
| --- | --- | --- |
| 1 | 書き方 | `<!-- map: … -->`〜`<!-- /map -->` の範囲の中の `mermaid` のブロック 1 つと補足 1 つを 1 つの図として読む。印の引数は見せ方の初期値（`focus`・`play`・`title`・`open`・`closed`・`interval`）だけを持つ。`open`・`closed` は今の印と同じく図を折りたたみに入れる。図の種類は Mermaid の 1 行目で決め、この PR で描くのは `flowchart` と `sequenceDiagram`。補足は `version` と機能ごとのトップレベルのキー（`notes`・`walkthroughs`・`layout`・`plays_over`）を持ち、スキーマで検査する。知らないキー・知らない引数・描かない図の種類は描画を止めずに書き方の警告にする。1 つの文書に図を複数置ける |
| 2 | 自動配置 | `flowchart` の `subgraph` を入れ子の箱として、階層ごとに `direction` の向きで並べる。座標を書かずに、ノード・箱が重ならず、線が箱を横切らない。ノードは左上に種類の行（アイコンと名前）、その下に名前を置き、どのノードでも種類の行の位置を変えない。名前は文節の切れ目で折り返し、描いた中身が収まる大きさで配置する（中身がノードからはみ出さない・詰まらない）。長い名前の広げ方は設定 `map.node_fit` で選ぶ（`height`: 幅は変えず折り返して高さを増やす・`width`: 上限まで幅を広げてから折り返す）。線のラベルは、ほかのラベルとノードに重ならない置き場所が無いときは出さず、線のツールチップに出す |
| 3 | 配置と見た目の調整 | 補足の `layout` で、ノード・箱・線ごとに大きさ・色（mdmark の名前の色）・位置（同じ段に揃える・並び順の固定・寄せる・座標の固定）・線の出入りの辺と経由点・データの印（`packet`。色は線の色・元のノードの色・先のノードの色・色の名前、形は丸・四角・ひし形。既定は線の色の丸）・グループを最初に閉じるか（既定は開く）を上書きする。上書きの無い部分は自動配置のまま。中へ入る・開閉で配置し直しても、上書きを保つ |
| 4 | 中へ入る | 箱のタイトル（ボタン）を押すと、その箱の中だけを配置し直し、外は薄く残す。今入っている箱のタイトルは押せない。外から中への線は薄く残した外の箱から引く。図の右上の戻るボタンか Esc で外へ戻る。右上のツールの先頭に戻る・全て開く・全て閉じるを常に同じ位置で置き（全体の図では戻るは押せない）、図を動かす矢印のボタンは置かない |
| 5 | 開閉 | 開閉のボタンは、開いた箱でも閉じた箱でも左上に置く。箱を閉じると中を隠し、中への線を閉じた箱へ付け替え、同じ箱どうしの線を 1 本にまとめる（本数とラベルは出さない）。Shift を押しながら開閉のボタンを押すと、その箱と中の箱を全て開閉する。開閉と中へ入った状態は、同じタブの中で描き直しても保つ |
| 8 | 巡回 | 補足の `walkthroughs` の手順を、図の枠の下に常に出す帯の前へ・停止・自動で進める・次への 4 つのボタンで進める。帯の 1 行目に番号（左）・手順のタイトル・操作のボタン（右）、2 行目から説明の文を出し（狭い幅ではタイトルを番号とボタンの下の行に回す）、説明の文の長さと行数によらずボタンの位置を変えない（説明の文が無いときは 1 行目だけ）。前へ・次へは常に押せ、端では反対の端へ回る（始める前の前へは最後の手順へ）。自動で進める間隔（秒）は印の引数 `interval` で決め、画面からは変えない（最後の次は最初へ戻る）。各手順はタイトルと説明の文と、中へ入る箱・強調するノードを指し、強調するノード（表示は変えず、ほかのノード・線・ラベルを薄くする）どうしの線の上に、データの印を元から先へ流し続ける。手順を進めても、両方の手順で残す線の表示は途切れさせない（両向きの矢印 `<-->` は両方へ）。自動で進めている間は、手順ごとに強調するノードの中心へ図の枠の中をスクロールする（倍率は変えない）。読者が図の枠をスクロール・拡大・縮小・押したら、自動で進め直すまでスクロールしない。前へ・次へで進めたときはスクロールしない |
| 9 | シーケンスの再生 | `sequenceDiagram` の図の下に、構成図の案内と同じ帯（番号・説明の文と、前へ・停止・自動で進める・次への 4 つのボタン）を常に出し、メッセージを 1 通ずつ進める。帯のタイトルはメッセージの文、説明の文は送り手 → 受け手と補足の `notes` の説明（改行はそのまま）。進めたメッセージは、`plays_over` で指した同じノードを持つ構成図の上でも強調する（構成図の案内を始めるとシーケンス図の強調は解く）。再生している間は、構成図とシーケンス図の両方で今のメッセージの線と送り手・受け手のほかを薄くし、データの印を送り手から受け手へ流し続ける。ボタンと自動で進める間隔は巡回と同じ（最後の次は最初へ戻る）。データの印は再生の機能に欠かせない動きのため、読者が再生・次へ・線のホバー・参加者の選択で始めた動きは、動きを減らす設定（`prefers-reduced-motion`）でも流す（今の GIF と同じく、自動で始める再生は動きを減らす設定では止めて始める） |
| 404 | シーケンス図の参加者 | map のシーケンス図で、参加者の箱を押すとその参加者が送る・受けるメッセージとライフラインの表示は変えず、ほかを薄くする（2 人以上ならそのあいだのメッセージ）。選んでいる間は、そのメッセージの線にデータの印を送り手から受け手へ流し続ける。参加者の名前の文字の上は、文字を選んでコピーできるよう、押しても選択しない（種類の行と余白で選ぶ）。参加者の選択と解除はキーボードでも操作でき、選んでいるかをスクリーンリーダーが読める（キーは部品設計で決める）。参加者の箱の名前の文字の外を押したまま左右へ動かして（4px 動くまでは押した扱い。キーボードでは箱にフォーカスして Alt + 左右の矢印。並べ替えのつまみのアイコンは置かない）並び順を変え、右上の「参加者の並び順と選択を元に戻す」で、記載の順に戻して選択を解く（参加者の表示と非表示はユーザーの判断で作らない） |
| - | 構成図のノードの選択 | 構成図のノードを押すと、選んだノードとそのノードの線の表示は変えず、ほかを薄くする（線の相手のノードも薄くする。2 つ以上選ぶと、選んだノードどうしの線だけを残す。シーケンス図の参加者と同じ）。選んでいる間は、その線にデータの印を流し続ける。選んだノードの強調は案内・再生の強調より優先する。右上の「配置と選択を元に戻す」（選んだか、ノード・線を動かしたときだけ押せる）か Esc で解く。選択と解除はキーボードでも操作でき、選んでいるかをスクリーンリーダーが読める（キーは部品設計で決める）。ノードの中の i と開閉のボタンを押したときは選ばない |
| - | ノードと線の移動 | 構成図のノードを押したままドラッグして、ポインターの動いた分だけ動かす（4px 動くまでは押した扱い）。動かし始めに全てのノードとグループの位置を固定し、動かしたノードと、それを含むグループの大きさのほかは変えない。グループは中身に合わせて右と下へ広がり、ノードはグループの左端・上端より外へは動かさない。ノードや広がったグループと、ほかのノード・グループとの間が 16px より狭くなる位置へは動かさない。線のどの区間も、区間と直角の向きへドラッグして動かせる（その区間の上ではポインターを動かせる向きの形にする）。両端の区間は、ノードにつながる端をノードの辺に沿って動かす。辺の端（8px の内側）を越えて動かしたときは、越えた側の辺（上・下・左・右）につなぎ替え、線をノードの中央まで延ばしてから直角に曲げてその辺へ入れる（矢じりもその辺に付く）。真ん中の区間を動かしたときも、ノードの外にある一番近い折れ点の位置（ノードの上・下・左・右）から、つなぐ辺を決め直す（ノードの中に入った折れ点は捨てる）。ノードの名前の文字の上は、文字を選んでコピーできるよう、押しても選択も移動もしない（種類の行と余白で操作する）。ポインターは、押して選べる・動かせる場所（構成図のノードとシーケンス図の参加者の名前の文字の外）では持ち手の形、名前の文字の上では文字の形にする。種類の行の文字（種類の名前）は選択できない（選んでコピーできるのはノードと参加者の名前の文字だけ）。種類の行は押す場所として高さ 24px 以上を取り、種類を書かないノードでも空の行を残す。動かした位置は同じタブの中で描き直しても保ち（sessionStorage）、文書には書き戻さない。「配置と選択を元に戻す」で自動配置に戻す。ノードと区間の移動はキーボードでも操作できる（キーは部品設計で決める） |
| - | シーケンス図の記法 | Mermaid の `sequenceDiagram` の記法を全て読んで描く: `participant`・`actor`（`as` の別名）・`box` 〜 `end`（参加者のまとまりと色）・`create`・`destroy`、メッセージの矢印 10 種（`->`・`-->`・`->>`・`-->>`・`<<->>`・`<<-->>`・`-x`・`--x`・`-)`・`--)`。`--` は点線、`x` は失敗の ×、`)` は非同期の開いた矢じり）、`activate`・`deactivate` と矢印の `+`・`-`（活性化の帯）、`Note left of`・`right of`・`over`（注記）、`loop`・`alt` / `else`・`opt`・`par` / `and`・`critical` / `option`・`break`・`rect`（複合フラグメント。入れ子にできる）、`autonumber`、`link`・`links`（参加者のツールチップのリンク）、`%%` のコメント。複合フラグメントの見出しと注記は、メッセージと重ならない行に置く。最初の行は一番高い参加者の箱の下から始める（名前が折り返して高くなった箱と重ならない）。活性化の帯は線より上に面の色で描き、帯に出入りするメッセージの線は帯の端で止める（線が帯に重ならない）。読めない行は書き方の警告にする |
| - | シーケンス図のブロック | `loop`・`alt` などの複合フラグメントと、名前の無いブロック（`rect` の直前の `%% block: 名前` のコメントで名前を付ける。Mermaid ではコメントとして無視され、ほかの場所でも描ける）を、タブの山形で開閉し（Shift で中のブロックごと）、タブの名前を押すとそのブロックの中のメッセージと、そのメッセージに関わる参加者だけの図にする（そのブロックの枠とタブは残し、タブの名前は押せない文字にして開閉の山形を出さない。構成図の今入っているグループと同じ）。右上に、外へ戻る・全て開く・全て閉じるを構成図と同じ位置で置く。閉じたブロックは、名前とメッセージの数を持つ 1 行にする。活性化の帯の始まりか終わりが閉じたブロックの中にあるときは、帯を閉じたブロックの行から・行まで描く |
| 18 | 枠の入れ子と層の分割 | 枠は `subgraph` の入れ子、層は補足の `layout` の層の指定で描く。層の名前・並び・色は使う側が決め、mdmark は層の種類を持たない。使い方集『構成図の決まり』に、入れ子は 2 レイヤーまでを推奨し、深いものは別の図に切り出してリンクする決まりと、枠と層の入れ子の凡例・層の色の重なり・枠のタイトルの位置の決まりを追加する（#309） |

今の図の機能は A-38 のとおりに扱う。

| 今の機能 | 新しい図での形 |
| --- | --- |
| 箱の種類（`llm`・`dm`・`script`・`mcp`・`data`・`external`）と色・アイコン | mdmark は種類を持たない。使う側が設定（`mdmark.config.yaml` の `map.kinds`）で、種類ごとの名前・アイコン（Lucide の名前）・形（`rounded`・`rect`・`pill`・`double`）・色を作り、Mermaid のクラス（`:::app` など）で指す。種類を書かないノードは種類の行を出さない |
| 線の種類（`flow`・`read`・`write`・`reply`・`loop`）と模様 | mdmark は線の意味を持たない。使う側が設定（`map.lines`）で、Mermaid の矢印（`-->`・`-.->`・`==>`）ごとと名前ごとに、名前・模様（`solid`・`dashed`・`dotted`・`dash-dot`・`long-dash`）・太さ・矢じり（`filled`・`open`・`none`）・色を作る。名前の線は補足の `layout` の `line` で指す |
| 箱の説明（`hint`・`io`）と線の詳細（`tip`） | 補足の `notes`。ツールチップに出す |
| 拡大・縮小・移動・全画面・ツールチップ・リサイズハンドル | 今の図の枠をそのまま使う。図の題の行には題だけを出し、範囲と更新日は出さない。凡例は出さない（ノードの種類はノードの種類の行のアイコンと名前、線は模様で見分ける）。リサイズハンドルは、枠線と面を持たない帯を表示する枠の下端（横のスクロールバーの下）に置き、右端に上下にだけ動かせると分かる横の 2 本線のアイコンを出す（今の図の枠の部品を変えるため、フロー図・シーケンス図などにも当たる） |
| 箱の名前の用語の下線 | ラベルと補足の文に付ける |
| 点検（`check`） | 補足のスキーマの検査、補足から指すノード・線の ID の参照の検査、補足の値に `--` を含む警告を追加する |

`map` の範囲の中の `mermaid` のブロックは、`mermaid` のコードブロックの描画（mermaid のライブラリで描く経路）の対象から外す。

描く見た目は今のフロー図・シーケンス図の部品を使い、自動配置の結果を部品の定義にして渡す（線の交差の飛び越え・ノードの見た目・ツールチップが今の図と同じになる）。箱は部品の上に重ね、色を変えられる。線の矢じりは線と同じ色にする。構成図とシーケンス図の線にポインターを当てると、線と両端のノードの表示は変えず、ほかのノード・線・ラベルを薄くし（案内・再生の強調と同じ見え方）、ポインターを当てている間はその線にデータの印を流し、補足の `notes` に説明がある線だけツールチップに説明を出す。ポインターの形は変えない。

図の枠は常に置き場所の幅いっぱい（右側の目次をピン止めしていないときは目次の右端の線の手前まで。ピン止めしたときは目次のパネルの手前まで）に広げ、本文の幅との切り替えのボタンは置かない。倍率は等倍より縮めず、収まらない分は図の枠の中で横にスクロールする。表示する枠の高さは開いたときの高さ（上限あり）か、読者がリサイズハンドルで変えた高さを保つ。リサイズハンドルで高くするときは上限を持たず、ダブルクリックで図の高さに合わせる（倍率は変えない）。操作しても描き直しても、図の倍率・表示する位置・枠の高さは変えず、ノードと箱は前の位置から今の位置へ動かす（`prefers-reduced-motion` では動かさない）。

自動配置と Mermaid の記法の読み取りは、外のライブラリを使わずに mdmark に独自に作る（PoC 検証で成立を確認した。ライブラリ本体.md の `## PoC 結果`）。
