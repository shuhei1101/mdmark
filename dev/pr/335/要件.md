# 要件

## 要望

ブロックの色分け（`diffMode: blocks` と、`mount` の比較元の Markdown との差分の強調）で、空行だけが一致する並びを避け、変えていない段落を追加・削除と判定しない。

- 段落 `A`・`B`・`C`（1 行の段落を空行で区切る）を比較元 `A`・`C`・`D` と比べたとき、`B` だけが追加、`D` だけが削除のブロックになり、`A`・`C` に色が当たらない
- 変えていない段落・見出し・リストの項目・表の行が、空行の一致の並びのせいで追加・削除と判定されない
- 変更が無い文書と、今の単体テストのケース（`test_color_diff_blocks*`）の結果は今と同じ

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 差分のパネル（`diffMode` が `blocks` でない差分）の行の表示 | 判断が分かれる。モジュール構成設計で直し方を `colorDiffBlocks` の中に置き、`computeDiff` とパネルの表示は変えない。パネルの行の並びで空行の一致を避けるかは Issue の事象（ブロックの色分けの判定）に含まれないため、今回は扱わない判断。別に起票するかをレビューで確定する | 判断と理由を書いてレビューで確定 |
