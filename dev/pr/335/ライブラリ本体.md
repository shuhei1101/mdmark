## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 行の比較の分類 | `colorDiffBlocks` が使う行の比較で、空行だけが一致する並びを変えていない行の手がかりにせず、空白だけでない行の一致を優先して追加・削除の行を決める | `未確定`（決める段: モジュール構成設計） |
| 既存機能への影響 | 変更が無い文書と既存の `test_color_diff_blocks*` の結果は今と同じにする。差分のパネルの行の表示は変えない | `要件.md` の `## スコープ外` |
| テスト | 段落 `A`・`B`・`C` と比較元 `A`・`C`・`D` のケースを `colorDiffBlocks` の単体テストに足し、`B` だけ追加・`D` だけ削除・`A`・`C` に色が無いことを確かめる | - |

| 案 | 内容 |
| --- | --- |
| A | `colorDiffBlocks` の中で、空白だけの行を除いた行どうしを比べ、結果を元の行番号へ戻して分類する（`computeDiff` とパネルは変えない） |
| B | `computeDiff` の行の比較で、空白だけの行を比べる前に除いて戻す（パネルの行の表示も変わる） |

推奨: A

Issue の誤りはブロックの色分けにだけ出ており、パネルの行の表示を変えずに直せるため。
