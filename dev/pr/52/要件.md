# 要件

## 要望

E2E『チャートを描く』の `test_error_when_definition_invalid` は、最後の検証で、書き方の警告（`.mdmark-syntax-warning`）の外にある HTML の段落だけを取って「後ろの段落」であることを確かめる。
書き方の警告の題と本文の `p` は検証の対象に入れない。
完了の基準は、release/v0.6.0 のビルドした配布物で `test_error_when_definition_invalid` が Chromium・Firefox の両方で pass すること。
