## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 入力欄を出す条件 | 関連文書を持つツールチップに、決めた件数以上の関連文書があるときだけ出す。意味だけのツールチップには出さない | 件数は `未確定`（[要件](./要件.md)。決める段: モック作成） |
| 入力欄を置く処理 | `mount` の操作が開いたツールチップに入力欄を足すか、部品が HTML に出すかを決める | `未確定`（[要件](./要件.md)。決める段: 部品設計） |
| 絞り込み | 入力した文字を題か `description` に含む文書だけを残す。英字の大文字と小文字は区別しない。空にすると全件に戻す | 文書の並びの順は変えない |
| 一致なし | 残る文書が無いときは、並びの代わりに一致する文書が無いことを文字で出す | 文言はモック作成で決める |
| キーボード | 語 → 入力欄 → 残った文書のリンクの順に Tab で移る。入力欄にフォーカスがある間は出したまま。Esc で閉じて語へフォーカスを戻す | WCAG 1.4.13 の今の操作を保つ |
| 閉じたとき | 入力欄の文字を消し、全ての文書の並びに戻す | 次に開いたときは絞り込まれていない |
| Esc の後の開き直し | 語を離れて 150ms（`CLOSE_DELAY_MS`）以内に戻ると開き直らない。語を離れたときに Esc の印をすぐ外すか、テストで閉じるのを待つかを決める | `未確定`（決める段: モジュール構成設計。[レビューの任意の指摘](https://github.com/shuhei1101/mdmark/pull/60#discussion_r4352795723)） |
| アクセシビリティ | 入力欄にツールチップの語を含む読み上げ名を付け、残った件数を読み上げで伝える | 役割と読み上げ名は部品設計で決める |
| 印刷 | 印刷の CSS で入力欄も外す | 今のツールチップと同じ扱い |
| 既存機能への影響 | 意味だけのツールチップと、件数が条件に満たない関連文書のツールチップの HTML と操作は変えない | - |
