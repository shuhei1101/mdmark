# 用語のツールチップの中で関連文書の並びを絞り込めるようにする

## 概要

読む人が、用語のツールチップの中で関連文書の並びを絞り込み、目当ての文書へ移れるようになる。

## 背景

[Issue #29](https://github.com/shuhei1101/mdmark/issues/29) の要望。
[#27](https://github.com/shuhei1101/mdmark/pull/27)（起点 [#5](https://github.com/shuhei1101/mdmark/issues/5)）で、本文の語に用語の意味と関連文書を出すツールチップを入れた。
関連文書が多いと並びが長くなり、ツールチップの中をスクロールして探すことになる（部品設計『用語のツールチップ』の状態 `ManyDocs`）。
絞り込みは、ユーザーとの合意で #27 に入れず後続にした（[確認ログ](https://github.com/shuhei1101/mdmark/pull/27#discussion_r4286985896)）。
