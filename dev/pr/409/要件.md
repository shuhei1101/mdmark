# 要件

## 要望

Sprint v0.10.0 の E2E（release の [4bb3708b](https://github.com/shuhei1101/mdmark/commit/4bb3708be49be0d95be47b793f54e5d07e412fad)）で fail した次の 9 件を、`src` を変えずにテストとシナリオ 1 件の書き換えで pass させる。
修正は release ブランチ `release/v0.10.0` へ入れる。

<!-- table: data -->

| ケース | テスト | 修正の方法 |
| --- | --- | --- |
| 単一ユースケース『文書をHTML文字列にする』 | `test_normal_when_includes_given` | 取り込みの枠を、属性の並びによらず `class="mdmark-include"` を持つ `div` で確認する |
| 単一ユースケース『PDFに印刷する』 | `test_normal_when_theme_selected` | 配色を確認するリンクを、1 行だけの段落にせず本文の文の中に配置し、リンクのカードにしない |
| 単一ユースケース『VSCodeでプレビューを開く』 | `test_normal_when_range_scripts` | `script-src` の単語の数の期待を、Webview の配信元（`Webview.cspSource`）の単語を含めた数にする |
| 単一ユースケース『外部ライブラリを使うときだけ読み込む』 | `test_error_when_icon_not_in_lucide` | 本文の行内のコードを、書き方の警告の枠の中の `code` を除いて数える |
| 単一ユースケース『コードブロックを飾る』 | `test_error_when_unknown_line_mark` | シナリオとテストの「知らない印」を、`LINE_MARK_KINDS` に無い印へ替える |
| 単一ユースケース『選んだ箇所にコメントする』 | `test_normal_when_updated` | 箇所が見つからないコメントの一覧が、先頭へ戻るボタンを除いた最後の子であることを確認する |
| 単一ユースケース『書いた内容をプレビューに映す』 | `test_normal_when_aliases_yaml_saved` | 本文の `innerText` を、ツールチップを閉じてから比べる |
| 複合ユースケース『プラグインを入れて端末と文書のフォルダをセットアップする』 | `test_normal` | プラグインを入れる前に、端末の `CLAUDE_CONFIG_DIR` のフォルダを作成する |
| 同上 | `test_normal_when_already_set_up` | 同上 |

<!-- /table -->

終わりの条件は、上の 9 件が release の今の配布物で pass し、同じ spec の他のケースが fail しないこと。

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| シナリオ『コードブロックを飾る』の異常シナリオ（知らないコードの行の印） | [73668037](https://github.com/shuhei1101/mdmark/commit/73668037)（`拡張記法でコードブロックの題・行番号・行の強調とコードの行の印を書けるようにする (#65)`） | 使える印が `++`・`--`・`highlight` だけのときに、使えない印の例として `[!code focus]` を記載した | 2 回 | - |
| `src/render/syntax/code-blocks.ts` の `LINE_MARK_KINDS` | [db341d81](https://github.com/shuhei1101/mdmark/commit/db341d81)（`既存の記法・点検への項目の追加 6 件（…コードの折りたたみ） (#275)`） | `focus`・`error`・`warning` を使える印に追加した。シナリオとテストの使えない印の例は替えていない | 2 回 | 使えない印の例を `LINE_MARK_KINDS` に無い印へ替えても、#65 の「知らない印を警告にする」目的は壊さない。同じ問題を修正し続けてはいない |
