## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 照合の辞書 | `buildDictionary` が `glossary` がオンのとき、索引の `terms[].avoid` の語から代わりの用語（`id`・語・意味）を引ける表を辞書に持たせ、照合する語に加える | 同じやめた言い方は索引の `terms` で先の用語を使う |
| 照合の優先 | 同じ位置で用語の語・別名とやめた言い方が当たるときは用語を選び、長い語を先に当てる今の規則を保つ | `findAvoidedTerms` の数え方と揃える |
| マーカーとツールチップ | `termSegments` がやめた言い方に当たった語を、波線のマーカーと「代わりの用語」のツールチップの HTML に置き換える | 見た目は[確認ログ](./確認ログ.md)のとおり |
| 部品 | `renderTermTip` に代わりの用語を受ける引数を足し、代わりの用語の区分を出す | 引数の名前・区分の文言は部品設計で決める |
| 操作 | ツールチップの開閉・置き場所・`mount` の `id` の振り直しは、用語のツールチップと同じ要素の形に載せて変えない | - |
| 被参照の一致 | `collectReferences`・`collectMatches` はやめた言い方を参照に数えない | 戻り値は変えない |
| 機能のオン・オフ | `glossary` がオフなら照合しない | - |
| 印刷 | 用語の下線と同じく、印刷の CSS でマーカーとツールチップを外す | - |
| アクセシビリティ | マーカーは下線の形でも示し色だけに頼らない。語は `tabindex="0"` でフォーカスでき、ツールチップを `aria-describedby` で指す | 用語のツールチップと同じ |
| 既存機能への影響 | やめた言い方を書いていない索引・索引なし・`glossary` オフでは出す HTML を変えない | 既存の単体・結合・E2E を回帰で回す |
| 配布物のサイズ | 非機能要件の配布物のサイズの決定値に収める | ビルドのサイズの検査で確かめる |
