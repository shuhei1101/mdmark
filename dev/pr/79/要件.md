# 要件

## 要望

描いた文書（`mount`・`render`）の本文に、索引の用語のやめた言い方（`terms[].avoid`）が出たら、その語に用語の下線と見分けられるマーカーを付け、ポインターを乗せたときとフォーカスしたときに、代わりに使う用語の語とその意味をツールチップで出す。

- 照合は `checkIndex` の `avoided_term` と同じ範囲と語の切れ目で行う（見出し・リンクの中・コード・用語集の表の中は照合しない。やめた言い方が用語の語・別名の一部として出たところは、用語として扱いやめた言い方にしない）
- 同じやめた言い方を複数の用語が持つときは、索引の `terms` で先の用語を代わりの用語にする（`avoided_term` の `message` と同じ）
- マーカーとツールチップは用語の機能（`glossary`）がオンのときだけ出す。オフのとき、索引を渡さないとき、やめた言い方を書いていない索引では、描いた文書は今と変わらない
- 開閉の操作は用語のツールチップと同じ（ポインター・フォーカスで開き、ツールチップの上へ移っても開いたまま、Esc で閉じてフォーカスを語に残す。下に収まらなければ上に開く）
- 印刷では用語の下線と同じくマーカーとツールチップを外し、語を本文の文字として出す
- マーカーは用語の下線と同じく、節（h2〜h4）ごとに、やめた言い方ごとの最初の 1 回だけに付ける（用語の下線とは別に数える）
- やめた言い方は参照先を持たないため、被参照の一致（`collectReferences`・`collectMatches`）と関連文書の一覧は今と変わらない

`未確定`: マーカーの見た目と、ツールチップの区分の見出し・文言（決める段: モック作成）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 用語の破線の下線とは別の形の下線（波線など）を引き、ツールチップに「代わりの用語」の区分を置いて語と意味を出す | 用語のツールチップの開閉・置き場所をそのまま使え、用語と下線の形で見分けられる | 下線の形を 1 つ増やす |
| B | 語の前後に注意のアイコンを置き、ツールチップで代わりの用語を出す | 一目でやめた言い方と分かる | 本文の文字の並びに要素が割り込み、読む流れを切る |

推奨: A

既存の用語のツールチップの部品と操作を使い回せ、本文の文字の並びを変えずに、色に頼らない下線の形で用語と見分けられるため。

`未確定`: 埋め込んだ HTML の段落と図の箱の中の `{{語}}` にやめた言い方が出たときの扱い（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 埋め込んだ HTML の段落は本文と同じくマーカーを付け、図の箱の中の `{{語}}` には付けない | 埋め込んだ HTML の用語の下線と同じ扱いになる。`{{語}}` は書き手が用語として指した語だけを照合する今の規則を変えない | 図の箱の中のやめた言い方は描いた文書で気づけない |
| B | どちらにも付けない | 本文の段落だけに変更を閉じられる | 埋め込んだ HTML の中だけ用語の下線と扱いが違う |

推奨: A

埋め込んだ HTML の段落は本文と同じ照合（`termSegments`）を通っていて、用語の下線と揃えるほうが読む人に一貫するため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 用語集の表のやめた言い方の列（[#62](https://github.com/shuhei1101/mdmark/issues/62)・[PR #78](https://github.com/shuhei1101/mdmark/pull/78)）から入れたやめた言い方へのマーカーとツールチップ | 要望は索引の `terms[].avoid` が対象。用語集の表のやめた言い方は PR #78 で点検だけに入る予定で、この PR のマーカーの仕組みを前提にする後続になる | 起票予定 |
| `collectMatches`（本文の参照を取り出す）がやめた言い方の位置を返すこと | 判断: 含めない。`collectMatches` は参照先（用語・文書）を返す関数で、やめた言い方は参照先を持たない。返すなら戻り値の形を変える公開関数の変更になり、要望の範囲（描いた文書のマーカーとツールチップ）を超える。レビューで確定する | 起票予定 |
| 点検の `avoided_term` の照合範囲・文言の変更 | 要望に含まれない。描いた文書の照合を点検に揃える側で、点検は変えない | 予定なし |
