# 要件

## 要望

ページのタイトル直下のリードと、同じ階層の `index.yaml` の行の `summary` を同じ 1 行にし、`index.yaml` から README を生成し直す。
develop で食い違っている次の 5 ページを対象にする（develop の全ての `index.yaml` の `.md` の行と、そのページのリードを突き合わせて見つけた）。

| ページ | リード | `summary` | 統一する側 |
| --- | --- | --- | --- |
| `docs/リファレンス/用語集.md` | 「テーマ」の後ろに「選べるテーマ」、「図の部品」の後ろに「ER 図・多重度」がある | どちらも無い（README の目次には「ER 図・多重度」だけがある） | `summary` をリードに合わせる（用語集の表に「選べるテーマ」「ER 図」「多重度」の行がある） |
| `docs/使い方/図を描く/図を描く.md` | 「フロー図・シーケンス図・グラフ・ER 図を描く手順」 | 「ER 図」が無い | `summary` をリードに合わせる（ページに ER 図の手順がある） |
| `docs/使い方/導入/版を上げる.md` | 末尾に「手順」がある | 末尾に「手順」が無い | リードを `summary` に合わせる |
| `docs/リファレンス/VSCode拡張機能.md` | 先頭に「VS Code 拡張機能の」が無い | 先頭に「VS Code 拡張機能の」がある | リードを `summary` に合わせる |
| `dev/設計書/デザイン方針.md` | 末尾に「。」がある | 末尾に「。」が無い | リードを `summary` に合わせる |

## 影響するユースケース

なし（ドキュメントのリードと索引だけを修正し、シナリオ・公開関数・コードは変わらない）。
