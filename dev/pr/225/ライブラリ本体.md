## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 折りたたみの見出し | 表・タブ・ステップの `title=` を折りたたみの見出しにする。無ければ表は「表（{行の数} 行）」、タブは「タブ（{タブ名を・で並べたもの}）」、ステップは「手順（{手順の数} ステップ）」 | 表の行の数は本文の行の数 |
| タブとステップの折りたたみ | `closed`・`open` で範囲を `details` に入れ、既定で閉じる・開く。両方を書くと書き方の警告を出し、表と同じく `closed` を当てる。`closed`・`open` の無い `title=` は書き方の警告を出し、折りたたみに入れない | `details` で描くので、印刷の前に開く処理は今のまま当たる |
| ツリーの注釈 | 罫線の後ろの名前と注釈を分け、注釈を全ての行で同じ位置の列に揃えて、中の Markdown のインラインを描く | 区切りは、前に空白がある最初の `#`。列の見た目はモック作成で決める |
| ツリーのアイコン | ファイルの拡張子ごとにアイコンを変え、フォルダは開閉の状態でアイコンを変える | 対応表はモック作成で決める |
| ツリーの `...` | 名前が `...` の項目を「ほかにもある」の項目として描く | - |
| ツリーの開閉 | フォルダ名かアイコンのクリックで開閉し、Shift を押しながらで入れ子を全部開閉する。既定はルートだけ開き、`open=all` で全て、`open={階層の数}` でその階層まで開く。読めない `open=` の値は書き方の警告を出す | `details` 以外で作るときは、印刷の前に開く処理を `src/print.ts` に追加する |
| ASCII の罫線 | `\|-- `・`` `-- ``・`\|   ` を、今の罫線と同じ段の数え方で読む | 1 つのツリーで 2 種類の罫線を混ぜてもよい |
| ツリーのコピー | ツリーにコピーボタンを置き、元の罫線のテキストをそのままクリップボードへ書く。書けないときの扱いは表のコピーにそろえる | 印刷ではボタンを出さない |
| 既存のツリーの見え方 | 名前の中に区切りの `#` を含む既存のツリーは、変更後にその後ろが注釈として出る | 公開の関数・設定・索引は変わらない |
