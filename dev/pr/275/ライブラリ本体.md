## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| グラフの種類（#159） | `MdmarkChartType` に面・積み上げの棒と面・横棒・ドーナツ・レーダー・バブル・折れ線と棒の組み合わせの種類を追加する。今の 4 種類の定義はそのまま描ける | 今の SVG のグラフの部品に追加し、ライブラリを追加しない（ライブラリ選定で決定） |
| グラフの系列（#159） | 系列の色 `--mdmark-color-series-{N}`・点のマーカー・塗りの模様を、ライトとダークの両方で見分けられる数まで増やし、5 つ以上の系列を描く | 増やす数は部品設計で決め、全テーマのライト・ダークに値を持たせる |
| ER 図（#244） | 図の部品に ER 図を追加する。定義はテーブル（物理名・論理名）・列（名前・型・主キー・外部キー・NOT NULL）・関係（元・先・多重度・ラベル）を持つ | 見た目はモック作成で決める |
| ER 図の操作（#244） | 拡大・縮小・移動・全画面・ツールチップは今の図の枠と図のツールチップを使う。列の多いテーブルは主キーと外部キーの列だけを出して残りを畳める | 畳む列の数の基準は部品設計で決める |
| 図の点検（#187） | `collectCheckIssues` が build の対象の文書の図の定義を読み、定義の誤り・ノードの重なり・ノードと枠からのはみ出し・線がノードを横切る・ラベルの文字数がノードの幅を超えるをずれとして返す。ブラウザーを使わない | ラベルの長さは文字幅の目安（全角と半角の幅）で計算し、目安の値は非機能要件と照らして設計で決める |
| 表のセルの結合（#183） | 表のマーカーの引数 `header-rows=N`・`row-header=N` と、セルの `^^`（上と結合）・`<<`（左と結合）を読む。`^^` は上の値を引き継ぎ、データは全ての行に値を持たせ、表示だけ縦に結合する | 表のマーカーの無い表の `^^`・`<<` は文字のまま出す |
| 結合し直し（#183） | 並べ替え・絞り込みの後に、隣り合う同じ値だけを結合し直す。コピー・絞り込み・集計は値で動く | - |
| 見出しのボタン（#183） | 絞り込み・並べ替え・ピン止めのボタンは、列ごとに分かれた最下段の見出しに置く | - |
| 行見出しのピン止め（#183） | `row-header=N` のはみ出す表は、#245（#283）の既定のピン止めで行見出しの列までを留める | `pin=` との兼ね合いは部品設計で決める |
| タブの入れ子（#191） | タブのマーカーの入れ子を数えて開きと閉じを対応させ、内側のタブは外側より深い見出しで区切る | 数える場所は `未確定`（`要件.md` の `## 要望`） |
| タブ名の強調（#191） | タブ名にする見出しの太字（`### **案 A**`）を、タブのボタンでも強調して出す。強調の見た目はデザイントークンで変えられる | 今は `attachTabGroup` が見出しの文字だけをボタンに入れて太字が落ちる |
| 注意書き（#216） | `> [!TIP] タイトル` の種類の後ろの文字をタイトルにし、`+`（開いた状態で折りたたみ）と入れ子を受ける。種類は増やさない | `src/parts/callout.ts` は `open` を既に受ける |
| コードの行のマーカー（#216） | `[!code focus]`（ほかの行を薄くする）・`[!code error]`・`[!code warning]` を追加する | コピーは今と同じく行のマーカーを除き、`del` の行だけを除く |
| コードの折りたたみ（#249） | tree を除く全てのコードブロックで、次の行が深い行を畳める行にし、同じ深さ以下の行の手前までを畳む。閉じ括弧の行は残す。Shift を押しながらで入れ子もまとめて畳む・開く | 操作の置き場所と見た目は D-74 のとおり |
| インデントの縦線（#249） | インデント 1 レベルごとに細い縦線を引き、ポインターを乗せた行のブロックの縦線だけ濃くする | - |
| `fold=`（#249） | `<!-- code: fold=8,12 -->` で最初から畳む行を指定する。開いた状態で描き、畳んだ状態は覚えない。コピーは畳んだ行も含む | 今の `title=`・`lines`・`highlight=` に追加する |
| 印刷 | 畳んだコードの行と閉じた注意書きを、印刷の前に開き、後に戻す | 今の折りたたみの印刷と同じ処理に載せる |
| アクセシビリティ | 追加する操作（列の畳み・コードの畳む・開く・タブ）はキーボードで操作でき、状態を `aria-expanded` などで示す。系列は色だけでなく、点のマーカー・模様でも見分けられる | 部品設計の `accessibility` の今の決まりに従う |
| 書き方の警告 | 読めない引数・セルのマーク・定義には、今の記法と同じく書き方の警告を出し、読めた指定だけを当てて描く | - |
| 性能 | 配布物の大きさを非機能要件の上限の中に収める | ビルドのサイズの検査で確かめる |
| 既存機能への影響 | 今の書き方の表・タブ・注意書き・コードブロック・グラフ・図の描き方を変えない | 既存の単体・結合・E2E を回帰として回す |
