## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 本文の幅 | 既定の上限を外す（`--mdmark-content-width: none`）。使う側は今の `--mdmark-content-width` で上限を渡せるまま | モック作成で案 A に決定（確認ログ） |
| 表の高さ | 表の縦の高さの上限を外し、縦はページのスクロールで読む。横にはみ出す表は今のまま表の中で横にスクロールする | インターフェース定義で `--mdmark-table-max-height` を廃止に決定。設定・索引の Schema ではないため移行の手順は置かず、変更履歴で知らせる |
| 見出し行 | 表が画面に残っている間、見出し行をページのスクロールで画面の上端から CSS カスタムプロパティのずれ（既定 0）だけ下に留める。横のスクロールとピン止めした列に見出し行のセルを揃える | PoC 検証で案 D（CSS のスクロール連動のアニメーション）に決定。`animation-timeline` を持たないブラウザでは案 C で留める（`## PoC 結果`）。変数名はインターフェース定義で `--mdmark-sticky-top` に決定 |
| 集計の行 | 計算ごとに 1 行ずつ、先頭のセルに計算の名前（合計・平均・件数）を出す。先頭の列を集計するときは、名前を左、値をセルの末尾に寄せて縦線で区切る。表が画面に残っている間、集計の行を見出し行と同じ仕組みでページのスクロールで画面の下端に留める。狭い幅では集計の行の上下の余白を詰める | 今の表の中の下端に留める動きを、ページのスクロールに置き換える。留め方は見出し行と同じ。余白を詰める幅と量は部品設計で決める |
| 集計できないセル | `sum` / `avg` の列に数として読めないセルが 1 つでもあれば、その列のその計算のセルを空にし、その列に読めないセルがあることを表の上の書き方の警告の枠で警告する。空のセルは集計から除き、数として読めないセルに数えない | 警告の位置はモック作成で決定（確認ログ） |
| 「集計」ボタン | `+total` の表の上のツールの並びに「集計」ボタンを置き、`total=` に書いた計算のうち出す計算を選ばせる。既定は `total=` に書いた全ての計算 | インターフェース定義で、選択は覚えず描き直すと既定に戻すと決定 |
| 表のコピー | `+copy` の「表をコピー」のメニューで Markdown の表か TSV かを選ばせ、絞り込み・列の表示の切り替えの後に見えている行と列をコピーする。クリップボードへ書けないときは、コピーする中身を選択した状態のパネルを出す | 選ばせ方はモック作成で決定（確認ログ） |
| 行の URL のコピー | 行のアンカーを押すと、アンカーの解決済みの `href`（`rewriteLinks` が書き換えた後の値）を絶対 URL にしてコピーし、リンクのアイコンの横に 2 秒出す小さな表示で知らせる。アドレスバーの URL を行を指す URL に替える今の動きは保つ | 知らせ方はモック作成で決定（確認ログ） |
| 最終列を畳む | 描いた文書の幅が 720px 未満のとき（コンテナクエリ）、1 行に収まらない最終列だけを畳み、行を押すと開く。行の詳細を持つ行は、行の詳細と開閉を 1 つにまとめる。印刷では畳まずに出す | モック作成で案 A に決定（確認ログ） |
| コードブロックの言語のラベル | 情報文字列の最初の語をコードの上の帯の左端に出す。最初の語が `言語:ファイル名` の形のときは、`:` の前を言語（色分けにも使う）、後ろをファイル名としてラベルに並べる。言語の無いコードブロックには出さない。読み上げの名前は題、ファイル名、言語の順に先にあるものを使う | 位置とファイル名はモック作成でユーザーの返信により決定（確認ログ）。インターフェース定義で、`tree`・図の `json`・埋め込んだ HTML の `html` は最初の語がちょうど一致するときだけ当て、`:ファイル名` を付けたものは普通のコードブロックにすると決定。長いファイル名の見た目は部品設計で決める |
| コードブロックのコピー | コピーボタンで、行のマーカーとマーカーだけを持つ行コメントの頭を除き、`[!code --]` の行を含めない変更後のコードをコピーする。結果をボタンの文言で知らせる。印刷では出さない | ファイルツリー・図の部品の定義・埋め込んだ HTML として描くコードブロックには付けない |
| 色分けする言語 | 対応表に `dockerfile`（別名 `docker`）と `diff`（別名 `patch`）を追加する。`diff` の色分けと、`[!code ++]` / `[!code --]` の行の色を両立させる | highlight.js の言語のモジュール `dockerfile`・`diff` |
| タブの中の見出しへ移る | URL の ID（まとめた HTML の `#/{文書のパス}#{ID}` も同じ）が選ばれていないタブの中の要素を指すとき、`tabs.ts` がそのタブを選び、外側の閉じた節を開いてから要素へスクロールする。ページを開いたときと `hashchange` の両方で動く。覚えたタブの選択より URL の ID を優先する | `revealHashTarget` はタブの中の要素の処理を `tabs.ts` に任せる（受付判断のレビュー） |
| `badge:` だけのインラインコード | 頭の後ろが空か空白だけのインラインコードは、バッジにせずインラインコードのまま出す | |
| 配布物の大きさ | 今回の変更を入れた後の `dist/index.js` を実測し、上限 384KB を超えるときは非機能要件『配布ファイル 1 つのサイズ』の前例（#42・#49・#55・#69）と同じく実測を添えて上限を上げる | 今の残りは 1,821 バイト |
| アクセシビリティ | コピーボタン・「集計」ボタン・コピーの形式の選択はキーボードで操作でき、結果を読み上げる（`aria-live`）。畳んだ最終列の開閉は `aria-expanded` を持つ | |
| 既存機能への影響 | 表のピン止め・並べ替え・絞り込み・件数・列の表示の切り替え・行の詳細・閉じた表と、コードブロックのタイトル・行番号・行の強調・色分けの見た目と振る舞いを保つ | |

| B | 横にはみ出さない表は枠の `overflow` を外して `position: sticky` で留め、はみ出す表だけ A にする | はみ出さない表は CSS だけで済む | 2 つの仕組みを持ち、幅が変わるたびに切り替える。はみ出す表は A と同じ処理が要る |
| C | 複製を作らず、元の見出し行のセルを `transform: translateY` でページのスクロールに合わせて画面の上端まで下げる。集計の行のセルも同じく画面の下端まで上げる | ボタン・状態・フォーカス・読み上げが元の 1 組のまま。セルは元の表の中にあるため、横の位置・幅・ピン止めが今のまま揃う | 縦の位置をスクロールのたびに JS で合わせ続ける。下げたセルが本文の行に重なるため、背景と重なりの順を持たせる |
| D | C と同じく元の見出し行と集計の行のセルをずらし、ずらす量を `view-timeline` と `animation-timeline` の CSS のアニメーションでスクロールの位置から決める。JS は表の大きさが変わったときに動く範囲の変数を入れ直すだけ | C のメリットに加え、コンポジターがスクロールと同じフレームでずらすため、見出し行が本文と一緒に動くフレームが出ない | `animation-timeline` を持たないブラウザ（Firefox・Chrome 114 以前・Safari 25 以前）では効かず、別の扱いが要る |

推奨: D

`overflow` を持つ枠の中の `position: sticky` は画面ではなく枠に対して効くため、横スクロールを保ったまま画面に留めるには、枠の外の要素（A）か、スクロールに合わせてずらすセル（C・D）が要る。
D は C と同じく見出し行のボタンの操作と状態を今の `src/interact/tables.ts` のまま使え、A が要る複製との同期が要らない。
描いたフレームで、C はホイール 1 回ごとに見出し行が 1 フレーム遅れ、D はずれが 0px だった（`## PoC 結果`）。
どの案も満たさなければ、横にはみ出す表では見出し行を留めないか、表の高さの上限を残すかの要件の見直しへ進む。

PoC 検証の成功条件: 横にはみ出し、ピン止めした列・並べ替え・絞り込みと集計の行を持つ表で、次が全て成り立つ。

- 縦に留まる: ページの縦のスクロール中、見出し行が画面の上端（ずれ 48px を渡したときはその下）から ±1px に、集計の行が画面の下端から ±1px に留まる
- 表から外れる: 表が画面から外れると、見出し行と集計の行も画面から外れる
- 横に揃う: 枠の横スクロールの左端・中ほど・右端と、ピン止めした列に、見出し行と集計の行のセルの位置と幅が ±1px で揃う
- 追従の遅れ: 30 回のスクロールのそれぞれで、次のフレームまでに位置が合う
- ボタンと状態: 留めた見出し行から並べ替え・絞り込み・ピン止めを操作でき、`aria-sort`・`aria-expanded`・`aria-pressed` が 1 組のまま正しく変わる。絞り込みのパネルが押したボタンの下に出る
- フォーカスと読み上げ: Tab で見出し行のボタンへ 1 回ずつだけ移り、アクセシビリティツリーに見出し行が 1 組だけある
- 幅の変化: 並べ替え・絞り込み・列の表示の切り替え・ピン止めの後と、画面の幅を 1280→390→1280px と変えた後も、横に揃う
- 印刷: 印刷では留めず、見出し行が 1 組だけ出る
- 動く環境: 上の全ての条件を Chromium と Firefox（Playwright）で、縦に留まる・横に揃う・ボタンと状態を VS Code 拡張機能のプレビュー（`@vscode/test-electron`）で確かめる

本番との違い: PoC は留める処理を PoC のページのスクリプトに置き、`src/interact/tables.ts` には入れない。
表の HTML とボタンの操作は今の `mount` が描いたものをそのまま使う。
VS Code 拡張機能のプレビューにはページのスクリプトを置けないため、留める処理を入れた PoC の配布物を作り、`MDMARK_VSCODE_DIST_BASE` で読ませる。
違いは留める処理の置き場所だけで、表の DOM・スクロールの追従・ボタンの操作は本番と同じため、結論に影響しない。

最小再現コードの要点（案 C。表の中の見出し行・本文・集計の行の、ずらす前の位置から求める）:

```js
const update = () => {
  const box = naturalBox(table);
  const top = stickyTop(root);
  // 見出し行: 画面の上端より上に出た分だけ下げ、本文の最後の行より下へは下げない
  const headMax = Math.max(0, box.bodyBottom - box.headTop - box.headHeight);
  const headShift = Math.min(Math.max(0, top - box.headTop), headMax);
  table.style.setProperty("--poc-head-shift", `${headShift}px`);
  // 集計の行: 画面の下端より下に出た分だけ上げ、本文の最初の行より上へは上げない
  const footMin = Math.min(0, box.bodyTop - box.footTop);
  const footShift = Math.max(Math.min(0, innerHeight - box.footTop - box.footHeight), footMin);
  table.style.setProperty("--poc-foot-shift", `${footShift}px`);
};
// CSS: thead th { transform: translateY(var(--poc-head-shift)) } / tfoot td { transform: translateY(var(--poc-foot-shift)) }
// 呼ぶ契機: window の scroll・表の中の scroll（capture）・resize・表の ResizeObserver
```

最小再現コードの要点（案 D。動く範囲だけを変数で渡し、ずらすのはアニメーション）:

```css
table { view-timeline: --poc-table block; view-timeline-inset: var(--poc-sticky-top, 0px) 0px; }
thead th {
  animation: poc-head linear both;
  animation-timeline: --poc-table;
  /* 表の上端から見出し行の上端までの量だけ遅れて動き始め、本文の最後の行で止める */
  animation-range: exit-crossing var(--poc-head-start) exit-crossing calc(var(--poc-head-start) + var(--poc-head-max));
}
@keyframes poc-head { from { transform: translateY(0); } to { transform: translateY(var(--poc-head-max)); } }
/* 集計の行は entry-crossing の終わりの側で、translateY(-var(--poc-foot-max)) から 0 へ動かす */
/* 変数を入れる契機: resize・表の ResizeObserver（スクロールでは入れない） */
```
