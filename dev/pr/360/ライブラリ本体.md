## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 取り込む Schema | alias-inject `v0.3.0` の `schemas/aliases.schema.yaml` を JSON にした `schemas/alias-inject/v0.3.0/aliases.schema.json` を追加し、v0.2.0 のファイルを削除する | `schemas/files.yaml` の行も変更する |
| Schema のずれ | `validateAliasRows` から `refValue`・`customValue`・`aliasTypeValue` の枝の絞り込みを除外し、`enum`・`required`・`type`・`minLength` のエラーを日本語の 1 文にする | `where` の書き方（`aliases[1].alias_type`）は変更しない |
| metadata の適用 | キーごとに `metadata` の列名（`.` で入れ子の列をたどる）の値を取り、`metadata` にないキーは同じ名前の列から取る | `alias_type` は行の属性から取る |
| body_file | `name` が空のとき、`body_file` の列の値のファイル名から拡張子を除いたものを名前にする | `records` を持つ行の名前の既定（レコードの `id`）より先に適用するかを設計で決める |
| 点検のずれ | `alias_field_missing` は `metadata` の列名の列がレコードにないとき、`alias_unknown_type` はレコードの値でなく行の `alias_type` が Schema で縛られるため、出る条件を設計で見直す | - |
| 移行の手順 | `migrations/next/steps.yaml` に、`metadata.alias_type` を行の `alias_type` へ、`{type: ref, field}` を列名の文字列へ書き換える手順を追加する | `未確定`（要件.md の `## 要望`） |
| 移行のスクリプトの出力 | `mdmark upgrade` が `call` のスクリプトの標準出力の行を当てた手順の行の下に、失敗したときの標準エラーの行を失敗の理由の後ろに出す | 除外したキーと値・行を分ける修正方法を利用者に示すため |
| 作ったエイリアス | `MdmarkAlias` と `mount`・`render`・`collectMatches` は変更しない | - |
