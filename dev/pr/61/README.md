# 索引の用語にやめた言い方（avoid）を書けるようにし、本文に出たら点検で知らせる

## 概要

文書を書く人が索引の用語にやめた言い方（`avoid`）を書き、文書の本文にやめた言い方が残っていることを `checkIndex`・`mdmark check` の点検で知れるようにする。

## 背景

[Issue #30](https://github.com/shuhei1101/mdmark/issues/30) の要望。
[PR #27](https://github.com/shuhei1101/mdmark/pull/27)（起点 [Issue #5](https://github.com/shuhei1101/mdmark/issues/5)）で、索引の用語（`terms`）と、索引と文書のずれを返す点検（`checkIndex`）を入れた。
用語のやめた言い方は、起点 Issue の点検の項目に無いため PR #27 の要件.md の `## スコープ外` に切り出した。
PR #27 はマージ済みで、索引の形（`src/knowledge/index-shape.ts`）・点検（`src/knowledge/check.ts`）・索引の JSON Schema（`schemas/mdmark.index.schema.json`）は develop にある。
