## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 索引の形 | `terms` の要素に任意のキー `avoid`（空でない文字列の並び）を、ER 図『索引』・JSON Schema・`MdmarkIndexTerm`・`INDEX_SHAPE.term` に追加する | 索引の版（`schema: 1`）は変えない |
| 移行 | `avoid` は省いてよいキーで古い索引もそのまま合うため、`migrations/next/` に手順を置かず `migrations/no-steps.yaml` に索引の Schema の行を追加する | - |
| 点検のずれ | `checkIndex` の `kind` に `avoided_term` を追加し、並びの最後（`duplicate_term` の後）に返す | 同じ種類の中は索引の `docs` の順・行の順 |
| 点検の一致 | 索引の文書の本文から、全ての用語の `avoid` の語を探し、出た行とやめた言い方の組ごとに 1 件返す。同じ行に同じ語が何度出ても 1 件 | 探す範囲と語の切れ目は文書の別名の一致と同じ。用語の語・別名と一緒に探し、長いほうを当てる |
| ずれの内容 | `file` は文書のパス、`where` は `{行} 行目`、`message` はやめた言い方と代わりに使う用語の語と直し方 | - |
| CLI | `mdmark check` は `checkIndex` のずれをそのまま出す | 終了コードの決まりは変えない |
| 既存機能への影響 | `avoid` を書いていない索引の点検の結果と、ツールチップ・被参照の振る舞いは変わらない | - |
