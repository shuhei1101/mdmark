# 要件

## 要望

VS Code 拡張機能のプレビューで、重ねて参照した設定の `aliases` からエイリアスを作り、`mount` の `opts.aliases` に指定して、本文に出たエイリアスに下線と種類ごとのツールチップを出す。

- エイリアスは CLI と同じ `loadAliases`（`src/cli/aliases.ts`）で作り、拡張機能ホストから `render` のメッセージで Webview へ送信する
- 設定に `aliases` が無いときは、今のプレビューと同じ描画にする
- `aliases` の行が指す YAML を参照できない・スキーマに合わないときは、その行・レコードを除いて描き、出力チャネルに警告を記録する（プレビューの描画は止めない）
- `aliases` の行が指す YAML は設定ファイルと同じく見張り、書き換えたらエイリアスを作り直して描き直す
- 確認の基準: `aliases` に用語のエイリアスの行を持つ設定ファイルの隣の Markdown をプレビューで開くと、本文の別名に下線が付き、ホバーでツールチップに種類と意味が出る

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| VS Code 拡張機能の「HTML に書き出す」「ブラウザで開く」「PDF に印刷する」が書き出す HTML へのエイリアスの埋め込み | Issue の要望はプレビューに限る。ただし書き出す HTML も同じ設定から `mount` を呼ぶため、プレビューだけ下線が出ると見え方がずれる。レビューで含めないと確定した | [#379](https://github.com/shuhei1101/mdmark/issues/379) |
| プレビューへの索引（`index`）と参照の表（`references`）の指定 | Issue の要望はエイリアスに限る。プレビューの被参照・索引の用語は別の機能 | 予定なし |
