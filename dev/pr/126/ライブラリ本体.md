## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 正規化の関数 | 文字列に NFKC（`String.prototype.normalize("NFKC")`）・英字の小文字化・前後の空白の除去をかける関数を 1 つ置き、照合・点検・検索の全てで同じ関数を使う | 辞書の語の登録と本文の照合の両方で使う |
| 辞書 | 辞書の語のキーを正規化した語にし、正規化した後に同じになる語は今の優先の順で先の用語を残す。やめた言い方が用語の語・別名と同じかの判定も正規化した語で行う | `words` は正規化した語の長い順 |
| 本文の照合 | 本文の文字列を正規化して辞書の語と照合し、一致した範囲を正規化する前の本文の位置へ戻して返す | NFKC で長さが変わる文字（`㍻` など）があるため、正規化した位置と元の位置の対応を持つ。語の区切りは元の本文で取る。`Intl.Segmenter` が無い環境の区切りでは、全角の英数字の連なりも 1 語にする |
| `findWords` の戻り値 | 一致した範囲の位置（元の本文）と、辞書を引く正規化した語を返す | 呼び出し元（記法・参照の表・本文の参照・点検）は正規化した語で辞書を引く |
| 辞書を引く関数 | 語を正規化してから辞書を引く関数を辞書に持たせ、呼び出し元は `terms.get` を直接呼ばない | 図の `{{語}}`（diagrams.ts・html.ts・matches.ts）のように `findWords` を通らずに書いた語で引く箇所も、同じ正規化で当たる |
| 点検 `duplicate_term` | 正規化した語どうしで重なりを判定する | 知らせる文言には記載した表記をそのまま出す |
| 点検 `avoided_term` | やめた言い方の照合を同じ正規化で行う | 知らせる文言のやめた言い方は記載した表記 |
| `findDocs`・`listTags` | 含むかの判定の両側に同じ正規化をかける | 今の大文字と小文字を区別しない判定を置き換える |
| 既存機能への影響 | 一致する範囲が広がるだけで、索引・設定の Schema と公開関数の引数は変えない | `collectMatches` の `text` は今と同じく照合した辞書の語 |
| 性能 | 正規化は辞書を作るときに語ごとに 1 回、本文はテキストの塊ごとに 1 回かける | 照合の回数は今と同じ |
