# 要件

## 要望

E2E『用語の意味をツールチップで見る』の `test_normal_when_keyboard` は、見出しの開閉のボタンとアンカーのリンクを Tab で越えてから、最初の用語にフォーカスが移ることを確かめる。
Tab を押すたびのフォーカス先は、`## 一つ目` の開閉のボタン → そのアンカーのリンク → 最初の用語 `ワークスペース` の順で確かめる。
フォーカスした用語のツールチップ・`aria-describedby` の `role="tooltip"`・Esc の検証は変えない。
完了の基準は、release/v0.3.0 のビルドした配布物で `test_normal_when_keyboard` が Chromium・Firefox の両方で pass すること。
