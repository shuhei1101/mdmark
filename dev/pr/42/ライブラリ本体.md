## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 図の部品 | フロー図・シーケンス図・グラフの部品を TypeScript で作り、文書に書いた部品の定義（JSON）から描く。部品の定義の形は JSON Schema で縛り、合わない定義は書き方の警告に出す | この Issue で作り、#6 はこの仕組みに載せる（[確認ログ](./確認ログ.md)） |
| 図の見た目 | 要件の「図の枠と層」〜「線の交差」を部品の描き方で守らせる。色は `--mdmark-` の CSS 変数にし、ライト / ダークで切り替える | 値はデザイン方針に足す |
| 図の操作 | 文字の選択とドラッグの切り替え・ボタンとキーでの拡大・縮小・矢印キーとボタンでの移動・全体が収まる初めの倍率を、図の部品の共通の操作として付ける | #6 のチャートにも同じ決まりを当てる（[確認ログ](./確認ログ.md)） |
| ツールチップ | 矢印の詳細・箱の入力・処理・出力・箱の中の用語を、ホバーとフォーカスで出し Esc で消えるツールチップにする。用語は今の用語のツールチップと同じ部品を使う | 用語集は図の外にも置く |
| 操作できる部品 | スライダー・グラフ・今の値を JSON にしてクリップボードへ写すボタンを部品にする | グラフの描き方（自前の SVG か外部ライブラリか）は設計で選ぶ |
| 固有の定義 | 使う側の固有の部品は `registerExtension` で足し、固有の CSS とともにその場所の文書にだけ当てる | 当てる範囲は設定ファイルの単位（[要件](./要件.md)） |
| 使う側の点検 | 雛形の JavaScript を `// @ts-check` と JSDoc にし、tsconfig で配布物の型定義を読んで JavaScript も点検する（`tsc --noEmit`） | 型定義の置き方は今の拡張の手順（配布物と同じタグの `dist/` の `.d.ts`）に揃える |
| 崩れの確かめ | 図の部品は Storybook のストーリーを持ち、結合テストと E2E でスクリーンショットを撮る。見本のページは E2E で開いて撮る | - |
| 手順書と決まり | 作り方の手順書を `docs/使い方/図を描く/`、HTML の書き方・構成図の決まり・フローチャートの決まりを `docs/リファレンス/` に置く | 更新ドキュメントは [要件](./要件.md) |
| スクリプト | 文書に書いたスクリプトを実行しない今の条件（`render` のサニタイズ）を保ち、部品の定義はデータとして読む | D-22 |
| 非機能要件 | 図の部品を足した配布ファイル 1 つのサイズが今の上限に収まるかを確かめる。ツールチップと操作のアクセシビリティ（WCAG 1.4.13・2.5.7）の項目を足す | 値は設計で決める |
