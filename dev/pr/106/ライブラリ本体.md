## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 描く文書の表のやめた言い方 | `render` が `glossaryAvoid` を渡し、`glossaryRule` が読んだ表の行のやめた言い方を `buildDictionary` へ渡す | 経路の型（`ownGlossary` の行に持たせるか、別の並びで渡すか）はモジュール構成設計で決める |
| ほかの文書の表のやめた言い方 | `collectReferences` の戻り値の用語集の表の用語に、行のやめた言い方を持たせる | 項目を足すだけで、今の項目は変えない。`references` を渡さないときは描く文書の表だけが効く |
| 照合の辞書 | `buildDictionary` の `avoided` を、索引の `terms[].avoid` に加えて用語集の表のやめた言い方からも作る。代わりの用語は表の行の用語（`id` は用語集の表の用語の下線と同じ `glossary:{docId}:{用語}`） | 同じやめた言い方は、点検の `avoided_term` と同じく索引の `terms`、索引の `docs` の順の文書の表の順で先の用語 |
| マーカーとツールチップ | PR #79 の `termSegments`・`renderTermTip`・CSS をそのまま使う | 見た目と操作は変えない |
| 機能のオフ | `glossary` がオフのときは表のやめた言い方も辞書に入れない | 今の `avoided` と同じ |
