## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 切り分け | 8 件を release で 1 件ずつ実行し、実際の振る舞いと設計書・テストの期待を突き合わせて、食い違う側を決める | 原因の PR は `git log -S` と `git bisect` で辿る |
| ドラッグの始め方 | リンクを持つノード・グラフの項目の上から押したポインターでも、閾値を超えて動いたら図の移動にする | 動かさずに離したときはリンク・項目の操作を残す |
| ツールチップ・ポインター | ノードの名前・レーンの上に重なって押さえを奪う要素をポインターの対象から除外し、ER 図のテーブルのツールチップをテーブルの下に出す | - |
| 凡例・グループのタイトル | フロー図の凡例に線の種類 `flow` の「処理の流れ」を出し、上端に留まったグループのタイトルを手前に出す | 設計書の側が誤っていればドキュメント修正で修正する |
| mermaid の拡大率 | 全体を収める拡大率が 100 未満になるように `MERMAID_MIN_FIT` と `fitMin` の扱いを設計書に合わせる | - |
| 単体テスト | 実装を修正した箇所ごとに、退行を捉える単体テストを追加する | - |
