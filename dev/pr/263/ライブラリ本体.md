## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 色のプリセット | テーマの CSS 変数に、色の名前ごとに面の薄い色と文字の色の組を足す（参考: `--mdmark-color-accent-blue-bg`・`--mdmark-color-accent-blue-text`）。ライト・ダーク・選べるテーマのそれぞれで、文字と面のコントラストを WCAG 2.2 AA（4.5:1）以上にする | 色の名前は blue・red・green・yellow・orange・purple・gray の 7 色（要件.md・確認ログ）。変数名は `--mdmark-color-accent-{色}-bg`・`--mdmark-color-accent-{色}-text`（インターフェース定義『文書を描く』の制約「色のプリセット」） |
| 知らない色の名前 | 色の名前の一覧に無い名前を書くと、色を付けずに書き方の警告の枠で知らせる | |
| 表の列の強調 | 表のマーカーの引数で列名を指定し、その列のセルを面の薄い色にし、見出しのセルに色以外の見分け（下端の線）を付ける | `highlight=列名[:色],…`。色を省くと blue（インターフェース定義『文書をHTML文字列にする』の制約「表の列と行の色」） |
| 表の行の色 | 列の値と色の名前の組か行の位置で行に色を付け、色を付けた行に上下の線を付ける。並べ替え・絞り込みの後も、値で付けた色は行に付いたまま動く | 値は `row-color=列名:値=色,値=色,…`、位置は `row-at=位置=色,…`（見出し行を除いて 1 から、`2-4` で範囲）。両方が当たる行は `row-at=` の色（インターフェース定義『文書をHTML文字列にする』の制約「表の列と行の色」） |
| バッジの色 | `badge:` の後ろの最初の `:` の前が色の名前の一覧にあるときだけ色とし、無いときは今のまま全てをラベルにする | 今 ``badge:red:x`` と書いた文書は、ラベルが `red:x` から `x` に変わる。変更履歴で知らせる |
| 本文の文字の色 | 色の名前で本文の文字に文字の色を付ける。色だけで意味を伝えないよう、太字にする（確認ログ） | 書き方は `[決め手の 1 文]{color=blue}`（要件.md・確認ログ） |
| 画像の属性 | 画像の直後の `{...}` を属性として読み、`width`（px か %）・`align`（left・center・right）・`nolightbox` と、動画・音声の `autoplay`・`muted`・`loop`・`poster` を当てる。読めない属性は書き方の警告の枠で知らせ、読めた属性だけを当てる | `autoplay` に `muted` が無いときは `muted` を足す |
| キャプション | 画像だけの段落の画像を `figure` にし、title を `figcaption` にする。`fig` のマーカーの図は今の番号の付け方を保つ | |

結論: 成立。GIF の止め方は案 A を採る。

`canvas` に `display` を当てると `hidden` 属性が効かず、最初から止まって見える。実装では `canvas[hidden]` に `display: none` を当てる。

最小再現コードの要点（`poc/gif/gif-pause.ts`）:

```ts
await img.decode();
const canvas = document.createElement("canvas");
canvas.width = img.naturalWidth;
canvas.height = img.naturalHeight;
canvas.getContext("2d")?.drawImage(img, 0, 0);
canvas.hidden = true;
img.after(canvas);
button.addEventListener("click", () => {
  const paused = canvas.hidden;
  canvas.hidden = !paused;
  img.style.visibility = paused ? "hidden" : "";
  button.textContent = paused ? "再生" : "停止";
  button.setAttribute("aria-pressed", String(paused));
});
```

diff の見どころ: `poc/gif/gif-pause.ts`（案 A の本体）、`poc/gif/run.ts`（3 つのブラウザでの撮影の比較と、下限の照合）。
