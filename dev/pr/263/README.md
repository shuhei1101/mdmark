# 表の列と行を名前の色で強調し、画像・動画・GIF・音声・リンクと添付のカードを描けるようにする

## 概要

文書を書く人が、名前で指定する色で表の列・行・バッジ・本文の文字を強調し、画像・動画・GIF・音声とリンク・添付のカードを Markdown の書き方のまま文書に置けるようにする。

## 背景

[#262](https://github.com/shuhei1101/mdmark/issues/262) は、[#158](https://github.com/shuhei1101/mdmark/issues/158)（名前で指定する色のプリセットと、表・バッジ・本文の文字の色）と [#199](https://github.com/shuhei1101/mdmark/issues/199)（画像の属性・キャプション・ライトボックス・ギャラリー・テーマごとの切り替え、アセットのルートと書き出し、動画・GIF・音声、リンクと添付のカード）を 1 本の作業 PR で進める束。
どちらも `src/render`・`src/parts`・`src/index.css` の記法と部品を足し、#199 の画像の属性の書き方（`{...}`）は #158 の本文の文字の色の書き方にも使える。

今の mdmark は、表のマーカーに色の指定が無く、バッジは 1 色だけで、色の CSS 変数は系列・図の箱・注意書きなど用途ごとの色だけを持つ。
画像は markdown-it の既定の `img` のまま描き、キャプションは `fig` のマーカーの直後の画像だけに付く。
`mdmark export` は文書のフォルダからの相対パスの画像を `data:` URL に埋めるが、`mdmark build` は画像を埋めない。
動画・音声は描けず、VS Code 拡張機能のプレビューの CSP は `media-src` を持たない。

配布物 `dist/index.js` は、非機能要件『配布ファイル 1 つのサイズ』の上限 440KB（450,560 バイト）に対して、手元の最新のビルドで 446,474 バイト。
