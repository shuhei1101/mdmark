# 要件

## 要望

[#262](https://github.com/shuhei1101/mdmark/issues/262) の子 Issue の終わりの条件を全て満たす。

<!-- table: data -->

| Issue | 終わりの条件 |
| --- | --- |
| [#158](https://github.com/shuhei1101/mdmark/issues/158) | ライトとダークの両方で読める色のプリセットを名前で指定でき、表の列の強調・行（位置か列の値）の色・バッジの色・本文の文字の色の記法で同じ色の名前を使える。色以外の見分けも付く。使い方集に、決め手の 1 文だけに色を付ける色の使い方のガイドがある |
| [#199](https://github.com/shuhei1101/mdmark/issues/199) | 画像の属性でサイズと配置を指定でき、title がキャプションになり、ライトボックス・ギャラリー・テーマごとの切り替えが動く。アセットのルートの設定と書き出しでの扱い（画像は埋め込み、動画・音声はコピーして相対リンク）・`check` の見つからないファイルのずれがある。動画・GIF・音声を描け、URL だけの行がリンクのカード、ファイルへのリンクだけの行が添付のカードになる |

<!-- /table -->

子 Issue の本文から補う振る舞い:

<!-- table: data -->

| 項目 | 振る舞い |
| --- | --- |
| 色のプリセット | テーマの CSS 変数に、色の名前ごとの面の薄い色と文字の色の組を持つ。ライト・ダークと、選べるテーマのそれぞれで読める値にする |
| 表の列の強調 | 表のマーカーの引数で列名を指定し、その列を薄い色で強調する（参考: `highlight=金額`）。強調した列の見出しに、色以外の見分け（線など）も付ける |
| 表の行の色 | 列の値と色の名前の組（参考: `row-color=状態:完了=green,保留=yellow`）か、行の位置で行に色を付ける。色を付けた行に、色以外の見分け（左端の線など）も付ける |
| バッジの色 | `badge:` の後ろに色の名前を頭に付けられる（参考: ``badge:red:要確認``） |
| 本文の文字の色 | 本文の文字に色の名前で色を付ける記法を足す |
| 色の使い方のガイド | 使い方集に、決め手の 1 文だけに色を付け、使いすぎないガイドを足す（例: 推奨案の決め手の 1 文を青、見送った案の決め手のデメリットの 1 文を赤） |
| 画像のサイズと配置 | 画像の後ろの属性 `![](a.png){width=300 align=left}`。幅は px と %、配置は left・center・right（left・right は本文を回り込む） |
| キャプション | 画像だけの段落の画像を図にし、title をキャプションにする。`fig` のマーカーが無くても付く |
| ライトボックス | 画像を押すと全画面で拡大し、同じ文書の画像を前後に送る。既定はオンで、属性 `nolightbox` で外す。操作は図の全画面と揃える |
| ギャラリー | `<!-- gallery: cols=3 -->` のマーカーで囲んだ画像を格子に並べ、サブ図の番号（1a・1b）を付ける |
| テーマごとの切り替え | URL のフラグメント `#only-dark`・`#only-light` を付けた画像を、そのテーマのときだけ出す |
| アセットの置き場所 | 文書からの相対パスを基準にし、設定でアセットのルート（参考: `assets.root`）を持てる |
| 書き出し | 画像は埋め込み、動画・音声は書き出し先へコピーして相対リンクにする。`mdmark export` と `mdmark build` の両方に当てる |
| 見つからないファイル | `check` が、見つからない画像・動画・音声・添付のファイルをずれとして返す |
| 動画・音声 | `![キャプション](a.mp4)` で拡張子から判断し、再生バー付きで描く。属性で `autoplay`（`muted` を付ける）・`loop`・`poster`・幅を指定する |
| GIF | 画像のまま描き、止める・再生するボタンを付ける |
| リンクのカード | URL だけの行を、書いた文字・ドメイン・URL のカードにする。外へは要求せず、タイトルの取得や iframe の埋め込みはしない |
| 添付のカード | ファイル（PDF など）へのリンクだけの行を、種類のアイコン・ファイル名のカードにする |

<!-- /table -->

決定: 本文の文字の色の書き方（[確認ログ](./確認ログ.md)）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 角括弧で囲んだ文字の後ろに画像と同じ属性を書く（`[決め手の 1 文]{color=blue}`） | 画像の属性と書き方を 1 つにでき、mdmark の無い所では角括弧の文字として読める | 角括弧と波括弧が mdmark の無い所でそのまま見える |
| B | 頭に色の名前を付けたインラインコード（``color:blue:決め手の 1 文``） | バッジと同じ書き方で、mdmark の無い所ではコードとして残る | 本文の文字がコードの見た目の書き方になり、文の途中で読みにくい |
| C | 文書の HTML で `<span data-color="blue">` を許す | 記法が増えない | Markdown として読みにくい |

採用: A

#199 で画像の後ろの属性を入れるため、同じ書き方で色を指定でき、読む人の目に入る記号が最も少ない。

決定: 色の名前の一覧（[確認ログ](./確認ログ.md)）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | blue・red・green・yellow の 4 色 | 少なく、選び迷わない | バッジの状態で使う中立の色が無い |
| B | A に orange・purple・gray を加えた 7 色 | 中立の gray と、4 色で足りない分類を表せる | ライト・ダーク・選べるテーマごとに読める値を決める数が増える |

採用: B

バッジは状態の分類に使い、中立の gray と 5 つ以上の分類が要る場面がある。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `==text==` の蛍光ペンのマーカーと、その色の名前 | 今回の色の名前を前提にする後続 | [#213](https://github.com/shuhei1101/mdmark/issues/213) |
| wide のマーカーで図・表・画像を本文の幅を越えて広げる | 画像を触るが、要望が別 | [#220](https://github.com/shuhei1101/mdmark/issues/220) |
| cards のマーカーで囲んだリストのカードの格子 | リンクのカードとは別の記法 | [#218](https://github.com/shuhei1101/mdmark/issues/218) |
| columns のマーカーで本文を横に分割する | 画像を並べる手段が別 | [#193](https://github.com/shuhei1101/mdmark/issues/193) |
| YouTube・Figma などの iframe の埋め込みと、リンクのタイトルの取得 | D-39 で、書き出しの外へ要求しない前提を保つため入れないと決まった | 予定なし |
| PDF をページの中に表示する | D-40 で、ブラウザの PDF の表示に頼り書き出しが大きくなるため入れないと決まった | 予定なし |
| 文書の HTML で `<picture>` を許す | D-38 で、URL のフラグメントで切り替えると決まった | 予定なし |
