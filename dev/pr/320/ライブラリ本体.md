## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 見出し 1・見出し 2 の線 | `--mdmark-heading-rule-width` の既定を `1px` にし、`border-block-end` の色を `--mdmark-color-border-muted` にする。`padding-block-end: 0.3em` は維持する | - |
| 区切り線 | `hr` の `border-block-start` の太さを `0.25em` にする | 色は `--mdmark-color-border` のまま |
| 新しい枠線の色の CSS 変数 | `--mdmark-color-border-muted: color-mix(in oklab, var(--mdmark-color-border) 70%, var(--mdmark-color-bg))` を `.mdmark` で 1 か所宣言し、各テーマの枠線の色と地の色に追従させる（`--mdmark-color-bg-opaque` と同じ持ち方） | テーマごとの値を持たないため、`src/index.css` のテーマの配色と `dev/mock/assets` のテーマは変えない |
| 右側の目次の上端 | `mdmark-side-toc-head` から `p.mdmark-side-toc-title` を削除し、すべて展開・すべて折りたたむ・ピン止めの 3 つのボタンを 1 行に並べる。`sections` がオフの文書ではピン止めのボタンだけが残る | ボタンの並び順はモックで提示する |
| ピン止めのボタンのアイコン | 押す前は lucide の `panel-right-dashed`、押した後は `panel-right` にし、選択中の背景と印の色を当てて塗らない。`aria-label`・`title`・`aria-pressed` は維持する | `src/parts/icons.ts` と外部ライブラリ『lucide』の使うアイコンに 2 つを追加し、`pin` を外す |
| hover で開く目次の位置 | 目次の枠を画面に固定し、上端を、文書のどこを読んでいても見えている枠の上端（スクロールする場所の上端に `--mdmark-sticky-top` を足した位置）に `--mdmark-space` を足した位置に出す。枠は右端の線の上から 3 本分の位置まで届く高さを持つ | fixed の出し方・ピン止めした状態・狭い幅の帯・ポインターを置けない端末の位置は変えない |
| アクセシビリティ | ラベルを削除しても `nav` の `aria-label="右側の目次"` でランドマークの名前を保つ | - |
| 既存機能への影響 | 公開関数・設定のキーは変えない。CSS 変数は追加だけ | 破壊的変更なし |
