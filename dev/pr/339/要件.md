# 要件

## 要望

`dev/mock/files.yaml` で、`id:` が無いと拡張子を落とした `path` が同じ ID になる行の組ごとに、片方の行に `id:` を付けて ID を分ける。
`id:` の値は、前例の `refs/151/assets/code-block.css` と同じく `dev/mock/` に拡張子付きの `path` を続けた値にする（例 `id: dev/mock/refs/257/assets/scene.css`）。

終わりの条件は、`dev/mock/files.yaml` の全行で、`id:` があればその値、無ければ `dev/mock/` と拡張子を落とした `path` を ID として数えたとき、重なる ID が 0 件になること。

Issue に挙がった #257 の組のほかに、develop には同じ型の重なりが 8 組あり、あわせて分ける。
