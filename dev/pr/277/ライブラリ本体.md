## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品 | 右の余白のマーカーの部品を新設し、HTML 文字列を返す関数とストーリーを置く | 部品設計を新設 |
| 置き場所 | 本文の右の余白に、箇所の要素の `getBoundingClientRect` から求めた行の縦の中ほどに、マーカーの縦の中ほどを合わせて置く | 右側の目次を置く文書では、本文の列と右側の目次の間に余白の列を置く（要件.md） |
| 同じ行の箇所 | 同じ行の高さに出る箇所は 1 つのマーカーにまとめ、箇所の数を添える | 押すと行の最初の箇所の吹き出しを開く（要件.md） |
| 置き直し | 箇所の付け直し（読み込み・保存・`update`）・描く先の要素の大きさの変化（`ResizeObserver`）・タブの切り替え・セクションと行の詳細の開閉で置き直す | 箇所が見つからないコメントはマーカーを持たない |
| 閉じた中の箇所 | 閉じたセクション・選ばれていないタブ・閉じた行の詳細の中の箇所は、`getBoundingClientRect` が 0 を返すため、箇所の位置からは置かない | 開くボタンの行に破線のマーカーを置き、押すと開いてから箇所へ移る（要件.md） |
| 操作 | マーカーを押すか、フォーカスして Enter・Space を押すと、箇所までスクロールしてその箇所の吹き出しを開く | 吹き出しの開閉は今の箇所のマーカーと同じ処理を使う |
| アクセシビリティ | マーカーは `button` で、箇所の文字を含む名前を持つ | 色だけに頼らずアイコンの形で示す |
| 印刷 | マーカーを出さない | - |
| 既存機能への影響 | `mountComments`・右側の目次・本文の列の幅（`--mdmark-content-width`）を変えない | - |
| 性能 | 置き直しは `requestAnimationFrame` で 1 フレームに 1 回にまとめる | - |
