# 要件

## 要望

`mount` で描いた文書で、コメントの機能（`comments`）がオンのとき、本文の右の余白に、コメントのある箇所ごとのマーカーを出す。

- マーカーは、本文の中のコメントの箇所（`mdmark-comment-mark`）が出ている行の高さに置く
- マーカーを押すと、その箇所まで本文をスクロールし、その箇所のコメントの吹き出しを開く
- マーカーはキーボードでも押せる（フォーカスして Enter・Space）
- コメントの保存・読み込み・描き直し（`update`）で箇所が変わったら、マーカーも同じ箇所に置き直す。箇所が見つからないコメントにはマーカーを出さない
- 描く先の要素の幅が変わって行が折り返し直したら、マーカーを新しい行の高さへ置き直す
- タブの切り替えと、セクション・行の詳細の開閉でも、マーカーを置き直す
- 閉じたセクション・選ばれていないタブ・閉じた行の詳細の中の箇所のマーカーを、本文の先頭の高さに重ねて出さない
- 印刷ではマーカーを出さない

右側の目次を置く文書でのマーカーの置き場所は、本文の列と右側の目次の間の余白に置く（案 A で確定。[確認ログ](./確認ログ.md)）。

同じ行に複数の箇所があるときは、1 つのマーカーにまとめ、箇所の数を添える。押すと行の最初の箇所の吹き出しを開く（案 A で確定）。

閉じたセクション・選ばれていないタブ・閉じた行の詳細の中の箇所は、閉じたセクションの見出し・タブの見出し・行の詳細を開く行の高さにマーカーを置き、押すとそれを開いてから箇所までスクロールし、吹き出しを開く（案 A で確定）。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `mountComments` で付けた要素のマーカー | 使う側の要素には mdmark が置く右の余白が無い。今の判断は対象外で、`mountComments` にも出すかはレビューで確定する | 予定なし |
| `reloadComments()` でマーカーを描き直す処理 | `reloadComments()` 自体を #222 で作る | [#222](https://github.com/shuhei1101/mdmark/issues/222) |
| dev-docs の画面の側での対応 | dev-docs のリポジトリの作業 | [shuhei1101/dev-docs#44](https://github.com/shuhei1101/dev-docs/issues/44) |
| 書き出した HTML（`mdmark export`・`mdmark build`）でのコメント | 書き出した HTML はコメントの読み書きの関数を持たず、コメントを出さない | 予定なし |
