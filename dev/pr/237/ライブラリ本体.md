## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `has` に渡すロケーター（#231） | 303・321・324 行目の `has` には、`#doc` から始まらない `page.locator(".mdmark-tree-name", { hasText: name })` の形を渡す | 外側の `tree.locator(".mdmark-tree-row" / ".mdmark-tree-folder" / ".mdmark-tree-file", …)` は変えない。`has` 以外で使う `nameOf` は変えない |
| 閉じたフォルダのボタン（#231） | 全て閉じた後の `src/`・`parts/` の `aria-expanded` の確かめは、閉じた `ul` の中でも当たる探し方（`getByRole` の `includeHidden: true`）にする | 見えているボタンを押す・フォーカスする箇所の探し方は変えない |
| コピーのパネルの文言（#231） | 502 行目の期待値を、部品設計『ファイルツリー』の `copyFallback` のタイトル `クリップボードにコピーできませんでした` にする | 503 行目の読み上げ（`role="status"`）の `手でコピー` の確かめは変えない |
| 期待するタブ名（#232） | 173 行目の期待値を `["macOS", "Windows", "uv", "pip"]` にする | 続く全てのタブ名が見えることの確かめと、印刷の後に戻す確かめは変えない |
