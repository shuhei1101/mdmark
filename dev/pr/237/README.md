# Sprint v0.9.0 の E2E の 2 件のテスト不備（ファイルツリーのロケーターと文言・印刷のタブ名の期待値）を修正する

## 概要

release/v0.9.0 の E2E で fail した 2 つの spec を、設計どおりの描画に合うロケーターと期待値へ修正し、pass させる。

## 背景

[Issue #236](https://github.com/shuhei1101/mdmark/issues/236) の束の修正（子 Issue は [#231](https://github.com/shuhei1101/mdmark/issues/231)・[#232](https://github.com/shuhei1101/mdmark/issues/232)）。
[release PR #229](https://github.com/shuhei1101/mdmark/pull/229) の E2E（[E2E 実行 Issue #153](https://github.com/shuhei1101/mdmark/issues/153)）で次の 2 つが fail し、tester がどちらもテスト不備と切り分けた。製品の挙動は設計どおり。

- 単一ユースケース『ステップ・ファイルツリー・バッジで本文を組む』のファイルツリーの 3 件: `has` に `#doc` から始まるロケーターを渡している・閉じた `ul` の中のボタンを `getByRole` の既定で探している・コピーのパネルに部品設計に無い文言を期待している
- 単一ユースケース『文書を印刷する』の `test_normal_when_syntax_expanded`: [#225](https://github.com/shuhei1101/mdmark/pull/225) で閉じたタブの範囲（`uv`・`pip`）を追加した後も、期待するタブ名が追加前の 2 件のまま
