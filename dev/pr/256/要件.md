# 要件

## 要望

1. 使い方集（`guide/index.yaml` が指す 17 ページと索引の文）を、knowledge の規約『文章の書き方』の語の選び方（原則・ドキュメントの語の対応表）と確認表（強調・冗長・ぼかし・繰り返し・裏返し・見れば分かる説明）で修正する
   - 比喩の語: 箱 → ノード、層 → レイヤー
   - 一字の語: 印 → マーカー、題 → タイトル、節 → セクション、形 → スキーマ・構造、版 → バージョン
   - 訓読みの動詞: 足す → 追加する、写す・写し → コピー、消す → 削除する、直す → 修正する、送る → 送信する
   - 終わりの条件: 17 ページで上の避ける語が、コード・記法の値（`<!-- 名前 -->` の名前、設定のキー、CSS のクラス名、UI の文言など書き換えると挙動が変わるもの）を除いて 0 件になる
2. 使い方集に『文書の書き方』（name `writing`）のページを追加する。中身は次の 4 行の表で、判定のフローチャートは置かない

   | 決まり | 中身 |
   | --- | --- |
   | 表し方の優先順位 | knowledge の規約『表し方の優先順位』（[shuhei1101/knowledge#132](https://github.com/shuhei1101/knowledge/issues/132)）を参照する。要点は 図（フロー図・構成図・グラフ・ファイルツリー）→ 表 → 箇条書き → 文 で、上の表し方で書けたものを下の表し方で書き足さない |
   | 見れば分かることを書かない | 図・表を読めば分かる説明、冒頭のリード、概要を削る |
   | 裏返しを書かない | 「〜する」の後の「〜しない」、同じことの言い直しを削る |
   | 参考は末尾にまとめる | 参考のリンクと参考にした情報は、ページの末尾の参考のセクションにまとめ、既定で再帰的に閉じる。各セクションの補足は参考へのリンクか、閉じたセクションにする |

   - 判定のフローチャートは mdmark に複製せず、knowledge の判定フローチャート『表し方の選び方』を参照する（[ユーザーのコメント](https://github.com/shuhei1101/mdmark/issues/185#issuecomment-6539021405)）
   - 終わりの条件: `read_guide` に `writing` を渡すとページの本文が返り、SessionStart の索引に `writing` の行が出る
3. SessionStart の動線から「書く前に『文書の書き方』を読む」と案内するのは [#186](https://github.com/shuhei1101/mdmark/issues/186) で行い、この PR では行わない
