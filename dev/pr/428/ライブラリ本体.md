## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 位置の保存 | `startBundle` がルーターとして `history.scrollRestoration` を `manual` にする。履歴の項目ごとのキー（`history.state` に持たせた項目の ID）をメモリに持ち、`popstate`・文書の一覧と文書間のリンクのクリック・`pagehide`・間引いたスクロールのときに、そのキーへ `scrollX`・`scrollY` を sessionStorage へ保存する | URL に出さない。`popstate` の時点の `history.state` は移り先の項目のため、メモリに持ったキーを使う |
| 移り方の見分け | 文書の一覧・リンクのクリックで移るときは新しい履歴の項目として扱い、保存した位置を持たない項目では今どおり見出しか頭へ移す | 戻る・進む・再読み込みでは、その項目の保存した位置を使う |
| 位置の復元 | 文書を描いた後（外部ライブラリの読み込みで高さが変わる分を含め、描き終えた後）に保存した位置へ移す。文書の高さを超える位置は末尾まで | 保存した位置が無ければ今どおり |
| フォーカス | 戻る・進むで位置を戻したときも、今どおりフォーカスを h1 へ移す（`preventScroll`） | - |
| sessionStorage が使えないとき | 例外を `console.warn` に出し、今どおり見出しか頭から表示する | タブの localStorage と同じ扱い |
| タブ・図の高さ | 決まりに合うため変えない | 要件の突き合わせの表 |
| 開閉と選んだタブ | 位置と同じ履歴の項目のキーで、要件.md の突き合わせの表に挙げた本文の開閉と `group=` の無いタブで選んだタブを保存し、戻すときは開閉とタブを戻してから位置を戻す | `group=` のタブは localStorage の選択のとおり |
