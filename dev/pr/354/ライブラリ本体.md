## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 端末の設定のキー | tmux のセッション名のキー `serve.tmuxSession` を、端末の設定だけが持つキーとして Schema に足す（`mdmark.config.yaml` に書いても読まない） | 省いてよいキーの追加なので `migrations/no-steps.yaml` に行を置く |
| 端末の設定のバージョン | 端末の設定にも `version` を置き、`mdmark upgrade --settings` で `file: config` の手順を当てて移行する | - |
| 端末の設定の雛形 | `global-setup` が作る端末の設定の雛形を置く | 置き場所はモジュール構成の設計で決める |
| 設定の点検 | `mdmark check` が足したキーの形を点検する | 既存の端末の設定の点検に乗る |
