# 要件

## 要望

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 選んだ列だけを留める | ピン止めのボタンを押した列だけが留まる。複数の列を選べ、留めた列のボタンをもう一度押すとその列だけを解除する |
| 留める位置 | 留めた列は、その列より左を表示している間は表の右端に、その列を過ぎて右へスクロールした後は左端に留まる。複数の列を留めたときは、左端・右端のそれぞれで留めた列が重ならずに並ぶ |
| 動きの切り替え | 選んだ列だけを留める動きと、今の「押した列までを留める」動きを設定で選べる。既定は選んだ列だけを留める動き |
| ボタン | ピン止めのボタンは増やさない（列ごとに 1 つのまま） |
| 既存の動きとの兼ね合い | 既定のピン止め（行見出しの列・先頭の列）・`-pin`・`pin=`・表がはみ出す間だけ留めること・列の表示の切り替え・列の並べ替え・多段の見出し・印刷を、新しい動きでも成り立たせる |

<!-- /table -->

<!-- table: data -->

| 項目 | 決めたこと |
| --- | --- |
| 設定のキー | `table.pin` に `each`（既定。選んだ列だけを留める）か `through`（押した列までを留める）を記載する。`mount` は他の値を無視して `each` にし、CLI は他の値を設定ファイルの誤りにする |
| `pin=` | 設定の動きに従う。`each` では記載した列だけを留め、`pin=No,物理名` のように `,` で区切って複数の列を記載できる。`through` では記載した列のうち最も右の列までを留める |
| 既定のピン止め | `pin=` を省くと、`each` では行見出しの列（行見出しが無ければ先頭の列）を 1 列ずつ留め、`through` では今と同じく行見出しの最後の列までを留める |
| 列の並べ替え | `each` では留めているかを列が持ったまま動き、テーブル設定の一覧を留めた列で分けない。`through` では今と同じく、ピン止めの列とそれ以外の列の境をまたげない |
| 移行 | 移行の手順は作らず、`migrations/no-steps.yaml` に行を配置する。既存の文書の `pin=列名` は、その列だけを留める見え方に変わる |

<!-- /table -->

## 変更箇所の由来

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |
| --- | --- | --- | --- | --- |
| 「押した列までを留める」ピン止め | [a6e0aad8](https://github.com/shuhei1101/mdmark/commit/a6e0aad8e7f166a86f157761f802b77169e08e0b)（`HTML コメントの印で表・注意書き・タブなどの表示を付ける拡張記法を作る (#19)`） | 表の機能の 1 つとして、はみ出す表の列を左端に留めるために作った。押した列までを留める理由は PR ドキュメントに無い | 1 回 | - |
| `pin=列名`・既定のピン止め | [064265d6](https://github.com/shuhei1101/mdmark/commit/064265d6)（`はみ出す表は既定で先頭の列をピン止めし、pin=・wide= と真偽値の ✓ 表示を追加する (#283)`） | はみ出す表で先頭の列を既定で留め、`pin=列名` でその列までを留める | 1 回 | 選んだ列だけの動きでは、既定の「先頭の列・行見出しの列まで」は留める列の集まりとして読み替えれば目的を壊さない |

`src/interact/tables.ts` のピン止めの範囲は [#19](https://github.com/shuhei1101/mdmark/pull/19)・[#57](https://github.com/shuhei1101/mdmark/pull/57)・[#283](https://github.com/shuhei1101/mdmark/pull/283)・[#303](https://github.com/shuhei1101/mdmark/pull/303) の 4 回変わったが、目的はそれぞれ記法の新設・件数と列の表示の追加・既定のピン止めの追加・列の並べ替えの追加で、同じ事象を直し続けてはいない。
