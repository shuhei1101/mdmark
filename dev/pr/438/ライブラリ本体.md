## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 留める列の持ち方 | 先頭からの数ではなく、留めた列の集まりで持つ。押した列を集まりに加え、もう一度押すと外す | 押した列までの動きでは、押した列までの列を集まりにする |
| 留める位置 | 留めた列ごとに `position: sticky` と、それより左で留めた列の幅の合計を `left`、右で留めた列の幅の合計を `right` に入れ、左端と右端の両方に留まるようにする | 境の線は、左端に留まった最も右の列の右と、右端に留まった最も左の列の左にだけ出す。幅は今の `pinColumns` と同じ `offsetWidth` の整数で足し合わせ、留めた列の間に隙間を出さない |
| 設定 | `table.pin`（`each` が既定・`through`）を追加する | [要件](./要件.md) |
| `pin=` | `,` で区切った複数の列名を読む。`each` では記載した列だけ、`through` では最も右の列までを留める | 知らない列名だけを記載の警告にして、読めた列名は当てる |
| 移行 | `migrations/no-steps.yaml` に Schema の変更の行を配置する | 移行の手順は作らない |
| 列の並べ替え | `each` では留めているかを列が持ったまま動かし、ピン止めの同じ側の中だけに限る判定とテーブル設定の一覧の分け方を `through` だけに当てる | - |
| 列の表示の切り替え・多段の見出し・行見出し・集計の行・印刷 | 隠した列は幅の合計から外し、見出しと集計の行も同じ位置に留める。印刷では今と同じく留めない | - |
| 既存機能への影響 | 押した列までの動きを選んだ表は今と同じ見え方にする | - |
| アクセシビリティ | ピン止めのボタンの `aria-pressed` は列ごとに留めているかを示す | - |
