## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 単語の置き換え | 正の対応表の `pattern` と `allow` でヒットした箇所を、文脈で `ok` の単語に置き換える | `allow` に当たる複合語（書き込む・割り当てる など）は変えない |
| 用語集の用語 | 「印」「題」「版」「箱」「知らせの枠」などの置き換え先を用語集で 1 つに決め、全てのページ・コード・画面で同じ単語にする | `未確定`（[要件](./要件.md) の案 A・B） |
| ファイル名 | NG の単語を含むファイルを `git mv` で改名し、リンク・目次・`files.yaml`・設計書の参照・対応テストファイルを合わせる | 改名後に `mdmark check` と dev-docs の `check_project` で参照の切れが 0 件になることを確認する |
| 画面と CLI の文言 | メッセージを「〜できませんでした」「〜しますか?」の書式にし、エラーには原因と対処を入れる | 識別子・Enum の値・定数・CLI のサブコマンドとオプション名は変えない |
| JSON Schema | `description` を修正し、`migrations/no-steps.yaml` に行を追加する | キー・型・既定は変えない |
| 件数の確認 | 修正後に正の対応表と `集計/reposcan.py` で数え直し、残す箇所を理由つきで PR に記載する | - |
