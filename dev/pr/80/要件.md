# 要件

## 要望

mdmark が描く文書の既定の見た目（色・線・余白・文字・角丸）を、mindstella のデザイントークン（[tokens.css](https://github.com/shuhei1101/mindstella/blob/develop/plugins/mindstella/skills/mindmap/preview/tokens.css)・[デザイン方針](https://github.com/shuhei1101/mindstella/blob/develop/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E3%83%87%E3%82%B6%E3%82%A4%E3%83%B3%E6%96%B9%E9%87%9D.md)）に揃える。

- 描いた文書と、`mdmark build` のまとめた HTML の文書の一覧が持つ UI をすべて洗い出し、明るい配色とダークの配色の両方で 1 枚のキャンバスに並べる
- キャンバスの上で「この見た目で統一する」案を作り、ユーザーが合意してから CSS 変数の値と部品の CSS に当てる
- 表の見出し行・罫線・面の色は、mindstella の本文の表（`.md th` の `--surface-2` / `--border-soft` / `--surface`）と同じ明るさの差にする
- CSS 変数の名前（`--mdmark-` の接頭辞と各変数名）は変えず、値だけを変える。使う側の上書きはそのまま効く
- 各色の文字は、置く面の上でコントラスト比 4.5:1 以上を保つ
- 印刷ではダークを解除する既定はそのままにする

`未確定`: 書体（決める段: デザインスタイル選定）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | OS 標準の書体の並び（`--mdmark-font-body`）のまま、大きさ・行間・太さだけを mindstella に寄せる | 書き出した HTML が外を読まない決まりを保てる | 端末によって字形が mindstella と揃わない |
| B | mindstella と同じ Inter・Noto Sans JP・JetBrains Mono を、配布物の外から読む | 字形まで揃う | 書き出した HTML が外へ要求しない決まりと、配布物のサイズの上限にぶつかる |

推奨: A

書き出した HTML は外へ要求しないことを非機能要件で決めており、書体を読みに行くとこれを崩すため。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| コードブロックのシンタックスハイライトの配色 | 別の Issue で扱っている | [#67](https://github.com/shuhei1101/mdmark/issues/67) |
| 親の class（`vscode-dark` など）でダークの配色に切り替える | 配色の切り替えの仕組みの話で、値を揃える作業とは別 | [#22](https://github.com/shuhei1101/mdmark/issues/22) |
| CSS 変数の名前を mindstella のトークン名（`--bg` など）に合わせる | 使う側の上書きが効かなくなる破壊的変更になり、要望（値を揃える）に含まれない | 予定なし |
| mindstella 側のスタイルの変更 | このリポジトリの外 | 予定なし |
