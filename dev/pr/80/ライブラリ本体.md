## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| UI の洗い出し | 描いた文書の部品（表・注意書き・タブ・図・差分・コメントなど）と、まとめた HTML の文書の一覧を、明るい配色とダークの配色で 1 枚のキャンバスに並べる | モック作成の段で designer が作る |
| 統一案 | キャンバスの上で、色・線・余白・文字・角丸の値を mindstella のデザイントークンに寄せた案を作り、今の値と並べる | ユーザーの合意を取ってから当てる |
| CSS 変数 | `--mdmark-` の変数名は保ち、明るい配色・ダークの配色の値を合意した案の値にする | 変数を足すのは、案が今の変数で表せないときだけ |
| 部品の CSS | 変数でなく値を直に持つ部品の CSS を、合意した案に合わせる | - |
| まとめた HTML | 文書の一覧・パネルの CSS を同じ変数の値で揃える | - |
| アクセシビリティ | 文字と面の組み合わせのコントラスト比 4.5:1 以上、種類・状態は色だけに頼らない今の決まりを保つ | - |
| 印刷 | 印刷でダークを解除する既定を保つ | - |
| 既存機能への影響 | 使う側が層の外に書いた上書きは、変数名を保つためそのまま効く | - |
