## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| グラフの項目のツールチップ（#160） | 点・棒・円の項目を図のツールチップの持ち主にし、ポインターとフォーカスで系列の名前と値（折れ線・棒は横の目盛りと値、散布図は x と y、円は項目の名前と値と割合）を出す。点は見えない当たりの範囲を線の `mdmark-diagram-wire-hit` と同じ考え方で広げる | #159 で追加した種類（面・積み上げ・横棒・ドーナツ・レーダー・バブル・組み合わせ）の項目も含める。種類ごとの内容は部品設計で決める |
| 移動とツールチップの両立（#160） | ポインターが動いた距離が小さいうちは移動にせず、ツールチップを優先する | 距離のしきい値はモジュール構成設計で決める |
| 表の幅（#168） | 表を本文の幅いっぱいに広げ、中身が収まらないときだけ今の横スクロールと端の影で示す。列の最小幅と見出しの折り返さない指定は今のまま | `未確定`（決める段: モジュール構成設計） |
| リサイズハンドル（#169） | 図・グラフの表示の範囲の右下に、ドラッグと上下キーで縦にだけ高さを変えるリサイズハンドルを置く。高さを変えたら全体を収める倍率を計算し直す。全画面のモーダルの中には置かない | 上限は #198 の修正（今の倍率の図の高さ）のまま |
| リサイズハンドルの出し分け（#169） | 設定の `features` と文書のマーカーで出し分ける機能のキーを追加する（既定はオン） | キーの名前は単一ユースケース設計で決める |
| 高さの戻しと保持（#169） | ダブルクリックで定義から決まる高さに戻す。変えた高さを sessionStorage に持ち、読み直しても保つ | 図ごとのキーの決め方はモジュール構成設計で決める |
| 列のボタン（#172） | アイコンだけにし、列を隠しているときは隠した列の数のバッジを出す。読み上げの「（N 列を隠しています）」は残す。メニューの見出しをボタンの呼び名に合わせる | ツールチップと aria-label の語は `未確定`（`要件.md` の `## 要望`） |
| 列のボタンのストーリー（#172） | Storybook に A（アイコンだけ）・B（アイコン＋語）・C（帯のボタンを 1 つのメニューにまとめる）の stories を並べ、A でコピーのボタンの文字の有無も見せる | C は見比べるためだけのストーリー |
| 図のツールチップの位置（#188） | 設定の `tooltips` に図の位置のキー（例 `diagramPlacement`。既定 `bottom`）を追加し、本文は `placement`（既定 `top`）のままにする。`mdmark check` が新しいキーも点検し、書き出した HTML も引き継ぐ | 埋め込んだ HTML の `data-hint` の扱いは `未確定`（`要件.md` の `## 要望`） |
| 凡例（#188） | `legendFor` が、図に 2 種類以上あるノードの種類と線の種類だけを載せる。枠・層・交差・ツールチップのマーカー・用語の下線は載せない。『構成図の決まり』も同じに修正する | 載せる項目が無い図で凡例の場所を出すかは部品設計で決める |
| グループのタイトルのヒント（#188） | `frame`・`lanes` に `hint` を追加し、タイトルの右のマーカーからノードと同じツールチップを出す | 図の定義の点検で文字の値として確かめる |
| グループのタイトルを留める（#188） | `frame`・`lanes` のタイトルを、グループが表示の枠に見えている間は上端に留める。既定はオンで、定義の `stickyTitles: false` で切る | シーケンス図の相手の行を留める処理と同じ考え方 |
| 設定の Schema（#169・#188） | `schemas/mdmark.config.schema.json` にキーを追加し、`migrations/no-steps.yaml` に行を置く | 既存の設定はそのまま動く |

表の幅の広げ方（#168）: `table` は `display: block` のため、`width: 100%` だけでは外側のブロックが広がるだけで列は中身の幅のままになる（#168 の task-reviewer の指摘）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 表を包む要素を描画で追加して横スクロールと枠をそちらへ移し、`table` は `display: table` で `width: 100%` にする | 列が本文の幅まで広がり、収まらない表だけ包む要素の中で横にスクロールする | `src/render` の表の出力と、表を前提にした CSS・操作（見出し行と集計の行の留め方・端の影）を包む要素に合わせて修正する |
| B | `table` を `display: block` のまま、中の行のボックスを広げる CSS を当てる | 描画の出力を変えない | 匿名の表のボックスは CSS で幅を指定できず、列を本文の幅まで広げられない |

推奨: A

B では #168 の終わりの条件（列が本文の幅まで広がる）を満たせないため。
