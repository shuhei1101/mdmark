# 要件

## 要望

描いた文書の表示を、子 Issue 5 件の終わりの条件まで改善する。
子ごとの範囲と決まったこと（検討事項 D-11・D-17・D-19・D-24・D-28・D-29）は子の Issue の本文と、本文の `## 必読` に挙げた話し合いの記録が正。
今の文書・設定・図の定義は、書き換えずにそのまま描ける。

| 子 | 終わりの条件 |
| --- | --- |
| [#160](https://github.com/shuhei1101/mdmark/issues/160) | グラフの点・棒・円の項目へのポインターとキーボードのフォーカスで、系列の名前と値（折れ線・棒は横の目盛りと値、散布図は x と y、円は項目の名前と値と割合）がツールチップで出て、拡大した図のドラッグでの移動と両立する |
| [#168](https://github.com/shuhei1101/mdmark/issues/168) | 表が本文の幅いっぱいに広がり、中身が本文の幅に収まらないときだけ今の横スクロールと端の影で示す（列の最小幅と見出しの折り返さない指定は今のまま。表ごとの幅の固定値は不要） |
| [#169](https://github.com/shuhei1101/mdmark/issues/169) | 図・グラフの表示の範囲の右下のリサイズハンドルで、ドラッグと上下キーで高さを縦にだけ変えられる。リサイズハンドルは機能のオン・オフで出し分け（既定は出す）、ダブルクリックで元の高さに戻し、変えた高さを sessionStorage に持って読み直しても保つ。高さを変えたら全体を収める倍率を計算し直し、全画面のモーダルの中ではリサイズハンドルを出さない |
| [#172](https://github.com/shuhei1101/mdmark/issues/172) | 列の表示・非表示のボタンがアイコンだけ（ツールチップと aria-label は「列」）になり、列を隠しているときは隠した列の数のバッジを出す（読み上げの「（N 列を隠しています）」は残す）。メニューの見出しをボタンに合わせて見直し、Storybook に A・B・C の stories を並べる |
| [#188](https://github.com/shuhei1101/mdmark/issues/188) | 図のツールチップの既定が `bottom` で、設定に図の位置（例 `tooltips.diagramPlacement`）を分けて持つ（本文は `top` のまま）。凡例は図に 2 種類以上あるノードの種類と線の種類だけを載せる（『構成図の決まり』と `legendFor`）。`frame`・`lanes` に `hint` のツールチップと、グループが見えている間タイトルを上端に留める動き（既定はオン、定義の `stickyTitles: false` で切る）がある |

#188 の凡例の絞り込みは、`legendFor` を共有するフロー図とシーケンス図の両方に当てる（『フローチャートの決まり』は凡例を『構成図の決まり』に従わせている）。
グラフの系列の凡例は変えない。

`未確定`: 列のボタンのツールチップと aria-label の語（決める段: モック作成）

#172 の D-24（2026-10-27）は「列」に決めたが、後の [#275](https://github.com/shuhei1101/mdmark/pull/275) のモックの確認（[確認ログ](https://github.com/shuhei1101/mdmark/blob/develop/dev/pr/275/%E7%A2%BA%E8%AA%8D%E3%83%AD%E3%82%B0.md)）でユーザーが文字のラベルを「列の表示」から「列設定」に変え、develop は「列設定」になっている。

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | アイコンだけにし、ツールチップと aria-label を「列設定」にする | 後に決めた呼び名のまま、帯を短くできる。メニューの「リセット」と合わせて設定のメニューと読める | #172 の終わりの条件の「列」と食い違う |
| B | アイコンだけにし、ツールチップと aria-label を「列」にする（#172 の D-24） | #172 の終わりの条件のとおり | #275 で決めた「列設定」を戻す |

推奨: A

ユーザーが後に決めた呼び名で、アイコンだけにする #172 の目的（帯をすっきりさせ、隠した列を数で示す）はどちらの語でも満たせるため。
モックの確認でユーザーに確かめる。

`未確定`: 埋め込んだ HTML の `data-hint` のツールチップの既定の位置（決める段: 単一ユースケース設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 図のツールチップと同じく図の位置（既定 `bottom`）にする | 同じ処理（`attachDiagramTips`）が付けるツールチップの位置が揃い、同じ HTML の中のチャートの項目のツールチップとも揃う | 本文に近い使い方の HTML でも下に出る |
| B | 本文の位置（既定 `top`）にする | 本文の用語のツールチップと揃う | 同じ処理が付けるツールチップで、持ち主によって位置の設定が分かれる |

推奨: A

#188 が図のツールチップとして扱う範囲を、ツールチップを付ける処理の単位で決めると、設定の説明と実装の分岐が 1 つで済むため。
