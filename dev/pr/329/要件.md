# 要件

## 要望

タッチ端末で開いた用語のツールチップを、ツールチップと語の外のタップで閉じられるようにする。
マウスのホバーとキーボードの開閉（Esc・Tab でツールチップの中へ移る）は今のまま保つ。

対象は用語のツールチップの全ての種類（用語・関連文書・やめた言い方・エイリアスの種類ごとの区分）と、図の箱の中の用語・埋め込んだ HTML の中の用語に付く用語のツールチップとする。
ツールチップの中のリンクとコピーのボタンのタップは外のタップに当たらず、ツールチップを閉じない。

語（ツールチップの持ち主）のタップでの開閉は、図のツールチップと同じにする。
`pointerType` が `touch` のとき、閉じた語のタップで開き、開いた語のもう一度のタップで閉じる。タッチの `pointerenter`・`pointerleave` では開閉しない。
