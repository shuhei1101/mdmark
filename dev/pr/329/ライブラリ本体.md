## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 外のタップで閉じる | タッチのタップで開いている間だけ `document` に捕捉の段の `pointerdown` を付け、対象が語の枠（語とツールチップ）の外なら閉じる | ツールチップの中のリンク・コピーのボタンの `pointerdown` では閉じない |
| 語のタップでの開閉 | `pointerType` が `touch` の語の `pointerdown` で開閉を切り替え、タッチの `pointerenter`・`pointerleave` では開閉しない | `mouse`・`pen` は今のまま |
| 埋め込んだ HTML の中の用語 | 本文の用語と同じ開閉の処理を通す。埋め込んだ HTML のヒントのツールチップ（`diagram-tips.ts`）の外の `pointerdown` と、用語のツールチップの外の `pointerdown` は、互いの持ち主とツールチップを外として扱い、どちらを開いても他方を閉じる | 図の部品の中の用語は `diagram-tips.ts` が出すため対象外 |
| 単体テスト | `terms.browser.test.ts` に、タッチの 1 回のタップ（`pointerenter`・`pointerdown`・`pointerup`・`pointerleave`・`focus` を実際の順序で発火）で開いたままになるケース、`pointerleave`・`blur` を発火させずに外の `pointerdown` だけで閉じるケース、ツールチップの中のリンク・ボタンの `pointerdown` で閉じないケース、マウスの `pointerdown` で切り替えないケースを加える | |
| 結合テスト | `mount.browser.test.ts` に、用語のツールチップをタッチで開いて外のタップで閉じるケースを加える | |
| E2E | 『用語の意味をツールチップで見る』に、Playwright の `hasTouch` のコンテキストで、タップで開いたツールチップを外のタップで閉じるケースを加える | |
