# 要件

## 要望

Sprint v0.10.0 の E2E（release の [4bb3708b](https://github.com/shuhei1101/mdmark/commit/4bb3708be49be0d95be47b793f54e5d07e412fad)）で fail した次の 4 件を、release で pass させる。
修正は release ブランチ `release/v0.10.0` へ入れる。
release の [7d857008](https://github.com/shuhei1101/mdmark/commit/7d857008) で、手元の chromium で 4 件を実行し直した。
実装は変えず、シナリオ 1 件の準備と E2E 3 件を修正する。

<!-- table: data -->

| テスト | 手元で確認した結果（7d857008・chromium） | 原因 | 修正する側 |
| --- | --- | --- | --- |
| 単一ユースケース『まとめたHTMLで文書を行き来する』の `test_normal_when_wide_range` | fail。wide の範囲の幅が段落の幅 `1082` のままで広がらない | 本文の幅 `--mdmark-content-width` の既定は `none` で、テーマが空のまとめた HTML では段落が文書の領域いっぱいに広がる。wide の範囲は描く先の要素より親が広いときだけ広げる（部品設計『wide の範囲』）ため、広げる幅が無い | シナリオの準備とテストに、本文の幅を `640px` にするテーマを記載し、画面の幅をシナリオの 1280px にそろえる |
| 単一ユースケース『図と表を本文の幅より広げる』の `test_normal_when_side_toc_shown` | pass | 起票後に release へ入った #408・#411 の後で pass する | 修正しない |
| 同上の `test_normal_when_narrow` | fail。`scrollable` が false | 表を横にスクロールさせる要素が #308 で表を包む `.mdmark-table-scroll` へ移ったのに、テストは表と `.mdmark-wide-range` だけを確認している（#411 のピン止めの 2 件と同じ型） | テストのスクロールの判定に `.mdmark-table-scroll` を含める |
| 複合ユースケース『ビューで探してコメントを付ける』の `test_normal` | fail。`selectText` が「選ぶ文字が無い」を投げる | #277 で本文が `div.mdmark-content` に包まれ、テストのセレクター `#doc > p` が段落に当たらない | テストのセレクターを本文の列の直下の段落にする |

<!-- /table -->

終わりの条件は、上の 4 件が release の今の配布物で chromium と firefox の両方で pass し、同じ spec の他のケースが fail しないこと。
