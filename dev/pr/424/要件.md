# 要件

## 要望

- フロー図のノードの種類 `dm` の既定の `tag`・凡例の名前・CSS 変数 `--mdmark-color-diagram-dm` の説明を、利用側の固有の用語「意思決定モデル」を含まない汎用の名前にする
- 使用方法・リファレンス・見本・設計書・モック・Storybook・テストから「意思決定モデル」を無くす（`dev/pr/` を除き、develop で `git grep "意思決定モデル"` が 0 件）
- 使用方法『図を描く』に、判定の質問のノードは `question`、`dm` は別の用途であることを示し、判定の質問のノードを描く人が `question` を選べるようにする
- `dm` のキーと CSS 変数 `--mdmark-color-diagram-dm` は残し、表示名を「判断（AI）」にする（[確認事項](https://github.com/shuhei1101/mdmark/pull/424#discussion_r4507239642) で推奨案 A に決定）
