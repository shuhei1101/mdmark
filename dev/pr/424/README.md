# フロー図のノードの種類 dm の表示名「意思決定モデル」を汎用の名前にし、dm と question の使い分けを示す

## 概要

フロー図を描く人が、ノードの種類 `dm` のノードと凡例で、利用側の固有の用語でない汎用の名前を確認できるようにする。
判定の質問のノードを描く人が、使用方法の `dm` と `question` の使い分けを参照して `question` を選べるようにする。

## 背景

[Issue #333](https://github.com/shuhei1101/mdmark/issues/333) の要望。
フロー図のノードの種類 `dm` の表示名が、aituber の固有の用語「意思決定モデル」になっている。
判定フローチャートの質問のノードに `dm` を指定すると、ノードと凡例に「意思決定モデル」と出て、判定の主体が読み取れない。
判定フローチャートのノードの種類 `start`・`question`・`action`・`result` は [#251](https://github.com/shuhei1101/mdmark/issues/251) で追加済み。
