## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `dm` の表示名 | `KIND_STYLES` の `dm` の `tag`・`legend` を、利用側の固有の用語を含まない汎用の名前にする | `未確定`（要件の `dm` の扱いと表示名） |
| 使い分けの説明 | 使用方法『図を描く』の `kind` の表に、判定の質問のノードは `question` を指定することを示す | - |
| 見本の用語 | 見本・モック・Storybook・テストの用語「意思決定モデル」を、汎用の用語（例: 「分類モデル」）に替える | 用語のツールチップの振る舞いは変えない |
| 既存機能への影響 | `dm` のキーと CSS 変数 `--mdmark-color-diagram-dm` は変えない（要件の推奨 A のとき） | 案 B のときは `破壊的変更` と移行の手順を足す |
