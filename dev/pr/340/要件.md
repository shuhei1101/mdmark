# 要件

## 要望

390px × 844px の画面で、コメントの吹き出し（`Parts/CommentBubble`）・入力欄（`Parts/CommentForm`）の全ストーリーを開いたとき、ページの `scrollWidth` が `clientWidth` 以下になる（横スクロールが出ない）。
同じ `STATIC_POPOVER_STYLE` で描くコメントのボタン（`Parts/CommentButton`）のストーリーも同じ条件を満たす。

- 原因（`position: static` にした枠の幅と、ストーリーの描く先の要素の余白など計算に入っていない幅）を調べ、部品の CSS とストーリーの描き方のうち誤っている側を修正する
- 実際の文書で `document.body` に `position: fixed` で配置する吹き出し・入力欄の幅と位置は変えない
- 390px の画面でのはみ出しを、ストーリーの結合テストで確認する
