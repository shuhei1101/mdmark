## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 知らないキー | 対象のマーカーで、知っているキーの一覧に無い `キー=値` は警告を追加せずに読み飛ばす | |
| 知らない機能 | 表の `+名前`・`-名前` のうち `TABLE_FEATURES` に無いものは警告を追加せずに読み飛ばし、既定の種類の機能のまま描く | |
| 知らない指定の単語 | 表の種類・タブ・ステップ・ギャラリー・ファイルツリー・コードブロック・`wide`・`section` の知らない単語は警告を追加せずに読み飛ばす。`section` の知らない値は開いた状態で描く | `title=` の直後の単語は今のまま警告にする |
| page のマーカー | 知らないキーは読み飛ばし、`scheme`・`theme`・`toc` の知らない値だけを今の警告にする | |
| 値の誤りと組み合わせの誤り | 表に無い列名・読めない番号・読めない値・`closed` と `open` の同時指定・`closed`・`open` の無い `title=`・機能の無い表の `hide=`・`total=`・`pin=` の警告は今のまま | |
| 点検 | `text`・`file` の点検で、描画が読み飛ばした知らないキー・機能・指定を、書き方の警告とも知らないマーカーとも別のずれの種類で返却する | ずれの種類は `unknown_mark_arg` |
| 書き方の警告の部品 | 部品の引数と HTML は変えず、ストーリーの例だけを知っているキーの誤った値に差し替える | |
