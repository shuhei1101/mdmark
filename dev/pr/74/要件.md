# 要件

## 要望

配布物 `dist/index.js` に、画面を出さずに本文の参照を取り出す公開関数を 1 つ追加する。
`collectReferences`・`mount`・`render` の引数と戻り値は変えない。

入力は、索引（`MdmarkIndex`）・文書のパスから Markdown の本文を引く表（複数の文書を渡せる）・設定（`MdmarkConfig`。読むのは `features`）にする。
照合の辞書は、索引の用語・用語集の表の用語・文書の別名から作る（ツールチップと同じ）。

戻り値は次の 2 つを持つ。

- 文書ごとの参照の配列。要素は、参照先の種類（索引の用語・用語集の表の用語・文書）・ID・タイトル・短い説明と、一致した文字列・本文の中の位置を持つ
- 渡した全ての文書の参照先を、重なりを除いてまとめた 1 つの配列（同じ参照先は 1 回だけ入る）

参照先の値は、種類ごとに次のとおり取る。

| 種類 | ID | タイトル | 短い説明 |
| --- | --- | --- | --- |
| 索引の用語 | `terms[].id` | `terms[].term` | `terms[].meaning` |
| 用語集の表の用語 | ツールチップと同じ `glossary:{文書の id}:{用語}` | 用語の列 | 意味の列 |
| 文書 | `docs[].id` | `docs[].title` | `docs[].description`（無ければ持たない） |

一致の規則はツールチップの下線と同じにする。

- 辞書の語と優先の順は `buildDictionary` と同じ（索引の `terms` → 照合する文書の用語集の表 → ほかの文書の表。文書の別名は、照合する文書自身の別名を除く）
- 語の区切りに揃う一致だけを取り、重なるときは長い語を先に取る（`findWords` と同じ）
- 照合する範囲は、コード・リンク・見出し・用語集の表の中を除く（`forEachInline`・`matchableChildren` と同じ）
- 文書の印で `glossary` がオフの文書は用語を、`backlinks` がオフの文書は文書の別名を照合しない

ツールチップの、節ごとに同じ参照先の最初の 1 回だけに下線を付ける制限は下線の出し方のため、文書ごとの参照の配列には同じ参照先の出現を全て並べる。

Node とブラウザのどちらでも同じ結果を返し、DOM に頼らず、引数を書き換えない。

`未確定`: 本文の中の位置の表し方（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 本文の Markdown の行（1 から）と、その行の中の始まりと終わりの位置（UTF-16） | `checkIndex` のずれの `{行} 行目` と同じ行の数え方で、使う側が本文の行から一致を切り出せる | 行の中の位置を本文の文字へ戻す処理が要る |
| B | 本文の Markdown の頭からの始まりと終わりの位置（UTF-16） | 使う側が `slice` 1 回で一致を切り出せる | 行の中の位置と同じく本文の文字へ戻す処理が要り、人が読んでも場所が分からない |
| C | 本文の Markdown の行（1 から）だけ | 段落のトークンの行の範囲と改行から求められ、作りが小さい | 同じ行に同じ語が 2 回出ると、どちらか区別できない |

推奨: A

使う側（AI へ本文を返すアプリ）は行で本文を扱い、点検のずれと同じ数え方にそろえられる。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 本文に書いた文書の `id` の文字列を参照として照合する | Issue の「項目の ID」は参照先の ID として返す値と読んだ。ツールチップは文書の `id` を照合せず、照合に足すと画面と取り出しの参照がずれる。この読み方はレビューで確定する | 予定なし |
| 埋め込んだ HTML（`<!-- html -->` のコードブロック）の中の文字と、図の部品の箱の `{{語}}` の照合 | 取り出しの対象は使う側が AI へ返す Markdown の本文の地の文とし、コードブロックの中は照合しないと判断した。埋め込んだ HTML の下線も取り出しに含めるかはレビューで確定する | 予定なし |
| 取り出した参照を AI へ返す MCP のツール | 使う側のアプリ（mindstella）の Issue が持つ | 予定なし |
| 取り出しを呼ぶ CLI のコマンド | 要望は公開関数まで | 予定なし |
