## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 公開関数 | `src/knowledge/` に取り出しの関数を追加し、`src/index.ts` から公開する。入力は `collectReferences` と同じ `index`・`documents`・`config` | 関数名はインターフェース定義設計で決める |
| 照合 | 文書ごとに `parseDocument` で本文を読み、`buildDictionary`（`docId` に照合する文書、`references` に同じ入力の `collectReferences` の結果）の辞書で、`forEachInline`・`matchableChildren` の範囲を `findWords` で照合する | 下線の照合と同じ関数を通し、照合の規則を別に書かない |
| 埋め込んだ HTML と図の部品 | 埋め込んだ HTML の文字は `termsFilter` と同じ範囲を `findWords` で、図の部品の定義の `{{語}}` は `lookup` と同じく辞書の用語に完全に一致する語を、参照にする | 照合の範囲は描く処理と同じ関数から取り、別に書かない |
| 文書ごとの参照 | 一致ごとに 1 要素とし、本文の頭からの順に並べる。参照先の種類は索引の用語・用語集の表の用語・文書の 3 つ | 1 つの語が用語と文書の別名の両方に当たるときは、参照先ごとに 1 要素 |
| まとめた参照 | 全ての文書の参照先を、種類と ID の組で重なりを除き、索引の `docs` の順・文書の中の初出の順に並べる | 一致した文字列と位置は持たない |
| 位置 | 本文の Markdown の中の位置を返す | 表し方は要件.md の `未確定` |
| 機能のオフ | 文書の印で `glossary` がオフなら用語、`backlinks` がオフなら文書の別名を、その文書から取り出さない | 設定の `features` と文書の印の重ね方は `collectReferences` と同じ |
| 既存機能への影響 | `collectReferences`・`mount`・`render`・`checkIndex` の引数・戻り値と描いた HTML は変わらない | - |
