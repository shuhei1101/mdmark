# 拡張記法の表に件数の表示・列の表示の切り替え・集計の行・表のコピー・行へのリンクを追加する

## 概要

文書を書く人が表の印の `+機能` で、件数の表示・列の表示の切り替え・集計の行・表のコピー・行へのリンクを表に付けられるようにする。

## 背景

[Issue #23](https://github.com/shuhei1101/mdmark/issues/23) の要望。
[PR #19](https://github.com/shuhei1101/mdmark/pull/19)（起点 [Issue #4](https://github.com/shuhei1101/mdmark/issues/4)）で入れた表の印は、並べ替え・ピン止め・絞り込み・折り畳みを持つ。
上の 5 つの機能は PR #19 の要件.md の `## スコープ外` に切り出した。
PR #19 はマージ済みで、表の印の実装（`src/render/syntax/tables.ts`・`src/parts/table.ts`・`src/interact/tables.ts`）は develop にある。
