## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 表の印の読み取り | 機能名に `count`・`columns`・`total`・`copy`・`rowlink`、キーに `hide=列名,…`・`total=列名:計算,…` を足す。列名は `filter=` と同じく見出しの文字と照らし、表に無い列名・知らない計算は書き方の警告にしてその指定だけを当てない | 既定の機能に入れるかは要件.md の `未確定` |
| 件数の表示 | 表の上の帯に `{表示している行の数} / {全ての行の数} 件` を出し、絞り込みのたびに書き換える。読み上げは `aria-live="polite"` で知らせる | 文言はモック作成で決める |
| 列の表示の切り替え | 表の上の帯のボタンで、列名のチェックボックスを並べたメニューを開く。隠した列は見出しとセルを `hidden` にし、最後の 1 列は外せない | ピン止めした列を隠したときの留め方は部品設計で決める |
| 集計の行 | `tfoot` の行に集計を出し、絞り込み・列の表示の切り替えに合わせて計算し直す。並べ替えでは動かない | 小数の桁はモック作成で決める |
| 表のコピー | 表の上の帯のボタンで、表示している行と列（集計の行を含まない）をクリップボードへ写し、ボタンの中で写したことを知らせる。クリップボードが使えないときは失敗を知らせる | 形式は要件.md の `未確定` |
| 行へのリンク | 各行の先頭のセルに `#ID` のリンクを置き、行に `id` を付ける。URL の `#ID` が行を指すとき（描いたときと `hashchange`）、閉じた表・閉じた節を開き、絞り込みで隠れていれば絞り込みを外してから行へ移り、行を強調する | ID の決め方は要件.md の `未確定`。まとめた HTML の `#` の形との合わせ方はインターフェース定義設計で決める |
| 印刷 | 表の上のボタンと行へのリンクの印は印刷に出さない。件数と集計の行は印刷に出し、隠した列は隠したまま出す | |
| アクセシビリティ | ボタンは読み上げの名前を持ち、メニューは `aria-expanded`・`aria-controls` で開閉を示し、Esc で閉じてボタンへフォーカスを戻す（絞り込みのドロワーと同じ作法） | |
| 既存機能への影響 | 並べ替え・ピン止め・絞り込み・折り畳み・行の詳細の振る舞いは変えない。行の詳細は列を隠しても行に付いて動く | |
| 性能 | 配布物の大きさの上限（非機能要件）に収める | 増分はビルドの検査で確かめる |
