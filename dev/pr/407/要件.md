# 要件

## 要望

リポジトリの移行の手順を参照する次の 3 つのテストを、`migrations/next/` が有ればそこから、無ければバージョンが最も新しい `migrations/v{バージョン}/` から参照するようにする。
release・master（`migrations/next/` を移した後）と develop（`migrations/next/` が有る）のどちらでも、3 つのテストと `npm run typecheck` が通る。

| テスト | 現在の参照先 |
| --- | --- |
| 単体テスト [tests/unit/migrations/drop-tag-vocabulary.test.ts](https://github.com/shuhei1101/mdmark/blob/4bb3708b/tests/unit/migrations/drop-tag-vocabulary.test.ts) | `migrations/next/drop-tag-vocabulary.mjs` の import |
| 結合テスト [tests/integration/lib/upgrade.test.ts](https://github.com/shuhei1101/mdmark/blob/4bb3708b/tests/integration/lib/upgrade.test.ts) の `test_normal_when_tag_vocabulary_dropped` | `migrations/next/` の `steps.yaml` と `.mjs` |
| E2E [tests/e2e/単一ユースケース/版を上げる.spec.ts](https://github.com/shuhei1101/mdmark/blob/4bb3708b/tests/e2e/%E5%8D%98%E4%B8%80%E3%83%A6%E3%83%BC%E3%82%B9%E3%82%B1%E3%83%BC%E3%82%B9/%E7%89%88%E3%82%92%E4%B8%8A%E3%81%92%E3%82%8B.spec.ts) の `nextMigrationFiles()` | `migrations/next/` の `steps.yaml` と `.mjs` |
