## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 参照するフォルダの決め方 | `migrations/next/` が有ればそれを、無ければ `migrations/v{バージョン}/` のうちバージョンが最も新しいフォルダを返却する関数を単体・結合・E2E が共有するテストの補助（`tests/migrations-dir.ts`）に配置し、3 つのテストで共有する | バージョンは数値で比べる |
| 単体テストの import | 決めたフォルダのファイルを実行時に import する | `npm run typecheck` が、存在しないフォルダのパスを解決しないようにする |
| 結合テスト・E2E | `join(REPO_ROOT, "migrations", "next")` を、決めたフォルダに置き換える | - |
| 一時フォルダに `migrations/next/` を作るテスト | 変更しない | 影響を受けない |
