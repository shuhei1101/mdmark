# 要件

## 要望

`mdmark check` で、点検する文書の本文にある知らない印を、1 つにつき 1 行のずれとして出す。

- 知らない印は、描く処理が印として拾う HTML コメント（`<!-- 名前 -->`・`<!-- 名前: 引数 -->`・`<!-- /名前 -->`）のうち、名前が `features`・記法の印・設定の `libraries` の対応表・設定の `extensions` の拡張が登録した印・設定の `check.ignore` の名前のどれにも当たらないもの
- 印を拾う範囲は描く処理と同じにし、コードブロックとインラインコードの中の文字は拾わない
- 点検する文書は、索引の点検に渡す文書（設定に `index` があるとき）と `build` の対象の文書（設定に `build` があるとき）を合わせたものにし、同じファイルは 1 回だけ点検する
- 拡張が登録した印の名前は、設定の `extensions` のモジュールを `mdmark export` と同じく束ね、Node で読み込んで既定の書き出しの `directive` から取る。読み込めない拡張は `extensions[{位置}]` を指す `schema` のずれにし、その拡張の印は知らない印として出す
- 設定に省いてよいキー `check.ignore`（印の名前の並び）を追加し、他のツールへの指示（`<!-- prettier-ignore -->` など）のような印として書いていない HTML コメントを、書いた人が知らない印から外せるようにする
- ずれの行は今の `{ファイル}:{場所}: {種類}: {内容}` の形で出し、種類は `unknown_mark`、ファイルは設定ファイルのフォルダからの相対パス、場所は印のある行の番号、内容は知らない印の名前と直し方の 1 文にする
- ずれがあれば今の点検と同じく終了コード 1 で終わる
- `mdmark upgrade` が移行の手順を当てた後に流す点検には、知らない印を含めない（移行の前から文書にある知らない印で版を上げられなくならないようにする）

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 既知の印の読めない引数（知らない種類・機能・キー）の点検 | 描いた文書の中に書き方の警告として出ており、要望は知らない印だけ | 予定なし |
| `features` の印の知らない機能名の点検 | 描く処理が知らせずに無視すると決めており（インターフェース定義『文書をHTML文字列にする』）、要望は知らない印だけ | 予定なし |
| Claude Code のプラグインと MCP から点検を呼ぶ口 | `runCheck` を呼ぶ側の変更で、点検の中身に依らない | [#11](https://github.com/shuhei1101/mdmark/issues/11) |
