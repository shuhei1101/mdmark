# 要件

## 要望

Firefox だけで fail する図の E2E の 2 件を、ケースごとに実装とテストのどちらが設計書（シナリオ・部品設計『図の枠』『図のツールチップ』『グラフ』）と食い違うかを切り分け、食い違う側を修正する。
2 件が release ブランチの E2E で Firefox と Chromium の両方で pass し、同じテストファイルの他のケースも fail しないことを終わりの条件にする。

| ケース | テスト | 終わりの条件 |
| --- | --- | --- |
| 単一ユースケース『図を拡大・縮小・移動する』 | `test_normal_when_resized` | リサイズハンドルを下へ 200px ドラッグすると、表示する枠がドラッグした量のとおりに高くなる（Firefox で約 856px 高くならない） |
| 単一ユースケース『図の要素のツールチップを見る』 | `test_normal_when_chart_items` | グラフの項目へ移したフォーカスが Firefox でも項目に留まり、`toBeFocused()` が pass する |

テストの期待が設計書と食い違うケースは、テストを設計書に合わせて修正し、実装は変えない。
