## 現状

| 分類 | ページ / ファイル | 概要 | 補足 |
| --- | --- | --- | --- |
| 実装 | `LICENSE` | リポジトリの直下のライセンスの本文 | 無い。新規作成 |
| 実装 | [package.json](https://github.com/shuhei1101/mdmark/blob/develop/package.json) | ライブラリ本体のパッケージの定義 | `license` が無い |
| 実装 | [package-lock.json](https://github.com/shuhei1101/mdmark/blob/develop/package-lock.json) | 依存の固定 | 直下のパッケージの項目に `license` が無い |

## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `LICENSE` | 直下に MIT License の全文を置き、著作権表示を `Copyright (c) 2026 shuhei1101` にする | 本文は [vscode/LICENSE](https://github.com/shuhei1101/mdmark/blob/develop/vscode/LICENSE) と同じ MIT の全文で、著作権表示の行だけが違う |
| `package.json` | `"license": "MIT"` を `"private"` の次に追加する | - |
| `package-lock.json` | `npm install --package-lock-only` で直下のパッケージの項目に `"license": "MIT"` を入れる | 依存の解決結果は変えない |
| 既存機能への影響 | ビルド・テスト・配布物の中身を変えない | `npm run build` の `dist/` が変わらないことを確かめる |
