## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 部品 | 先頭へ戻るボタンを新しい部品として `src/parts/` に置き、ストーリーを持つ | 部品設計を新規作成する |
| 閲覧機能 | スクロールの量が閾値を超えたらボタンを出し、閾値未満では隠す | 閾値はスクロールする場所の高さ 1 つ分 |
| 操作 | 押すと描いた文書の先頭（描く先の要素の上端）へスクロールし、文書の先頭へフォーカスを移す | 利用者の環境が動きを減らす設定（`prefers-reduced-motion: reduce`）のときは瞬時に移る |
| スクロールする場所 | 描く先の要素に最も近いスクロールする祖先の要素を見て、無ければ画面全体を見る | - |
| 配置 | 画面の右下に固定し、右側の目次・余白のマーカー・ミニマップと重ならない位置に置く | スクロールする場所の右端・下端から 16px。ミニマップ・余白の列と横の範囲が重なるときは、その左から 8px 空ける（スクロールの位置で動かさない） |
| 設定 | `features` に機能の名前を英語のキーで追加し、文書のマーカーで上書きできるようにする | 既定はオン |
| アクセシビリティ | `button` 要素で、`aria-label`・`title` に用途を書く。隠している間は Tab で届かず、読み上げにも出さない | - |
| 印刷 | 印刷の規則でボタンを出さない | - |
| 既存機能への影響 | 右側の目次・余白のマーカー・ミニマップ・ライトボックスと図の全画面の重なりの順を変えない | 全画面とライトボックスを開いている間はボタンを前に出さない |
| 性能 | スクロールのたびの判定は `scroll` の受け取りを `passive` にし、閾値をまたいだときだけ表示を切り替える | - |
