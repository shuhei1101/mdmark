# 要件

## 要望

`mount` が描いた文書に、先頭へ戻るボタンを置く。

- 文書を一定量スクロールしたら、画面の右下にボタンを出し、押すと描いた文書の先頭へ戻る
- 文書の先頭の近くにいる間は出さない
- 印刷・PDF では出さない
- キーボードで押せ（Tab で届き、Enter・Space で押せる）、読み上げでボタンの用途が分かる（アクセシブルな名前を持つ）
- 押した後のフォーカスは文書の先頭へ移し、続けて Tab で本文を読み進められる
- 右側の目次・余白のマーカー・ミニマップなど、描いた文書の右側に置く部品と重ならない位置に置く
- 設定の `features` と文書の `<!-- features: -->` のマーカーで、ほかの機能と同じくオン・オフできる。設定の Schema に機能の名前を追加し、`migrations/no-steps.yaml` に行を置く

ボタンを出し始めるスクロールの量: スクロールする場所の高さ 1 つ分（[確認ログ](./確認ログ.md)）

機能の既定のオン・オフ: 既定でオン（[確認ログ](./確認ログ.md)）

スクロールする場所: 描く先の要素に最も近いスクロールする祖先の要素（無ければ画面全体）を見て、そこを先頭へ戻す（モックへの合意。[確認ログ](./確認ログ.md)）

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| 文書の先頭のマーカーでのページの設定（配色など）の指定 | 機能のオン・オフは既存の `<!-- features: -->` のマーカーで足り、ページの設定のマーカーの新設は別の要望 | #161 |
| 右側の目次をピン止めしていないときも画面の右端に置く変更 | 右側の目次の置き場所の変更は別の要望。後から入る側がボタンと重ならない位置に置く | #270 |
| 先頭以外の場所（前の見出し・末尾）へ移るボタン | 要望に含まれない | 予定なし |
