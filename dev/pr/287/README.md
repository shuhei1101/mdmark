# 描いた文書を一定量スクロールしたら、画面の右下に先頭へ戻るボタンを出す

## 概要

読む人が、長い文書を下までスクロールした後に、画面の右下のボタンで文書の先頭へ戻れるようになる。

## 背景

[Issue #162](https://github.com/shuhei1101/mdmark/issues/162) の要望。
`mount` が描いた文書には先頭へ戻る操作が無く、長い文書を読んだ後はスクロールで戻る必要がある。
右側の目次（[#166](https://github.com/shuhei1101/mdmark/pull/166)）は描く先の要素の右上に留まり、狭い幅では上端の帯になるため、画面の右下にはまだ部品が無い。
