# 要件

## 要望

`collectMatches` の戻り値に `avoided`（文書の `id` から、本文に出たやめた言い方の出現の並び）を加える。
要素は一致した文字列・本文の位置（`line`・`start`・`end`）と、代わりの用語（`kind`・`id`・`title`・`description`。`MdmarkMatchTarget` と同じ項目）を持つ。

- やめた言い方の照合は、描いた文書のマーカーと同じ照合の辞書 `buildDictionary` の `avoided` を使う（照合の範囲・語の切れ目・用語の語と別名を優先する規則・`glossary` がオフの文書では照合しないことを描いた文書と揃える）
- 節ごとに最初の 1 回だけに付ける数え方は効かせず、本文の一致と同じく出現を全て返す
- 代わりの用語は照合の辞書の `avoided` が返す用語にする（今は索引の用語。用語集の表のやめた言い方を辞書へ入れる [PR #106](https://github.com/shuhei1101/mdmark/pull/106) が先に develop へ入ったときは、用語集の表の用語も代わりの用語になる）
- 既存の戻り値の項目（`byDocument`・`targets`）と、その中身は変えない
- 被参照（`collectReferences`）と点検（`checkIndex` の `avoided_term`）は変えない
