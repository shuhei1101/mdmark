## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 戻り値 | `avoided`（文書の `id` から、やめた言い方の出現の並び）を加える。要素は一致した文字列・`line`・`start`・`end`・代わりの用語を持つ。既存の `byDocument`・`targets` とその要素は変えない | - |
| 照合 | 文書ごとに作る `buildDictionary` の `avoided` の語を、地の文と埋め込んだ HTML の段落の文字で、描いた文書のマーカーと同じ規則で照合する。図の部品の `{{語}}` は照合しない | 用語の語・別名の一部として出たところは返さない |
| 代わりの用語 | `avoided` が返す用語の `id` から、`byDocument` と同じ参照先の項目（`kind`・`id`・`title`・`description`）を引く | 用語集の表の用語は PR #106 が辞書へ入れた後に `kind: "glossary"` で返る |
| 機能のオン・オフ | `glossary` がオフの文書では、やめた言い方を返さない（空の並び） | 描いた文書と同じ |
| 既存機能への影響 | 参照先の一致・`targets`・`collectReferences`・`checkIndex` は変えない | 戻り値への項目の追加で、破壊的変更にならない |
