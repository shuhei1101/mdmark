# 要件

## 要望

E2E の『使い方集を読む』『ClaudeCodeで使い方集を参照して書き点検する』の `test_normal` で、dev-docs への `search_docs` の呼び出しが MCP の SDK の既定の要求の時間切れ（60 秒）で落ちないようにする。

- `tests/e2e/dev-docs.ts` の `searchDocs` の `client.callTool` に、規約『資源の値の決め方』の「下流を待つタイムアウト」で導いた要求の時間切れを明示して指定する
- 導出の元の値は、起動した dev-docs への `search_docs`（使い方集の一覧と、本文の `view: "full"`）の所要時間の実測にする。dev-docs に所要時間の公開仕様が無く、実測が 1,000 回に満たないため、実測の最大にその 50% を加えた仮の値にし、1,000 回以上の計測で導き直す作業をスコープ外に残す
- 時間切れの値と導出の元の値は、`tests/e2e/dev-docs.ts` の定数のコメントと、設計書『テスト実行方法』の E2E テストの前提に記載する
- 2 ケースの `test_normal` が全件の実行で pass する（ケースの待ちは、呼び出しの時間切れの合計に余裕を加えた値を spec の `test.setTimeout` で指定する）
