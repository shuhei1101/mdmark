成立。
推奨の組は TypeScript 7 の上で揃って動き、ビルドツールとテストランナーを選び直す必要は無い。
E2E の配信に使った `http-server` は検証のための仮置きで、配信の手段はモジュール構成設計で決める（依存に入れずに毎回 `npx` で取ると、初回の取得で数分かかる）。

最小再現コードの要点（[scripts/build.mjs](https://github.com/shuhei1101/mdmark/blob/1642bd5299bf000569f961f13358ff8665d1d681/scripts/build.mjs)）:

```js
const version = process.argv[2];
await build({
  entryPoints: ["src/index.ts", "src/index.css"],
  outdir: "dist",
  bundle: true,
  format: "esm",
  define: { __MDMARK_VERSION__: JSON.stringify(version) },
});
```

diff の見どころは、`define` で埋めた版を `src/index.ts` の公開関数が返し、E2E がその値を `dist/` を読んだページで確かめている点。
実行の記録は [poc/検証の記録.log](https://github.com/shuhei1101/mdmark/blob/1642bd5299bf000569f961f13358ff8665d1d681/poc/%E6%A4%9C%E8%A8%BC%E3%81%AE%E8%A8%98%E9%8C%B2.log)。
