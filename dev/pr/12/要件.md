# 要件

## 要望

機能の Issue が、依存の導入・lint・ビルド・テストの揃った状態から着手できる。

<!-- table: data -->

| 項目 | 要件 |
| --- | --- |
| 言語とビルド | コードを TypeScript で書き、1 コマンドで `dist/` に JavaScript と CSS を出す |
| 配布 | 配布物を、GitHub のリポジトリを元にした CDN から、版のタグを固定した URL で読める。使う側へ複製して配る形は取らない |
| 版 | 版を semver で付け、版ごとの変更履歴を持つ |
| lint と整形 | Biome で検査し、違反が 0 件 |
| テスト | 単体・結合・E2E を種別ごとに 1 コマンドで実行できる |
| リポジトリの構成 | `src/`・`dist/`・`templates/`・`schemas/`・`migrations/{版}/`・`guide/`・`plugin/` の役割を設計書に定める |
| 依存と名前 | 自作のほかのプロジェクトに依存せず、その名前をリポジトリ・ドキュメント・コードに出さない（開発の運用に要る箇所を除く） |
| サーバーの言語 | 配布物はブラウザが読む JavaScript と CSS だけで使え、使う側のサーバーの言語に依存しない |
| 完了の基準 | クローンした直後に、依存の導入・lint・ビルド・テストが順に通り、ビルドした配布物を読み込んだページで公開の入口を呼べる |

<!-- /table -->

`dist/` は release ブランチでだけビルドして commit し、版のタグが指す commit に配布物を入れる。
release ブランチでビルドする担当と時点（`version.ini` の更新より後）と、hotfix のときに `dist/` を作り直す場所は、単一ユースケース設計で決める。

変更履歴の正本は `docs/はじめに/変更履歴.md`（リリースのたびに入った PR が 1 PR = 1 行で足される）にし、ルートの `CHANGELOG.md` はそこへのリンクだけにする。

## 影響するユースケース

| 種別 | ユースケース | 影響 | 依存 |
| --- | --- | --- | --- |
| 単一ユースケース | 開発者が配布物をビルドして検査する | 新規（依存の導入・lint・ビルド・テスト） | |
| 単一ユースケース | 使う側が版を固定して配布物を読み込む | 新規（CDN の URL からの JavaScript と CSS の読み込み） | 開発者が配布物をビルドして検査する |
| 複合ユースケース | 版を出してから使う側が読み込むまで | 新規（ビルド・版のタグ・読み込みの連鎖） | 開発者が配布物をビルドして検査する, 使う側が版を固定して配布物を読み込む |

## スコープ外

<!-- table: data -->

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| Markdown を描く機能（mount・render・テーマ・機能のオン・オフ）と設定の JSON Schema | 土台は描く機能を持たない | [#3](https://github.com/shuhei1101/mdmark/issues/3) |
| 拡張記法と、未対応の表示でも本文が読める記法の条件 | 記法を作る Issue が満たす条件 | [#4](https://github.com/shuhei1101/mdmark/issues/4) |
| 索引の JSON Schema | 索引を作る Issue が作る | [#5](https://github.com/shuhei1101/mdmark/issues/5) |
| 部品の JSON Schema | 部品を作る Issue が作る | [#6](https://github.com/shuhei1101/mdmark/issues/6) |
| `templates/` の中身と CLI | 今回は置き場所と役割だけを定める | [#9](https://github.com/shuhei1101/mdmark/issues/9) |
| `migrations/{版}/` の中身と版を上げる機能 | 今回は置き場所と役割だけを定める | [#10](https://github.com/shuhei1101/mdmark/issues/10) |
| `guide/` と `plugin/` の中身 | 今回は置き場所と役割だけを定める | [#11](https://github.com/shuhei1101/mdmark/issues/11) |
| npm レジストリへの公開 | 配布は GitHub のリポジトリを元にした CDN で行う | 予定なし |
