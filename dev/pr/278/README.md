# フロー図の質問・開始のノードの位置が sanitize で落ちて左上に重なる不具合を修正する

## 概要

文書を書く人が、フロー図の部品で `kind` を `question`（質問）・`start`（開始）にしたノードを、定義の `x`・`y` の位置に描けるようになる。

## 背景

[Issue #276](https://github.com/shuhei1101/mdmark/issues/276) の不具合。
[#268](https://github.com/shuhei1101/mdmark/pull/268) で追加した質問・開始のノードは、名前を形に内接させるため `style` の末尾に `padding` を追加する。
sanitize の図の部品向けの `style` の許可（`DIAGRAM_STYLE_PATTERN`）が `padding` を許さないため、埋め込んだ HTML 向けの許可へ回って `left`・`top` が落ち、ノードが図の左上に重なる。
[shuhei1101/knowledge#134](https://github.com/shuhei1101/knowledge/pull/134) の判定フローチャートの描き直しが、この修正と #268 を含むバージョンのリリースを待っている。
