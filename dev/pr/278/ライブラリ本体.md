## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| sanitize の許可 | `DIAGRAM_STYLE_PATTERN` の宣言の選択肢に `padding:{数}px` と `padding:{数}px {数}px` を追加する（`{数}` は 0 以上の整数か小数） | 負の値・単位の無い値・3 つ以上の値は許さない。`nodeInset` が出す 2 つの書き方だけを許す |
| 埋め込んだ HTML | 埋め込んだ HTML の `style` の許可（`filterEmbeddedStyle`）は変えない | `data-mdmark-own` を持たない要素は今のまま |
| 単体テスト | `sanitize.test.ts` に、mdmark が出した図のノードの `left`・`top`・`width`・`height`・`padding` の `style` がそのまま残るケースと、文書に書いた要素の同じ `style` が残らないケースを追加する | 負の `padding` を持つ `style` が `DIAGRAM_STYLE_PATTERN` に当たらないことも確かめる |
| E2E | 判定フローチャートの正常シナリオで、質問・開始のノードの `left`・`top` が定義の `x`・`y` に当たり、ノード同士が重ならないことを確かめる | 既存のケースに確認を追加する |
