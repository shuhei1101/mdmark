# 要件

## 要望

フロー図の部品で `kind` が `question`・`start` のノードを、他の種類のノードと同じく定義の `x`・`y` の位置に描く。

- sanitize が、図の部品が出したノードの `style` の `padding`（px の値 1 つか 2 つ。負の値は許さない）を許し、`left`・`top`・`width`・`height` を残す
- `mount` と `render` で描いた質問・開始のノードの `style` に、`left`・`top`・`width`・`height` と `padding` が残ることをテストで確かめる
- 使い方『図を描く』の「判定フローチャートを書く」の見本の定義で、質問・開始のノードが互いに重ならず定義の位置に描かれることを E2E で確かめる
