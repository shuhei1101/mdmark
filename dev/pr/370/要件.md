# 要件

## 要望

- GitHub の参照（`npx github:shuhei1101/mdmark#{参照}`）で入れたとき、開発用の処理（`lefthook install` と `npm ci --prefix tools/eslint`）を実行せず、CLI が起動する（`serve` が終了せずに待ち受け、MCP のクライアントの `tools/list` がツールの一覧を返却する）
- 開発の作業ツリーでは、今までどおり Git フックと `tools/eslint/` の依存を入れられる
  - `prepare` を除外する。Git フックは lefthook の package の postinstall が直下の `npm ci` で入れ、`tools/eslint/` の依存は `npm run lint:eslint` が起動の前に無ければ入れる
- 利用者と同じ入れ方（npm が Git のリポジトリから取り出して入れ、`prepare` があれば実行する経路）で入れて `serve` を起動する E2E を追加し、release の前に確認できるようにする
