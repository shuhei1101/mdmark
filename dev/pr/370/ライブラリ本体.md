## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| `prepare` の開発用の処理 | `prepare` を除外し、GitHub の参照から入れる経路で `lefthook install` と `npm ci --prefix tools/eslint` を実行しない | [要件](./要件.md)の案 B |
| 開発の作業ツリーでの導入 | Git フックは lefthook の package の postinstall に任せ、`tools/eslint/` の依存は `lint:eslint` が呼ぶ `scripts/eslint.ts` が無いときだけ入れる | 開発コマンドに `tools/eslint/package-lock.json` が変わった後の `npm ci --prefix tools/eslint` を追加 |
| 単一 UC の追加 | ビルドした作業ツリーを一時の Git リポジトリに commit し、`npm exec --yes git+file://{リポジトリ}#{ref} serve` で入れて起動し、MCP のクライアントの `tools/list` がツールの一覧を返却する | `github:` の参照との経路の違いは、単一ユースケース『GitHubの参照から入れてCLIを起動する』の Mock の行 |
| E2E の追加 | `tests/e2e/単一ユースケース/GitHubの参照から入れてCLIを起動する.spec.ts` を追加し、npm のキャッシュ（`npm_config_cache`）を一時フォルダにして手元のキャッシュを使用しない | 依存は npm レジストリから実際に入れる |
| 外部 API 制約 | 追加する E2E は npm レジストリへつなぐ。導入にかかる時間からテストのタイムアウトを決める | タイムアウトの値は E2E テスト作成で実測して決める |
