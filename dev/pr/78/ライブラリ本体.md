## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 用語集の表の引数 | `glossary` の印に任意の引数 `avoid=列名` を追加する。セルは「、」「,」で区切り、空の言い方を除く | 区切りは別名の列と同じ |
| 表に無い列名 | `avoid=` の列名が表に無いときは、`aliases=` と同じ書き方の警告を出し、その表から用語を入れない | - |
| 描いた文書 | やめた言い方の列は、描いた文書の HTML・下線・ツールチップを変えない | 表は今までどおり普通の表として描く |
| 点検の一致 | `findAvoidedTerms` が、索引の用語の `avoid` に加えて、索引の文書の用語集の表のやめた言い方も探す。代わりに使う用語は、索引の `terms`、索引の `docs` の順の文書の表の順で先のもの | 表を持たない文書も含め、索引の全ての文書の本文から探す |
| ずれの内容 | `kind` は `avoided_term` のまま。`file`・`where`・`message` は索引の用語の `avoid` と同じ形 | 新しい種類は足さない |
| 公開の型 | `MdmarkGlossaryEntry` は変えず、やめた言い方は用語集の表の行の読み取りから点検へ渡す | 描いた文書での扱いは #63 |
| CLI | `mdmark check` は `checkIndex` のずれをそのまま出す | 終了コードの決まりは変えない |
| 既存機能への影響 | `avoid=` を書いていない用語集の表の読み取り・描画・点検の結果は変わらない | 索引の Schema は変えないため移行の手順は要らない |
