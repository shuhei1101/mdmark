# 要件

## 要望

用語集の表の印（`glossary`）に、やめた言い方の列を指す任意の引数 `avoid=列名` を書けるようにする。
やめた言い方のセルは、別名のセルと同じく「、」か「,」で区切り、「・」は言い方の中の文字として扱う。
`avoid=` の列名が表に無いときは、ほかの列と同じく書き方の警告を出し、その表からは用語を入れない。
`avoid=` を書いていない用語集の表は、今までどおり読めて、描いた文書と点検の結果も変わらない。
やめた言い方の列は描いた文書を変えず、本文のやめた言い方に下線もツールチップも付けない。

`checkIndex` は、索引の文書の本文に用語集の表のやめた言い方が出たら、索引の用語の `avoid` と同じく `avoided_term` のずれを返す。
ずれの行・内容・探す範囲・語の切れ目・1 件にまとめる決まりは、索引の用語の `avoid` と同じにする。
同じやめた言い方が複数の用語にあるときは、索引の `terms`、索引の `docs` の順の文書の用語集の表の順で、先の用語を代わりに使う用語として内容に書く。
`mdmark check` は `checkIndex` のずれをそのまま出すため、同じずれを出して終了コードで知らせる。
点検は索引と文書を書き換えない。

用語集の表のやめた言い方は、表を持つ文書に限らず、索引の全ての文書の本文から探す。

`未確定`: やめた言い方を公開の型 `MdmarkGlossaryEntry`（`collectReferences` の戻り値の `glossary`）に持たせるか（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 点検の中だけで読み、公開の型は変えない | 公開の API が変わらない | 描いた文書でやめた言い方を扱う [#63](https://github.com/shuhei1101/mdmark/issues/63) が型を変え直す |
| B | `MdmarkGlossaryEntry` に `avoid` を持たせる | #63 がそのまま使える | この PR の要望に要らない公開の型の変更が入る |

推奨: A

この PR の要望は点検で知らせるまでで、公開の型をどう持つかは描いた文書での使い方と一緒に #63 で決めるほうが手戻りが少ない。
