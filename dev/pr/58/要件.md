# 要件

## 要望

タブの印に `group=名前` のキーを加え、同じ `group` のタブ群の選択を揃え、選んだタブ名を覚える。
キーの名前と、揃える・覚える振る舞いは、ai-monitor のドキュメントサイトのタブ（規約『ドキュメント管理』の `### タブとステップ`）と同じにする。

| 機能 | 振る舞い |
| --- | --- |
| 同じ組のタブの選択を揃える | 読む人がタブを選ぶと、同じページの同じ `group` のタブ群のうち、同じタブ名を持つものを同じタブ名へ切り替える。そのタブ名を持たないタブ群は今の選択のまま変えない |
| 選んだタブを覚える | 読む人が選んだタブ名を `group` ごとに localStorage へ残す。`group` を持つタブ群は、描いたとき（読み直し・本文の差し替えを含む）に残したタブ名のタブを選び、残していないかそのタブ名が無ければ最初のタブを選ぶ |

- 残すのは読む人が押したか、キーで移って選んだときだけにする（描いたときの選択と、揃えて切り替わったタブ群の選択は残さない）
- localStorage が使えない（localStorage を取り出す・読み書きするときに例外が出る）ときは、残さず・読まずに、選択を揃える動きと切り替えを続ける
- `group` を持たないタブ群は、今と同じく他のタブ群と揃えず、選択を覚えず、描いた直後は最初のタブを選ぶ
- 値の無い `group=` を書いたタブの印は、書き方の警告を出し、`group` を持たないタブ群として描く
- `group=` 以外のキーと、`キー=値` の形でない指定を書いたタブの印は、表の印と同じく書き方の警告を出し、その指定を当てずに読めた指定だけで描く
- `render` は `group` をタブの部品の HTML に写すだけで、選択は持たない（全ての中身を出す今の形のまま）
- 印刷は今と同じく全ての中身を出す
- `tabs` の機能がオフの文書では、タブにしないので揃える・覚える動きも付かない

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `group` を持たないタブ群の選択を覚える | 文書の中で位置以外にタブ群を指す名前が無く、文書を直すと別のタブ群に当たる。覚えたいタブ群には `group` を付ける | 予定なし |
| URL でタブを指して開く | 要望に含まれない | 予定なし |
