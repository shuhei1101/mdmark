## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| タブの印の読み取り | `<!-- tabs: group=名前 -->` の `group` の値を読み、タブの部品へ渡す。値の無い `group=` は書き方の警告を差し込み、`group` を持たないタブ群として描く | 印の引数は今の `parseMarkArgs` の `キー=値` で読む |
| `render` の出力 | `group` を持つタブ群は `mdmark-tabs` に `data-group` を付ける。中身は今と同じく全て出す | |
| 選択を揃える | 読む人がタブを選ぶと、同じページの `data-group` が同じ `mdmark-tabs` のうち、同じタブ名を持つものをそのタブ名へ切り替える。フォーカスは押したタブ群に残す | ページの中の別の `mount` の文書も対象 |
| 選んだタブを覚える | 読む人が選んだときだけ、`group` ごとのキーで localStorage へタブ名を残す。描いたとき・本文を差し替えたときは残したタブ名のタブを選び、無ければ最初のタブを選ぶ | キーの名前はモジュール構成設計で決める |
| localStorage が使えないとき | 読み書きの例外を拾い、残さず・読まずに揃える動きと切り替えを続ける。書き方の警告は出さない | |
| 印刷 | 今と同じく全ての中身を出す | |
| アクセシビリティ | 揃えて切り替わったタブ群も `aria-selected`・`tabindex`・`hidden` を押したタブ群と同じ作法で付け直す | |
| 既存機能への影響 | `group` を持たないタブ群の動きは変えない | |
| 性能 | 配布物の大きさの上限（非機能要件）に収める | 増分はビルドの検査で確かめる |
