# 要件

## 要望

[#245](https://github.com/shuhei1101/mdmark/issues/245) の要望。範囲と決まったこと（D-206・D-209）は Issue の本文と、本文の `## 必読` に挙げた話し合いの記録が正。
[#275](https://github.com/shuhei1101/mdmark/pull/275) から切り出した作業で、単一ユースケースとモックは #275 でレビューとユーザーの合意を経た内容を移す（[確認ログ](./確認ログ.md)）。

| 項目 | 終わりの条件 |
| --- | --- |
| 既定のピン止め | 表が幅からはみ出すときは先頭の列が既定でピン止めされ、`-pin` で外せる |
| `pin=`・`wide=` | `pin=列名` でその列までを留め、`wide=列名` でその列を折り返さずに広く取り、はみ出した分は横にスクロールする |
| 真偽値 | `check=列名` で指定した列の `true` / `false` のセルを ✓ と空欄で出す |
| 使い方集 | 使い方集の `tables` に書き方がある |

真偽値のセルを ✓ と空欄で出す列は、表のマーカーの引数 `check=列名` で指定する（#275 の単一ユースケース設計で決定）。
`pin=`・`wide=` と同じく列名の引数で書け、`true` の文字を見せたい表の見え方を変えないため。
列の全てのセルが `true` / `false` の列を自動で ✓ と空欄にする案は、文字のまま見せたい表も変わるため採らない。
