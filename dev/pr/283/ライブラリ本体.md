## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 既定のピン止め | 表が幅からはみ出すときは、既定で先頭の列をピン止めする。`-pin` で外す。`pin=` を書いた表は `pin=` の列までを留める | - |
| `pin=`・`wide=` | `pin=列名` でその列までを留め、`wide=列名` で列を折り返さずに広く取り、はみ出した分は横にスクロールする | - |
| 真偽値 | `check=列名` で指定した列の真偽値のセル（`true` / `false`）を ✓ と空欄で出す | 並べ替え・絞り込み・コピーは `true` / `false` の値で動く |
| アクセシビリティ | ✓ は読み上げで「はい」、空欄は「いいえ」に当たる名前を持つ。ピン止めのボタンは押した状態を `aria-pressed` で示す | 部品設計の `accessibility` の今の決まりに従う |
| 書き方の警告 | 見出しに無い列名の `pin=`・`check=` には、今の記法と同じく書き方の警告を出し、読めた指定だけを当てて描く | - |
| 既存機能への影響 | はみ出さない表と、今の書き方の表の見た目を変えない（はみ出す表は先頭の列が留まる） | 既存の単体・結合・E2E を回帰として回す |

## 実装

- Storybook のストーリーは `parts-table--default-overflow`・`parts-table--no-pin`・`parts-table--pin-and-wide`・`parts-table--check` を追加・修正した
- MCP `start_storybook_serve` は `worktree に依存が用意されていません: missing=['.venv の Python']` を返して起動できなかった（mdmark は Python の依存を持たない）。代わりに `scripts/storybook-render.ts` の `renderPart` で 4 つのストーリーを描き、エラー無く描かれ、`data-pin`・`data-check`・留めた列・`mdmark-wide`・✓ の数が部品設計の状態どおりであることを確かめた
- ✓ のアイコンは `iconSvg` が出す SVG の class が `mdmark-diagram-icon` のため、CSS は `.mdmark-check svg` に当てた（モジュール構成の `.mdmark-icon` の記述と同じ見た目）
- セルの値は `src/table-logic.ts` ではなく、モジュール構成のとおり `src/interact/text.ts` の `cellValue` で読む
