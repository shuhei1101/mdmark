# はみ出す表は既定で先頭の列をピン止めし、pin=・wide= と真偽値の ✓ 表示を追加する

## 概要

文書を書く人が、はみ出す表の先頭の列を既定で留め、留める列・広く取る列・真偽値を ✓ で出す列を表のマーカーで指定できるようになる。

## 背景

[Issue #245](https://github.com/shuhei1101/mdmark/issues/245) の要望。
はみ出す表で既定では何もピン止めせず、横にスクロールすると行の名前が見えなくなる。列の幅の指定も真偽値の表示も無い。
[#275](https://github.com/shuhei1101/mdmark/pull/275) の範囲から切り出し、先に完了させる。
