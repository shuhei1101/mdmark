## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 開いた状態で描く指定 | `mount` の `opts` に、`diffSource` を渡したときに読む人が押さずに差分を開いた状態で描く省略可能な指定を加える。省いたときは今のとおり「変更を見る」を押してから開く | 名前と値はインターフェース定義で決める |
| 比べるリビジョン | 開いた状態で描くときも、`revisions` が返した一番新しいリビジョンを後、その 1 つ前を前にする | VS Code 拡張機能は変更後・変更前の順の 2 つを返す |
| 色分けの描き方 | 決定: 変更後の文書を描き、追加・変更したブロックに追加の色、削除したブロックを削除の色でその位置に差し込む（B に決定。[確認ログ](./確認ログ.md)）。リストと表は項目・行の単位で色を当てる | 描いた結果のブロックと Markdown の差分の行を元の行番号で対応づける。追加と削除は左の余白の + / − と読み上げの「追加:」「削除:」で示す |
| 配色 | 色は既存の `--mdmark-color-diff-*` の CSS 変数で取る。新しい色の変数を加えるときはテーマごとの明暗の値を全て置く | - |
| アクセシビリティ | 追加・削除を色だけで表さず、マーカーと読み上げの名前を持たせる | 既存の差分の行と同じ考え方 |
| 既存機能への影響 | 指定を渡さない `mount`・`render`・書き出し・まとめの出力は変えない | - |
