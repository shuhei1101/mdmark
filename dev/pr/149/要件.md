# 要件

## 要望

release/v0.8.0 の E2E で fail した次の 2 つの spec を、テストだけの修正で pass させる。
製品の実装と設計書は変えない。

| Issue | 終わりの条件 |
| --- | --- |
| [#146](https://github.com/shuhei1101/mdmark/issues/146) | `tests/e2e/複合ユースケース/ClaudeCodeで索引を書き換えて点検してから配る.spec.ts` の `test_normal` が、`find_docs` に `format: "json"` を渡すか markdown の本文から当たった行を数える読み方に変わり、pass する |
| [#147](https://github.com/shuhei1101/mdmark/issues/147) | `tests/e2e/単一ユースケース/表から用語集に用語を入れる.spec.ts` の `test_normal_when_avoid_column` と `test_normal_when_other_document_avoid_column` で、`has` に渡すロケーターが `#doc` から始まらない形になり、Chromium・Firefox の両方で 6 件すべて pass する |
