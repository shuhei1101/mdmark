## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 機能 | 表の機能に `resize`（列の幅）を追加し、既定の種類と `data` の種類に入れる。`-resize` で解除でき、`plain` の表には付かない | - |
| つまみ | 列の見出しのセルの右端に、幅を変えるつまみを配置する。ポインターを乗せたとき・フォーカスしたとき・ドラッグ中に表示し、ポインターが粗い画面（`(pointer: coarse)`）では常に表示する | 見た目はモック作成で決める |
| ドラッグ | つまみの範囲で始めたドラッグだけを幅の変更にし、つまみの左の列の幅だけを変える。ほかの列の幅は保つ | 見出しのボタンの操作と取り違えない。マウスとタッチの両方で操作できるようにする |
| ドラッグの代わりの操作 | つまみを動かさずに押すと、つまみの下に「狭める」「広げる」のボタンを出す。1 回で ←・→ キーと同じ 16px 変える。Esc とつまみの外へのフォーカスで閉じる | WCAG 2.2 の 2.5.7（Dragging Movements） |
| 幅の上限 | 列の幅は、列の最小幅から、表の見える幅からほかの留めた列の幅の合計を引いた幅までにする。上限は `aria-valuemax` に入れる | 留めた列を広げても重ならない |
| 元の幅に戻す | つまみのダブルクリック（スマホではダブルタップ）で、その列の幅の指定を解除して描いたときの幅に戻す | `wide=` の列は `wide=` の幅に戻る |
| ピン止め | 幅を変えるたびに、留めた列の `left`・`right` を今の列の幅で再計算する | 留めた列の間に隙間や重なりを出さない |
| 最終列を畳む | 列の幅を変えても、最終列を畳むかは決め直さない | 広げた分は表の中の横のスクロールで出す |
| キーボード | つまみを `role="separator"`（`aria-orientation="vertical"`・`aria-valuenow` に列の幅）にして Tab で選べるようにし、←・→ キーで幅を変え、Enter で元の幅に戻す | - |
