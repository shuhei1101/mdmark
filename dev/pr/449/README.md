# 表の列の幅を、見出しの右端をドラッグして変えられるようにし、ダブルクリックで元の幅に戻す

## 概要

表を参照する人が、列の見出しの右端をドラッグしてその列の幅を変え、ダブルクリック（スマホではダブルタップ）で元の幅に戻せるようにする。

## 背景

[Issue #359](https://github.com/shuhei1101/mdmark/issues/359) の要望。
今の表の列の幅は、文書に記載する `wide=列名`（[#283](https://github.com/shuhei1101/mdmark/pull/283)）でしか変えられず、表を参照する人は狭い列を広げたり、広い列を狭めたりできない。
留めた列の位置の計算は、[#438](https://github.com/shuhei1101/mdmark/pull/438) で選んだ列だけを左端か右端に留める動きに変わっている。
