# 要件

## 要望

VS Code 拡張機能の ID を `ShuheiNishikawa.mdmark-vscode`、表示名を `mdmark for VS Code` に固定し、Marketplace と Open VSX の両方で使う。

- `vscode/package.json` の `name` を `mdmark-vscode`、`displayName` を `mdmark for VS Code` にする。`vscode/package-lock.json` の `name`（ルートと `packages[""]`）も `mdmark-vscode` にする。`publisher`（`ShuheiNishikawa`）は変えない
- 拡張機能の ID を前提にしているテスト（結合テストの `EXTENSION_ID`、E2E の設定画面の絞り込みの文字）を `ShuheiNishikawa.mdmark-vscode` にする
- 拡張機能の ID・`name`・表示名を前提にしている設計書・公開ドキュメントを新しい値にそろえる
- .vsix のファイル名（`mdmark-{バージョン}.vsix`）は変えない。`vsce package` に `--out mdmark-$npm_package_version.vsix` を渡していて `name` に従わず、Marketplace の判定にも関係しない
- コマンドの `category`（`mdmark`）・設定のキー（`mdmark.*`）・コマンドの ID（`mdmark.*`）・出力のチャンネル名は変えない
- 確かめる基準: `npm --prefix vscode run package` が書く .vsix の `extension/package.json` の `name` が `mdmark-vscode`・`displayName` が `mdmark for VS Code` で、`dev/pr/` と `dev/mock/` を除くリポジトリに古い ID `ShuheiNishikawa.mdmark`（後ろに `-vscode` が続かないもの）が残らない

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| .vsix のファイル名（`mdmark-{バージョン}.vsix`）と、それを参照する設計書・E2E | `--out` で決めていて `name` に従わず、Marketplace の判定にも関係しない（Issue の一案のとおり） | 予定なし |
| `dev/mock/pages/vscode-preview/181/` のモックの設定の検索欄の `@ext:ShuheiNishikawa.mdmark` | #181 で合意したモックの記録で、今後の実装の元にならない | 予定なし |
| `vscode/README.md` の見出し（`# mdmark`） | 拡張機能の ID・`name`・表示名を前提にしていない。Marketplace のページの名前は `displayName` から出る | 予定なし |
| Marketplace と Open VSX への公開の自動化（`vsce publish`・`ovsx publish`） | 要望に含まれない | #84 |
