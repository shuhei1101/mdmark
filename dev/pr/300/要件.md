# 要件

## 要望

テスト（単体・結合・E2E）を実行しても、ポート 8782 で待ち受けるプロセスを起動しない。
手元で `mdmark serve` が 8782 で待ち受けている状態でも、テストの結果が変わらない。
`mdmark` の既定のポート（8782）の値は変えず、既定の値は単体テスト `test_read_port` で確認する。

E2E の共通の準備 `tests/e2e/plugin.ts` から `DEFAULT_PORT` と既定のポートを譲り合うロック（`lockDefaultPort`）を削除し、`mdmark serve` を起動する E2E は全て `MDMARK_PORT` に空きポートを指定して起動する。
8782 で待ち受けるプロセスの有無を期待値にしているケースは、指定した空きポートでの有無に置き換える。

シナリオ『MCPサーバーを起動・停止する』の「正常シナリオ（起動する）」は `MDMARK_PORT` に空きポートを指定して起動する形に変え、既定のポートで待ち受けることは単体テスト `test_read_port` で確認する。
同じ手順になる「正常シナリオ（ポートを上書きする）」は削除する。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| `mdmark` の既定のポート（8782）と `plugin/.mcp.json` の接続先 | 要望が既定の値を変えないと定めている | 予定なし |
| 単体テスト `tests/unit/src/plugin/http.test.ts` の 8782 | `Request` の URL と Host の文字列だけで、待ち受けるプロセスを起動しない | 予定なし |
| 公開ドキュメント（`docs/`）の 8782 | 利用者向けの既定のポートの説明で、テストの変更で変わらない | 予定なし |
