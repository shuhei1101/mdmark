# 要件

## 要望

`frameWidth` を持つストーリー（`parts-layoutcolumns--narrow`・`parts-cardgrid--narrow`・`parts-lightbox--narrow`・`parts-wide--small-screen`・`parts-highlight--long`・`parts-gallery--narrow-two`・`parts-gallery--narrow-one`）を、`frameWidth` 以下の画面幅（390x844 を含む）で開いたとき、`detect_screen_issues` が `horizontal-scroll` を返却しない。
画面幅が `frameWidth` と余白の和より広いときは、今と同じく部品を `frameWidth` の幅で描く。
