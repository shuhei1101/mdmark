# 要件

## 要望

VS Code のプレビューのパネルを背面に回して Webview が作り直されたあと、表に戻して描き直したプレビューのスクロールの位置を、背面に回す前の位置へ戻す。

- 歯車（`mdmark.openSettings`）から設定画面を開き、プレビューのタブを押して表に戻したとき、プレビューの見えている先頭の位置が押す前と同じになる（`tests/e2e/単一ユースケース/プレビューから設定を開く.spec.ts` の `test_normal` が pass する）
- 同じ列の別のタブの後ろに回して表に戻したときも同じ（シナリオ『書いた内容をプレビューに映す』の `正常シナリオ（背面から戻る）`）
- 戻した位置をエディタへ送り返して、エディタのスクロールを動かさない
- 差分のパネルも同じく戻す

背面に回す前の位置は、`retainContextWhenHidden: false` のまま、Webview が見えている先頭の元の行番号を Webview の状態（`setState`）に保存し、作り直した後の最初の `render` を描いた後にその行へ戻す（インターフェース定義『プレビューを描き直す』の制約「背面のパネル」）。
