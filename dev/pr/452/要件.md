# 要件

## 要望

結合テスト（`npm run test:integration`）のメモリの使用を減らし、ほかの作業と重なっても全件を最後まで実行できるようにする。

| 要件 | 終わりの条件 |
| --- | --- |
| ブラウザの共有 | `integration-storybook` の Chromium のプロセスを、ファイルごとでなくプロジェクトで 1 つにする。`storybook-setup.ts` の `globalSetup` で `chromium.launchServer()` を起動し、`provide` で指定した `wsEndpoint` へ各ファイルが `chromium.connect()` で接続してページを開く。Vite の依存の事前バンドルを待つ温めは、ファイルごとでなくプロジェクトで 1 回にする |
| ページを閉じる | `openStory` で開いたページを、そのテストの終わりに閉じる |
| 並列の上限 | `vitest.config.ts` の `integration-node`・`integration-storybook`・`integration-browser` に同じ `maxWorkers` を設け、同時に実行するファイルの数を、`integration-node`・`integration-storybook` の合計と `integration-browser` のそれぞれで CPU 数の半分（端末によらず式で決める）までにする。3 つには `sequence.groupOrder` に `unit`・`unit-browser` と違う値を置く |
| 測定 | 同じ端末で、修正の前（develop）を引数なしと暫定の `--maxWorkers=4` の 2 回、修正の後を引数なしで 1 回、`npm run test:integration` を実行する。それぞれの所要時間と、実行中のメモリの使用の最大（テストのプロセスと Chromium の合計）を測り、`ライブラリ本体.md` の `## テスト結果` に記録する |
| メモリの使用 | 修正の後を引数なしで実行したメモリの使用の最大が、修正の前を `--maxWorkers=4` で実行した最大以下 |
| 所要時間 | 修正の後の所要時間が、修正の前（引数なし）の 1.2 倍以内 |
| 全件 pass | 修正の後に `npm run test:integration` が全件 pass する |
