## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 外のタップで閉じる | `document` に捕捉の段の `pointerdown` を付け、開いている番号の `sup.mdmark-fn-ref`（番号とツールチップ）の外が対象なら閉じて `is-dismissed` を付ける | ツールチップの中のリンクの `pointerdown` では閉じない |
| 番号のタップ | `pointerType` が `touch` の番号の `pointerdown` で開き、タッチの `pointerenter`・`pointerleave` では開閉しない。開いた番号のもう一度のタップで末尾の一覧へ移る（確認ログの決着） | `mouse`・`pen` と Enter は今のまま |
| 用語のツールチップとの重なり | 用語のツールチップ（`terms.ts`）の外の `pointerdown` と脚注の外の `pointerdown` は、互いの持ち主とツールチップを外として扱い、どちらを開いても他方を閉じる | |
| 単体テスト | `footnotes.browser.test.ts` に、タッチの 1 回のタップ（`pointerenter`・`pointerdown`・`pointerup`・`pointerleave`・`focus`・`click` を実際の順序で発火）で開いたままになるケース、外の `pointerdown` だけで閉じるケース、ツールチップの中のリンクの `pointerdown` で閉じないケース、マウスのクリックで今のまま一覧へ移るケースを加える | |
| 結合テスト | `mount.browser.test.ts` に、脚注のツールチップをタッチで開いて外のタップで閉じるケースを加える | |
| E2E | 『脚注を見る』に、Playwright の `hasTouch` のコンテキストで、タップで開いたツールチップを外のタップで閉じるケースを加える | |
