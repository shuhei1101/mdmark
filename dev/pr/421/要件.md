# 要件

## 要望

単体テストで、先に作った 2 つの Promise の片方を `await` している間にもう片方が拒否され、未処理の拒否になる書き方を、Promise を作った直後に 1 つずつ待つ書き方に直す。
実装コードは変えない。

| テスト | 箇所 |
| --- | --- |
| `tests/unit/src/cli/markdown-check.test.ts` の `test_read_yaml_key_when_missing` | `missing` と `notString` |
| `tests/unit/src/cli/check.test.ts` の `test_run_check_when_arguments_conflict` | `withBase` と `withoutKey`（同じ型の箇所） |

終わりの条件:

- `npm run test:unit` の全件実行で `Unhandled Rejection` と `PromiseRejectionHandledWarning` が出ない
- 2 つのテストが、直す前と同じ拒否のエラーの型と文言を検証している
