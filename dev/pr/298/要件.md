# 要件

## 要望

[#244](https://github.com/shuhei1101/mdmark/issues/244) の要望。範囲と決まったこと（D-201）は Issue の本文と、本文の `## 必読` に挙げた話し合いの記録が正。
[#275](https://github.com/shuhei1101/mdmark/pull/275) から切り出した作業で、単一ユースケースとモックは #275 でレビューとユーザーの合意を経た内容を移す（[確認ログ](./確認ログ.md)）。

| 項目 | 終わりの条件 |
| --- | --- |
| ER 図の部品 | テーブル（物理名・論理名）・列（名前・型・主キー・外部キー・NOT NULL）・関係（元・先・多重度・ラベル）の定義から ER 図を描く |
| テーブルの種類と色 | テーブルの種類（マスター・トランザクション）を見出しの札と種類の既定の色で示し、`color=` でテーブルの色を指定できる |
| 操作 | 拡大・縮小・移動・全画面・ツールチップが既存の図の部品とそろい、テーブルにポインターを乗せると概要と列の説明を出す |
| 列の畳み | 列の多いテーブルは、主キーと外部キーの列だけを出して残りを畳める |
| 使い方集 | 使い方集の `docs/使い方/図を描く/図を描く.md` に ER 図の部品の書き方があり、`docs/files.yaml` のそのページの行の `description` から ER 図で引ける |

テーブルの種類と色は、#275 のモックの確認でユーザーの指摘により追加した。
