## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| ER 図 | 図の部品に ER 図を追加する。定義はテーブル（物理名・論理名）・列（名前・型・主キー・外部キー・NOT NULL）・関係（元・先・多重度・ラベル）を持つ。テーブルの種類（`master`・`transaction`）を見出しの札と種類の既定の色で示し、`color=` でテーブルの色を指定できる | 見た目は #275 のモック作成で合意した（[確認ログ](./確認ログ.md)） |
| ER 図の操作 | 拡大・縮小・移動・全画面・ツールチップは今の図の枠と図のツールチップを使う。列の多いテーブルは主キーと外部キーの列だけを出して残りを畳める | 畳む列の数の基準は部品設計で決める |
| アクセシビリティ | 列の畳みはキーボードで操作でき、状態を `aria-expanded` で示す | 部品設計の `accessibility` の今の決まりに従う |
| 書き方の警告 | 読めない定義には、今の記法と同じく書き方の警告を出し、読めた定義の図だけを描く | - |
| 性能 | 配布物の大きさを非機能要件の上限の中に収める | ビルドのサイズの検査で確かめる |
| 既存機能への影響 | 今のフロー図・シーケンス図・グラフの描き方を変えない | 既存の単体・結合・E2E を回帰として回す |
