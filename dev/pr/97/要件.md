# 要件

## 要望

コードブロックの情報文字列の言語に応じて、コードを色分け（シンタックスハイライト）して描く。

| 項目 | 振る舞い |
| --- | --- |
| 色分けする言語 | `typescript`（別名 `ts`）・`javascript`（`js`）・`json`・`yaml`（`yml`）・`python`（`py`）・`bash`（`sh`・`shell`）・`html`（`xml`）・`css`・`markdown`（`md`）・`sql` を色分けする。別名は同じ言語として扱う |
| 色分けしないコードブロック | 言語の無いコードブロックと、色分けに対応していない言語のコードブロックは、今のまま色分けせずに描く |
| PR #65 の飾りとの両立 | 題・行番号・行の強調・コードの行の印（足した行・消した行）を付けたコードブロックも、行ごとの分け方と行番号・行頭の `+`・`-` を保ったまま、行の中身を色分けする |
| 当てないコードブロック | ファイルツリー・図の部品の定義・埋め込んだ HTML として描くコードブロックには当てない |
| 写す中身 | 文字を選んで写したときの中身は、色分けの前と同じ文字にする |
| 色 | 色分けの色は CSS 変数で持ち、ライトとダークの両方を持つ。使う側は今のテーマの上書きと同じく CSS 変数で色を変えられる |
| 印刷 | 印刷でも色分けを出す |
| 読み込めないとき | 色分けに使うものを読み込めないときも、コードは欠けずに色分けなしで描く |
| 書き出した HTML | CLI で書き出した HTML でも色分けし、外へ要求しない（非機能要件『書き出した HTML の外部への要求』） |
| 配布物の大きさ | `dist/index.js` を非機能要件『配布ファイル 1 つのサイズ』の上限に収める |
| 機能のオン・オフ | 色分けを機能 `syntax` のオン・オフで切れるようにし、既定はオン |

色分けのライブラリは配布物に束ねず、色分けする言語のコードブロックがある文書でだけ、版を固定した URL から本体と使う言語の分を読む（『外部ライブラリを使うときだけ読み込む』と同じ形）。
書き出した HTML には、使った言語の分だけを埋める。

色分けのライブラリは highlight.js（`@highlightjs/cdn-assets@11.12.0`）にする（[外部ライブラリの設計書](https://github.com/shuhei1101/mdmark/blob/design/render/syntax-highlight/dev/%E8%A8%AD%E8%A8%88%E6%9B%B8/%E5%A4%96%E9%83%A8%E3%83%A9%E3%82%A4%E3%83%96%E3%83%A9%E3%83%AA/highlight.js.yaml)）。

`render`（文書を HTML 文字列にする）は色分けせず、`mount` が描いた後に色分けする。
色分けのライブラリの読み込み先は、設定の `syntax.url`（highlight.js の `es/` フォルダの URL）で差し替える。
