# 要件

## 要望

使う側が描く先の要素（`.mdmark`）の `--mdmark-color-bg` を透明（`transparent`）にし、新しい変数に周りの面の色を指定すれば、次の地を透けずに描く。

<!-- table: data -->

| 区分 | 対象 |
| --- | --- |
| 浮く部品 | 用語のツールチップ・図のツールチップ・全画面の図（モーダル）・ライトボックス・表の列のメニュー・表のメニュー・コピーの形式のパネル・行の URL の知らせ・絞り込みの引き出し・コメントのボタン・コメントの吹き出し・右側の目次のパネル（狭い幅の目次を含む）・まとめた HTML の上の帯と一覧のパネル |
| 覆い・留める見出し | 表の横スクロールの影を隠す覆い・ページのスクロールで留める表の見出し行・ピン止めした列・行の詳細・シーケンス図の相手の見出し・図の線のラベル・選んだタブ |
| 地の色を前提にした色 | 地の色を混ぜた塗り（注意書きの面・図のノードと層と凡例・グラフの模様・バッジの面）・地の色の線（グラフの点と円の項目の縁）・地の色の文字（「コメントを保存」のボタン・押したビューの切り替えと差分の表示の切り替えのボタン） |

<!-- /table -->

そのため、本文の地の `--mdmark-color-bg` とは別に、不透明を前提にした地の CSS 変数を 1 つ公開し、上の対象の参照先をその変数へ替える。

- 新しい変数の既定は `var(--mdmark-color-bg)` にする。新しい変数を書かない使う側は、`--mdmark-color-bg` を上書きしているかによらず見た目が変わらない（`--mdmark-color-bg` だけを透明にした使う側は今と同じく透ける）
- 使う側が新しい変数に周りの面の色を指定すると、表の覆いの色が周りの面と一致し、横スクロールしない表の端に影が出ない
- 描く先の要素（`.mdmark`）とまとめた HTML（`.mdmark-bundle`）の地は `--mdmark-color-bg` のまま描く
- リファレンス『API』の配色の変数とテーマごとの値の表、使い方『テーマを上書きする』に、新しい変数と、`--mdmark-color-bg` を透明にするときに新しい変数へ周りの面の色を指定する書き方を記載する

新しい変数の名前は `--mdmark-color-bg-opaque` にする。

| 対象箇所 | commit | 目的 | 変更回数 | 影響 |

| `src/index.css` の表の横スクロールの影を隠す覆い | [fb64adf2](https://github.com/shuhei1101/mdmark/commit/fb64adf2)（`Markdown をブラウザで描く土台（mount・render・テーマ・機能のオン・オフ）を作る (#16)`） | 横スクロールする表の、続きがある側の端にだけ影を出す（地の色の覆いを中身と一緒に動かし、端の影を隠す） | 2 回 | - |
| `src/index.css` の表の横スクロールの影を隠す覆い | [8a64a17b](https://github.com/shuhei1101/mdmark/commit/8a64a17b)（`mdmark の見た目を洗い出し、mindstella のデザイントークンに揃える (#80)`） | 見た目の値を mindstella のデザイントークンに揃えた（覆いの色は `--mdmark-color-bg` のまま） | 2 回 | 覆いの色を新しい変数へ替えても、続きがある側の端にだけ影を出す目的は壊さない。覆いが周りの面と同じ不透明な色であることが前提で、今回の不具合はこの前提が `--mdmark-color-bg` の透明化で崩れたもの。目的の事象が別のため、直し続けてはいない |

| 項目 | 理由 | 対応予定 |

| MindStella のプレビューへの新しい変数の指定 | 別リポジトリ（shuhei1101/mindstella）の作業で、今回の変数の名前が決まらないと中身が決まらない（Issue の後続） | 起票予定 |

| VS Code 拡張機能のプレビューの状態の表示と設定ファイルを読めない帯の地（`vscode/src/webview/preview.css` の `--preview-bg`） | 文書の外に出す枠で、使う側が `--mdmark-color-bg` を透明にして周りになじませる対象ではない | 予定なし |
| モックの CSS（`dev/mock/`）の `--mdmark-color-bg` | モックは合意した案の記録で、配布物の見た目を変えない | 予定なし |
