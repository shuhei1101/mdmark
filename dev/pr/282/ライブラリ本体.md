## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 公開の CSS 変数 | 不透明を前提にした地の CSS 変数を 1 つ追加する | 名前は `未確定`（要件.md の `## 要望`） |
| 変数の値 | 既定を `var(--mdmark-color-bg)` にする | 使う側が `.mdmark` で上書きした `--mdmark-color-bg` を受けるよう、`.mdmark` で宣言する（`:root` で宣言すると `:root` の値で確定し、`.mdmark` での上書きを受けない） |
| 参照先の切り替え | `src/index.css`・`src/viewer/viewer.css` で `--mdmark-color-bg` を参照する箇所のうち、描く先の要素（`.mdmark`）とまとめた HTML（`.mdmark-bundle`）の地を除く全てを新しい変数へ替える | 対象は要件.md の `## 要望` の表 |
| 使う側の上書き | `--mdmark-color-bg` を不透明な色に上書きしている使う側は、新しい変数もその色になり見た目が変わらない。`--mdmark-color-bg` を透明にする使う側は、新しい変数に周りの面の色を指定する | 指定の書き方は使い方『テーマを上書きする』に記載する |
| 既存の見た目への影響 | 上書きしない使う側の計算値は変わらない | 既存の結合テスト・E2E を回帰として流す |
