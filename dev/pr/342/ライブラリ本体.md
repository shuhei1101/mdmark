## 変更方針

<!-- table: data -->

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| Storybook | フレームワークを `@storybook/react-vite` にし、`addon-a11y` を加える | `未確定`（ストーリーの扱い。要件.md） |
| 部品のストーリー | 部品の HTML 文字列とストーリーの ID・状態は変えない | 部品（`src/parts/`）のコードは変えない |
| ESLint | 直下に `eslint.config.js`（Flat Config）を配置し、今の `eslint-plugin-compat`（対応ブラウザの下限の確認）の設定と、Webview の React の規則を同じファイルに持つ | - |
| Git フック | 直下に `lefthook.yml` を配置し、pre-commit で lint と型検査、pre-push で単体テストを実行する。入口は直下の `package.json` の npm scripts にする | 実行する検査はモジュール構成設計で確定する |
| 既存機能への影響 | 配布物（`dist/index.js`・`dist/index.css`）と公開の `mount`・`mountView`・`mountComments` は変えない。配布物のサイズの検査に合格する | ビルドの単体テストと結合テストで確認する |

結論: 成立。要件.md の `未確定`（ストーリーの扱い）の推奨 A（Storybook を `@storybook/react-vite` の 1 つにする）が成り立つ。

実装へ持ち越す所見:

| 所見 | 扱い |
| --- | --- |
| 今の `.storybook/preview.js` が付ける図・表・ファイルツリーの操作（`attachDiagrams` など）は、PoC のデコレーターに入れていない | 共通のデコレーターの中で、描いた後に同じ操作を呼ぶ |
| WSL の `/mnt/c` では Storybook の開発サーバーがファイルの変更を拾わない | ストーリーを修正したら起動し直す。結合テストは毎回起動するため影響しない |
| 初回の起動は Vite の依存の事前ビルドで 30 秒を超えることがある | 結合テストの Storybook の起動待ちの値を、モジュール構成設計で確認する |
