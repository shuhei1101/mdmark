## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 置く側の決め方 | 新しい `src/interact/placement.ts` の `chooseTipSide` に上下の判定をまとめ、用語・図・ヒントの置く処理から呼ぶ。`attachTermTips`・`attachDiagrams`・`openDiagramDialog`・`attachDiagramTips` は `placement` を受けるオブジェクトの引数にする | 単体テストの `tests/unit/src/interact/placement.test.ts` を作った後、モジュール構成『操作』の `test_files` に足す |
| 用語のツールチップの置き場所 | `place()` で、語の最初の行の上に置く。最初の行の上端からツールチップの高さを引くと 0 を下回るときだけ、最後の行の下に置く | 下に置いたときを表す class は部品設計で決める |
| スクリプトが動かないときの用語のツールチップ | `.mdmark-term-tip` の既定を語の上にし、ポインターが語からツールチップへ移るための透明な線をツールチップの下側に置く | - |
| 図のツールチップの置き場所 | `place` で持ち主（箱の印は箱）の上に `TIP_GAP_PX` を空けて置き、上に収まらないときだけ下に置く | - |
| ヒントのツールチップの置き場所 | `placeHint` で持ち主の上に置き、上に収まらないときだけ下に置く | - |
| 横の位置 | 持ち主の左端に揃え、画面の端から `VIEWPORT_MARGIN_PX` の内に収める（今のまま） | - |
| 出す場所の設定 | 設定に `tooltips.placement`（`top` / `bottom`）を足し、`resolveConfig` で既定 `top` を当て、`mount` から 3 つの置く処理へ渡す。`bottom` のときは下を先にし、下に収まらず上に収まるときだけ上に置く。Schema にキーを足し、`migrations/no-steps.yaml` の `next` の行の `sha256` と `reason` を直す | - |
| 書き出した HTML | `mdmark export`・`mdmark build` が設定の `tooltips` を埋める設定に写し、開いたときの `mount` に渡す | - |
| テスト | 用語・図・ヒントのツールチップが上に開くこと、画面の上端の近くの語では下に開くことを、単体（`terms.browser.test.ts`・`diagram-tips.browser.test.ts`）・結合（ストーリー）・E2E（影響する 2 シナリオ）で確かめる | `bottom` のときの動きも確かめる |
