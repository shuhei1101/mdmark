# 要件

## 要望

描いた文書のツールチップを、既定で持ち主（語・線のラベル・箱の印・ヒントの要素）の上に出す。
上に収まらないとき（持ち主の上端からツールチップの高さを引くと画面の上端を越えるとき）だけ下に出す。
次のツールチップを全て対象にし、出す場所の決め方を揃える。

| ツールチップ | 置く処理 | 今の動き |
| --- | --- | --- |
| 用語と関連文書のツールチップ（本文・埋め込んだ HTML の中・図の箱の中の用語） | [src/interact/terms.ts](https://github.com/shuhei1101/mdmark/blob/develop/src/interact/terms.ts) の `place()` | 語の下に出し、下に収まらず上に収まるときだけ上に出す |
| 図のツールチップ（線の入力の詳細・箱の入力・処理・出力・箱の `hint`） | [src/interact/diagram-tips.ts](https://github.com/shuhei1101/mdmark/blob/develop/src/interact/diagram-tips.ts) の `place` | 持ち主の下に出し、下に収まらず上に収まるときだけ上に出す |
| 埋め込んだ HTML の `data-hint` のツールチップ | [src/interact/diagram-tips.ts](https://github.com/shuhei1101/mdmark/blob/develop/src/interact/diagram-tips.ts) の `placeHint` | 持ち主の下に出し、下に収まらず上に収まるときだけ上に出す |
| スクリプトが動かないときの用語のツールチップ（CSS だけで開く） | [src/index.css](https://github.com/shuhei1101/mdmark/blob/develop/src/index.css) の `.mdmark-term-tip` | 語の下に出す |

画面に出す文言を足すときは「題」を使わず「タイトル」と書く。

出す場所は設定 `tooltips.placement` で変えられるようにする。
値は `top`（既定）/ `bottom` で、`mount` の `opts.config` と `mdmark.config.yaml` の両方で同じキーを読む。
`bottom` のときは下に出し、下に収まらず上に収まるときだけ上に出す（今の動き）。

横の位置は今のまま、持ち主の左端に揃え、画面の端から 16px の内に収める。
