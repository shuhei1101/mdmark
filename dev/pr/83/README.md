# ツールチップを既定で語の上に出し、出す場所を設定で変えられるようにするか決める

## 概要

描いた文書を読む人が、この先の本文をツールチップに隠されずに読み進められるよう、用語・図の要素・埋め込んだ HTML のヒントのツールチップを既定で上に出す。
出す場所を使う側が設定で変えられるようにするかを決める。

## 背景

[Issue #68](https://github.com/shuhei1101/mdmark/issues/68) の要望。
読む人はマウスカーソルを上から下へ動かして読み進めるため、今の動き（下に出し、下に収まらないときだけ上に出す）では、出たツールチップがその先の本文を隠す。
[PR #60](https://github.com/shuhei1101/mdmark/pull/60) のモックへの確認で、ユーザーがツールチップを出す場所の変更と、全ての箇所の洗い出し・設定の検討を求めた。
