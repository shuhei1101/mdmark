# 要件

## 要望

端末の設定のフォルダに CSS のテンプレートのフォルダを持ち、Claude Code のプラグインの MCP サーバーに、テンプレートの一覧・登録・配置の 3 つのツールを追加する。

- テンプレートのフォルダ: 端末の設定のファイルと同じフォルダの `templates/css/`。CSS のファイルと、説明の索引 `templates.yaml` を配置する
- 索引: テンプレートごとに `name`（索引の中で一意）・`file`（テンプレートのフォルダからの CSS のファイル名）・`description`・`tags` を並べる。スキーマの正は `schemas/` の JSON Schema に配置し、登録のときに検査する
- 一覧（`list_templates`）: 索引の行を説明とタグつきで返す。フォルダか索引が無ければ空の一覧を返す。索引を書き換えない
- 登録（`add_template`）: 作業のフォルダの CSS のファイルを、名前・説明・タグと一緒にテンプレートのフォルダへコピーし、索引に行を追加する。フォルダと索引が無ければ作る。同じ名前があれば、上書きを指定しない限りエラーにし、何も書き換えない
- 配置（`apply_template`）: 選んだテンプレートの CSS を配置先のフォルダへコピーし、配置したパスと、`theme` に記載する値（配置先の設定ファイルのフォルダからの相対パス）を返す。配置先は引数で指定するか、既定で `project_dir` から上へ探して最も近い `mdmark.config.yaml` のフォルダにする
- 確認する基準: 一時フォルダを `MDMARK_CONFIG` で端末の設定にしたサーバーで、`add_template` で CSS を 1 つ登録すると、`list_templates` がその名前・説明・タグを返す。別の作業のフォルダで `apply_template` を呼び、返った値を `theme` に記載して `export_html` で書き出した HTML に、テンプレートの CSS の規則が適用される

`未確定`: テンプレートのフォルダの場所（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | 端末の設定のファイルと同じフォルダの `templates/css/` | `MDMARK_CONFIG` で端末の設定を移すと、テンプレートも一緒に移る | 端末の設定のファイルを任意の場所に置くと、テンプレートもその隣になる |
| B | 常に `${XDG_CONFIG_HOME:-~/.config}/mdmark/templates/css/` | 場所が 1 つに決まる | `MDMARK_CONFIG` でテスト用の端末の設定を指しても、テンプレートは手元の端末のフォルダを読み書きする |

推奨: A

結合テストと E2E は `MDMARK_CONFIG` で一時フォルダを端末の設定にするため、テンプレートも同じ一時フォルダに閉じられる。

`未確定`: `apply_template` が設定の `theme` を書き換えるか（決める段: インターフェース定義設計）

| 案 | 内容 | メリット | デメリット |
| --- | --- | --- | --- |
| A | CSS を配置し、`theme` に記載する値を返すだけにする | 使う側の設定ファイルのコメントと、既に記載した `theme` を書き換えない | `theme` の記載は Claude Code が別に行う |
| B | 最も近い `mdmark.config.yaml` の `theme` も書き換える | 1 回の呼び出しで適用される | `theme` は 1 つしか持てず、既に記載した CSS を置き換える |

推奨: A

`theme` は 1 つの CSS しか指せず、既に使う側の CSS を適用している設定で黙って置き換えると、元の CSS が適用されなくなる。

## スコープ外

| 項目 | 理由 | 対応予定 |
| --- | --- | --- |
| CLI のテンプレートのコマンド（`mdmark template` など） | 要望は MCP のツールで、CLI から一覧・登録・配置する要望は無い | 予定なし |
| テンプレートの削除・名前の変更のツール | 要望は一覧・登録・配置で、削除はテンプレートのフォルダのファイルと索引の行を削除すれば足りる | 予定なし |
| 端末の設定を作るスキル（`global-setup`）でテンプレートのフォルダも作る | スキルは #165 が作る | #165 |
| CSS 以外のテンプレート（設定・索引の雛形など） | 要望は CSS で、雛形は `mdmark init` が配置する | 予定なし |
