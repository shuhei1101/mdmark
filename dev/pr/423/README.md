# VS Code のプレビューで、折りたたんだセクションの中を編集中にもプレビューが見出しの辺りへ追従するかを確認する

## 概要

文書の作成者が、折りたたんだセクションの中を編集しているときも、プレビューがそのセクションの見出しの辺りへ追従する。

## 背景

[Issue #332](https://github.com/shuhei1101/mdmark/issues/332) の要望。
エディタとプレビューのスクロールの同期（単一ユースケース『エディタとプレビューのスクロールを合わせる』）は、元の行番号を持つ要素の位置を目印にする。
折りたたんだセクションの中の要素は高さが 0 で目印から外れるため、見出しの辺りに留まるとコードからは読めるが、実際の画面では確認していない。
