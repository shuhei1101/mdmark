# 要件

## 要望

- commit・push で、Git フックが lint・型検査・単体テストを実行しない
  - 直下の `lefthook.yml` を削除し、devDependencies から `lefthook` を削除する（`package-lock.json` も合わせる）
  - 削除した後の直下の `npm ci` が、`.git/hooks` に Git フックを入れない
  - 手で実行する検査（`npm run check`・`npm run test:unit`）は今のまま残す
- 残す生成・配布のジョブは無い（今の `lefthook.yml` は検査だけを持つ）
- lefthook を前提にした設計書を、削除した後の状態に合わせる
- 手元のクローンの `.git/hooks` に lefthook が入れたフック（`pre-commit`・`pre-push`）は、release が master へ入った後に削除する（`反映作業/index.yaml`）。master の `package.json` に `lefthook` が残る間は、どの worktree の `npm ci` もフックを入れ直すため
  - 削除するまでは、pre-push が端末の負荷で通らないときに `git push --no-verify` で push する（[PR #374](https://github.com/shuhei1101/mdmark/pull/374) の確認ログ）
