## 変更方針

| 対象 | 方針 | 補足 |
| --- | --- | --- |
| 線と枠の横の位置 | `followPanelPosition` が `--mdmark-side-toc-panel-end` に、右端の基準からの間隔を入れる。aside の位置は使わない | 右端の基準と間隔は要件の `## 要望`（スクロールする場所の右端から 1rem） |
| 他の部品との重なり | 差分のミニマップと横の範囲が重なる間は、線と枠をミニマップの左端から 8px 左へずらす | 要件の `## 要望`（モック作成で決定） |
| aside の幅 | 線を画面の右端へ移した後に aside が `min-width` で本文の右に幅を取り続けるかを、モジュール構成設計で決める。`min-width` を削除する場合は、コメントの余白の列（`.mdmark-comment-margin`）も先頭へ戻るボタンと同じく避けるかをあわせて決める | 本文の列の幅が変わる場合はモックで見せる |
| ピン止め・fixed・狭い幅・タッチ | 変えない。ピン止めすると今までどおり本文の右の列に出す | - |
| 縦の位置と重なりの順 | #320 の枠の上端・#322 の線の上端と高さ・`z-index: 5` は維持する | - |
| 既存機能への影響 | 公開関数・設定のキー・マーカー・CSS 変数の名前は変えない | 破壊的変更なし |
