# 要件

## 要望

描く先の要素の幅が 48rem 以上でポインターを置ける端末の hover の出し方で、ピン止めしていないとき、右側の目次の右端の線と hover で開く目次の枠を画面の右端に配置し、文書をスクロールしても画面の右端に留める。
描く先の要素が画面より狭くても、線と枠の右端は右端の基準から同じ距離に出る。
ピン止めしたとき・fixed の出し方・狭い幅（48rem 未満）の帯・ポインターを置けない端末の振る舞いは変えない。
#320 で決めた枠の縦の位置と、#322 で決めた線の縦の位置・高さは維持する。

右端の基準は、スクロールする場所（`findScrollContainer`）の右端にする（単一ユースケース設計で決めた）。
画面全体がスクロールするページ（dev-docs・まとめた HTML・VS Code のプレビュー）では画面の右端になり、画面の一部をスクロールするパネルに描いた文書ではパネルの右端になる。
枠の縦の位置・先頭へ戻るボタンと同じ基準にし、パネルの外に線と枠を出さない。

右端の線と目次の枠は、右端の基準（スクロールバーを除く）から 1rem 離す（先頭へ戻るボタンの `--mdmark-back-to-top-gap` と同じ）。
差分のミニマップを出している間は、ミニマップの左端から 8px 左へずらす（先頭へ戻るボタンの `BACK_TO_TOP_AVOID_GAP_PX` と同じ避け方。モック作成で決めた。[確認ログ](./確認ログ.md)）。
