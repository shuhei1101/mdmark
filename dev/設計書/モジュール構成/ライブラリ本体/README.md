# ライブラリ本体

ライブラリ本体の公開の入口・描く処理・部品と、ビルドと部品の描画のスクリプト

## 目次

<!-- table: data -->

| ページ | 概要 |
| --- | --- |
| [公開の入口.ts](./公開の入口.ts.yaml) | 配布物の入口の JavaScript（version()・mount()・render()）と、描いた文書の CSS |
| [描く.ts](./描く.ts.yaml) | 要素に文書を描く mount と、外部ライブラリの読み込み・印刷の前後の折り畳み |
| [描画.ts](./描画.ts.yaml) | Markdown を本文の HTML 文字列にする render と、マーカーの読み取り・落とす設定 |
| [設定と機能.ts](./設定と機能.ts.yaml) | 設定に既定を適用する処理と、文書のマーカーで機能のオン・オフを決める処理 |
| [部品.ts](./部品.ts.yaml) | 通知ブロック・読み込み中のブロックの HTML を返却する関数とストーリー |
| [ビルド.ts](./ビルド.ts.yaml) | バージョンを決めて検査し、esbuild で dist/ を書き込み、サイズを検査する |
| [部品の描画.ts](./部品の描画.ts.yaml) | Storybook のストーリーに部品の HTML を出す描画のインターフェースと Storybook の設定 |
| [記法.ts](./記法.ts.yaml) | マーカーと記法を HTML にする markdown-it のコアルール |
| [操作.ts](./操作.ts.yaml) | mount が描いた記法に付ける表・タブ・セクションと行の詳細の操作 |
| [拡張.ts](./拡張.ts.yaml) | registerExtension の登録表と、Standard Schema での引数の検査 |
| [索引と用語.ts](./索引と用語.ts.yaml) | 索引の構造の検査・参照の表・索引の点検と、用語集の表・用語の下線・関連文書の一覧・ツールチップの操作 |
| [CLI.ts](./CLI.ts.yaml) | init・check・export・build の CLI と、設定・文書の読み取り・埋め込み・HTML の組み立て |
| [書き出したHTMLの起動.ts](./書き出したHTMLの起動.ts.yaml) | 書き出した HTML を開いたときに埋めたモジュールを用意して描き、まとめた HTML で文書を行き来する処理 |
| [バージョンを上げる.ts](./バージョンを上げる.ts.yaml) | mdmark upgrade のバージョンの比較・移行の手順の読み取りと適用・コピーと戻し・変更履歴・質問 |
| [図.ts](./図.ts.yaml) | 図の部品の定義の型と確認・線の形状・部品の HTML・記法のコアルール・拡大と縮小・全画面・ツールチップ・写す操作 |
| [mermaid.ts](./mermaid.ts.yaml) | mermaid のコードブロックを読み込み中のブロックから図の枠に置き換える処理と、テーマの変数の対応表・ソースのタイトルの取り出し・部品の HTML |
| [差分.ts](./差分.ts.yaml) | 差分の取り出し元の型と検査・行と単語の比較・差分を開く UI とミニマップ・差分の部品の HTML |
| [ビューとコメント.ts](./ビューとコメント.ts.yaml) | ビューとコメントの部品を別の配布ファイルに分け、使用するときだけ読み込む処理と、mountView・mountComments・部品の HTML |
| [検査.ts](./検査.ts.yaml) | Webview に適用する ESLint の設定・検査の npm scripts |
| [設定を重ねて読み込む.ts](./設定を重ねて読み込む.ts.yaml) | 端末の設定と上のフォルダの mdmark.config.yaml を探して重ね、CLI・MCP・VS Code 拡張機能が共に呼ぶ処理 |
