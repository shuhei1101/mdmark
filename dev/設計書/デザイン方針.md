# デザイン方針

mdmark が描く文書の既定の見た目に通すデザインの方向性。

| モチーフ・装飾 | 使う場所 | 補足 |

## 色の役割

<!-- table: data -->

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 主 | 地・本文・見出し・主のボタン | `--mdmark-color-bg` / `--mdmark-color-text` / `--mdmark-color-heading` | 主のボタンは文字の色で塗り、ボタンの文字を地の色にする。主のボタンはコメントの入力欄の「コメントを保存」だけで、文言でも示す |
| 控えめな文字 | 引用 | `--mdmark-color-muted` | - |
| 印 | リンク・フォーカスの枠 | `--mdmark-color-link` | mindstella の印の色（青緑）。強い色はこの 1 色だけ。リンクは下線と併せて示す |
| 面と線 | コード・引用・表の見出し行の面、枠と罫線 | `--mdmark-color-surface` / `--mdmark-color-border` | mindstella の本文の表（`--surface-2` / `--border-soft`）と同じ明るさの差 |
| 表の見出し行 | 印の付いた表の留まる見出し行の面 | `--mdmark-color-table-head` | `--mdmark-color-surface` と同じ値 |
| 状態色 | 知らせの枠・書き方の警告・やめた言い方のマーカーだけ | `--mdmark-color-notice-bg` / `--mdmark-color-notice-border` / `--mdmark-color-notice-text` | 書き方の警告は線と題のアイコンだけに使い、地を塗らない。やめた言い方のマーカーは `--mdmark-color-avoided-underline` の既定に線の色を使い、波線の形でも示す |
| コメントの印 | コメントが付いた本文の文字の地と下線、入力欄を開いている間の選んだ文字 | `--mdmark-color-comment-bg` / `--mdmark-color-comment-line` | 地の色と下線で示し、色だけに頼らない |
| 入力欄の誤り | コメントの入力欄の知らせの文字とアイコン、誤りのある本文の欄の枠 | `--mdmark-color-error` | 知らせはアイコンと文でも示す |
| 種類の色 | 注意書きの面・線・題・アイコンだけ | `--mdmark-color-callout-note` / `-tip` / `-important` / `-warning` / `-caution` | 面は種類の色を地に 7%、線は 40% 混ぜる。題の文字とアイコンでも種類を示す |
| 図の層・ノードの種類 | 図の層の背景、箱の枠・アイコン | `--mdmark-color-diagram-llm` / `-dm` / `-script` / `-mcp` / `-data` / `-external` | 層の背景は箱の色を `--mdmark-diagram-lane-tint` でうっすら敷く。箱の種類は色に加えてアイコンと種類の名前でも示す |
| 図の線の種類 | 図の処理の流れ・戻る線 | `--mdmark-color-diagram-line` | 線の種類は色と模様（破線の間隔・太さ・矢じり）の組で分け、色だけで分けない |
| グラフの系列 | グラフの系列の線と点 | `--mdmark-color-series-1` 〜 `-4` | 色に加えて線の模様と点の形でも分ける |
| 色分けの種類 | コードブロックの色分けの文字だけ | `--mdmark-color-syntax-keyword` / `-string` / `-number` / `-type` / `-name` / `-comment` | キーワード・文字列・数値・型・名前・コメントの 6 種類に絞り、変数名・引数・記号は本文の色のまま。コメントは斜体でも示す |

<!-- /table -->

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 本文 | OS 標準のゴシック | `--mdmark-font-body`。大きさ 0.875rem（mindstella の本文の 13px より 1 段大きい 14px）、行間 1.8、行の長さは既定で描く先の幅いっぱい（使う側が `--mdmark-content-width` で上限を渡せる） |
| 見出し | 本文と同じゴシックの太字 | `--mdmark-font-heading` / `--mdmark-heading-weight`（700） |
| コード | 等幅 | `--mdmark-font-mono` |
| 数値 | 等幅数字 | 表の中で桁を揃える |

## 形と奥行き

<!-- table: data -->

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| コードブロック・折り畳み・知らせの枠 | 線と小さめの角丸 | `--mdmark-radius`（4px） |
| 引用 | 面の色と角丸 | 線を引かない |
| 表 | 角丸の外枠と縦横の 1px の線 | 見出し行だけ面の色、本文の行は地の色。外枠の角丸は `--mdmark-radius` の 2 倍 |
| 注意書き | 種類の色の薄い面と淡い線、小さめの角丸 | - |
| 書き方の警告 | 破線と小さめの角丸 | 知らせの枠の塗りと見分ける |
| 節 | 余白と見出しの大きさ・太さ | 見出しの下に線を引かない。見出しの上の余白を下より広く取る |

<!-- /table -->

## 動き

| 場所 | 動き | 補足 |
| --- | --- | --- |
| 折り畳みの開閉 | 動きを付けない | ブラウザ既定の開閉のまま |

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| 印の色以外の強い色 | 印が目立たなくなる | 状態・種類・系列の色は表示にだけ使う |
| 影 | 奥行きは線と面の色で表し、表し方を混ぜない | - |
| グラデーション・光る影 | 静かな見た目とぶつかる | - |
| 見出しの前の記号 | 開発者でない読み手に意味が伝わらない | 変数 `--mdmark-h1-marker` などの既定は空 |
