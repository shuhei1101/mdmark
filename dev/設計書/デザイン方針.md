# デザイン方針

mdmark が描く文書の既定の見た目に通すデザインの方向性。

## 採用スタイル

| 項目 | 内容 | 補足 |
| --- | --- | --- |
| スタイル | モダン | - |
| 分類 | 業務系 | - |
| 明暗 | 両方 | 印刷ではダークを解除する |
| 見本（画面全体） | [dev/mock/styles/modern/](../mock/styles/modern/index.html) | - |
| 見本（部品） | - | 部品を持たない |
| 値の置き場所 | `dev/mock/assets/style.css` | 接頭辞 `--mdmark-` の CSS 変数。使う側が上書きする |
| 選んだ理由 | ジャンルは技術 / プログラミング（技術文書の表示）で、利用者は mdmark を自分のページへ組み込む開発者と、描かれた設計書・手順書を読む人。技術文書で見慣れた中立の見た目にし、どの使う側のページにも馴染ませて、上書きの起点にする | [確認ログ](../pr/16/確認ログ.md) |

## 雰囲気のことば

明快・中立・見慣れた

## モチーフ・装飾

| モチーフ・装飾 | 使う場所 | 補足 |
| --- | --- | --- |
| 細い区切り線 | 見出し 1・見出し 2 の下 | 見出し 3 には引かない |

## 色の役割

| 役割 | 使う場所 | トークン | 補足 |
| --- | --- | --- | --- |
| 主 | 地・本文・見出し | `--mdmark-color-bg` / `--mdmark-color-text` / `--mdmark-color-heading` | - |
| 控えめな文字 | 引用 | `--mdmark-color-muted` | - |
| 差し色 | リンク・フォーカスの枠 | `--mdmark-color-link` | リンクは下線と併せて示す |
| 面と線 | コード・表の本文の行・引用の面、枠と罫線 | `--mdmark-color-surface` / `--mdmark-color-border` | - |
| 表の見出し行 | 表の見出し行の面 | `--mdmark-color-table-head` | 本文の行の面と分ける |
| 状態色 | 知らせの枠・書き方の警告だけ | `--mdmark-color-notice-bg` / `--mdmark-color-notice-border` / `--mdmark-color-notice-text` | 書き方の警告は線と題のアイコンだけに使い、地を塗らない |
| 種類の色 | 注意書きの枠の線・題・アイコンだけ | `--mdmark-color-callout-note` / `-tip` / `-important` / `-warning` / `-caution` | 題の文字とアイコンでも種類を示す |
| 図の層・ノードの種類 | 図の層の背景、箱の枠・アイコン | `--mdmark-color-diagram-llm` / `-dm` / `-script` / `-mcp` / `-data` / `-external` | 層の背景は箱の色を `--mdmark-diagram-lane-tint` でうっすら敷く。箱の種類は色に加えてアイコンと種類の名前でも示す |
| 図の線の種類 | 図の処理の流れ・戻る線 | `--mdmark-color-diagram-line` | 線の種類は色と模様（破線の間隔・太さ・矢じり）の組で分け、色だけで分けない |
| グラフの系列 | グラフの系列の線と点 | `--mdmark-color-series-1` 〜 `-4` | 色に加えて線の模様と点の形でも分ける |

## 文字の役割

| 役割 | 書体の方向 | 補足 |
| --- | --- | --- |
| 本文 | OS 標準のゴシック | `--mdmark-font-body`。大きさ 1rem、行間 1.75、行の長さ 46rem まで |
| 見出し | 本文と同じゴシックの太字 | `--mdmark-font-heading` / `--mdmark-heading-weight` |
| コード | 等幅 | `--mdmark-font-mono` |
| 数値 | 等幅数字 | 表の中で桁を揃える |

## 形と奥行き

| 要素 | 区切り方 | 補足 |
| --- | --- | --- |
| コードブロック・折り畳み・知らせの枠 | 線と小さめの角丸 | `--mdmark-radius`（6px） |
| 引用 | 面の色と角丸 | 線を引かない |
| 表 | 縦横の線 | 見出し行は見出し行の面の色を敷く |
| 注意書き | 種類の色の線と小さめの角丸 | 地は本文と同じ |
| 書き方の警告 | 破線と小さめの角丸 | 知らせの枠の塗りと見分ける |
| 節 | 余白と見出しの下の線 | 見出しの上の余白を下より広く取る |

## 動き

| 場所 | 動き | 補足 |
| --- | --- | --- |
| 折り畳みの開閉 | 動きを付けない | ブラウザ既定の開閉のまま |

## 使わないもの

| 使わないもの | 理由 | 補足 |
| --- | --- | --- |
| 影 | 奥行きは線と面の色で表し、表し方を混ぜない | - |
| グラデーション・光る影 | 中立の見た目とぶつかる | - |
| 見出しの前の記号 | 開発者でない読み手に意味が伝わらない | 変数 `--mdmark-h1-marker` などの既定は空 |
