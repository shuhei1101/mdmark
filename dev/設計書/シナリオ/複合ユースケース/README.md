# 複合ユースケース

単一ユースケースをつないだ業務の流れのシナリオ

## 目次

| ページ | 概要 |
| --- | --- |
| [雛形から1枚のHTMLを配る](./雛形から1枚のHTMLを配る.yaml) | 文書を書く人が CLI で雛形を置き、点検して 1 枚の HTML にまとめ、読む人が file:// で開いて文書を行き来する |
| [固有の部品で図の文書を描いて確かめる](./固有の部品で図の文書を描いて確かめる.yaml) | 使う側が雛形に固有の部品と CSS を足して型で点検し、図の文書を描いて読む人の操作で確かめる |
| [コードブロックのHTMLでチャートとヒントを読む](./コードブロックのHTMLでチャートとヒントを読む.yaml) | 文書を書く人がコードブロックの HTML にチャートとヒントを書き、読む人が描いた文書と書き出した HTML で拡大・移動とツールチップで読む |
| [ビューで探してコメントを付ける](./ビューで探してコメントを付ける.yaml) | 文書を書く人が項目の表をビューの印で囲み、読む人がビューを切り替えて表形式を列で絞り込み、選んだ箇所にコメントを付ける |
