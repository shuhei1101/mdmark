| [版を上げる.ts](./版を上げる.ts.yaml) | 文書の作成者が、移行の手順をバージョンの順に適用して設定のバージョンを呼んだ CLI のバージョンにする（mdmark upgrade） |
| [ビューを描く.ts](./ビューを描く.ts.yaml) | 利用側のページと拡張のモジュールが、列名と項目の値から要素の中にボード表示と表形式のビューを描く（mountView） |
| [コメントを付ける.ts](./コメントを付ける.ts.yaml) | 利用側のページが、自分の要素と読み込みと保存の関数を指定し、要素の中の選んだ箇所にコメントを付ける（mountComments） |
| [本文の参照を取り出す.ts](./本文の参照を取り出す.ts.yaml) | 利用側の処理が、索引と文書の本文から、本文に出た用語・文書の別名の一致と参照先を取り出す（collectMatches） |
