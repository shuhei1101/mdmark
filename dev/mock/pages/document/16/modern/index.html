配布物を読み込んで文書を描く

mdmark は、使う側のページが渡した Markdown をブラウザで文書として描きます。見た目の値は --mdmark- で始まる CSS 変数で配り、API リファレンスに一覧があります。

導入の流れ

  1. 配布物の index.js と index.css をページで読み込む
  2. 描く先の要素を用意する
  3. mount に要素と Markdown を渡す
    • 本文だけを差し替えるときは update を呼ぶ
    • 片付けるときは destroy を呼ぶ

文書を描く

import { mount } from "https://cdn.example.com/mdmark@0.2.0/dist/index.js";

const view = mount(document.querySelector("#doc"), { markdown: "# はじめに\n\n本文を書きます。", config: { features: { table: true, print: true }, libraries: {} } });

view.update("# 書き直した本文");

テーマの変数

変数 役割 明るい配色 ダーク 上書きの例
--mdmark-color-link リンクの色 #0969da #4493f8 .mdmark { --mdmark-color-link: red; }
--mdmark-font-size 本文の文字の大きさ 1rem 1rem .mdmark { --mdmark-font-size: 1.125rem; }
--mdmark-padding 描く先の要素の内側の余白 1.5rem 1.5rem .mdmark { --mdmark-padding: 0; }

使う側が層の外に書いた CSS は、詳細度によらず mdmark の CSS に勝ちます。
