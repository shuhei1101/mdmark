配布物を読み込んで文書を描く

mdmark は、使う側のページが渡した Markdown をブラウザで文書として描きます。見た目の値は --mdmark- で始まる CSS 変数で配り、テーマの上書きで変えられます。配布物の版は v0.6.0 です。

導入の流れ

  1. 配布物の index.js と index.css をページで読み込む
  2. 描く先の要素を用意する
  3. mount に要素と Markdown を渡す
    • 本文だけを差し替えるときは update を呼ぶ
    • 片付けるときは destroy を呼ぶ

文書を描く

描く先の要素と、Markdown と設定を渡します。

import { mount } from "./mdmark/index.js";

const view = mount(document.querySelector("#doc"), {  markdown: "# はじめに\n\n本文を書きます。",
  config: { features: { table: true } },
});

テーマの上書き

使う側のページの CSS で変数の値を書き換えます。

変数 役割 既定の値
--mdmark-color-bg 文書の地の色 #ffffff
--mdmark-color-link リンクの色 #0f766e
--mdmark-color-border 枠と表の罫線の色 #e4e4e7
--mdmark-color-table-head 表の見出し行の色 #f4f4f5

注意書き

補足

変数の名前は変わらないため、使う側の上書きはそのまま効きます。

ヒント

層の外に書いた CSS は、詳細度によらず mdmark の CSS に勝ちます。

重要

書き出した HTML は外のファイルを読みに行きません。

警告

版を上げる前に mdmark check を通してください。

注意

設定の版を手で書き換えると、移行の手順が当たりません。

印の無い引用は、面の色と字下げで本文と分けます。

文書の差分

2 つの版の間で変わった行と語を色で分けます。コメントを付けた範囲は面と下線で示します。

## テーマの上書き
-リンクの色は #0969da です。
+リンクの色は #0f766e です。
変数の名前は変わりません。
