開発の進め方

作業の一覧・リリース・導入の手順・ファイルの置き場所をまとめた文書です。

作業の一覧

表の指定に +search を書いた表です。語の欄と列の絞り込みの両方を満たす行だけを残します。

状態を「済」で絞り込み、語の欄に「描画」と入れた表です。

語に当たる行が無い表です。

リリース

表の指定に closed を書いた表と、open と title=リリースの一覧 を書いた表です。

導入

タブの指定に closed を書いたタブと、open と title=入れ方 を書いたタブです。

タブ（uv・pip）

uv

uv add mdmark で入れます。

pip

pip install mdmark で入れます。

入れ方

macOS

Homebrew で Node.js を入れます。

Windows

winget で Node.js を入れます。

ステップの指定に closed を書いたステップと、open と title=準備 を書いたステップです。

手順（2 ステップ）
  1. 依存を入れる
  2. ビルドする
準備
  1. リポジトリをクローンする
  2. 依存を入れる
  3. テストを流す

ファイルの置き場所

注釈を書き、ツリーの指定に open=all を書いたツリーです。C#/ と #notes.md は前に空白が無いため、名前のまま残します。

mdmark/
├── src/ # ソース
│   ├── index.ts # 入口の `mount`
│   └── tree.css
├── README.md # **必読** `badge:新規`
├── C#/
│   └── Program.cs
├── #notes.md
├── package.json
└── ...

指定の無いツリーです。ルートだけを開きます。

app/
├── src/
│   └── parts/
│       └── tree.ts
├── docs/
│   └── logo.svg
├── data.csv
└── LICENSE

ツリーの指定に open=2 を書いたツリーです。2 階層目までを開きます。

app/
├── src/
│   └── parts/
│       └── tree.ts
└── build.sh

ASCII の罫線で書いたツリーです。

site/
|-- index.html
|-- assets/
|   `-- app.js
`-- dist.zip

読めない指定

タブの指定に closed と open を両方書いたタブです。closed として描きます。

書き方の警告

<!-- tabs: closed open --> の closed と open は同時に書けません。closed として描いています。

タブ（macOS・Windows）

macOS

Homebrew で Node.js を入れます。

Windows

winget で Node.js を入れます。

ステップの指定に、ステップで使えない fold を書いたステップです。fold を当てずに描きます。

書き方の警告

<!-- steps: fold --> の fold はステップでは使えません。使える指定は closed・open・title= です。

  1. 依存を入れる
  2. ビルドする

ステップの指定に title= だけを書いたステップです。開閉しないステップとして描きます。

書き方の警告

<!-- steps: title=準備 --> の title= は closed か open と一緒に書きます。タイトルを付けずに描いています。

  1. リポジトリをクローンする
  2. 依存を入れる

ツリーの指定に読めない open=deep を書いたツリーです。ルートだけを開きます。

書き方の警告

<!-- tree: open=deep --> の open= には all か階層の数を書きます。ルートだけを開いて描いています。
