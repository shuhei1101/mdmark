# リリースの手順

タグを打ってから配布物が届くまでの手順と、確かめる項目をまとめます。

## 確かめる項目

| 項目 | 確かめ方 | 担当 |
| --- | --- | --- |
| テスト | `npm test` がすべて通る | 開発者 |
| 配布物 | `dist/` にバージョンが埋まっている | 開発者 |
| 変更履歴 | 今回の PR が載っている | レビュアー |

> [!WARNING]
> 打ったタグは消さないでください。jsDelivr に届いた配布物は消えません。

## 手順

1. `version.ini` のバージョンを上げる
2. release ブランチを develop へマージする
3. タグ `v0.7.0` を打って push する

  • Mdmark: Config Path

    拡張機能が features と libraries を読む YAML のパス。相対パスは Markdown を含むワークスペースのフォルダから解決する

  • Mdmark: Color Theme

    プレビューと書き出す HTML の配色のテーマ。空のときは mdmark.config.yaml の colorTheme に従い、そこにも無ければ dev-swiss を使う

  • Mdmark › Export: Output Dir

    HTML を書き出すフォルダ。空のときは Markdown と同じフォルダ。相対パスは Markdown を含むワークスペースのフォルダから解決する
