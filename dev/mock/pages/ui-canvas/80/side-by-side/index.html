見た目の洗い出し

mdmark が描く文書とまとめた HTML の UI を部品ごとに、今の値（左）と採用した dev-swiss の値（右）で並べる。どちらも今の src から作った配布物で描いている。

部品dev-swiss の値だけで表せない箇所扱い
注意書き種類の色を地に 7% 混ぜた面と、40% 混ぜた線。今の CSS は種類の色そのものの線だけで、面を塗らない必須（部品の CSS を変える）
フロー図箱の角丸 8px（データの箱は 8px / 20px）を CSS に直に持ち、--mdmark-radius（4px）に揃わない論点
図の全画面・まとめた HTML の一覧のパネル開いたときの後ろの幕の色 rgb(0 0 0 / 0.5)・rgb(0 0 0 / 0.4) を CSS に直に持つ（キャンバスには出ない）論点
