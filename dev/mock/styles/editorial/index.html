配布物を読み込んで文書を描く

mdmark は、使う側のページが渡した Markdown をブラウザで文書として描きます。見た目の値は --mdmark- で始まる CSS 変数で配り、テーマの上書きで変えられます。

導入の流れ

  1. 配布物の index.js と index.css をページで読み込む
  2. 描く先の要素を用意する
  3. mount に要素と Markdown を渡す
    • 本文だけを差し替えるときは update を呼ぶ
    • 片付けるときは destroy を呼ぶ

文書を描く

描く先の要素と、Markdown と設定を渡します。

import { mount } from "./mdmark/index.js";

const view = mount(document.querySelector("#doc"), {
  markdown: "# はじめに\n\n本文を書きます。",
  config: { features: { table: true } },
});

view.update("# 書き直した本文");

テーマの上書き

使う側のページの CSS で変数の値を書き換えます。

変数 役割 既定の値
--mdmark-font-size 本文の文字の大きさ 1.0625rem
--mdmark-line-height 本文の行間 1.9
--mdmark-radius 枠の角の丸み 2px

使う側が層の外に書いた CSS は、詳細度によらず mdmark の CSS に勝ちます。

対応ブラウザ

下限の版を見る
  • Chrome 99
  • Firefox 97
  • Safari 16.4

売上の推移

図は、文書が使うときだけ外部ライブラリを読み込んで描きます。

この箇所を表示できません 図を描くライブラリを読み込めませんでした。通信の状態を確かめて、ページを読み込み直してください。

読み込めなかった箇所のほかは、そのまま描かれます。
