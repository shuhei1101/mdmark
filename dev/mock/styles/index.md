# スタイル一覧

mdmark が描いた文書の既定の見た目（テーマの既定の値）の採用案と候補。

| スタイル | 説明 |
| --- | --- |
| [dev-swiss](./dev-swiss/index.html) `badge:採用` | 開発者ツール × スイス。mindstella と同じ色・行間・角丸で、文字は mindstella の本文（13px）より 1 段大きい 14px にし、見出しの下の線を引かず、注意書きを種類の色の薄い面と淡い線で囲む |
| [developer-tool](./developer-tool/index.html) | 開発者ツール。小さめの文字と詰めた余白で 1 画面に多く載せ、見出しを等幅にして前に `#` を置く |
| [editorial](./editorial/index.html) | エディトリアル。白地に墨色の本文と臙脂のリンク、明朝の見出し、短い行と広い行間で読み物として読ませる |
| [flat](./flat/index.html) | フラット。mindstella の色で、見出しの下の線と表の縦の罫線を引かず、面の明るさの差で区切る |
| [modern](./modern/index.html) | モダン。白地に灰の面と青のリンク、見出しの下に細い区切り線を引く、技術文書で見慣れた見た目 |
| [soft-modern](./soft-modern/index.html) | モダン × mindstella の色。線・余白・文字の大きさは今のまま、色だけを mindstella のトークンに揃える |
