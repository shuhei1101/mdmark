2 桁の行番号と範囲の強調（lines highlight=9-10）

import { mount } from "mdmark";

const element = document.querySelector("#doc");
const response = await fetch("/README.md");
const markdown = await response.text();

const config = {
  features: {
    code: true,
    print: true,
  },
};
mount(element, markdown, config);

読めない指定（異常シナリオ）

書き方の警告

<!-- code: title=app.ts color=red --> の color= は使えません。使えるキーは title=・lines・highlight= です。読めた指定だけを当てて描いています。

コードブロックに無い行の番号（異常シナリオ）

書き方の警告

<!-- code: highlight=2,5 --> の 5 行目がありません。コードブロックは 3 行です。行の番号を 1〜3 で書いてください。5 行目を除いて強調しています。

import { mount } from "mdmark";
const doc = await fetch("/README.md");
mount(document.querySelector("#doc"), await doc.text());

知らないコードの行の印（異常シナリオ）

書き方の警告

コードの行の印 [!code focus] は使えません。使える印は [!code ++]・[!code --]・[!code highlight] です。この行には当てず、書いた文字のまま描いています。

const doc = await fetch("/README.md"); // [!code focus]

印の後にコードブロックが無い（異常シナリオ）

書き方の警告

<!-- code: title=app.ts --> の直後にコードブロックがありません。印の次の行にコードブロックを書いてください。

mount にはコードブロックの題を付けられます。
