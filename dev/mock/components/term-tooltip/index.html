用語のツールチップ

通常（ポインターを乗せるか Tab でフォーカスすると開く）

使う側のアプリは、ワークスペース話し合いの記録を置くフォルダこの用語が出る文書: API、使い方ごとに文書を置きます。詳しくは 置き場所の決まり を見てください。

開いた（意味だけ）

どの文書から読まれているかは、末尾のバックリンクその文書を参照している文書で確かめられます。

開いた（意味と、用語が出る文書）

使う側のアプリは、ワークスペース話し合いの記録を置くフォルダこの用語が出る文書: API、使い方ごとに文書を置きます。

長文（長い意味と多くの文書）

描く前にサニタイズ描く前の HTML から、スクリプトと許可していない要素・属性を落とすこと。文書に書いた script 要素・イベント属性・javascript: の URL を実行しないための処理で、索引に書いた題と意味にも当てるこの用語が出る文書: API、使い方、アーキテクチャ、設定の一覧、非機能要件、印刷する、テーマを上書きするを通します。

上に開いた（下に収まらないとき）

本文の印HTML コメントで書く指定この用語が出る文書: 使い方は描くときに読み取ります。

表のセルの中（表の枠で切れない）

段受け持つもの
本文を描く用語に下線を引き、被参照その文書を参照している文書の一覧を置く

索引も用語集の表も無い文書（下線を引かない）

使う側のアプリは、ワークスペースごとに文書を置きます。
