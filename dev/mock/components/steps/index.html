手順の中にコードと入れ子のリスト（入れ子の番号付きリストはステップにしない）

  1. 配布物を読み込む 
    <link rel="stylesheet" href="dist/index.css">
  2. 描く先の要素を用意する
    1. 要素に ID を付ける
    2. 高さを決める
  3. mount に要素と Markdown を渡す

長文

  1. 使う側のページで、版を固定した URL から配布物の JavaScript と CSS の両方を読み込み、読み込みが終わってから次の手順へ進む
  2. 描く先の要素を用意する

番号付きリストが無い（異常シナリオ）

書き方の警告

<!-- steps --> の範囲に、手順にする番号付きリストがありません。手順を 1. から始まる番号付きリストで書いてください。範囲の中身はそのまま描いています。

書き方の警告

<!-- steps: closed open --> の closed と open は同時に書けません。closed として描いています。

  2. ビルドする
