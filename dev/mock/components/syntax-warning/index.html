書き方の警告

知らない種類（表）

書き方の警告

<!-- table: unknown +sort --> の種類 unknown は使えません。使える種類は data・plain です。既定の種類に +sort を当てて描いています。

知らない機能・キー（表）

書き方の警告

<!-- table: data +unknown size=2 --> の読めない指定を当てずに描いています。

  • +unknown: 使えない機能です。使える機能は sort・pin・filter です
  • size=: 使えないキーです。表の印はキーを持ちません

閉じの印が無い

書き方の警告

<!-- table: data --> の閉じの印 <!-- /table --> がありません。範囲の終わりに閉じの印を書いてください。印から文書の終わりまでを範囲にして描いています。

タブ名にする見出しが無い

書き方の警告

<!-- tabs --> の範囲に、タブ名にする見出しがありません。タブにしたい中身ごとに見出し（### macOS など）を書いてください。範囲の中身はそのまま描いています。

番号付きリストが無い

書き方の警告

<!-- steps --> の範囲に、手順にする番号付きリストがありません。手順を 1. から始まる番号付きリストで書いてください。範囲の中身はそのまま描いています。

知らない開閉の指定

書き方の警告

<!-- section: hidden --> の hidden は使えません。使える値は closed・open です。この節は開いた状態で描いています。

表に無い行を指す行の詳細

書き方の警告

<!-- row-detail: 5 --> の 5 行目がありません。表は 3 行です。行の位置を 1〜3 で書いてください。詳細は表の後の本文として描いています。

切れた参照

書き方の警告

リンク先の #fig-missing の図表がありません。<!-- fig: missing --> を図か表の直前に書くか、リンク先を直してください。

重なった ID

書き方の警告

<!-- fig: arch --> の ID arch は、前の図表と重なっています。別の ID にしてください。この図には番号だけを付け、ID を付けていません。

読めないファイルツリー

書き方の警告

ファイルツリーの 3 行目が、上の行より 2 段深く書かれていて読めません。罫線の段を 1 段ずつ深くしてください。コードブロックのまま描いています。

拡張の引数が Schema に合わない

書き方の警告

<!-- greet: World 2 --> の引数が、拡張 greet の決まりに合いません。直してから読み込み直してください。

  • 1 つ目の World: 英小文字だけで書いてください
  • 2 つ目の 2: 引数は 1 つだけ書けます

長文（長い印）

書き方の警告

<!-- table: data +sort +filter +pin +unknown-feature-with-a-very-long-name closed open --> の closed と open は同時に書けません。どちらか 1 つにしてください。closed を当てて描いています。

比べる: 知らせの枠（外部ライブラリ・拡張を読めない。読む人へ向けた枠）

この図を表示できません

表示に使う拡張（greet）を読み込めませんでした。ネットワークにつながっているかを確かめて、ページを読み込み直してください。
