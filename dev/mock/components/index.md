# コンポーネント索引

新しく足す・変える部品のモック。

| コンポーネント | 説明 |
| --- | --- |
| [backlinks](./backlinks/index.html) | 描いた文書を参照している文書の一覧（文書の末尾の「関連文書」の節） |
| [badge](./badge/index.html) | 頭に `badge:` を付けた行内のコードを描いた札と、頭の後ろが空でバッジにしない行内のコード |
| [callout](./callout/index.html) | 種類ごとの題・色・アイコンを持つ注意書きの枠と、閉じた注意書き |
| [chart](./chart/index.html) | 系列を色と線の模様・点の印の組で分けたグラフ（折れ線）と、色と塗りの模様の組で分けた棒・円、点の印で分けた散布図 |
| [code-block](./code-block/index.html) | コードブロックの題・行番号・行の強調と、コードの行の印で分けた足した行・消した行・強調の行、言語に応じた色分け、言語のラベルとコピーボタン、印刷の見え方 |
| [comment](./comment/index.html) | 選んだ箇所の印・文字を選んだときのコメントのボタン・入力欄と保存できない知らせ・吹き出しと、箇所が見つからないコメントの一覧 |
| [diagram-frame](./diagram-frame/index.html) | 図の題・範囲・更新日・凡例と、右上の拡大・縮小のボタン、押すと戻る倍率のボタンと移動のボタン |
| [diagram-tooltip](./diagram-tooltip/index.html) | 図の矢印の詳細・箱の入力・処理・出力・箱の hint・箱の中の用語のツールチップと、ヒントを外した図 |
| [diff-html-switch](./diff-html-switch/index.html) | 差分の中の埋め込んだ HTML の範囲を、ソースの色分けとプレビューの前と後で切り替える見方のボタンと、片側にだけある・変えていない・スクリプトを書いた範囲 |
| [diff-lines](./diff-lines/index.html) | 削除した行の赤と `-`・追加した行の緑と `+`・行の中で変わった語の濃い色の差分の行・削除した行と追加した行の位置を示すミニマップと、変更が無い・比較対象のリビジョンが無い・読み込み中・一覧を取り出せない場面 |
| [embedded-html](./embedded-html/index.html) | 印の範囲のコードブロックの HTML を本文に溶け込ませて描いた場所と、チャートを含む・列より広い・機能がオフ・書き方の警告の場面 |
| [doc-list](./doc-list/index.html) | まとめた HTML の文書の一覧（フォルダごとに 1 段の見出しにパスを書き、開いている文書を示す） |
| [figure](./figure/index.html) | 図と表に付ける通し番号と、番号にした参照のリンク |
| [file-tree](./file-tree/index.html) | 罫線で書いたフォルダ構成を描いた入れ子のツリー |
| [flow-diagram](./flow-diagram/index.html) | システムの枠と 3 層・外部のシステム・線の種類・線の交差・ループの戻りを持つフロー図 |
| [hint](./hint/index.html) | `data-hint` を持つ要素の右上の印・行内の破線の下線と、図のツールチップと同じ見た目のツールチップ |
| [notice](./notice/index.html) | 外部ライブラリを読めない箇所に出す知らせの枠と、読み込み中の印の場所 |
| [param-control](./param-control/index.html) | スライダー・グラフ・今の値を写すボタンを組み合わせた操作できる部品と、写した・写せなかったの知らせ |
| [preview-status](./preview-status/index.html) | VS Code 拡張機能のプレビューのパネルに出す読み込み中・描けない理由と「リロード」・設定ファイルを読めない帯と「設定ファイルを開く」 |
| [revision-picker](./revision-picker/index.html) | 文書の右上の「変更を見る」と、前と後のリビジョンを日時・label・author で選ぶ欄と、本文を取り出せない場面 |
| [row-detail](./row-detail/index.html) | 表の行の下に開閉して出す行の詳細 |
| [section](./section/index.html) | 見出しのアンカーと、見出しから開閉する節（h1 の節を含む）・右側の目次の上部のすべて展開とすべて折りたたむ・Shift を押しながらの入れ子の開閉 |
| [sequence-diagram](./sequence-diagram/index.html) | 相手を左から右、メッセージを時刻の順に並べ、繰り返しの戻りを持つシーケンス図 |
| [settings-gear](./settings-gear/index.html) | VS Code 拡張機能のプレビューから設定を開く歯車のボタン（エディタのタイトルバーの歯車と、プレビューの中の歯車とテーマのメニュー）の通常・ホバー・フォーカス・押下・メニューを開いた状態 |
| [steps](./steps/index.html) | 番号と線でつないだ手順 |
| [syntax-warning](./syntax-warning/index.html) | 読めない指定とその直し方を書く人へ知らせる書き方の警告 |
| [table](./table/index.html) | 表の種類ごとの見た目と、並べ替え・絞り込み・ピン止め・閉じた表・件数の表示・列の表示の切り替え・計算ごとの集計の行・コピーの形式・行へのリンク、画面の上端と下端に留める見出し行と集計の行、狭い幅で畳む最終列 |
| [tabs](./tabs/index.html) | 見出しの文字をタブ名にしたタブと、URL の ID が指す見出しを持つタブを選ぶ処理 |
| [term-tooltip](./term-tooltip/index.html) | 用語と文書の別名の破線の下線・やめた言い方の波線の下線と、ポインター・フォーカスで開く用語・関連文書・代わりの用語のツールチップと、エイリアスの種類ごとのツールチップ・コマンドのコピーのボタン |
| [toc](./toc/index.html) | 見出しを階層どおりに入れ子にした目次と、描いた文書の右側の目次（hover の右端の線・ピン止め、fixed のサイドバー、今いる節のハイライト、狭い幅の帯） |
| [view](./view/index.html) | 印の表の行を列の値ごとに並べたボードと表のビュー、切り替え・列の見出しのアイコン・表の列の絞り込み |
