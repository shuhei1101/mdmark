# コンポーネント索引

新しく足す・変える部品のモック。

| コンポーネント | 説明 |
| --- | --- |
| [backlinks](./backlinks/index.html) | 描いた文書を参照している文書の一覧（文書の末尾の「関連文書」の節） |
| [badge](./badge/index.html) | 頭に `badge:` を付けた行内のコードを描いた札 |
| [callout](./callout/index.html) | 種類ごとの題・色・アイコンを持つ注意書きの枠と、閉じた注意書き |
| [figure](./figure/index.html) | 図と表に付ける通し番号と、番号にした参照のリンク |
| [file-tree](./file-tree/index.html) | 罫線で書いたフォルダ構成を描いた入れ子のツリー |
| [notice](./notice/index.html) | 外部ライブラリを読めない箇所に出す知らせの枠と、読み込み中の印の場所 |
| [row-detail](./row-detail/index.html) | 表の行の下に開閉して出す行の詳細 |
| [section](./section/index.html) | 見出しのアンカーと、見出しから開閉する節 |
| [steps](./steps/index.html) | 番号と線でつないだ手順 |
| [syntax-warning](./syntax-warning/index.html) | 読めない指定とその直し方を書く人へ知らせる書き方の警告 |
| [table](./table/index.html) | 表の種類ごとの見た目と、並べ替え・絞り込み・ピン止め・閉じた表 |
| [tabs](./tabs/index.html) | 見出しの文字をタブ名にしたタブ |
| [term-tooltip](./term-tooltip/index.html) | 用語と文書の別名の破線の下線と、ポインター・フォーカスで開く用語と関連文書のツールチップ |
| [toc](./toc/index.html) | 見出しを階層どおりに入れ子にした目次 |
